# P05 结合位点与分子对接

编号：P05 · 类型：模型专题 · 目录规模：52 个小节（三级叶子节点，少于 100）。

**知识主线**：识别口袋 → 准备受体配体 → 采样结合姿态 → 评分与实验解释。

**范围与边界**：fpocket、P2Rank（来源模型仓库的配置名为 p2ank）、DiffDock、DiffPepDock；区分口袋发现、姿态预测与亲和力预测。口袋发现包括正构、别构与无配体先验的隐蔽口袋，并说明各自的评价困难。
