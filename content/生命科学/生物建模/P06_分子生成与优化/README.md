# P06 分子生成与优化

编号：P06 · 类型：模型专题 · 目录规模：50 个小节（三级叶子节点，少于 100）。

**知识主线**：化学表示与生成语法 → 条件生成与片段编辑 → 潜空间与图生成 → 分子优化与主动学习 → 科学对象生成（LOGOS） → 生成质量与外部验证。

**范围与边界**：以 GenMol、MolMIM、LOGOS 为入口；分子生成、分子优化与科学对象生成分开讲，不把生成模型当作实验可成药性的保证。LOGOS 的材料任务仅交代边界。
