# P07 核酸序列与结构建模

编号：P07 · 类型：模型专题 · 目录规模：53 个小节（三级叶子节点，少于 100）。

- 5.2.1 序列同源、结构相似与时间切分 <a id="p07-5-2-1"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-5-1-1)
  - 学习目标：说明序列同源、结构相似与时间切分在 RNA 数据中的分工；判断同源泄漏与时间泄漏；把切分策略与泛化结论对应起来。
- 5.2.2 模型验证：基线对照、消融实验与外部验证 <a id="p07-5-2-2"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-5-2-1)
  - 学习目标：说明 RNA 模型评测的基线、消融与外部验证；判断热力学基线、非神经基线与神经模型的差别；把评测协议与模型声明对应起来。
- 5.2.3 训练语料与同源划分：RNA 结构数据的来源与去重 <a id="p07-5-2-3"></a> [WAITING]
  - 学习目标：说明 RNA 结构训练语料的来源、同源划分与去重；判断结构探测数据与热力学数据的差别；把语料构建与 5.2.4 的探测验证分开。
- 5.2.4 RNA 结构探测证据：SHAPE、DMS 与反应性约束 <a id="p07-5-2-4"></a> [WAITING]
  - 学习目标：连接化学反应性和结构可及性，区分实验测量、二级结构假设和折叠软件约束，不由反应性直接断言唯一三维结构。
