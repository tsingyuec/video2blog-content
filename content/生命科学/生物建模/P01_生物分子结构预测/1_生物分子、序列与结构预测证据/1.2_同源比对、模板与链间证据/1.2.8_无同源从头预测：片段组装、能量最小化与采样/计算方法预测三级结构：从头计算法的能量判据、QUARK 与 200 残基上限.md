# 计算方法预测三级结构：从头计算法的能量判据、QUARK 与 200 残基上限

> 本文基于视频演说图文稿整理，配图截自视频。视频按「同源建模 → 穿线 → 从头计算 → 综合法 → 质量评估」的顺序讲完整套方法谱系；本文聚焦**没有模板时怎么算**这一支，其余方法只作为适用边界的对照。时间戳链接中的秒数是**该分 P 内的秒数**，正文会标注分 P 编号。

## 本讲要解决的核心问题（SCQA）

**背景**：蛋白质的三维结构主要靠 X 射线衍射、核磁共振、冷冻电镜等实验手段测定；这些方法普遍存在"三高"——实验材料要求高、仪器造价高、耗时成本高。

**冲突**：几百万条已知蛋白质序列里，只有十万多个有实验结构。绝大多数蛋白质根本没有模板可用：找不到一致度 30% 以上的同源结构，连"把序列穿到已知折叠里"也做不出合格模型。

**疑问**：既没有模板、也没有可靠的穿线结果，还能不能只凭一条氨基酸序列算出三维结构？如果能，它凭什么算得对，又为什么只对小蛋白有效？

**回答（中心思想）**：无模板路线（从头计算法）把"结构预测"变成"**在能量函数定义的构象空间里找最低点**"：以 Anfinsen 的"序列决定结构、结构处于最低自由能"为物理前提，用片段组装生成合理的主链几何，用能量函数给每个构象打分，用蒙特卡洛类采样在能量面上搜索，最后靠质量评估挑出可信模型。它的代价是计算量随链长爆炸，所以工业级软件把可用范围硬性限制在**约 200 个残基以内**；一旦链长超过这个门槛，实际做法退回"综合法"（有模板的片段用同源建模，没模板的片段才用从头计算）。

## 一、先有方法谱系，才谈得上"无模板"

课程把计算方法分成四类，并明确它们不是平级备选，而是**按证据强弱排队**的： [【跳转到 01:26】](https://www.bilibili.com/video/BV13t411372E/?p=81&t=86)

| 方法 | 依赖的证据 | 何时用 |
| --- | --- | --- |
| 同源建模法 | 序列相似 ⇒ 结构相似，需要一致度 ≥ 30% 的模板 | 首选，最快最准 |
| 穿线法（threading） | 序列不相似也可能共享折叠，用能量判据挑模板 | 找不到同源模板时 |
| 从头计算法（ab initio） | 只用序列 + 能量函数 + 构象搜索 | 前两者都失败时 |
| 综合法 | 把序列分域分段，逐段选方法 | 一条链里部分有模板、部分没有 |

![实验方法与计算方法的成本对比：左边是衍射仪、核磁谱仪、电镜，右边是一台电脑](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00005_p81_exp_vs_comp.webp)

这条队列的含义很关键：**从头预测不是"更高级的预测"，而是"最后的兜底"**。它之所以排在最后，不是因为原理不漂亮，而是因为它的搜索空间最大、单位预测成本最高。

### 1.1 为什么模板路线会先失败

同源建模的流程是"选模板 → 做比对 → 建模 → 评估 → 不满意就重建"，其中模板要求目标序列与模板序列一致度**超过 30%**。 [【跳转到 00:43】](https://www.bilibili.com/video/BV13t411372E/?p=82&t=43)

![同源建模的步骤流程：模板选择、模板—目标比对、结构建模、评估与迭代](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00043_p82_homology_flow.webp)

视频给了两条边界：一是**覆盖度**——模板再相似也可能比目标序列短，模型两端没有模板参考，那两段质量就不高；二是**罕见的比对错位**——研究者发现过两个序列高度相似、晶体结构却在一个 β 折叠片末端扭转 60° 的例子，按传统同源建模照抄模板会得到错误结构。 [【跳转到 04:28】](https://www.bilibili.com/video/BV13t411372E/?p=82&t=268)

### 1.2 穿线法：第一次把"能量"请进来

穿线法的前提是：PDB 里十万多个结构按 SCOP 拓扑只归为 **1393 种折叠**，而且 2008 年之后没有新的拓扑产生——新解出的结构一定落在已有的某一种里。 [【跳转到 00:30】](https://www.bilibili.com/video/BV13t411372E/?p=83&t=30)

![SCOP 折叠数随年份的增长曲线：已知结构十万多个，不同拓扑只有 1393 个](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00030_p83_scop_folds.webp)

于是可以把目标序列"像线一样穿"进每一个已知结构，看穿到哪个结构里最舒服：**穿得舒服，能量就低；穿得不舒服，能量就高**。讲师用穿衣服打比方——不合身的衣服让人一直扭动，动得越多能量越高；合身的衣服能待住不动，能量就降下来。 [【跳转到 01:06】](https://www.bilibili.com/video/BV13t411372E/?p=83&t=66)

![穿线法：把目标序列穿进模板库中的每个结构，用能量函数挑出最佳模板](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00066_p83_threading_energy.webp)

注意这里出现了本节的关键概念：**能量函数不只是"评价模型好坏的分数"，它本身就是搜索的判据**。穿线法算的是"序列—结构匹配"的能量，从头计算法算的是"构象本身"的能量——两者共用同一套思路，只是搜索对象从"选哪个模板"换成了"主链怎么摆"。

## 二、从头计算法的物理前提：最低自由能

从头计算法的原理建立在 1973 年 Anfinsen 在《科学》上的一句话：**蛋白质的三维结构决定于自身的氨基酸序列，并且处于最低自由能状态**。 [【跳转到 00:05】](https://www.bilibili.com/video/BV13t411372E/?p=84&t=5)

![Anfinsen 原理与能量面示意：肽链在三维空间中有大量姿态，只有最低点对应稳定结构](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00005_p84_anfinsen.webp)

这句话直接决定了算法的三个部件：

1. **搜索空间**：一条肽链在三维空间里"所有可能的存在姿态"；
2. **打分函数**：给每个姿态算一个自由能；
3. **搜索策略**：在所有姿态里找出自由能最低的那一个，作为预测结果。

讲师随即补了一句大实话：**"可想而知这得是多么大的计算量，因此轻易我们不用从头计算法，实在没招了才用它。"** [【跳转到 00:45】](https://www.bilibili.com/video/BV13t411372E/?p=84&t=45)

这句"计算量大"不是修辞。自由能是构象的函数 $E(\mathbf{x})$，而构象维度随残基数线性增长、构象数目随维度指数增长；要在这样一个高维、崎岖、充满局部极小的能量面上找全局最低点，正是从头预测一切工程取舍（片段化、低分辨率、限长）的来源。

## 三、QUARK：片段组装 + 副本交换蒙特卡洛 + 知识基力场

课程推荐的从头预测软件是密歇根大学张阳教授的 **QUARK**。软件主页把算法写得非常清楚，也正是本节要讲的三个部件： [【跳转到 01:17】](https://www.bilibili.com/video/BV13t411372E/?p=84&t=77)

![QUARK 主页：用 1–20 残基的小片段搭模型，在原子级知识基力场下做副本交换蒙特卡洛模拟](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00077_p84_quark.webp)

- **片段组装**：模型由 **1–20 个残基长的小片段**拼出来，而不是逐个原子从零摆放；
- **采样策略**：**副本交换蒙特卡洛模拟**（replica-exchange Monte Carlo）；
- **能量函数**：**原子级的知识基力场**（atomic-level knowledge-based force field）；
- **成绩与限制**：在 CASP9 与 CASP10 的 free-modeling 组排名第一；**序列长度 200 AA 以内**，更大的蛋白建议改用 I-TASSER。

### 3.1 为什么用"片段"而不是"逐残基"

逐残基搜索等于让算法自己重新发现二级结构：每个残基的 φ/ψ 都有大范围可取值，组合数立刻爆炸。片段组装换了个思路——**从已知结构里统计出"哪些局部构象在真实蛋白中经常出现"，把这些局部构象作为积木**。这样每一步采样都落在一段"生物学上合理"的主链几何上，搜索空间被大幅剪枝。

代价是片段库必须足够大：一个 100 多残基的蛋白，3 残基片段库就有几兆字节、9 残基片段库十几兆字节（这是下一篇文章里 Rosetta 实操视频给出的实测数字）。片段越长，局部几何越"定型"，但也越难找到匹配的片段。

### 3.2 为什么用"知识基"力场

QUARK 用的是**知识基**（knowledge-based）力场：不是从物理第一原理推导原子间相互作用，而是**统计 PDB 中真实结构里"什么几何常见、什么几何罕见"**，把频率转成能量。这与穿线法用能量挑模板是同一套哲学：真实结构里常见的构象给低分，罕见的构象给高分。

下一篇文章（Rosetta 打分函数）会把这类能量项逐项拆开：范德华、溶剂化、静电、氢键属于**物理基**，主链/侧链二面角偏好、参考项属于**知识基**，两类项各自带权重，加权求和得到总能量。

### 3.3 为什么用"副本交换蒙特卡洛"

蒙特卡洛采样的核心规则是：新构象能量更低就接受；能量更高时以一定概率接受，从而**翻过能量壁垒**，不至于卡在局部极小里。副本交换则同时跑多个"温度"不同的副本，让高温副本负责探索、低温副本负责收敛，并定期交换构象。

这解释了为什么从头预测必须"跑很久"：QUARK 的等待时间比穿线法多得多，**大约要两天以上**才出结果，而且一次给出排名前十的模型。 [【跳转到 01:51】](https://www.bilibili.com/video/BV13t411372E/?p=84&t=111)

## 四、200 残基：一条硬边界

QUARK 的输入框直接写着"sequence in FASTA format, less than 200 AA"，讲师也重复了两次：**只能为长度在 200 个氨基酸以内的蛋白质预测结构，太大的蛋白质不行**。 [【跳转到 01:17】](https://www.bilibili.com/video/BV13t411372E/?p=84&t=77)

这条边界不是软件作者的保守，而是三个成本同时随链长增长的结果：

1. **构象空间**：链越长，能量面上的局部极小越多，找到全局最低所需的采样步数呈超线性增长；
2. **片段组合**：每个位置都要从片段库里挑一个候选，长度翻倍意味着需要一致收敛的片段数翻倍；
3. **单次打分**：能量函数里大量项是原子对之间的（范德华、静电、氢键），原子数翻倍，成对项约翻四倍。

所以工程上的处理是"**分工**"：小蛋白（< 200 aa）交给从头计算，大蛋白退回穿线法或综合法。这也解释了为什么 AlphaFold 之前的 CASP 里，free-modeling 组的靶标大多是中小蛋白——不是大家不想算大的，是算不动。

## 五、综合法：一条链里"哪段有模板就用模板"

第四类方法是综合法，代表软件是 **Robetta**：它把同源建模法和从头计算法合在一起，**能找到模板的区域用同源建模，找不到的区域用从头计算**。 [【跳转到 00:20】](https://www.bilibili.com/video/BV13t411372E/?p=85&t=20)

![Robetta 的原理：综合同源建模、穿线与从头计算，按片段情况分别处理](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00005_p85_robetta.webp)

实际使用时，Robetta 先把整条序列切成多个 domain，再给每个 domain 标注建议方法——例如"Predict Domain 1 structure with ab initio modeling""Predict Domain 3 structure with comparative modeling"，用户逐段点击预测。 [【跳转到 00:53】](https://www.bilibili.com/video/BV13t411372E/?p=85&t=53)

![Robetta 把序列分成多个 domain，逐段标注该用从头计算还是比较建模](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00053_p85_robetta_domains.webp)

时间预算的对比很能说明问题：**同源建模需要几小时到几天，从头计算需要几天到几周**，取决于目标序列的预测难易程度；Robetta 本身还要排队两小时以上。 [【跳转到 00:53】](https://www.bilibili.com/video/BV13t411372E/?p=85&t=53)

## 六、算完不算完：模型质量评估

无模板路线的输出是"一堆候选模型"，必须挑。软件自带的分数是第一道筛子：

- I-TASSER 用 **C-score**（-5 到 +2，越高越可信）和 **TM-score**（> 0.5 认为拓扑正确；< 0.17 属于随机模型）； [【跳转到 04:50】](https://www.bilibili.com/video/BV13t411372E/?p=83&t=290)
- SWISS-MODEL 用 **QMEAN**；
- QUARK 用 **TM-score** 给排名前十的模型排序。

但课程强调：自带系数"可以一定程度上反映模型质量，但不能完全反映"，**至少要有三个评估体系都认为模型可靠**，才建议使用。第三方评估常用 SAVES 平台上的六种工具，其中最常用的是 Verify3D 与 PROCHECK。 [【跳转到 00:34】](https://www.bilibili.com/video/BV13t411372E/?p=86&t=34)

![Verify3D：超过 80% 的残基 3D-1D score 大于 0.2 才算合格，曲线低谷提示需要修正的区段](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00076_p86_verify3d.webp)

**Verify3D** 的思路是"序列—结构相容性"：把模型里每个残基的环境（埋藏/暴露、二级结构）与该残基类型在真实结构中偏好的环境比对，给出 3D-1D score。合格线是**超过 80% 的残基分数 ≥ 0.2**，分布曲线的低谷就是可疑区段。

![PROCHECK 的拉氏图：合格模型应有超过 90% 的残基落在红色允许区与黄色额外允许区](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00100_p86_ramachandran.webp)

**PROCHECK** 输出拉氏图（Ramachandran plot），检查主链 φ/ψ 是否落在允许区：合格模型应有**超过 90% 的残基**位于红色允许区与正黄色额外允许区。 [【跳转到 01:40】](https://www.bilibili.com/video/BV13t411372E/?p=86&t=100)

这一节与从头预测的关系是闭环的：**能量函数负责"生成"，质量评估负责"验收"**。两者都在评判构象合理性，但验收用的是与生成过程独立的几何/立体化学判据，避免"自己给自己打分"。

## 七、把选择写成决策树

课程最后给出一张决策树，把本节所有边界收在一张图里： [【跳转到 01:37】](https://www.bilibili.com/video/BV13t411372E/?p=85&t=97)

![方法选择决策树：模板 ≥30% → SWISS-MODEL；能穿线 → I-TASSER；长度 <200 → QUARK；否则 Robetta](assets/计算方法预测三级结构：从头计算法的能量判据、QUARK%20与%20200%20残基上限/00097_p85_decision_tree.webp)

1. 能找到一致度 ≥ 30% 的模板 → **SWISS-MODEL**（又快又准）；
2. 不能，但能"舒服地穿"到现有结构里 → **I-TASSER**；
3. 也不能，且序列长度 < 200 → **QUARK**（等两三天值得）；
4. 长度 > 200 → 退回 **I-TASSER** 慢慢等；
5. I-TASSER 也做不出合格模型 → 这条蛋白太特殊，需要为它单独开发方法。

对照本系列的其他小节：模板建模（1.2.7）解决的是第 1 步"怎么把模板变成模型"；本节解决的是第 3 步"没有模板时怎么算"；而 AlphaFold 一类方法之所以是范式变化，是因为它把"搜索"换成了"从 MSA 直接回归坐标"，不再需要在能量面上采样——但它仍然要面对同样的验收问题（pLDDT、PAE 与几何合理性检查）。

## 小结

- 从头计算法在方法谱系里是**兜底**而非首选：先试同源模板（≥30% 一致度），再试穿线，最后才用从头计算。
- 它的物理前提是 **Anfinsen 假说**：序列决定结构，天然结构对应**最低自由能**；于是预测 = 在构象空间里找能量最低点。
- 工程上把"找最低点"拆成三件可做的事：**片段组装**压缩搜索空间、**能量函数**给构象打分、**蒙特卡洛/副本交换**翻越局部极小。
- QUARK 是这条路线最典型的实现：1–20 残基片段 + 原子级知识基力场 + 副本交换蒙特卡洛，CASP9/10 free-modeling 第一。
- 代价是计算量随链长爆炸，所以有**200 残基上限**；超过就退回穿线法，或用综合法（Robetta）分域分方法处理。
- 无模板路线的输出必须验收：自带分数（C-score/TM-score/QMEAN）只是初筛，至少三个独立评估体系（如 Verify3D、PROCHECK）都通过才算可信。

| 术语 | 一句话解释 |
| --- | --- |
| 从头计算法（ab initio） | 不依赖任何已知结构模板，只用序列 + 能量函数 + 构象搜索算出三维结构 |
| Anfinsen 假说 | 蛋白质三维结构由氨基酸序列决定，且处于最低自由能状态 |
| 能量函数 / 打分函数 | 给一个构象算一个总能量，越低越稳定；是搜索的判据也是筛选的依据 |
| 知识基力场 | 从 PDB 真实结构统计"哪些几何常见"再转成能量的打分方式 |
| 片段组装 | 用从已知结构统计出的短片段（1–20 残基）作为积木拼接主链，而非逐残基搜索 |
| 蒙特卡洛采样 | 能量降低就接受、能量升高按概率接受，从而能翻过能量壁垒 |
| 副本交换（replica exchange） | 同时跑多个不同"温度"的副本并定期交换，兼顾探索与收敛 |
| 穿线法（threading） | 把序列穿进已知折叠库，用能量挑最合适的模板 |
| 综合法 | 把序列分域分段，有模板的段用同源建模、没模板的段用从头计算（如 Robetta） |
| TM-score | 衡量两个结构拓扑相似度的分数，>0.5 通常认为拓扑正确 |
| Verify3D | 检查"残基类型与其结构环境是否相容"的模型评估工具 |
| 拉氏图（Ramachandran plot） | 主链 φ/ψ 二面角的分布图，用来检查构象是否落在允许区 |
