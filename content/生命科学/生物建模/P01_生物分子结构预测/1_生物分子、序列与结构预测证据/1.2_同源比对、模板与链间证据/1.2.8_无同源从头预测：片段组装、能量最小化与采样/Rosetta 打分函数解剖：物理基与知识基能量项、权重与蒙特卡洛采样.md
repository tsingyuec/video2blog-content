# Rosetta 打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样

> 视频来源：[Rosetta 打分函数 - Rosetta Virtual Workshop 2020 & 2021 - The Meiler Lab](https://www.bilibili.com/video/BV1pZ4y1X7ag/)（Bilibili · 钰沐菡-YuMuhan，转载 Meiler Lab 的 Rosetta Workshop 课程，讲者 Cristina Elisa Martina，约 21 分钟）
> 本文基于视频演说图文稿整理，配图截自视频。原视频为英文讲解，本文按中文叙述重写，能量项名称保留 Rosetta 原始写法。上一篇文章讲了"怎么用片段库搭构象"，这一篇讲"**搭出来的构象凭什么打分、分数怎么驱动搜索**"——也就是无模板路线的第二根支柱：能量函数。

## 本讲要解决的核心问题（SCQA）

**背景**：从头预测把结构预测变成"在构象空间里找能量最低点"。既然要"找最低"，就必须先有"能量"这个量。

**冲突**：一个构象的能量无法直接测量。物理上要知道成千上万个原子之间的相互作用，实验上也拿不到任意构象的自由能。更要紧的是，就算有了能量，能量面上到处都是局部极小，一路往下走只会掉进坑里。

**疑问**：Rosetta 的能量到底由哪些项组成？这些项凭什么可信？它们怎么组合成一个总分？又靠什么机制从局部极小里爬出来？

**回答（中心思想）**：Rosetta 的总能量是**一组能量项的加权和**，这些项分成两类——**物理基**（范德华、溶剂化、静电、氢键、二硫键）与**知识基**（主链/侧链二面角偏好、肽键 ω、脯氨酸闭环、参考项）。物理基项权重基本固定为 1，知识基项权重靠实验标定。搜索侧则用**蒙特卡洛采样**：能量降低就接受，能量升高按 $e^{-\Delta E/kT}$ 的概率接受，从而能翻过壁垒、避免困在局部极小。

## 一、为什么需要打分函数

讲者给了两个典型场景： [【跳转到 00:17】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=17)

![两类典型问题：同序列不同构象谁更稳定；同一折叠上哪种突变最合适](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00054_why_score.webp)

1. **同序列、不同构象**：构象 A 与构象 B，哪一个更稳定？
2. **同一折叠、不同突变**：单点突变或多点突变，哪一种最适合这个折叠？

这两类问题的共同点是"**需要排序**"：不是算出一个绝对的自由能，而是判断"哪个更好、好多少"。这正是打分函数的用途——给每个结构一个数值，从而能比较、能排序。 [【跳转到 00:54】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=54)

### 1.1 定义：加权和

视频给出的定义可以直接写成公式：

$$
E_{\text{total}} = \sum_i w_i \, E_i(\text{几何自由度},\ \text{化学身份})
$$

也就是说，每一项能量都是"几何 + 化学"的函数（距离、角度、原子类型），再乘上各自的权重 $w_i$ 求和。 [【跳转到 00:54】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=54)

### 1.2 版本与单位

Rosetta 的打分函数一直在迭代：老论文里的 **score12** → **Talaris13** → **Talaris14** → 现在常用的 **ref2015**。 [【跳转到 01:22】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=82)

单位问题很实际：历史上总能量用 **REU**（Rosetta Energy Unit）表示，是个任意单位，**没法直接跟实验的 kcal/mol 或分子动力学结果比较**；到 ref2015 才可以换算成 kcal/mol。 [【跳转到 01:30】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=90)

这意味着：**跨打分函数版本比较分数是没有意义的**，只能在同一版本内比较。

## 二、两档分辨率：先用粗的搜，再用细的修

Rosetta 里你会遇到两类打分函数： [【跳转到 02:30】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=150)

![低分辨率（质心/粗粒化）与高分辨率（全原子）打分函数的对比](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00150_low_high_res.webp)

| | 低分辨率（centroid / coarse-grain） | 高分辨率（full-atom） |
| --- | --- | --- |
| 表示 | 主链每个重原子显式；侧链用一个球/质心隐式代表大小与性质 | 所有原子显式 |
| 特点 | 能量函数简单、**快** | 更准确、**耗时** |
| 用途 | 构象空间的**全局搜索**（从头折叠、loop 建模） | 构象空间的**局部搜索**（精修） |

关键在最后一行：**全局搜索必须用粗打分，局部精修才用细打分**。因为全局搜索要评估成千上万个差异巨大的构象，用全原子打分根本跑不完；而到了局部，构象已经很接近，需要精细的能量才能分辨优劣。

所以 Rosetta 的很多应用都是"**先低分辨率跑一遍、再用高分辨率精修**"，在计算时间与精度之间取折中。 [【跳转到 03:30】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=210)

这条工程原则在从头预测里尤其重要：上一篇文章里 246 秒/模型的成本，已经是"低分辨率全局搜索 + 高分辨率精修"组合之后的结果。

## 四、物理基项：从范德华到二硫键

### 4.1 范德华：三项拼出一条 Lennard-Jones 曲线

前三个项（`fa_atr`、`fa_rep`、`fa_intra_rep`）描述范德华相互作用。理想情况就是物理课上的 **Lennard-Jones 势**：距离太近强烈排斥，距离适中轻微吸引，距离太远没有相互作用。 [【跳转到 05:53】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=353)

![Lennard-Jones 曲线与 Rosetta 的拆分：排斥项只取近距上升段，吸引项只取中距下降段](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00392_lj_curves.webp)

Rosetta 没有直接用一条完整的 LJ 势，而是**拆成几段分别描述**：`fa_rep` 负责距离很小、能量陡升的排斥段；`fa_atr` 负责中距离的吸引段；超过一定距离后不再计算相互作用（截断），以节省计算量。 [【跳转到 06:32】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=392)

为什么拆？因为这样每一段可以单独调权重、单独做平滑处理，让能量面更"好走"——这直接关系到采样能不能顺利收敛。

### 4.2 溶剂化：三项隐式近似

接下来三项与溶剂化有关。Rosetta 里**蛋白的溶剂化默认是隐式的**：只有对结合至关重要的水（比如与配体或另一个蛋白结合时的水）才显式表示，其余环境水用隐式项近似。 [【跳转到 06:32】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=392)

隐式的好处是省掉大量水分子，代价是精度下降——这是从头预测能在可接受时间内跑完的前提之一。

### 4.3 静电与氢键

`fa_elec` 描述两个带电荷原子相隔一定距离时的相互作用，形式就是库仑定律。 [【跳转到 07:32】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=452)

氢键用了**四个项**，按"谁和谁"划分：

- `hbond_lr_bb`（长程主链）：主要描述 **β 折叠股/片**之间的氢键，因为它们在序列上离得远；
- `hbond_sr_bb`（短程主链）：主要描述 **α 螺旋**，因为螺旋里的氢键通常是残基 $i$ 与 $i+3$ 之间；
- `hbond_bb_sc`：主链—侧链氢键；
- `hbond_sc`：侧链—侧链氢键。

四项合起来，就能描述一个蛋白（或几个相互作用蛋白）里形成的全部氢键。 [【跳转到 08:32】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=512)

顺带一个细节：讲者提到幻灯片上 SR/LR 的标注写反了，**LR 才是长程**——这类小坑在实操读文档时很常见。

### 4.4 二硫键

`dslf_fa13` 单独处理二硫键：二硫键是**共价键**，不是弱相互作用，所以不能当成"两个半胱氨酸碰巧靠近"来算，必须正确描述键长、键角。 [【跳转到 09:01】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=541)

## 五、知识基项：把 PDB 统计变成能量

物理基项算的是"原子之间该有多少相互作用"；知识基项算的是"**这种几何在真实结构里有多常见**"。做法是统计整个 PDB：偏好角度出现得多 → 给低分（有利），罕见 → 给高分（不利）。 [【跳转到 05:10】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=310)

### 5.1 主链与侧链的二面角偏好

`rama_prepro` 描述 Ramachandran 图上 φ/ψ 的概率：残基落在红色允许区，Rosetta 给**负分**（越负越好）；落在不利区域，能量升高，蛋白稳定性受影响。 [【跳转到 09:35】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=575)

`fa_dun` 是侧链版本的同一逻辑：侧链角度也有偏好构象，落在常见 rotamer 区能量好，落在罕见面能量差。 [【跳转到 10:09】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=609)

### 5.2 肽键 ω：只允许 0° 或 180°

`omega` 项是个很直观的例子：肽键只能是顺式（0°）或反式（180°），此时能量为零；如果落在 90° 附近，会有一个约 80 的能量值——"这种情况物理上不可能"。 [【跳转到 10:50】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=650)

同样的逻辑用于脯氨酸（`pro_close`，环必须闭合）和酪氨酸（`yhh_planarity`，χ₃ 必须共平面，0° 或 180°）。 [【跳转到 11:16】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=676)

### 5.3 参考项：只在设计时出场

`ref` 是知识基里最后一项，**只用于设计**：如果你只是比较同一序列的不同构象，它不计入；一旦开始设计（改变氨基酸类型），它会把各氨基酸的去折叠能量（实验已知）以及设计时的氨基酸频率调整考虑进去。 [【跳转到 11:25】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=685)

这一点对理解"结构预测"与"蛋白设计"的分工很重要：**预测时序列固定，参考项是常数；设计时序列在变，参考项才成为变量**。

## 六、权重：物理基固定为 1，知识基靠实验标定

有了项还不够，还要定权重。 [【跳转到 12:22】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=742)

![权重表：物理基项权重基本为 1，知识基项权重带 kcal/mol 系数，部分项权重为 0](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00742_weights.webp)

规则很清楚：

- **物理基项权重基本为 1**——因为我们反映的是物理数据，不需要额外缩放；
- **知识基项权重必须靠实验验证标定**，所以不一定等于 1（表里能看到 0.45、0.4、0.7、0.6、1.25、0.625 这类系数）；
- **部分项的权重被设为 0**，等于默认不参与计算，需要时再打开。

讲者特别强调：**不要随便改权重**，除非你非常清楚自己在做什么。 [【跳转到 12:59】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=779)

如果确实要改，有三种方式：命令行 `score:weights` 指定文件、score:set_weight 逐项设置、patch 文件或 XML 脚本。 [【跳转到 13:16】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=796)

## 七、读一份打分文件：253 与 −82 的差别在哪

讲者回到开头那个例子，逐行读打分文件：第一行表头，红色一行是构象 A，绿色一行是构象 B，**第二列永远是总分**（A = 253，B = −82）。 [【跳转到 14:24】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=864)

![构象 A（253 REU）与构象 B（−82 REU）：红色球是疏水残基，A 松散暴露、B 紧密堆积](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00961_total_energy.webp)

接着看其它列：两者的差别集中在**吸引项与排斥项**——B 的吸引项更负、排斥项更正，也就是 **Lennard-Jones 相互作用更好**。 [【跳转到 15:00】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=900)

为什么？换成俯视图、把疏水残基标成红色就一目了然：构象 A 堆积松散，疏水残基暴露在溶剂中；构象 B 堆积紧密，疏水残基彼此作用。 [【跳转到 15:40】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=940)

这就是"读懂能量项"的价值：**分数差不是抽象数字，它对应一个具体的结构问题（疏水核心没形成）**。讲者的原话是——理解每个能量项，能帮你理解自己结构里的生物学问题。

## 八、蒙特卡洛采样：怎么从局部极小里爬出来

有了能量函数，剩下的问题是"怎么在能量面上走"。Rosetta 用的是**蒙特卡洛采样**。 [【跳转到 16:01】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=961)

规则分两种情况：

1. **新构象能量更低**（$E_{\text{new}} < E_{\text{old}}$）→ 直接接受； [【跳转到 16:29】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=989)

![能量下降即接受：从高能构象走到低能构象，是采样最直接的一步](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/00989_mc_accept.webp)
2. **新构象能量更高** → 取一个 0~1 的随机数 $p$，按概率接受：

$$
\text{若 } e^{-\left(E_{\text{new}}-E_{\text{old}}\right)/k_BT} > p \ \text{则接受，否则丢弃}
$$

![蒙特卡洛接受准则：能量下降必接受，能量上升按玻尔兹曼概率接受](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/01027_mc_local_min.webp)

这条规则的意义在图上一目了然：蓝色那个构象掉进了**局部极小**，不是天然结构所在的全局极小。若只接受能量下降，就永远出不来；而允许"以一定概率接受更差的构象"，才有机会越过能量壁垒。 [【跳转到 17:07】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1027)

讲者顺手做了个对比：**分子动力学一旦掉进局部极小，想越过壁垒非常困难**；而蒙特卡洛采样可以在各处采样、翻越壁垒，最终找到全局极小处的天然结构。 [【跳转到 17:15】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1035)

这也解释了上一篇文章里为什么"一个模型要 246 秒、要跑几百个模型"：蒙特卡洛是随机过程，单次运行的结果有运气成分，必须靠**多次独立采样 + 事后收敛判断**来兜底。

## 九、三个必须知道的扩展

### 9.1 膜蛋白要用专门的打分函数

膜蛋白有一部分插在膜里，而膜不是简单的疏水层：从外到内是水 → 极性头层 → 界面 → 外层疏水 → 内层疏水 → 界面 → 极性 → 水。 [【跳转到 17:41】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1061)

![膜蛋白的分层环境：极性层、界面层、疏水核心，需要专门的打分函数](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/01061_membrane.webp)

所以插膜部分不能按普通溶剂化打分，极性层与疏水层也必须区别对待。Rosetta 提供了专门的膜蛋白打分函数（如 `mpframework_smooth_fa_2012`、`ref2015_memb`、`franklin2019`），做膜蛋白就该用其中之一。 [【跳转到 18:35】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1115)

### 9.2 约束：把实验数据塞进能量函数

通常我们有实验数据，比如"这两个原子相距 6 Å"。做法是加**约束（constraint / restraint）**：如果采样出的距离偏离目标，模型就会被丢弃或惩罚。 [【跳转到 18:51】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1131)

![约束的类型：原子对距离、二面角、角度、坐标固定、结合位点等](assets/Rosetta%20打分函数解剖：物理基与知识基能量项、权重与蒙特卡洛采样/01149_constraints.webp)

约束的类型包括原子对距离、二面角、角度、坐标固定、位点约束等。它的作用有两个：**纳入实验信息**，以及**让设计/建模产出更好的模型**。 [【跳转到 19:39】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1179)

这正是上一篇文章结尾说的"带约束的折叠比盲折更常见"的机制层面解释。

### 9.3 其它分子与实验数据接口

Rosetta 还有非天然氨基酸、碳水化合物（聚糖）、DNA/RNA 的能量项，默认权重为 0，需要时打开即可。 [【跳转到 19:47】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1187)

此外还能把电子密度、残余偶极耦合（RDC）、SAXS 等实验数据整合进打分函数。 [【跳转到 20:20】](https://www.bilibili.com/video/BV1pZ4y1X7ag/?t=1220)

## 小结

- 打分函数（能量函数）的作用是**给结构赋值并排序**；总能量是"几何 + 化学"的函数按权重求和。
- 版本很关键：score12 → Talaris13/14 → ref2015；只有 ref2015 起 REU 才能换算成 kcal/mol，**跨版本比分数没有意义**。
- 两档分辨率分工明确：**低分辨率（质心）做全局搜索，高分辨率（全原子）做局部精修**，先粗后细是标准套路。
- 能量项分两类：**物理基**（范德华、溶剂化、静电、氢键、二硫键）与**知识基**（φ/ψ 与侧链偏好、ω、脯氨酸、酪氨酸平面性、参考项）。
- 权重上，物理基基本固定为 1，知识基靠实验标定；部分项默认权重为 0。**不要随意改权重**。
- 读打分文件时，总分在第二列；分差能追溯到具体能量项，进而对应到具体的结构缺陷（如疏水核心未形成）。
- **蒙特卡洛采样**用玻尔兹曼概率接受更差的构象，从而越过能量壁垒、避免困在局部极小；这也是为什么要跑几百个模型并做事后收敛判断。
- 膜蛋白、约束、非天然残基与实验数据接口，都是在这套框架上"加项/换项"实现的。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 打分函数 / 能量函数 | 给结构算总能量的函数，越低越稳定，用于比较与排序 |
| REU | Rosetta 能量单位；ref2015 起可换算为 kcal/mol |
| 低分辨率（centroid） | 主链显式、侧链用质心球代替的打分模式，快，用于全局搜索 |
| 高分辨率（full-atom） | 全原子打分，准但慢，用于局部精修 |
| 物理基项 | 基于物理定律的能量项：范德华、静电、氢键、溶剂化、二硫键 |
| 知识基项 | 基于 PDB 统计的能量项：二面角偏好、rotamer 概率、ω 惩罚等 |
| Lennard-Jones 势 | 描述原子间"近排斥、中吸引、远无作用"的经典势函数 |
| rama_prepro | 主链 φ/ψ 落在 Ramachandran 允许区时给负分的知识基项 |
| fa_dun | 侧链 rotamer 是否符合天然结构偏好的知识基项 |
| 权重（weight） | 每个能量项在总分中的系数；物理基多为 1，知识基靠实验标定 |
| 蒙特卡洛采样 | 能量降低必接受、升高按 $e^{-\Delta E/kT}$ 概率接受的搜索方法 |
| 约束（constraint） | 把实验距离/角度等信息作为惩罚项加入打分，缩小搜索空间 |
