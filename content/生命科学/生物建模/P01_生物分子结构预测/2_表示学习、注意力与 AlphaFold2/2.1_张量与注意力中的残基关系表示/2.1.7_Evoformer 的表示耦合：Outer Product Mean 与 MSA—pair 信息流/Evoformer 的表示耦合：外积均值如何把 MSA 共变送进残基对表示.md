# Evoformer 的表示耦合：外积均值如何把 MSA 共变送进残基对表示

> 视频来源：[《【AI】05-AlphaFold从零实现系列 - Evoformer》](https://www.bilibili.com/video/BV16NxEekEir/)（Bilibili · 搬运 Killian Mandon 的 AlphaFold 从零实现课程第五讲）｜时长约 24 分钟
>
> 导读：这一讲不推导注意力，而是把 Evoformer 的一个 block 拆成「MSA stack → 外积均值 → pair stack」三段，逐行念论文的 Algorithm 6/7/8/10。本文只讲两条表示**怎么互相喂**：pair 怎么进 MSA 的行注意力当偏置，MSA 又怎么通过外积均值变成 pair 的更新量。三角更新、三角注意力只点到位置，留给专门的小节。

## 本讲要解决的核心问题（SCQA）

**背景**：上一节（2.1.6）我们已经知道，Evoformer 的 MSA 通路里，行方向注意力负责「同一条序列内不同残基之间的对话」，列方向注意力负责「同一残基位置在不同物种之间的对话」。而残基对表示 $Z_{ij}$ 一直作为偏置被喂进行注意力。

**冲突**：但信息不能只往一个方向流。MSA 表示里藏着共演化信号（哪些位置总是一起变），残基对表示里藏着几何约束（哪两个残基该挨着）。如果只有 pair → MSA 这一条通道，MSA 里学到的新证据就永远回不到几何那一侧，结构模块拿不到更新的距离信息。

**疑问**：MSA 表示和残基对表示形状完全不同（一个是 $(s_c, r, c_m)$，一个是 $(r, r, c_z)$），它们到底靠什么模块对接？一个 Evoformer block 里，这两条通道的输入输出是什么、按什么顺序被调用？

**回答（中心思想）**：两条表示靠**一个模块**对接——**外积均值（Outer Product Mean）**。它把 MSA 表示在同一个残基列上、两个不同残基位置的向量做外积，再沿序列维求平均，压成 $c\times c$ 的「共变指纹」，最后线性投影成 $c_z$ 维、加到 $Z_{ij}$ 上。于是每层 Evoformer 的固定节奏是：**MSA 内部先做行/列注意力和过渡层（行注意力吃 pair 偏置），再用外积均值把 MSA 的共变写进 pair，最后 pair 内部做三角更新与三角注意力**。

## 一、一层的输入输出：两个张量、两条通道

### 1.1 两个张量的形状与含义

Evoformer 接收的是一对张量，输出的是**形状完全相同**的一对张量：

| 表示 | 形状 | 两个「空间」维度分别是什么 | 每个向量代表什么 |
| --- | --- | --- | --- |
| MSA 表示 $M_{si}$ | $(s_c, r, c_m)$ | 第一维 $s$ 是比对里的序列（物种），第二维 $i$ 是残基位置 | 某个物种在某个位置上的「残基身份 + 上下文」 |
| 残基对表示 $Z_{ij}$ | $(r, r, c_z)$ | 两个维度都是残基位置 $i$、$j$ | 残基 $i$ 与残基 $j$ 之间的关系 |

其中 $r$ 是蛋白质的残基数量，$s_c$ 是输入嵌入阶段选出的、作为聚类中心的序列条数，$c_m$ 和 $c_z$ 是两个表示的嵌入维度（通道数）。

[【跳转到 01:20】](https://www.bilibili.com/video/BV16NxEekEir/?t=80)

注意图里 pair representation 和 MSA representation 旁边那个字母 **R**：那是 recycle 嵌入的位置，AlphaFold 会把整个架构跑上几轮，用上一轮迭代的输出更新这两个表示。所以严格说，Evoformer 的输入不只是「特征」，还包含「上一轮自己的答案」。

### 1.2 为什么不能直接做全注意力

把两个张量并排看，会立刻遇到一个工程问题：**太大了**。视频用一条 400 个残基的蛋白质举例：

- 残基对表示有 $400 \times 400 = 160{,}000$ 个条目；
- 注意力的显存需求是序列长度的平方级，光一个注意力模块就要约 **102 GB** 显存；
- 作为对比，标准 GPT-4 的上下文窗口才 8000 个 token。

![400 个残基的蛋白质，残基对表示有 160000 个条目](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00207.webp)

[【跳转到 03:27】](https://www.bilibili.com/video/BV16NxEekEir/?t=207)

AlphaFold 的解法不是压缩，而是**换切法**：对 400 个残基改用行方向或列方向的注意力，每一行只需要 400 个注意力分数，量级约 $400^3$，大约 256 MB 一个模块。这就是「行/列注意力」在工程上的由来——它不是为了更聪明，是为了塞得进显存。

## 二、pair → MSA 的回馈：偏置是怎么塞进行注意力的

### 2.1 先把「带偏置的门控自注意力」复习一遍

Evoformer 的注意力不是教科书里的自注意力，而是三个改动叠在一起：**加偏置、加门、限定方向**。视频先快速过了一遍通用流程：

1. 对输入序列做线性嵌入，得到 query、key、value，以及一个额外的**门嵌入** $g$；
2. 算每个 query 与每个 key 的缩放点积，**加上偏置**，再用 softmax 归一化；
3. 用注意力权重对 value 加权求和；
4. 结果乘上门嵌入（sigmoid 压到 0–1），最后过一个线性层输出。

门的作用可以理解成「这个位置这次更新要不要听」：sigmoid 输出接近 0 就把这一路的更新掐掉。注意这里的记法约定：一个从 $c_{in}$ 到 $h\cdot c$ 的线性层，指的是输出维度为「头数 × 每头通道数」的线性层，后面紧跟一次 reshape。

### 2.2 行方向注意力：偏置就是残基对表示

MSA 表示有三个维度，做注意力前必须先决定「沿哪个维度做」。行方向注意力选的是**残基维**：把每一条序列当成一个长度为 $r$ 的序列，在序列内部做注意力。

![Algorithm 7：MSA 行方向门控自注意力，pair 表示在第 3 行变成偏置 b](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00434.webp)

[【跳转到 07:14】](https://www.bilibili.com/video/BV16NxEekEir/?t=434)

把伪代码逐行翻译成一句话：

- 第 1–2 行：对 MSA 做层归一化，再用**无偏置**线性层投影出 $q^h_{si}, k^h_{si}, v^h_{si}$，每个都是 $c$ 维，$h$ 是头编号。
- 第 3 行：**$b^h_{ij} = \mathrm{LinearNoBias}(\mathrm{LayerNorm}(z_{ij}))$**。这一行就是 pair → MSA 的回馈：残基对表示先归一化，再线性投影成每个头一张 $(r,r)$ 的偏置表。
- 第 4 行：门 $g^h_{si} = \mathrm{sigmoid}(\mathrm{Linear}(m_{si}))$。
- 第 5 行：注意力分数 $a^h_{sij} = \mathrm{softmax}_j\left(\frac{1}{\sqrt{c}} {q^h_{si}}^\top k^h_{sj} + b^h_{ij}\right)$。
- 第 6 行：$o^h_{si} = g^h_{si} \odot \sum_j a^h_{sij} v^h_{sj}$。
- 第 7 行：把各头拼接，过输出线性层。

这几行公式里藏着三个值得盯的细节：

**第一，softmax 沿 $j$ 做，不沿 $s$ 做。** 行索引 $s$ 只出现在 query 和 key 里，从不进入 softmax 的归一化维度。也就是说：每一条序列各自独立地在自己的残基之间分配注意力，不同物种之间在这一步不交流。这正是「行方向」的含义——就像对一个矩阵的每一行单独求和时，被求和的是列维度。

**第二，$b$ 是这里唯一不用粗体写的字母。** 视频特意提醒：其他符号（$q, k, v, m, z$）都代表向量，而 $b^h_{ij}$ 的每个条目只是一个**标量**。所以 pair 表示虽然比偏置「多一个维度」，其实是同一件事：$z_{ij}$ 是 $c_z$ 维向量，投影到 $h$ 个头之后，每个头只剩一个数。

**第三，偏置的形状天然匹配。** pair 表示本来就是 $(r, r, c_z)$，天然带着「残基 $i$ 对残基 $j$」的索引；行注意力的分数表也正好是 $(s, i, j)$ 里对每个 $s$ 共享的 $(i,j)$。唯一要做的是把通道维 $c_z$ 换成头数 $h$，所以只需要一个线性层——不需要任何 reshape 或广播技巧。

### 2.3 列方向注意力：这一步不吃偏置

列方向注意力把方向转 90 度：固定残基位置 $i$，在**不同物种**之间做注意力。

![Algorithm 8：列方向门控自注意力，没有偏置项](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00571.webp)

[【跳转到 09:31】](https://www.bilibili.com/video/BV16NxEekEir/?t=571)

对比 Algorithm 7 和 8，差别只有两处：

- 列方向注意力**没有第 3 行**，也就是没有偏置。原因很直白：pair 表示的索引是「残基—残基」，而列注意力的注意力维度是「物种—物种」，两者对不上，硬塞没有意义。
- softmax 的归一化维度从 $j$ 换成了 $t$（物种索引）：$a^h_{sti} = \mathrm{softmax}_t\left(\frac{1}{\sqrt{c}} {q^h_{si}}^\top k^h_{ti}\right)$。

所以「pair 信息进入注意力的位置」在整层里只有一个：**行注意力的偏置项**。这也是检查模块图时最该确认的一条连线。

### 2.4 实现时的一个坑：注意力维度不是最后一维

视频在这里给了一个很实用的工程提醒。在多头注意力的通用实现里，头数通常不是张量的最后一个维度，而是**倒数第三个维度**（形状形如 `(batch, heads, seq, dim)`）。所以把 MSA 和偏置喂进注意力模块时，只需要在初始化时正确指定「注意力维度」：

- 行方向注意力：要把**列维度**指定为注意力维度，因为行注意力里真正被循环遍历的索引是列（残基）；
- 列方向注意力：把**物种维度**指定为注意力维度。

另外，论文伪代码里有一处索引写法（$v$ 和 $o$ 的下标写成 $st$ 而不是 $ti$）与代码不一致，视频作者认为这是论文排版问题，并说明自己按代码实现——这类细节不影响理解，但复现时要以能跑通的实现为准。

## 三、MSA → pair 的通道：外积均值

这是本节的核心。前面所有模块都在各自的张量内部折腾，只有这一个模块负责**跨表示**：把 $(s_c, r, c_m)$ 的 MSA 表示，变成能加到 $(r, r, c_z)$ 上的东西。

### 3.1 四步伪代码

![Algorithm 10：外积均值，五行完成 MSA 到残基对的形状转换](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00650.webp)

[【跳转到 10:50】](https://www.bilibili.com/video/BV16NxEekEir/?t=650)

$$
\begin{aligned}
m_{si} &\leftarrow \mathrm{LayerNorm}(m_{si}) \\
a_{si},\ b_{si} &= \mathrm{Linear}(m_{si}) \qquad a_{si}, b_{si} \in \mathbb{R}^{c} \\
o_{ij} &= \mathrm{flatten}\left(\mathrm{mean}_s\left(a_{si} \otimes b_{sj}\right)\right) \qquad o_{ij} \in \mathbb{R}^{c \cdot c} \\
z_{ij} &= \mathrm{Linear}(o_{ij}) \qquad z_{ij} \in \mathbb{R}^{c_z}
\end{aligned}
$$

逐行读：

1. **归一化**：对 MSA 表示做层归一化，稳定数值。
2. **两个投影**：用同一个线性层把 $c_m$ 维的 $m_{si}$ 投到 $c=32$ 维，得到两套向量 $a_{si}$ 和 $b_{si}$。注意这里的通道数 $c=32$ 远小于 $c_z$，是刻意压小的。
3. **外积 + 求均值 + 展平**：对固定的残基位置 $i$ 和 $j$，取 $a_{si}$（位置 $i$ 的向量）与 $b_{sj}$（位置 $j$ 的向量）做外积，得到一个 $c \times c$ 的矩阵；对全部序列 $s$ 求平均；再把这个矩阵展平成 $c \cdot c = 1024$ 维。
4. **线性投影**：把 1024 维压回 $c_z$ 维，形状正好是 $Z_{ij}$ 要的通道数。

### 3.2 为什么是外积：把「两个位置的通道」两两配对

外积 $a_{si} \otimes b_{sj}$ 做的事很朴素：$a$ 的每一个通道和 $b$ 的每一个通道相乘，得到 $c \times c$ 个数。如果把每个通道理解成一种「特征探测器」，那么外积就是在问：

> 位置 $i$ 的第 $p$ 种特征，和位置 $j$ 的第 $q$ 种特征，**在同一个物种身上**是不是同时出现？

这正是共演化（covariation）信号的一种代数写法。举一个具体例子：假设位置 $i$ 的某个通道对「带负电」敏感、位置 $j$ 的某个通道对「带正电」敏感，那么在一个物种里如果 $i$ 是谷氨酸、$j$ 是赖氨酸，这两个通道会同时亮，对应的那个外积条目就大；换一个物种两者都变成中性，这个条目就小。外积把这种「同现」写成了一张 $c \times c$ 的表。

### 3.3 为什么要求均值：沿序列维消掉物种

外积之后，每个 $(i,j)$ 位置都有一个**按物种**的 $c \times c$ 表——也就是 $s_c$ 张表。但 pair 表示里每个 $(i,j)$ 只能有一个 $c_z$ 维向量，没有「物种」这一维。

`mean_s` 就是用来消掉这个维度的：把 $s_c$ 个物种的外积表逐元素平均，得到一张「这一对位置在整条 MSA 上的平均共变指纹」。直观地说，单个物种只能说明「这一次是这样」，只有跨物种平均之后，才剩下「这对位置倾向于一起变」这种跨物种的统计规律。

求均值还顺带解决了另一个问题：**它让输出的形状与 $s_c$ 无关**。不管输入是几十条还是几千条序列，外积均值出来的都是 $(r, r, c \cdot c)$，再投影成 $(r, r, c_z)$，可以直接和 pair 表示相加。

![展平之后是 c×c：外积的通道维被拉平，再由线性层压回 c_z](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00695.webp)

[【跳转到 11:35】](https://www.bilibili.com/video/BV16NxEekEir/?t=695)

### 3.4 两个容易忽略的设计

视频特意点出这段代码里「有两件事需要注意」：

**第一，外积不是 $m$ 和它自己做，而是 $a$ 和 $b$ 两个不同投影之间做。** 如果直接对 $m_{si}$ 和 $m_{sj}$ 做外积，模型能表达的只有「同一套特征自己和自己配对」。拆成 $a$、$b$ 两套投影之后，模型可以学到「用 $a$ 描述位置 $i$ 的哪种性质、用 $b$ 描述位置 $j$ 的哪种性质」，再让它们相乘。这多出来的一层自由度，就是模型把语义带进外积的空间。

**第二，这里其实算了两个方向的外积。** 一个发生在**残基维**上：$a$ 的列索引取 $i$、$b$ 的列索引取 $j$，于是对每个源物种、每个残基位置都算一次，这才产生了 $(r, r)$ 这个形状；另一个发生在**通道维**上：张量的不同通道两两相乘，展开成 $c \times c$。两个外积叠在一起，才有了「$(r,r)$ 的空间结构 + $c \cdot c$ 的通道结构」。

### 3.5 一个实现与伪代码的差异：均值放在线性层之前还是之后

这是本节最「工程」的一段，也是复现时最容易踩的坑。

论文伪代码写的是 $\mathrm{mean}_s(a_{si} \otimes b_{sj})$ **再**过线性层——也就是先平均、后投影。而实际实现（用 `einsum` 写的时候）常常是**先沿行维求和、投影完再除以序列数**。两种写法在数学上差别不大，但有一个具体后果：如果除法放在线性层之后，线性层的**偏置项也会被一起除掉**；放在之前则不会。

视频作者的处理原则很干脆：**我们不训练模型，所以必须坚持实际实现**，否则预训练权重和我们的外积均值对不上。这句话值得记住——读论文伪代码是为了理解机制，复现时要以权重能对上为准。

### 3.6 一句话总结这个模块

外积均值做的事情可以压缩成一条流水线：

```
MSA 表示 (s_c, r, c_m)
   │ LayerNorm + 两个线性投影
   ▼
a (s_c, r, 32)      b (s_c, r, 32)
   │ 对每个 (i, j)：a[:, i, :] ⊗ b[:, j, :]  → (s_c, 32, 32)
   │ 沿 s_c 求平均
   ▼
o (r, r, 1024)
   │ 线性层
   ▼
更新量 (r, r, c_z)  ── 加到 pair 表示上
```

注意最后那个「加到」：模块输出的是**更新量**，不是新的 pair 表示。图上的 `+` 是残差相加，这一点在第四节还会再出现一次。

### 4.1 顺序：MSA 三步 → 一次通信 → pair 五步

一个 block（共 $N_{block}=48$ 个）内部的顺序是固定的：

| 段 | 行号 | 模块 | 作用对象 |
| --- | --- | --- | --- |
| MSA stack | 2 | MSA row attention with pair bias | $m$（吃 $z$ 的偏置） |
| MSA stack | 3 | MSA column attention | $m$ |
| MSA stack | 4 | MSA transition | $m$ |
| Communication | 5 | **Outer product mean** | $m \rightarrow z$ |
| Pair stack | 6 | Triangle multiplication, outgoing | $z$ |
| Pair stack | 7 | Triangle multiplication, incoming | $z$ |
| Pair stack | 8 | Triangle attention, starting node | $z$ |
| Pair stack | 9 | Triangle attention, ending node | $z$ |
| Pair stack | 10 | Pair transition | $z$ |

这张表就是本节的答案：**两条表示在一层里只交换一次信息**，位置在 MSA stack 做完之后、pair stack 开始之前。MSA 先把「序列内部」和「物种之间」的证据各聚合一遍，然后把聚合结果通过外积均值一次性写进 pair；pair 拿到新证据后，再在几何一侧做五步精修。下一层重复同样的节奏。

### 4.2 每一行都是 `+=`：残差连接不是装饰

注意伪代码里所有行都是 `+=`，不是 `=`。视频专门解释了这个细节，因为它对「外积均值」这种模块尤其重要。

以三角乘法更新为例：它只取整个张量的两行（或两列）相乘再求和来生成输出，这是个相当「变革性」的操作——输出和输入的尺度可能完全不在一个量级。如果没有残差连接，模型只能学到很小的嵌入权重，让输出接近零，否则一加就把原表示冲掉了；有了残差连接，模块只需要学「往哪个方向偏移多少」，而不是「整个替换成什么」。

外积均值同理：它输出的是 $(r,r,c_z)$ 的**增量**，加到原有的 $Z_{ij}$ 上。所以看图时那个 `+` 号不是画图习惯，而是这个模块能工作的前提。

### 4.3 dropout 与「每一行每一列都有自己的权重」

视频还澄清了两个容易误解的点：

- **dropout 只影响训练**。AlphaFold 用的是 row-wise / column-wise dropout：随机把整行或整列的表示置零，同时放大其余部分以保持期望值。推理时不应用 dropout，所以复现推理时可以直接忽略这些 `DropoutRowwise` 包装。表里的系数（MSA 侧 0.15、pair 侧 0.25）就是这些 dropout 的概率。
- **同一个 block 里，行和列各有各的权重**。虽然图上画成一个方块，但行方向注意力和列方向注意力是两套独立参数，三角更新的 outgoing 与 incoming 也是两套。

### 4.4 出口：只留第一行

Evoformer 的最后一步（第 12 行）很反直觉：从 MSA 表示里**只取第一行**，过一个线性层，得到所谓的 **single representation**（单一表示，$s_i \in \mathbb{R}^{c_s}$，$c_s=384$）。

MSA 表示的其余部分到此为止——它们被丢弃，不再被模型使用。为什么可以这样？因为 MSA 的第一行就是**真正的目标序列**（query），其余行都是搜出来的同源序列。经过几十层 Evoformer 的反复交换，同源序列提供的证据已经被聚合进了第一行和 pair 表示里，所以只需要把第一行交给结构模块。

视频用了一个类比：这和情感分析里只保留第一个 token 的输出做分类是同一件事——模型需要学会把信息聚合到那一个位置上。

### 4.5 出口的另一半：pair 表示

与 single representation 一起交给结构模块的，还有 pair 表示 $Z_{ij}$。到这里，两条表示的「职责分工」就很清楚了：

- $Z_{ij}$ 是**几何侧**的载体，形状 $(r,r,c_z)$，天然对应「残基 $i$ 与 $j$ 的关系」，后面直接喂给结构模块；
- single representation 是**序列侧**的载体，形状 $(r, c_s)$，每个残基一个向量，携带从整条 MSA 聚合来的信息。

而把它们连起来的，就是本节反复讲的那一个模块：外积均值。

## 五、为什么三角关系要单独学（本节只点到）

读完模块图会发现一个不对称：MSA stack 只有三个模块，pair stack 却有五个，而且名字里全带「triangle」。视频在这里花了不少篇幅解释「为什么」，但完整的机制（三角乘法、三角注意力的公式与实现）我们留给专门的小节，这里只交代**它和本节的关系**。

### 5.1 pair 表示的每个条目是「有方向的」

MSA 表示的每个向量只说一件事：某个物种的某个残基是什么。pair 表示不一样——每一对残基有**两个**条目：

![pair 表示的条目 ij 与 ji 分别携带 i→j 和 j→i 的信息](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00884.webp)

[【跳转到 14:44】](https://www.bilibili.com/video/BV16NxEekEir/?t=884)

可以粗略地认为 $Z_{ij}$ 携带从 $i$ 到 $j$ 的信息，$Z_{ji}$ 携带从 $j$ 到 $i$ 的信息。视频举了个拟人的例子：谷氨酸告诉附近的甘氨酸「我带负电」，甘氨酸回一句「我不在意，我是中性的」。当然这只是直觉——条目的实际值只是学到的特征，语义并没有被完全解释清楚——但它解释了为什么 pair stack 的操作要区分方向。

### 5.2 更新 $Z_{ij}$ 时，为什么要看 $k$

假设我们要用 $Z_{ik}$ 去更新 $Z_{ij}$。第一个索引 $i$ 固定，所以这是**行操作**，视频称之为 outgoing update（出向更新）或「围绕起始节点的更新」。

问题在于：如果 $Z$ 的条目编码了距离，那么只知道 $i$ 到 $k$、$i$ 到 $j$ 的距离是不够的——还必须知道 $j$ 到 $k$ 的距离，否则可能违反三维空间里的三角不等式。所以更新时必须把第三个点 $k$ 相关的边也拉进来，这就是「补全三角形」：

![用 ik 更新 ij 时，需要 jk 来补全三角形](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/00929.webp)

[【跳转到 15:29】](https://www.bilibili.com/video/BV16NxEekEir/?t=929)

反方向（incoming，围绕终止节点）同理：用 $Z_{kj}$ 更新 $Z_{ij}$ 时，列索引固定，需要 $Z_{ki}$ 来补全三角形。

### 5.3 本节只需要记住位置

对「表示耦合」这个主题来说，三角部分只需要知道三件事：

1. 它发生在 **pair stack 内部**，不跨表示，所以不属于「耦合」；
2. 它的输入输出都是 $Z_{ij}$，靠残差相加，和其他模块一样；
3. 它解决的是**几何自洽性**（三个点之间的距离要能构成三角形），而外积均值解决的是**证据注入**（把 MSA 的共变写进 pair）。两者分工不同，所以值得分开学。

![Algorithm 11：三角乘法更新，第 4 行把 a(i,k) 与 b(j,k) 逐点相乘再对 k 求和](assets/Evoformer%20的表示耦合：外积均值如何把%20MSA%20共变送进残基对表示/01008.webp)

[【跳转到 16:48】](https://www.bilibili.com/video/BV16NxEekEir/?t=1008)

上面这张图就是「点到为止」的那一页：可以看到它的第 4 行也是「两两相乘再求和」，形状上和外积均值有点像，但求和维度是第三个残基 $k$，而不是序列 $s$。这个差别正是两个模块的本质区别——一个在残基之间传播几何约束，一个在物种之间提取共变证据。

## 小结

- **一层 Evoformer 的输入输出形状完全相同**：MSA 表示 $(s_c, r, c_m)$ 与残基对表示 $(r, r, c_z)$ 进、同样两个形状出，所以 block 可以堆 48 层，也可以被 recycle 反复调用。
- **两条表示在一层里只交换一次**：MSA stack 三步做完，经外积均值写入 pair，再进 pair stack 五步。这个顺序就是模块图上的全部信息流。
- **pair → MSA 的回馈只有一处**：行方向注意力的偏置项 $b^h_{ij}$，由 $Z_{ij}$ 层归一化后线性投影得到，每个头一张 $(r,r)$ 的标量表。列方向注意力不吃偏置。
- **外积均值是唯一的 MSA → pair 通道**：两个线性投影 → 外积（残基维 + 通道维各一次）→ 沿序列维求平均 → 展平 $c\cdot c$ → 线性投影到 $c_z$ → 残差加到 $Z_{ij}$。
- **求均值是这个模块的关键动作**：它消掉物种维，让输出形状与 MSA 深度无关，同时把「单个物种的同现」变成「跨物种的共变统计」。
- **所有模块都是 `+=`**：输出是增量而不是替换，这是外积均值和三角更新这类「变革性操作」能稳定训练的前提。
- **只留第一行**：Evoformer 出口的 single representation 来自 MSA 第一行（目标序列），其余行丢弃；pair 表示则整体交给结构模块。
- **三角关系单独学**：它在 pair 内部维护几何自洽性（补全三角形），与外积均值的「证据注入」是两件事。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| MSA 表示 $M_{si}$ | 形状 $(s_c, r, c_m)$ 的三维张量，两个空间维是「物种」和「残基位置」 |
| 残基对表示 $Z_{ij}$ | 形状 $(r, r, c_z)$ 的三维张量，两个空间维都是残基位置，编码残基间关系 |
| 行方向注意力 | 固定一条序列，在残基之间做注意力，softmax 沿残基维；可吃 pair 偏置 |
| 列方向注意力 | 固定一个残基位置，在物种之间做注意力，softmax 沿物种维；不吃偏置 |
| 偏置 bias $b^h_{ij}$ | 由 $Z_{ij}$ 线性投影得到的标量表，加在注意力分数上，是 pair → MSA 的唯一入口 |
| 门 gate $g$ | sigmoid 后的 0–1 向量，逐元素乘在注意力输出上，控制这次更新听多少 |
| 外积均值 Outer Product Mean | 把 MSA 两个位置的外积沿序列维平均，压成 $c\cdot c$ 再投影到 $c_z$ 的跨表示模块 |
| 过渡层 transition | 两层前馈网络（升到 4 倍维再降回），MSA 侧和 pair 侧各有一个 |
| 残差连接 | 模块输出以 `+=` 加到输入上，学的是增量而非替换 |
| single representation | Evoformer 出口处从 MSA 第一行投影得到的 $(r, c_s)$ 表示，交给结构模块 |
| recycle | 把上一轮迭代的输出重新嵌入，作为下一轮的输入，整个架构跑数轮 |
| 三角更新 / 三角注意力 | pair stack 内部的五个模块，用第三个残基补全三角形以维持几何自洽 |
