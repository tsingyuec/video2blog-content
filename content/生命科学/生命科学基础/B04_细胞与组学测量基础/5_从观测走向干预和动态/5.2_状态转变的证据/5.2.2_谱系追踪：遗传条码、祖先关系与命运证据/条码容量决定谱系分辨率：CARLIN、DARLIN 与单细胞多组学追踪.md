# 条码容量决定谱系分辨率：CARLIN、DARLIN 与单细胞多组学追踪

> 视频来源：[2023.12.22 特别活动 ｜ 单细胞谱系追踪前沿和交叉学科经验分享](https://www.bilibili.com/video/BV1Ax4y1Q7HP/)（B 站 · BioLinkX，约 38 分钟；录像从报告中间开始，开头几句为承接前文的半句）
> 导读（100 字以内）：这篇从工程化条码这一侧讲谱系追踪：条码空间有多大、一个细胞能被回收多少、哪些条码必须扔掉，以及这些数字如何直接决定「能分辨到克隆还是亚克隆」。后半段把条码和转录组、染色质、甲基化放进同一个细胞，用命运偏向和克隆记忆说明谱系证据能回答什么。字幕错拼（如「卡里/COLIN」→CARLIN、「搭扣/八扣」→barcode）已按幻灯片订正。

## 本讲要解决的核心问题（SCQA）

**背景**：谱系追踪的基本逻辑很简单——给祖先细胞写入一个可遗传的条码，子代都带着它，共享条码的细胞就是同一个克隆。上一节（5.2.2 导读）和 [4.3.4 的 Polylox 报告](../../../../B01_生命科学基础主干/4_细胞、个体与变化/4.3_细胞增殖、生殖与命运调控/4.3.4_干细胞、自我更新与细胞分化/细胞谱系与谱系追踪：条形码如何重建造血干细胞的分化树.md) 已经讲过这条逻辑在造血系统里的应用。

**冲突**：但条码不是无限多的。如果一只小鼠有 $10^{10}$ 个细胞，而条码系统只能产生 4 万种条码，那么「共享条码」就完全可能是撞码而不是同源。另一方面，即使条码写得出来，单细胞流程也未必测得回来——捕获率低、编辑失败、条码频率过高，都会让可用的细胞所剩无几。

**疑问**：条码容量到底怎样限制谱系分辨率？一个细胞从「被测到」到「可用于分析」要过几道关？哪些条码必须扔掉、凭什么扔？把条码和转录组、表观组放进同一个细胞之后，能多回答哪些问题？

**回答（中心思想）**：**谱系追踪的分辨率由两个数字决定：条码空间有多大，以及每个细胞能被可靠回收多少。** CARLIN 的 4.4 万条码对成年小鼠远远不够，且只有约 10% 的细胞可用；DARLIN 用 Cas9-TdT 融合蛋白增加插入突变、扩到三个位点，把理论条码数提到 $10^{18}$、可用细胞提到约 60%。但容量变大不等于可以随便用：必须先用预实验建立「等位基因字典」，剔除未编辑、未检测到和高频（易碰撞）的条码。只有过了这三关，条码才能支撑克隆水平的结论；再把它与转录组、染色质、甲基化配对，才能问「哪个克隆偏向哪种命运、这种记忆存在哪一层」。

## 一、为什么要单细胞谱系追踪：状态相似不等于命运相同

报告从一个具体的对照讲起。2014 年有一篇 Science 论文研究造血：如果只看转录组，把每种细胞类型 FACS 分选后聚类，会发现 MEP（megakaryocyte-erythroid progenitor，之后会变成红细胞和巨噬细胞）在转录组上更接近造血干细胞 [【跳转到 00:33】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=33)。

但如果改看组蛋白修饰 H3K27me3 再聚类，MEP 反而更接近它将要变成的红细胞 [【跳转到 01:23】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=83)。

这个对照说明两件事：**第一，状态相似性依赖你测的是哪一层**——转录组说它像干细胞，表观组说它像红细胞；**第二，表观层面可能更早预示命运** [【跳转到 01:48】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=108)。这也是为什么讲者要同时捕获多个维度，并且要有一个能直接读「体内命运选择」的工具。

## 二、CARLIN：把条码写进小鼠，但容量只有 4.4 万

### 2.1 设计：一个 target array，十个位点

2020 年 Kao 实验室开发了 CARLIN。它的载体里有一段 target array，包含十个 target site，每个 site 对应一个 gRNA；加 Dox 诱导后，Cas9 切割这些位点，产生插入或删除（indel），indel 的组合就成了这个细胞的条码 [【跳转到 02:18】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=138)。

![CARLIN 的设计：一段含十个 target site 的 array，Dox 诱导后 Cas9 切割产生插入、删除或两者兼有的 indel 条码](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/00213.webp)

它的亮点是**同一个细胞里既能读到转录组、又能读到谱系条码**，而且是在小鼠体内做的 [【跳转到 02:43】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=163)。这解决了体外培养「体内体外不一样」的问题。

### 2.2 两个硬限制：容量与回收率

讲者把 CARLIN 的问题说得很直接 [【跳转到 03:33】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=213)：

- **容量不够**：这个体系只能产生 4 万 4 千种不同的条码，而一只成年小鼠可以有 $10^{10}$ 个细胞。条码空间远小于细胞数，意味着大量细胞必然共享条码，只能研究细胞特别少的情形（比如早期胚胎），无法研究成年造血、心脏、大脑、肝脏这类复杂组织 [【跳转到 03:58】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=238)。
- **回收率低**：由于编辑效率等原因，最后只有 10% 的细胞有被成功编辑的谱系条码。测 1 万个细胞，可能只有 1000 个能用，甚至更少 [【跳转到 04:23】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=263)。

这两条正好对应本节的两个核心限制：**容量决定「会不会撞码」，回收率决定「有没有足够证据」**。前者制造假共享，后者制造假分离。

## 三、DARLIN：用插入突变和三个位点把容量抬到 $10^{18}$

### 3.1 先诊断 CARLIN 的条码为什么少

DARLIN 的设计不是凭直觉，而是先分析了 CARLIN 的产物分布：Cas9 切割后由内源修复产生的突变，**大量是长删除**——在 270 bp 的 target array 里，很多删除长达 200 甚至 220–230 bp，一个 array 里七八十的信息被擦掉；而插入非常稀少 [【跳转到 06:44】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=404)。

![CARLIN 的 indel 长度分布：删除可以长到 200 bp 以上，几乎擦掉整个 array；插入长度则集中在很短的范围内](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/00404.webp)

信息被擦掉，组合数自然上不去。这是一个很典型的工程思路：**先测量失败模式，再针对失败模式改设计**。

### 3.2 加一个 TdT：把「擦除」变成「写入」

他们的改法是引入 Cas9 与 TdT 的融合蛋白。Cas9 负责产生双链断裂，TdT（terminal deoxynucleotidyl transferase）是一种不依赖模板的 DNA 聚合酶，可以在断点处随机加核苷酸，从而**大大提高插入突变的概率** [【跳转到 07:09】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=429)。

意外的好处是：加入 TdT 后，删除的长度也变短了 [【跳转到 07:59】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=479)。删除变短、插入变多，两个方向都增加了可用组合。

### 3.3 三个位点相乘：$10^6 \times 10^6 \times 10^6$

单个位点就能产生 $10^6$（超过 100 万）种条码；他们把 target array 放到三个独立位点（col1a1、TIGER、Rosa26），三个位点的组合相乘，理论条码数达到 $10^{18}$ [【跳转到 08:24】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=504)。

![DARLIN 小鼠：Cas9-TdT 加三个 target array，理论条码数 $10^{18}$，约 70% 被测细胞有条码](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/00324.webp)

同时，不同组织里的编辑效率都接近 100%，约 70% 捕获到的细胞有合格条码 [【跳转到 05:24】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=324)。

这里要提醒一个读法：**$10^{18}$ 是理论组合数，不是实际观测到的条码数**。真实可用的条码还受编辑偏好、测序深度和下面要讲的过滤规则约束。

## 四、从「测到细胞」到「可用克隆」：三道过滤关

### 4.1 三种必须扔掉的细胞

讲者把质控拆成三步，每一步都会砍掉一批细胞 [【跳转到 09:39】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=579)：

1. **没检测到条码**：测到了转录组，但没测到谱系条码——无法归入任何克隆；
2. **条码未被编辑**：条码存在，但没有任何 indel，等于一个「空标签」，所有未编辑细胞都会共享它；
3. **条码频率过高**：虽然被编辑过，但这个 indel 组合出现得太频繁，无法用它标记特定克隆。

![DARLIN 的三步过滤：排除未检测到条码的细胞、排除未编辑的条码、排除高频（易碰撞）的条码，剩下的才进入下游克隆分析](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/00629.webp)

第三步是本节最关键的一条判读规则。**高频条码不是「信息」，而是「碰撞」**：如果某个条码在成千上万个细胞里都出现，它要么是编辑热点、要么是独立产生过很多次，无论哪种，共享它都不能推出同源。这和 Polylox 用产生概率 $P_{gen}$ 过滤稀有条码是同一个道理（见 [4.3.4 细胞谱系与谱系追踪](../../../../B01_生命科学基础主干/4_细胞、个体与变化/4.3_细胞增殖、生殖与命运调控/4.3.4_干细胞、自我更新与细胞分化/细胞谱系与谱系追踪：条形码如何重建造血干细胞的分化树.md) §4.3）。

### 4.2 回收率：CARLIN 10%，DARLIN 约 60%

把三步的通过率乘起来，差距非常直观：CARLIN 每一步大概只有四五十%，最后只有 10% 的细胞可用；DARLIN 每一步接近 90%，最后约 60% 的细胞可用 [【跳转到 10:54】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=654)。

这个数字直接对应统计功效：**可用细胞越少，谱系树的连接越稀疏，越容易把有亲缘的细胞读成无关**。讲者后面用降采样实验专门演示了这一点（§5.1）。

### 4.3 为什么 DARLIN 回收率高

讲者给了两个原因 [【跳转到 11:39】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=699)：

- Cas9-TdT 融合蛋白的表达量比原来 CARLIN 的 Cas9 高很多，更多融合蛋白意味着更多双链断裂和编辑；
- 三个 target array 的表达量也高（约为 Cas9 的 2–4 倍），加上三个位点本身，检测到条码的概率大幅上升。

## 五、分析侧的难点：先建字典，再谈克隆

### 5.1 没有字典，条码不可读

讲者特别提醒做生信的同学：DARLIN 的分析比较 tricky。不同 indel 的产生频率不一样，高频的不能用，必须用低频的才能可靠标记克隆 [【跳转到 12:54】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=774)。

这意味着**在做生物学实验之前，你必须知道哪些条码可用**。做法是做一个预实验，收集 reference dataset，从里面估计每个条码的产生频率，形成「等位基因字典」（allele bank）[【跳转到 13:19】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=799)。

### 5.2 正式实验与预实验的分工

正式实验的流程是：Dox 诱导产生条码（一两天）→ 等一段时间（几周到几个月），让克隆扩增、分化、迁移 → 用测序或成像读出细胞和条码 → 按 allele bank 筛出可靠克隆 → 做下游克隆分析 [【跳转到 13:44】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=824)。

![DARLIN 的实用流程：诱导、等待扩增与分化、 profiling、按 allele bank 识别可靠克隆，最后做克隆耦合、共享比例、命运偏向与克隆记忆分析](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/00824.webp)

预实验则相反：同样诱导产生条码，但**很快**就处死小鼠、提取细胞分析，尽量不让克隆扩增和分化发生，这样测到的频率才接近条码「内在」的产生概率 [【跳转到 14:59】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=899)。

这个设计值得记住：**要估计条码的产生概率，就必须在克隆还没扩增时取样**。否则你测到的高频，分不清是「这个条码容易产生」还是「这个克隆恰好扩增了」。

### 5.3 降采样演示：稀疏数据会吃掉真实信号

为了说明工具的价值，讲者做了一个对照：拿 DARLIN 的数据降采样到与 CARLIN 相近的稀疏度，再问「还能不能找到那些注定走向 MKP 的 HSC」[【跳转到 24:26】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1466)。

结果是：降采样后数据过于稀疏，**无法 identify 哪些 HSC 会走向 MKP、它们在哪里** [【跳转到 24:51】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1491)。

这是本节最直接的一条证据：**同样的生物学、同样的算法，只因为每个细胞的条码/表达信息变少，结论就消失了**。所以读谱系追踪论文时，必须先看「每个细胞平均有多少条码、多少细胞可用」，再看树画得漂不漂亮。

## 六、把条码和状态放进同一个细胞

### 6.1 四模态：条码、转录组、染色质、甲基化

讲者介绍的第二项技术是单细胞多组学谱系追踪：同一个细胞分出细胞核和细胞质，细胞核做开放区域标记 + 亚硫酸氢盐处理 + 甲基化测序，得到染色质可及性和 DNA 甲基化；细胞质做转录组；再从 RNA 里读出谱系条码。四部分信息在同一个细胞里配对 [【跳转到 15:33】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=933)。

质控显示：约 60% 的细胞有可靠条码，每个细胞检测到约 3000 个基因，甲基化在转录起始位点下降、在 gene body 上升再下降，符合预期 [【跳转到 16:45】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1005)。

### 6.2 克隆命运偏向：同一个「HSC」标签下的不同选择

在 E17 打条码、等九周，再取成年小鼠的造血细胞做单细胞测序，就能看到每个克隆产出了哪些细胞类型 [【跳转到 17:44】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1064)。

![E17 打条码、九周后测序：一个多能克隆覆盖 HSC、LMPP、Mono、Neu、MKP、Ery；另一些克隆只产 MKP 或只产 Mono](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/01114.webp)

结果有三类克隆：多能克隆（覆盖几乎所有被分析的细胞类型）、MKP 偏向克隆（只产生巨噬细胞前体）、Mono 偏向克隆（强烈倾向单核细胞）[【跳转到 18:34】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1114)。

这张图直接说明「状态标签不能替代谱系」：这些细胞在测序时都被注释成 HSC 或祖细胞，**状态相同，命运不同**。命运的信息在克隆身份里，不在当下的表达谱里。

### 6.3 迁移：造血干细胞主要待在原地

第二个应用问的是「成年小鼠的 HSC 能不能从一个骨头跑到另一个骨头」。做法是成年时打条码、等四个月，取头骨、脊柱、左腿、右腿四种骨头，分选四种细胞类型，建条码库 [【跳转到 26:16】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1576)。

![四种骨头 × 四种细胞类型的克隆耦合热图：对角线很亮，说明血细胞主要在本地产生，跨骨头共享有限](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/01601.webp)

结果是强局部性：每种骨头里的细胞主要和同一骨头内的细胞共享条码，特别是 MKP [【跳转到 27:06】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1626)。进一步量化：头骨来源的 MKP 有接近 40% 的克隆与其他骨头共享，而 HSC 只有 5% [【跳转到 27:31】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1651)。

讲者的解释是：MKP 更下游，骨髓造血后血要进入外周循环发挥功能，所以会跑到别处；HSC 更倾向留在原地 [【跳转到 28:21】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1701)。

这里的结论强度值得注意：**5% 不是 0**。条码证据支持「大部分 HSC 不迁移」，不支持「HSC 绝对不迁移」；而且这个比例本身受检出率影响，真实共享比例可能被低估。

### 6.4 克隆记忆：转录组会淡，甲基化不会

最后一个故事关于「记忆」。基因表达有随机性，但有些基因会持续开启好几个细胞周期，于是它的后代在一段时间内都带着同样的标记；有工作把这类基因叫 heritable，并报道它可能带来短期的耐药性 [【跳转到 28:56】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1736)。

讲者团队把问题扩展到整个转录组和表观组：在第 10 天给 DARLIN 小鼠打条码，然后在 36 小时（AGM 区域）、5.5 天（胎肝）、两个多月（骨髓）三个时间点取造血干细胞，做单细胞多组学 [【跳转到 32:58】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=1978)。

![同一批克隆在三个模态上的分布：转录组和染色质可及性上克隆完全混合，DNA 甲基化上同一克隆的细胞明显聚在一起](assets/条码容量决定谱系分辨率：CARLIN、DARLIN%20与单细胞多组学追踪/02178.webp)

结果是分层的 [【跳转到 35:28】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=2128)：

- **转录组**：克隆记忆随时间逐渐衰减，到后期不同克隆完全混在一起；
- **染色质可及性**：记忆一直比较低；
- **DNA 甲基化**：36 小时就很高，胎肝期保持，两个多月后仍然很强。

讲者用「非常 surprise」形容这个结果：这些细胞从 AGM 迁移到胎肝、再到骨髓，经历了大量时空变化和微环境变化，但甲基化仍然记得它们来自同一个克隆 [【跳转到 36:18】](https://www.bilibili.com/video/BV1Ax4y1Q7HP/?t=2178)。

这条结果对「状态轨迹」是一个重要提醒：**如果你只看转录组，克隆身份在几周后就已经读不出来了**。转录组相似度反映的是当前状态，不是继承历史；真正长期保留克隆记忆的，可能是甲基化这类表观标记。

## 七、这套证据能支持什么、不能支持什么

| 能支持 | 依据 | 不能支持 |
| --- | --- | --- |
| 两个细胞属于同一克隆 | 共享低频、被编辑的条码 | 共享高频条码就推出同源（可能是碰撞） |
| 克隆的多能性或命运偏向 | 同一克隆的后代分布在哪些细胞类型 | 命运偏向由哪个基因决定 |
| 组织内 vs 跨组织的克隆共享比例 | 多骨头取样的条码共享率 | 「绝对不迁移」这类全称结论 |
| 克隆记忆存在哪一层 | 同一克隆在转录组/ATAC/甲基化上的聚集程度 | 记忆的因果机制 |
| 条码系统的分辨率上限 | 理论条码数 × 可用细胞比例 | 理论条码数等于实际可分辨克隆数 |

三条最容易犯的读法错误：

1. **把理论条码数当实际分辨率**：$10^{18}$ 是组合上限，实际可用条码受编辑偏好、测序深度和过滤规则限制；
2. **忽略回收率**：10% 与 60% 的可用细胞，会给出稀疏程度完全不同的树；降采样实验已经证明信号会消失；
3. **用高频条码做共享判断**：高频条码是碰撞的同义词，必须先进 allele bank 过滤。

## 小结

- **条码容量是硬约束**：CARLIN 的 4.4 万条码对 $10^{10}$ 个细胞远远不够，只能研究细胞少的情形；条码空间不足会制造假共享。
- **回收率是第二道硬约束**：CARLIN 只有约 10% 细胞可用，DARLIN 约 60%；可用细胞越少，谱系树越稀疏，越容易把亲缘读成无关。
- **DARLIN 的改进有明确诊断依据**：先发现 CARLIN 的突变以长删除为主、插入稀少，再用 Cas9-TdT 增加插入、缩短删除，并用三个位点相乘把容量抬到 $10^{18}$。
- **三道过滤缺一不可**：没检测到条码、条码未编辑、条码频率过高，三类细胞都必须剔除；高频条码等于碰撞。
- **分析前先建字典**：用预实验（打条码后尽快取样）估计每个条码的产生频率，形成 allele bank，再判断哪些克隆可靠。
- **谱系 + 多组学才能问机制**：同一细胞里读条码、转录组、ATAC、甲基化，才能看到克隆命运偏向、迁移局部性，以及「转录组记忆会淡、甲基化记忆很持久」这种分层现象。
- **状态轨迹不能替代谱系**：转录组上的克隆记忆几周就消失，而克隆身份仍在；反过来，谱系树也不能告诉你每个细胞此刻在表达什么。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 条码容量（barcode diversity） | 一个条码系统理论上能产生多少种不同条码；容量小于细胞数就会撞码 |
| 条码碰撞（barcode collision） | 两个无关克隆独立获得同一条码，被误判为同源 |
| CARLIN | 含十个 target site 的 CRISPR 条码小鼠，理论条码约 4.4 万，单细胞可同时读转录组 |
| DARLIN | CARLIN 的改进版：Cas9-TdT 融合蛋白 + 三个 target array，理论条码 $10^{18}$ |
| TdT | 不依赖模板的 DNA 聚合酶，在断点处随机加核苷酸，增加插入突变 |
| indel | 插入或删除突变；CRISPR 切割后修复的产物，是演化条码的基本单位 |
| allele bank | 预实验建立的条码频率字典，用来判断哪些条码可靠、哪些属于高频碰撞 |
| 回收率（recovery rate） | 从被测细胞到可用于克隆分析的细胞比例 |
| 克隆耦合（clonal coupling） | 两类细胞共享条码的程度，用来判断它们是否常来自同一克隆 |
| 命运偏向（fate bias） | 某个克隆产出某类细胞明显多于其他克隆的现象 |
| 克隆记忆（clonal memory） | 同一克隆的细胞在某个分子层面上仍保持相似、可被识别的现象 |
| 降采样（subsampling） | 人为减少每个细胞的信息量，用来模拟低质量数据、检验结论是否依赖数据密度 |
