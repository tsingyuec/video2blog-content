## 2 从样本到表达矩阵

<a id="b04-2-1"></a>

### 2.1 RNA 测序的观测过程

- 2.1.1 向量、矩阵、张量与维度 <a id="b04-2-1-1"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-1-1)
  - 学习目标：说明向量、矩阵与张量的维度约定和广播规则；判断模型输入输出的形状；把线性代数记号与后续网络实现对应起来。
- 2.1.2 单细胞建库：细胞捕获、转录本捕获与文库偏差 <a id="b04-2-1-2"></a> [DONE]
  - 学习目标：比较液滴和孔板等代表策略的捕获单位，解释取样偏差及读出覆盖，不展开全部建库平台。
- 2.1.3 细胞条形码与 UMI：细胞归属、分子去重与碰撞 <a id="b04-2-1-3"></a> [DONE]
  - 学习目标：用一组读段追踪细胞归属和分子计数，区分条形码纠错、PCR 重复与 UMI 碰撞。
- 2.1.4 读段质控与测序质量：质量值、接头、比对率与 rRNA 比例 <a id="b04-2-1-4"></a> [DONE]
  - 学习目标：用质量值、接头污染和比对率判断文库质量，说明质控阈值对下游计数的影响。
- 2.1.5 基因命名、稳定标识符与版本 <a id="b04-2-1-5"></a> [REUSE](../B02_基因组与基因调控基础/README.md#b02-5-2-1)
  - 学习目标：说明基因符号、稳定标识符与版本的关系；判断跨数据集特征对齐时的同名/别名风险；把基因标识与 2.1.6 的量化汇总联系起来。
- 2.1.6 RNA 读段量化：比对、转录本歧义与基因汇总 <a id="b04-2-1-6"></a> [DONE]
  - 学习目标：从读段到基因计数解释参考依赖、多重匹配与汇总规则，区分原始读段和表达矩阵。
- 2.1.7 测序深度与捕获效率：文库复杂度、饱和度与检测概率 <a id="b04-2-1-7"></a> [DONE]
  - 学习目标：比较增加读数和增加真实分子数的效果，解释测序深度对低表达检测及样本比较的影响。

<a id="b04-2-2"></a>

### 2.2 数据对象与观测偏差

- 2.2.1 细胞乘基因矩阵及细胞、基因注释 <a id="b04-2-2-1"></a> [DONE]
  - 学习目标：读出行列含义与稀疏结构，说明细胞和基因注释表如何约束后续分析。
- 2.2.2 单细胞计数稀疏性、低计数与未检出 <a id="b04-2-2-2"></a> [DONE]
  - 学习目标：说明单细胞计数稀疏性、低计数与未检出的来源；判断零值何时是技术缺失而非生物不表达；把归一化、插补与差异表达的前提区分开。
- 2.2.3 单细胞质控：检测基因数、线粒体比例与阈值 <a id="b04-2-2-3"></a> [DONE]
  - 学习目标：说明线粒体比例、检测基因数与样本类型的关系；判断固定阈值为何会误伤高代谢或低复杂度细胞；把质控门槛与 2.2.2 的稀疏性、2.2.4 的双细胞区分开。
- 2.2.4 双细胞污染：混合转录组、同型与异型双细胞 <a id="b04-2-2-4"></a> [DONE]
  - 学习目标：解释双细胞的产生及其对聚类注释的影响，辨认表达特征与模拟双细胞检测的证据限制。
- 2.2.5 环境 RNA 污染：背景转录本、估计与校正 <a id="b04-2-2-5"></a> [DONE]
  - 学习目标：区分游离 RNA 与真实细胞表达，解释背景估计及过度去污染风险，不重复双细胞机制。

## 4 细胞群体比较与差异分析

<a id="b04-4-1"></a>

### 4.1 实验单位与统计对象

- 4.1.1 重复测量、分层结构与伪重复 <a id="b04-4-1-1"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-2-1)
  - 学习目标：说明重复测量、分层结构与伪重复的区别；判断样本单位是细胞、供体还是实验批次；把统计单位与实验设计对应起来。
- 4.1.2 假设检验：零假设、p 值与显著性 <a id="b04-4-1-2"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-1-3)
  - 学习目标：用一个零假设说明判定和常见误读。
- 4.1.3 多重检验校正与假发现率（FDR） <a id="b04-4-1-3"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-1-4)
  - 学习目标：用许多基因同时检验的案例说明校正。
- 4.1.4 供体、样本、细胞系与细胞的层级 <a id="b04-4-1-4"></a> [DONE]
  - 学习目标：区分供体、样本、细胞系与单细胞层级，说明各层级的独立重复含义。
- 4.1.5 生物重复、伪重复与伪 bulk 汇总：从细胞到样本的聚合 <a id="b04-4-1-5"></a> [DONE]
  - 学习目标：说明生物重复与技术重复的差别；判断伪重复何时会夸大显著性；比较伪 bulk 汇总与细胞级模型的统计单位；说明聚合对效应量和不确定性的影响。
- 4.1.6 效应量、置信区间与估计不确定性 <a id="b04-4-1-6"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-1-1)
  - 学习目标：解释差异表达中的效应量与置信区间；区分统计显著性与生物效应大小；判断样本量和方差对区间宽度的影响；避免把排序当成效应量。

### 4.2 差异与功能解释

- 4.2.1 差异表达中的离散度收缩与零膨胀假设 <a id="b04-4-2-1"></a> [DONE]
  - 学习目标：说明差异表达模型为何需要离散度收缩；比较零膨胀与负二项对零值的解释；判断离散度估计对检验结果的影响；把通用计数似然与 DE 实现区分开。
- 4.2.2 计数似然与过度离散：泊松、负二项与对数连接 <a id="b04-4-2-2"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-2-1-4)
  - 学习目标：说明泊松、负二项与对数连接在计数数据中的假设；判断过度离散的来源；把似然选择与差异表达模型联系起来。
- 4.2.3 差异表达建模：设计矩阵、组间比较与效应量 <a id="b04-4-2-3"></a> [DONE]
  - 学习目标：说明统计单位、协变量、对照及表达变化估计，区分细胞层面和样本层面的问题。
- 4.2.4 差异表达判读：不确定性、多重检验与生物意义 <a id="b04-4-2-4"></a> [DONE]
  - 学习目标：用同一结果解释置信区间、FDR、效应大小与标记选择，统计公式引用 M01，不重复统计学课程。
- 4.2.5 细胞组成变化与细胞内表达变化 <a id="b04-4-2-5"></a> [DONE]
  - 学习目标：用混合群体案例辨认两种不同问题。
- 4.2.6 细胞组成差异的统计：比例数据、组成约束与组成检验 <a id="b04-4-2-6"></a> [DONE]
  - 学习目标：说明细胞比例数据的组成约束；比较 CLR/ILR 等对数比变换与 Dirichlet-multinomial 模型；区分组成变化与细胞内表达变化；判断组成检验的零假设与适用条件。
- 4.2.7 单细胞差异表达方法谱系：细胞级检验、伪 bulk 与模型化 <a id="b04-4-2-7"></a> [DONE]
  - 学习目标：对照细胞级检验、伪 bulk 与模型化方法，说明各自对样本单位和稀疏性的假设。
- 4.2.8 功能解释：ORA、GSEA 与背景集判读 <a id="b04-4-2-8"></a> [DONE]
  - 学习目标：区分过代表分析与排序富集，说明背景集和基因集冗余如何影响结论。
- 4.2.9 表达结论的正交验证：qPCR、流式与原位杂交 <a id="b04-4-2-9"></a> [DONE]
  - 学习目标：比较 qPCR、流式与 RNAscope/免疫组化的读出对象；说明引物、抗体与对照的设置；判断正交验证在什么情况下支持或反驳测序结论；识别批次与样本处理带来的偏差。
