# FastQC 报告怎么读：质量值、接头、重复率与 rRNA 污染

> 视频来源：[Post sequencing quality evaluation](https://www.youtube.com/watch?v=L8zasCYKJP0)（YouTube · DnA lab short read sequencing workshop）｜时长约 23 分钟
> 这支视频不教软件安装，而是逐张图讲 FastQC 报告在说什么。本文按“测序仪问题 → 文库问题”的顺序重组，保留视频里的例子和判断标准。

## 本讲要解决的核心问题（SCQA）

**背景**：测序公司交付的 FASTQ 文件动辄几十 GB，直接打开只能看到四行一组的序列和符号。

**冲突**：这些符号里既有测序仪读错、读不出的碱基，也有建库时残留的接头，甚至还有核糖体 RNA、线粒体 RNA 这类“生物来源的污染”。它们都会占用测序读数，却不贡献我们想要的基因表达信息。

**疑问**：不看几千万条 read，怎么快速判断这批数据能不能用？哪些图是在查测序仪，哪些图是在查文库？

**回答（中心思想）**：FastQC 把 read 层面的问题分成两类——测序仪相关的质量问题和文库相关的问题。前者看每条 read 的逐碱基质量、flow cell 空间质量和每条 read 的平均质量；后者看碱基组成、GC 分布、N 比例、长度分布、重复率和接头含量。红灯不是判决书，但它能指出问题出在测序、建库还是污染，从而决定是修剪、去重、重新建库还是找测序公司。

## 一、报告首页：先看 summary 的红绿灯，再看具体图

FastQC 输出一份 HTML 报告。顶部记录运行时间和文件名，便于归档；同时给出总序列数、被标记为质量差的序列数和平均 GC 含量。左侧是各分析模块的汇总，右侧是具体图表。[【跳转到 03:21】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=201)

每个模块旁边有红绿灯：绿色通过，黄色警告，红色不通过。视频作者的态度很明确：不要被这些警告绑架，但可以用它快速定位“问题可能在哪”。[【跳转到 03:46】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=226)

![FastQC 报告首页：左侧模块汇总、右侧基础统计与逐碱基质量图](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00201.webp)

报告里的模块可以按两个来源分组：

| 来源 | 模块 | 回答的问题 |
| --- | --- | --- |
| 测序仪 | 逐碱基质量、flow cell 空间质量、每条 read 平均质量 | 测序过程稳不稳，有没有局部坏点 |
| 文库 | 碱基组成、GC 分布、N 比例、长度分布、重复率、过表达序列、接头含量、k-mer | 建库有没有偏差、污染或复杂度不足 |

## 二、测序质量要看三个尺度

FastQC 用三种方式评估测序质量：逐碱基质量（每个位置的碱基平均质量）、flow cell 空间质量（同一 tile 上的平均质量）、每条 read 的平均质量分布。[【跳转到 07:34】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=454)

![FastQC 评估测序仪质量的三个尺度：逐碱基、逐 tile、逐 read](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00454.webp)

### 2.1 逐碱基质量：看质量随 read 位置的变化

逐碱基质量图的横轴是 read 中的位置，纵轴是质量分数。好的 read 全程落在绿色区域；随着 read 变长，质量会下降，这在 Illumina 平台上很常见，越新的机型下降越少。[【跳转到 05:05】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=305)

![逐碱基质量图：绿色为高质量区，黄色和红色分别对应警告与不合格](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00305.webp)

视频给了一个“需要留意”的例子：在 read 中间约 35 bp 处出现质量骤降。因为图上是所有 read 的平均，这说明有一部分 read 在该位置严重掉质量。处理方式是修剪掉低质量部分；如果几乎全部 read 都在同一位置大幅掉质量，就应该联系测序公司，这种问题本应在下机前被发现。[【跳转到 05:30】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=330)

### 2.2 flow cell 空间质量：找测序芯片上的“坏点”

同样的质量信息按 flow cell 上的位置排列，就得到空间质量图：横轴是 read 位置，纵轴是 flow cell 上的位置，蓝色好、红色差。[【跳转到 06:05】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=365)

![flow cell 空间质量图：整块 tile 呈均匀蓝色说明没有局部坏点](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00370.webp)

常见的异常有两种：开头质量低但随后恢复，或者沿 read 逐渐衰减。视频提醒，比对软件会把碱基质量纳入打分，所以轻微的空间质量损失不致命；但如果某个区域整条 read 都大幅掉质量，就要怀疑 flow cell 故障，应联系测序公司。很多低质量 read 可以通过修剪挽救，剩下的高质量 read 仍可继续分析。[【跳转到 07:05】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=425)

### 2.3 每条 read 的平均质量：决定要不要按 read 丢弃

逐 read 质量图不再平均所有 read，而是先算每条 read 的平均质量，再看这些平均值的分布。视频的例子里，大多数 read 的平均质量在 39–40，说明文库质量很高。[【跳转到 07:59】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=479)

当 flow cell 局部出问题时，这个分布会变形：少数 read 平均质量极低，一部分落在 27 左右，大部分仍然很高。视频作者的建议是：考虑把平均质量低于 30 的 read 修剪或丢弃，再进入比对。[【跳转到 08:49】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=529)

## 三、碱基组成：正常是四条平行线

逐碱基碱基组成图看每个位置上 A、T、C、G 的比例。人类基因组约 40% GC，所以正常图里 G 和 C 各约 20%，A 和 T 各约 30%，四条线大致平行。[【跳转到 09:39】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=579)

![逐碱基碱基组成：四条线平行、无尖峰，说明没有明显的序列偏好](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00604.webp)

视频指出两类可解释的波动：

- **开头约 10 bp 的波动**：来自反转录时的随机六聚体引物（random hexamer），不同 hexamer 的结合效率不同，属于建库方式的固定偏差。[【跳转到 10:04】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=604)
- **沿 read 出现的周期性尖峰**：每个峰大致对应接头上的一个碱基，可以顺着峰读出 G、A、T、C、G、G 这样的接头序列。这是接头过表达，可以在后续计算中切除。[【跳转到 10:54】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=654)

理想状态是平滑的线，而不是尖刺。

## 四、GC 分布：尖峰暴露污染来源

每条 read 的 GC 含量分布图里，红线是实际分布，蓝线是理论分布。人类样本的实际峰值应在 40% GC 附近。[【跳转到 11:19】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=679)

![GC 分布：在 50% 附近出现尖峰，提示接头过表达](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00729.webp)

视频给了两个“尖峰”的例子：

- **接头尖峰**：所用 Illumina 接头约 50% GC，接头过表达会在 50% 处顶出一个高峰，把整体分布拉偏。
- **线粒体 RNA 尖峰**：在心肌、骨骼肌这类线粒体很多的样本里，rRNA 去除没有清掉线粒体 RNA，会在特定 GC 位置形成尖刺。同理，rRNA 去除不彻底、或者根本没做 rRNA 去除/ poly-A 选择，也会在 GC 分布上留下痕迹。[【跳转到 12:59】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=779)

所以 GC 分布不只是“看峰值对不对”，尖峰的位置还能反推污染类型：50% 附近想到接头，样本特异的窄峰想到线粒体或 rRNA。

## 五、N 比例与长度分布：测序仪读不出的位置

Illumina 读不出某个碱基时，会在该位置写一个 N。正常数据里 N 应该接近零，图上是一条贴底的平线。视频的例子里，第 10 个碱基处出现 N 的 read 约占 10%（作者原话是 about 10 of my reads），原因是测序仪里进了气泡，导致该位置读错。[【跳转到 13:24】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=804)

![read 碱基组成的四个检查项：逐碱基组成、GC 分布、N 比例与长度分布](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00804.webp)

如果 N 的比例很高，应联系测序公司；比对软件有处理 N 的规则，所以少量 N 不会让比对完全失败，但会影响下游比对。

长度分布图正常情况下所有 read 都是设定长度（如 50 bp 或 150 bp）。如果修剪过接头，图上会出现一批较短的 read：视频的例子是文库片段比测序读长还短，切除末端接头后，一部分 read 变短，大部分仍约 125 bp。[【跳转到 14:39】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=879)

## 六、重复率与文库复杂度：高重复不一定是技术问题

FastQC 会计算“如果去重，还能剩下多少比例的序列”。蓝线是总序列，红线是去重后的序列。视频给了一个几乎无重复的好文库做对照。[【跳转到 15:29】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=929)

![序列重复水平：蓝线为总序列，红线为去重后序列，两者接近说明复杂度高](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/00954.webp)

低复杂度文库的表现是：少数 read 有成千上万份拷贝。视频的 ChIP-seq 例子里，8% 的 read 属于同一个 read 的 8000 多份拷贝，很可能是接头二聚体；同时大量 read 都有多份拷贝，说明文库被过度扩增，需要在比对后去重，只保留唯一 read。[【跳转到 16:19】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=979)

RNA-seq 的情况不同：重复可能来自真实的生物学信号——某些基因表达量极高，本来就会产生大量相同 read。视频的例子里，10% 的 read 高度重复，对应单个基因的上万份拷贝；还有一个峰来自核糖体 read，约 40% 的 read 被 rRNA 占用。[【跳转到 17:09】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1029)

![生物学来源的重复：高表达基因与 rRNA 都会形成高峰](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/01029.webp)

这解释了 rRNA 比例为什么关键：rRNA 在细胞总 RNA 里占绝对多数，去除不彻底时，测序读数会被 rRNA 大量占用，真正来自 mRNA 的 read 变少，文库的有效复杂度下降。视频的建议是优化 rRNA 去除步骤；如果污染已经发生，也可以靠增加测序量来补足有效覆盖。[【跳转到 21:18】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1278)

## 七、过表达序列与接头含量：把污染落到具体序列

FastQC 会列出过表达的长序列（默认 50 bp），给出序列、read 数、占文库比例和可能的来源。软件自带 Illumina 接头库；如果怀疑 rRNA，也可以把 rRNA 序列加进去让它查找。视频作者的习惯是：取排名第一的过表达序列，BLAST 到目标物种，确认它是不是 rRNA——如果是，说明 rRNA 去除没做好。[【跳转到 18:19】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1099)

接头含量图则直接看“read 的哪个位置开始读进接头”。正常应全程为零；如果插入片段太短，测序读到片段末端后会继续读进接头，曲线在某个位置开始上升。视频的例子在约 70 bp 处开始上升，说明文库片段比 125 bp 的读长更短，后续需要切掉接头才能改善比对。[【跳转到 19:07】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1147)

![接头含量图：曲线在 read 后段抬升，说明插入片段短于测序读长](assets/FastQC%20报告怎么读：质量值、接头、重复率与%20rRNA%20污染/01147.webp)

k-mer 含量是最后一个模块。FastQC 默认找 5-mer，也可以设到 7-mer。它几乎总能找到过表达的 k-mer，多数只是没切干净的接头，所以除非在排查疑难文库，不必过度解读。[【跳转到 20:22】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1222)

## 八、发现问题之后：修剪、去重、补测序

视频最后给了一套处理原则：[【跳转到 20:28】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1228)

- **不要追求“完美”报告**。作者原话是“我都不知道完美是什么意思”，报告不完美不等于文库不能用。
- **能修的先修**：切掉低质量 read、读进接头的部分、接头二聚体。
- **去重分场景**：DNA 测序、全基因组、ChIP-seq 建议去重，因为 ChIP-seq 起始量低，容易过度扩增；RNA-seq 的重复可能是真实的高表达信号，不能一律去掉。
- **比对器会用质量分**：低质量碱基在比对时会被降权，所以轻微质量问题影响有限，修剪后通常更好。
- **rRNA 污染高就补测序**：如果污染已经占掉大量读数，增加测序量可以获得所需的有效覆盖。

修剪前后的对比很直观：接头二聚体让碱基组成图上下抖动，GC 分布出现尖峰；切掉接头后曲线变平滑，GC 尖峰消失。视频的例子里，修剪前约 1.5% 的文库是接头，修剪后不再有过表达序列。[【跳转到 22:33】](https://www.youtube.com/watch?v=L8zasCYKJP0&t=1353)

## 小结

- FastQC 报告分两类问题：测序仪相关（逐碱基、flow cell 空间、逐 read 质量）和文库相关（碱基组成、GC、N、长度、重复、接头、k-mer）。
- 逐碱基质量看随位置的变化；flow cell 空间质量找局部坏点；逐 read 平均质量决定是否按 read 丢弃（视频用平均质量 30 作为修剪线）。
- 碱基组成正常是四条平行线；开头波动来自随机六聚体引物，周期性尖峰是接头。
- GC 分布的尖峰能反推污染：50% 附近多为接头，样本特异的窄峰多为线粒体或 rRNA。
- 重复率要分场景解读：ChIP-seq 的低复杂度多为过度扩增，RNA-seq 的高重复可能是真实高表达或 rRNA 占用。
- rRNA 比例高意味着有效复杂度低：先优化去除步骤，必要时补测序；接头则通过修剪解决，修剪后应重跑 FastQC 确认。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| FastQC | 对 FASTQ 做质量评估并生成 HTML 报告的工具，只评估不改数据 |
| 逐碱基质量 | 把所有 read 在同一位置的质量取平均，看质量随读长的变化 |
| flow cell 空间质量 | 按测序芯片上的位置排列质量值，用于发现局部坏点 |
| 过表达序列 | 在文库中出现频率异常高的具体序列，常来自接头或 rRNA |
| 接头二聚体 | 两个接头互相连接、没有插入片段的短产物，会抢占测序读数 |
| 文库复杂度 | 文库中不同分子种类的丰富程度；复杂度低时重复率升高、有效信息减少 |
| rRNA 污染 | 测序读数中来自核糖体 RNA 的部分，去除不彻底会挤占 mRNA 读数 |
