# Phred 质量值与 FASTQ：测序数据质控的第一道门槛

> 视频来源：[转录组 3.数据质控](https://www.bilibili.com/video/BV1xksoz7Eg7/)（Bilibili · 科易课堂）｜时长约 7.6 分钟
> 本文按这支视频的顺序，把 FASTQ 文件、Phred 质量值、RNA-seq 质量分布特征和一套常见的过滤标准串起来；重点放在“每个数字在说什么”，而不是软件操作。

## 本讲要解决的核心问题（SCQA）

**背景**：转录组测序下机后拿到的是一堆 FASTQ 文件，后续所有分析都从这些 reads 开始。

**冲突**：文件里既有真实的 cDNA 序列，也混着测序仪读错的碱基、没切干净的接头和测序质量很差的片段。如果直接拿原始 reads 去比对和定量，错误会一路传到表达矩阵。

**疑问**：怎么判断一条 read 可不可信？质量值到底在度量什么？过滤时又该按什么标准删？

**回答（中心思想）**：FASTQ 第四行用 Phred 质量值给每个碱基标注了“读错的概率”，质控就是先用质量分布、碱基组成和接头比例判断这批数据是否正常，再按明确的阈值把接头、低质量、含 N 过多和长度异常的 reads 去掉，得到 clean reads 后才进入下游分析。

## 一、FASTQ 的第四行：每个碱基都带一个错误率标签

高通量测序的结果最初是原始图像数据，经过转化后得到原始测序序列（Sequenced Reads），也就是 Raw Data，通常以 FASTQ（简称 fq）格式存储。FASTQ 里每条 read 都包含名称、碱基序列和对应的测序质量信息。[【跳转到 00:00】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=0)

FASTQ 固定四行一条 read：[【跳转到 00:51】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=51)

1. 第一行以 `@` 开头，是测序标识符和描述文字；
2. 第二行是碱基序列；
3. 第三行以 `+` 开头，一般省略标识符；
4. 第四行是与第二行一一对应的测序质量，每个字符代表一个碱基的质量。

关键在第四行。每个质量字符的 ASCII 码值减去 33（Sanger 质量值体系），就是该碱基的测序质量得分。不同的 Score 代表不同的碱基测序错误率，例如 Score 为 20 和 30 分别表示错误率 1% 和 0.1%。[【跳转到 00:17】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=17)

![FASTQ 四行结构与 ASCII 码减 33 的质量值换算](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00017.webp)

这也解释了一个常见困惑：为什么 FASTQ 第四行看起来像乱码。字符本身不是分数，减 33 之后的数值才是分数；同一个字母在不同质量体系下可能代表不同分数，所以读文件前要先确认编码方式。

## 二、Phred 分值：分数每加 10，错误率降一个数量级

测序错误率与碱基质量有关，受测序仪本身、测序试剂、样品等多个因素共同影响。每个碱基的错误率由 Phred 数值（Phred Score、Qphred）通过公式转化得到，而 Phred 数值是在碱基识别（Base Calling）过程中，由预测“碱基判别发生错误概率”的模型计算出来的。[【跳转到 01:19】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=79)

视频给出的简明对应表把分数、错误识别比例、正确识别率和 Q-score 放在一起：[【跳转到 01:42】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=102)

| Phred 分值 | 不正确的碱基识别 | 碱基正确识别率 | Q-score |
| --- | --- | --- | --- |
| 10 | 1/10 | 90% | Q10 |
| 20 | 1/100 | 99% | Q20 |
| 30 | 1/1000 | 99.9% | Q30 |
| 40 | 1/10000 | 99.99% | Q40 |

![碱基识别与 Phred 分值的对应关系表](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00102.webp)

这张表是后面所有“Q20 比例”“Q30 比例”说法的来源：Q20 意味着这个碱基有 99% 的把握读对，Q30 则是 99.9%。分数越高，错误率越低，但两者不是线性关系，而是每提高 10 分，错误率缩小到原来的十分之一。

## 三、RNA-seq 的质量分布有两个固定特征

把一条 read 上每个位置的质量值平均起来，就得到“测序质量分布”。对 RNA-seq 技术，碱基质量值分布有两个特点：[【跳转到 01:52】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=112)

- **质量值随 read 长度增加而降低**。这是高通量测序平台共有的特征，越往 read 末端，信号越容易衰减。
- **前 6 个碱基的质量值比其他位置低一些**。原因是随机引物和 RNA 模板的不完全结合，属于建库方式带来的固定偏差，不是测序仪故障。

![RNA-seq 质量分布：末端下降与前几个碱基偏低](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00112.webp)

这两点决定了读质量图时的正常预期：一条“看起来不错”的曲线，通常是开头略低、中段平稳、末端缓慢下降。如果中段突然塌陷，或者整条曲线都压在低分区，才需要怀疑测序或建库出了问题。

## 四、碱基组成：AT/GC 分离提示建库或测序偏差

除了质量值，还要看每个位置上 A、T、C、G 的比例。碱基含量分布检查用于检测有无 AT/GC 分离现象，这种现象可能由测序或建库带来，并且会影响后续的定量分析。[【跳转到 02:52】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=172)

视频特别解释了转录组里的一个固定现象：反转录合成 cDNA 时所用的 6 bp 随机引物，会让前几个位置的核苷酸组成存在一定偏好性。这种偏好与测序物种和实验室环境无关，但会影响转录组测序的均一化程度。[【跳转到 03:17】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=197)

除此之外，理论上每个测序循环上 G 与 C、A 与 T 的含量应分别相等，且整个测序过程稳定不变，在图上呈水平线。质控后，横坐标是过滤后序列的碱基位置，纵坐标是每个位置上 A、T、C、G 各自的比例，不同碱基用不同颜色表示。[【跳转到 03:34】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=214)

![质控后的碱基含量分布：四条线应大致平行、稳定](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00214.webp)

读这张图时，开头几个位置的波动可以用随机引物解释；如果整条 read 上四条线持续分离、交叉或出现尖峰，就要考虑是否存在污染或建库偏好。

## 五、过滤标准：把“不可信的 read”明确删掉

测序得到的某些原始下机序列会含有测序接头序列以及低质量序列。为了保证信息分析数据的质量，需要对原始序列过滤，得到高质量的 clean reads，后续分析都基于 clean reads。[【跳转到 03:54】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=234)

视频给出的质控标准是五条：[【跳转到 03:59】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=239)

1. **去除接头污染的 reads**：reads 中接头污染的碱基数大于 5 bp；双端测序若一端受到接头污染，则去掉两端的 reads。
2. **去除低质量 reads**：reads 中质量值 Q ≤ 19 的碱基占总碱基的 50% 以上；双端测序若一端为低质量 reads，则去掉两端 reads。
3. **去除含 N 过多的 reads**：若一端含 N 比例大于 5%，则去掉两端 reads。
4. **去除过短的 reads**。
5. **去除过长的 reads**。

![数据过滤的五条标准：接头、低质量、N 比例与长度异常](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00239.webp)

这套标准体现了两个判断原则。第一，阈值是“比例 + 长度”的组合，不是看到一两个低质量碱基就丢整条 read；第二，双端测序以“一端不合格就丢两端”为单位，避免留下无法配对、位置信息不完整的单端 read。

## 六、过滤统计表：用 before/after 对比判断损失是否合理

过滤之后要核对统计表。视频逐项解释了表中字段的含义：[【跳转到 04:57】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=297)

| 字段 | 含义 |
| --- | --- |
| Before QC reads / bases | 过滤前总序列数 / 总碱基数 |
| Before QC Q20 bases / rate | 过滤前质量值大于 20（错误率小于 1%）的碱基数及其占比 |
| Before QC Q30 bases / rate | 过滤前质量值大于 30（错误率小于 0.1%）的碱基数及其占比 |
| Before QC GC content | 过滤前 GC 含量 |
| After QC reads / bases | 过滤后总序列数 / 总碱基数 |
| After QC Q20 / Q30 bases / rate | 过滤后对应质量水平的碱基数及占比 |
| After QC GC content | 过滤后 GC 含量 |
| low quality reads | 因低质量碱基过多被过滤掉的序列数 |
| too many N reads | 因含 N 过高被过滤掉的序列数 |
| too short / too long reads | 因长度过短 / 过长被过滤掉的序列数 |
| adapter trimmed reads / bases | 接头修剪过的序列数 / 碱基数 |
| duplication | 重复序列的比例 |

![过滤统计表：before/after 的 reads、Q20/Q30 与 GC 含量并排展示](assets/Phred%20质量值与%20FASTQ：测序数据质控的第一道门槛/00297.webp)

这张表的价值在于“对照”：过滤后 Q30 比例应上升，reads 数应下降但不应断崖式减少；如果低质量或接头过滤掉的 reads 占比过高，说明文库或测序环节本身有问题，而不是靠过滤就能补救。

Q30 可以反映测序的碱基质量水平。视频最后把全部样本质控后 Q30 碱基占比画成柱状图，横坐标是不同样本，纵坐标是 Q30 占比，用来横向比较样本间的测序质量。[【跳转到 06:52】](https://www.bilibili.com/video/BV1xksoz7Eg7/?t=412)

## 小结

- FASTQ 每条 read 四行，第四行的字符是 ASCII 编码，减去 33 才是 Phred 质量值。
- Phred 分值度量“读错的概率”：Q20 对应 1% 错误率，Q30 对应 0.1%，每加 10 分错误率降一个数量级。
- RNA-seq 质量分布有两个正常特征：末端下降，前 6 个碱基偏低（随机引物造成）。
- 碱基组成图看 AT/GC 是否分离；开头波动可由随机引物解释，全程分离才提示建库或测序问题。
- 过滤标准通常同时约束接头碱基数、低质量碱基比例、N 比例和 read 长度；双端测序以“一端不合格丢两端”为单位。
- 过滤统计表要对照 before/after：Q30 应上升、reads 不应断崖式减少；损失过大说明问题在文库或测序，而不在过滤。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| FASTQ | 存储测序 read 的文本格式，每条 read 四行：标识、序列、加号、质量 |
| Phred 质量值 | 由碱基识别错误概率转化来的分数，分数越高错误率越低 |
| Q20 / Q30 | 质量值 20 / 30，分别对应 1% / 0.1% 的碱基错误率 |
| 接头污染 | read 中混入测序接头序列，多由插入片段过短或接头二聚体造成 |
| clean reads | 按接头、低质量、N 比例和长度标准过滤后保留的 reads |
| duplication | 完全相同的 read 占全部 read 的比例，反映文库复杂度与技术重复 |
