# 药物在体内的五道关卡：ADME 流程、生物利用度与失败率

> 视频来源：[Lecture 9 ADME](https://www.youtube.com/watch?v=2oxoL55U5wY)（YouTube · NPTEL「计算机辅助药物设计」课程，讲者 Mukesh Doble，IIT Madras）｜时长约 33 分钟
> 导读：这是一堂把 ADME 讲成「一颗药片的旅程」的课：从口腔、胃、小肠，到肝脏这道门卫，再到组织、靶细胞和肾脏。本文按「为什么要看 ADME → 旅程地图 → 生物利用度 → 分布体积 → 影响吸收的因素 → 剂型与处方 → 计算预筛的位置」重排；药代参数（半衰期、清除率、浓度-时间曲线）的细节留给本系列 2.2.6。

## 本讲要解决的核心问题（SCQA）

**背景**：评价一个化合物，最直觉的做法是看它对靶点多有效——酶抑制得多强、细菌杀得多干净。这些在体外都能测，而且测得准。

**冲突**：可是把同一个分子喂给动物或人，效果常常差得远。讲者给了两个数字：临床试验中的药物失败，约 **39%** 与药代性质有关（靶位浓度不够、疗效不足），约 **21%** 与**毒性**有关。也就是说，六成的失败跟「分子本身对不对」关系不大，跟「分子到不到得了该去的地方、会不会伤到别处」关系很大。

**疑问**：一个分子从吞下去到起作用，中间要过几道关？每一关会怎样把它拦下来？

**回答（中心思想）**：口服药要过五道关——**吸收、分布、代谢、排泄**，再加上贯穿全程的**毒性**。每一关都会扣掉一部分分子，最后到达靶位的比例就是**生物利用度 $F$**。把这条链路画成地图，就能看出哪一段最可能出问题：吸收段看溶解度与通透性，分布段看血浆蛋白结合与分布体积，代谢段看肝脏这道门卫，排泄段看肾与胆汁，而毒性则可能在任何一个环节之外独立发生。

## 一、先把两个词分清：药代是「身体对药做了什么」

[【跳转到 22:37】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1357)

讲者用一句话把两个学科切开：

- **药代动力学（PK）**：身体对药物做了什么——吸收、分布、代谢、排泄；
- **药效动力学（PD）**：药物对身体做了什么——结合靶点、产生效应。

ADME 属于前者。它不回答「这个分子能不能抑制酶」，只回答「这个分子能不能以足够的浓度、足够长的时间出现在靶点附近」。两者都成立，药才有效。

课程一开始还给了另一张图，说明为什么 ADME 不能单独看：

![化合物结构决定理化性质，理化性质决定生化性质，三者共同决定药代与毒性](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/00101.webp)

[【跳转到 01:06】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=66)

图里三层是同一件事的三个尺度：分子量、氢键给受体、亲脂性、极性表面积、pKa、形状、反应性这些**结构描述符**，先决定**理化性质**（溶解度、通透性、化学稳定性），再决定**生化性质**（代谢、转运体亲和、蛋白结合、靶点亲和），最后才落到**活体层面**（清除率、半衰期、生物利用度、半数致死量）。改动一个结构描述符，三层会同时变——这正是 ADME 优化难的地方。

## 二、为什么必须在第一步就筛 ADME

[【跳转到 10:23】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=623)

讲者列了 ADME 不好的四种后果，其实都是同一件事的不同说法：

1. **疗效不足**：比如细菌感染，药物在感染部位的浓度必须高于该菌的最小抑菌浓度（MIC），否则杀不死；
2. **毒性**：浓度过高本身就是毒性来源；
3. **药物相互作用**：一个病人同时吃降压药、ACE 抑制剂、抗凝的阿司匹林，三种药在代谢环节上会互相干扰；
4. **剂型与给药途径受限**：口服、静注、腹腔、肌注、阴道、经皮、鼻腔，每条路径进入血浆的方式和峰浓度都不一样。

[【跳转到 11:47】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=707)

紧接着就是那两个失败率数字：临床失败中约 39% 来自药代（靶位浓度不够），约 21% 来自毒性。讲者的结论很直接：既然失败集中在这些环节，就应该在**第一步**（还在试管里的时候）先把它们筛一遍，而不是等到动物和临床。

## 三、一颗口服片的旅程：五道关，每道都在扣人

[【跳转到 12:55】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=775)

讲者用「一片口服药」走了一遍全程：

1. **胃肠道**：先到胃（pH 约 1–3），再到小肠、大肠，pH 一路升高。pH 变化会改变药物的解离状态，**溶解度与吸收随之改变**；
2. **吸收**：穿过胃肠壁进入血液。没吸收的部分直接从粪便排出；
3. **肝脏（首过效应）**：门静脉把血先送进肝脏。讲者称肝脏是「了不起的门卫」，它开始降解药物——这就是**首过代谢**；
4. **分布**：进入体循环后分布到组织、器官，一部分被组织「吸走」，一部分与血浆蛋白结合（结合了就暂时用不上）；
5. **排泄**：肾脏（尿）、肺（呼出气体）等途径把药物和代谢物排掉。

![ADME 全景：肠内与肠外两条入口，肝脏首过代谢，组织储库，肾与肺两条出口](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/00785.webp)

[【跳转到 16:14】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=974)

讲者还画了一条更细的「pH 链」，说明同一颗药在不同位置面对的环境有多不一样：

![从口腔到靶细胞：口腔 pH 6.8、胃 pH 1–3、十二指肠到回肠 pH 5–8、血浆 pH 7.4，每一段都在改变药物的解离与稳定性](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01019.webp)

他特别提醒两件事：**酯键和酰胺键在酸性 pH 下可能水解**，所以胃这一关不只是「溶不溶」的问题，还有「会不会被消化掉」的问题；而到了血浆（pH 7.4），前面那些 pH 差异带来的解离状态变化才算稳定下来。

## 四、生物利用度：一条 AUC 比值，把整段旅程压缩成一个数

[【跳转到 15:15】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=915)

讲者的定义很朴素：**给药剂量里，最终以活性形式进入体循环的比例**，就是生物利用度。口服的符号是 $F$。

![口服生物利用度：剂量 D0 只有一部分以 D_abs 进入血浆，其余在肝与肾被清除](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01144.webp)

计算方式是两条浓度-时间曲线下的面积之比：

$$
\%F = 100 \times \frac{\mathrm{AUC}_{\text{口服}}}{\mathrm{AUC}_{\text{静脉}}}
$$

静脉注射默认 100% 进入体循环，所以拿它当分母。讲者给了一个具体做法：给大鼠静注一次、口服一次，分别采血测浓度-时间曲线，两条曲线下面积相除，就得到这个化合物的 $F$。

![静注与口服的浓度-时间曲线：口服的峰更低、峰出现得更晚，曲线下面积也更小](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01562.webp)

[【跳转到 26:02】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1562)

这张图里有两件事值得记住：

- **峰高不同**：口服要经过溶出、跨膜、首过代谢，能进体循环的量本来就少；
- **峰时不同**（$T_{\max}$）：口服要一两个小时才到峰，静注几乎立刻到峰。给药途径直接改变峰形，这也是同一剂量在不同途径下毒性不同的原因。

讲者还专门加了一句限定：**$F$ 只表示「有多少药到了体循环」，不表示「药有多有效」**。有效性要看它能不能杀细菌、杀肿瘤细胞，那是体外药效实验回答的问题。

## 五、分布体积：一锅水加一勺盐

[【跳转到 16:59】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1019)

讲者用了一个很好懂的比喻：把药想成一小勺盐，身体想成一锅水。

- 锅很大（分布体积大），盐撒进去浓度就低；
- 锅很小，浓度就高。

所以**表观分布体积 $V_d$** 不是真实的解剖体积，而是「要让血浆里出现这个浓度，需要多大一锅水」的折算值。它取决于：

- 药物本身：小分子、亲脂的容易钻进组织，血浆浓度就低（$V_d$ 大）；大分子、亲水的留在血里，血浆浓度高（$V_d$ 小）；
- 人的因素：年龄、性别、吃的食物、健康状态。

讲者强调：**同一个人的 $V_d$ 会随药物而变**，所以它不是一个可以查表的常数。

## 六、吸收这一关，影响因素有六类

[【跳转到 23:47】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1427)

讲者把口服吸收的影响因素归成六类，这是本节最像「检查清单」的部分：

![吸收这一关要跨过的屏障：肠壁、毛细血管壁、细胞膜、血脑屏障](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01427.webp)

1. **崩解与溶出**：片剂要先崩开、再溶出，药物才可能被吸收；
2. **胃肠道中的稳定性**：pH 与各种酶都可能把药物降解；
3. **胃肠蠕动与混合**：药物随胃肠液移动、与食物混合，食物里的蛋白等成分会吸附药物；
4. **通透性**：跨过肠壁靠被动扩散，所以通透性必须够好（这一点在上一讲讨论过）；
5. **血流与排空时间**：胃排空最长约 3 小时，小肠可达数小时，大肠可达数天——药物在哪一段停留久，就在哪一段吸收得多；
6. **处方**：表面活性剂、稳定剂、增溶剂都会改变吸收行为。

这六条里，第 1、6 条是**剂型**能改的，第 4 条是**分子结构**决定的，第 2、3、5 条是**生理条件**决定的。分清这一点，才知道遇到吸收问题时该动分子还是动处方。

## 七、给药途径与剂型：有些问题可以绕过分子

[【跳转到 19:04】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1144)

讲者列了口服之外的路径：舌下、直肠、静脉、肌注、皮下、皮内、经皮、吸入、滴眼。他顺带把三个容易混的注射方式说清楚了：

- **皮下**：打进皮肤下面的脂肪层；
- **肌注**：打进肌肉；
- **皮内**：打进表皮下面的真皮层。

不同途径的吸收速率不同，血浆峰形也不同。有些给药是**局部**起效（眼药水、阴道用药、皮肤用药），有些则是为了**全身**（吸入麻醉、尼古丁贴片）。

[【跳转到 28:17】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1697)

讲者用一张地高辛的数据说明「处方能改命」到什么程度：同样是 0.25 mg、稳态下的血药浓度，八个不同厂商的产品可以差到接近十倍。

![地高辛：八家厂商、同样 0.25 mg，稳态血药浓度差近十倍](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01697.webp)

原因不在分子，而在**怎么造这片药**：制片工艺、辅料、晶型都会改变溶出与吸收。这就是为什么仿制药要做**生物等效性**研究。

[【跳转到 29:16】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=1756)

处方层面能做的事还有一长串：

![缓释制剂的手段：油性储库注射、多层肠溶片、树脂缓释胶囊、输注泵、贴片](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/01831.webp)

- **缓释**：油性/黏稠的储库注射、多层肠溶片、树脂缓释胶囊、带传感器的输注泵、尼古丁贴片；
- **前药**：药物先接上另一个基团，帮助它过膜或提高稳定性，进体内后被酶切掉才变成活性形式；
- **脂质体与靶向递送**：把药包进脂质体，或用 pH、温度、酶、抗体—抗原识别来定位释放。

讲者的落点是：**释放曲线可以被拉长到很长一段时间**，而这属于制剂与递送的解法，不是分子改造的解法。

## 八、计算预筛在这张地图上的位置

[【跳转到 01:41】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=101)

课程前半段演示了几个免费工具（Molinspiration、CRDD 门户、OSIRIS Property Explorer、SwissADME），做法都一样：输入 SMILES，输出一堆性质。以瑞士 ADME 对二甲双胍的输出为例：

![SwissADME 对二甲双胍的输出：分子量、TPSA、五种 logP 估计与共识值、水溶性、胃肠道吸收、血脑屏障、P-gp 底物、CYP 抑制、生物利用度评分](assets/药物在体内的五道关卡：ADME%20流程、生物利用度与失败率/00568.webp)

[【跳转到 08:18】](https://www.youtube.com/watch?v=2oxoL55U5wY&t=498)

这张输出值得逐块读一遍，因为它正好对应前面那张地图：

- **理化性质**：分子量、氢键给受体数、可旋转键、TPSA、摩尔折射率；
- **亲脂性**：五种算法各给一个 $\log P$，最后给一个共识值——讲者特意指出，不同软件的算法不同，所以数值会有差异；
- **水溶性**：三种模型各给一个估计值；
- **药代**：胃肠道吸收（高/低）、血脑屏障透过、P-gp 底物、五个 CYP 亚型的抑制；
- **类药性规则**：Lipinski、Ghose、Veber、Egan、Muegge 逐条给「违反几条」；
- **生物利用度评分**：二甲双胍是 0.55（软件提示这是「大鼠 $F > 10\%$ 的概率」）。

讲者对这个分数的评价是「很好」——因为二甲双胍本来就是上市药。他也提醒：这些是**预测**，真实值要去药物数据库查。

对照着看，就能看出这类工具在风险地图上的位置：它把**便宜但需要合成样品才能测**的性质，提前到「只要有一个 SMILES」就能估。它不是判据，而是**排序器**——先按预测值把明显不合格的分子挑出去，把合成和实测的力气留给剩下的。

## 小结

- 药代（PK）回答「身体对药做了什么」，药效（PD）回答「药对身体做了什么」；ADME 属于前者。
- 结构描述符 → 理化性质 → 生化性质 → 活体表现，是同一件事的三个尺度，改一处三层都会动。
- 临床失败里约 39% 与药代有关、约 21% 与毒性有关，这是必须在第一步就筛 ADME 的理由。
- 口服药的旅程：胃肠道（pH 一路升高）→ 吸收 → 肝脏首过代谢 → 分布（含血浆蛋白结合）→ 肾/肺排泄；没吸收的从粪便走。
- 生物利用度 $F$ 是口服与静注 AUC 之比，只说明「有多少到了体循环」，不说明「有多有效」。
- $V_d$ 是折算出来的「一锅水」，随药物与个体而变，不是解剖体积。
- 吸收受崩解溶出、pH 稳定性、蠕动与食物、通透性、血流与排空、处方六类因素影响。
- 剂型、前药、缓释与靶向递送能绕开一部分分子层面的缺陷；地高辛的厂商差异说明处方足以改变临床暴露。
- 计算预筛的作用是排序，不是判决。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| ADME | 吸收、分布、代谢、排泄四个过程的合称，描述药物在体内的去向 |
| 首过效应 | 口服药经门静脉先过肝脏，被代谢掉一部分后才进入体循环 |
| 生物利用度 $F$ | 给药剂量中以活性形式进入体循环的比例，口服时用 AUC 比值计算 |
| $T_{\max}$ | 血药浓度达到峰值的时间，给药途径不同则不同 |
| $V_d$ | 表观分布体积，把体内药量折算成浓度所需的假想体积 |
| 生物等效性 | 不同厂家同一剂量产品在体内暴露是否等价，通常用 AUC 与峰浓度比较 |
| 前药 | 本身无活性、需在体内经酶转化才释放活性药物的衍生物 |
| 缓释制剂 | 通过储库、包衣、树脂等方式让药物在较长时间内缓慢释放的剂型 |
