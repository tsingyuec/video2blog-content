# B06 化学生物学与药物发现基础

编号：B06 · 类型：生物学基础 · 目录规模：54 个小节（三级叶子节点，少于 100）。

**知识主线**：化学结构 → 分子性质与相互作用 → 活性测量 → 多目标药物发现。

**范围与边界**：小分子与功能肽共用的化学和药理底座；生成模型不是实验可成药性的保证。

## 1 分子化学身份与计算表示

<a id="b06-1-1"></a>

### 1.1 化学身份

- 1.1.1 水、离子与非共价相互作用 <a id="b06-1-1-1"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-1-1-1)
  - 学习目标：说明水、离子与非共价相互作用在分子识别中的角色；判断疏水、静电、氢键和范德华力的相对贡献；把结合热力学与实验条件联系起来。
- 1.1.2 原子价态与化学键：连接关系、键级与分子结构 <a id="b06-1-1-2"></a> [DONE]
  - 学习目标：从价电子和键级解释合法连接及形式电荷，不扩成完整量子化学。
- 1.1.3 芳香性与共轭：电子离域、环结构与化学性质 <a id="b06-1-1-3"></a> [DONE]
  - 学习目标：用代表环系解释芳香性和共轭，区分图上的键标记与实际电子结构。
- 1.1.4 官能团与分子反应性：酸碱中心、亲核/亲电与常见转化 <a id="b06-1-1-4"></a> [DONE]
  - 学习目标：用少量官能团解释反应位置及性质差异，连接药物改造但不穷举有机反应。
- 1.1.5 分子立体化学：对映异构与手性识别 <a id="b06-1-1-5"></a> [DONE]
  - 学习目标：用一个镜像异构案例区分相同连接与不同空间结构。
- 1.1.6 分子形态：质子化、互变异构与盐形式 <a id="b06-1-1-6"></a> [DONE]
  - 学习目标：围绕样品和建模输入的一致性解释几种形态。

<a id="b06-1-2"></a>

### 1.2 计算表示

- 1.2.1 分子图与 SMILES：分支、环闭合与立体标记 <a id="b06-1-2-1"></a> [DONE]
  - 学习目标：将一个分子在图和线性表示间对应，检查环编号、手性和多种等价写法。
- 1.2.2 InChI 与结构标识：分层编码、标准化与身份比较 <a id="b06-1-2-2"></a> [DONE]
  - 学习目标：比较结构标识、原始表示和标准化结果，说明盐、互变异构及立体层对身份判定的影响。
- 1.2.3 三维构象、构象集合与化学身份的区别 <a id="b06-1-2-3"></a> [DONE]
  - 学习目标：区分化学身份与构象状态，说明同一分子的构象集合如何影响性质与对接。
- 1.2.4 分子描述符、分子指纹与相似性搜索 <a id="b06-1-2-4"></a> [DONE]
  - 学习目标：对照描述符与指纹表示，用 Tanimoto 等相似度做检索，说明相似不等于活性相同。

## 2 分子理化性质与生物可及性

<a id="b06-2-1"></a>

### 2.1 物理化学性质

- 2.1.1 酸碱平衡：pKa、溶液 pH 与电荷状态 <a id="b06-2-1-1"></a> [DONE]
  - 学习目标：用酸碱平衡解释分子在不同 pH 下的状态。
- 2.1.2 分配与分布系数：logP、logD 与电离条件 <a id="b06-2-1-2"></a> [DONE]
  - 学习目标：用同一分子比较中性物种分配和指定 pH 下的总体分布，关联 pKa 而不重复酸碱平衡。
- 2.1.3 分子溶解度：溶剂化、晶体状态与测量条件 <a id="b06-2-1-3"></a> [DONE]
  - 学习目标：区分热力学和动力学溶解度，说明固态、pH 与实验条件对可用浓度的影响。
- 2.1.4 氢键、疏水作用与分子柔性 <a id="b06-2-1-4"></a> [DONE]
  - 学习目标：说明官能团如何决定氢键与疏水贡献，连接分子柔性对结合熵的影响。

<a id="b06-2-2"></a>

### 2.2 生物可及性

- 2.2.1 ADMET：吸收、分布、代谢、排泄与毒性 <a id="b06-2-2-1"></a> [DONE]
  - 学习目标：只做研发风险地图，具体性质的测量和预测留给专题案例。
- 2.2.2 生物膜通透性：被动扩散、转运体与外排 <a id="b06-2-2-2"></a> [DONE]
  - 学习目标：比较跨膜机制及实验条件，说明分子理化性质、细胞背景和转运共同影响可及性。
- 2.2.3 蛋白结合与自由药物：总浓度、游离浓度与靶位暴露 <a id="b06-2-2-3"></a> [DONE]
  - 学习目标：用一个结合/分布案例区分给药浓度和有效作用浓度，连接体外实验与体内暴露。
- 2.2.4 药物代谢与清除：代谢酶、转化反应与排泄 <a id="b06-2-2-4"></a> [DONE]
  - 学习目标：连接分子改造、代谢产物和清除路径，说明酶抑制/诱导及相互作用，不穷举酶家族。
- 2.2.5 前药与生物活化：可及性缺陷、代谢转化与靶向释放 <a id="b06-2-2-5"></a> [DONE]
  - 学习目标：说明前药设计要解决的可及性缺陷；区分载体前药与生物前药；解释代谢活化与靶向释放的机制；判断前药策略对溶解度、稳定性和毒性的影响。
- 2.2.6 药代动力学：生物利用度、浓度时间曲线与半衰期 <a id="b06-2-2-6"></a> [DONE]
  - 学习目标：用一条暴露曲线解释吸收、分布和清除的总体结果，区分药代暴露与药效。
- 2.2.7 安全性评价：脱靶、剂量依赖毒性与治疗窗口 <a id="b06-2-2-7"></a> [DONE]
  - 学习目标：比较期望效应和损伤的浓度范围，说明靶标相关毒性、脱靶及实验外推限制。

## 3 从相互作用到药理活性

<a id="b06-3-1"></a>

### 3.1 结合与效应

- 3.1.1 结合动力学：kon、koff 与平衡解离常数 Kd <a id="b06-3-1-1"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-3-1-6)
  - 学习目标：读懂 kon、koff 与 Kd 的联系，不重复完整药理学。
- 3.1.2 随机变量与概率分布：离散概率、连续密度与归一化 <a id="b06-3-1-2"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-2-1)
  - 学习目标：用离散和连续例子区分概率质量、密度与区间概率，检查分布归一化。
- 3.1.3 效应量、置信区间与估计不确定性 <a id="b06-3-1-3"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-1-1)
  - 学习目标：在一个组间比较中解释大小与不确定性。
- 3.1.4 酶动力学：米氏曲线、Km、kcat 与催化效率 <a id="b06-3-1-4"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-3-2-2)
  - 学习目标：说明 Km、Vmax、kcat 与催化效率的含义；读懂米氏曲线与抑制曲线；判断竞争、非竞争与不可逆抑制的动力学特征。
- 3.1.5 平衡结合与抑制：Kd、Ki 及实验假设 <a id="b06-3-1-5"></a> [DONE]
  - 学习目标：区分测量对象与相应实验假设。
- 3.1.6 生物物理结合测量：SPR、ITC、MST 与热稳定性位移 <a id="b06-3-1-6"></a> [DONE]
  - 学习目标：比较 SPR、ITC、MST 与热稳定性位移的测量原理；说明平衡常数、速率常数与热力学参数的对应关系；判断标记、固定化与缓冲条件带来的伪影；选择适合小分子—蛋白结合的测量路线。
- 3.1.7 酶抑制与调节：竞争、非竞争与变构控制 <a id="b06-3-1-7"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-3-2-3)
  - 学习目标：说明竞争、非竞争与变构抑制的动力学差异；判断抑制曲线形状与机制假设的对应；把抑制类型与 3.1.8 的别构耦合区分开。
- 3.1.8 变构与结合耦合：构象选择、诱导契合与远程调控 <a id="b06-3-1-8"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-2-2-2)
  - 学习目标：说明构象选择、诱导契合与远程调控的差别；判断非竞争抑制和远端突变如何改变结合；把别构机制与 3.1.7 的抑制曲线判读联系起来。
- 3.1.9 共价与不可逆抑制：反应性基团、可逆性与选择性风险 <a id="b06-3-1-9"></a> [DONE]
  - 学习目标：区分可逆与共价抑制，说明反应性基团带来的选择性和毒性风险。
- 3.1.10 协同结合与别构模型：Hill 系数、MWC 与 KNF <a id="b06-3-1-10"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-2-2-3)
  - 学习目标：说明 Hill 系数偏离 1 的协同含义；比较 MWC 与 KNF 的假设；判断剂量响应陡度变化是否支持多位点协同。
- 3.1.11 剂量响应：IC50、EC50 与曲线判读 <a id="b06-3-1-11"></a> [DONE]
  - 学习目标：把曲线、效能和实验条件一起讲，不把半数指标当固定分子常数。
- 3.1.12 药理读数：亲和力、效能与检测干扰 <a id="b06-3-1-12"></a> [DONE]
  - 学习目标：用同一组曲线判断作用机制、最大效应与检测伪影。

<a id="b06-3-2"></a>

### 3.2 实验设计

- 3.2.1 生化筛选：纯化靶标、反应读数与检测干扰 <a id="b06-3-2-1"></a> [DONE]
  - 学习目标：从靶标和检测体系解释活性信号，比较真正作用、聚集和光学干扰等伪影。
- 3.2.2 细胞靶标验证：进入细胞、靶点占据与通路响应 <a id="b06-3-2-2"></a> [DONE]
  - 学习目标：连接细胞暴露、靶点作用和下游效应，区分细胞活性、靶点结合及通路机制。
- 3.2.3 表型筛选：整体读出、候选发现与靶点解析 <a id="b06-3-2-3"></a> [DONE]
  - 学习目标：解释从表型到候选再到作用机制的证据链，比较靶标驱动筛选，不把表型改善直接归因单一靶标。

## 4 从命中化合物到候选药物

<a id="b06-4-1"></a>

### 4.1 设计目标

- 4.1.1 化学空间、化合物库与命中发现策略：高通量筛选、DNA 编码库与片段筛选 <a id="b06-4-1-1"></a> [DONE]
  - 学习目标：对照筛选策略的规模、成本和覆盖，说明命中来源如何影响后续优化。
- 4.1.2 靶标类别与可成药性：酶、GPCR、离子通道与蛋白—蛋白界面 <a id="b06-4-1-2"></a> [DONE]
  - 学习目标：对照不同靶标类别的结合位点特征，说明可成药性判断的依据与局限。
- 4.1.3 预测相关性、排序指标与数值准确性 <a id="b06-4-1-3"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-4-1-5)
  - 学习目标：比较相关、校准和排序这几种不同目标。
- 4.1.4 构效关系（SAR）、活性悬崖与先导优化 <a id="b06-4-1-4"></a> [DONE]
  - 学习目标：用结构改动和活性变化讲清 SAR。
- 4.1.5 多参数优化：活性、选择性与可开发性权衡 <a id="b06-4-1-5"></a> [DONE]
  - 学习目标：用帕累托权衡说明不能只优化单个分数。
- 4.1.6 可合成性、反应路线与实验可获得性 <a id="b06-4-1-6"></a> [DONE]
  - 学习目标：用合成步骤、原料可得性和收率判断可合成性，说明计算评分与实际路线的差距。

<a id="b06-4-2"></a>

### 4.2 计算证据的角色

- 4.2.1 对接姿态与评分：几何假设、近似能量与排序 <a id="b06-4-2-1"></a> [DONE]
  - 学习目标：说明对接生成的是构象假设，区分几何合法、打分和真实结合；算法在 P05 深入。
- 4.2.2 结合预测与药效证据：预测—实验对接与失败归因 <a id="b06-4-2-2"></a> [DONE]
  - 学习目标：区分结合预测、靶点占据与细胞药效三类证据；判断预测失败应归因于位姿、亲和力还是细胞暴露；说明计算证据在候选排序中的边界。
- 4.2.3 预测适用域与外部验证：骨架切分、时间切分与域外样本 <a id="b06-4-2-3"></a> [WAITING]
  - 学习目标：用骨架和时间切分检查适用域，说明域外预测为何不能直接用于决策。

## 5 肽类分子的特殊性

<a id="b06-5-1"></a>

### 5.1 功能肽的化学结构与作用机制

- 5.1.1 肽键、主链方向与二面角 <a id="b06-5-1-1"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-1-1-5)
  - 学习目标：说明肽键平面、主链方向与二面角的几何约束；判断骨架自由度的来源；把蛋白质几何与后续结构模型对应起来。
- 5.1.2 肽拓扑：线性、头尾成环与二硫键约束 <a id="b06-5-1-2"></a> [WAITING]
  - 学习目标：从连接图和构象自由度比较肽形式，说明闭环、二硫键及多环不是同一种约束。
- 5.1.3 非天然残基与肽修饰：D 型、主链改造与功能权衡 <a id="b06-5-1-3"></a> [WAITING]
  - 学习目标：比较代表性化学改造对构象、稳定性和活性的影响，区分修饰可行和实际可合成。
- 5.1.4 两亲性、电荷与膜相互作用 <a id="b06-5-1-4"></a> [WAITING]
  - 学习目标：用净电荷、疏水矩和两亲性解释膜结合与选择性，连接 MIC 与溶血读数。
- 5.1.5 抗菌肽非膜作用：胞内靶标与机制验证 <a id="b06-5-1-5"></a> [WAITING]
  - 学习目标：用代表肽说明胞内靶向、进入细胞及作用证据，比较膜破坏，不把表达响应当直接靶标证明。
- 5.1.6 肽的化学合成与环化：SPPS、非天然残基与纯度 <a id="b06-5-1-6"></a> [WAITING]
  - 学习目标：说明固相肽合成的偶联、脱保护与裂解步骤；判断环化、二硫键与非天然残基的可行性；区分粗肽纯度、盐形式与批次差异；把计算设计与实际可合成性对照。

<a id="b06-5-2"></a>

### 5.2 功能肽的评价

- 5.2.1 抗菌活性、最小抑菌浓度 MIC 与菌株背景 <a id="b06-5-2-1"></a> [DONE]
  - 学习目标：解释 MIC 的测量定义与菌株依赖性，说明不同实验体系间数值不可直接比较。
- 5.2.2 抗菌肽选择性：细胞毒性、溶血与治疗窗口 <a id="b06-5-2-2"></a> [WAITING]
  - 学习目标：比较抗菌肽的 MIC 与溶血/细胞毒性端点；说明治疗窗口的肽特异性判读；避免把通用小分子治疗窗口直接套用到膜活性肽。
- 5.2.3 肽稳定性：蛋白酶降解与序列修饰 <a id="b06-5-2-3"></a> [WAITING]
  - 学习目标：从降解位置、时间尺度和修饰策略解释稳定性实验，区分抗降解与体内暴露证据。
