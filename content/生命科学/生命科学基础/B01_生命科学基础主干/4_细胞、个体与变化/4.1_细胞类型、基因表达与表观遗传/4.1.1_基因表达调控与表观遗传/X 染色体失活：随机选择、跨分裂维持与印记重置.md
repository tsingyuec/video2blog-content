# X 染色体失活：随机选择、跨分裂维持与印记重置

> 视频来源：[表观遗传系列-10. X染色体失活：看细胞如何把一碗水端平](https://www.bilibili.com/video/BV1Fr4y1n7t8/)（Bilibili · Lithium_Salt，约 13 分钟）
> 导读（100 字以内）：这支视频用一条 X 染色体讲清"表观状态怎么被稳定锁住、又怎么被重置"。本文只取其中与跨分裂维持、重置边界相关的部分，剂量补偿的遗传学细节从简。

## 本讲要解决的核心问题（SCQA）

**背景**：表观修饰不改变 DNA 序列，却能改变基因表达。上一节已经说明，DNA 甲基化在复制之后可以靠"识别半甲基化、照母链补齐"被维持下去。

**冲突**：但"能维持"不等于"整条染色体都能被稳定关掉"。雌性细胞有两条 X 染色体、雄性只有一条，X 上有一千多个基因，如果两条都表达，雌性细胞里这些基因的剂量就是雄性的两倍。细胞必须整条整条地把一条 X 关掉，而且这个"关"要在此后所有分裂和分化中保持不变——这比单个基因的开关难得多。

**疑问**：一条整染色体是怎么被锁死的？锁住之后靠什么跨分裂维持？又是在什么时候、被什么机制重新解锁？

**回答（中心思想）**：X 染色体失活是一个**由一条长非编码 RNA 触发、由多层抑制性修饰加固、靠"哪条 X 表达 Xist"这个状态自我维持**的开关。它一旦在胚胎内细胞团里随机选定，就会在此后所有体细胞分裂中稳定保留；而它的重置发生在生殖细胞和早期胚胎——也就是说，**"稳定"来自正反馈式的锁定，而不是来自不可逆的化学标记**。

## 一、为什么需要整条染色体的开关

[【跳转到 00:00】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=0)

X 染色体上有 900–1600 个基因，Y 染色体上只有 70–200 个。这个数量差带来一个必须解决的问题：**剂量补偿**。

[【跳转到 01:49】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=109)

![X 染色体承载上千基因，Y 染色体只有不到两百个，两条 X 与一条 X 的剂量差必须被平衡](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00109.webp)

视频给出的两条出路是：要么让雄性 X 上的基因都表达一倍，要么把雌性的一条 X 沉默掉。哺乳动物选了后者，这就是 **X 染色体失活**（X-chromosome inactivation）。结果是每个雌性细胞里只有一条 X 的基因被表达，另一条上绝大多数基因被关闭。

[【跳转到 02:13】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=133)

这里可以顺带看清一个常被误解的现象：X 连锁隐性遗传病的女性携带者通常不发病，并不是因为“突变基因没表达”，而是因为随机失活让一半细胞只表达正常拷贝、另一半只表达突变拷贝，而前者已足以完成生理功能。**同一个基因型在不同细胞里可以有不同的表达状态**，这是随机失活最直接的后果。

这个机制有一个直观的副产品：玳瑁猫和三花猫都是母猫。毛色基因在 X 上，两条 X 携带不同颜色等位基因时，随机失活让一半毛囊表达黑色、一半表达黄色，于是拼出花斑。

[【跳转到 00:57】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=57)

![玳瑁猫的毛色是 X 染色体随机失活的可见结果：不同细胞关闭了不同的 X](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00057.webp)

## 二、锁住一条染色体：RNA 覆盖加多层修饰

### 2.1 Xist：覆盖在染色体上的长非编码 RNA

[【跳转到 05:15】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=315)

X 染色体上有一条长非编码 RNA 叫 **Xist**（X-inactive specific transcript）。当 Xist 被稳定表达时,它会缠绕在自己所在的那条 X 染色体上,把它逐步"勒紧"。

[【跳转到 05:28】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=328)

![Xist RNA 覆盖整条 X 染色体，随后 HP1、macroH2A、H3K27me3、H3K9me3 等抑制性成分被招募上来](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00328.webp)

关键在于**后续的加固**：Xist 覆盖之后，大量抑制性的表观修饰被招募过来"添砖加瓦"——HP1、macroH2A，以及 H3K27me3、H3K9me3 这类抑制性组蛋白修饰。到最后这条染色体被各种抑制性修饰插满，DNA 紧紧团在一起，形成显微镜下可见的**巴氏小体**（Barr body）。

这里体现的正是本节最关心的机制类型：**一个初始信号（Xist RNA）招募来一整套修饰，修饰反过来让这个位点持续保持关闭**。关闭状态不是靠某一个化学标记，而是靠"信号—修饰—更彻底的关闭"这个自我加固的循环。

### 2.2 开关的方向：Xist 与 Tsix 互为抑制

Xist 的反义链上编码另一条非编码 RNA，叫 **Tsix**（Xist 反过来拼）。两者互相抑制对方表达，因此一条 X 上到底“开 Xist 还是开 Tsix”，决定它被失活还是保持活跃。

[【跳转到 05:57】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=357)

[【跳转到 09:27】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=567)

![计数（counting）决定失活几条，选择（choice）决定失活哪一条；Xist 开、Tsix 关则失活，反之则保持活跃](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00567.webp)

这张图是本节最实用的流程图，它把失活拆成两个独立问题：

- **counting**：细胞能"数"出自己有几条 X，只保留一条活跃，其余全部失活。这也是 XXX、XXY 这类性染色体数目异常影响相对有限的原因。
- **choice**：在需要失活的那几条里，选哪一条。

一旦 choice 完成、Xist 稳定表达并完成沉默，这个状态就进入自我维持：Xist 开着 → 该 X 保持关闭 → 该 X 上的 Tsix 无法表达 → Xist 继续开。

## 三、维持与重置：两种失活，两种命运

### 3.1 早期胚胎：印记失活，由亲本来源决定

在着床前胚胎中，失活不是随机的，而是**固定失活父源 X**。原因在配子形成时就写好了：卵子中 Xist 基因上带有 H3K27me3 这种抑制性修饰，阻止 Xist 表达，于是母源 X 保持活跃；精子染色体上没有这个修饰，受精后父源 X 正常表达 Xist，把自己失活。

[【跳转到 06:09】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=369)

![卵子给 Xist 打上 H3K27me3 印记使其沉默，父源 X 则正常表达 Xist 并自我失活](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00369.webp)

视频作者顺带指出一个措辞问题：被加上印记的母源 X 不是"被失活"，而是"被保护而保持活跃"，所以叫"印记失活"其实不如叫"印记活化"。

### 3.2 囊胚期：印记被擦除，改为随机失活并永久保持

胚胎发育到囊胚期，细胞发生第一次分流：外层滋养层细胞发育成胎盘等胚外组织，内细胞团发育成个体。此时母源的 H3K27me3 修饰被逐渐清除，**原来那套靠组蛋白印记维持的机制失效了**，内细胞团必须换一种方式维持剂量补偿——于是转向随机失活：约 50% 的细胞失活父源 X，另 50% 失活母源 X。

[【跳转到 07:34】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=454)

![同一枚胚胎走向两条命运：胚外组织保留印记失活，内细胞团擦除印记后改为随机失活](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00454.webp)

这张图是本节的核心，它同时展示了"维持"和"重置"：

- **胚外组织**：印记被维持（imprint maintained），继续失活父源 X；
- **内细胞团**：印记被擦除（imprint erased），重新做 counting 与 choice，随机失活。

而随机失活的结果是**永久的**：一个细胞在内细胞团阶段失活了哪条 X，它此后分裂、分化出的所有细胞都保留同一个选择。视频的原话是，这个细胞经过分裂和分化出的所有细胞，都会保留母细胞的 X 染色体失活结果——**除非它成为生殖细胞**。

[【跳转到 07:59】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=479)

胚外组织走的是另一条路：外层滋养层细胞继续维持印记失活，直到胎盘完成使命后被丢弃。同一个胚胎里，两群细胞用两套不同的维持机制，这是“表观状态取决于细胞所处环境与谱系”的一个直接例子。

[【跳转到 08:54】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=534)

这就是"细胞身份跨分裂维持"最干净的实例：**同一个选择被写进染色质状态，然后靠状态本身跨分裂传递**。它和上一节 DNA 甲基化的维持是同一种逻辑——不是每次分裂重新决策，而是把决策结果变成可以被继承的物理状态。

### 3.3 重置发生在哪：生殖细胞与早期胚胎

重置有两个入口：一是内细胞团擦除组蛋白印记、重新随机选择；二是生殖细胞形成时，整个表观状态被大规模清空，好让下一代重新按亲本来源打印记。视频开头提到的甲基化清除曲线，与这里的 X 失活重置是同一套发育逻辑。

### 3.4 边界：不是整条染色体都被关掉

失活并非“全有全无”。X 上有一小部分基因可以**逃逸失活**（escape），在失活的 X 上依然表达。这也解释了为什么性染色体数目异常（XXX、XXY）不是完全无害：逃逸基因的剂量会随 X 数目增加而升高，导致一定程度的发育障碍。

[【跳转到 10:20】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=620)

[【跳转到 10:50】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=650)

![克隆胚胎的表观障碍：体细胞核移植胚胎在着床前出现异常的母源 X 失活，与正常胚胎的印记失活模式不同](assets/X%20染色体失活：随机选择、跨分裂维持与印记重置/00650.webp)

视频最后用一个实验现象收束：体细胞核移植（克隆）胚胎的成活率低，原因之一就是 X 失活异常。

[【跳转到 11:15】](https://www.bilibili.com/video/BV1Fr4y1n7t8/?t=675)

因为克隆胚胎里不存在卵子留下的那层 H3K27me3 印记,着床前所有 X 都会被失活;虽然到囊胚期外层细胞会以随机方式部分恢复,但早期这段表达异常已经足以影响后续胎盘发育。消除 Xist 能显著提高克隆胚胎发育到出生的成功率。

这个例子说明的是本节最重要的一条边界：**表观状态是"稳定"的，但稳定来自机制持续运作，而不是来自不可逆。** 一旦上游的印记、剂量计数或维持机器被破坏，稳定性立刻消失。

## 四、把 X 失活接回"表观状态与细胞身份"

1. **细胞身份 = 一组被稳定锁定的表达决策。** X 失活把"用哪条 X"这个二选一的决策，变成整条染色体的染色质状态，于是后续所有分裂都不必重新决策。
2. **稳定靠正反馈，不靠单一标记。** Xist 与 Tsix 互为抑制、抑制性修饰层层加固，构成一个自锁回路；上一节甲基化的"识别—补齐"也是同一类自维持结构。
3. **可重置是系统的一部分。** 印记失活 → 随机失活 → 生殖系清空，说明同一套机制可以在不同发育阶段被换掉；"跨分裂维持"与"跨世代重置"并不矛盾。
4. **边界要写清楚。** 逃逸基因、克隆胚胎的异常都提示：表观状态是概率性、条件性的稳定，不能当作绝对的、不可逆的开关。

## 小结

- 雌性有两条 X、雄性一条，X 上基因数以千计，因此需要**剂量补偿**；哺乳动物的方案是整条失活一条 X。
- 失活由长非编码 RNA **Xist** 覆盖染色体触发，随后招募 HP1、macroH2A、H3K27me3、H3K9me3 等抑制性成分加固，形成巴氏小体。
- **Xist 与 Tsix 互为抑制**，构成自锁开关；counting 决定失活几条，choice 决定失活哪条。
- 着床前胚胎是**印记失活**：卵子给 Xist 打 H3K27me3，父源 X 表达 Xist 并自我失活。
- 囊胚期内细胞团**擦除印记、改为随机失活**，此后该选择在分裂与分化中永久保留；胚外组织则继续维持印记失活。
- 重置发生在内细胞团与生殖细胞；**逃逸失活的基因**和**克隆胚胎的异常**是两条重要边界：表观状态的稳定是条件性的、可被破坏的。
