# RNA 加工：加帽、剪接与尾部加工

本节不重复 DNA 转录过程，只聚焦转录本成熟的三道工序。正文见相邻小节 2.2.1 已整理的博客，其中第四节「RNA 加工：一条转录本要过三道工序」完整覆盖本节目标。

## 学习目标覆盖

- **加帽**：见 [转录如何发生：从启动子到成熟 mRNA 的分子流水线](../2.2.1_转录：DNA%20模板与%20RNA%20合成/转录如何发生：从启动子到成熟mRNA的分子流水线.md) 第 4.1 节，说明 5′ 端帽子在转录早期（聚合酶暂停时）加上，以及它对稳定性和后续翻译的作用。
- **加尾**：同文第 3.6 节讲多聚腺苷酸化信号与转录终止，第 4.1 节讲 3′ poly(A) 尾的保护作用。
- **剪接**：同文第 4.2–4.4 节，从内含子/外显子定义讲到剪接体用 RNA-RNA 配对定位剪接位点，再到分支与外显子连接的两步化学反应。
- **可变剪接的意义**：同文第五节，用「两万个基因、几十万种蛋白质」说明同一转录本如何在不同细胞里产生不同产物。

## 阅读顺序

先读 2.2.1 的第一至三节，建立「转录发生在染色质上、聚合酶 II 带着 CTD 平台跑完五个阶段」的框架；再读第四节，把加帽、剪接、加尾放回同一条转录本流水线。若只关心加工，可直接从第四节开始，遇到 CTD、暂停、终止等词再回看第三节。

## 边界

本节不展开剪接体组分的逐个结构、剪接调控蛋白网络，也不讨论 RNA 编辑；这些属于后续 RNA 结构与调控专题。博客中的单细胞语境段落（第六节）可跳过，不影响本节目标。
