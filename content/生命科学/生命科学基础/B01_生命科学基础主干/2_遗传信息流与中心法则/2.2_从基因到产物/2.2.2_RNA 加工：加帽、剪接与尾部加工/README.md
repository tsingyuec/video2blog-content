# RNA 加工：加帽、剪接与尾部加工

## 学习目标覆盖

- **加帽**：见第一篇，说明帽子在转录早期（5′ 端刚伸出聚合酶时）加上，以及 5′,5′-三磷酸酯键为何能挡住核酸酶。
- **加尾**：见第二篇，讲 AAUAAA 加尾信号、下游 10~30 nt 处切割、poly(A) 聚合酶加尾，以及加尾与转录终止的先后关系。
- **剪接**：见第三篇，从内含子/外显子定义讲到 GU-AG 位点、分支点 A、富嘧啶区，再到剪接体的 snRNP 组成与两步转酯反应。
- **可变剪接的意义**：第三篇末尾给出「剪接方式不同 → 成熟 mRNA 不同 → 蛋白不同」的入口，具体模式见相邻小节 2.2.1 的博客第五节。

## 阅读顺序

先读加帽（5′ 端先被封住）→ 再读加尾（3′ 端怎么被封住、以及它和转录终止的关系）→ 最后读剪接（两端都封好之后，中间的内含子怎么被切掉）。三篇合起来是一条完整的「转录本成熟流水线」。

## 边界

本节不展开剪接体组分的逐个结构、剪接调控蛋白网络，也不讨论 RNA 编辑；这些属于后续 RNA 结构与调控专题。转录机制本身（启动子、起始/延伸/终止）见相邻小节 2.2.1。
