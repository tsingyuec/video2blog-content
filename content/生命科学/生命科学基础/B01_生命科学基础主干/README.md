# B01 生命科学基础主干

编号：B01 · 类型：生物学基础 · 目录规模：51 个小节（三级叶子节点，少于 100）。

**知识主线**：从生命的物质与层级出发，沿遗传信息流走向分子功能、细胞状态和可检验的生物学问题。

**范围与边界**：建立共同语言，不替代遗传学、结构生物学或单细胞专题；先掌握主干，再按问题分流。

**前置知识**：无外部硬性前置，起点由本地第一阶段建立；本脉络不设复用小节，所需分支知识在对应专题展开。

**组织与素材策略**：以系统入门课或围绕一个机制/读数的讲解为主。比较任务允许一篇覆盖相互关联的几个概念；不按名词数拆分。

**本脉络的深度边界**：本脉络建立生命科学共同主干；基础过程要能解释，不只辨认名词。复制酶学、免疫网络和结构算法等在分支深入，神经、内分泌与发育只承担入门机制，不重复完整专题。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 博客已从 cairn 的 `生命科学基础主干` 迁入对应小节子目录；`2.2.2` 的内容由 `2.2.1` 的博客覆盖，暂无独立博客，保持 `[WAITING]`。

## 1 生命的物质与组织层级

<a id="b01-1-1"></a>

### 1.1 生命的化学基础与生物大分子

- 1.1.1 水、离子与非共价相互作用 <a id="b01-1-1-1"></a> [DONE]
  - 学习目标：区分氢键、离子键、疏水作用与范德华力的来源和强度，说明水环境如何影响折叠与结合，不展开溶剂化计算。
- 1.1.2 生物大分子：核酸、蛋白质、糖类与脂质 <a id="b01-1-1-2"></a> [DONE]
  - 学习目标：用一个细胞示意图说明核酸、蛋白质、糖和脂质的分工；不展开四门化学课程。

<a id="b01-1-2"></a>

### 1.2 从分子走向系统

- 1.2.1 生命组织层级：分子、细胞、个体与种群 <a id="b01-1-2-1"></a> [DONE]
  - 学习目标：建立观察尺度的地图，能区分细胞实验与个体、种群结论；不深入生态学模型。

<a id="b01-1-3"></a>

### 1.3 细胞结构、生物膜与物质运输

- 1.3.1 原核与真核细胞、细胞器与分工 <a id="b01-1-3-1"></a> [DONE]
  - 学习目标：对照原核与真核细胞的区室和基因组组织，说明细胞器分工，不逐项记忆细胞器清单。
- 1.3.2 生物膜结构与跨膜运输 <a id="b01-1-3-2"></a> [DONE]
  - 学习目标：用扩散、通道和主动运输解释一种膜两侧差异。
- 1.3.3 内膜系统与囊泡运输：分泌途径、内吞与溶酶体 <a id="b01-1-3-3"></a> [DONE]
  - 学习目标：追踪蛋白与膜从内质网到高尔基体、分泌或溶酶体的路线，说明囊泡运输的方向性与区室身份。
- 1.3.4 细胞骨架、细胞形态与胞内运输 <a id="b01-1-3-4"></a> [DONE]
  - 学习目标：认识主要骨架分工及运输案例，不钻入所有马达蛋白。
- 1.3.5 细胞连接、黏附与细胞外基质 <a id="b01-1-3-5"></a> [DONE]
  - 学习目标：区分紧密连接、黏附连接与桥粒，说明细胞外基质如何影响组织形态与信号。

## 2 遗传信息流与中心法则

<a id="b01-2-1"></a>

### 2.1 DNA 与遗传信息

- 2.1.1 DNA 双螺旋：链方向、互补配对与信息存储 <a id="b01-2-1-1"></a> [DONE]
  - 学习目标：用一段双链序列说明方向性、互补性和遗传信息；复制酶机制在 B02 展开。
- 2.1.2 DNA 复制概览：半保留复制与遗传连续性 <a id="b01-2-1-2"></a> [DONE]
  - 学习目标：通过一次细胞分裂追踪亲代和子代 DNA，区分复制、转录和遗传传递，不讲全部复制酶学。
- 2.1.3 基因、基因组与染色体 <a id="b01-2-1-3"></a> [DONE]
  - 学习目标：区分基因、基因组与染色体三个层级，说明基因与产物的对应关系，不展开基因组组装。

<a id="b01-2-2"></a>

### 2.2 从基因到产物

- 2.2.1 转录：DNA 模板与 RNA 合成 <a id="b01-2-2-1"></a> [DONE]
  - 学习目标：解释 RNA 聚合酶如何识别启动子并启动转录；说明模板链、编码链与 RNA 产物的方向关系；区分起始、延伸与终止三个阶段；指出转录与 DNA 复制的关键差异。
- 2.2.2 RNA 加工：加帽、剪接与尾部加工 <a id="b01-2-2-2"></a> [DONE]
  - 学习目标：连起加帽、剪接和尾部加工的过程，不再重讲 DNA 转录。
- 2.2.3 非编码 RNA 的类型与调控功能 <a id="b01-2-2-3"></a> [DONE]
  - 学习目标：用几个代表性 RNA 建立功能地图，不穷举非编码 RNA 家族。
- 2.2.4 遗传密码：密码子、简并性与阅读框 <a id="b01-2-2-4"></a> [DONE]
  - 学习目标：用密码子表解释简并性与摆动配对，说明阅读框改变如何造成移码后果。
- 2.2.5 翻译：核糖体、mRNA 与多肽合成 <a id="b01-2-2-5"></a> [DONE]
  - 学习目标：说明核糖体如何读取 mRNA 上的密码子；解释起始、延伸、终止与阅读框维持；区分 tRNA 适配、肽键形成与移位；指出翻译错误和提前终止的后果。

<a id="b01-2-3"></a>

### 2.3 信息流的边界

- 2.3.1 中心法则、逆转录与 RNA 复制 <a id="b01-2-3-1"></a> [DONE]
  - 学习目标：用转录、翻译、逆转录和 RNA 复制辨认信息流；区分信息传递与表型决定论。

## 3 从分子结构到生物功能

<a id="b01-3-1"></a>

### 3.1 结构与功能的联系

- 3.1.1 蛋白质序列、折叠与功能位点 <a id="b01-3-1-1"></a> [DONE]
  - 学习目标：提供进入蛋白专题的地图；折叠机制、结构域和位点评价在 B03 展开。
- 3.1.2 RNA 结构与调控作用 <a id="b01-3-1-2"></a> [DONE]
  - 学习目标：说明 RNA 二级结构与类别差异，连接结构对翻译和调控的影响，不展开具体 RNA 家族。

<a id="b01-3-2"></a>

### 3.2 分子识别与酶催化

- 3.2.1 酶的底物识别与催化作用 <a id="b01-3-2-1"></a> [DONE]
  - 学习目标：用底物结合和催化反应衔接结构与功能，不展开酶动力学推导。
- 3.2.2 蛋白质降解与蛋白稳态：泛素化、蛋白酶体与自噬 <a id="b01-3-2-2"></a> [DONE]
  - 学习目标：区分泛素—蛋白酶体与自噬两条降解路线，说明降解如何决定蛋白丰度和信号终止。

<a id="b01-3-3"></a>

### 3.3 能量代谢与物质转化

- 3.3.1 ATP、氧化还原与反应偶联 <a id="b01-3-3-1"></a> [DONE]
  - 学习目标：解释 ATP 水解与电子传递如何驱动吸能反应，区分能量载体与反应方向，不展开代谢通路细节。
- 3.3.2 分解代谢：糖酵解与三羧酸循环 <a id="b01-3-3-2"></a> [DONE]
  - 学习目标：沿碳流和能量载体读通主线，不逐个背诵酶名。
- 3.3.3 电子传递链、质子梯度与 ATP 合成 <a id="b01-3-3-3"></a> [DONE]
  - 学习目标：讲清质子梯度、氧化磷酸化与反应偶联。
- 3.3.4 自养、异养与合成代谢的碳源和能源 <a id="b01-3-3-4"></a> [DONE]
  - 学习目标：只比较物质与能量从哪里来；光合作用的全部反应不作为本单元覆盖义务。

<a id="b01-3-4"></a>

### 3.4 细胞信号转导与反馈调控

- 3.4.1 受体、信号转导与第二信使 <a id="b01-3-4-1"></a> [DONE]
  - 学习目标：追踪配体结合到胞内响应的信号链，区分受体类型与第二信使作用。
- 3.4.2 反馈、稳态与时间依赖的细胞响应 <a id="b01-3-4-2"></a> [DONE]
  - 学习目标：用负反馈与正反馈解释稳态和开关行为，说明响应的时间尺度，不展开动力学建模。

## 4 细胞、个体与变化

<a id="b01-4-1"></a>

### 4.1 细胞类型、基因表达与表观遗传

- 4.1.1 基因表达调控与表观遗传 <a id="b01-4-1-1"></a> [DONE]
  - 学习目标：区分转录调控与表观修饰层，说明细胞身份如何跨分裂维持，不展开具体修饰酶。
- 4.1.2 细胞类型、状态与微环境 <a id="b01-4-1-2"></a> [DONE]
  - 学习目标：区分类型、状态与微环境三个描述维度，说明单细胞测量中的判读边界。

<a id="b01-4-2"></a>

### 4.2 遗传变异与演化机制

- 4.2.1 遗传变异与自然选择：可遗传差异和适合度 <a id="b01-4-2-1"></a> [DONE]
  - 学习目标：在一个种群例子中区分变异产生与选择作用，说明环境依赖，不把演化理解成有目的的改变。
- 4.2.2 遗传漂变与基因流：随机抽样、瓶颈与群体交换 <a id="b01-4-2-2"></a> [DONE]
  - 学习目标：比较选择和随机频率变化，解释有效群体大小、奠基者效应与迁移，不展开完整群体遗传方程。
- 4.2.3 物种形成与共同祖先：繁殖隔离和分支演化 <a id="b01-4-2-3"></a> [DONE]
  - 学习目标：用分支演化解释物种形成与共同祖先，连接系统发育阅读，不要求完整物种概念史。

<a id="b01-4-3"></a>

### 4.3 细胞增殖、生殖与命运调控

- 4.3.1 细胞周期：生长、DNA 复制与检查点 <a id="b01-4-3-1"></a> [DONE]
  - 学习目标：画出周期阶段和关键检查点，说明外部信号与增殖控制，不穷举细胞周期蛋白。
- 4.3.2 有丝分裂：纺锤体、染色体分离与细胞分裂 <a id="b01-4-3-2"></a> [DONE]
  - 学习目标：追踪一组复制染色体分配到子细胞的过程，区分染色单体和同源染色体。
- 4.3.3 减数分裂、有性生殖与遗传重组 <a id="b01-4-3-3"></a> [DONE]
  - 学习目标：说明减数分裂的染色体行为与重组来源，解释遗传多样性与连锁，不展开重组率估计。
- 4.3.4 干细胞、自我更新与细胞分化 <a id="b01-4-3-4"></a> [DONE]
  - 学习目标：区分自我更新、分化和谱系，连接后续细胞图谱。
- 4.3.5 细胞衰老：增殖停滞、损伤响应与组织影响 <a id="b01-4-3-5"></a> [DONE]
  - 学习目标：区分衰老和暂时静止，解释持续损伤与组织背景，不把单一标志物当作完整判据。
- 4.3.6 程序性细胞死亡：凋亡信号、执行与清除 <a id="b01-4-3-6"></a> [DONE]
  - 学习目标：用一条代表性凋亡路径说明死亡调控与清除，比较坏死但不展开所有死亡类型。

<a id="b01-4-4"></a>

### 4.4 从个体生理到生命多样性

- 4.4.1 内环境稳态：物质交换与生理反馈 <a id="b01-4-4-1"></a> [DONE]
  - 学习目标：用一种生理反馈回路说明运输、交换与调控；不逐器官讲生理学。
- 4.4.2 神经、内分泌与免疫系统的分工 <a id="b01-4-4-2"></a> [DONE]
  - 学习目标：只建立三类通讯的尺度和作用边界，免疫机制跳转 B05。
- 4.4.3 细胞型微生物：细菌与真核微生物的结构和生长 <a id="b01-4-4-3"></a> [DONE]
  - 学习目标：比较细胞结构、基因组组织和生长条件，区分研究对象而不展开分类大全。
- 4.4.4 病毒：遗传物质、感染周期与宿主依赖 <a id="b01-4-4-4"></a> [DONE]
  - 学习目标：追踪进入、复制、装配和释放，区分病毒颗粒与感染细胞及不同信息流。
- 4.4.5 宿主—微生物互作：共生与感染 <a id="b01-4-4-5"></a> [DONE]
  - 学习目标：用一条宿主互作链区分携带、共生和致病。
- 4.4.6 生态互作：竞争、捕食与互利共生 <a id="b01-4-4-6"></a> [DONE]
  - 学习目标：以一组相互作用解释个体效应和群体结果，区分生态变化与遗传演化，不推导生态动力学模型。
- 4.4.7 神经通讯：膜电位、动作电位与突触传递 <a id="b01-4-4-7"></a> [DONE]
  - 学习目标：沿一个信号通路解释电信号和化学传递，比较传导速度、作用距离与靶细胞；不扩成完整神经科学课程。
- 4.4.8 内分泌调控：激素、受体与反馈轴 <a id="b01-4-4-8"></a> [DONE]
  - 学习目标：用一个反馈轴连接分泌、运输、受体和负反馈，区分局部信号与系统调节，不穷举激素。

<a id="b01-4-5"></a>

### 4.5 发育与组织建成

- 4.5.1 胚胎发育：细胞命运、形态发生与空间图式 <a id="b01-4-5-1"></a> [DONE]
  - 学习目标：用一个发育过程连接分化和组织形态，说明信号梯度与基因调控的分工，不逐物种讲胚胎学。
- 4.5.2 组织稳态：干细胞生态位、更新与修复 <a id="b01-4-5-2"></a> [DONE]
  - 学习目标：以一个组织解释细胞补充、微环境和损伤修复，区分单细胞分化与组织层面的稳定。
