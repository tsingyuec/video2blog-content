## 3 基因表达调控机制

<a id="b02-3-1"></a>

### 3.1 顺式与反式调控

- 3.1.1 受体、信号转导与第二信使 <a id="b02-3-1-1"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-3-4-1)
  - 学习目标：说明受体、信号转导与第二信使的接力关系；判断胞外信号如何变成胞内响应；把信号通路与细胞状态、扰动响应联系起来。
- 3.1.2 顺式调控元件：启动子、增强子与组合结构 <a id="b02-3-1-2"></a> [DONE]
  - 学习目标：用一个基因座定位调控元件和目标，说明位置、方向与细胞背景，不假定最近基因就是靶基因。
- 3.1.3 转录因子识别：序列基序、协同结合与调控作用 <a id="b02-3-1-3"></a> [DONE]
  - 学习目标：连接结合偏好、位点占据和转录响应，区分 motif 命中、真实结合与功能调控。
- 3.1.4 染色质开放性与转录可及性 <a id="b02-3-1-4"></a> [WAITING]
  - 学习目标：解释可及性与转录因子结合的关系，测量技术只作例子。

  - 学习目标：区分启动子、基因体和不同细胞背景中的甲基化，避免将甲基化一概解释为转录关闭。
- 3.1.6 DNA 甲基化证据：亚硫酸氢盐读出与因果验证 <a id="b02-3-1-6"></a> [DONE]
  - 学习目标：从测量信号到位点比例解释覆盖和细胞混合，比较关联、酶干预与调控因果；不展开实验操作。
- 3.1.7 组蛋白修饰、核小体与染色质状态 <a id="b02-3-1-7"></a> [DONE]
  - 学习目标：用核小体及修饰组合解释可及性与转录背景，区分修饰标记、读写机制和因果证据。
- 3.1.8 染色质重塑：核小体定位、重塑复合体与可及性 <a id="b02-3-1-8"></a> [DONE]
  - 学习目标：解释 ATP 依赖的核小体改变，区分重塑、组蛋白修饰和测得的开放性。
- 3.1.9 表观遗传继承：基因组印记、X 染色体失活与细胞记忆 <a id="b02-3-1-9"></a> [DONE]
  - 学习目标：用印记和 X 失活解释等位基因特异性表达，说明表观状态如何跨分裂维持。

## 4 遗传变异与功能后果

<a id="b02-4-1"></a>

### 4.1 变异的层级

- 4.1.1 变异来源：生殖系与体细胞突变、突变率与突变特征 <a id="b02-4-1-1"></a> [DONE]
  - 学习目标：区分生殖系与体细胞变异的来源和遗传后果；说明点突变、插入缺失与结构变异的发生过程；解释突变率与突变特征的含义；判断变异解释应使用哪类来源证据。
- 4.1.2 短序列变异：单核苷酸变异与插入缺失 <a id="b02-4-1-2"></a> [DONE]
  - 学习目标：读懂常见短变异及其位置。
- 4.1.3 结构变异、拷贝数变化与基因组重排 <a id="b02-4-1-3"></a> [DONE]
  - 学习目标：用缺失、重复和重排建立结构变异概念。
- 4.1.4 基因型与等位基因：杂合、纯合与群体频率 <a id="b02-4-1-4"></a> [DONE]
  - 学习目标：在个体和群体层面读懂等位基因与基因型频率，区分样本频率、基因型和测序比例。
- 4.1.5 性状遗传：显性、隐性、分离与复杂性状 <a id="b02-4-1-5"></a> [DONE]
  - 学习目标：用家系和减数分裂解释单基因遗传模式，说明外显率和多基因背景，不把简单规则套到所有性状。
- 4.1.6 连锁与单倍型：重组、相位与连锁不平衡 <a id="b02-4-1-6"></a> [DONE]
  - 学习目标：用相邻变异解释等位基因组合、重组及群体相关，区分共遗传与因果作用。
- 4.1.7 遗传力与数量遗传基础：加性效应、遗传力与遗传相关 <a id="b02-4-1-7"></a> [DONE]
  - 学习目标：用加性效应和遗传力解释复杂性状，说明关联研究能估计什么。

<a id="b02-4-2"></a>

### 4.2 功能与疾病证据

- 4.2.1 编码区变异：密码子改变与蛋白功能后果 <a id="b02-4-2-1"></a> [DONE]
  - 学习目标：连起密码子、氨基酸与可能的功能后果。
- 4.2.2 剪接变异：位点破坏、异构体比例与转录本后果 <a id="b02-4-2-2"></a> [DONE]
  - 学习目标：追踪一个变异从剪接识别到 RNA 和蛋白产物的改变，核对所用转录本和组织背景。
- 4.2.3 调控区变异：结合位点、表达变化与背景依赖 <a id="b02-4-2-3"></a> [DONE]
  - 学习目标：通过顺式元件案例解释非编码变异的作用路径，比较预测、表达关联及功能扰动证据。
- 4.2.4 观察研究中的混杂、选择偏差与关联解释 <a id="b02-4-2-4"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-2-3)
  - 学习目标：画出简单因果图，说明共同原因和选择机制产生的偏差；不把预测相关解释为干预效果。
- 4.2.5 遗传关联分析：关联位点、连锁信号与精细定位 <a id="b02-4-2-5"></a> [DONE]
  - 学习目标：说明关联统计量与候选因果变异的区别，连接连锁不平衡及人群背景，不展开完整 GWAS 实操。
- 4.2.6 变异致病性证据：人群、家系、功能与临床解释 <a id="b02-4-2-6"></a> [DONE]
  - 学习目标：整合多类证据评价候选变异，区分功能变化、疾病关联和临床诊断；ClinVar 条目判读引用 D01。

## 5 演化与可比性

<a id="b02-5-1"></a>

### 5.1 序列同源、比对与系统发育
