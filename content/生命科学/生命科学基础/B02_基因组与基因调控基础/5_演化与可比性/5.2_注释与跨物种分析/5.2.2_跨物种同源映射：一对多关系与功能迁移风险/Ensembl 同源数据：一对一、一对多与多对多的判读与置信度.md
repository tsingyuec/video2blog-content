## 本讲要解决的核心问题（SCQA）

**背景**：做跨物种分析时，我们几乎从不自己算同源关系，而是直接去 Ensembl 这样的数据库里查：这个人类基因在小鼠、斑马鱼、果蝇里分别对应谁，把对方的功能注释搬过来用。

**冲突**：查出来的结果不是一条干净的一对一记录，而是一张按分类群分组的表。同一个基因，有的物种给出一对一，有的物种给出一对多，有的物种干脆列在"没有同源"里；每一行还并排挂着 dN/dS、target %ID、query %ID、GOC、WGA 覆盖度、High Confidence 六列数字，彼此并不总是一致。

**疑问**：一对一、一对多、多对多这些类型到底是怎么算出来的？为什么会出现一对多和"完全没有同源"？那几列质量指标各自在质疑什么，看到"High Confidence = No"时该不该用这条关系？

**回答（中心思想）**：Ensembl 的同源关系是从**基因树**上读出来的——两个基因的共同祖先节点如果是物种分化，就是直系同源；如果是基因复制，就是旁系同源；复制发生在物种分化之后的**哪一侧、哪几个物种里**，决定了一对一、一对多还是多对多。所以一对多不是数据错误，而是真实的演化结果。也正因为关系是推断出来的，数据库才会附上置信度标记：跨物种功能迁移必须先看类型、再看指标，最后回到树上确认，而不是取第一条记录就走。

## 一、同源关系是从基因树上读出来的

### 1.1 三个词的分工，一句话带过

**同源**（homology）是伞形词，指两个序列来自同一个祖先序列；它下面分两支：**旁系同源**（paralog）由基因复制产生，**直系同源**（ortholog）由物种分化产生。这两个词的定义、以及 in-paralog/out-paralog 的参照问题，已在 [5.1.3 同源、直系同源与旁系同源](../../5.1_序列同源、比对与系统发育/5.1.3_同源、直系同源与旁系同源/同源、直系同源与旁系同源：从基因树读出复制与分化.md) 讲清，本节不再重复定义，只关心它们在数据库里**怎么被操作成一张表**。[【跳转到 01:00】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=60)

### 1.2 三类直系同源：差别只在"复制发生在分化之后、发生在谁身上"

Ensembl 的基因树上，**红色方块是基因复制节点，蓝色圆点是物种分化节点**。直系同源由物种分化节点定义，但分化之后两个物种各自的复制历史不同，就派生出三种形态：[【跳转到 01:35】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=95)

- **一对一直系同源**（one-to-one）：物种分化之后，两边都没有再发生复制。这是最"干净"的关系，也是最常被默认使用的关系。
- **多对多直系同源**（many-to-many）：物种分化之后，**两个物种都**发生了复制。此时不能说"人类这个基因对应小鼠那个基因"，只能说"人类这一组对应小鼠那一组"。
- **一对多直系同源**（one-to-many）：物种分化之后，**只有一边**发生了复制，另一边仍保留祖先的那一份拷贝。

![同一棵示意基因树上的三种直系同源：绿色括号分别标出一对一、多对多与一对多；红方块是复制节点，蓝圆点是物种分化节点](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00145.webp)

这张图还藏着一个容易被忽略的细节：一对多里的"多"，是从**同一个祖先拷贝**复制出来的，所以每一个拷贝都是那个祖先基因的合法直系同源，没有哪一个是"唯一正确的那个"。这正是 [5.1.3](../../5.1_序列同源、比对与系统发育/5.1.3_同源、直系同源与旁系同源/同源、直系同源与旁系同源：从基因树读出复制与分化.md) 里说的"直系同源可以是一对多"在数据库层面的具体形态。

### 1.3 旁系同源也分两种：同一物种内 vs 跨物种

旁系同源同样按复制节点读，但要看复制发生在物种分化之前还是之后：[【跳转到 01:10】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=70)

- **物种内旁系同源**（within-species paralog）：复制发生在物种分化**之后**，两个拷贝都在同一个物种里。
- **物种间旁系同源**（between-species paralog）：复制发生在物种分化**之前**，于是两个物种各带一份、彼此互为旁系同源。

![旁系同源由复制节点（红方块）定义：复制在分化之后得到物种内旁系同源，在分化之前得到物种间旁系同源](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00120.webp)

注意这张图里同一个物种内可以有好几对旁系同源（Hsap1/Hsap2/Hsap3 之间），而"物种间旁系同源"那一对（Hsap1–Mmus1）在图上恰恰是直系同源的位置——这说明**旁系同源和直系同源不是互斥的标签，而是对同一棵树上不同节点的两种命名**，一对基因相对某个事件是直系同源，相对更早的复制就是旁系同源。

## 二、基因树怎么建：这条流水线决定了后面所有的偏倚

### 2.1 蛋白编码基因的六步流水线

Ensembl 的同源数据不是"两两比对取最高分"，而是先聚成家族、再建树、最后在树上标注事件。蛋白编码基因走的是这条流水线：[【跳转到 02:25】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=145)

1. 取每个基因的**代表蛋白翻译**；
2. 用 BLAST 把这条序列与**同物种及所有其他物种**的全部蛋白比对；
3. 用 hcluster_sg 把高分命中**松散聚类**；
4. 对每个簇做**多蛋白比对**（M-Coffee/Mafft）；
5. 用 DNA 序列为每个簇**建系统发育树**（TreeBeST + NCBI 分类）；
6. 在树上推断**成对的直系/旁系同源**，并给每棵树分配稳定的 ENSGT 编号。

![Ensembl 蛋白编码基因的建树流水线：代表翻译 → BLAST → 聚类 → 多序列比对 → 建树 → 在树上推断同源关系](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00170.webp)

"在树上推断"这一步是理解一对多的关键：同源关系是**树节点的事件类型**，不是比对分数。同一对序列，如果聚类时被分进了不同簇，它们连"候选同源"都算不上。

### 2.2 参考偏倚就藏在第一步：人类用 CCDS，其他物种用最长转录本

流水线第一步有一句很容易划过去的话：**人类用 CCDS（共识编码序列），其他物种只用最长转录本**。[【跳转到 02:25】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=145)

这句话意味着两件事：

- **同一个基因，进入比对的序列在两边不是同一种东西**。人类那一侧是经过人工审校的共识编码序列，其他物种那一侧是"最长的那条转录本"——最长不等于最准，也不等于表达量最高。
- **转录本选择会改变树形**。如果某个物种的最长转录本多带了一个外显子，比对时就会多出一段，聚类和建树的输入随之改变；一个基因的可变剪接越复杂，这种偏差越大（可变剪接本身见 [2.1.8 可变剪接](../../../2_转录与转录本加工/2.1_转录与加工/2.1.8_可变剪接：外显子选择、异构体与组织特异性/可变剪接的六种模式：同一基因如何拼出不同转录本.md)）。

所以"Ensembl 说这是一对一"这句话，严格说是"**用 Ensembl 选定的那套代表序列建出来的树，读出来是一对一**"。这是数据库层面的**参考偏倚**：参考物种的注释质量更高，非参考物种的注释更粗糙，两边并不对等。

### 2.3 非编码 RNA 走另一条路

非编码 RNA 不能照搬蛋白流水线，原因是它们**靠二级结构而不是序列相似**来认亲，而且序列上每个位点并不独立演化。所以流程改成：从 Rfam 导入 RNA 家族模型 → 找出 Ensembl 里已有的成员并过滤多余拷贝（这一步同时用于判断基因获得与丢失）→ 并行跑"二级结构比对"和"基因组序列"两条流水线 → 分别建树 → 之后再合并。[【跳转到 03:15】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=195)

对使用者来说，这条分支的实际含义是：**非编码 RNA 的同源关系与蛋白编码基因的同源关系不是同一套算法产出的**，两者的置信度不能直接横向比较。

## 三、判读一张同源表：先看类型分布，再看"没有同源"

### 3.1 按分类群汇总的四列

打开 TP53 的 Orthologues 页面，最上面是一张按分类群分组的汇总表，四列分别是**一对一、一对多、多对多、没有同源**的物种数。[【跳转到 12:07】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=727)

![TP53 同源关系的分类群汇总表：灵长类 22 个一对一、1 个一对多；啮齿类 22 个一对一、2 个一对多；全物种合计 77 个一对一、7 个一对多、2 个多对多、11 个没有同源](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00732.webp)

这张表本身就是一份"复制历史摘要"：一对多的物种数越多，说明这个基因家族在该类群里发生谱系特异性复制的次数越多；多对多的出现则说明**两个物种各自都扩张过**，此时任何"取最像的那一个"的做法都在丢信息。

### 3.2 "没有同源"也是信息，不是缺失

页面下方专门有一块：**Ensembl 里哪些物种完全没有这个基因的同源基因**。演示里 C. elegans 和 Saccharomyces 就落在这一栏。[【跳转到 12:42】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=762)

这一栏有三种可能的成因，读表时必须区分：

- **真的丢了**：该谱系发生过基因丢失（整段缺失或假基因化）；
- **太远，树建不起来**：序列分化到 BLAST 都抓不住，于是根本没进同一个簇；
- **注释缺失**：那个物种的基因组里其实有，但没被注释成基因。

前两种是生物学结论，第三种是数据质量问题。把"没有同源"一律当成"这个基因是某类群特有的"，是跨物种分析里最常见的一类过度解读。

## 四、六列质量指标：每一列在质疑什么

主表每一行是一个物种，右侧并排着 dN/dS、target %ID、query %ID、GOC、WGA 覆盖度、High Confidence。它们不是冗余的六个分数，而是从不同角度质疑"这条同源关系"。以阿尔及利亚鼠（*Mus spretus*）为例：[【跳转到 13:32】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=812)

![TP53 同源关系明细表：dN/dS、target %ID、query %ID、GOC、WGA 覆盖度与 High Confidence 六列并排，阿尔及利亚鼠为 0.2133、75.90%、75.32%、100、52.74、Yes](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00837.webp)

### 4.1 dN/dS：这对同源基因还受不受约束

dN/dS（又称 Ka/Ks）估计非同义替换与同义替换的比值，即 $\mathrm{dN/dS} = K_a / K_s$。**越接近 1，说明非同义替换越少、蛋白序列越相似**。演示里阿尔及利亚鼠是 0.2133，远小于 1，说明这段蛋白仍处在较强的纯化选择下。dN/dS 的算法与解释边界见 [5.1.8 序列分歧与选择压力](../../5.1_序列同源、比对与系统发育/5.1.8_序列分歧与选择压力：同义／非同义替换与 dN／dS/dN／dS%20与选择压力：同义与非同义替换的比值怎么算、怎么读.md)。

要注意的是：dN/dS 低只说明**序列受约束**，不说明功能相同。一个保留着酶活性的直系同源基因，完全可能换了底物或换了表达部位。

### 4.2 target %ID 与 query %ID：为什么要有两个方向

这两个百分比常被当成同一个数的两种写法，其实它们的分母不同：[【跳转到 13:57】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=837)

- **target %ID**：目标物种的序列（阿尔及利亚鼠的基因）有多大比例能对上查询物种（人类）的序列；
- **query %ID**：查询物种的序列（人类的基因）有多大比例能对上目标物种的序列。

讲者给了一个很清楚的例子：**如果人类的基因很短、阿尔及利亚鼠的基因很长**，那么鼠序列里会有一大段找不到对应，target %ID 就下降；而人类那段短序列几乎能完整覆盖，query %ID 反而升高。

这个不对称正是**一对多映射的算术根源**：当一个物种的拷贝比另一个物种短（截短、少一个外显子、或只是一个结构域片段），两个方向的百分比就会分叉。看到 target 和 query 差得远，第一反应应该是"两边长度或结构不一致"，而不是"取平均"。

### 4.3 GOC 与 WGA 覆盖度：来自基因组上下文，而不是序列本身

- **GOC**（gene order conservation，基因顺序保守度）：TP53 上下游的基因在对方物种里是否还是这个顺序。演示里阿尔及利亚鼠是 100，说明完全一致。共线性本身是 [5.2.3 比较基因组学](../../../README.md#b02-5-2-3) 的主题，这里只用它当旁证。
- **WGA 覆盖度**（whole genome alignment coverage）：两个物种的全基因组有多大比例能完美比对。演示里阿尔及利亚鼠对人类约 52.74%。这个数**不是这个基因的属性，而是这两个物种的属性**——它给整行数据设了一个上限：如果两个物种只有一半基因组能对上，那么这一行里任何指标都不该期待满分。

### 4.4 High Confidence 是合成判断，不是第六个独立证据

**High Confidence** 是数据库把上面几项合起来给的一个结论：target %ID、query %ID 都够高、GOC 也强，才标 Yes。[【跳转到 15:12】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=912)

![同一张表里 High Confidence 为 No 的行：GOC 很低、target 与 query %ID 都掉到 50% 以下，说明这条"同源"关系证据薄弱](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00937.webp)

读这张图要抓住两点：

1. **No 不代表"不是同源"，只代表"证据不够"**。它可能是真的同源但分化太远，也可能是聚类时被错并进来的旁系同源。
2. **High Confidence 是数据库的标准，不是你的标准**。如果你的分析对假阳性极敏感（例如要把小鼠敲除表型外推到人），就应该只保留 High Confidence 为 Yes 的行，并且额外核对树。

## 五、从表到树：一对多必须放回树上才能用

表格把关系压成了"类型 + 分数"，但一对多到底对到哪几个拷贝、这些拷贝彼此是什么关系，只有树上看得见。演示里点开 TP53 的 Gene Tree 页：[【跳转到 08:01】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=481)

![TP53 基因树页面：查询基因用红字标出，近缘节点展开、其余节点折叠成灰色漏斗，右侧是每个基因的蛋白比对，底部是节点颜色与比对分数的图例](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/00486.webp)

这张图上有四件对判读有用的事：

- **节点颜色就是事件类型**：红色是复制、蓝色是物种分化。点开任一节点会弹出它的事件类型与置信度，所以"这个一对多是怎么来的"可以直接在树上验证。[【跳转到 08:56】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=536)
- **折叠是按分类阶元做的**：页面底部可以把节点按 species、order、phylum 等阶元折叠，于是"只看哺乳纲内部的复制"这种视角可以一键切换。[【跳转到 10:12】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=612)
- **右侧的比对条按一致性着色**（0–33%、33–66%、66–100% 三档，外加 gap 与 aligned），能一眼看出哪一段是两边都保守的核心、哪一段只有一边有。
- **树可以导出成稳定 URL 或图片**，展开/折叠状态会被记住，便于复现和给合作者看。[【跳转到 10:31】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=631)

所以正确的判读顺序是：**先在汇总表看类型分布 → 在明细表筛 High Confidence → 点进 Gene Tree 确认一对多的复制节点在哪**。反过来（先看分数、再猜关系）就会把旁系同源当成直系同源。

## 六、旁系同源与基因家族：扩张与收缩

同源页面的 Paralogs 部分列出的是**这个基因自己的家族成员**。演示里 TP53 的旁系同源是 TP63 和 TP73，它们来自更早的一次复制。[【跳转到 15:53】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=953)

家族层面最有用的视图是**基因获得与丢失树**（gene gain and loss tree）：把每个物种在这个家族里的成员数标在物种树上，显著扩张的谱系用红色标出。[【跳转到 17:07】](https://www.youtube.com/watch?v=7S1-nqYRtrY&t=1027)

![TP53 家族的基因获得与丢失树：每个物种旁的方块数即该家族成员数，人类有 3 个成员，夜猴与大象被标为显著扩张（大象 14 个成员）](assets/Ensembl%20同源数据：一对一、一对多与多对多的判读与置信度/01032.webp)

这张图把"一对多"的来源直接摊开了：**人类有 3 个成员，大象有 14 个**，那么拿人类基因去大象里找同源，注定是一对多，而且"哪一个是功能对应"这个问题在大象身上可能根本没有唯一答案。家族扩张与收缩本身的判读见 [5.2.3 比较基因组学](../../../README.md#b02-5-2-3)。

## 七、功能迁移的判读清单

把上面的内容压成一张可执行的清单。每一步都对应本讲里的一个具体界面或指标：

| 步骤 | 要查什么 | 在 Ensembl 哪里看 | 常见错误 |
| --- | --- | --- | --- |
| 1. 关系类型 | 一对一、一对多、多对多，还是无同源 | Orthologues 汇总表 | 只取第一条记录，不看类型 |
| 2. 证据强度 | High Confidence 是否为 Yes；target 与 query %ID 是否对称 | Orthologues 明细表 | 把 No 当成"不是同源"，或直接忽略 |
| 3. 选择压力 | dN/dS 是否远小于 1 | 明细表 dN/dS 列 | 用低 dN/dS 推断功能相同 |
| 4. 基因组上下文 | GOC 与 WGA 覆盖度 | 明细表后两列 | 忽略 WGA 上限，期待满分 |
| 5. 复制节点 | 一对多的复制发生在哪个阶元、哪一侧 | Gene Tree 页（点节点看事件） | 把旁系同源当直系同源 |
| 6. 家族规模 | 对方物种在这个家族里有几个成员 | Gene gain and loss tree | 在扩张过的家族里强求一对一 |

## 小结

- **同源关系是树上读出来的**：共同祖先节点是物种分化就是直系同源，是基因复制就是旁系同源；复制发生在分化之后的哪一侧，决定一对一、一对多还是多对多。
- **一对多是真实结果，不是数据缺陷**：一对多里的每个拷贝都同样合法，"取最像的那一个"是在用相似度替换同源关系。
- **参考偏倚藏在流水线第一步**：人类用 CCDS、其他物种用最长转录本，两边进入比对的序列并不对等；非编码 RNA 更是另一套算法。
- **"没有同源"有三种成因**：真丢失、分化太远建不起树、注释缺失；只有前两种是生物学结论。
- **六列指标各质疑一个角度**：dN/dS 看约束、target/query %ID 看长度对称性、GOC 看共线性、WGA 看物种可比性、High Confidence 是合成判断。
- **判读顺序不能反**：先看类型分布，再筛置信度，最后回树上确认复制节点。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 一对一直系同源（one-to-one） | 物种分化后两边都没再复制，最"干净"的对应关系 |
| 一对多直系同源（one-to-many） | 分化后只有一侧发生复制，另一侧仍保留祖先的单拷贝 |
| 多对多直系同源（many-to-many） | 分化后两个物种都发生复制，只能按"组"对应 |
| 物种内旁系同源（within-species paralog） | 复制发生在物种分化之后，两个拷贝在同一物种里 |
| 物种间旁系同源（between-species paralog） | 复制发生在物种分化之前，两个物种各带一份 |
| CCDS | 人类共识编码序列；Ensembl 为人类建树时用它，其他物种用最长转录本 |
| dN/dS（Ka/Ks） | 非同义与同义替换的比值；越接近 1 表示非同义替换越少、蛋白越相似 |
| target %ID / query %ID | 两个方向的一致性百分比；分母不同，长度不等时会分叉 |
| GOC（gene order conservation） | 上下游基因顺序的保守程度，用来旁证同源关系 |
| WGA 覆盖度 | 两个物种全基因组能完美对齐的比例，是整行指标的上限 |
| High Confidence | 数据库综合 target/query %ID 与 GOC 给出的置信标记，No 表示证据不足 |
| 基因获得与丢失树 | 在物种树上标注每个物种的家族成员数，用来看家族扩张与收缩 |
