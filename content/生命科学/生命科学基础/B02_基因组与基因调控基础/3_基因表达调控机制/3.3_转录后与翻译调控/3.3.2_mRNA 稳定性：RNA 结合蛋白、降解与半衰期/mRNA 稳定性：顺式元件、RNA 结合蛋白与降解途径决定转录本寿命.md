# mRNA 稳定性：顺式元件、RNA 结合蛋白与降解途径决定转录本寿命

## 本讲要解决的核心问题（SCQA）

**背景**：细胞里的 mRNA 不是造好就一直在的。它一边被转录出来，一边被降解掉，任何时刻测到的量都是这两股力量拉扯后的结果。

**冲突**：做实验的人常常把"mRNA 表达量高"直接读成"这个基因转录活跃"。但同一个表达量，可以来自"转录很快、降解也很快"，也可以来自"转录很慢、但转录本很耐用"。只测丰度，分不出这两种情况。更麻烦的是，降解不是随机磨损：某条 mRNA 什么时候被拆、拆得多快，是由它自己的序列和结合在上面的蛋白决定的。

**疑问**：一条 mRNA 的寿命由什么决定？细胞用什么机器把它拆掉？"半衰期"这个数是怎么测出来的，它和表达量、转录速率是什么关系？

**回答（中心思想）**：mRNA 稳定性由**两层因素**决定——转录本自身的顺式元件（主要是 3′UTR 上的 AU 富集元件等）和结合上去的 RNA 结合蛋白；这两层因素最终都汇聚到**同一条执行路线**：脱腺苷酸化削短 poly(A) 尾 → 脱帽 → 外切酶降解（另有去尾后 3′→5′ 降解、中间内切和 NMD 等分支）。半衰期是这条降解路线的**时间尺度**；而稳态表达量 ≈ 合成速率 × 寿命，所以"表达量高"既可能是转录快，也可能是降解慢——这正是放线菌素 D 实验要先把"合成"关掉、只留"降解"的原因。

## 二、寿命由两个因素决定：自己身上的序列，和结合上去的蛋白

视频把稳定性的调控因素归结为两条："mRNA 自身的序列特征"和"RNA 结合蛋白"。[【跳转到 00:25】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=25)

![mRNA 稳定性的两个决定因素：序列特征（AU 富集元件）与 RNA 结合蛋白（保护或招募降解机器），共同汇聚到去腺苷酸化这条机制](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1VkHY6uECM_00030.webp)

### 2.1 顺式元件：3′UTR 上的 AU 富集元件是不稳定的标签

"mRNA 自身的序列特征，比如 3′UTR 上的 AU 富集元件（AU-rich element，ARE），是很多不稳定 mRNA 的标志。"[【跳转到 00:30】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=30)

这里要先解释三个词：

- **3′UTR（3′非翻译区）**：mRNA 终止密码子之后、poly(A) 尾之前的那一段，不编码蛋白，但装满了调控位点。
- **顺式元件**：写在这条 RNA 分子自己身上的一段序列，只能影响"自己这一条"，不能扩散去管别的分子。
- **AU 富集元件**：一段富含 A 和 U 的短序列，是许多短寿命 mRNA 的共同标记。

ARE 本身不会拆 RNA，它只是一个"把手"。真正的动作是：**ARE 被 RNA 结合蛋白识别 → 招募去腺苷酸化酶 → poly(A) 尾巴被一点点削短 → 尾巴短到一定程度，mRNA 就被降解了**。[【跳转到 00:30】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=30)

所以"顺式元件"和"降解机器"之间不是直接连接，中间必须经过一个**反式因子**（结合上去的蛋白）。同一个把手，配上不同的蛋白，结局可以完全相反——这就是下一小节。

### 2.2 RNA 结合蛋白：同一段 RNA，可以被保护，也可以被送去降解

视频把 RNA 结合蛋白（RNA binding protein，RBP）的作用分成方向相反的两种：[【跳转到 00:55】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=55)

| 类型 | 做什么 | 视频里的例子 |
| --- | --- | --- |
| 保护型 | 结合上去，挡住降解机器 | PABP 结合在 poly(A) 尾巴上 |
| 招募型 | 结合上去，把降解机器叫来 | 结合到 TNF-α mRNA 上、加速其降解的蛋白 |

PABP（poly(A) binding protein，多聚腺苷酸结合蛋白）值得单独说一句：它结合的是**每一条正常 mRNA 都有的 poly(A) 尾**，所以它提供的是一种"默认保护"。这也解释了为什么降解的第一步通常必须是**先把尾巴削短**——不破坏这个默认保护，后面的脱帽和外切就无从下手（第三节会展开）。

### 2.3 一个例子：TNF-α 的 mRNA 寿命被临时改写

视频给了一个临床锚点：正常情况下，炎症因子 TNF-α 的 mRNA **半衰期很短**；但在炎症刺激下，某些 RNA 结合蛋白结合到它 3′UTR 上，把它**稳定住**，让 TNF-α 持续表达；"如果这个调控失控，就会导致慢性炎症"。[【跳转到 00:55】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=55) [【跳转到 01:08】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=68)

![TNF-α 的稳定性调控：正常时半衰期很短，炎症刺激下 RNA 结合蛋白结合 3′UTR 把它稳定住，失控则导致慢性炎症](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1VkHY6uECM_00068.webp)

这个例子的价值在于它把"稳定性"从抽象概念变成了一个可观察的开关：**序列没变、转录速率可以没变，只改结合蛋白，蛋白产量就变了**。这也是为什么后面测半衰期的实验常常以"某药物处理 / 某基因敲低后稳定性变化"的形式出现——视频举的两个文献例子，一个是 CB-2 处理后 VEGF mRNA 稳定性变化，一个是敲低 m6A 甲基化酶 METTL3 后 RNA 稳定性变化，都是用同一套放线菌素 D 方法做出来的。[【跳转到 01:45】](https://www.bilibili.com/video/BV1tP411y75j/?t=105)

![文献中用放线菌素 D 测稳定性的两个实例：左图是 CB-2 处理前后 VEGF mRNA 的降解曲线，中右图是敲低 METTL3 后靶 mRNA 的降解曲线](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1tP411y75j_00105.webp)

### 2.4 miRNA 位点也是顺式元件（机制见 3.3.1）

同一支视频的后半段讲 miRNA，其中与本节直接相关的一点是：miRNA 响应元件位于靶 mRNA 的 3′UTR 上，是**顺式元件**；miRNA 本身由其他基因编码、可以扩散，是**反式因子**。当 miRNA 与靶标部分互补配对时，它不切割 mRNA，而是"抑制翻译起始，同时招募去腺苷酸化酶，加速 mRNA 降解"。[【跳转到 02:04】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=124) [【跳转到 02:29】](https://www.bilibili.com/video/BV1VkHY6uECM/?t=149)

这里只需要记住结论：**miRNA 是"招募型 RBP 的一种特例"**——它自己不带酶，靠招募去腺苷酸化酶来缩短寿命。miRNA 怎么生成、种子区怎么配对、怎么区分预测与真实靶标，见 [3.3.1 miRNA 调控](../3.3.1_miRNA%20调控：靶标识别、RNA%20沉默与背景依赖/miRNA靶标预测：种子区配对、评分与预测的边界.md)，本文不重复。

## 三、降解机器：默认路线是先去尾、再脱帽、再外切

第二支视频（陈博士）从"为什么脱腺苷酸化是最重要的降解途径"讲起，把执行机器拆得很清楚。[【跳转到 00:00】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=0)

### 3.1 正常 mRNA 是首尾相连的环，这本身就是一层保护

翻译时，mRNA 的 5′端（帽）通过 eIF4E、eIF4G 与 3′端的 PABP 相互作用，形成一个**封闭的环状结构**。视频的说法是，这个环状结构的目的是"防止脱腺苷酸化酶和脱帽酶的攻击"，"首尾相连、防止降解"。[【跳转到 00:25】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=25) [【跳转到 00:50】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=50)

![封闭环状结构与四条降解路线：5′帽经 eIF4E/eIF4G 与 3′端 PABP 相连，右表列出封闭环状保护、去尾脱帽、去尾、脱帽、中间切割五种情形](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1YDLp6hEmP_00050.webp)

这张表是本节最值得反复看的一页：左边是"正常状态怎么被保护"，右边是"保护被打破后有四条路"。注意一个容易忽略的点——**翻译机器和保护结构是同一套组件**。核糖体在翻译时用的 eIF4E/PABP，同时也是防止降解的锁。这解释了为什么"翻译活跃"和"mRNA 稳定"经常同向变化，而不是彼此独立。

### 3.2 四条降解路线

视频把真核 mRNA 的降解归纳为四条路线，并明确说"去尾脱帽降解是最重要、最常见的一种"，前两条都属于脱腺苷酸化：[【跳转到 04:04】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=244) [【跳转到 04:29】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=269)

1. **去尾 → 脱帽 → 5′→3′外切**：脱腺苷酸化酶侵入环状结构、削短 poly(A)；随后脱帽酶去掉 5′端 7-甲基鸟嘌呤帽子；失去两头保护的 RNA 被 5′→3′核酸外切酶水解。
2. **去尾 → 3′→5′外切**：脱腺苷酸化后不脱帽，直接由 3′→5′核酸外切酶从尾巴端往里啃，这就是**外泌体**路线。
3. **脱帽 → 5′→3′外切**：少数 mRNA 不经过脱腺苷酸化，直接脱帽后被 5′→3′外切酶降解。
4. **中间内切**：核酸内切酶识别内部特异序列，从中间切断，产生的游离 3′端和 5′端再被外切酶收拾。

![去尾脱帽路线的分步图：poly(A) 尾被 deadenylase 逐步削短至 A0，脱帽酶移除帽子，最后 5′→3′核酸外切酶降解 RNA 本体](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1YDLp6hEmP_00304.webp)

视频对这条主线的总结很形象："就这么一条 mRNA，两头可以降解、中间可以切断"，所以记四条路线时，可以按"从哪头下手"来记。[【跳转到 04:29】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=269)

### 3.3 外泌体：3′→5′方向的降解机器

外泌体（exosome）是执行第 2 条路线的多亚基机器，视频说课本不要求，但结构值得知道：它由 **RNA 解旋酶、ATP 酶、外泌体核心和核酸酶**组成。RNA 从中心孔道被送入核心，解旋酶和 ATP 酶先帮忙解开二级结构，核心里的核酸酶再把它切碎。[【跳转到 02:44】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=164) [【跳转到 03:09】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=189)

![外泌体的结构：RNA 解旋酶与 ATP 酶在顶部解开 RNA 二级结构，RNA 经中心孔道进入外泌体核心，由核酸酶切割](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1YDLp6hEmP_00164.webp)

"先解旋、再切割"这个顺序有实际含义：RNA 是有二级结构的，如果机器不先把结构打开，酶就切不到该切的位置。所以降解速率不只取决于酶有多少，也取决于**这段 RNA 好不好解**。

### 3.4 无义介导降解：按"翻译状态"而不是按序列拆

第四条路线的特例是**无义介导的 mRNA 降解（NMD）**。视频先补了两个概念：[【跳转到 05:04】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=304)

- **提前终止密码子（PTC）**：剪接异常等原因让终止密码子提前出现在可读框中间。
- **外显子拼接复合体（EJC）**：剪接完成后留在外显子—外显子连接处上游的一组蛋白，是诱导 NMD 的重要因子。

机制可以用视频的"火车头"比喻讲完：正常情况下，核糖体像火车头一路往前推，把路上的 EJC 都推掉；一旦遇到 PTC，核糖体提前停下，后面的 EJC 就留在 mRNA 上，这些残留的 EJC 募集来脱帽酶和外切酶，把这条 mRNA 降解掉。[【跳转到 07:00】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=420) [【跳转到 07:25】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=445) [【跳转到 07:50】](https://www.bilibili.com/video/BV1YDLp6hEmP/?t=470)

![NMD 的 EJC 模型：正常终止密码子时 EJC 被经过的核糖体移除；出现 PTC 时核糖体提前停下，EJC 保留并募集 UPF1 等因子，最终由脱帽酶 Dcp1a 和外切酶 Xrn1 降解 mRNA](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1YDLp6hEmP_00420.webp)

NMD 与前面三条路线的区别在于**判据**：前三条看的是"尾巴和帽子还在不在"，NMD 看的是"翻译过程有没有走完"。也就是说，同一条 mRNA，如果它不被翻译，NMD 就无从判断它有没有 PTC。这条通路的三类坏 mRNA、三条监视通路和核糖体足迹证据，在 [B01《mRNA 监视》](../../../../B01_生命科学基础主干/2_遗传信息流与中心法则/2.2_从基因到产物/2.2.5_翻译：核糖体、mRNA%20与多肽合成/mRNA%20监视：提前终止密码子、无义介导降解与核糖体足迹的读框证据.md) 里有完整展开，本文只把它作为"降解路线之一"定位。

## 四、怎么测半衰期：把"合成"关掉，只看"降解"

到这里，机制层面已经清楚。但"半衰期"是一个**测量出来的数**，不是从序列推出来的。第三支视频（进哥的小课堂）整支都在讲这个测量。[【跳转到 00:00】](https://www.bilibili.com/video/BV1tP411y75j/?t=0)

### 4.1 放线菌素 D 的作用原理

放线菌素 D（Actinomycin D，ACTD）是一种能**插入 DNA** 的转录抑制剂：它与 DNA 形成稳定复合物，阻止双螺旋展开，从而抑制 DNA 依赖性 RNA 聚合酶的活性，**抑制新生 RNA 的生成**。这样就把"合成"这一项关掉了，剩下的变化只能来自降解，于是可以"通过抑制转录来测定 RNA 的动力学、检测 RNA 的半衰期"。[【跳转到 02:10】](https://www.bilibili.com/video/BV1tP411y75j/?t=130)

这一步是整支视频的逻辑基石，值得停下来想一遍：**只有把合成关掉，"量随时间下降"才能被解释为降解**。如果不关合成，测到的下降可能只是"合成变慢"，而不是"降解变快"。

### 4.2 时间点设计：0、1、2、4、6、8 小时

基本流程是：细胞铺板贴壁 → 加药处理（例子里是 4-HOT，也可以是过表达/敲低或其他刺激）→ 加 ACTD，在 **0、1、2、4、6、8 小时**分别收集细胞、提取 RNA。给药 0 小时之后**立即**收集，作为基线。[【跳转到 03:06】](https://www.bilibili.com/video/BV1tP411y75j/?t=186) [【跳转到 03:31】](https://www.bilibili.com/video/BV1tP411y75j/?t=211)

![放线菌素 D 实验的流程与时间点：铺板、加药、加 ACTD 后按 t=0/1/2/4/6/8 小时分别收样](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1tP411y75j_00211.webp)

时间点的选择不是随意的：**采样间隔必须和半衰期同一个量级**。如果半衰期只有半小时，8 小时的点早就到底了；如果半衰期超过一天，8 小时内几乎看不到下降。视频后面提到的"延长到 8–12 小时"和"circRNA 更稳定"就是在处理这个问题。[【跳转到 07:22】](https://www.bilibili.com/video/BV1tP411y75j/?t=442)

### 4.3 这个实验不能用内参——这是最容易做错的一步

常规 qPCR 会用 ACTB、GAPDH 这类"稳定表达"的基因做内参。视频明确说：**这个实验不能使用内参基因**。理由是 ACTD 是广谱转录抑制剂，"所有 RNA（mRNA、circRNA 和 rRNA 等）的转录都会被抑制，所以理论上没有不变的、合适的内参 RNA"。[【跳转到 04:02】](https://www.bilibili.com/video/BV1tP411y75j/?t=242) [【跳转到 04:27】](https://www.bilibili.com/video/BV1tP411y75j/?t=267)

![为什么不能用内参：ACTD 抑制所有 RNA 的转录，没有真正不变的内参；图中 circRNA、ACTB、Target1 三条降解曲线斜率不同](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1tP411y75j_00267.webp)

后果可以具体推出来：假设 ACTB 自己也在降解（红色），circRNA 降解较慢（蓝色），目标基因降解较快（绿色）。用 ACTB 去标准化 circRNA，circRNA 会显示成"上升"；用 ACTB 去标准化一个降解稍慢的目标基因，它仍然下降，但**下降速度被压平，算出的半衰期比真实值高很多**。[【跳转到 05:17】](https://www.bilibili.com/video/BV1tP411y75j/?t=317)

这就是"用错内参"的典型症状：**不是数据噪声变大，而是系统性偏移**——慢降解的 RNA 被算得更慢，甚至被算成上升。

### 4.4 逆转录要等体积，不要等质量

第二个易错点：ACTD 处理之后没有新生 RNA，总 RNA 量会随时间下降。如果每个时间点都取**等质量** RNA 去逆转录，等于把"总量下降"这件事标准化掉了，降解曲线就被抹平，最后"可能得到一条波动、不规律的曲线"。[【跳转到 06:07】](https://www.bilibili.com/video/BV1tP411y75j/?t=367)

正确做法是**等体积**逆转录，和做 qPCR 时一致。[【跳转到 06:32】](https://www.bilibili.com/video/BV1tP411y75j/?t=392)

这里的道理和 4.3 是同一个：**这个实验要测的就是"量在减少"，任何把量拉平的归一化都会破坏信号**。

### 4.5 拟合与读数：one phase decay 给出半衰期

数据处理比常规 qPCR 的 $2^{-\Delta\Delta C_t}$ 简单：把 Ct 值导出、算重复均值、把每个时间点归一化到 t = 0 得到 ΔCt，再换算成相对丰度；然后用 **one phase decay**（单相指数衰减）拟合，软件直接给出半衰期。[【跳转到 09:02】](https://www.bilibili.com/video/BV1tP411y75j/?t=542) [【跳转到 10:28】](https://www.bilibili.com/video/BV1tP411y75j/?t=628)

![文献案例的降解曲线与拟合结果：对照组与处理组的半衰期分别为 0.7304 和 0.7707，两条曲线接近、重叠较多](assets/mRNA%20稳定性：顺式元件、RNA%20结合蛋白与降解途径决定转录本寿命/BV1tP411y75j_00608.webp)

顺便注意视频对这个案例的点评：两组半衰期 0.73 与 0.77 很接近，所以"两条曲线重叠得比较多、不是很明显"。[【跳转到 11:18】](https://www.bilibili.com/video/BV1tP411y75j/?t=678) 这提醒一件事：**半衰期的差异要大到能在曲线上看出来，才值得当结论**；只报两个数字而不看曲线形状，容易把拟合噪声当成生物学差异。

## 五、转录速率与稳态表达量：同一个读数，两种来源

前面四节分别讲了"谁决定寿命""怎么拆""怎么测"。最后一节把这三件事接回学习目标：**为什么测到一个表达量，不能直接当成转录活性**。

### 5.1 稳态是合成与降解的平衡

在任何时刻，一条 mRNA 的量取决于两件事：单位时间新合成多少、单位时间降解掉多少。当两者相等时，量不再变化，这个量就是**稳态表达量**。

放线菌素 D 实验正好把这个平衡"拆开"给我们看：加药前，细胞处在一个稳态，t = 0 的那个点就是稳态水平；加药后合成被关掉，曲线只剩降解。**同一条曲线同时包含两个信息**——起点高度是稳态水平，下降快慢是降解速率。[【跳转到 02:10】](https://www.bilibili.com/video/BV1tP411y75j/?t=130)

### 5.2 一个推演：高表达不等于高转录

> 说明：下面的关系式与三种情形是**本节的推演**，用来说明测量逻辑的后果，不是三支视频的原话。视频只提供了"ACTD 关掉合成、曲线反映降解"这一事实和"越稳定产生的蛋白越多"这一结论。

把稳态写成近似关系：

$$
\text{稳态表达量} \approx \text{合成速率} \times \text{mRNA 寿命}
$$

其中寿命与半衰期同向变化（半衰期越长，寿命越长）。于是同样的表达量可以由完全不同的组合产生：

| 情形 | 合成速率 | 半衰期 | 稳态表达量 | 加 ACTD 后的曲线 |
| --- | --- | --- | --- | --- |
| A 转录快、降解也快 | 高 | 短 | 中等 | 掉得很快 |
| B 转录慢、降解也慢 | 低 | 长 | 中等 | 掉得很慢 |
| C 转录快、降解慢 | 高 | 长 | 高 | 掉得慢且起点高 |

A 和 B 的稳态表达量可以一模一样，但生物学含义完全不同：A 是"快速周转、随时可关"，B 是"少量生产、长期备用"。**只测丰度，分不出 A 和 B；只有测了半衰期，才能把两者分开。**

这也解释了 2.3 节 TNF-α 例子的意义：炎症刺激下把 mRNA 稳定住，属于"改寿命而不改转录"的调控；如果只测表达量上升，就会误判成"转录被激活"。

### 5.3 反过来：半衰期也不能单独说明转录

对称地，半衰期变长也不等于表达量一定升高——如果同时转录速率下降，两者可以抵消。所以一个完整的判断需要两个参数：**降解侧**用 ACTD 这类"关合成、看衰减"的实验测；**合成侧**需要另一类直接测新合成 RNA 的实验。

本节的三支视频都只覆盖降解侧，没有给出测合成速率的方法，这是本节的边界。看文献时如果只看到半衰期数据，应把它读成"降解参数"，而不是"表达调控的全部"。

## 六、边界与常见误读

- **半衰期是群体平均，不是单分子寿命**：ACTD 实验测的是整群细胞、整批分子的平均衰减行为，曲线上的每个点都是大量分子的总和。因此它描述的是"这批分子整体掉一半需要多久"，不能读成"每个分子都恰好活这么久"。
- **稳定性与翻译不是两件独立的事**：3.1 节已经看到，翻译用的 eIF4E/PABP 同时也是防降解的锁；NMD 更是直接由翻译状态触发。所以"翻译效率"和"稳定性"经常同向变化，不能假设二者互不影响。
- **本节不展开 miRNA 生成与靶标预测**：miRNA 只作为"3′UTR 上的顺式位点 + 招募型反式因子"出现，完整机制见 [3.3.1](../3.3.1_miRNA%20调控：靶标识别、RNA%20沉默与背景依赖/miRNA靶标预测：种子区配对、评分与预测的边界.md)。
- **本节不展开翻译起始调控**：UTR 元件如何影响核糖体招募、起始因子如何被调控，属于 3.3.3 的范围；本文只在"环状结构"处提到 eIF4E/eIF4G，因为它们是降解保护结构的一部分。
- **RNA 修饰只作为应用例子出现**：视频提到 METTL3 敲低影响稳定性，但没有讲 m6A 的写入、读取与去除机制，那属于 3.3.4。

## 小结

1. **稳定性是转录之后的一道独立闸门**：转录量不变，改半衰期就能改蛋白产量。
2. **决定寿命的是两层因素**：转录本自己的顺式元件（3′UTR 上的 ARE 等）和结合上去的 RNA 结合蛋白（保护型如 PABP，招募型如结合 TNF-α mRNA 的蛋白）。
3. **两层因素汇聚到同一条执行路线**：脱腺苷酸化削短 poly(A) → 脱帽 → 外切酶降解；另有去尾后 3′→5′（外泌体）、直接脱帽、中间内切三条分支。
4. **NMD 的判据不同**：它不看尾巴和帽子，而看翻译有没有走完——PTC 让核糖体提前停下，残留的 EJC 募集脱帽酶和外切酶。
5. **测半衰期的核心操作是关掉合成**：ACTD 插入 DNA 抑制新生 RNA，之后量的下降只能来自降解。
6. **这个实验不能套常规归一化**：不能用内参 RNA，逆转录要等体积；真正要对齐的是细胞数目。
7. **表达量是合成与降解的乘积**：高表达既可能来自高转录，也可能来自长半衰期；只测丰度分不开，必须补测半衰期。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| mRNA 稳定性 | 一条 mRNA 在细胞里能被保留多久；用半衰期或降解速率描述 |
| 半衰期（t₁/₂） | 降解掉一半所需的时间；指数衰减拟合的直接输出 |
| 顺式元件 | 写在这条 RNA（或 DNA）自己身上、只能影响自身的调控序列 |
| 反式因子 | 由别的基因编码、可以扩散并结合到顺式元件上的分子（蛋白或 RNA） |
| 3′UTR | 终止密码子之后、poly(A) 尾之前的非翻译区，稳定性调控位点的主要所在地 |
| AU 富集元件（ARE） | 3′UTR 上富含 A/U 的短序列，许多短寿命 mRNA 的标志 |
| RNA 结合蛋白（RBP） | 结合 RNA 的蛋白；可保护转录本，也可招募降解机器 |
| PABP | 多聚腺苷酸结合蛋白，结合 poly(A) 尾，提供默认保护 |
| 脱腺苷酸化 | 把 poly(A) 尾逐步削短，通常是降解的第一步 |
| 脱帽 | 移除 5′端 m⁷G 帽子，使 RNA 暴露于 5′→3′外切酶 |
| 外泌体（exosome） | 3′→5′方向的多亚基降解机器，含解旋酶、ATP 酶、核心与核酸酶 |
| 无义介导降解（NMD） | 识别含提前终止密码子的 mRNA 并降解的质量监控通路 |

| 放线菌素 D（ACTD） | 插入 DNA、抑制转录起始延伸的抑制剂，用于关闭合成测降解 |
| 稳态表达量 | 合成与降解达到平衡时的 mRNA 量 |
