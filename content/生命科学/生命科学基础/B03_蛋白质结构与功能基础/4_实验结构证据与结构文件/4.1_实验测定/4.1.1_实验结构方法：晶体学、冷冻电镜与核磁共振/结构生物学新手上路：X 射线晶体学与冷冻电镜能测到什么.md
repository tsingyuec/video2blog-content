## 本讲要解决的核心问题（SCQA）

**背景**：结构决定功能。到今天为止，PDB 上已经登录了 15 万个实验结构，绝大多数来自 X 射线晶体学，冷冻电镜贡献的曲线正在指数上升。

**冲突**：同一份"蛋白质结构"可能来自晶体、来自冷冻电镜，也可能来自溶液中的核磁共振。它们看到的并不是同一件事：一个是晶体里的静态平均，一个是玻璃态冰里成千上万个颗粒的平均，还有一个是溶液里由距离约束推出来的模型集合。

**疑问**：这些方法各自测到什么？适合什么对象？读结构文件时，哪些地方本来就不该太当真？

**回答（中心思想）**：三种实验方法的分工，本质上由三条物理限制决定——**波长决定分辨率上限，信号强度决定要不要结晶，样品状态决定能不能看到动态**。X 射线晶体学用"结晶放大信号"换来最高分辨率，代价是必须结晶、而且只看到晶体里的静态平均构象；冷冻电镜用电子束加图像平均绕开结晶，擅长膜蛋白与大复合物，但受辐照损伤和小分子量限制；核磁共振在溶液里测距离约束，只适合较小的蛋白，却能看到动态。理解了这三条限制，方法选择就不再是"哪个更先进"，而是"哪个能回答我的问题"。

## 一、分辨率极限：为什么必须换成 X 射线或电子

### 1.1 分辨率就是"能分清多近的两个点"

讲方法之前，讲者先补了一个物理概念：分辨率极限。想象你站在风平浪静的湖面上，远处有两块石头，一阵清风吹来，湖面出现平行的水波；波打在石头上，被石头变成一圈圈圆形波，两圈波互相干涉，形成明暗相间的条纹。你站在远处，即使看不见石头，也能从条纹间距推算出两块石头相隔多远。

如果两块石头离得太近，波打过去根本分辨不出来——对这道波来说，两块石头和一块石头没有区别。想看得更细，只能用更细的"尺子"，也就是更短的波长：

$$
\Delta d = \frac{\lambda}{2n \sin\theta}
$$

![分辨率极限：波长越短，能分辨的间距越小；幻灯片把它概括成"杀鸡不能用牛刀"](assets/结构生物学新手上路：X%20射线晶体学与冷冻电镜能测到什么/00642.webp)

[【跳转到 10:42】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=642)

### 1.2 可见光的极限是 200 纳米，而蛋白质只有几纳米

人眼可见光的波长在 380 到 740 纳米之间，光学显微镜的分辨率极限约 200 纳米；2014 年拿诺贝尔奖的超分辨率荧光显微镜把这个极限又推进了一步，但仍然远远不够。

蛋白质的大小大概是 6 到 10 纳米；要看清它的"鼻子、眼睛、嘴巴"，也就是碳碳单键，尺度是 0.154 纳米。所以结构生物学用到的 X 射线波长是 0.1 纳米量级——只有这样才满足物理需求。这种 X 射线普通实验室产生不出来，做实验要跑到国家同步辐射中心，比如上海光源、日本的 Spring-8。

## 二、X 射线晶体学：用结晶把信号放大十几个数量级

### 2.1 结晶不是"为了好看"，而是为了信号强度

有了光源、有了蛋白质，还有两个技术问题。第一个是衍射光太弱：单个蛋白质分子对 X 射线的散射极其微弱，相当于湖面上只有鸡蛋大的一块石头，激起的波纹根本传不远。

解决办法就是结晶：让同样的分子以同样的构象整齐排列、汇聚在一起。一块 0.05 到 1 毫米的晶体里含有 $10^{17}$ 到 $10^{20}$ 个蛋白质分子，只要一个分子在某个方向上有衍射，所有分子在同一方向、同一时刻也都有衍射，信号强度就按同样的倍数叠加起来。

![结晶的作用：单分子衍射太弱，$10^{17}$ 到 $10^{20}$ 个分子同向叠加后信号才够检测](assets/结构生物学新手上路：X%20射线晶体学与冷冻电镜能测到什么/00851.webp)

[【跳转到 13:46】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=826)

### 2.2 从衍射点到电子密度，再到原子模型

第二个问题是 X 射线无法聚焦——没有材料能像凸透镜那样把 X 射线聚起来成像。傅立叶在两百年前就给了答案：光的叠加可以用傅立叶变换与逆变换描述。所以不需要透镜，直接把探测器放在"本该放透镜"的位置记录衍射点，再用计算机做逆变换，就还原出电子密度图。

流程是：晶体衍射 → 探测器记录衍射点 → 傅立叶逆变换得到电子密度 → 在密度里"填牙签"，放进氨基酸的原子坐标 → 得到模型。同一套原子坐标可以画成 space-filling、ribbon、surface 等不同表示，看起来"长得不一样"，其实只是显示方式不同。

![X 射线结晶法流程：衍射图经傅立叶逆变换得到电子密度，再手工填入分子模型；右侧是同一坐标的三种显示方式](assets/结构生物学新手上路：X%20射线晶体学与冷冻电镜能测到什么/00949.webp)

[【跳转到 15:49】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=949)

这段历史走了近一百年：1895 年伦琴发现 X 射线，1926 年后开始解小分子结构，1959 年血红蛋白成为人类第一个解出晶体结构的蛋白质，三年后获诺贝尔化学奖。此后四五十年，结构生物学基本就是 X 射线晶体学的时代。幻灯片上那张时间线也顺带标出了另外两条路线：1962 年 Klug 用电子显微镜解烟草花叶病毒，1975 年 Henderson 用电子晶体学解视紫红质，1985 年 Wüthrich 用核磁共振解蛋白酶抑制剂——三种方法各自拿到过诺贝尔奖。

### 2.3 它到底测到了什么

严格说，晶体学测到的不是"这个蛋白质在细胞里的样子"，而是**这个蛋白质在晶体里、被晶格接触固定住之后，所有分子共同的平均构象**。这句话决定了它的强项与短板：强在原子级精度、弱在"平均"和"静态"。

## 三、晶体学的三个先天缺陷

讲者把晶体学的局限概括成三条，并配了一张很有画面感的图：标本盒里钉住的蝴蝶，和花上正在飞的蝴蝶。

![X 射线结晶法的"先天缺陷"：结晶需要大量蛋白与大规模试错，且只能看到"结晶"状态——像标本盒里的蝴蝶，而不是花上飞着的蝴蝶](assets/结构生物学新手上路：X%20射线晶体学与冷冻电镜能测到什么/01198.webp)

[【跳转到 19:58】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=1198)

1. **结晶是瓶颈**：没有一套体系能"给我一级结构就预测出结晶条件"，只能大量试错。实验室里 80% 到 90% 的时间花在结晶上；分子量越大越难结晶。
2. **膜蛋白极难结晶**：膜蛋白的穿膜区需要去垢剂或脂类环境，晶格接触很难建立，所以膜蛋白的晶体结构一直非常少。
3. **只能看"结晶态"**：晶体里的蛋白质前后左右、上下都与其他分子接触。我们期待的动态蛋白质，得到的却是静态结构，看不到时间轴上的变化。

正因为第三条，科学家长期在找"能在溶液条件下、还保持高分辨率"的办法——这就引出了电子显微镜。

## 四、冷冻电镜：不结晶也能到原子分辨率

### 4.1 电子束的波长比 X 射线还短，而且能"折射"

电子显微镜用的不是电磁波，而是电子束，波长 4 到 17 皮米，比 X 射线还小两个数量级；更关键的是电子束可以被电磁场偏转，只要在"本该放透镜"的位置放一块电磁铁，就能像光学显微镜那样直接成像——理论上非常完美。

[【跳转到 21:43】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=1303)

### 4.2 现实的两个瓶颈：辐照损伤与检测器

理论丰满、现实骨感。电子束能量太强，打多了样品就坏；打少了信号又太弱，而早期检测器（CCD）性能不够。这是一个死结：想看清就要强电子束，强电子束就把样品打坏。所以直到 2010 年左右，电镜还只能看清蛋白质的轮廓。

### 4.3 2013-2014 年的"分辨率革命"

转机来自三项技术同时成熟：

- **直接电子探测器**（如 Gatan K2）：讲者的比喻是"以前隔着一层纱窗看对面，现在把纱窗换成透明玻璃"；
- **300 kV 冷冻电镜平台**（如 Titan Krios）：把样品装载、上机、数据采集做成高度程序化的流程，让"半路出家"的人也能上手；
- **图像处理软件**（以 RELION 为代表）：把贝叶斯方法引入冷冻电镜三维重构。

### 4.4 两种用法：单粒子与断层扫描

- **单粒子（single particle, SPA）**：把纯化好的蛋白铺在载网上，拍几百到几千张照片，得到几万到几十万个分子，假设它们以随机取向朝向相机，再用计算把这些二维投影还原到三维。它相当于"高配版的 X 射线"，分辨率高，但需要纯化样品、且把所有颗粒平均起来。
- **断层扫描（cryo-ET）**：直接把细胞切薄，放在电子束下一边转一边拍，看分子在细胞里真实的样子、怎么排列、空间分布如何。它相当于"高配版的光学显微镜"，能看原位状态，但每个分子、每个样品都是独一无二的，没法大量平均，分辨率相对较低。

## 五、两种方法怎么分工

讲者在问答里反复被问到"X 射线会不会被冷冻电镜取代"，他的回答是：不会，因为两者的能力边界不同。

| 比较项 | X 射线晶体学 | 冷冻电镜 |
| --- | --- | --- |
| 测到的信号 | 晶体衍射 → 电子密度 | 颗粒投影像 → 三维密度 |
| 常规分辨率 | 3 埃以内很常见 | 平均 3 到 4 埃，记录已到 0.9 埃量级 |
| 对象大小 | 小蛋白、酶与底物复合物最擅长 | 大分子、复合物、膜蛋白更有优势，通常需要百 kDa 以上 |
| 结晶要求 | 必须，且是主要瓶颈 | 不需要，冷冻固定即可 |
| 膜蛋白 | 很难结晶，结构很少 | 去垢剂或 nanodisc 稳定后可做，是膜蛋白结构的主要来源 |
| 动态信息 | 基本没有，得到的是静态平均 | 可通过分类看到不同构象，断层扫描可看原位排布 |
| 时间成本 | 单套数据 3 到 5 分钟，通量高、流程成熟 | 单次数据几天到几周，后期处理需要经验与人工干预 |
| 主要不确定性 | 晶格接触与非自然条件、柔性区缺失、辐射损伤 | 取向优势、辐照损伤、小分子量蛋白分辨率不足 |

[【跳转到 38:00】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=2280)

讲者的具体建议很实用：做酶与底物的结构，优先 X 射线；看大尺度上几个大分子怎么结合、膜蛋白通道处于什么状态，优先冷冻电镜。膜蛋白之所以在 2010 年后结构数量猛增，正是冷冻电镜加上去垢剂、nanodisc 这类样品手段的结果。

## 六、读结构时要盯住的不确定性

公开课最有价值的部分，是问答里那些"怎么判断这个结构可不可信"的细节。

**第一，R-work 与 R-free。** 有位听众的数据是 2.5 埃、R-work 0.18、R-free 0.29，两者差 0.1。讲者说这是明显的过拟合：经验上 R-free 与分辨率数值大致同量级（2.5 埃对应 R-free 约 0.25），差值过大说明模型在跟着噪声走。补救办法是把没把握的模型位置删掉、看不清的水分子全部删掉，加二级结构、Ramachandran 等理论限制，而不是加 annealing 这类"花哨功能"。

[【跳转到 46:21】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=2781)

**第二，缺失残基不是"没解析出来"那么简单。** 晶体里有十个分子，某段 loop 在每个分子里位置都不同，平均化之后就消失了。所以结构文件里的一段缺失，往往正说明那段本来就很柔。也正因如此，为了拿到晶体而把不稳定片段切掉，是结晶学的共性做法，也是它的一个限制——切到只剩一点点，也就解释不了什么了。

[【跳转到 35:04】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=2104)

**第三，冷冻电镜的取向优势。** 有研究把普通载网拿到同步辐射上统计，发现 80% 到 90% 的颗粒贴在气液界面上，取向高度偏好。缓解办法包括加少量去垢剂、用 graphene grid 或在载网上加碳膜，以及把载网倾斜一个角度采数据——但倾斜会牺牲分辨率，没有完美解。

[【跳转到 36:26】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=2186)

**第四，结构要过验证。** 提交 PDB 前有 structure validation：看 clash、rotamer 异常、各种统计指标。若 R-free 与分辨率明显不匹配，PDB 不会拒绝，但会给一个"红得厉害"的评分，同行一看就知道这个结构不可靠。

[【跳转到 34:06】](https://www.bilibili.com/video/BV1f64y1v7Fq/?t=2046)

**第五，分辨率不等于准确度。** 冷冻电镜报的是平均分辨率，局部可能好很多也可能差很多；晶体学报的是整体衍射极限，柔性区同样不可信。两种方法都需要回到密度图去看局部。

## 七、预测不能替代实验

问答里有人问 AlphaFold 会不会取代实验。讲者的判断是：不会，至少现在不会，因为预测有两个硬短板——**做不了大分子量蛋白，也预测不了蛋白质之间的相互作用**。它的做法是从 15 万个 PDB 结构里学一个最可能的答案，过程是机器学习，而不是基于量子物理或量子化学的计算。他的比喻是：这是一个刚会站起来走路的小孩，不能断言它将来一定跑得比博尔特快。

同源建模的思路则更老也更实用：序列一致性高于 30%，就假设 fold 相同，用已知结构当模板；SWISS-MODEL 这类工具一小时就能给出一个人的模型，只要后续用突变实验验证，就足够支撑论文结论。

## 小结

- **分辨率由波长决定**：可见光极限 200 纳米，看蛋白质的碳碳单键需要 0.1 纳米量级的 X 射线；电子束波长更短，且能被磁透镜聚焦。
- **X 射线晶体学靠结晶放大信号**：$10^{17}$ 到 $10^{20}$ 个分子同向衍射，才够被探测器记录；代价是必须结晶、只看到晶体中的静态平均。
- **晶体学的三个先天缺陷**：结晶耗时且靠试错、膜蛋白难结晶、看不到溶液中的动态。
- **冷冻电镜绕开结晶**：单粒子靠"随机取向 + 大量平均"换分辨率，断层扫描靠"原位 + 不平均"换环境信息，两者分辨率与信息类型互补。
- **分工取决于问题**：小蛋白、酶与底物用 X 射线；大复合物、膜蛋白、构象异质性用冷冻电镜；核磁共振则负责溶液中的小蛋白与动态（见同节另一篇）。
- **读结构要看不确定性**：R-work 与 R-free 的差距、缺失残基、取向优势、局部分辨率、PDB 验证评分，都比"分辨率数字"更能说明这个模型能信到什么程度。
- **预测不是证据**：AlphaFold 与同源建模给的是假设，大分子与相互作用仍是短板，实验结构仍是第一选择。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 分辨率极限 | 波动成像能分清的最小间距，约为波长的一半量级，波长越短看得越细 |
| 同步辐射光源 | 产生高强度、波长可调的 X 射线的大型设施，如上海光源、Spring-8 |
| 电子密度图 | 由衍射数据经傅立叶逆变换得到的密度分布，模型要"填"进这个密度里 |
| R-work / R-free | 模型与实验数据的偏差指标；R-free 用未参与精修的反射计算，二者差距过大意味着过拟合 |
| 单粒子解析（SPA） | 把大量随机取向的颗粒二维投影平均、重构出三维密度 |
| 断层扫描（cryo-ET） | 在电镜下一边倾斜样品一边成像，重构细胞原位切片的三维密度 |
| 取向优势（prefer orientation） | 颗粒在载网上偏向某一朝向，导致某些视角缺失、密度图各向异性 |
| 辐照损伤 | 电子束打坏样品，导致高分辨率信号随剂量衰减 |
| 同源建模 | 用序列相似性高于 30% 的已知结构当模板，构建未知蛋白的三维模型 |
