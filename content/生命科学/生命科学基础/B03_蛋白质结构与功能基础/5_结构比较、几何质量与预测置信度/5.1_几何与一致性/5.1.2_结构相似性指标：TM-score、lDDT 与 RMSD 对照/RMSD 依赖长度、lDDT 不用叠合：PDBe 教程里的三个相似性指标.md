>
> 这是 EMBL-EBI / PDBe 的官方培训课件，讲法偏"定义 + 图示"，正好补上实践类教程里常被跳过的那一层：每个指标为什么长成这样。本文取它的前半段（相似性指标：RMSD、TM-score、lDDT、Aligned Error），后半段关于 pLDDT / PAE / pTM / ipTM 的置信度解读只在末尾做区分，详细展开见 5.2 节。叠合算法（Kabsch）的推导见 5.1.1。

## 本讲要解决的核心问题（SCQA）

**背景**：蛋白结构是有规则的、明确定义的三维形状，因此"比较两个结构像不像"在原则上是可做的。这件事有两个典型用途：把已知结构按形状归类、划分结构家族；以及把预测模型和实验结构比对，判断算法是否可靠。[【跳转到 01:06】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=66)

**冲突**：最自然的做法是"对齐之后量差距"，也就是 RMSD。但 RMSD 有一个众所周知的毛病：**它受蛋白长度影响**——比较两个短蛋白时算的距离项本来就少，比较两个长蛋白时项数多，而结构之间总归有些差异，于是**长蛋白的 RMSD 天然偏大**。[【跳转到 05:14】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=314) 就算换成 TM-score 把长度因素修掉，又会撞上另一个问题：**多域蛋白的两个域相对转动时，任何"全局叠合"都只能对齐其中一个域**。[【跳转到 07:22】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=442)

**疑问**：这三个指标（RMSD、TM-score、lDDT）各自是怎么定义、各自修掉了什么问题、又各自留下了什么盲区？

**回答（中心思想）**：三个指标的差别可以归结为**两个设计选择**——"要不要先做空间叠合"和"要不要按长度归一化"。RMSD 要叠合、不归一化，所以简单直观但怕长度、怕域间转动；TM-score 要叠合、但用与长度相关的 $d_0$ 归一化，所以与长度无关、对整体折叠敏感；lDDT **不叠合**、只比较同一结构内部的邻居距离，所以天生免疫域间取向、可以逐残基给出局部质量，代价是**主动丢掉了域间取向信息**。要把这块信息找回来，就得再加一个按残基对计算的 **Aligned Error**。

## 一、为什么需要一个"相似性分数"

讲者把动机归成两类。[【跳转到 01:01】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=61)

**第一类是结构分类。** 因为有办法量化"结构相似性"，人们才可能把已知结构系统地归类，识别出不同的**结构家族**，进而了解蛋白结构世界的多样性。[【跳转到 01:31】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=91)

**第二类是评估预测。** 假设我们有一个算法（比如 AlphaFold）产出结构预测，我们想知道这些预测离实验观测有多近——这需要一个度量。[【跳转到 01:56】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=116)

一句话总结：相似性分数的作用，是给"比较结构"这件事提供一个**定量、一致**的口径，既能用来找结构相似的蛋白，也能用来评估预测模型。[【跳转到 02:21】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=141)

## 二、RMSD：先对齐，再量残基位置差

### 2.1 "对齐"到底指什么

讲者先把这个词拆开。如果比较的两个蛋白**长度相同**，残基之间天然存在一一对应关系；所谓"在空间中做对齐"，就是把两个蛋白摆到某个相对位置上，**使两个结构的一致性达到最优**——实现这一点的算法有很多。[【跳转到 03:34】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=214)

如果两个蛋白**长度不同**，就必须先决定"这个蛋白的哪个残基对应那个蛋白的哪个残基"，通常也是以"让对齐最优"为准则来做这个决定。[【跳转到 03:59】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=239)

### 2.2 定义与读数

对齐之后就可以算了：设 $d_i$ 为残基 $i$ 在结构 1 与结构 2 中位置之间的距离，RMSD 就是这些距离平方的平均值再开方。[【跳转到 04:24】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=264)

$$
\mathrm{RMSD} = \sqrt{\frac{1}{N}\sum_{i=1}^{N} d_i^{2}}
$$

读法：**越相似，RMSD 越小**；越不像，RMSD 越大。惯例上 **2 Å 以内**表示两个结构高度相似。[【跳转到 04:49】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=289)

![RMSD 幻灯片：公式、逐对残基距离 $d_i$ 的示意，以及"好的取值约 2 Å 以内"](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00339.webp)

同一页幻灯片上还写着一句关键提醒：**Problem: Affected by length of protein!**——这正是下一个指标要解决的问题。

### 2.3 长度依赖从哪来

讲者的解释很朴素：比较两个短蛋白时，参与计算的距离项少；比较两个长蛋白时，项数多。而结构之间**总归存在一些差异**，项数一多，累积起来的 RMSD 就偏大。因此"长蛋白的 RMSD 偏高"并不一定意味着预测更差。[【跳转到 05:14】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=314)

## 三、TM-score：用 $d_0$ 把长度因素除掉

绕开长度问题的经典方案是 **TM-score（Template Modeling Score，模板建模分数）**，它是结构生物信息学里用得极广的一个相似性分数。[【跳转到 05:39】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=339)

$$
\mathrm{TM\text{-}score} = \max\left[\frac{1}{L_N}\sum_{i}^{L_T} \frac{1}{1+\left(\dfrac{d_i}{d_0}\right)^{2}}\right]
$$

$$
d_0 = 1.24\sqrt[3]{L_N - 15} - 1.8
$$

这两个式子值得逐项看：

- **分母 $L_N$** 是目标蛋白的长度，把求和变成"平均每个残基贡献多少"；
- **$d_0$ 由长度 $L_N$ 决定**，所以 $d_i/d_0$ 是一个"相对于该长度而言算不算大"的无量纲量——这就是**长度归一化**的来源，它让 TM-score 与蛋白长度无关；
- **$\dfrac{1}{1+(d_i/d_0)^2}$** 这一项在 $d_i$ 很小时接近 1，$d_i$ 变大后迅速衰减到 0。也就是说**小偏差几乎满分、大偏差几乎不给分**，中间是平滑过渡——这正是它对离群点不敏感的原因。

![TM-score 幻灯片：完整公式、$d_0$ 的长度公式，以及 0–1 取值、取多次比对最大值、只计对齐残基、与蛋白大小无关四条性质](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00389.webp)

幻灯片上列出的四条性质，正好是这个指标的使用说明书：[【跳转到 06:04】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=364)

- **取值 0 到 1**：1 表示完全相似，0 表示毫无相似性；
- **取多次结构比对中的最大值**：TM-score 允许多个比对作为输入，最后取 TM-score 最高的那个；
- **只统计被对齐上的残基**：没对齐的部分不进分母；
- **与蛋白大小无关**。

### 3.1 TM-score 也怕域间转动

讲者接着给了一个反例，说明 TM-score 并非万能。设想两个蛋白，各自都由两个结构域组成，**结构上几乎完全相同**，唯一的差别是**两个域之间的相对取向不同**——你可以把连接两个域的那段 linker 里的某个残基想成一个**铰链**。[【跳转到 06:50】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=410)

这时无论算 RMSD 还是 TM-score，都必须先对齐；而**任何一次对齐最多只能让一个域对上**，另一个域必然有位移。于是这两个分数**永远会被域间取向污染**，而对齐这种结构"从来都不是一件简单的事"。[【跳转到 07:22】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=442)

![Domain Orientation：一个域被叠好，另一个域绕着铰链转开——全局叠合类指标无法同时照顾两边](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00442.webp)

要绕开这个问题，就需要一个**局部指标**：它对域间取向不敏感。[【跳转到 07:47】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=467)

## 四、lDDT：不做空间叠合的局部指标

**lDDT（Local Distance Difference Test，局部距离差异检验）** 就是为这个场景设计的。它衡量**局部**相似性、对域间取向无所谓；更关键的是它 **alignment-independent（与对齐无关）**——你根本不需要先求出结构比对就能算它。[【跳转到 08:02】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=482)

### 4.1 怎么算

讲者把步骤拆成四步：[【跳转到 08:27】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=507)

1. 和别的指标一样，先拿到残基之间的一一对应关系——**但不需要把它们在空间里对齐**；
2. 选一个**截断距离（cutoff）$R_0$**。对每个残基，找出它在两个结构中**都落在截断距离内**的那些邻居残基；
3. 在两个结构里分别量出"这个残基到这些邻居"的距离，再看**这些距离中有多大比例保持不变**（用若干不同的容差阈值来判定"没变"）；
4. 这个比例就是该残基的 lDDT 分数。

![lDDT 的几何图像：以某个残基为圆心、$R_0$ 为半径圈出邻居，再逐条比较"圆心到邻居"的距离在两个结构里是否一致](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00507.webp)

![lDDT 的计算要点：在截断半径 $R_0$ 内找对应距离、算保持不变的百分比、取值 0–100、可逐残基也可全蛋白平均](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00557.webp)

注意第 2 步里"在两个结构中**都**落在截断距离内"这个限定：它保证了参与比较的距离对是"本来就该比较"的那些，避免拿一个结构里存在、另一个结构里根本不存在的邻近关系来充数。

### 4.2 读数与阈值

- 取值 **0 到 100**；
- **80 及以上**表示高度相似，**50 以下**表示相似性差；[【跳转到 09:17】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=557)
- 可以算**单残基**的分数，也可以对**整个蛋白**取平均。[【跳转到 08:52】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=532)

逐残基这个能力很实用：因为 lDDT 能落到残基粒度，你可以直接在两个结构上**看出哪些区域最相似**——相当于自带一张"局部质量地图"。

### 4.3 代价：域间取向被主动丢掉

讲者把这一点说得很直接：lDDT 是局部分数，**域间取向的信息因此丢失了，而且这是设计使然（by design）**。[【跳转到 09:17】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=557)

如果你确实关心域间取向，就需要一个**补充指标**。视频里给出的方案是 **Aligned Error（对齐误差，AE）**。

## 五、Aligned Error：把域间取向找回来

Aligned Error 是**按残基对**计算的。步骤是：[【跳转到 10:07】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=607)

1. 在一个蛋白里挑两个残基，记为 $i$ 和 $j$；在第二个蛋白里找到对应的 $i$ 和 $j$；
2. **用残基 $i$ 来对齐两个结构**——也就是调整两个结构的相对位置，使两个蛋白里"残基 $i$ 的所有原子"重叠得最好；
3. 对齐之后，量出**残基 $j$ 的 Cα 在蛋白 1 与蛋白 2 之间的距离**，这个距离就是残基对 $(i,j)$ 的 aligned error。[【跳转到 10:32】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=632)

![Aligned Error 的做法：绕残基 $i$ 对齐，再量残基 $j$ 的 Cα 距离](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00682.webp)

读法也很直观：

- 两个蛋白里**两个域的相对关系差不多** → 距离小 → aligned error 小；
- **域间取向差得远** → 距离大 → aligned error 大。[【跳转到 10:57】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=657)

### 5.1 它是矩阵，而且不对称

因为要对**每一对** $(i,j)$ 都算一次，结果自然是一个**矩阵**。视频给了一张多域蛋白的 aligned error 热力图：颜色深的地方误差小，浅的地方误差大。图中深色块正好对应"两个蛋白里结构相似的那些域"，而**域间区域明显更亮**，说明域间取向差异显著。[【跳转到 11:22】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=682)

![Aligned Error 矩阵热力图：对角附近的深色块是"域内一致"，块与块之间的亮带是"域间取向不一致"](assets/RMSD%20依赖长度、lDDT%20不用叠合：PDBe%20教程里的三个相似性指标/00705.webp)

还有一处容易被忽略的细节：**$(i,j)$ 的 aligned error 不等于 $(j,i)$ 的 aligned error**。原因很简单——如果改成绕残基 $j$ 对齐，量出来的距离当然不一样。所以这个矩阵**看起来对称，其实并不对称**。[【跳转到 12:15】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=735)

## 六、相似性分数与"预测分数"不是一回事

到这里，相似性指标讲完了。讲者顺势做了一次概念切分，这一步很重要：

- **相似性分数（similarity score）** 衡量的是**两个结构之间**的相似程度；
- **预测分数（prediction score）** 衡量的是**我们对某个预测的置信度**。[【跳转到 12:57】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=777)

很多预测分数是**建立在相似性分数之上**的，名字里就能看出来：**pLDDT**（predicted lDDT）、**PAE**（predicted aligned error）、**pTM**（predicted TM-score）。[【跳转到 13:02】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=782)

它们的关系可以这样记：**pLDDT 之于 lDDT、PAE 之于 Aligned Error、pTM 之于 TM-score**——同一个"问题"，一个用在"两个结构的比对"上，一个用在"模型自己估计自己"上。至于这些置信度分数怎么读、有哪些坑（比如高 pLDDT 也可能对应低 lDDT），属于 5.2 节的内容，这里只做区分。

## 七、三个指标怎么选

把全片压成一张表：

| 指标 | 要不要先叠合 | 长度归一化 | 敏感于 | 盲区 |
| --- | --- | --- | --- | --- |
| **RMSD** | 要 | 无 | 全局位置偏离；局部细节 | 长度依赖；离群点被放大；域间转动 |
| **TM-score** | 要（取多次比对最优） | 有（$d_0$ 随 $L_N$ 变） | 整体折叠；域错位 | 域间取向仍会影响分数；需先对齐 |
| **lDDT** | **不要** | 不需要（局部比例） | 局部邻居环境；可逐残基 | 域间取向（设计使然） |
| **Aligned Error** | 逐残基对局部对齐 | 不需要 | 域间取向；按残基对给出 | 是矩阵不是单值；不对称 |

讲者的收尾判断是：**所有分数都有各自合适的用途，也都有各自的局限；选哪个、怎么用，取决于你想问什么。** [【跳转到 21:28】](https://www.youtube.com/watch?v=dVFHr0ZV4-0&t=1288)

> 一句话记住这一节：**RMSD 差在"长度"，TM-score 用 $d_0$ 补上了长度；RMSD 与 TM-score 都差在"域间转动"，lDDT 用"不叠合"补上了这一块，代价是主动丢掉了域间取向——于是又需要 Aligned Error 把它单独找回来。**

## 小结

- **相似性分数存在的意义**：给"两个结构像不像"一个定量、一致的口径，用于结构分类和预测评估。
- **RMSD 的公式与惯例**：对齐后逐对残基量距离，平方平均再开方；2 Å 以内算高度相似。
- **RMSD 的核心缺陷是长度依赖**：长蛋白参与计算的距离项多，累积误差大，RMSD 天然偏高。
- **TM-score 的两处设计**：$d_0$ 随长度变化实现长度归一化；$\frac{1}{1+(d_i/d_0)^2}$ 让大偏差迅速饱和。取值 0–1，取多次比对最大值，只计对齐残基。
- **全局叠合的共同软肋是域间取向**：两个域相对转动时，任何一次对齐只能对齐一个域。
- **lDDT 用"不比较位置"绕开它**：在截断距离内找对应邻居，统计距离保持不变的比例，取值 0–100，80 以上算好、50 以下算差；可逐残基，因此能定位"哪里最像"。
- **lDDT 的盲区是设计使然**：域间取向信息被主动丢弃。
- **Aligned Error 按残基对补回取向信息**：绕 $i$ 对齐、量 $j$ 的距离，得到一张不对称的矩阵。
- **相似性分数 ≠ 预测分数**：pLDDT / PAE / pTM 是"模型对自己置信度的估计"，分别对应 lDDT / Aligned Error / TM-score。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 空间对齐（alignment in space） | 把两个结构摆到使一致性最优的相对位置 |
| RMSD | 对齐后逐对残基距离的均方根，单位 Å，2 Å 以内算高度相似 |
| 长度依赖 | 长蛋白参与计算的距离项多，导致 RMSD 系统性偏大 |
| TM-score | 用 $d_0$ 归一化、对大偏差饱和的相似性分数，取值 0–1，与长度无关 |
| $d_0$ | 由目标蛋白长度 $L_N$ 决定的尺度参数，$1.24\sqrt[3]{L_N-15}-1.8$ |
| lDDT | 局部距离差异检验，统计截断半径内邻居距离保持不变的比例，0–100 |
| 截断距离 $R_0$ | lDDT 中判定"哪些残基算邻居"的距离上限 |
| Aligned Error | 绕残基 $i$ 对齐后残基 $j$ 的 Cα 位移，按残基对给出，构成不对称矩阵 |
| pLDDT / PAE / pTM | 分别对应 lDDT / Aligned Error / TM-score 的"预测版"置信度分数 |
