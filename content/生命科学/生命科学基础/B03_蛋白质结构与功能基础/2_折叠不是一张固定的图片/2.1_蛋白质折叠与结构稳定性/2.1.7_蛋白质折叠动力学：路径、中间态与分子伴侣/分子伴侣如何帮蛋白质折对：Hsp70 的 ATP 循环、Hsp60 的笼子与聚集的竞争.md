# 分子伴侣如何帮蛋白质折对：Hsp70 的 ATP 循环、Hsp60 的笼子与聚集的竞争

> 视频来源：[2.2.4 HSP70等分子伴侣帮助蛋白质折叠](https://www.bilibili.com/video/BV1zF4m1K7Xz/)（Bilibili · UP 主「Truthen教授生命世界」，据 HarvardX《Principles of Biochemistry》整理，时长约 14 分钟）
> 简要导读：上一支视频讲的是「稀溶液里一条链怎么折」。这一支换了个前提：细胞质其实挤得像早高峰，新生的链随时可能和邻居黏成聚集体。本文按「拥挤 → 聚集风险 → 分子伴侣 → Hsp70 的 ATP 循环 → Hsp60 的笼子」这条线复述，并在结尾解释为什么「天然态最稳定」并不等于「蛋白质一定折得成」。

## 本讲要解决的核心问题（SCQA）

**背景**：我们学过的折叠知识，几乎都建立在一个假设上——蛋白质被均匀稀释在水溶液里折叠，就像实验试管里的缓冲液那样 [【跳转到 00:00】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=0)。在这个前提下，折叠漏斗模型很好用：链沿着能量景观往下滑，落到最低点就是天然构象。

**冲突**：细胞里不是这样。细胞质非常拥挤，塞满了蛋白质和 RNA 分子 [【跳转到 00:25】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=25)。核糖体上新生成的链一出来，身边就贴着一堆同类。更要命的是，**驱动正确折叠的力，同时也驱动聚集**——两者都靠疏水效应把疏水残基埋起来 [【跳转到 02:10】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=130)。

**疑问**：既然天然构象在热力学上最稳定，为什么蛋白质还会折错、还会聚集？细胞靠什么把这条链从聚集的岔路上拉回来？

**回答（中心思想）**：因为**热力学上最稳定**和**动力学上到得了**是两件事。聚集物在热力学上同样有利、而且往往形成得更快，所以单靠「天然态最稳定」并不能保证折对。细胞的对策是**分子伴侣**：它们不改变天然态是能量最低点这个事实，而是**短暂地遮住暴露的疏水表面、阻止分子间黏连**，给蛋白质反复尝试折叠的机会 [【跳转到 13:21】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=801)。Hsp70 用 ATP 水解驱动的构象循环实现「短暂结合」，Hsp60（细菌中的 GroEL）则提供一个与外界隔绝的笼子。

## 一、把前提换掉：从稀溶液到拥挤的细胞质

### 1.1 细胞质不是空旷的溶液

片中的第一张图就纠正了一个直觉：我们以为细胞质是宽阔空间、分子可以自由漂浮，实际上它非常拥挤，充满了蛋白质分子和 RNA 分子 [【跳转到 00:25】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=25)。

![细菌细胞质环境的模拟：各种蛋白质分子挤在一起，几乎没有空隙](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00025.webp)

这个变化看似只是「浓度高一点」，实际上改变了折叠问题的性质：在稀溶液里，一条链的对手只有自己；在细胞里，它的对手是周围所有同样暴露着疏水表面的分子。

### 1.2 折叠漏斗旁边，还有半个「聚集漏斗」

片中把原来那张「自由能—构象空间」的图**往右扩展**：左边是稀溶液里的天然折叠，右边加上细胞质里的情形，表示蛋白质形成聚集物的可能性 [【跳转到 02:10】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=130)。

![左：稀溶液中自由能只有一个通往天然态的深谷；右：细胞质里出现多个聚集相关的深谷，其中有些比天然态更深](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00130.webp)

关键在于这张图的读法：右边那些聚集态的谷**不比天然态浅**，有的甚至更深。这就是「热力学稳定性 ≠ 折叠效率」的第一层含义——天然态是最稳定的**单体**状态，但分子间聚集在热力学上同样有利。

### 1.3 聚集不只是「没功能」，而是更糟

片中强调，聚集物的危害甚至更大 [【跳转到 02:35】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=155)。它给出的例子是一张 **β 淀粉样蛋白（amyloid beta）聚集物**的电子显微镜照片，这类聚集物是阿尔茨海默病的病理特征之一 [【跳转到 02:56】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=176)。

![β 淀粉样蛋白聚集物的电镜照片：纤维状缠结结构，是阿尔茨海默病的病理特征之一](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00176.webp)

所以细胞防聚集，不只是为了提高折叠产量，也是为了避免毒性产物。

## 二、分子伴侣的定位：不改变热力学，只改变过程

### 2.1 先说清楚它不是什么

片中有一句很容易被忽略但很重要的话：**并不是每一种蛋白质都需要分子伴侣才能形成天然结构**。天然结构在热力学上是有利的，这是热力学假说（thermodynamic hypothesis）的内容 [【跳转到 03:26】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=206)。

也就是说，分子伴侣不是「帮链找到最低点」的机器——最低点本来就在那里。它的作用是**防止新合成的蛋白质与其他蛋白质发生聚集**，从而让链有机会自己走到最低点。

### 2.2 为什么大蛋白尤其需要帮助

片中给了一个很具体的动力学理由。假设某个蛋白的正确折叠要求序列上相距很远的两段相互作用——比如 N 端和 C 端。但翻译是从 N 端开始的：N 端先被翻译出来，在 C 端还没被合成之前，它就已经暴露在拥挤环境里，可能先形成聚集 [【跳转到 04:41】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=281)。

![上：没有 Hsp70 时，新生链在翻译完成前就聚集成团；下：Hsp70 存在时反复结合—释放，链最终正确折叠](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00281.webp)

这就是「折叠效率」问题：序列信息完全正确，热力学终点也明确，但**合成的时间差**制造了一个动力学窗口，窗口里链可能走错路。

## 三、Hsp70：靠 ATP 循环做到「短暂结合」

### 3.1 核心要求是「短暂」，不是「牢固」

Hsp70 优先与**疏水残基**相互作用，短暂地掩盖这些疏水残基，防止它们互相黏连 [【跳转到 05:15】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=315)。

片中特别点出了为什么必须「短暂」：如果 Hsp70 稳定地抱住底物不放，那它自己就变成了另一种形式的「聚集物」，而不是它应该防止的那种聚集物 [【跳转到 05:40】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=340)。这句话是理解分子伴侣的关键——**保护必须是可撤销的**，否则保护就等于囚禁。

### 3.2 ATP 水解—交换构成的循环

Hsp70 靠一个核苷酸循环来实现「结合—释放」的反复 [【跳转到 06:05】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=365)：

1. **ATP 水解为 ADP**：Hsp70 发生很大的构象变化，这个变化使它能够与底物结合；
2. **底物结合**：结合口袋关闭，把底物的疏水表面隔离起来；
3. **ADP 被新的 ATP 替换**：构象回到不利于底物结合的状态，底物被释放；
4. **释放后的链**获得机会自我折叠，把疏水残基埋进疏水核。

![Hsp70 的核苷酸循环：ATP 结合、无底物 → ATP 水解 → ADP 结合、底物结合 → 核苷酸交换 → 释放底物](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00315.webp)

### 3.3 结构上看到的两件事：ATP 酶结构域与「盖子」

这两种状态的结构都已经被解析出来 [【跳转到 07:10】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=430)。Hsp70 有两个主要部分：

- **ATP 酶结构域**（图中蓝色）：ATP 深埋在它的中心；
- **底物结合结构域**：带一个**盖子结构**（图中黄色）。

![ATP 结合、无底物状态的 Hsp70：蓝色为 ATP 酶结构域，黄色为盖子结构，红色为底物结合结构域](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00430.webp)

ATP 水解之后，黄色盖子与底物结合结构域的一部分（图中橙色）紧密接触，形成一个**底物结合口袋**，把底物的疏水表面隔离在里面 [【跳转到 07:47】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=467)。

![ADP 结合、底物结合状态：盖子闭合，与底物结合结构域围出一个口袋，把疏水表面关在里面](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00467.webp)

反过来，ADP 换成 ATP 会让盖子远离底物结合结构域、打开口袋，底物随之释放 [【跳转到 08:21】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=501)。把两种状态叠加起来看，构象差异非常明显 [【跳转到 08:59】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=539)。

![两种核苷酸状态的叠加对比：盖子结构的大幅移动，正是「短暂亲和力」得以实现的结构基础](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00544.webp)

一句话总结这段结构内容：**ATP 水解控制盖子的开合，盖子决定底物的亲和力，亲和力的周期变化决定底物被「握住多久」**。

### 3.4 名字的来历，以及一个反直觉的观察

Hsp70 就是 **heat shock protein 70**（热休克蛋白 70），是热休克蛋白的一大类，大多数热休克蛋白都是分子伴侣 [【跳转到 09:40】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=580)。名字来自它们的表达受高温刺激而增加：细胞短暂暴露于高温（热休克）会促进热休克基因的表达。

片中用一张 **Western 印迹**来展示这一点：热处理后 0、2、4、8 小时检测 Hsp70，第 2 和第 4 小时的表达量明显高于时间 0；作为对照的 actin 在整个时间段大致恒定 [【跳转到 10:05】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=605)。

![Western 印迹：热休克后 2、4 小时 Hsp70 条带加深，而对照 actin 基本不变](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00605.webp)

但片中紧接着指出一个更重要的观察：**即使在没有热激的时间点 0，Hsp70 的表达水平依然非常高** [【跳转到 10:30】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=630)。这说明 Hsp70 不是「应激专用」的应急蛋白，它在正常状态下帮助蛋白质折叠就已经是常规工作。

## 四、为什么热激要上调分子伴侣：一张 S 形曲线解释

高温会使蛋白质变性。片中用一张图把这件事量化：横轴是温度，纵轴是处于天然态的蛋白质比例。曲线在 20–40 °C 附近基本维持在 100%，40 °C 之后开始下降，到 65 °C 左右降到 0 [【跳转到 11:20】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=680)。

![天然态蛋白比例随温度变化：40 °C 之后急剧下降，65 °C 附近几乎全部解折叠](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00680.webp)

解折叠的后果不只是「失去结构」，而是**暴露出疏水残基**。这对细胞是危险的：当温度回到正常状态时，这些变性蛋白可能通过**分子间**的疏水作用形成不恰当的聚集物 [【跳转到 11:45】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=705)。

所以细胞上调分子伴侣表达的逻辑是：**趁疏水表面还暴露着，先把它们遮住**，防止聚集，让蛋白质有机会在分子内部重新折叠、恢复天然三维结构。

片中补充说，热激不是唯一的触发条件。其他应激也会观察到分子伴侣表达增加，例如分泌细胞非常活跃、生成大量分泌蛋白时，会引发「蛋白质折叠应激」——翻译过多分泌蛋白可能导致聚集物产生，而上调分子伴侣表达就是应对之一 [【跳转到 12:35】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=755)。

## 五、Hsp60 / GroEL：把整条链关进笼子里

Hsp70 不是唯一的分子伴侣。片中给出的量级是：**哺乳动物基因组含有约 200 个编码分子伴侣的基因** [【跳转到 12:56】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=776)。

其中一个很有意思的是 **Hsp60**，在细菌中称为 **GroEL**。它是一个非常大的多聚体**笼状结构**；片中展示的是它的横截面，可以看到笼子的内部空腔 [【跳转到 13:21】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=801)。

![GroEL/GroES 复合物的横截面：GroES 盖在一端，内部是一个可以容纳整条肽链的空腔](assets/分子伴侣如何帮蛋白质折对：Hsp70%20的%20ATP%20循环、Hsp60%20的笼子与聚集的竞争/00776.webp)

它的思路和 Hsp70 不同：Hsp70 是逐个遮住疏水片段，Hsp60 是**让整个蛋白质进入笼子**。这样蛋白质就在一个免于与其他蛋白质发生疏水相互作用的安全环境里折叠成天然结构 [【跳转到 13:21】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=801)。

## 六、收尾：热力学最稳定，不等于动力学上到得了

片尾把整节课的判断讲得很清楚 [【跳转到 13:46】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=826)：

- 热力学假说说「蛋白质热力学上最稳定的状态就是它的天然构象」，这对**大多数在稀溶液中折叠的蛋白质**是成立的；
- 但在细胞这个拥挤环境里，分子伴侣通过多种方式协助折叠：其中一个作用是**帮助蛋白质在折叠过程中克服热力学陷阱**；
- **更重要的是**，分子伴侣**阻止那些在热力学上有利的聚集物的形成**——这也是许多分子伴侣基因实际上是**必需基因**的原因 [【跳转到 14:11】](https://www.bilibili.com/video/BV1zF4m1K7Xz/?t=851)。

把这两条对照起来，就是本小节要区分的那件事：

| 问题 | 热力学回答 | 动力学回答 |
| --- | --- | --- |
| 终点在哪 | 天然构象是自由能最低点 | 但聚集态也可能是深谷 |
| 能不能到 | 只要自由能更低，理论上就该到 | 能不能在降解或聚集之前到达，取决于路径与速率 |
| 分子伴侣做什么 | 不改变天然态是最低点 | 遮住疏水表面、阻断聚集岔路、提供隔离空间 |

## 小结

- 细胞质**非常拥挤**，折叠漏斗模型在稀溶液成立，在细胞里必须额外考虑聚集这一侧。
- **驱动折叠的力同样驱动聚集**：疏水效应既把疏水残基埋进分子内部，也能把不同分子的疏水表面黏在一起。
- 聚集物在热力学上**同样有利**，有些甚至比天然态更深；β 淀粉样蛋白聚集物是阿尔茨海默病的病理特征之一。
- **天然态最稳定 ≠ 一定折得成**：大蛋白的 N 端在 C 端还没翻译完时就可能先聚集，这是纯粹的动力学窗口问题。
- **Hsp70** 优先结合疏水残基，靠 ATP 水解—ADP/ATP 交换驱动盖子开合，实现**短暂**结合；稳定结合反而会让它自己变成「另一种聚集物」。
- Hsp70 在**没有热激**时表达量也很高，说明它是常规折叠的参与者；热激时进一步上调，是为了应对变性蛋白暴露的疏水表面。
- **Hsp60 / GroEL** 用笼状空腔把整条链与外界隔开，提供免于疏水相互作用的折叠环境。
- 许多分子伴侣基因是**必需基因**，因为阻止「热力学上有利的聚集」本身就是生存必需。

| 术语 | 一句话解释 |

| 分子伴侣（molecular chaperone） | 帮助其他蛋白质折叠、防止其聚集的蛋白，不改变底物天然态的能量地位 |
| 热力学假说（thermodynamic hypothesis） | 蛋白质天然构象是其在给定环境下自由能最低的状态 |
| 聚集物（aggregate） | 多个蛋白质分子通过（主要是疏水）相互作用黏成的非天然组装体 |
| β 淀粉样蛋白（amyloid beta） | 易形成纤维状聚集物的肽，其聚集是阿尔茨海默病的病理特征之一 |
| Hsp70 | 热休克蛋白 70，靠 ATP 循环短暂结合并掩蔽底物的疏水残基 |
| ATP 酶结构域（ATPase domain） | Hsp70 中结合并水解 ATP 的部分，水解驱动构象变化 |
| 底物结合结构域（SBD） | Hsp70 中结合底物的部分，带一个可开合的「盖子」 |
| 盖子结构（lid domain） | 覆盖底物结合口袋的片段，闭合时把疏水表面隔离在口袋内 |
| 热休克反应（heat shock response） | 高温等应激下上调热休克蛋白（多为分子伴侣）表达的反应 |
| Western 印迹（Western blot） | 用抗体检测特定蛋白表达量的实验方法，条带深浅反映蛋白多少 |
| Hsp60 / GroEL | 笼状多聚体分子伴侣，把整条肽链关进空腔中隔离折叠 |
| GroES | 盖在 GroEL 笼口上的「盖子」蛋白，与 GroEL 组成笼状复合物 |
| 必需基因（essential gene） | 敲除后细胞无法存活的基因 |
