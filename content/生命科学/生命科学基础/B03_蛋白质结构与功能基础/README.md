## 1 从氨基酸到蛋白链

<a id="b03-1-1"></a>

### 1.1 序列与化学性质

- 1.1.1 水、离子与非共价相互作用 <a id="b03-1-1-1"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-1-1-1)
  - 学习目标：说明氢键、离子键、疏水作用与范德华力的来源和强度差异；判断水环境如何改变折叠与结合；把非共价作用作为后续结构判读的前提。
- 1.1.2 翻译：核糖体、mRNA 与多肽合成 <a id="b03-1-1-2"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-2-2-5)
  - 学习目标：说明核糖体读取 mRNA、起始/延伸/终止与阅读框维持；区分 tRNA 适配、肽键形成与移位；判断翻译错误对蛋白序列的影响。
- 1.1.3 蛋白质序列、折叠与功能位点 <a id="b03-1-1-3"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-3-1-1)
  - 学习目标：提供进入蛋白专题的地图；折叠机制、结构域和位点评价在 B03 展开。
- 1.1.4 氨基酸侧链、电荷与疏水性 <a id="b03-1-1-4"></a> [DONE]
  - 学习目标：按侧链化学性质分类氨基酸，说明电荷与疏水性如何影响折叠和界面，不背侧链结构式。
- 1.1.5 肽键、主链方向与二面角 <a id="b03-1-1-5"></a> [WAITING]
  - 学习目标：用肽键平面和 phi/psi 解释主链构象自由度，说明 Ramachandran 允许区的来源。

<a id="b03-1-2"></a>

### 1.2 蛋白质层级、结构域与功能组织

- 1.2.1 蛋白质结构层级：二级结构、三级折叠与四级装配 <a id="b03-1-2-1"></a> [DONE]
  - 学习目标：在同一蛋白上区分序列、局部构象、单链折叠和复合物，建立层级地图而非逐层推导。
- 1.2.2 蛋白质拓扑与折叠类型：二级结构排列和结构同源 <a id="b03-1-2-2"></a> [WAITING]
  - 学习目标：比较相似结构单元在不同拓扑中的组合，区分折叠相似、序列同源与结构域分类。
- 1.2.3 蛋白质结构域、序列基序与功能组织 <a id="b03-1-2-3"></a> [DONE]
  - 学习目标：在序列和结构上定位一个结构域与短基序。
- 1.2.4 天然无序区：构象柔性、功能基序与相互作用 <a id="b03-1-2-4"></a> [WAITING]
  - 学习目标：从结构缺失、序列性质和动态互作解释无序功能，不把所有低置信区都当作无序。
- 1.2.5 蛋白质翻译后修饰：位点、可逆调控与功能后果 <a id="b03-1-2-5"></a> [DONE]
  - 学习目标：以磷酸化等代表案例连接修饰位点、酶和功能改变，不穷举修饰化学。

## 2 折叠不是一张固定的图片

<a id="b03-2-1"></a>

### 2.1 蛋白质折叠与结构稳定性

- 2.1.1 二级结构、氢键与疏水核心 <a id="b03-2-1-1"></a> [WAITING]
  - 学习目标：区分 α 螺旋、β 折叠与无规卷曲的氢键模式，说明疏水核心对稳定性的作用。
- 2.1.2 随机变量与概率分布：离散概率、连续密度与归一化 <a id="b03-2-1-2"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-2-1)
  - 学习目标：用离散和连续例子区分概率质量、密度与区间概率，检查分布归一化。
- 2.1.3 分布统计量：期望、方差与协方差 <a id="b03-2-1-3"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-2-4)
  - 学习目标：用同一分布解释位置、离散程度与相关变化。
- 2.1.4 折叠自由能景观：熵、焓与构象盆地 <a id="b03-2-1-4"></a> [DONE]
  - 学习目标：从自由能和概率关系解释稳定态、亚稳态与构象变化，区分势能最低和自由能最低。
- 2.1.5 效应量、置信区间与估计不确定性 <a id="b03-2-1-5"></a> [REUSE](../../../深度学习/数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-3-1-1)
  - 学习目标：在一个组间比较中解释大小与不确定性。
- 2.1.6 蛋白质稳定性测量：热变性、化学变性与 Tm/ΔG <a id="b03-2-1-6"></a> [WAITING]
  - 学习目标：解释热变性和化学变性曲线如何给出 Tm 与稳定性，说明测量条件对数值的影响。
- 2.1.7 蛋白质折叠动力学：路径、中间态与分子伴侣 <a id="b03-2-1-7"></a> [WAITING]
  - 学习目标：解释折叠速率、动力学陷阱和辅助折叠，区分热力学稳定性与折叠效率。

<a id="b03-2-2"></a>

### 2.2 构象与环境

- 2.2.1 蛋白质构象系综：群体、互变与功能状态 <a id="b03-2-2-1"></a> [WAITING]
  - 学习目标：用多个构象及其群体解释动态结构，区分结构差异、平衡概率和转变速率。
- 2.2.2 变构与结合耦合：构象选择、诱导契合与远程调控 <a id="b03-2-2-2"></a> [WAITING]
  - 学习目标：比较配体结合前后构象群体和能量变化，辨认两种机制并存及远程功能耦合。
- 2.2.3 协同结合与别构模型：Hill 系数、MWC 与 KNF <a id="b03-2-2-3"></a> [WAITING]
  - 学习目标：用 Hill 系数判断协同性，对照 MWC 与 KNF 解释别构如何传播。
- 2.2.4 膜环境、溶液条件与蛋白稳定性 <a id="b03-2-2-4"></a> [WAITING]
  - 学习目标：说明膜环境如何改变疏水暴露、界面电荷与聚集倾向；比较去垢剂、脂质双分子层与溶液条件的差异；判断膜蛋白稳定性数据的外推边界；联系 2.2.5 的溶解性与聚集判读。
- 2.2.5 蛋白质折叠、错误折叠与聚集 <a id="b03-2-2-5"></a> [WAITING]
  - 学习目标：区分聚集风险、溶解性和折叠稳定性。

## 3 蛋白质功能与分子相互作用

<a id="b03-3-1"></a>

### 3.1 分子识别

- 3.1.1 酶的底物识别与催化作用 <a id="b03-3-1-1"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-3-2-1)
  - 学习目标：用底物结合和催化反应衔接结构与功能，不展开酶动力学推导。
- 3.1.2 受体、信号转导与第二信使 <a id="b03-3-1-2"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-3-4-1)
  - 学习目标：说明受体—配体结合如何触发构象变化与下游信号；区分第二信使的放大与终止；判断信号转导的读数与结合读数的差别。
- 3.1.3 结合位点、界面与相互作用网络 <a id="b03-3-1-3"></a> [DONE]
  - 学习目标：区分口袋、界面与变构位点，说明氢键、盐桥和疏水接触如何共同决定识别。
- 3.1.4 蛋白质—核酸识别：序列特异性读取与复合物 <a id="b03-3-1-4"></a> [WAITING]
  - 学习目标：说明碱基读取、磷酸骨架接触与形状识别，解释蛋白—核酸复合物的特异性来源。
- 3.1.5 结合亲和力与分子识别特异性 <a id="b03-3-1-5"></a> [DONE]
  - 学习目标：用结合平衡和交叉结合案例解释两者。
- 3.1.6 结合动力学：kon、koff 与平衡解离常数 Kd <a id="b03-3-1-6"></a> [WAITING]
  - 学习目标：读懂 kon、koff 与 Kd 的联系，不重复完整药理学。
- 3.1.7 结合亲和力与动力学的实验读数：SPR、BLI 与等温滴定量热 <a id="b03-3-1-7"></a> [WAITING]
  - 学习目标：比较 SPR、BLI 与 ITC 的测量原理和可及参数；读懂结合曲线、稳态与动力学拟合；区分平衡常数、速率常数与实验伪影；判断测量条件对亲和力数值的影响。

<a id="b03-3-2"></a>

### 3.2 酶催化、动力学与调节

- 3.2.1 酶催化：活化能、过渡态与催化残基 <a id="b03-3-2-1"></a> [WAITING]
  - 学习目标：用一条酶反应解释速率加速与催化位点，区分反应热力学和活化势垒。
- 3.2.2 酶动力学：米氏曲线、Km、kcat 与催化效率 <a id="b03-3-2-2"></a> [WAITING]
  - 学习目标：在明确假设下读懂底物—速率曲线，区分 Km、结合亲和力和周转效率。
- 3.2.3 酶抑制与调节：竞争、非竞争与变构控制 <a id="b03-3-2-3"></a> [WAITING]
  - 学习目标：比较不同抑制机制对动力学曲线的影响，区分实验拟合和机制确定，不展开全部药理学。
- 3.2.4 辅因子与酶活性：金属离子、辅酶与功能状态 <a id="b03-3-2-4"></a> [DONE]
  - 学习目标：解释辅因子参与催化或结构稳定的方式，区分 apo/holo 状态及模型缺失辅因子的后果。

<a id="b03-3-3"></a>

### 3.3 蛋白定位与复合物装配

- 3.3.1 蛋白质亚细胞定位：靶向信号、运输与功能环境 <a id="b03-3-3-1"></a> [WAITING]
  - 学习目标：从序列定位信号到细胞区室说明运输与环境，区分定位预测和实际实验观察。
- 3.3.2 蛋白复合物装配：亚基配对、化学计量与功能耦合 <a id="b03-3-3-2"></a> [WAITING]
  - 学习目标：说明亚基配对、化学计量与装配顺序；区分层级装配与结构域独立折叠；判断化学计量错误对复合物功能的影响；注明与 1.2.1 结构层级的分工。

## 4 实验结构证据与结构文件

<a id="b03-4-1"></a>

### 4.1 实验测定

- 4.1.1 实验结构方法：晶体学、冷冻电镜与核磁共振 <a id="b03-4-1-1"></a> [WAITING]
  - 学习目标：比较各方法测到什么、适合什么对象、有哪些不确定性；不要求复现三套实验流程。
- 4.1.2 分辨率、占有率、缺失残基与结构不确定性 <a id="b03-4-1-2"></a> [DONE]
  - 学习目标：用分辨率、B 因子、占有率与缺失残基判断局部可信度，不把高分辨率等同于高准确。
- 4.1.3 X 射线晶体学结构证据：衍射、电子密度与模型拟合 <a id="b03-4-1-3"></a> [WAITING]
  - 学习目标：从衍射约束到原子模型解释密度和占有率，辨认晶体接触、分辨率与模型不确定性；不讲完整实验操作。
- 4.1.4 冷冻电镜结构证据：粒子重构、局部分辨率与异质性 <a id="b03-4-1-4"></a> [WAITING]
  - 学习目标：说明二维粒子到三维密度的基本路径，区分局部分辨率、构象分类和原子模型精度。
- 4.1.5 核磁共振结构证据：距离约束、动态测量与结构集合 <a id="b03-4-1-5"></a> [WAITING]
  - 学习目标：用 NOE 等代表观测理解结构约束和系综，区分模型集合、实验平均与真实群体权重。
- 4.1.6 溶液态与低分辨率结构证据：SAXS、交联质谱与氢氘交换 <a id="b03-4-1-6"></a> [WAITING]
  - 学习目标：对照散射、交联与氢氘交换能约束的结构信息，说明低分辨率证据的判读边界。

## 5 结构比较、几何质量与预测置信度

<a id="b03-5-1"></a>

### 5.1 几何与一致性

- 5.1.1 结构叠合、原子选择与 RMSD <a id="b03-5-1-1"></a> [WAITING]
  - 学习目标：说明叠合对象、原子选择与 RMSD 的尺度依赖；判断不同叠合范围对数值的影响；把 RMSD 与 TM-score/lDDT 的适用场景区分开。
- 5.1.2 结构相似性指标：TM-score、lDDT 与 RMSD 对照 <a id="b03-5-1-2"></a> [WAITING]
  - 学习目标：比较全局折叠和局部距离一致性，避免每个指标另做一次概论。
- 5.1.3 立体化学、碰撞与拉氏图 <a id="b03-5-1-3"></a> [WAITING]
  - 学习目标：用键长键角、原子重叠与拉氏图离群判断几何合理性，说明各项检查的局限。
- 5.1.4 结构接触与界面评价：接触图、埋藏面积与界面几何 <a id="b03-5-1-4"></a> [WAITING]
  - 学习目标：从坐标构造接触及界面描述，比较局部接触恢复和全局结构相似性；对接任务指标引用 P05。

<a id="b03-5-2"></a>

### 5.2 预测置信度与功能结论

- 5.2.1 结构预测置信度：pLDDT、PAE、pTM 与 ipTM <a id="b03-5-2-1"></a> [DONE]
  - 学习目标：用同一个预测结果辨认局部、相对位置、整体和界面置信度；指标名称不再各拆一节。
- 5.2.2 低置信结构：天然无序、多构象与实验验证 <a id="b03-5-2-2"></a> [WAITING]
  - 学习目标：用无序、多构象或错误预测的对照案例说明不能从分数直接推功能。
- 5.2.3 变异对结构与功能的影响：稳定性、界面与致病机制 <a id="b03-5-2-3"></a> [DONE]
  - 学习目标：从 ΔΔG、界面破坏和聚集倾向判断变异后果，说明计算预测与实验验证的分工。
