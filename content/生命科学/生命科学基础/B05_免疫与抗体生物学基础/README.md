## 3 多样性与亲和成熟

<a id="b05-3-1"></a>

### 3.1 抗体基因重排与成熟

- 3.1.1 基因、基因组与染色体 <a id="b05-3-1-1"></a> [REUSE](../B01_生命科学基础主干/README.md#b01-2-1-3)
  - 学习目标：说明基因、基因组与染色体三者的层级关系；判断一个注释对象属于哪一层；把染色体坐标与基因产物联系起来。
- 3.1.2 V(D)J 重排：基因片段选择与受体可变区形成 <a id="b05-3-1-2"></a> [DONE]
  - 学习目标：追踪重链和轻链的片段组合，解释重排顺序及编码区形成，不混同体细胞高频突变。
- 3.1.3 抗体多样性：连接加工、重轻链配对与选择 <a id="b05-3-1-3"></a> [DONE]
  - 学习目标：连接末端加工、配对组合和功能筛选，区分理论组合数量与实际抗体库。
- 3.1.4 体细胞高频突变：AID、可变区变异与克隆谱系 <a id="b05-3-1-4"></a> [DONE]
  - 学习目标：解释突变来源及序列谱系，区分亲缘关系、突变数量和真实亲和力改善。
- 3.1.5 亲和成熟：生发中心、竞争选择与功能富集 <a id="b05-3-1-5"></a> [DONE]
  - 学习目标：连接抗原竞争、辅助信号及克隆选择，说明突变和选择共同决定成熟结果。
- 3.1.6 抗体类别转换：恒定区重组与效应功能 <a id="b05-3-1-6"></a> [DONE]
  - 学习目标：说明保持抗原识别的同时改变抗体类别和作用方式，区分类别转换、可变区突变和人源化。
- 3.1.7 免疫球蛋白类别与亚类：IgG1–4、IgA、IgM 与 IgE 的结构和效应差异 <a id="b05-3-1-7"></a> [DONE]
  - 学习目标：比较五类免疫球蛋白的链组成、聚合状态与效应功能；区分 IgG 亚类的 Fc 受体结合与补体激活差异；判断类别选择对半衰期、组织分布和效应功能的影响；联系 3.1.5 的类别转换。
- 3.1.8 体外亲和力成熟工程：CDR 突变库、选择压力与亲和力—稳定性权衡 <a id="b05-3-1-8"></a> [DONE]
  - 学习目标：说明突变库构建与选择压力，解释亲和力提升常伴随稳定性或表达代价。

## 4 抗体工程的主要目标

<a id="b05-4-1"></a>

### 4.1 抗体直接作用与 Fc 效应

- 4.1.1 结合动力学：kon、koff 与平衡解离常数 Kd <a id="b05-4-1-1"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-3-1-6)
  - 学习目标：读懂 kon、koff 与 Kd 的联系，不重复完整药理学。
- 4.1.2 抗体直接作用：中和、阻断、激动与受体内化 <a id="b05-4-1-2"></a> [DONE]
  - 学习目标：比较抗原结合后不同功能路径，说明表位、价态和受体背景，不把结合阳性等同功能阳性。
- 4.1.3 Fc 介导效应：Fc 受体、吞噬、细胞毒与补体 <a id="b05-4-1-3"></a> [DONE]
  - 学习目标：连接抗体类别、Fc 相互作用和细胞效应，区分直接中和与招募免疫系统。
- 4.1.4 抗体药代动力学与 FcRn 循环：半衰期、清除与组织分布 <a id="b05-4-1-4"></a> [DONE]
  - 学习目标：说明 FcRn 循环如何延长半衰期，连接清除途径与给药方案。
- 4.1.5 Fc 糖基化与效应功能调控：岩藻糖基化与糖型工程 <a id="b05-4-1-5"></a> [DONE]
  - 学习目标：说明 Fc 糖型如何改变 FcγR 亲和与效应功能，区分糖型工程与抗原结合。

<a id="b05-4-2"></a>

### 4.2 改善可开发性

- 4.2.1 蛋白质折叠、错误折叠与聚集 <a id="b05-4-2-1"></a> [REUSE](../B03_蛋白质结构与功能基础/README.md#b03-2-2-5)
  - 学习目标：区分聚集风险、溶解性和折叠稳定性。
- 4.2.2 抗体可开发性：稳定性、聚集与溶解性 <a id="b05-4-2-2"></a> [DONE]
  - 学习目标：区分相关但不可互相替代的性质。
- 4.2.3 抗体化学修饰与降解：脱酰胺、氧化、糖型与异构体 <a id="b05-4-2-3"></a> [DONE]
  - 学习目标：识别常见降解与修饰位点，说明它们如何影响稳定性、效价和批次一致性。
- 4.2.4 抗体表达与纯化的产量限制：宿主、载体与工艺 <a id="b05-4-2-4"></a> [DONE]
  - 学习目标：说明宿主、载体、转染与培养条件对产量的影响；判断聚集、降解与糖型对纯化收率的限制；区分工艺问题与分子设计问题。
- 4.2.5 人源化、人源性与免疫原性的区别 <a id="b05-4-2-5"></a> [DONE]
  - 学习目标：区分人源化改造、序列人源性与免疫原性风险，说明人源性评分不能替代免疫原性证据。
- 4.2.6 抗体免疫原性：抗药抗体、抗原呈递与风险证据 <a id="b05-4-2-6"></a> [DONE]
  - 学习目标：区分人源性评分、预测表位和实际抗药抗体响应，说明患者背景与给药条件的影响。
- 4.2.7 抗体工程形式：双特异、多价与偶联设计 <a id="b05-4-2-7"></a> [DONE]
  - 学习目标：比较改变价态、靶标组合和携带效应物的基本逻辑，说明组装与功能评价新增的约束，不展开所有药物平台。
