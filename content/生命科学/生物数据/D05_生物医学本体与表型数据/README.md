# D05 生物医学本体与表型数据

编号：D05 · 类型：数据专题 · 目录规模：28 个小节（三级叶子节点，少于 100）。

**知识主线**：标准术语与关系 → 细胞和解剖 → 疾病和表型 → 注释、映射与语义分析。

**范围与边界**：按 CL、Uberon、HPO、MONDO、Disease Ontology、ECO 等本体组织。OLS 是检索服务，OBO Foundry 是协作与目录入口，不将服务覆盖的全部本体揉成一个数据库。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。

> 博客已从 `content/生物信息/2.7_本体与术语数据OLS` 迁入对应小节；暂无合适博客的 TASK 小节保持 `[WAITING]`。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 内容构成：21 个自有写作小节，7 个通用复用小节。`[REUSE]` 是终态，与 `[DONE]` 并列；计入本脉络小节规模，不另建正文，不参与认领。
