# D03 单细胞图谱与扰动数据

编号：D03 · 类型：数据专题 · 目录规模：40 个小节（三级叶子节点，少于 100）。

**知识主线**：自然细胞状态图谱 → 统一重处理的计数数据 → 遗传及化学扰动 → 可比较的模型任务。

**范围与边界**：以 scBaseCount、CELLxGENE、scPerturb、Tahoe-100M 的发布为主体。这里的“数据”指官方发布，不等于未经处理的测序读段。Velocyto 是计数量化产品/分析工具路线，不虚构为独立数据站。数据许可、访问层级与再分发条款单列，避免把“可下载”当成“可任意再用”。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。

> 博客已从 `content/单细胞扰动组学` 的 2.2、2.3、4.1、4.2、4.3、4.4 迁入对应小节；暂无合适博客的 TASK 小节保持 `[WAITING]`。

**本脉络的深度边界**：发布字段、覆盖范围和量化名称可能缺少适当视频；保留科学问题，先报告材料缺口，不用相邻热门视频掩盖。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。
