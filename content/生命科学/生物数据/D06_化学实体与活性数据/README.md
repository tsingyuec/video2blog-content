# D06 化学实体与活性数据

编号：D06 · 类型：数据专题 · 目录规模：28 个小节（三级叶子节点，少于 100）。

**知识主线**：化学实体身份 → ChEBI 的分类和关系 → 活性证据连接 → 生成、对接与扰动数据使用。

**范围与边界**：ChEBI 是 biodata 当前主要化学数据；PubChem、ChEMBL 仅为必要的身份和活性背景，不宣称本地已有镜像。骨架切分采用 Murcko 骨架口径，靶标标识覆盖 ChEMBL target 到 UniProt/Ensembl 的解析边界。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。
