# D01 基因组与遗传变异数据

编号：D01 · 类型：数据专题 · 目录规模：31 个小节（三级叶子节点，少于 100）。

**知识主线**：物种与参考组装 → 基因和转录本 → 项目样本血缘 → 变异及其临床证据。

**范围与边界**：以 NCBI 各数据及 GENCODE 为对象，不把 biodata 的 ncbi/gene 页面当作数据库本体。SRA/ENA、Ensembl 是必要的关联背景，不代表本地完整收录。人群频率以 dbSNP 聚合频率为界，不展开 gnomAD；个体级基因型数据只讲受控访问与再分发边界。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 内容构成：21 个自有写作小节，10 个通用复用小节。`[REUSE]` 是终态，与 `[DONE]` 并列；计入本脉络小节规模，不另建正文，不参与认领。
