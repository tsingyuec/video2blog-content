# D04 分子功能网络与通路数据

编号：D04 · 类型：数据专题 · 目录规模：34 个小节（三级叶子节点，少于 100）。

**知识主线**：基因产物功能注释 → 分子关系网络 → 反应和通路 → 富集与机制假设。

**范围与边界**：GO/GOA、STRING、Reactome；区分功能关联、物理结合、通路参与和因果调控。GO 的形式本体语言连接 D05，本篇主讲功能证据及分析。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。

> 博客已从 `content/biodata/string` 与 `content/单细胞扰动组学` 的 5.1 迁入对应小节；暂无合适博客的 TASK 小节保持 `[WAITING]`。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 内容构成：21 个自有写作小节，13 个通用复用小节。`[REUSE]` 是课程内容类型，不是进度状态；计入本脉络小节规模，但不另建正文或认领任务。
