# D02 蛋白质序列家族与结构数据

编号：D02 · 类型：数据专题 · 目录规模：31 个小节（三级叶子节点，少于 100）。

**知识主线**：蛋白条目与序列 → 非冗余簇 → 结构域家族 → 实验或预测结构。

**范围与边界**：UniProt、UniParc、UniRef、Pfam、InterPro、AlphaFold Protein Structure Database；PDB 是结构证据对照背景。按原站科学对象组织，不按本地表或下载覆盖率组织。
