# D07 抗体实验与公共参照数据

编号：D07 · 类型：数据专题 · 目录规模：39 个小节（三级叶子节点，少于 100）。

**知识主线**：抗原与实验设计 → 配对序列与谱系 → 表达纯化 → 结合、功能和可开发性证据。

**范围与边界**：biodata 的 antibody 对应内部实验数据，不存在可据仓库确认的独立公共站点。本篇以一手实验对象为主线，IMGT、OAS、SAbDab 作为明确标识的外部参照，不冒称为内部数据的上游来源。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以“读懂一个条目、实验设计或跨数据来源链”为单元，不按字段、版本号和免责声明拆分。精确数据事实须对照官方发布。

> 博客已从 `content/生物信息/5.4_性质可开发性域` 迁入对应小节；暂无合适博客的 TASK 小节保持 `[WAITING]`。

**本脉络的深度边界**：内部数据血缘只能由经授权的一手资料说明。公开教程适合讲实验通用原理，不能为内部来源作证。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 内容构成：17 个自有写作小节，22 个通用复用小节。`[REUSE]` 是课程内容类型，不是进度状态；计入本脉络小节规模，但不另建正文或认领任务。
