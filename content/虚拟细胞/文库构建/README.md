# 虚拟细胞 · 实验基础：文库构建

> `content/虚拟细胞` 系列讲的是 Perturb-seq / 单细胞扰动数据与虚拟细胞模型；本目录补的是**这些数据在湿实验里怎么产生**的前置知识。
> 选题来自 `explore`：文库构建 / 表达载体 / sgRNA / 基因敲除，每类取精排前两条，一视频一篇博客。
>
> **本目录 = 文库构建，分两头**：一头是**筛选侧**的 sgRNA 文库（把上万个 sgRNA 装进病毒、感染细胞池，谁死谁活用测序读出）；另一头是**测序侧**的 NGS 建库（把样本变成能上机的文库，读出每个 sgRNA 的丰度）。少了任何一头，Perturb-seq 的 count matrix 都无从谈起。

## 本篇要点

- **【零基础入门】CRISPR文库筛选全流程拆解**（8,787 汉字）：把「文库筛选」按工程顺序走完一整遍。先讲为什么需要它（两万个基因 vs 三年博士时间），再落到**动手前必须定死的四件事**（模型 / 扰动 / 压力 / 读出，以及 pooled 与 arrayed 的取舍）；然后逐步骤拆解：Cas9 稳转株要选**切割活性 ≥80%** 的细胞、sgRNA 文库从哪来（现货、Addgene、自设计，以及「每个基因 4–6 条 sgRNA」的依据）、覆盖度 99% 与均匀性这两条硬指标、MOI 与「一个细胞只装一条 sgRNA」的泊松约束、加压与测序、reference control 怎么设；最后用 AML 分化阻滞案例演示「流式读出 → 小库 + 单细胞 → 治疗靶点」的完整闭环，并以 Q&A 收尾（低覆盖度能不能做、类器官能不能筛、Cas9 活性不够怎么办）。
- **唯赞学堂｜浅谈NGS文库制备**（9,046 汉字）：讲的是**另一头**——测序建库。从两大平台的分叉点（Illumina 边合成边测序 / 华大 DNB）讲到文库解剖结构（一个插入片段 + 三段接头，index 是「数据的身份证」），重点全在**最容易出错的三处**：样本质量（降解、蛋白与 RNA 污染会同时毁掉超声打断和磁珠纯化）、片段选择（磁珠比例与双选的时机，最常见的「看起来做了、其实做错」）、接头连接与 PCR（风险是定量失衡而非操作失败）；再讲质控两道关、手动与自动化的取舍、从现象倒推原因的排查表。文末两节为编者补充：起始量决定建库策略（含 PCR-free 的适用边界），以及**这套「测序文库」与 CRISPR 筛选文库的关系**——前者测的正是后者的 sgRNA 分布。
