## 本篇要点

- **走进CRISPR/Cas9——sgRNA质粒构建**：解决「一条 sgRNA 载体到底怎么建」。先拆开 lentiCRISPR v2 的两个表达框（U6 驱动 sgRNA、EF1α 驱动 Cas9，Cas9 带 Flag/NLS，经 P2A 连嘌呤霉素抗性），再解释为什么用 BsmBI 做克隆位点（切掉 ~1.9 kb filler 便于用电泳判断酶切成功；两个黏端不互补，因此不用去磷酸化、也不会自连），最后把传统酶切连接与无缝克隆两条路线走完整（酶切→胶回收→连接→转化→菌落 PCR/测序；Gibson 的 15–20 bp 同源臂与多片段顺序），并说明单/双质粒系统与双 sgRNA 载体（中间载体法或直接合成）的选择逻辑。
- **玩转慢病毒：从高效载体构建到稳定细胞株构建**：解决「一条载体怎么变成一株稳转细胞」。按链路展开：一代/二代/三代包装系统的演进与安全性（三质粒→四质粒，删 vif/vpr/vpu/nef 再去 tat）、psPAX2 与 pMD2.G 各提供什么、穿梭质粒的必备元件与启动子/标记选择、无缝克隆的载体构建要点、293T 共转染包装与浓缩保存、荧光法倍比稀释测滴度（72 h 表达高峰）、按 MOI 感染与 1/2 小体积感染法、药筛建稳转株，以及五类常见失败原因的排查顺序。
