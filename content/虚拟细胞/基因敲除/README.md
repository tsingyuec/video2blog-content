## 本篇要点

- **如何进行基因编辑 新生培训（王新栋）**（8,529 汉字）：**高校实验室的新生培训**（非厂商讲座），可信度最高的一篇。从细菌免疫 → 张锋用于哺乳动物细胞 → 2020 诺奖讲到产业现状；机制上强调"一次切割由三件事决定"（RuvC/HNH 两个结构域、一条 20 nt 引导序列、一个 NGG PAM）；工程上把递送讲透（DNA / RNA / RNP 三种形式与四类载体的起效时间、持续时间、整合与脱靶风险对照）；最有价值的是两个"真实坑"：**T7E1 条带不清 ≠ sgRNA 无效**（直接转染后提基因组会看不清，建议先短程嘌呤霉素筛选再提基因组），以及新手最容易犯的**坐标错误**（必须用全基因组序列设计，别只贴 CDS）；最后覆盖 RNP 体外切割验证、敲入的 AAV 模板与单克隆分离，以及 dCas9-KRAB 抑制 / dCas9 激活这两种"不切 DNA 也能调控"的用法。
- **CRISPR/Cas9 基因敲除全过程**（8,541 汉字）：**工程视角最完整**的一篇，主线是"敲到一个可交付的单克隆株"。先区分敲低与敲除、四把工具横向对比；再讲编码基因敲除的两个硬约束（切所有转录本共有区、靠近 N 端以触发无义介导降解）与**非编码 RNA 的三种拆法**（启动子上游 + 第一外显子双切、polyA 插入终止、针对最后一个内含子的新方法，并各自说明风险：可能影响重叠的编码基因、下游起始位点仍可转录）；工程段最实用：两个"劝退测试"（细胞是否适合单克隆、克隆形成率是否 ≥10%）、梯度稀释与克隆环取单细胞、**终验三层**（测序判纯合/杂合、PCR 判大片段缺失、WB 判无蛋白），以及"三保一"（一次构建多条 sgRNA）背后的经验；末尾收录六个高频困惑的现场回答。
