## 本篇要点

- **第 8 讲 gRNA 的选择及引物设计**（5,953 汉字）：系列课的第 8 讲（承接第 7 讲的技术基础），也是最"手把手"的一篇。核心判断是**「要设计的其实只有 spacer 那一段」**。靶位点选择给了五条可操作的规则：尽量靠 5′、优先外显子 1/2、落在所有转录本共有区、避开可变剪接与剪接接头、用 NCBI CDD 确认是否在保守结构域；接着是 SnapGene 实操——怎么把外显子边界精确到"第几个碱基"、怎么在**正反两条链**上搜 NGG 并取它上游 20 nt（而不是只搜 TGG）；最后把 20 nt 写成一对引物：`F = ATTG + [G] + spacer`、`R = AAAC + revcomp(spacer)`，配两对实例逐碱基推导，并解释为什么一个基因至少要备 2–3 对。
- **十分钟搞定 sgRNA 设计**（3,873 汉字）：单集闭环。机制部分讲清 Cas9 的三步（结合激活 → 互补配对定位 → HNH 切靶标链 / RuvC 切非靶标链）与 PAM 这道"门禁"（3–6 个碱基，四条鉴定路线）；设计部分给三条黄金法则（20 nt、避免与非目标区相似、看 GC 与二级结构）；实操部分以 **PCSK9** 为例走完 NCBI 取序列 → 选外显子且靠蛋白 N 端 → 网站打分 → BLAST 查特异性；再讲切完之后 NHEJ 与 HDR 怎么按实验目的选、四类递送方式的物理限制，以及**三层验证**（T7E1 判断"切没切"、Sanger 看"切成什么"、扩增子深度测序看"占多少比例"）。
