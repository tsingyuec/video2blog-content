# 杂项

不适合进入知识脉络的碎片化内容。这里不是垃圾桶，而是**有明确收录规则的归档区**。

## 收录条件（满足任一）

- 单篇或两三篇博客，无法构成连续学习线；
- 工具安装、配置、报错排查等操作碎片；
- 新闻、评测、观点、会议花絮、访谈片段；
- 系列未完成，剩余内容不足以成脉络；
- 与任何脉络的学习目标都不匹配，强行归类会破坏脉络完整性。

## 组织方式

- 不设章/节/小节，不设 `WAITING/PROCESSING/DONE` 状态机；
- 只做索引和标签，保留来源系列、视频链接、原小节，便于回溯；
- 可以被脉络的“延伸阅读”引用，但**不计入脉络小节数，不参与 REUSE 课程编排**；
- 仍要通过死链、公式、图片检查。
