## 本讲要解决的核心问题（SCQA）

**背景**：扩散模型如今几乎在你能想到的每一个生成领域都有应用——图像、视频、音乐、3D 模型，甚至用于发现新分子。把它推上聚光灯的，是 2020 年乔纳森·何（Jonathan Ho）及其合作者发表的论文《去噪扩散概率模型》（DDPM）；该领域最早的文献记载则来自 2015 年 Sohl-Dickstein 等人的《利用非平衡热力学进行深度无监督学习》。2015 年时 GAN 是图像生成的主流，扩散模型少人问津；而 DDPM 很快成为该领域被引用最多的论文，截至 2025 年引用量已超过 20,000 次。它最主要的贡献，是把扩散模型从仅限于玩具数据集的理论概念，变成先进的图像生成技术，并引入了一个比 2015 年版本简单得多的训练目标。[【跳转到 00:36】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=36)

**冲突**：我们想从「所有自然图像」（或其中人脸子集）这样的数据分布 p 中采样新样本，但这个分布复杂到**写不出一个表达式**来完整描述它，甚至可能根本不存在这样的表达式——连分布长什么样都不知道，怎么采样？[【跳转到 02:03】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=123)

**疑问**：在没有任何分布公式的情况下，有什么办法生成新样本？

**回答（中心思想）**：DDPM 用一个看似不相关的流程解决它——**从图像中去除高斯噪声**。先设计一条前向过程，逐步给图像加噪直到变成纯噪声；再训练神经网络逐步逆转这些步骤。生成时从随机噪声出发，迭代执行采样循环 N 步（DDPM 论文设定约 1000 步），图像细节在最后几百步浮现，最终得到新样本。[【跳转到 02:53】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=173)

## 一、生成建模的挑战与「去噪」思路

在数据生成的背景下，训练数据来自某个概率分布 p。理想中，生成新图像 = 从这个潜在分布中抽取新的样本点；但如前所述，p 没有可用的描述。扩散模型的解法分两半：[【跳转到 03:09】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=189)

1. **前向（加噪）**：每一步添加少量高斯噪声，逐渐抹去图像结构；继续很多步后，图像变成纯噪声；
2. **反向（去噪）**：训练一个模型学会逐步逆转这些步骤、一点一点去噪。若模型有效，它就能从随机噪声开始，逐步细化为有意义的图像。

关键直觉：加噪是我们自己定义的、有精确公式的过程，而「把噪声一步步还原成图像」恰巧是可以被神经网络学会的。

![前向加噪：每步添加少量噪声、逐渐抹去结构，最终图像变成纯噪声](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00173.webp)

## 二、前向过程第一版：直觉版本与「方差爆炸」的教训

### 2.1 逐步加噪：q(x₁|x₀) = N(x₀, β)

从一张无噪图像 x₀ 开始。生成下一步 x₁ 使用条件分布 q：在 x₀ 上添加一定量的高斯噪声 ε，噪声量由标量 β 控制。与其说「给 x₀ 加噪」，不如说「从以 x₀ 为中心、方差为 β 的高斯分布中抽取一个样本」。对 x₂ 做同样的事：从以 x₁ 为中心、方差为 β 的分布采样。[【跳转到 03:30】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=210)

![第一步加噪：q(x₁|x₀) 是以 x₀ 为中心、方差为 β 的高斯分布](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00210.webp)

### 2.2 噪声可以累加：一步直达 x_t

既然每步只是「加噪声」，噪声项可以相加：从 x₀ 直接跳到 x₂，等于加两倍噪声、从方差为 2β 的高斯分布采样。一路推到任意时间步 t，得到简单公式：**q(x_t | x₀) 是以 x₀ 为中心、方差为 tβ 的高斯分布**。[【跳转到 04:40】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=280)

### 2.3 方差爆炸：这一版到不了标准正态

我们想要的是「把数据分布逐渐变成标准正态分布」的过程，但这一版做不到：均值始终固定在 x₀ 处不随过程改变，而方差 tβ 会**无限增大**——文献中称之为「方差爆炸」（variance exploding）扩散。它永远收敛不到 N(0,1)。[【跳转到 05:05】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=305)

![方差爆炸：均值固定不动、方差随步数无限增大](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00305.webp)

## 三、方差保持扩散过程：真正可用的加噪路径

### 3.1 两个收敛条件与 √(1−β) 系数

重新设计一个切实可行的扩散过程，需要满足两个条件：**均值收敛于 0，方差收敛于 1**。为此，在每一步给均值乘上一个逐渐减小至零的系数。DDPM 论文选的「神奇数字」是 **√(1−β)**。选它的主要原因之一是其简单性——它能得出条件分布的简洁表达式。[【跳转到 05:55】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=355)

### 3.2 ᾱ_t：任意时间步一步直达

在固定 β 的简化情形下，记 **ᾱ_t = (1−β) 的 t 次幂**。只要 β 严格取在 0 到 1 之间，当 t 趋于无穷大时 ᾱ_t → 0，条件分布的均值趋于零、方差趋于一——我们终于得到一个**方差保持（variance preserving）**的扩散过程。妙处在于：借助这个闭式，可以**直接从无噪输入 x₀ 跳到任意时间步**，无需遍历之前所有步骤。[【跳转到 06:50】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=410)

![ᾱ_t 闭式：从 x₀ 一步直达任意时间步](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00410.webp)

（注：原论文的写法稍有不同——实际扩散模型通常在每一步使用**不同**的噪声量，而非固定 β。只要每个 β_t ∈ (0,1)，任何噪声安排都可以；此时第 t 步的 ᾱ_t 等于每一步 (1−β_i) 的**连乘积**，这正是论文中找到的表达式。）[【跳转到 08:23】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=503)

### 3.3 一维示例：约 100 步后收敛到标准正态

用一个一维分布直观验证：对原始无噪数据分布 p，仅做一次扩散步骤几乎看不出变化；重复约 100 步后效果明显——均值趋近于零、分布的离散程度趋于稳定。这正是「把任何分布逐步转变为正态分布」的直观证据。[【跳转到 07:40】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=460)

![一维示例：约 100 步后分布收敛到标准正态](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00460.webp)

## 四、反向过程与训练目标：负对数似然 → ELBO

### 4.1 用神经网络逆转扩散：p_θ

前向过程用条件分布 q 定义；反向过程则定义条件分布 p_θ(x_{t−1} | x_t) 用于回溯。前向过程所有参数固定；反向过程的目标是找到最佳参数 θ（就是神经网络的权重）来有效去噪。[【跳转到 08:59】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=539)

### 4.2 训练目标：最小化负对数似然

训练采用统计中的标准方法：**最小化负对数似然**——找到参数 θ，使模型生成真实样本 x₀ 的可能性最大。完整的反向过程是各步条件分布的乘积（联合分布）；计算似然需要对联合概率做**边缘化**，即对所有能生成 x₀ 的可能路径求和：把「自然图像的密度分布」与「纯高斯噪声的密度分布」之间所有路径加起来。可能的路径实在太多，这个量**难以处理**（intractable），无法精确计算。[【跳转到 12:02】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=722)

### 4.3 ELBO：证据下界

用两个著名技巧绕开难题：先「乘以并除以」前向过程的密度，把积分重写为期望的形式；再用 **Jensen 不等式**（负对数是凸函数，可把对数移进期望内），代价是引入一个不等式。于是得到负对数似然的一个**上界**——这就是**证据下界 ELBO**（它是似然本身的下限，故得此名）。[【跳转到 13:17】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=797)

![ELBO：负对数似然的上界，似然的下界](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00797.webp)

（完整推导见 DDPM 论文补充材料 A 部分。）[【跳转到 13:42】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=822)

### 4.4 KL 散度：分布之间的「距离」

ELBO 里大量出现 **KL 散度**（库尔贝克–莱布勒散度）：衡量两个概率分布接近程度的量，可以想象成概率空间中的一种距离。分布差异大（均值或方差不同），KL 散度大；分布几乎相同，KL 散度趋近于零；只有完全相同时才等于零。[【跳转到 14:20】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=860)

![KL 散度：概率分布之间的差异度量](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/00860.webp)

## 五、从 ELBO 到最终损失 ‖ε − ε_θ‖²

### 5.1 逐项化简：舍弃常数项与几乎无用的重建项

通过代数运算与贝叶斯定理，ELBO 可重写为更有用的形式。其中：左边第一项与模型参数无关，优化时可忽略；右侧最后一项衡量模型从 x₁ 重建 x₀ 的能力——但扩散模型通常要走**约一千次去噪步骤**，从 x₁ 到 x₀ 时几乎已无噪声、图像早已基本恢复，所以这一项很小、提供不了多少学习信号，通常直接舍弃。剩下的主体是**一列 KL 散度之和**：每一项都在比较「网络的反向步骤 p_θ(x_{t−1}|x_t)」与另一个分布 q。[【跳转到 15:35】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=935)

### 5.2 真后验：训练时的「标准答案」

q 就是**真正的后验分布** q(x_{t−1} | x_t, x₀)——若以干净图像 x₀ 为条件，逆向过程其实可以精确算出，且有**封闭形式表达式**（同样是繁琐代数与贝叶斯法则的产物）。你可能会问：既然有闭式，为什么还要神经网络？因为用它生成等于**作弊**：真后验以 x₀ 为条件，而推理时我们恰恰要从纯噪声生成未知的 x₀。但在**训练时** x₀ 已知，可以拿来当标准答案——损失函数真正要做的，就是训练网络去**匹配真实后验**（哪怕网络实际只能看到 x_t）。[【跳转到 16:50】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1010)

### 5.3 高斯近似、固定方差 → L2 距离

近似后验 p_θ 也取高斯分布，原因有二：有定理表明**高斯马尔可夫链的逆链仍是高斯链**；且用高斯一切都简单得多。于是网络要预测的是高斯的参数——均值 μ_θ 与方差 σ_θ。作者进一步把方差**固定为常数、不参与学习**，网络只学均值。匹配两个高斯、又只能控制均值，KL 散度恰好简化为**两个均值之间的普通平方距离**：整体目标变成最小化一列 L2 距离之和，每项衡量预测均值 μ_θ 与真实后验均值 μ̃ 的偏差（带一个按方差 σ_t 变化的权重因子）。[【跳转到 19:09】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1149)

### 5.4 重参数化技巧：x_t 相互抵消

真实后验均值 μ̃ 的闭式是 x₀ 与 x_t 的加权组合，不便使用。借助**重参数化技巧**（与本视频开头、以及 VAE 中使用的是同一种）：把 x_t 写成「x₀ 加上 ε」（ε 为纯高斯噪声），反过来 x₀ 也可以只由 x_t 与 ε 表示。对网络预测的均值 μ_θ 做同样处理，写成 x_t 与一个预测噪声项 ε_θ 的函数。把两个表达式代入损失后，**x_t 的项相互抵消**，露出最终目标函数——简单得多的损失：**ε 与 ε_θ 之间的平方距离 ‖ε − ε_θ‖²**。ε_θ 由此成为网络对「生成 x_t 时加到 x₀ 上的噪声」的估计；最小化损失 = 让这个预测尽可能准。[【跳转到 20:24】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1224)

![重参数化：μ̃ 与 μ_θ 都改写成 x_t 与 ε 的函数](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/01224.webp)

![最终损失：真实噪声与预测噪声之间的平方距离](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/01249.webp)

### 5.5 推导链路回顾

从负对数似然出发 → 因难以处理引入替代指标 **ELBO** → 展开为若干项之和，舍弃常数项与可忽略的重建项，得到 KL 散度之和 → 高斯近似 + 固定方差使 KL 项化为 L2 距离 → 重参数化把均值都用 ε 表示，最终收敛到 **‖ε − ε_θ‖²**。[【跳转到 21:39】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1299)

工程上的最后简化：不必对每个样本的所有时间步求和（数百步求和相当耗费资源），而是**为每个样本随机选取一个时间步 t**；样本量足够大时，这趋近于最初的目标。[【跳转到 22:29】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1349)

## 六、动手实现：在 MNIST 上训练 DDPM

### 6.1 库、数据与网络

Python 实现依赖两个库：PyTorch（定义与训练神经网络），以及基于 PyTorch、面向成像逆问题的 **DeepInverse**——它提供 DDPM 所需的 U-Net 现成实现与预训练权重。数据用 MNIST 手写数字（小型灰度图）：批量大小 32，每张调整为 32×32 像素；实例化 DiffusionUNet 并指定输入输出通道数；从头训练（不加载预训练权重），优化器用标准学习率的 Adam，损失就是前面推导出的均方误差。[【跳转到 24:41】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1481)

### 6.2 β 调度（噪声时间表）

先定义扩散常量：β 调度描述每一步添加的噪声水平，采用从较小初始 β 到较大最终 β 的**线性插值**（与原论文一致；也可以换用余弦调度等）。随后据此计算 α 值、α 的累积乘积 ᾱ，以及 √ᾱ、√(1−ᾱ) 等常用项。[【跳转到 25:31】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1531)

![β 线性调度：每一步的噪声水平时间表](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/01531.webp)

### 6.3 训练循环与训练动态

每一步训练：从 0 到 1000 之间**随机抽取时间步 t**，从标准正态分布抽取 ε，用方差保持闭式计算含噪图像（理论与实现的公式完全一致）；把含噪图与 t 一起输入网络得到噪声估计 ε_θ，计算它与真实 ε 的均方误差。代码里对所有时间步使用**相等的权重 1**（同样是原论文的做法，实测往往比按时间加权效果更好）。如此重复约 100 个 epoch，训练结束保存权重。[【跳转到 25:56】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1556)

训练动态：MSE 迅速下降并稳定在很低的值；每个 epoch 结束展示去噪样本可以直观追踪进展——训练早期高噪声水平下输出很差、低噪声时已相当不错；随着训练推进，模型在所有时间步上的去噪能力都变强，但**极高噪声下仍难以直接还原出正确数字**——这完全可接受，因为它用来生成新样本时依然表现出色。[【跳转到 27:11】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1631)

## 七、采样：noise → N_step → sample

### 7.1 采样循环：从纯噪声走约一千步

推理代码在单独文件中实现：导入库、加载训练好的权重，并**重新定义与训练时完全相同的扩散常量**（包括 β 调度）——训练与推理的参数必须完全匹配，否则推理时各时间步的噪声量与训练时见到的不一致。[【跳转到 28:15】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1695)

采样循环本身：

1. **起点**：采样一张纯高斯噪声，它就是初始变量 x_T（对应「任何纯噪声都可视作某张图加噪到底」）；[【跳转到 28:28】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1708)
2. **去噪一步**：把噪声图与时间步 t 一起输入网络预测 ε_θ；把噪声估计代入后验均值公式，再加一点点噪声，从近似后验中采样出 x_{t−1}；[【跳转到 28:53】](https://www.youtube.com/watch?v=EhndHhIvWWw&t=1733)
3. **重复**：把更新后的图像再输入网络、计算后验均值、采样下一张——这一循环通常会**执行上千次**。

![采样起点：x_T 就是一张纯高斯噪声](assets/Diffusion%20Models：DDPM｜Generative%20AI%20Animated/01708.webp)

## 小结

- DDPM（2020，Jonathan Ho 等）把扩散模型从理论概念变成先进的图像生成技术；前身是 2015 年的非平衡热力学扩散，DDPM 的关键贡献是**简单得多的训练目标**。
- 生成建模的难点：数据分布写不出表达式却要采样。解法：加噪有公式（学得会），去噪可由神经网络逐步逆转。
- 第一版加噪（均值不动、方差 tβ 无限增大）会「方差爆炸」；给均值乘 √(1−β) 得到**方差保持过程**，ᾱ_t（各步 1−β 的连乘）让任意时间步一步直达，且分布收敛于 N(0,1)。
- 训练目标从负对数似然出发，经边缘化（难以处理）→ Jensen 不等式得到 **ELBO** → 舍弃常数项与近无用的重建项 → KL 散度之和 → 高斯近似 + 固定方差化为 L2 → 重参数化让 x_t 抵消，最终只剩 **‖ε − ε_θ‖²**。
- 训练时用真后验 q(x_{t−1}|x_t,x₀) 作标准答案（它有闭式），网络只能看 x_t，学会「匹配真后验」；推理时从纯噪声出发，没有 x₀ 可用。
- 实操（MNIST + DeepInverse）：β 线性调度；每个样本随机抽 t ∈ [0,1000]，MSE（权重全 1）训练约 100 epoch；推理常量必须与训练一致。
- 采样即「noise → N_step → sample」：x_T ~ N(0,1) → 预测 ε_θ → 后验均值 + 小噪声 → x_{t−1} → 重复约一千次；细节在最后几百步浮现，核心循环不到 30 行；换 FFHQ 权重即可生成人脸。代价是每个样本评估网络约一千次——少步数采样是后续工作（如 DDIM）的方向。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| DDPM | 去噪扩散概率模型（2020）；把扩散模型变成实用图像生成技术的论文 |
| 采样 | 从概率分布中抽取新样本；生成图像 = 从数据分布中采样新图 |
| 前向过程 q | 有精确公式的逐步加噪路径，把任何数据分布逐渐变成 N(0,1) |
| 方差爆炸 | 第一版加噪的问题：均值不动、方差随步数无限增大 |
| 方差保持（VP） | 加噪时给均值乘 √(1−β)，使过程收敛于均值 0、方差 1 |
| ᾱ_t | 各步 (1−β_i) 的连乘；由它可从 x₀ 一步直达任意时间步 |
| β 调度 | 每步噪声水平的安排（线性/余弦等）；训练与推理必须一致 |
| 负对数似然 | 「模型生成真实样本的可能性」取负对数；越小越好 |
| 边缘化 / 难以处理 | 对所有可能路径求和；路径太多，无法精确计算 |
| ELBO（证据下界） | 负对数似然的上界（= 似然的下界），由 Jensen 不等式导出 |
| KL 散度 | 两个概率分布差异的度量，可视为概率空间中的「距离」 |
| 真后验 q(x_{t−1}|x_t,x₀) | 以干净图为条件时逆向一步的精确分布；有闭式，训练时的标准答案 |
| 重参数化技巧 | 把随机变量改写成「确定量 + 独立噪声」的形式，使 x_t 在损失中抵消 |
| ε_θ / ε | 网络预测的噪声 / 前向加噪时真实使用的噪声；最终损失 = ‖ε − ε_θ‖² |
| 采样循环 | 从纯噪声 x_T 起，反复「预测噪声 → 后验采样」，执行约 N_step（~1000）次得到样本 |
| MNIST / FFHQ | 手写数字 / 高质量人脸数据集，视频中用于训练与展示生成效果 |
