# Getting Started with BindCraft：Designing Protein Binders

> 视频来源：YouTube《Workshop: Getting Started with BindCraft: Designing Protein Binders – Lennart Nickel》（欧洲合成生物学会网络研讨会，约 59 分钟）。主讲人 **Lennart Nickel** 是 BindCraft 论文的共同第一作者（EPFL 洛桑联邦理工学院，Bruno Correia 实验室），本篇是他亲授的"讲座 + 上手工作坊"。

## 本讲要解决的核心问题（SCQA）

**背景**：管线 A 的前两步已经就位——RFdiffusion 生成骨架（见 6.1.2），ProteinMPNN 配序列（见 6.1.3）。跑一晚上，集群能吐出成百上千个"看起来能结合靶标"的候选结合剂。

**冲突**：计算机里"看起来能结合"的设计，绝大多数在湿实验里是假的。Baker 实验室复盘自家旧酵母库发现：用传统物理方法（Rosetta）打分的设计池，实验成功率很低；但如果改用 AlphaFold **重新折叠**这些设计、按置信度过滤，成功设计能被大幅富集。当时一个项目动辄 10 万~1000 万个计算设计，缺的不是生成能力，而是一道可靠的**回折验证闸门**。

**疑问**：这道闸门具体怎么搭？按什么指标判定（pLDDT / pAE / ipTM）？阈值怎么定？验证过了又怎么推进到湿实验？

**回答（中心思想）**：BindCraft 把「幻想设计 → ProteinMPNN 序列优化 → 换一套 AlphaFold 权重回折验证 → 按置信度指标过滤」做成了一条端到端流水线。本讲由第一作者带你从设计原理、配置文件、实战经验一路走到湿实验验证手册——这正是管线 A 第三步「Protenix/OpenFold3 回折验证（ipTM 判定）」的经典范本。

## 一、回折验证为什么是蛋白设计的"裁判"

### 1.1 设计三步走，每一步都欠一次"验货"

蛋白质设计的标准工作流已经收敛成三大步骤（[【跳转到 06:19】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=379)）：

1. **生成骨架**：先拿到蛋白形状的雏形，此时还没有侧链和序列信息。对结合剂来说，关键是它与靶标的形状互补；工具如今多用扩散模型（RFdiffusion、Chroma）。
2. **逆折叠配序列**：为骨架找一段能折叠成它的序列——ProteinMPNN 是这一步的"头号主角"。
3. **回折验证**：把设计好的序列重新预测结构，看是否匹配最初画下的骨架——AlphaFold、ESMFold、RoseTTAFold 等结构预测工具都能干这活。

![设计三步走：骨架生成 → 逆折叠配序列 → 回折验证](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/00379.webp)

前两步产出候选，第三步才是"验货"。领域内把这套流程叫**可设计性检验**（designability test）：设计骨架 → 配序列 → 重预测 → 把两个结构对齐，看重预测结果与原设计的贴合程度，用 **TM-score**（全局结构相似度，0~1，越接近 1 越像）或经典 **RMSD**（均方根偏差，越小越像）量化（[【跳转到 08:24】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=504)）。

![可设计性检验：重预测结构与设计骨架对齐比较](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/00504.webp)

### 1.2 Baker 实验室的教训：AlphaFold 过滤能富集成功设计

BindCraft 诞生的直接推动力来自 Baker 实验室的一项复盘研究（[【跳转到 11:44】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=704)）：他们回看自家旧酵母展示库（约 2000 个设计/库，通常只能出 2~5 个命中）的实验结果，发现用 Rosetta 打分时实验成功率相当低；但假如当初用 AlphaFold 来过滤设计池——直接问模型"你认为这个结合剂能不能结合靶标"——设计池里的成功设计本可以被大幅富集。

背景是当时一个项目要做 10 万~1000 万个计算设计的结合剂，只有一小部分能成功。既然 AlphaFold 区分"能结合/不能结合"这么灵，为什么不直接让它参与设计？这就是 BindCraft 的起点。

![Baker 实验室复盘：用 AlphaFold 过滤设计池可富集成功设计](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/00704.webp)


## 二、BindCraft 的核心思想：让"裁判"直接参与设计

### 2.1 两条技术路线：随机突变 vs 梯度反向传播

用结构预测模型做设计的想法并非凭空出现——Sergey Ovchinnikov 是这条路线的主要推动者之一。最直接的用法是"随机序列 + 接受-拒绝"：从随机序列开始预测（通常一团糟），尝试突变，置信度变好就接受、变差就重试，迭代很多步最终也能"折"出一个蛋白——但要走约 **4 万步**，耗时极长、计算极重（[【跳转到 13:04】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=784)）。

更聪明的做法是换成**基于梯度的反向传播**：把"想要的折叠方式"与"当前预测"的接触图差异写成一个误差（loss），最小化它就能引导序列朝目标走。BindCraft 走的就是 ColabDesign 框架下的梯度路线（由 Sergey 等人实现辅助函数）。

### 2.2 松弛序列空间：先在概率里优化，再收敛到真实序列

直接在"每个位置一个氨基酸"的硬表示上做优化，收敛会在噪声里打转。BindCraft 在所谓**松弛序列空间**（relaxed sequence space）里工作：每个位置用概率表示——"这里大概 20% 是苏氨酸、10% 是丙氨酸"——在概率上做优化，过程平滑得多；随后用 **softmax** 逐步把说不通的氨基酸"踢出局"，收敛到 **one-hot 编码**（每位置唯一氨基酸）的物理真实形态（[【跳转到 16:19】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=979)）。

![松弛序列空间逐步收敛到 one-hot：右侧概率表示在收敛，左侧硬表示原地打转](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/00979.webp)

### 2.3 端到端流水线与可优化目标

BindCraft 不只是"幻想"这一步，而是一条端到端流水线（[【跳转到 18:24】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1104)）：

1. **幻想步骤**：以多项目标联合优化序列——模型置信度（AlphaFold 的 **pLDDT** 逐残基置信度、**pTM** 全局折叠置信度、**pAE/pTM/ipTM** 等界面指标）、接触数量（让结合剂紧凑）、回转半径 Rg（球状度）、负螺旋度（想要更多β折叠时用）等；
2. **ProteinMPNN 序列优化**：把幻想出的序列换成"更好表达、更稳定"的实现（湿实验经验之谈）；
3. **回折过滤**：**换一套不同的 AlphaFold 权重**重新预测设计序列——交叉验证、与初始轨迹对比做可设计性检验——这就是整条流水线的最终闸门。

为什么换一套权重？因为幻想阶段是用一套权重"养"出来的序列，天然讨好它自己；换一套权重再折叠，等于请一位没有利益关系的裁判复考——这正是"ipTM 判定"的精髓，也和用 Protenix/OpenFold3 回折验证 RFdiffusion+ProteinMPNN 设计（管线 A 第三步）一脉相承：**设计可以过拟合，验证必须独立**。

![BindCraft 端到端流水线：幻想 → MPNN → 换权重回折过滤](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/01104.webp)

## 三、战绩：从计算机直接进湿实验

### 3.1 12+ 靶标的泛化：10 个设计钓出 1 个纳摩尔

流水线产出的结合剂形态可以很不同：大多数是纯α螺旋的迷你蛋白，也可以强制做出纯β折叠结合剂（较罕见）。团队在 **12 个以上靶标**上验证泛化性，实验成功率远超预期：几乎所有情形下，**订购 10 个通过过滤的设计，至少能钓出 1 个纳摩尔级亲和力**的结合剂——对湿实验应用已是很好的起点（[【跳转到 19:06】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1146)）。

### 3.2 案例 1：阻断"产气荚膜梭菌毒素–克劳丁"结合，救回细胞

布法罗大学的合作者 Alex Vaknin 长期研究克劳丁（claudins，紧密连接蛋白）。产气荚膜梭菌（*Clostridium perfringens*）释放的毒素会结合克劳丁、寡聚成孔、杀死细胞。团队用 BindCraft 设计了阻断这一相互作用的结合剂，并借助 Martin Pacesa 此前"膜蛋白可溶化"的工作：固定毒素-克劳丁界面的"手掌"区表位、把其余部分做成可溶类似物，先在体外用可溶版本快速筛结合（如 Binder 12），再寄给合作者用野生型克劳丁验证——结合剂不仅结合毒素的同一位点，还能竞争该位点。最后的**细胞存活实验**显示：不同浓度的结合剂几乎能救回和文献中已优化的毒素抑制剂一样多的细胞（毒素通常杀死培养皿中约 75% 的细胞）。整个项目历时几周到几个月（[【跳转到 24:06】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1446)）。

![细胞存活实验：结合剂浓度依赖地救回被毒素杀死的细胞](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/01446.webp)

### 3.3 案例 2：AAV 衣壳重定向

Lennart 的博士主项目是改造**腺相关病毒（AAV）**——最主流的基因治疗载体，但生产难、用量大（跑遍全身只有小部分到靶）、免疫原性强（蛋白衣壳，基本只能一针）。团队的做法（与 Christian、日内瓦基因治疗平台的 Ben 合作）：先敲掉野生型 AAV 与细胞的所有相互作用（"沉默"病毒），再把 BindCraft 设计的结合剂装进衣壳，让它对只存在于特定组织（癌细胞、淋巴细胞等）的表面标志物重新"激活"。对结合剂的要求有三：要小、要能结合靶标、**N 端与 C 端要挨得近**（方便"即插即用"地装进衣壳，不必每次重调连接子）（[【跳转到 27:01】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1621)）。

![AAV 衣壳重定向：敲除天然相互作用的"沉默"病毒 + 装入设计的结合剂](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/01621.webp)

湿实验结果：带 GFP 基因组的重定向 AAV 在表达 PD-L1 或 HER2 的细胞系上表现出特异性（野生型病毒什么细胞都进）；所有结合剂**未经任何结合预筛选**、直接从计算机进病毒；其中一款 PD-L1 病毒在 HEK 过表达体系上已超越野生型，还能被抗 PD-L1 抗体竞争阻断——证明转导确实依赖设计的相互作用；395 号设计（迄今最优变体）对 PD-L1 过表达细胞真正有选择性（[【跳转到 39:57】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=2397)）。

![重定向 AAV 的 GFP 读出：设计病毒选择性感染靶受体表达细胞，野生型则到处进](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/02397.webp)


## 四、上手配置：三个文件走天下

### 4.1 靶标准备与裁剪

动手部分从"要一个结合 PD-L1 的结合剂"开始（[【跳转到 28:21】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1701)）：

1. **找结构**：去 PDB 找靶标的晶体/冷冻电镜结构；没有就退而求其次用 AlphaFold 预测结构。
2. **裁剪到结构域**：计算时间随体系大小增长，把结构裁到你真正关心的部分（比如 PD-L1 上与 PD-1 结合的两个 Ig 结构域），越小越高效。
3. **"不真实"的裁剪也可以**：得益于 ColabDesign 的辅助函数，BindCraft 能接受从三聚体里切出两个亚基、删掉膜蛋白整段跨膜区这类"非物理"输入；唯一要盯住的是**靶标在 AlphaFold 里的置信度是否仍然足够**——裁得太狠，AlphaFold 会"完全不知道发生了什么"，这会直接反映在靶标置信度上。

![从 PDB 结构裁出 PD-L1 靶标结构域](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/01746.webp)

### 4.2 热点残基：5 个起步，PeSTo 帮你找

在裁好的结构域上定义"想结合的残基"，有两种方式：让 BindCraft 自选（到处采样、尽量多出接触），或者**手动指定热点（hotspots）**——与很多工具"一个热点就够"不同，BindCraft 最好给 **5 个或更多热点**，接触优化效率才高。不知道选哪里？可以用 EPFL Dal Peraro 实验室的 **PeSTo** 网页服务器：输入蛋白结构，预测哪些残基最适合蛋白-蛋白/蛋白-配体/蛋白-离子相互作用（本例的 PD-1/PD-L1 界面残基就是直接从已知相互作用里抄的）。不给热点时，AlphaFold 有时能自己"领悟"，有时则到处乱采——这是"引导 vs 不引导"的权衡。

### 4.3 target / advanced / filter：三个设置文件

集群上装好 BindCraft 后，一次运行只需要三个文件（[【跳转到 32:44】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=1964)）：

1. **target settings（靶标设置）**——基础文件：所有路径、热点残基、结合剂长度、以及**最终设计数**（"我要多少个可直接进湿实验的设计"，程序会跑到凑够为止）。
2. **advanced settings（高级设置）**——鼓励阅读、不建议初期改动：里面是预调好的微调权重与采样步数；GitHub 上备有多套预设（多肽、困难靶标、柔性靶标、只要β折叠等），开箱即用。
3. **filter settings（过滤设置）**——**对应流水线的最后一步：把所有设计重新预测（回折），并决定按哪些指标过滤**。毕竟你只想把"大概率能成"的东西送进湿实验。默认过滤器就很好：结果太少可放宽，结果太好可收紧，只留真正高分的设计。

![target settings：路径、热点、长度与最终设计数](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/01984.webp)

![filter settings：回折重预测后按置信度指标过滤的判定面板](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/02059.webp)

写个小提交脚本、把三个文件一起提交即可。没有集群也可以先用官方 Colab notebook（慢，但适合理解概念），或选择已预装 BindCraft 的付费网页平台（如 Tamarind、Levitate）。

### 4.4 输出目录与排错向导

一夜跑完，输出分四个文件夹：**accepted**（通过全部过滤、理论上可直接订购的设计——最重要）、**mpnn**（回折前、尚未过滤的 MPNN 序列）、**trajectories**（序列优化前的原始轨迹）、**rejected**。排查失败时看两个 CSV：**failure.csv** 告诉你大多数设计因哪个指标、在哪个阶段被卡掉（排错起点）；**final_designs.csv** 存着所有通过筛选的好序列（[【跳转到 36:09】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=2169)）。

![输出目录：accepted / mpnn / trajectories / rejected 与排错向导](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/02169.webp)

## 五、进阶定制与实战经验

### 5.1 自定义损失函数：N/C 端距离与β折叠

在流水线上花过时间后，可以写自己的损失函数。例如 AAV 场景要求 N/C 端靠近：给"两端距离"加一项损失并做权重基准测试——权重越大，两端平均距离越短，方向就对了；结果里两端贴得很好的设计可以直接"即插即用"进衣壳（[【跳转到 38:24】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=2304)）。同理，启用**负螺旋度损失**（惩罚α螺旋）并把权重设为约 -2，就能得到几乎纯β折叠的结合剂。

![N/C 端距离损失的权重基准：权重越大两端越近](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/02304.webp)

### 5.2 靶标相关的成功率与预评估清单

不同靶标的计算成功率差异巨大：PD-L1 极好出"通过"的设计，有的靶标要大量采样才够送验。实操建议：**同时想好两三个靶标都试**，初期聚焦最出活儿的那个；结合剂**最优长度因靶标而异**，按不同长度分批跑、找到高效区间再集中采样。

选位点前先做**预评估**：疏水残基相互作用驱动结合——太多不特异、太少结合能不足，要恰到好处的混合；全亲水位点比疏水位点难打得多；结合位点里柔性残基（如赖氨酸）太多会棘手；**打结构化区域比打 loop 区容易，打单体比打多聚体容易**（裁剪得当、输入结构正确时多链也能做）。

### 5.3 诱导契合、flexible 设置与膜蛋白"砍树"

BindCraft 与扩散模型不同：每轮迭代**靶标与结合剂共折叠**——靶标也能适应结合剂（诱导契合），RMSD 变化因靶标而异。还可以用 **flexible 设置**主动屏蔽输入结构的部分区域，迫使 AlphaFold 少靠模板、多靠自己折叠，提高设计柔性。

另一个坑：AlphaFold 有时不"尊重"热点优化——尤其在有大疏水区时（比如输入膜结构，它总想结合跨膜区）。最好的办法是像砍树一样把膜蛋白的跨膜部分砍掉，只针对**胞外表位**设计、尽量删除疏水部分。

### 5.4 速度换质量：反馈循环的取舍

BindCraft 的反馈循环远不如扩散模型快（扩散模型几秒出一个设计），这是最常被抱怨的挫败点。但基准测试的结论是：**速度上的损失换来质量**——扩散模型通常要生成海量结构再过滤出少数能进湿实验的，而 BindCraft 是每个设计都更"贵"但更值得。


## 六、湿实验验证手册

### 6.1 表达纯化：250 mL 大肠杆菌就够

BindCraft 产出的迷你蛋白表达极好：标准大肠杆菌表达纯化、250 mL 培养物即可，通常每升能拿到几毫克甚至更多蛋白；纯化用亲和层析 + 尺寸排阻两步（[【跳转到 47:24】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=2844)）。

### 6.2 结合判定：SPR / BLI / FIDA 与 10 μM 阈值

BindCraft 论文的主力方案是 **SPR**（表面等离子共振）：纯化后的设计对阵靶标与非靶标，看 **10 μM** 下"结合/不结合"。10 μM 是按试管中常见浓度定的经验阈值，作为初筛起点不错。替代方案还有 **BLI**（生物层干涉）、无需固定化的 **FIDA**（流动诱导分散分析）或 pull-down——先拿到结合曲线再谈下一步（[【跳转到 48:09】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=2889)）。

![SPR/BLI 结合曲线：从"10 μM 结合/不结合"到定量亲和力](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/02889.webp)

### 6.3 特异性、寡聚与稳定性

- **位点验证**：找一个已知结合同一表位的竞争者做竞争实验（作者至今没遇到结合错位点的结合剂，但检查总没错）；对阵相似受体查脱靶。
- **寡聚行为**：不少结合剂在溶液中呈二聚体、却以单体形式结合——是有趣且常见的现象。
- **稳定性**：大多数结合剂稳定到"煮都煮不坏"；表面高负电荷使它们在低 pH 下也容易结晶。

## 七、未来方向与 Q&A 精华

### 7.1 缺的不是"判别器"，而是"亲和力预言家"

作者的展望 slide 点题（[【跳转到 50:00】](https://www.youtube.com/watch?v=8ihVV78pMA0&t=3000)）：AlphaFold 已能很好地区分结合剂与非结合剂，但**真正缺的是能预测亲和力的指标**——很多应用需要的可不只是中纳摩尔亲和力。同时需要"什么算命中"的社区标准：RFdiffusion 用阳性对照响应的 50% 定义命中；BindCraft 用"10 μM 下有结合信号"（部分新靶标没有对照可依）。洛桑公司 Adaptyv 与社区合作推出了一套易用、泛化的蛋白靶标基准集，供新设计方法做横向比较。

![未来展望：需要能预测亲和力的指标与统一的命中标准](assets/Getting%20Started%20with%20BindCraft：Designing%20Protein%20Binders/03000.webp)

### 7.2 新颖性高，但"不打 loop 区"是瓶颈

Q&A：BindCraft 设计的新颖性经 TM-score 对阵天然蛋白库与合成库检验后相当高（几乎不会重复造出同一蛋白），但共享特征是**很高的二级结构含量**——大多不与 loop 区相互作用（抗体恰恰偏爱打 loop 区），与高度预组织的二级结构元件作用时，结合动力学曲线往往不同。这是当前瓶颈之一。

### 7.3 临床化、皮摩尔亲和力与 avidity

- **进临床**：完全可能且已在发生。药企对这类"每个蛋白都是新的"模态有点发怵——抗体的开发应对策略积累了几十年；目前首批试验看起来不错，问题常出在**半衰期**而非免疫原性，只是数据集还太小。
- **重编程相互作用**：取决于你对系统的理解——知道哪条级联把受体推进信号状态，就能把目标写成几何约束或损失函数（激动剂 vs 拮抗剂的取舍）；不知道就无从引导。
- **膜蛋白裁剪**：序列不连续、却共同构成胞外结构域的片段，直接在 PyMOL 里删掉残基即可——BindCraft 能处理链断裂，极端裁剪也没问题。
- **皮摩尔亲和力**：抗体"自带"亲合力（avidity，多价结合加成），直接对比要小心；Fab/scFv/纳米抗体筛得好也能有高亲和力。对 BindCraft 初始设计做定向进化/计算亲和力成熟可以到皮摩尔，但**初始设计直接命中皮摩尔、且不加 avidity，作者还没见过**。

## 小结

- 管线 A 第三步的本质：**设计与验证必须分离**——用一套权重/模型生成，换另一套独立回折判定。
- BindCraft = 幻想设计 + ProteinMPNN + **换权重回折过滤**，端到端跑通"生成→验证→accepted"。
- ipTM/pAE/pLDDT 等置信度指标是判定语言；filter settings 就是这道闸门的阈值面板。
- 10 个通过过滤的设计 → 至少 1 个纳摩尔命中（12+ 靶标验证）；从计算机直接进病毒/细胞，无需结合预筛选。
- 配置只有三个文件（target / advanced / filter），排错看 failure.csv 与 final_designs.csv。
- 热点 5 个起步、靶标裁到最小、膜蛋白砍掉跨膜区、多位点分批试。
- 湿实验：250 mL 大肠杆菌、SPR/BLI/FIDA、10 μM 初筛、竞争实验验位点。
- 下一步的瓶颈：**能预测亲和力的指标**与统一的命中标准。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 回折验证（refolding） | 把设计好的序列重新交给结构预测模型折叠，检验是否与设计一致 |
| 可设计性检验（designability test） | 设计→配序列→重预测→对齐比较（TM-score/RMSD）的闭环 |
| ipTM | 界面 TM-score：衡量复合物中两条链相对摆放的置信度，0~1，越高越可信 |
| pAE / PAE | 预测对齐误差：残基间相对位置误差矩阵，界面处越低越好 |
| pLDDT | 逐残基置信度（0~100），判断局部结构可靠性 |
| 幻想设计（hallucination） | 从随机/松弛序列出发，以预测模型置信度为损失做梯度优化 |
| 松弛序列空间 / one-hot | 每位置用概率优化 vs 每位置唯一氨基酸的物理真实形态 |
| 热点（hotspots） | 手动指定、结合剂必须围绕其出接触的靶标残基，建议 ≥5 个 |
| filter settings | BindCraft 最终过滤（回折重预测后按指标判定）的阈值配置文件 |
| failure.csv / final_designs.csv | 排错向导 / 通过全部过滤的设计清单 |
| avidity（亲合力） | 多价结合带来的亲和力加成，与单价亲和力不可直接比较 |
| FIDA / BLI / SPR | 无需固定化 / 膜上干涉 / 表面等离子共振三类结合检测方法 |
