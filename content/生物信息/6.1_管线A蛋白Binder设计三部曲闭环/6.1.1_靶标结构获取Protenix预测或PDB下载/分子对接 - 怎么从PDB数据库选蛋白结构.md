# 从 PDB 数据库挑选蛋白结构：分辨率、共晶配体与 UniProt 捷径

> 视频来源：[分子对接 - 怎么从PDB数据库选蛋白结构](https://www.bilibili.com/video/BV1E64y1Z77W/)（B 站，13.5 分钟）

## 本讲要解决的核心问题（SCQA）

**背景**：做分子对接、网络药理学或蛋白建模，第一步都是拿到靶标蛋白的三维结构。到 PDB 数据库里一搜，随便一个经典蛋白（视频以 KRAS 为例）就有几百个结构。

**冲突**：同一蛋白有 340 个结构，解析年份、解析方法、分辨率各不相同，还有的结构缺残基、有的带配体、有的带突变——选错了结构，后面的对接和建模全都白做。

**疑问**：到底按什么标准挑？有没有比在 PDB 里逐个翻更快的检索办法？

**回答（中心思想）**：按「分辨率数值越小越好、结合位点残基必须完好、优先选带共晶配体的结构」这套标准筛选，并把 UniProt 的 Structure 栏当作快捷检索入口，就能快速锁定合适的靶标结构；批量需求再用 PDB 的 Advanced Search 解决。

## 一、在 PDB 里直接搜：340 个结构怎么下手

### 1.1 关键词搜索

把蛋白名字（KRAS）直接粘贴到 [RCSB PDB](https://www.rcsb.org) 的搜索栏里搜索，PDB 会返回所有包含这个关键词的结构——本例找出来 340 个。

![在 PDB 搜索 KRAS](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00076.webp)

做网络药理学或其他实验的同学，至少知道自己的蛋白名字或基因 ID，所以这一步没有门槛。

### 1.2 列表里的三列关键信息

结果列表的每一行都写着：**哪一年解析并上传**、**用什么方法解析**（X 射线晶体学还是 NMR）、**resolution（分辨率）**是多少。从这三列就能对每个结构的质量有个大概判断。

![搜索结果列表：年份、方法、分辨率](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00114.webp)

### 1.3 按分辨率排序

列表还可以按特点排序：按解析时间排（最老的在前，越往后离现在越近，也可以反过来），或按分辨率从最好到最差排——我们当然用后者。视频里按分辨率排序后，第一名是一个 **resolution 只有 1.011 Å** 的结构，而且是 2019 年解析的。

![按分辨率排序，最小 1.011 Å](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00164.webp)

## 二、看懂分辨率：数值越小结构越好

### 2.1 分辨率数值是什么意思

分辨率数值越大，分辨率越差、质量越差。PDB 官方有一个专门的科普页面（PDB-101 的 resolution 指南）解释这些数值的含义。

![PDB-101 分辨率指南页面](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00210.webp)

### 2.2 电子云密度随分辨率变模糊

同一结构在不同分辨率下的对比图最能说明问题：分辨率从 1～2 Å 到 2.7～3 Å，电子云密度越来越模糊。分辨率数值小的时候，能精确看到电子云密度区域里是什么原子；数值大的时候，只能看到分子的大致轮廓。这种模糊的结构我们可能不太信任——因为那个分子也可能是以另一种方式「塞进」电子云密度图的。所以一般选分辨率数值最小的。

![不同分辨率下电子云密度对比](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00285.webp)

### 2.3 陷阱：最小的分辨率可能缺结合位点残基

还有一个细节：整体分辨率最小的结构，有可能结合位点的一些**残基侧链缺失**了。所以在追求小分辨率数值的同时，还要检查结合位点的残基是不是都完好、没有缺失。

## 三、UniProt 捷径：一个页面看完所有结构

### 3.1 为什么去 UniProt

在 PDB 里逐个翻其实挺麻烦，也不知道该挑哪个。更高效的办法是去 [UniProt](https://www.uniprot.org) 数据库：把 KRAS 复制进去回车，选人类（human）的 KRAS 条目（[P01116](https://www.uniprot.org/uniprot/P01116)），进入这个 ID 的完整信息页。

![UniProt 的 KRAS 条目页](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00341.webp)

在页面左侧点 **Structure（结构）** 一栏，它会列出这个蛋白所有已知结构：第二栏是解析方法，还有分辨率，以及每个结构覆盖蛋白的哪一段序列、哪条链。往下拖动，就能快速对「这个蛋白有多少结构、分辨率分别如何」建立直观概念，挑分辨率最小的就行。

![UniProt Structure 栏列出全部已知结构](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00401.webp)

### 3.2 挑带共晶配体的结构

用 UniProt 找还有个好处：每点一个结构，左边就会显示它的 3D 结构。你可以看看里面有没有**共结晶的小分子**、有没有小分子结合在结合位点上——选一个带配体共结晶的结构，方便之后做对接时直接以它生成对接盒子。

![3D 预览窗口查看共晶配体](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00427.webp)

### 3.3 NMR 结构：多构象的用法

假如你想看这个蛋白的 NMR 结构——比如用它的 10 个或 20 个构象去做蛋白动力学模拟——在 UniProt 里也很方便：第二栏直接标明解析方法，拖到 NMR 那一段，右键点它就能跳到 PDB 里对应的结构页面（视频里打开的是 [6CC9](https://www.rcsb.org/structure/6CC9)）。

![NMR 解析的 KRAS 结构 6CC9](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00497.webp)

为什么有人想找 NMR 结构？因为 NMR 解析的结构不是一个构象，而是很多个构象。点开它的 3D report 会打开可视化窗口，注意里面写的 model——这是 10 个构象里的第 1 个；用鼠标旋转、缩放，或按向右箭头，就能看到构象在变化。把这些构象当成动力学模拟中不同时间点保留下来的构象，就可以做一个简单的动画来粗略模拟蛋白动力学。

![3D report：逐个查看 10 个 NMR 构象](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00514.webp)

### 3.4 Full report：一份完整质量报告

除了 3D report，还有一个 **Full report**，点开是一个 PDF——这个结构完整的质量报告。里面有大量结构质量信息：结构中包含哪些小分子、序列信息、二级结构信息，还有键长键角等。如果对晶体学解析比较了解，能从这个报告里找到很多对挑选结构有帮助的信息。

![6CC9 的完整验证报告 PDF](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00582.webp)

## 四、反向路径与批量检索

### 4.1 从 PDB 跳到 UniProt

上面的路径反过来走也行：在 PDB 搜出 300 多个结构后，随便点开一个，向下拉，会有一段信息告诉你这个蛋白的名字、有哪几条链、序列多长、来自什么物种，右下角还有它的 **UniProt ID**（视频里从 [6POZ](https://www.rcsb.org/structure/6POZ) 的详情页点进 UniProt），点击就能跳到 UniProt 页面，再同样去 Structure 一栏找结构。

![从 PDB 详情页跳转到 UniProt](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00655.webp)

### 4.2 Advanced Search：批量找结构

如果需要批量下载——比如批量下载 2019 年解析的所有结构——就用搜索栏下面的 **Advanced Search**：点 Deposition（入库时间）定义时间范围（2019 年之后，或 2010 到 2020 年之间）；如果已知蛋白的 UniProt ID，也可以在 ID/Keyword 里选 UniProt 选项，粘贴 ID 搜索，直接找到该蛋白的所有结构。

![Advanced Search 高级检索页面](assets/分子对接%20-%20怎么从PDB数据库选蛋白结构/00722.webp)

## 小结

- 同一蛋白在 PDB 里有几十到几百个结构，挑选标准比数量更重要。
- 分辨率数值（Å）越小结构越好；但要警惕分辨率最小的结构在结合位点缺失残基。
- UniProt 的 Structure 栏是最高效的检索入口：解析方法、分辨率、覆盖区段一页看完，还能直接 3D 预览。
- 做对接优先选带共晶配体的结构，可以直接以它生成对接盒子。
- NMR 结构自带多构象，可用来粗略模拟蛋白动力学；Full report PDF 提供完整质量信息。
- PDB 详情页与 UniProt 双向可跳转；批量需求用 Advanced Search 按时间或 UniProt ID 检索。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| PDB（RCSB PDB） | 收录生物大分子三维结构的公共数据库，结构以 PDB 格式存放 |
| resolution（分辨率） | 晶体结构精细程度的度量，单位 Å，数值越小越清晰 |
| 电子云密度图 | X 射线晶体学得到的密度图，原子模型就是「塞」进这张图里拟合出来的 |
| 共晶配体 | 与蛋白一起结晶的小分子；带共晶配体的结构可直接用于生成对接盒子 |
| NMR 构象（model） | NMR 解析的结构包含多个 model，对应多个构象 |
| UniProt | 蛋白序列与功能注释数据库，Structure 栏汇总该蛋白的全部已知结构 |
| Advanced Search | PDB 的高级检索，可按入库时间、UniProt ID 等条件批量筛选 |
