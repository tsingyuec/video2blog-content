## 本讲要解决的核心问题（SCQA）

**背景**：RNA 二级结构预测是结构生物信息学的日常操作——用 RNAfold 之类工具输入一条序列，返回一个点括号结构和一个 ΔG。多数教程到"最小自由能（MFE）结构越负越稳定"就停了。

**冲突**：讲者开宗明义地给出两个坏消息。其一，一条序列可能的二级结构以约 1.85^n 指数增长，在能量参数的不确定范围内挤着海量候选，MFE 结构的预测准确率长期只有 **40%–70%**；其二，MFE 折叠"不给任何可靠性指示"，就像只会说"明天晴天"的天气预报 [【跳转到 44:00】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2640)。

**疑问**：除了"最稳的那一个结构"，热力学模型里还藏着什么信息？我们怎么知道预测的哪一段可信、整个分子有多少种备选构象、又该拿哪一个结构当代表？

**回答（中心思想）**：把问题从"找一个最优结构"换成"给所有结构按玻尔兹曼权重求和"——也就是**配分函数（partition function）Z**。有了 Z，一次计算就能读出整套**系综（ensemble）指标**：**系综自由能 = −RT·ln Z**、每个碱基对的**配对概率**、衡量构象分散程度的**系综多样性**与逐位置的 **Shannon 熵**，并由此导出两种更聪明的代表结构——**MEA 结构**与**质心结构（centroid）**。质心结构的算法惊人地简单：把配对概率大于 0.5 的碱基对全部收进来。

## 一、RNA 二级结构：为什么值得单独预测

### 1.1 "结构"是分层的，本讲聚焦二级结构

"结构"在不同人眼里是完全不同的东西 [【跳转到 01:57】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=117)：做量子化学的人想的是金属离子配位、电子云与轨道；晶体学家要的是每个原子的 XYZ 坐标；做冷冻电镜或 FRET 的人关心几条螺旋之间怎么相对取向；而**二级结构**只问一件事——形成哪些**碱基对**、连成哪些**双螺旋**。所有层级都有效，选哪层取决于要回答的问题；而令人惊讶的是，仅凭二级结构这一层就能回答很多问题。

结构生物学的范式是"序列决定结构，结构决定功能" [【跳转到 03:50】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=230)，所以懂结构就离理解功能更近一步。

### 1.2 与蛋白质生物信息学的三点不同

对比蛋白质，RNA 结构生物信息学有三个特点 [【跳转到 04:12】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=252)：

- **字母表小**：只有 4 种核苷酸，同源搜索更难找到显著相似性；
- **蛋白质二级结构"无聊"**：只是问序列哪段在螺旋、哪段在折叠片，而 RNA 二级结构是**分子内部**的碱基配对交互，信息量完全不同；
- **三级结构数据稀缺**：1999 年时已知 RNA 三级结构屈指可数（而 PDB 里蛋白质结构已有数千个），如今虽有改善，但可用于统计的 RNA 结构仍远少于蛋白质。

### 1.3 两个功能实例：snoRNA 与 FMN 核糖开关

**snoRNA（小核仁 RNA）**分 H/ACA box 与 C/D box 两家 [【跳转到 06:08】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=368)，负责指导 rRNA 的转录后化学修饰：蛋白–酶复合体是"执行者"，snoRNA 是"导航"，rRNA 恰好结合进 H/ACA snoRNA 的**内部环**，修饰就精确发生在这里 [【跳转到 06:58】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=418)。想靠序列特征（box H、ACA 三个碱基）在基因组里找 snoRNA 毫无特异性，**真正把它们定义下来的是二级结构**——茎环的折叠方式。

![snoRNA 的茎环结构：rRNA 底物结合在内部环处，指导位点特异性修饰](assets/Ivo%20Hofacker：RNA%20secondary%20structures/00468.webp)

**核糖开关（riboswitch）**则不是非编码 RNA，而是 mRNA 5' UTR 里的**调控基序** [【跳转到 08:28】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=508)。以 FMN（黄素单核苷酸）核糖开关为例：它能折叠出可结合 FMN 的**适配体（aptamer）**结构；下游紧跟着一个带一串 U 的**终止发卡**。有 FMN 时适配体稳定、终止发卡形成，转录在编码区之前停下；没有 FMN 时 RNA 偏好另一种结构，终止发卡不形成，转录通读整条基因 [【跳转到 09:18】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=558)。这就是一个**基因开关**——同一序列两个构象，对应开与关两种命运，也自然引出"如何找新核糖开关、如何判断它在转录层还是翻译层调控"等生物信息学问题。

### 1.4 碱基对、同立体性与层级折叠

RNA 由核糖–碱基–磷酸骨架串成，Watson-Crick 型碱基对共六种：A-U、G-C 加上 RNA 中常见的 G·U 摆动对 [【跳转到 12:22】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=742)。为什么恰好是这六种？不是因为只有它们稳定（G·A 也能形成漂亮的氢键），而是因为**同立体性（isostericity）**：T-A 对与 C-G 对占据几乎相同的空间 [【跳转到 13:08】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=788)，把双螺旋里的 A-U 对抽掉换上 G-C 对，螺旋无需变形；硬塞进一个 G·A 对则必须扭曲螺旋、付出能量。这保证了六种标准碱基对在螺旋里**可互换**，也是二级结构可以被单独建模的化学基础。

![同立体性：标准碱基对占据相同空间，可在螺旋中互换而无需变形](assets/Ivo%20Hofacker：RNA%20secondary%20structures/00813.webp)

RNA 螺旋取 A 型（DNA 才是 B 型），主沟又深又窄，蛋白质无法像结合 DNA 大沟那样读出碱基序列——这就是为什么多数序列特异性 RNA 结合蛋白识别的是**未配对区域** [【跳转到 14:23】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=863)。

实验上 RNA 折叠是**层级式**的：先快速形成二级结构的螺旋，之后才组装三级结构（且常依赖镁离子）。关键原因在于**二级结构承载了从去折叠到折叠态的大部分能量**，三级结构贡献相对微弱 [【跳转到 16:51】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1011)。这个能量尺度的分离，正是"可以先预测二级结构"的物理许可。tRNA 是最好的例子：知道三叶草形二级结构，加上两处**共轴堆积**和 D 环–T 环之间的一处长程互作，就能推出标志性的 L 形三级形状 [【跳转到 18:19】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1099)。

![tRNA：三叶草二级结构加上共轴堆积与 D 环–T 环互作，即得 L 形三级轮廓](assets/Ivo%20Hofacker：RNA%20secondary%20structures/01124.webp)

### 1.5 形式化定义、假结与三种表示法

形式上，二级结构就是序列上的一个**碱基对集合**，但带四条限制 [【跳转到 19:09】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1149)：每个核苷酸至多配一对；只允许六种标准对；两个配对碱基之间要有最短间距；**排除假结（pseudoknot）**——不允许 i-j 与 k-l 两对交叉。

排除假结看似武断，却是动态规划能工作的命门：没有交叉对时，任何一对碱基都把结构**切成互不作用的内外两段** [【跳转到 20:24】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1224)。假结当然存在——最常见的是 H 型（一根螺旋茎上挂一个环-环互作），其次是"亲吻发卡"（两个发卡之间加互作）[【跳转到 20:59】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1259)。但预测假结在计算上要难得多（不限类型甚至 NP-hard），更要命的是我们对假结的**能量学知之甚少**，连最小环长都说不清 [【跳转到 21:33】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1293)。

![黑板图解：H 型假结与亲吻发卡——被标准模型排除的交叉配对](assets/Ivo%20Hofacker：RNA%20secondary%20structures/01288.webp)

表示法有三种 [【跳转到 22:36】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1356)：梯子状平面图（图：顶点=核苷酸，边=碱基对，骨架=磷酸）；把序列摆在圆周上、碱基对画成弧线的**圆弧图**（能这样画，说明二级结构是外平面图）；以及 ViennaRNA 包使用的**点括号记号**——未配对碱基记点、配对记一对匹配括号。没有假结意味着括号总是匹配的，而平衡括号串正是**树**的表达——所以 RNA 二级结构就是树，字符串算法（树编辑、树比对）可以推广过来比较结构。

## 二、能量从哪里来：按"环"分配的实验参数

### 2.1 本讲的核心一句话：不要假设 RNA 只有一种结构

在进入算法之前，讲者把本讲最重要的一条信息放在了表示法一节的结尾 [【跳转到 24:41】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1481)：**一条 RNA 序列可以有很多结构，我们经常不应该假设它只有一种结构**。表示结构系综最常用的工具就是**点图（dot plot）**：矩阵中每个点对应一个可能的碱基对，点的**面积正比于该碱基对在系综中形成的概率**；图底部是基态（native）结构的配对，上方散落的黑点则是所有备选构象 [【跳转到 25:31】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1531)。

![点图：点面积正比于碱基对在系综中的配对概率，黑点是基态之外的备选构象](assets/Ivo%20Hofacker：RNA%20secondary%20structures/01531.webp)

### 2.2 环类型与"最近邻"能量分配

把结构图按面切开，就得到**堆叠对（stacked pair）、内部环（interior loop）、凸起（bulge，单侧未配对的特殊内部环）、发卡环（hairpin）、多环（multi-loop，引出三条以上螺旋）** [【跳转到 26:21】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1581)。能量模型的做法是：**给每个环分配一份能量**。这个近似对大多数 RNA 相当不错，而能量数值来自**实验**——这在生物信息学里并不寻常（通常用训练集拟合参数）；如今结构数据够多，训练已成为替代方案，理想做法是两者兼用，因为实验不可能测遍所有内部环里的所有序列组合 [【跳转到 27:21】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1641)。

![环的类型：堆叠对、内部环、凸起、发卡环与多环——能量按环分配](assets/Ivo%20Hofacker：RNA%20secondary%20structures/01581.webp)

### 2.3 数量级直觉：一个堆叠 ≈ 五倍热能

查一张堆叠能量表：GC/UA 相邻堆叠的稳定性是 −2.4 kcal/mol，表中能量普遍在 −2 到 −3 kcal/mol [【跳转到 28:16】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1696)。这数字单独看没感觉，但 37 °C 下的**热能只有约 0.6 kcal/mol**——一个堆叠能稳定螺旋高达**五倍热能**。于是一个六对碱基、五个堆叠的螺旋几乎永远不会自发解链。

![堆叠能量表：−2.4 kcal/mol 的量级，约为 37 °C 热能的五倍](assets/Ivo%20Hofacker：RNA%20secondary%20structures/01696.webp)

### 2.4 参数怎么测：UV 吸收熔解曲线与二态假设

测参数最常用的手段是 **UV 吸收**：核酸在 260–270 nm 有吸收峰，且单链与双链吸收差别明显 [【跳转到 29:31】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1771)。设计一条可形成小螺旋的序列，升温让它解链，测吸收随温度的变化，就能反推出双链比例随温度的曲线；再做 **van't Hoff 分析**（1/T 对平衡常数取对数作图得直线）得到稳定性 [【跳转到 30:21】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1821)。这里有个隐含假设——**二态模型**：两条链要么结合要么分开，没有中间态。对两条短链这是好假设，但对更长的序列或复杂基序（如多环）就不再成立。

## 三、Nussinov 动态规划：MFE 预测的骨架

### 3.1 先数一数：可能的结构有多少

Zuker–Stiegler（1981）的 MFE 算法、Zuker 的次优结构、McCaskill 的配分函数与随机采样——一族算法全都建立同一个动态规划原理上 [【跳转到 31:30】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1890)。理解它最轻的入口是**数结构**：区间 i..j 的所有结构只有两类——第一个核苷酸未配对，或它与某个 k 配对（此时 i+1..k-1 与 k+1..j 各自独立成结构）；对所有可行的 k 求和，就得到递归 [【跳转到 32:20】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=1940)。数出来的渐近结果：可能的构象约以 **1.85^n** 增长——本质上是指数级的。

### 3.2 Nussinov 递归、填表与回溯

Nussinov 算法用一个玩具能量模型：**只给碱基对接能量**（如 G-C = −3，A-U = −2，G·U = −1），不考虑环 [【跳转到 34:00】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2040)。递归变成：E(i,j) = min( E(i+1,j)，min over k { E(i+1,k−1) + E(k+1,j) + 配对能量 } )，往三角矩阵里填表即可 [【跳转到 34:25】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2065)。讲者在黑板上用一个迷你序列演示：因最短环长限制，4–5 个核苷酸以下全是 0；第一次出现 −3（一个 G-C 对）；嵌套一个 G-C 后得 −6；填满全表后最优能量为 **−9** [【跳转到 35:10】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2110)。

![Nussinov 动态规划示例：三角矩阵自短序列向长序列填充，最优能量 −9](assets/Ivo%20Hofacker：RNA%20secondary%20structures/02135.webp)

表里只有**数值**，没有结构本身——要拿到结构必须**回溯（backtracing）**：从 −9 出发反向追问"这个 −9 从哪一格来"，逐步还原出未配对碱基与各层碱基对 [【跳转到 37:15】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2235)。复杂度：空间 O(n²)、时间 O(n³)（每格要对 k 求一遍最小值）[【跳转到 38:10】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2290)。

### 3.3 换上完整能量模型：四张表与 Turner 参数

把玩具模型换成按环分配的完整能量模型后，算法骨架不变，但配对时必须知道它**闭合的是哪种环**才能计价——于是需要四张动态规划表而非一张 [【跳转到 39:20】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2360)，复杂度仍是 O(n²) 空间、O(n³) 时间。用这套**最近邻 Turner 参数**算出的最优结构，就叫**最小自由能（MFE）结构** [【跳转到 40:10】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2410)。

为什么叫"最小**自由能**"？因为参数本身就是自由能：一种二级结构实际代表了一大群微观构象，熵项就藏在里面 [【跳转到 40:35】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2435)。这也意味着这些参数依赖外部条件——温度、离子环境等 [【跳转到 41:00】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2460)。

## 四、MFE 的天花板：40%–70%，以及"别依赖单一结构"

### 4.1 准确率有多少：看长度，也看怎么数

基准测试结果不一，但规律清楚 [【跳转到 41:30】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2490)：结构越长越难预测（构象数指数增长）；准确率口径也不同——有人把"只差一位的碱基对"也算对，理由是参考结构本身也不完美（很多来自序列分析推断）[【跳转到 42:20】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2540)。综合下来：约 100 nt 的短序列可期 **70%** 左右，1500 nt 的大概只有 **40%**（这里准确率指预测正确的碱基对占比）[【跳转到 43:10】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2590)。

![MFE 准确率基准：随序列长度从约 70% 跌向 40%](assets/Ivo%20Hofacker：RNA%20secondary%20structures/02515.webp)

值得安慰的是：即便预测"全错"，正确结构在能量上通常离 MFE 结构不远 [【跳转到 43:35】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2615)。问题在于**能量参数的不确定区间里挤着太多候选解**——这是一个**病态（ill-conditioned）问题**，而且序列越长越严重。

### 4.2 天气预报类比：预测必须自带可靠性

讲者给出的第一条对策掷地有声：**只要有可能，就不要依赖单一结构**——不要预测一个结构就说"这就是我的分子长这样" [【跳转到 44:25】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2665)。他用天气预报作比：现代天气预报不会只说"明天晴天"，而会说"明天下雨概率低于 5%"——**可靠性是指示的一部分**。生物信息学方法也应当如此，只报"最大概率的那一个、不管备选项"是不够的。

### 4.3 参数不是主因，模型假设才是

那么为什么不能再准一点？你也许会怪能量参数有误差——每几年确实都有一轮参数更新，但对基准准确率的提升**微乎其微** [【跳转到 45:26】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2726)。真正的原因在**模型假设本身** [【跳转到 46:16】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2776)：

- 只考虑二级结构：忽略假结、非标准碱基对与三维结构（三级能量虽小，也许足够翻转结构）；
- 参数在**标准条件**（37 °C、无镁离子）下测得——毫无生理意义，只是方便实验；细胞里的离子浓度、温度都可能不同；
- RNA 在细胞内会与蛋白质、小分子互作，它们都可能改变结构；
- **折叠动力学**：功能构象未必是热力学基态（这是后续讲座的主题）。

### 4.4 native ≠ ground state

"native structure（天然/功能结构）"是生物学家的用语：指**在细胞里执行功能的那个结构**，与它是否为基态无关 [【跳转到 47:31】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2851)。生物学家看到的是细胞内的 native 结构；而预测算法给出的是标准条件（1 M 钠、无镁）下的**基态结构**——两者本来就不必相同 [【跳转到 48:21】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2901)。既然如此，与其孤注一掷地押一个结构，不如把**整个结构系综**请回来。

## 五、配分函数：把整个系综装进一个数（本讲核心）

### 5.1 定义与玻尔兹曼概率

如何得到结构系综？答案是**看所有结构的配分函数，而不是只找最稳定的结构** [【跳转到 48:47】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2927)。配分函数是统计力学的基石——**所有热力学性质、所有平衡性质都能从它推导出来**。形式定义一句话：

> **Z = Σ over 所有结构 e^(−E(结构)/RT)**

化学家按摩尔计能量用 RT，物理学家按分子计用 kT，本质相同 [【跳转到 49:12】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2952)。有了 Z，任一结构出现的概率就是它的**玻尔兹曼概率**——玻尔兹曼因子除以 Z（Z 就是归一化常数）[【跳转到 49:37】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=2977)。能量越低的结构，权重越高，但**每个结构都有非零概率**：这就是"系综"的数学化身。

![配分函数：对所有结构按玻尔兹曼因子求和，是全部平衡性质的源头](assets/Ivo%20Hofacker：RNA%20secondary%20structures/02952.webp)

### 5.2 系综自由能 = −RT·ln Z

配分函数一旦到手，任何"依赖结构的量"的期望值都是**全结构的玻尔兹曼加权平均** [【跳转到 50:02】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3002)。而本条目主角登场——讲者在 50:31 一句话点题 [【跳转到 50:27】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3027)：

> **"整个系统、整个系综的自由能，就是对配分函数取对数。"**

即**系综自由能 F = −RT·ln Z**。与 MFE 的 ΔG（一个结构的能量）不同，系综自由能描述的是**全部构象合起来的热力学稳定性**：备选结构越多、越低，Z 越大，ln Z 越大，F 越负。对温度求导还能进一步得到熵等量 [【跳转到 50:27】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3027)。换句话说：**MFE 回答"最稳的构象有多稳"，系综自由能回答"整个热力学系综有多稳"**——这正是 RNAfold `-p` 输出里两个 ΔG 数字的本质区别。

![系综自由能：对配分函数取对数（× −RT），得到整个结构系综的自由能](assets/Ivo%20Hofacker：RNA%20secondary%20structures/03027.webp)

### 5.3 我关心的不是整个结构，而是某个特征：约束配分函数

很多时候我们既不关心 MFE 也不关心整个系综，只想知道**某个结构特征的概率** [【跳转到 50:52】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3052)：这个核糖开关会形成适配体吗？这个蛋白结合位点是不是单链（未配对）？形式化写法是**约束配分函数**：具有该特征的结构之和除以总配分函数 [【跳转到 51:42】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3102)。

直接按定义求和当然不可行——结构数轻松达到 10^25。但 Z 本身可以高效计算（见下节），而**许多约束也能顺着同一个递归加进去** [【跳转到 52:32】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3152)。讲者特别强调：这个概念在后面讲 RNA–蛋白、RNA–RNA 互作时会反复出现。

### 5.4 用动态规划算 Z：McCaskill 算法

计算 Z 的诀窍是**复用 Nussinov 的分解**：一个结构要么开头未配对（剩下部分独立），要么开头是 i–k 配对（内部与外部两段独立）[【跳转到 53:08】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3188)。对独立两段，配分函数**相乘**；于是 MFE 递归里取 min 的地方，配分函数递归全部换成"乘玻尔兹曼因子、再求和" [【跳转到 53:51】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3231)：

> **Z(i..j) = Z(i+1..j) + Σ over k： Z(i+1..k−1) · Z(k+1..j) · e^(−E(配对)/RT)**

完整环模型同理。这就是 McCaskill 算法：同样的 O(n²)/O(n³) 复杂度，把整个系综的权重算进一张表。

### 5.5 一个经典陷阱：递归必须"无歧义"

文献里常见另一种更"顺手"的分解（开头未配对、结尾未配对、首尾配对、或拆成两段……）[【跳转到 55:16】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3316)。用它算 MFE 完全没问题——同一个结构被多拆几次，取 min 的结果不变 [【跳转到 57:05】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3425)。但用它算**配分函数会错得离谱**：同一结构能沿不同位置切开，会被**重复计数约十次** [【跳转到 55:58】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3358)。所以配分函数必须使用**无歧义分解**——每个结构有且仅有一种生成方式 [【跳转到 56:36】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3396)。这也是后面上下文无关文法一节"歧义文法的概率不再是结构的概率"的同一件事。

### 5.6 配对概率：内外两个部分配分函数相乘

有了递归，每个碱基对的**配对概率 p(i,j)** 也能高效算出：除 i..j 区间内的配分函数外，再算一个"**区间之外**"的配分函数（把 i..j 从序列里挖掉，其余部分的 Z 记作 Z-hat）；两者结合即可得到 p(i,j) [【跳转到 57:11】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3431)。至此我们得到的是对热力学平衡的**严格描述**——所有可能构象都按正确权重计入（动力学是另一场讲座的事）[【跳转到 57:59】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3479)。

## 六、系综能回答什么问题

### 6.1 概率点图：一眼看出哪些配对可信

配分函数算出的配对概率最直观的呈现就是**概率点图** [【跳转到 58:24】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3504)。以 tRNA 为例：已知 native 结构的碱基对用彩色标出，其余黑点全是备选构象 [【跳转到 58:49】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3529)。有的 RNA 几乎只能形成一种结构（其余选择能量上差太多），预测自然可靠；有的 RNA 概率摊在许多构象上，单一预测就值得怀疑 [【跳转到 59:39】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3579)。代价是点图比一个结构更难解读——多花的功夫就是可靠性信息的成本。

![tRNA 概率点图：彩色点为 native 配对，黑点显示大量备选构象](assets/Ivo%20Hofacker：RNA%20secondary%20structures/03504.webp)

### 6.2 系综多样性：随机抽两个分子，它们的结构差多远

系综还自带一个全局指标。定义两结构的**碱基对距离**：一方有而另一方没有的碱基对数（可理解为"打开/关闭碱基对把 A 改造成 B"的最少步数，即编辑距离）[【跳转到 60:04】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3604)。想象一烧杯 RNA 分子，随机捞两条看它们结构的期望距离 [【跳转到 60:54】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3654)。妙处在于它可以直接从配对概率算出：随机两条结构中"一条有 i–j 对、另一条没有"的概率是 **p(i,j)·(1−p(i,j))**，对所有碱基对求和即得 [【跳转到 61:19】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3679)。这个**系综多样性**立刻告诉你：系综是被一个主结构统治（其余只差一两个对），还是真的有很多截然不同的构象 [【跳转到 61:44】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3704)。

### 6.3 局部可靠性：Shannon 熵与 5S RNA 实例

全局之外还要**逐位置**地问：预测的哪一段可靠？对序列上每个位置，它的配对伙伴分布（含"未配对"这一选项，记作 p(i,i)）构成一个概率分布，其 **Shannon 熵**衡量不确定性 [【跳转到 62:34】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3754)。把熵值用颜色叠画在结构图上即可读图。

讲者用 **5S 核糖体 RNA** 演示 [【跳转到 63:24】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3804)：native 结构已知（在核糖体里工作时的样子），但 RNAfold 给出了不同的结构。叠上熵着色后一目了然：**低熵区域**（"想不出还能怎么折"）恰好是与 native 一致的部分；**高熵区域**备选丛生——在点图上对应那根螺旋周围密密麻麻的黑点。结论不是"预测错了"，而是"这一段不可信、别依赖它"。

![5S RNA 实例：Shannon 熵着色区分"确定区域"与"存疑区域"](assets/Ivo%20Hofacker：RNA%20secondary%20structures/03804.webp)

## 七、更聪明的代表结构：MEA 与质心结构（centroid）

### 7.1 评分规则决定"最优"：一场预测比赛

MFE 结构其实是"最优结构"的一种——它自由能最好，因此也是**玻尔兹曼概率最高**的结构。但"最优"的判据不止一种 [【跳转到 65:13】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3913)。讲者把它变成一场比赛：出几条 RNA 序列，请大家提交预测，按规则给奖 [【跳转到 65:38】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3938)：

- **规则 A（全对或全错）**：结构完全正确得 1 分，有一个错就 0 分——那最佳策略是交 **MFE 结构**，因为它"整体正确"的概率最高 [【跳转到 66:03】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3963)；
- **规则 B（按碱基对计分）**：每猜对一个碱基对得 1 分——那你要交的是**期望正确碱基对数最多**的结构 [【跳转到 66:28】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=3988)。

### 7.2 MEA：期望正确碱基对数最大化

规则 B 的答案就是 **MEA（maximum expected accuracy，最大期望准确度）结构** [【跳转到 66:53】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4013)。对任一候选结构，它选中碱基对的配对概率之和就是"期望猜对的碱基对数"，最大化这个和即得 MEA [【跳转到 67:18】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4038)。解法依然熟悉：还是 Nussinov 动态规划，只是把碱基对的"能量"换成它的**配对概率 p(i,j) 当分数** [【跳转到 67:43】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4063)。

![MEA 与 centroid：把配对概率当作分数，用动态规划挑代表结构](assets/Ivo%20Hofacker：RNA%20secondary%20structures/04088.webp)

### 7.3 centroid：期望距离最小化，解法出乎意料地简单

另一类 MEA 结构是**质心结构（centroid structure）** [【跳转到 68:08】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4088)。设想评分标准换成：实验已知真实结构，按你预测与真实结构之间的**碱基对距离**打分——那你要交的是"与正确结构的期望距离最小"的结构。这正是 centroid 的定义：在所有可能结构中挑**居于中心**的那一个，它到其余所有结构的平均距离最小 [【跳转到 69:48】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4188)。

这个看起来很难的优化，答案却极其简单 [【跳转到 70:38】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4238)：目标函数里，入选的碱基对贡献 p(i,j)、未入选的贡献 1−p(i,j)——所以**只要 p(i,j) > 0.5，就该把它收进结构**（此时 1−p < p，收进来更划算）。centroid 就是"**把配对概率大于 0.5 的碱基对全部拿进来**"。

> **注（条目背景补充，视频未点名程序）**：本条目标题中的 `RNAcentroid` 对应的正是这里的**质心结构**概念——从配对概率一步计算 centroid；ViennaRNA 的 RNAfold 配分函数模式与 web server 均会输出 centroid / MEA 代表结构。

### 7.4 无假结保证与"没有免费午餐"

顺手收 0.5 以上的对，会不会收出一个非法结构（比如假结）？不会 [【跳转到 71:28】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4288)：若两对碱基的概率都大于 0.5，**必然存在至少一个结构同时含有这两对**（否则两对的概率加起来会超过 1），所以它们不可能交叉形成假结——centroid 必然是合法结构。

![两组构象簇之间的 centroid：落在没有任何结构驻留的"荒地"里](assets/Ivo%20Hofacker：RNA%20secondary%20structures/04313.webp)

但 centroid 有自己的软肋。把系综画成二维示意图：若结构分成两簇，centroid 会落在两簇**中间的"荒地"**——那里其实什么结构都没有 [【跳转到 72:17】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4337)。所以**没有免费午餐**：centroid 与 MEA 能在与它们判据一致的基准上加分，代价是在别的判据下更差 [【跳转到 72:33】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4353)。MEA 尤其喜欢"对冲下注"：两个可能结构各取一半，混合出一个本身毫无概率、但"无论哪个是对的都沾边"的结构 [【跳转到 72:38】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4358)。

## 八、系综的其它打开方式：次优结构与随机采样

### 8.1 Zuker 启发式：固定一个碱基对看最优

除了代表结构，我们还常想看看"亚军们"。Zuker 的经典做法：**固定某一个碱基对**，求该约束下的最优结构 [【跳转到 73:28】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4408)。这至多给出 n² 个结构，且选择偏任意——例如一条"两半各自可选"的序列本有 4 个近乎等优的结构，Zuker 法至多找到其中 3 个 [【跳转到 73:53】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4433)。

### 8.2 完整次优折叠：能量区间内一网打尽

更彻底的是**完整次优折叠（complete suboptimal folding）**：给定能量区间（如不确定度 3 kcal/mol），列出区间内**全部**结构 [【跳转到 73:53】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4433)。算法很高效（把回溯的判据从"是否最优"改成"是否落在能量区间内"即可），但区间内可能挤着上百万个结构 [【跳转到 77:50】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4670)。ViennaRNA 的 `RNAsubopt` 做的就是这件事——实践中它的速度上限往往是"往磁盘写结构的速度"。

### 8.3 随机采样：按玻尔兹曼权重转轮盘

想要"从系综里抽样"，就做**随机回溯（stochastic backtracing）**：回溯每一步的分支不再全要或取第一个，而是**随机选一个，选中概率正比于该部分结构对配分函数的贡献** [【跳转到 78:15】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4695)。这叫**轮盘选择**：把轮盘按各分支的（部分）配分函数分扇区，随机数落在哪一格就走哪条分支 [【跳转到 78:40】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4720)。整套回溯框架不变，只是把"选最优/全选"换成了"按权重抽签"。讲座末尾提到的**上下文无关文法**是同一件事的另一种描述语言（歧义文法会导致同一结构对应多棵语法树，配分函数被重复计数——呼应 5.5 的陷阱）[【跳转到 79:48】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4788)。

### 8.4 长序列怎么办：局部折叠（滑动窗口）

最后回到 Q&A 中的实际问题 [【跳转到 82:04】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4924)：整条折叠的最大对象是 RNA 病毒基因组（HIV 约 9,200 nt，最大的冠状病毒约 30,000 nt），再长就既算不动也不合理了——对动辄几十 kb 的 mRNA，算出的"基态"几乎注定不是 native 结构。原因很物理：翻译时核糖体一路碾过 RNA、沿途局部解链，**展开-重折叠持续发生** [【跳转到 83:19】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4999)。所以实用做法是**局部折叠**：用滑动窗口沿序列逐段计算，且窗口重叠部分可复用计算。顺带的练手项目：统计跨越内含子–外显子边界的预测碱基对占比 [【跳转到 84:17】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=5057)。

## 九、问答精选

- **长非编码 RNA 要按外显子分段折吗？** [【跳转到 80:38】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=4838) 不能假设子结构与内含子–外显子结构重合；但这是个可以轻松验证的好问题——预测一批 mRNA 的结构，数一数落在内含子内部与跨越边界的碱基对各有多少。
- **二级结构的参考数据从哪来？** [【跳转到 85:00】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=5100) 有实验支持的参考结构集（如 RNAstrand 数据库）；大分子如核糖体 RNA 有晶体结构；更经典的做法是**共变分析**——多序列比对中协同变异的列即碱基对的证据（很多 rRNA 二级结构在晶体结构出现之前就是靠共变推出来的）。
- **为什么标准条件不加镁？** [【跳转到 86:43】](https://www.youtube.com/watch?v=hrxPBdmm36w&t=5203) 纯粹是实验便利：缓冲液里没有镁时 RNA 降解更慢。生物学家关心的 native 状态本来就不等于这些试管条件。

## 小结

- **二级结构 = 碱基对集合**：六种 Watson-Crick 型对的**同立体性**让结构可互换、可单独建模；假结被排除是动态规划能工作的命门。
- **一族算法一个骨架**：Nussinov 动态规划——MFE 取 min、配分函数换成"乘玻尔兹曼因子求和"、MEA/centroid 把 p(i,j) 当分数，全部 O(n²) 空间、O(n³) 时间。
- **MFE 的准确率天花板约 40%–70%**，主因是模型假设而非参数；窄能量区间挤满候选解，是病态问题——**别依赖单一结构**。
- **配分函数 Z = Σ e^(−E/RT)** 是系综的化身；**系综自由能 = −RT·ln Z** 描述整个系综的稳定性，与 MFE 的 ΔG 是两个数字、两个问题。
- 系综一次性给出：**配对概率（点图）**、**系综多样性** Σ p(1−p)、逐位置 **Shannon 熵**——预测的可靠性读得出来。
- **MEA** 最大化期望正确碱基对数；**centroid** 最小化期望距离，且"p>0.5 全收"一步算出、自带无假结保证——但会"对冲下注"，两簇之间落在荒地。
- 次优与采样补全系综视图：Zuker 启发式、能量区间全枚举（`RNAsubopt`）、按配分函数加权的**轮盘选择**采样。
- 长序列改用**局部折叠**：核糖体本来就在沿途解链，窗口滑动才是贴近生理的问法。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 二级结构 | 序列上的碱基对集合；点括号记号 `(((...)))` 表示，本质是一棵树 |
| 同立体性（isostericity） | 标准碱基对占据等价空间、可在螺旋中互换——"只有六种对"的真正原因 |
| 假结（pseudoknot） | 交叉的碱基对（i-j 与 k-l）；标准模型排除它，动态规划才能分治 |
| MFE 结构 | 能量参数下最稳的单一构象；不携带任何可靠性信息 |
| 配分函数 Z | 所有结构玻尔兹曼因子之和；全部平衡性质由此导出 |
| 玻尔兹曼概率 | e^(−E/RT)/Z；结构在热力学系综中出现的概率 |
| **系综自由能** | **−RT·ln Z**；整个结构系综的自由能（对应 RNAfold `-p` 的 ensemble ΔG） |
| 约束配分函数 | 只统计满足某特征（如适配体形成、位点保持单链）的结构 |
| 配对概率 p(i,j) | 碱基对在系综中形成的概率；由区间内、外两个配分函数组合算出 |
| 系综多样性 | 随机两条结构的期望碱基对距离 = Σ p(1−p)；衡量构象分散度 |
| Shannon 熵 | 逐位置配对伙伴分布的不确定性；结构图上的局部可靠性着色 |
| MEA 结构 | 期望正确碱基对数最大的结构；Nussinov 框架 + p(i,j) 作分数 |
| 质心结构（centroid） | 与真实结构期望距离最小的代表结构；p>0.5 的对全收，自带无假结保证 |
| 轮盘选择 | 随机回溯的抽样规则：按部分结构对配分函数的贡献分配扇区 |
| `RNAsubopt` | 枚举能量区间内全部次优结构的 ViennaRNA 程序 |
