# DiffDock：把分子对接变成"生成 + 挑选"——置信度模型是怎么给位姿打分的

> 本文整理自 B 站视频[《DiffDock: Diffusion Steps, Twists, and Turns for Molecular Docking》](https://www.bilibili.com/video/BV1a3411X7K5/)（Valence Labs 讲座中字版，约 57 分钟，讲者 Gabriele Corso、Hannes Stärk 等，MIT）。这是 DiffDock 作者的亲讲：为什么分子对接要放弃"回归"、改用"扩散生成 + 置信度模型挑选"，以及那个给每个位姿打分的 `position_confidence` 到底是怎么训练出来的。

## 本讲要解决的核心问题（SCQA）

**背景**：分子对接是药物发现的基本问题——已知蛋白质结构和小分子，求小分子结合的三维位姿（pose）。传统方法靠"搜索算法 + 评分函数"，在盲对接（不给口袋位置）基准上成功率不足 2.5%；受 AlphaFold 启发的深度学习回归方法（EquiBind、TankBind 等）快得多，但准确性并没有真正提高。[【跳转到 01:50】](https://www.bilibili.com/video/BV1a3411X7K5/?t=110)、[【跳转到 03:44】](https://www.bilibili.com/video/BV1a3411X7K5/?t=224)

**冲突**：这不是模型不够大，而是范式错了。对接的"正确答案"天然是**多峰分布**：蛋白可能有多个结合位点，模型还有认知上的不确定性，会在多个位姿之间犹豫。回归模型最小化均方误差，只能输出分布的"平均值"——半个分子插进蛋白里、构象扭曲、原子自交的"物理笑话"就是这么来的。

**疑问**：既要快、要准、要物理合理，还要告诉用户"哪个预测最可信"，怎么办？

**回答（中心思想）**：DiffDock 分三步——先用 RDKit 固定分子局部结构，让扩散模型在"平移 × 旋转 × 扭转"的乘积空间上做 20 步反向扩散、采样出大量候选位姿；再用一个**置信度模型**（二分类器：这个位姿的 RMSD 是否小于 2 Å）给所有候选打分排序，取 top-1 或 top-5。这个置信度分数，就是各类管线里的 `position_confidence`。

## 一、老范式的两难：搜索太慢，回归"糊"

### 1.1 搜索 + 评分函数：盲对接成功率不足 2.5%

传统对接由两部分组成：搜索算法扫过数百万个候选位姿，评分函数给它们排序。计算昂贵不说，在不知道口袋的盲对接场景下往往直接失败。在标准基准 PDBBind 上，以"预测位姿与晶体结构的 RMSD 小于 2 Å"为成功标准，所有传统方法都低于 2.5%。[【跳转到 03:44】](https://www.bilibili.com/video/BV1a3411X7K5/?t=224)

![分子对接问题定义：给定蛋白与配体，求结合位姿](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00110.webp)

![传统方法在 PDBBind 盲对接上的成功率：全部低于 2.5%](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00224.webp)

### 1.2 回归范式为何注定失败：多峰后验与"平均位姿"

为什么 AlphaFold 式的回归方法搬过来就不灵？讲者给了一个漂亮的理论线索：对接的评测指标（"RMSD 落在 2 Å 内算成功"）在学习理论里叫**最小一致成本**——当 ε→0 时，它的最优估计收敛于**最大后验估计（MAP）**；而回归输出近似 MAP 的前提是分布**单峰**。盲对接的后验偏偏是**多峰**的：既有多口袋造成的"数学不确定性"，也有任务太难造成的"认知不确定性"。[【跳转到 06:14】](https://www.bilibili.com/video/BV1a3411X7K5/?t=374)、[【跳转到 07:29】](https://www.bilibili.com/video/BV1a3411X7K5/?t=449)

![评测标准"RMSD<2 Å"与最小一致成本：接近真值才算对](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00374.webp)

![对接后验的多峰性：蛋白可能有多个结合位点](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00449.webp)

多峰分布的"平均值"没有意义。视频展示的真实失败案例：模型在两个结合位点之间犹豫，回归输出把**半个分子塞进了位点、与蛋白发生冲突**；即使位点猜对了，不确定的构象也会被"平均"成扭曲的形状。[【跳转到 10:21】](https://www.bilibili.com/video/BV1a3411X7K5/?t=621)

![回归模型的失败案例：半个分子与蛋白冲突、构象扭曲](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00621.webp)

### 1.3 生成式思路：把所有模式都采出来

生成模型不做"平均"，而是**把每个模式都采样出来**——两个口袋就采两种位姿，都能采得很准，且没有自交或形变。剩下的新问题是：采出来的候选太多，研究人员只关心其中一两个——这就引出了本讲的第二主角：**置信度模型**。

## 二、在"位姿流形"上做扩散

### 2.1 位姿四要素：只扩散该扩散的

把小分子的所有原子坐标丢进 R^(3N) 直接做布朗运动式扩散，画面是荒谬的——太多自由度根本不归对接管。DiffDock 借鉴传统对接的智慧，把位姿拆成四条信息：

1. **局部结构**：键长、键角、手性、环结构——RDKit 已高精度确定，**保持固定**；
2. **位置**（平移，R³）；
3. **方向**（旋转，SO(3)）；
4. **扭转角**（每个可旋转键一个，共 m 维超环面 T^m）。

后三者才是扩散的对象。[【跳转到 14:00】](https://www.bilibili.com/video/BV1a3411X7K5/?t=840)

![位姿分解：局部结构（RDKit 固定）+ 位置 + 方向 + 扭转角](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/00840.webp)

### 2.2 乘积空间上的扩散与"纯扭转"的约定

在流形上做扩散，只需把"分数模型是欧氏空间中的向量场"改成"流形上的向量场"，再配各空间已知的**热核**（heat kernel）：平移是正态分布、旋转的切空间也是 R³（旋转向量，长度即角度）、扭转是超环面。细节上要把自由度"解开"：旋转约定**绕质心转**（与平移解耦），"纯扭转"定义为与刚体运动正交（在分子两侧施加相对旋转再做 RMSD 对齐，不引入动量）。这也是方法名"Steps, Twists, and Turns"的由来：在 R³ × SO(3) × T^m 的乘积空间上隐式扩散。[【跳转到 18:10】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1090)

### 2.3 分数模型与 20 步反向扩散

完整工作流：RDKit 嵌入局部结构 → 从平稳分布采随机位姿 → **分数模型**（E(3) 等变图神经网络，输入蛋白+配体联合点云）预测"平移向量 + 旋转向量 + m 个扭转更新"这组指令 → 应用更新，重复 **20 步**反向扩散，位姿逐渐聚拢到口袋。[【跳转到 20:40】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1240)

![DiffDock 工作流：随机位姿经 20 步反向扩散聚拢到结合口袋](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/01240.webp)

20 步在扩散模型里非常少——正因为只在对接相关的自由度上扩散，建模空间被大幅压缩。动画里每个随机起点各自独立地被"问"了 20 次"怎么更新"，绿色是晶体真值。[【跳转到 34:05】](https://www.bilibili.com/video/BV1a3411X7K5/?t=2045)

![反向扩散动画：多个随机起点在 20 步内聚拢，绿色为晶体真值](assets/DiffDock_%20Diffusion%20Steps,%20Twists,%20and%20Turns%20for%20Molecular%20Docking/02045.webp)

## 三、置信度模型：position_confidence 的来龙去脉（本讲核心）

### 3.1 怎么训练：自生成位姿 + 晶体真值标注

观众问得最多的问题就是"置信度模型到底是什么"。答案分三层：

1. **生成训练数据**：先训练好分数模型，然后在训练集的每个复合物上运行它，为每个复合物生成一批位姿；
2. **打标签**：把每个生成位姿与真实晶体位姿比对——RMSD 在 2 Å 以内记"正确"，否则记"错误"，得到二分类标签；
3. **训练分类器**：置信度模型的架构与分数模型几乎相同，只改了输出层，专门学习预测这个标签。[【跳转到 26:05】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1565)

### 3.2 怎么用：logit 当连续分数，取 top-1 / top-5

分类器虽然输出二分类，但它的 **logit 值是连续的**——直接拿来当置信度分数，就能给所有候选位姿排序：只要一个答案就取 top-1，要五个就取 top-5。要注意它在多口袋/对称场景下**仍返回多模态预测**：模型对两个口袋的好位姿可以同样自信，而不是强行压成单答案。[【跳转到 22:20】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1340)

### 3.3 它不是亲和力预测器——这正是优点

讲者反复强调：置信度模型**只判断"位姿对不对"，不预测亲和力**。Q&A 里一位计算化学家认为这是巨大优势：对接打分给出的"亲和力"在化学家眼里基本没有意义；而一个**独立的"位姿正确性"判断**非常宝贵——先确信拿到物理上合理的位姿，再在下游跑分子动力学、亲和力评分这些更贵的方法。"甚至计算化学家肉眼看位姿，也说不准哪个是最正确的物理位姿。"[【跳转到 52:34】](https://www.bilibili.com/video/BV1a3411X7K5/?t=3154)

> **背景补充**：这个置信度分数落到管线配置里，就是 `position_confidence` 字段（DiffDock 输出的 `position_confidence`，以及 `ligand_confidence` 等）。它与上一篇 RFdiffusion 博客里的 `plddt_mean` 异曲同工：**都用一个独立的神经网络给扩散生成结果打分，让下游只挑高置信度的候选**。

## 四、效果：成功率和选择性准确性（本讲核心）

### 4.1 严格基准：PDBBind 时间划分

PDBBind 收录了约 1.9 万个实验测定的蛋白-配体复合物。DiffDock 的评测非常克制：**按时间划分**（2019 年及更早训练、更新的测试）、训练/测试集**配体不重叠**、**相似蛋白也全部剔除**——防止"背题"。[【跳转到 27:20】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1640)

### 4.2 核心结果：更快、更准、更物理合理

- EquiBind、TankBind 等回归方法并没有比经典搜索法更准；"口袋预测 + 传统搜索"的组合也好一点，但与 DiffDock 之间仍有巨大差距；[【跳转到 28:52】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1732)
- 运行时间：比最准的基线**快 3 倍**（TankBind 单次前向更快，但以准确性为代价）；[【跳转到 30:07】](https://www.bilibili.com/video/BV1a3411X7K5/?t=1807)
- 物理合理性：DiffDock 的预测**从未出现自交**，空间位阻冲突也远少于回归方法——它们把原子位置"平均"成聚集结构的毛病，生成式采样天然没有。[【跳转到 38:39】](https://www.bilibili.com/video/BV1a3411X7K5/?t=2319)

### 4.3 选择性准确性：敢说"不确定"的价值

置信度分数还有一个漂亮的用法——**选择性准确性（selective accuracy）**：允许模型"弃权"。应用场景：100 个复合物，下游只处理 40 个，那就只处理置信度最高的 40 个（弃权 60%）。结果：在"只看最有信心的 40%"时，RMSD<2 Å 的成功率提升到 **77%**（随机挑选只是红线水平，基于真值的神谕是绿线，真实置信度模型是蓝线、紧贴神谕）。对从业者来说，"知道模型自己几斤几两"和"预测本身"同样值钱。[【跳转到 35:19】](https://www.bilibili.com/video/BV1a3411X7K5/?t=2119)、[【跳转到 37:24】](https://www.bilibili.com/video/BV1a3411X7K5/?t=2244)

## 五、边界与讨论（Q&A 精华）

- **ESM2 嵌入的贡献**：消融显示约 3~4% 的改进——有它更好，没有也远超以前的方法；
- **侧链柔性**：分数模型工作在**残基级别表示**上（"看骨架、推断侧链"），所以预测偶尔与侧链冲突（多数会被置信度模型过滤掉）；蛋白柔性完全未建模，从业者可用传统力场对 DiffDock 位姿做松弛，业内反馈尚可；
- **位姿聚集**：对称复合物（数据集只标注一个对称副本）和大蛋白的非对称多口袋场景下，多个位姿会聚集在不同结合位点——有些"错误"位姿看起来同样漂亮，可能是真实的第二结合口袋；
- **共价配体**：数据清洗只按 PDB 记录过滤，共价配体没有特殊注释，可能混入训练集；方法主要面向非共价结合；
- **口袋约束**：作为扩散模型，可以改先验/起点来"聚焦"已知口袋，或直接过滤落在口袋里的预测。[【跳转到 43:24】](https://www.bilibili.com/video/BV1a3411X7K5/?t=2604)

## 小结

- 对接评测（RMSD<2 Å）的最优估计收敛于 MAP，但盲对接后验是多峰的——回归输出"平均位姿"，物理上荒谬；生成模型把所有模式采出来才是正解。
- DiffDock 只扩散"位置 × 方向 × 扭转"，局部结构交给 RDKit 固定；E(3) 等变分数模型 20 步反向扩散，快（比最准基线快 3 倍）且物理合理（无自交）。
- **置信度模型 = 用"自生成位姿 + 晶体真值 RMSD<2 Å"标注训练的二分类器**，logit 即连续置信度分数，排序取 top-1/top-5——这就是 `position_confidence` 的出身；它只判位姿、不判亲和力，恰好是它的美德。
- 选择性准确性：弃权 60% 只处理最有信心的 40%，成功率升到 77%——置信度分数让"挑 40 个"变成了可优化的决策。
- 与 RFdiffusion 的"生成 + AF2 回折打分"对照：**两个领域的扩散模型用同一种方式解决"生成的结果信不信"**——再训练一个裁判模型，让分数决定谁进下游。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 盲对接（blind docking） | 不给口袋位置、只给蛋白结构和配体，求结合位姿 |
| pose（位姿） | 配体相对蛋白的位置、朝向与构象的组合 |
| 最小一致成本 / MAP | 评测指标的理论刻画：预测足够接近真值算成功，其最优估计收敛于最大后验 |
| 多峰后验 | "正确答案"不止一个（多位点/多构象），导致回归式平均失效 |
| 局部结构 | 键长、键角、手性、环结构，由 RDKit 固定，不参与扩散 |
| SO(3) / 旋转向量 | 三维旋转群；用向量表示旋转，长度即旋转角 |
| 扭转角 / T^m | 每个可旋转键一个角度，共 m 维超环面；"纯扭转"与刚体运动正交 |
| 分数模型 | E(3) 等变图神经网络，输出平移/旋转/扭转更新指令，驱动反向扩散 |
| 置信度模型 | 用自生成位姿+真值 2 Å 标签训练的二分类器；logit 作为 `position_confidence` |
| top-1 / top-5 | 按置信度取前 1/5 个位姿作为输出 |
| 选择性准确性 | 允许模型弃权时，剩余高置信预测的成功率（40% 处理量下达 77%） |
| ESM2 嵌入 | 蛋白语言模型特征，为分数/置信度模型贡献约 3~4% 提升 |
