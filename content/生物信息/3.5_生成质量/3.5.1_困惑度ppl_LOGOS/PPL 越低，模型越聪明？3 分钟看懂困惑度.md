## 本讲要解决的核心问题（SCQA）

**背景**：评价语言模型时最常见的数字之一就是困惑度（Perplexity，缩写 PPL），"PPL 越低，模型越好"几乎成了口头禅。

**冲突**：但这句口号不能照单全收——两个孤立的 PPL 数字可能根本不可比：测试文本、分词方式、上下文长度只要有一项不同，分数就失去了可比性。

**疑问**：PPL 到底在衡量什么？它是怎么算出来的？比较 PPL 时要满足什么前提？

**回答（中心思想）**：PPL 衡量的是模型沿真实文本逐 token 预测的"等效选项数"——把每个真实 token 的概率取倒数再求几何平均。在同一评测口径下，**PPL 越低，模型越能猜准真实文本的下一个 token**；但它不保证事实正确、数学解题与指令遵循，也不能跨口径直接比较。 [【跳转到 00:00】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=0)

## 一、PPL 在量什么：沿真实文本的猜词游戏

### 1.1 评测走的是"真实文本续写"，不是自由创作

给模型一句话："今天很热，我想喝一杯……"，接下来会是什么？模型给出一个概率分布：水 50%、茶 25%、咖啡 15%、其他合计 10%。假设原文接下来真的是"水"，评测时就看模型给"水"的概率。 [【跳转到 00:00】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=0)

![开场猜词游戏：模型对"接下来喝什么"给出的概率分布](assets/PPL%20越低，模型越聪明？3%20分钟看懂困惑度/00000.webp)

然后把原文里的"水"接回去，继续预测下一个词元（token）。注意：评测沿着真实文本往下走，而不是让模型自由编一个故事、再评价这个故事——这一点决定了 PPL 只反映"预测真实文本"的能力。 [【跳转到 00:25】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=25)

### 1.2 最简单的情形：概率均分时，PPL = 选项数

如果每一步都在四个选项之间平均分配概率，真实答案的概率就是 1/4，困惑度就是 4。你可以把它理解成：等效于在四个同样可能的选项里猜。 [【跳转到 00:25】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=25)

![均分概率的情形：真实答案概率 1/4，困惑度就是 4](assets/PPL%20越低，模型越聪明？3%20分钟看懂困惑度/00025.webp)

注意，这个"4"**不是候选词的实际数量**，而是"等效选项数"。

## 二、PPL 怎么算：取倒数、再取几何平均

### 2.1 一般情形：几何平均

看三个位置：模型给真实答案的概率分别是 1/2、1/4 和 1/8。把它们取倒数，得到 2、4、8；再取几何平均——也就是乘起来开三次方：2×4×8=64，64 开三次方等于 4。所以这段文本的困惑度是 4。 [【跳转到 00:50】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=50)

![三个位置概率 1/2、1/4、1/8：取倒数得 2、4、8，几何平均仍为 4](assets/PPL%20越低，模型越聪明？3%20分钟看懂困惑度/00050.webp)

### 2.2 与交叉熵损失：同一信息的两种表达

实际计算时，先对每个真实答案的概率取负的自然对数，再求平均——这就是平均交叉熵损失；最后取指数，就得到困惑度。所以在同一评测口径下，损失越低，困惑度也越低，两者是同一信息的两种表达。 [【跳转到 01:15】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=75)

## 三、三个常见误区

### 3.1 模型"自信" ≠ 困惑度低

关键是模型有没有把概率给对：如果真实答案是"水"，模型却几乎确定是"茶"、给"水"的概率很小，反而会受到很大惩罚。 [【跳转到 01:15】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=75)

### 3.2 只看训练损失会漏掉过拟合

训练时更值得看的是**没参与训练的验证集**：它能帮助判断模型是否学会了泛化。如果训练损失下降、验证损失却上升，就可能是在记忆训练数据，出现了过拟合。 [【跳转到 01:40】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=100)

![用验证集判断泛化：训练损失下降而验证损失上升，就是过拟合信号](assets/PPL%20越低，模型越聪明？3%20分钟看懂困惑度/00100.webp)

### 3.3 两个孤立的 PPL 数字不可直接比较

比较两个困惑度之前，先核对：是否同一份测试文本、同一种分词方式，还要看上下文长度和切分方法；同一个模型，看到的前文不同，分数也可能变化。因此不能只拿两个孤立的数字，就断言哪个模型更好。 [【跳转到 02:05】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=125)

## 四、PPL 的边界

困惑度衡量的是模型**对真实文本的预测表现**；事实正确、数学解题和听从指令，要靠别的评测方式来检查。 [【跳转到 02:05】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=125)

## 小结

记住一句话：**在可比的条件下，困惑度越低，模型越能猜准真实文本的下一个 token**。 [【跳转到 02:30】](https://www.bilibili.com/video/BV1pEa66NEP8/?t=150)

- PPL 评测沿真实文本逐 token 预测，不是评价模型自由编的故事。
- PPL 是"等效选项数"：概率均分时等于选项数；一般情形是"真实 token 概率取倒数后的几何平均"。
- PPL 与平均交叉熵损失互为指数关系，是同一信息的两种表达。
- 概率给错方向会被重罚——"自信"不等于低困惑度。
- 只看训练损失会漏过拟合，验证集表现才是泛化能力。
- 比较 PPL 必须同测试文本、同分词、同上下文口径；它也不覆盖事实正确与指令遵循。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 困惑度（PPL） | 模型沿真实文本逐 token 预测的"等效选项数"（真实概率取倒数后的几何平均），可比口径下越低越好。 |
| token（词元） | 文本的最小预测单位，评测时模型逐个预测下一个 token。 |
| 交叉熵损失 | 对真实答案概率取负对数后的平均值；取指数即得 PPL。 |
| 验证集 | 未参与训练的数据，用于判断模型是否真正泛化、有没有过拟合。 |
