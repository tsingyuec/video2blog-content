## 本讲要解决的核心问题（SCQA）

**背景**：抗体药开发进入候选筛选阶段后，往往有多条人源化抗体活性相当——单看活性已经分不出高下。

**冲突**：抗体是大分子蛋白，长期处于高浓度制剂环境容易出现聚集；聚集后安全性与有效性大打折扣。成药性还牵涉免疫原性（ADA 风险）、翻译后修饰、等电点等多个维度，全部靠湿实验评估又贵又慢。

**疑问**：能不能在湿实验之前，用序列与结构信息系统地评估并优化这些成药性风险？

**回答（中心思想）**：Discovery Studio 提供两条互补路线——基于序列（翻译后修饰位点预测与屏蔽、与上市/临床抗体比对读出 ADA 风险与回复突变设计）与基于结构（SAP 算法定位聚集区域并指导疏水→亲水突变、DI 可开发性打分、等电点计算），还能按成药性给活性相当的候选排序筛选。其中 SAP 与 DI 直接对应"聚集风险"的评估与优化。

## 二、序列路线（一）：翻译后修饰位点的预测与屏蔽

### 2.1 支持的修饰类型与"规则"视角

输入序列后，DS 能快速预测翻译后修饰位点，支持多种修饰类型：常见如脱酰胺位点、糖基化位点等 [【跳转到 03:39】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=219)。软件能给出"位点在哪"，但更需要关注的是"位点为什么出现在这个位置"——即修饰位点规则 [【跳转到 04:04】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=244)：规则 = 修饰类型 + 氨基酸组合 + 位置。

![PTM 位点规则窗口](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/00244.webp)

### 2.2 读懂规则语法：字母与括号

规则里的字母与括号各有含义 [【跳转到 04:29】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=269)、[【跳转到 04:54】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=294)：

- 单个字母 = 对应的氨基酸；
- X = 任意氨基酸；
- 中括号 [ ] = 可以是其中任意的氨基酸；
- 大括号 { } = 不能是大括号内的氨基酸；
- 小括号 ( ) = 其后重复的单元素。

结合案例：位点可以发生在 N 后接特定氨基酸组合的位置（如 NS、NG 这类组合）。

![规则语法：字母与括号的含义](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/00294.webp)

### 2.3 屏蔽策略：破坏规则 + CDR 区活性风险

真观测到修饰位点要改造时，它的位置无法改变，只能去破坏规则：比如序列中出现 NS，可以保留 N、把旁边的 S 突变成其他氨基酸，或者把 N 突变成别的氨基酸 [【跳转到 05:19】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=319)。注意：若位点在 CDR 区，突变可能影响活性——需要设计突变实验，找到"既避开修饰类型、又维持活性"的改造 [【跳转到 05:44】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=344)。

## 三、序列路线（二）：与上市/临床抗体比对，读出免疫原性风险

上一期以字幕所称"阿巴福单抗"（鼠源抗体）为例做了抗体人源化设计，它的临床 ADA（anti-drug antibody，抗药物抗体）风险高达 68.1% [【跳转到 06:42】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=402)。设计后的序列要评估：与已报道抗体比对，看与谁长得像、一致性/相似性多少、匹配抗体的 ADA 风险如何——由此判断新抗体的免疫原性、成药性风险状态 [【跳转到 07:07】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=427)。比对主要针对轻、重链可变区，结果直观呈现一致性、相似性、ADA 数据与抗体类型 [【跳转到 07:32】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=452)。

### 3.2 比对表怎么读

匹配序列之间大多数差异在 CDR 区——CDR 决定抗原结合的活性和选择性，CDR 的区别会拉低一致性（本例 85.7%，虽未到 90% 也已经很高）；除 CDR 以外其他区域的差异也有助于序列设计 [【跳转到 07:57】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=477)。视频以第二个抗体为例做深入比对——它的鼠源序列能从文献中直接提取（第一个抗体的鼠源序列只在较老的论文里、没有可直接复制的序列）[【跳转到 08:22】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=502)、[【跳转到 08:47】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=527)。

### 3.3 回复突变位点的序列学解读

比对逐列展示：参照抗体的鼠源序列、参照抗体的上市（或在临床）抗体序列、我们的候选序列、阿巴福单抗序列，以及 CDR 移植 + 回复突变考虑的三条序列 [【跳转到 09:17】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=557)、[【跳转到 09:42】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=582)。色块标记的位点揭示了回复突变的逻辑：

- **参照抗体**：某两位点鼠抗与上市抗体一致、但与 germline（种系基因）不同 → 说明做过回复突变，这些位点对活性比较重要；
- **阿巴福单抗**：对应位置与 germline 一致 → 无需回复突变；这样的位点即使与已上市抗体不一样，也不必重点关注 [【跳转到 10:07】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=607)；
- **"维持人源化 vs 回复突变"并行设计**：同一位点既保留维持人源化的版本，也设计回复突变版本，用活性实验衡量回复突变前后的差异 [【跳转到 10:32】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=632)、[【跳转到 10:57】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=657)；
- **组合与颗粒度**：H1 在 CDR graft 基础上回复突变 3 个位点，H2 在 H1 基础上再增加 2 个（3+2 组合）；设计颗粒度越细（如再加 H3、H4），排列组合越多，越能在"尽量少回复突变"与"维持活性"之间找到平衡——只有验证了"尽量少回复突变还能维持活性"的序列才比较理想 [【跳转到 12:37】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=757)、[【跳转到 13:02】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=782)。

序列比对不只用于人源化，也能反过来帮助后面的成药性评估 [【跳转到 13:49】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=829)。

## 四、结构路线（一）：SAP 预测聚集区域

### 4.1 为什么聚集：表面疏水相互作用

抗体作为大分子，长期处于高浓度溶液会有聚集趋势；聚集后安全性与有效性大打折扣，甚至带来安全隐患，所以要尽可能避免聚集风险 [【跳转到 14:08】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=848)。长期研究表明：蛋白聚集主要源于**蛋白表面的疏水相互作用**——在水溶液中，蛋白与蛋白之间的疏水相互作用让彼此距离拉近，导致聚集 [【跳转到 14:33】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=873)。

![聚集的根源：表面疏水相互作用](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/00848.webp)

### 4.2 SAP 算法：定位聚集区域与贡献氨基酸

由麻省理工（MIT）和诺华合作开发、验证的 **SAP 算法**，能很好预测抗体的聚集区域，以及区域中哪些氨基酸对聚集有较强贡献 [【跳转到 14:33】]。图中蓝色代表亲水区域、红色代表疏水区域 [【跳转到 15:05】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=905)；想降低蛋白疏水性，就把疏水性高的氨基酸突变成亲水类型氨基酸，降低聚集趋势、提高抗体稳定性 [【跳转到 15:30】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=930)。

![SAP：蓝色亲水、红色疏水](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/00873.webp)

### 4.3 DS 实操：prepare（加氢 + 制剂 pH）

聚集打分功能窗口直接输入蛋白即可，但输入前要先 prepare [【跳转到 15:46】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=946)：晶体结构下载下来的蛋白没有氢原子，需要加氢；而且蛋白在不同 pH 下表面电荷不一样——比如制剂 pH 一般在 6 左右，就按 6 做 prepare 再算 SAP；默认 7.4 与 6 的电荷状态不同，结果也会不同，为了贴合真实环境要按制剂 pH 准备 [【跳转到 16:11】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=971)。输出对每个氨基酸的疏水性打分：分数高 = 疏水性强 = 优化目标 [【跳转到 16:36】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=996)。

![DS 聚集打分窗口与 pH 设置](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/00946.webp)

### 4.4 案例：疏水→亲水突变与实验验证

案例：通过 SAP 找到抗体中疏水性强的氨基酸，把它们突变成亲水的赖氨酸；设计上既有单点突变，也有多点组合突变 [【跳转到 17:08】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1028)。实验验证：与野生型相比，单点和多点突变都能很好地提高稳定性，而且多点（如双点）突变提升效果更好 [【跳转到 17:38】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1058)。

## 五、结构路线（二）：DI 可开发性打分——从定性到定量

### 5.1 DI 的构成

SAP 不能很好地定量，所以在 SAP 基础上开发了 **DI 值**（可开发性打分）算法：综合疏水性打分与总电荷特性 [【跳转到 18:58】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1138)、[【跳转到 19:28】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1168)。其中 SAP 指算法中所有正得分氨基酸的打分总和——SAP 值越高疏水性越强，可开发性/稳定性越差；反过来说，DI 值越低，抗体稳定性越高。

![DI 的计算构成](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/01168.webp)

### 5.2 与真实溶解度的线性回归

验证案例：DS 的 DI 值打分与真实溶解度做线性回归——DI 值越高的抗体溶解度越低、DI 值越低溶解度越高，线性非常好，**R² 达到 0.8788** [【跳转到 20:08】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1208)。

![DI vs 溶解度线性回归](assets/【第四期】抗体成药性评估与优化｜Discovery%20Studio%20抗体药物设计与优化/01208.webp)

### 5.3 参照系：217 条上市抗体的 DI 分布

"DI 越小越好"，但小到什么程度需要参比对象：对 217 条已上市抗体做 DI 评估 [【跳转到 20:38】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1238)。饼图显示 [【跳转到 21:03】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1263)：**DI < 90 比较理想；< 100 可接受；> 100 的抗体占比较少**，聚集风险与稳定性因素要差一些——尽量选 100 以下、甚至 90 以下的抗体。此外 DI、溶解度与具体打分在三维空间上负相关：溶解度越高的抗体 DI 越低、打分越低 [【跳转到 21:28】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1288)。

### 6.2 pI 与清除率/半衰期

有研究证明，抗体的等电点与清除率有很好的线性关系：等电点越高的抗体清除率越高、半衰期可能越短；半衰期不是越长越好，要处在合理范围内——目前全长抗体 pI 在 8 左右比较合适 [【跳转到 22:10】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1330)。研究中更多关注 Fv 区：Fv 区什么样的等电点合适，需要对已上市、在临床抗体的分布做参照 [【跳转到 22:35】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1355)。

### 6.3 Fv 区 pI 分布：69% 落在 8~10

同样预测 217 条上市/临床抗体的等电点分布：**69% 在 8~10 之间**；小于 7、甚至大于 10 的都很少出现 [【跳转到 23:00】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1380)、[【跳转到 23:10】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1390)。一般推荐抗体 pI 在 8~10 左右比较合理；偏高或偏低就需要对应优化。至此，DS 在抗体成药性预测方面的功能介绍完毕 [【跳转到 23:35】](https://www.bilibili.com/video/BV1jN4y1Q71P/?t=1415)。

## 小结

- 成药性评估两条路线：**基于序列**（PTM 位点规则与屏蔽、上市/临床抗体可变区比对读 ADA 风险与回复突变设计）与**基于结构**（SAP 聚集预测、DI 可开发性打分、pI 计算）。
- 聚集的根源是表面疏水相互作用；SAP 定位聚集区域并量化逐氨基酸贡献，指导"疏水→亲水"突变（如突变成赖氨酸）；单点/多点突变经实验验证均能提高稳定性，多点组合提升更好。
- SAP 定性、DI 定量：DI = SAP 正分总和 + 电荷特性，与真实溶解度线性回归 R²≈0.8788；参照 217 条上市抗体，DI < 90 理想、< 100 可接受。
- pI 与清除率线性相关，全长抗体 pI≈8；217 条上市/临床抗体 Fv 区 pI 69% 落在 8~10。
- 多条候选活性相当时，可按 SAP 红色斑块（定性）与 DI/pI（定量）做成药性排序筛选。

## 字幕修正说明

- 口播中的"SIP/SP/SAIP"均指 **SAP**（空间聚集倾向）算法；"电压值/低压值/第二集"均指 **DI 值**；"可开关打分"为"可开发性打分"；"水源/属源"为"鼠源"；"tim line/基 line/吉木拉"为 **germline**（种系基因）；"F1 区/FA 区"为 **Fv 区**；"聚成/聚层"为"聚集"；"年度"为"粘度"；"积极性质"为"制剂性质"。
- 案例抗体名称以字幕"阿巴福单抗"为准，为上一期人源化案例中的鼠源抗体（临床 ADA 风险 68.1%）。
- DI 参照集规模口播先称 267、后称 217，正文按饼图口径取 217。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| SAP（Spatial Aggregation Propensity，空间聚集倾向） | MIT 与诺华合作开发的结构聚集预测算法：定位表面疏水聚集区域并量化逐氨基酸贡献 |
| DI（Developability Index，可开发性指数） | 在 SAP 基础上加入电荷特性的可开发性打分；越低稳定性/溶解度越好 |
| ADA（anti-drug antibody） | 抗药物抗体，免疫原性的直接体现；ADA 风险高的抗体临床效果打折 |
| 回复突变（back mutation） | 人源化时把框架区特定位点改回亲本鼠源残基以维持活性 |
| germline（种系基因） | 抗体可变区的胚系基因序列；与 germline 一致的位点无需回复突变 |
| PTM（翻译后修饰位点） | 蛋白质合成后化学修饰（脱酰胺、糖基化等）发生的位点，可用规则预测并通过突变破坏规则来屏蔽 |
| Fv 区 | 重链、轻链可变区组成的抗原结合片段 |
| pI（等电点） | 蛋白净电荷为零的 pH；与抗体清除率线性相关 |
