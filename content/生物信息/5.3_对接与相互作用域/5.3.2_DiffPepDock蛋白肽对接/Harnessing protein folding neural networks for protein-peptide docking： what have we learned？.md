# Harnessing protein folding neural networks for protein-peptide docking： what have we learned？

> 来源视频：[Harnessing protein folding neural networks for protein-peptide docking: what have we learned?（YouTube，62 分 33 秒，含现场问答）](https://www.youtube.com/watch?v=kB_kYNeCGaI) ｜ 本博客基于该视频的「图-字幕」视频演说图文稿整理，内容可核查。讲者所在实验室正是 Rosetta **FlexPepDock** 肽对接协议的开发团队；报告中人名/数字已按上下文校正，拿不准的保持中性表述。

## 本讲要解决的核心问题（SCQA）

**背景**：AlphaFold 等蛋白质折叠神经网络在"单体结构预测"上取得了革命性成功。与此同时，细胞里大量重要的蛋白-肽相互作用走的是另一条路：一条短的肽基序（motif）结合到蛋白的一个结构域上。

**冲突**：肽比结构域小得多、柔性大得多，序列数据库对肽的覆盖也极差——传统肽对接要么要求预先知道结合位点，要么算得极慢（高分辨率精修协议尤其慢）。

**疑问**：既然"肽 + 受体"合起来很像一个球状单体，那么**折叠神经网络能不能顺手把肽对接也解决了**？更重要的是——我们能从中学到什么？

**回答（中心思想）**：讲者实验室用三条互补路线回答了这个问题——①**肽侧**：片段库 + PIPER + FlexPepDock 精修；②**受体侧**：PatchMan 结构模板匹配；③**整体折叠**：AlphaFold 用聚甘氨酸 linker 把肽和受体连成一条链直接折叠。三条路线证明：**肽结合所需的构象信息，大量隐藏在单体结构数据里**；AlphaFold 最快、三条互补；而肽复合物不在训练集里，肽对接反过来成了检验"折叠网络到底学到了什么"的试金石。

## 一、把蛋白-肽相互作用看成"短信通信"

讲者开场给了一个贯穿全场的类比：细胞里的蛋白用 **SLiM（短线性基序，short motif sequence）**互相通信，就像人与人之间发短信——**非常短的消息，只要双方共享上下文，就能传递大量信息**。

- 肽基序 = 短信；肽结合结构域 = 收件人；
- 同一上下文里，短基序足以说明问题；**上下文一变，同样的基序可以有不同的含义**。

实验室的兴趣因此有两层：一是**基序与结合域相互作用的基本原理**，二是**上下文如何改变这种相互作用**。本报告讲的就是他们为建模这类相互作用开发的一系列工具，以及"如何一步一步往前走"。

![SLiM 短信类比：短基序-结合域像共享上下文的短信通信](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00051.webp)

## 二、高分辨率基线：Rosetta FlexPepDock

一切从他们的"看家协议"讲起：**Rosetta FlexPepDock**——对"已结合在蛋白上的肽"做高分辨率精修。

- **机制**：在 Rosetta 框架内，迭代优化肽的**刚体取向**与**主链构象**，用蒙特卡洛优化加能量最小化；迭代中先给一个很强的吸引项，再逐步恢复排斥项，最终得到堆积紧密的构象。
- **两种起点**：如果已知肽的大致结合构象，从附近构象出发精修即可；如果只知道结合位点，就用更扩展的协议、对起始构象做更密集的采样。
- **开发者**：协议由两位当年在组里的博士生开发，如今两人都已独立建组（一位在魏茨曼科学研究所）。
- **影响**：这个协议改变了肽对接领域的工作方式，各类衍生协议层出不穷，实验室几年前还出版过一本**汇集各种肽对接协议的书**。
- **一个亮点**：FlexPepDock 能**非常准确地定位热点残基（hotspot）**，即便不同预测的主链构象彼此不同——说明密集而精确的采样找到了正确的相互作用几何。

但它有三个硬限制：**准确但慢**（讲者原话：非常非常慢）；**肽的柔性受限**；**必须知道结合位点**。

![FlexPepDock 协议与"从局部精修走向全局对接的三条路线"总览](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00141.webp)

### 2.1 一个应用场景：免疫肽组学

FlexPepDock 还能处理**翻译后修饰（PTM）肽**。与从事免疫肽组学分析的 Merbl 实验室合作中，实验方发现了许多**因 PTM 而改变 MHC 结合偏好的肽**；由于这类修饰肽没有序列数据库可查，必须回到**结构层面**理解。

一个例子：**HLA-A2** 这类 MHC 有一个结合肽的疏水基序口袋；实验发现一条**赖氨酸被修饰的肽**照样结合 HLA-A2。用 FlexPepDock 建模后，**修饰肽的打分显著高于未修饰肽**——为实验观察提供了结构层面的解释。这也顺势成为机器学习的起点。

![HLA-A2 与修饰肽：建模打分为实验发现的 PTM-结合偏好提供结构解释](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00303.webp)

## 三、路线一（肽侧）：片段库 + PIPER + FlexPepDock 全局对接

FlexPepDock 快不起来，于是实验室思考如何把它**全局化**。关键的观察是：**肽结合在结构上"补全"了单体结构**——既然如此，也许蛋白建模的概念可以搬到肽对接上。第一条路线从**肽侧**看问题，由如今在牛津做博士后的组成员在当年开发。

### 3.1 核心观察与做法

- **观察**：肽虽然自由态没有确定结构，但结合态常有**保守的序列基序对应保守的结构基序**——这相当于在能量景观中"挖了一个凹坑"。那么，自由态系综里会不会**至少有一小部分构象**已经采样到了这个结合态构象？

![保守序列基序对应保守结构基序：相当于在能量景观中挖了一个"凹坑"](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00447.webp)

- **类比**：这与早期 Rosetta 协议的思想同构——**用代表局部序列偏好的片段来缩减构象空间**，把采样从所有二面角组合缩减为片段组合。
- **做法**：用 Rosetta 的 **fragment picker** 从单体库中抽取出与目标肽"序列相似 + 预测二级结构相似"的片段，建立**肽片段库**；然后用 **PIPER**（讲者多年合作者 Dima Kozakov 开发的高效对接协议）把**每个片段**在受体上穷举快速对接，得到能量景观；从景观里挑出值得跟进的构象，再用 **FlexPepDock 高分辨率精修**。

![肽片段库：深蓝为与真实结合构象相似的片段，黄为较差者——好构象在系综里](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00588.webp)

### 3.2 成绩与局限

- 能量景观呈现**漏斗形**：低能量区域能选出非常精确的构象。
- 在一个 **26 例肽-蛋白复合物**的数据集上，这个**全局对接协议**能把 **35% 的复合物**建到 **2 Å 主链 RMSD** 以内——"在此之前没有协议能做到"，与同期其他协议相比也表现相当好。

但有三个"卡脖子"场景：**抽不到好片段**（肽一长就可能抽不到）、**受体构象变化**（刚体对接处理不了）、以及后面会看到的**肽埋在蛋白内部**。于是有了第二条路线。

![PIPER-FlexPepDock 全局对接成绩：26 例中 35% 建到 2 Å RMSD 以内](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00645.webp)

## 四、路线二（受体侧）：PatchMan 结构模板匹配

第二条路线换成**受体视角**，由组内博士生 Alisa（音）用 **PatchMan** 协议实现。

### 4.1 第二个关键观察：自然界的"积木"

Serrano 实验室的研究显示：**肽-蛋白复合物的结合区局部，与某些单体蛋白的局部结构几乎一模一样**——尽管两者的整体折叠完全不同。局部相同、全局不同，说明**上下文重要，但局部模板是通用的**。

由此推出思路：**如果我知道受体，也许受体本身就能定义肽的构象**——去受体表面找互补的片段模板，模板就藏在单体或界面的结构库里。

### 4.2 协议流程

1. **切 patch**：遍历受体每个表面残基，取"该残基 + 邻近残基"构成局部 patch；
2. **找模板**：在 2014 年前后的结构库（**同时包含界面与单体**结构）中，用 **Master** 协议（极快、极高效的局部结构匹配工具）为每个 patch 找匹配；
3. **提取肽模板**：按距离截断，围绕匹配 patch 找**连续的肽段**并向两端延伸，得到肽的起始构象模板；
4. **换序列 + 精修**：把模板序列替换成目标肽序列，交给 FlexPepDock 精修，得到高分辨率模型，再择优。

![PatchMan：在结构库中为受体表面 patch 匹配局部基序并提取肽模板](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/00805.webp)

### 4.3 特点与成绩

- **完全不依赖序列**：既不看肽序列、也不限制受体结构来源，只看**主链几何**，因此能对受体表面做**极其密集的采样**——这也意味着可以用于**设计新的肽-蛋白相互作用**。
- **模板大多来自单体**：分析能量景观中打分 top 1% 且 ≤5 Å 的模板，**很多其实提取自单体结构而非界面**；这些模板的**序列同一性极低**——真正起作用的是结构，不是同源序列。这再次印证了"肽是单体的一部分"的视角。
- **能解片段法解不了的题**：一个非平凡构象案例中，PIPER-FlexPepDock 抽到的片段全部偏离 2 Å 以上、全部失败，而 PatchMan 命中了模板——top 10 模型里多数即使整体 RMSD 偏高，**motif 区的残基 RMSD 也很低**（只有末端螺旋略有偏移）。
- **对基序定义与肽长都不敏感**：PIPER-FlexPepDock 用"全肽"还是"只建 motif"成绩差异巨大；PatchMan 因为模板整体取自结构，**没有这种差别**。

![PatchMan 对"全肽 vs 仅 motif"不敏感，而片段法差异显著](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/01078.webp)

### 4.4 两个"解不了"与一个补救

- **肽埋太深**：一个四肽结合在蛋白**中心**的案例，PatchMan 完全找不到——因为自然界没有"四肽埋在球心"的单体模板。这类问题需要**肽与受体真正一起折叠**的协议，于是引出第三条路线。
- **结合位点被"关着"**：moesin 的 **FERM 结构域**案例（与噬菌体展示筛选出大量模板肽的合作团队长期研究）：FCA 位点被结合后，**FCB 位点会别构闭合**。用未结合态的晶体结构，PatchMan 找不到 FCB 处的肽位点——那里根本没有空隙。补救办法是：先用 patch 匹配定位肽的位置，再**允许受体骨架做最小化松弛**，就能得到很好的构象。很多相互作用都是这种"肽来了才开门"的类型。

## 五、路线三（整体折叠视角）：AlphaFold 用聚甘氨酸 linker 把肽“折”出来

前两条路线分别从肽侧和受体侧下手，第三条路线换了一个更大的视角。

### 5.1 假说与实验员的“先例”

- **假说**：肽在结构上补全受体，合起来像一个**球状单体**。
- **实验早有先例**：想解析低亲和力肽-蛋白复合物的晶体时，实验员会把肽用**聚甘氨酸 linker（polyglycine linker）**连到蛋白上——局部浓度高了，结晶概率随之提高。
- **in silico 的早期惨败**：实验室早就想把同样的思路搬进计算：蛋白序列 + polyglycine linker + 肽序列，交给折叠协议直接折。结果“失败得非常彻底”——**trRosetta、RoseTTAFold 这类协议根本不懂“polyglycine 密码”**，不明白 polyglycine 是不折叠的；Arne Elofsson 在结构域-结构域（domain-domain）问题上用同样的思路也报告了失败。

![polyglycine linker 假说：把肽接在受体上当作一条单体来折叠](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/01232.webp)

### 5.2 AlphaFold 为什么值得一试

AlphaFold 代码于 7 月中旬开放后，实验室**两三周内**就完成了全套分析——“这个领域必须快”。灵感来自一项研究（该研究作者曾在这个研讨班做过报告）：**AlphaFold 识别无序区（unstructured regions）的能力远超优化多年的 IUPred2**。既然它认得“无序”，也许就读得懂 polyglycine 密码。事实证明确实如此：

- **成功案例**：AlphaFold 清楚地知道 polyglycine 只是“连接物”，把肽放进了结合位点里非常准确的位置；
- **失败也可预知**：失败案例中它能“知道自己不知道”——成功时你成功，失败时你提前知道会失败，这能省下大量时间。

### 5.3 评测设置与成绩

- **数据**：先在 **14 例有基序 + 12 例无基序**的初始集上验证；再自建一个大型**非冗余**校准集——每条相互作用涉及**不同的结合域**，且逐一确认不含晶体接触等假象。
- **肽结构**：motif 集中 **75% 的肽**全原子模型建到 **3 Å 以内**——AlphaFold 既会折肽、也会折受体；
- **界面**：真正关心的是肽-受体界面的建模质量。按界面残基 RMSD ≤2.5 Å 统计：**motif 集约 90%，无基序集与大型非冗余集约 40%**（图中与 FlexPepDock 的表现对照）；
- **最重要的发现**：这一切发生在**肽完全没有 MSA（多序列比对）覆盖**的前提下——没有共进化信息，信号一定来自别处。

![AlphaFold 聚甘氨酸路线成绩：各数据集界面残基 RMSD 的累计曲线](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/01432.webp)

### 5.4 调参与两个“意外”

- **recycling（回收迭代）要多于默认值**效果才好；
- **polyglycine linker 与 separate chains（分链输入）各有擅长**：有的案例 linker 好、有的分链好，**两者合用**能覆盖最多相互作用；
- **pLDDT 是极好的代理指标**：pLDDT **高于 0.7** 的残基对应高分辨率、正确建模的区域，可用来指认 motif 所在；
- **模型是可用的**：对晶体结构与 AlphaFold 模型分别做 Rosetta **丙氨酸扫描**，预测的 **ΔΔG 相关性很好**——建模好的案例里真阳性多、假阳性/假阴性少，受体侧与肽侧都成立。也就是说，**AlphaFold 模型可以直接当实验结构的代理来用**。

![丙氨酸扫描：晶体结构与 AlphaFold 模型预测的 ΔΔG 高度相关](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/01641.webp)

### 5.5 甚至能建模结合诱导的构象变化

回到 moesin 的“闭合位点”问题：AlphaFold 能把**结合诱导的构象变化**也建模出来——**蓝色（未结合态）与绿色（结合态）**两种构象都能正确预测，包括“肽占用了蛋白原本一段链的位置、β 发夹被顶开”这类复杂情形。这引出一串问题：它是不是总预测结合态构象？能否用于动力学？已有研究开始通过**多样化 AlphaFold 预测**来挖掘构象变化。

### 5.6 “学到”还是“背下来”？

肽复合物不在训练集里，表现却这么好，自然要问是不是记忆：

- 数据集里若有**带 polyglycine linker 的融合蛋白**可以解释一切——检查后发现**模板基本不被使用**，有没有模板成绩都好；
- **翻译后修饰、配体的存在与否**几乎不影响表现；
- 结论：**远不止记忆**。肽对接也因此反过来成了**检验折叠网络学到什么**的验证集。

## 六、三条路线合起来看

三者的对比结论清晰：

- **都能用，对 motif 尤其好**；**AlphaFold 快得多**；
- **推荐用法**：先用 AlphaFold 快速出模型，再用较慢的协议精修；
- **三者互补**：AlphaFold 能解的 PatchMan 未必能解，反之亦然；大多数相互作用**至少能被其中一条路线捕获**。

![三条路线对比：各有擅长、互补覆盖，AlphaFold 最快](assets/Harnessing%20protein%20folding%20neural%20networks%20for%20protein-peptide%20docking：%20what%20have%20we%20learned？/01833.webp)

报告的总结可以归纳成四点：

1. 深度学习结构预测的成果，可以“用得很简单”地迁移到肽对接——本报告给出了**三条盲对接策略**，更多用法还在探索中；
2. 反过来，**肽对接是 AlphaFold 的验证场**：肽复合物不在训练集里，可以用它检验“学到还是背下来”；
3. “条条大路通罗马”——要**从不同视角**看，才能得到全貌；
4. 学到的三个事实：**肽在自由态系综中确实采样着结合态构象**（所以片段/模板协议可行）；**受体表面决定肽的结合构象**（patch 协议成立）；**单体折叠与肽-蛋白对接捕捉的是非常相似的东西**（AlphaFold 协议成立）。

边界也要讲清楚：以上结论适用于**能结晶、形成单一稳定构象**的相互作用；许多肽介导的相互作用不属于此类（也许永远结晶不出来）——如何把这套范式推广到更广的相互作用空间，是开放问题。未来工作包括：优化对接管线与打分学习以提速；与 Norman Davey 合作大规模表征 motif-结构域相互作用（既包括已知基序的，也包括从噬菌体展示数据出发、超越序列基序的**结构基序**）；结合结构与序列信息及深度学习学习特异性（含 PTM）；以及以 PatchMan 为起点走向设计。

## 七、问答精选（Q&A）

报告后的问答信息量很大，摘录要点：

1. **内在无序/多构象的肽怎么办？** 高亲和力相互作用也可能不取单一构象（例如针对无序区的高亲和力实验中，肽就没有单一结构）。同一肽在不同位点取不同构象时，至少一条协议能分别捕捉；真正的难题是**如何描绘“复合结合图景”**——没有单一结构，而是许多构象共同构成结合特征。
2. **MSA 之惑**（现场听众）：肽的 MSA 不重要，但 motif 注释本身靠保守性定义，矛盾吗？回答：**共进化信息不可能来自肽**——肽太短，显著比对要求极高的序列同一性，永远得不到足够深的比对；也不知道肽与受体的配对关系。讲者的猜想是：**肽结合构象是一个受限的构象集合**，AlphaFold 流程后段（局部结构模块）恰好能捕捉这类受限集合；需要多次 recycling 可能正是在强化这种信号。严格的验证（同一受体不同构象的案例）还没做。
3. **局部序列决定局部结构**：多年前的研究已证明局部结构基序定义**早期折叠中间体**；有些区域只由局部相互作用主导。只要 **10%~15% 的布居**采样到结合态构象，再加上足够高的局部浓度，结合伙伴就能把它“拉”过来——这正是别构。可以用片段系综的多样性沿链扫描“哪些区域像被剪出去做肽”；需要小心去除序列保守性带来的混淆；也可与 **ELM** 数据库对照，检验模型学到的东西。
4. **动态与别构**：改造 AlphaFold 看动力学仍是“婴儿步”。本组协议能同时建模 moesin 的开/合两态，理解开放时谁结合、闭合时谁结合；**加入肽后闭合构象的布居增加**（定性层面）；从结合态出发去掉肽会立刻回到未结合态，从未结合态加肽精修又会打开——但能量的定量还不够。
5. **热点残基 vs 结构残基**：现在的丙氨酸扫描把界面外残基固定，无法回答“突变是破坏了结合、还是破坏了肽的折叠”；FERM 结构域 FCA/FCB 位点的别构现象看得见、机制还不清楚。一个新方向是用**语言模型嵌入**在癌症突变数据上寻找**非局部效应**。
6. **能推广到小分子吗？** 可以想：用 patch 找“周围能塞下小分子”的区域；已有工作用 patch 找结合相似小分子的其他蛋白。本组的特点是**只看主链、不看表面**——这样采样更大，宁可广撒网“抓住稀有鸟”，之后序列可变、公共基底还在。
7. **寡聚体与晶体接触能否扩库？** 完全可以：同源寡聚体的紧密接触理应进入数据集；2014 年的数据集结构虽少、覆盖率却很高，新数据库结构更多、成绩更高；晶体接触、以连续片段形成紧密界面的异源复合物也都能用。这在某种意义上是“同源建模的扩展”，但讲者想强调的是：**它不只是同源建模**。

## 小结

- 蛋白-肽相互作用的本质类比是**短信通信**：短基序（SLiM）+ 结合域，上下文决定含义。
- **FlexPepDock** 是高分辨率精修基线：准、能定位热点残基，但慢、肽柔性受限、必须知道位点。
- 三条全局化路线对应三个视角：**肽侧**（片段库 + PIPER + FlexPepDock，26 例 35% ≤2 Å）、**受体侧**（PatchMan：模板多来自单体、只看主链、对肽长不敏感）、**整体折叠**（AlphaFold + polyglycine linker：motif 集 75% ≤3 Å、界面 90%~40% ≤2.5 Å、无肽 MSA 仍成功）。
- **AlphaFold 最快且互补**，推荐“先 AlphaFold、再精修”的工作流；肽无 MSA 覆盖仍成功，说明**信号不是共进化**。
- **pLDDT > 0.7 指认高分辨 motif 区**；模型经**丙氨酸扫描 ΔΔG** 验证可直接当实验结构代理；甚至能建模**结合诱导的构象变化**与别构。
- 肽复合物不在训练集里——**肽对接反过来是检验折叠网络“学到还是背下来”的试金石**。
- 边界：结论适用于能结晶、单一稳定构象的相互作用；无序肽的“复合结合图景”仍是开放难题。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| SLiM（短线性基序） | 肽中负责结合的短基序，“蛋白世界的短信” |
| FlexPepDock | Rosetta 肽-蛋白高分辨率精修协议，讲者实验室的看家工具 |
| PIPER | 高效蛋白对接协议（Dima Kozakov 开发），此处用于穷举对接肽片段 |
| 片段库（fragment picker） | 从单体结构中抽取“序列相似 + 二级结构相似”的肽片段，缩减构象空间 |
| PatchMan | 受体侧结构模板匹配：表面 patch → 结构库找模板 → 提取肽模板 → 换序列精修 |
| Master | 极快的局部结构匹配协议，用于在结构库中检索 patch 匹配 |
| polyglycine linker | 用聚甘氨酸把肽连到受体上“当单体折叠”，实验结晶与 in silico 折叠通用 |
| pLDDT | AlphaFold 逐残基置信度；高于 0.7 指认被高分辨正确建模的 motif 区 |
| interface RMSD | 肽-受体界面残基的均方根偏差，衡量界面建模质量 |
| 丙氨酸扫描 / ΔΔG | 逐残基突变为丙氨酸并预测结合能变化；用于验证模型可当实验代理 |
| IUPred2 | 长期优化的蛋白无序区预测工具，其无序区识别能力被 AlphaFold 大幅超越 |
| ELM | 真核线性基序数据库，可对照检验模型学到的基序知识 |
| 别构（allostery） | 一个位点的事件（如肽结合）影响远端位点（如另一位点开/合）的现象 |
