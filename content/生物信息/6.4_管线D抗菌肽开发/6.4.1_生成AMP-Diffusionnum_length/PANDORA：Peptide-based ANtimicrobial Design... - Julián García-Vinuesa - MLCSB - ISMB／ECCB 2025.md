# PANDORA：从 prompt 到强化学习优化的抗菌肽自动设计闭环

> 视频来源：YouTube《PANDORA: Peptide-based ANtimicrobial Design... - Julián García-Vinuesa - MLCSB - ISMB/ECCB 2025》，讲者 Julián García Espinosa（智利），ISMB/ECCB 2025 · MLCSB 分会报告，时长 9 分 27 秒。
> 本篇是「管线 D：抗菌肽开发」**生成步**（6.4.1）的第二支配套视频：与 HydrAMP 篇（条件 VAE 的"单模型生成机制"）互补，本篇看的是**生成步如何嵌进一条自动化设计流水线**——生成、多重过滤、实验反馈优化怎么串成一个闭环。

## 本讲要解决的核心问题（SCQA）

**背景**：抗菌药耐药性（AMR）不断加剧。WHO 已点名"危急"级别的病原体——鲍曼不动杆菌（*A. baumannii*）、铜绿假单胞菌（*P. aeruginosa*）等。这类威胁传统上靠传统药物发现来应对，但该流程**慢、贵、对患者甚至有毒性**，而且**对目标靶点的特异性差**。[【跳转到 00:25】](https://www.youtube.com/watch?v=cMswvAyJ628&t=25)

**冲突**：抗菌肽（AMP）是近年兴起的新路线——活性谱广、特异性高、耐药性低；但它有两个硬伤：**在患者体内降解快**，以及**合理化设计困难**。同时，"AI 设计肽"涉及的模型五花八门（生成、分类、预测……），研究者手工串起这些工具费时费力。[【跳转到 01:28】](https://www.youtube.com/watch?v=cMswvAyJ628&t=88)

**疑问**：能不能把"生成候选 → 多重过滤 → 计算机验证 → 实验反馈优化"整条链自动化，让 AI 自己跑完？

**回答（中心思想）**：能。讲者介绍 **PANDORA**——一个**多智能体（multi-agent）平台**：把生成、分类、预测模型组合成一支"虚拟科学家团队"，从用户的 prompt 出发，依次跑过**生成 → 分类过滤 → 预测过滤 → in silico 验证 → 强化学习优化**五个模块；整个系统随实验室反馈**持续自我更新**，且可随新任务换装新模型。[【跳转到 02:18】](https://www.youtube.com/watch?v=cMswvAyJ628&t=138)

## 一、背景：AMR 危机、传统流程的痛点与抗菌肽的优缺点

### 1.1 传统药物发现跟不上危机

WHO 点名的危急病原体（如鲍曼不动杆菌、铜绿假单胞菌）大多正被传统药物发现流程追赶。讲者总结这套流程的四个痛点：**慢、贵、可能对患者有毒、靶标特异性差**。这解释了为什么领域需要新范式。[【跳转到 00:25】](https://www.youtube.com/watch?v=cMswvAyJ628&t=25)

![WHO 危急病原体清单：鲍曼不动杆菌、铜绿假单胞菌等](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00025.webp)

### 1.2 抗菌肽：三个优点、两个短板

AMP 的优点：**活性谱广、特异性高、耐药性低**。短板：**体内降解快**（容易被酶解）、**合理设计难**（哪些序列能杀菌缺乏可靠的设计法则）。PANDORA 的目标正是补上"设计难"这一环。[【跳转到 01:53】](https://www.youtube.com/watch?v=cMswvAyJ628&t=113)

![抗菌肽的优点与缺点：广谱/高特异性/低耐药 vs 降解快/合理设计难](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00111.webp)

## 二、PANDORA 是什么：一支"虚拟科学家团队"

PANDORA 把**预测模型、生成模型、分类模型**装进一个多智能体系统——每个智能体像团队里的一位虚拟科学家，负责**创建、评估、优化**新的候选治疗分子。它有三个卖点：

- **自主生成**：给定任务后平台自动跑完整个设计流程；
- **省时省钱**：压缩研究者在"发现新药"上投入的时间与成本；
- **可适应、可扩展**：可以为新问题**创建新模型**或**改造已有模型**，覆盖新的研究前沿。[【跳转到 02:43】](https://www.youtube.com/watch?v=cMswvAyJ628&t=163)

一切的入口是一个 **prompt**：用户在 prompt 里描述想要的肽，系统据此决定**打开/关闭哪些模型**。[【跳转到 03:08】](https://www.youtube.com/watch?v=cMswvAyJ628&t=188)

![多智能体平台：预测/生成/分类模型组成虚拟科学家团队](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00139.webp)

## 三、五模块流水线：从生成到强化学习优化

### 3.1 模块一：生成模型——候选肽从哪来

流程第一站是**生成模型**。团队正在研究几种生成候选肽的最佳路线：**变分自编码器（VAE）、神经语言模型、扩散模型**等——这与 6.4.1 条目的主角 AMP-Diffusion（ESM2 潜空间扩散）同属"扩散生成"路线的候选。[【跳转到 03:33】](https://www.youtube.com/watch?v=cMswvAyJ628&t=213)

![生成模块：VAE、神经语言模型、扩散模型等多条路线在研](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00218.webp)

### 3.2 模块二：分类过滤——第一道闸门

生成出的肽先按 prompt 要求做**分类过滤**。讲者示例了五类可作第一道闸门的分类：抗细菌、抗革兰氏阳性菌等。模型做法：**预训练蛋白质语言模型**提供表征，再训练多种**经典机器学习算法**，用 ROC 曲线、精确率-召回率曲线和混淆矩阵选出最好的分类方案——从图上看进展顺利。[【跳转到 04:23】](https://www.youtube.com/watch?v=cMswvAyJ628&t=263)

![分类过滤：蛋白质语言模型嵌入 + 经典 ML，以 ROC/PR 曲线与混淆矩阵选型](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00282.webp)

### 3.3 模块三：预测过滤——第二道闸门

过了分类闸门后进入**预测过滤**：同样依 prompt 而定，按**半衰期**、用户要求的**比值**、或 **IC50** 等指标筛选。这里有个前瞻点：团队不只探索序列模型，还在尝试引入**几何深度学习**（以三维结构为输入的深度学习），比较哪条路线最好。[【跳转到 05:13】](https://www.youtube.com/watch?v=cMswvAyJ628&t=313)

![预测过滤：按半衰期/IC50 等指标筛；序列模型之外还在引入几何深度学习](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00328.webp)

### 3.4 模块四：in silico 验证——让物理化学"复核"

第三道闸门是**计算机验证**，思路直白：如果预测模型说这条肽有活性或亲和力，就用**分子对接**（受限对接、无受限对接等多种方式在探索）或**分子动力学（MD）**复核，看结果是否与预测一致——多一层独立证据。[【跳转到 05:38】](https://www.youtube.com/watch?v=cMswvAyJ628&t=338)

![in silico 验证：分子对接与 MD 复核预测模型的结论](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00339.webp)

### 3.5 模块五：强化学习优化——会自我改写的终点

流水线终点是**强化学习模型**：拿到一条潜在的抗菌肽（供湿实验用）后，还能继续修改这条序列——目标是**提升活性、降低毒性**；修改动作包括对蛋白序列做**插入、删除、替换或交换**。这一模块之所以是"会变动的模型"，是因为团队会**把实验室（wet lab）的信息整合进来并更新模型**——这正是"强化"的来源，让平台越用越好。[【跳转到 06:28】](https://www.youtube.com/watch?v=cMswvAyJ628&t=388)

![强化学习优化：对序列做插入/删除/替换/交换，并整合湿实验反馈持续更新](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00398.webp)

### 3.6 总览：一条从输入序列出发的闭环

收尾总览：PANDORA 五个模块串成"输入序列 → 分类/回归模型过滤 → in silico 验证预测结论 → 生成更好的序列"的闭环；团队计划通过**实验室概念验证**检验整个平台。[【跳转到 06:53】](https://www.youtube.com/watch?v=cMswvAyJ628&t=413)

![PANDORA 五模块总览：生成 → 分类 → 预测 → in silico → 强化学习](assets/PANDORA：Peptide-based%20ANtimicrobial%20Design...%20-%20Julián%20García-Vinuesa%20-%20MLCSB%20-%20ISMB／ECCB%202025/00436.webp)

## 四、问答：为什么是"多智能体"而不是固定工作流

现场唯一提问直击架构：**为什么用多智能体系统？用普通的参数化工作流不行吗？**（因会场收音问题主持人复述了一遍）讲者的回答划清了模块的"动"与"不动"：**分类模型和回归模型是固定不动的**；持续更新的是**生成一侧——强化学习等模块**。换句话说，智能体的意义在于把"会随实验反馈自我改写的部分"和"稳定的打分工具"分开管理，前者不断进化、给用户产出更好的肽。[【跳转到 08:26】](https://www.youtube.com/watch?v=cMswvAyJ628&t=506)

## 小结

- **痛点**：AMR 危急病原体（鲍曼不动杆菌、铜绿假单胞菌）面前，传统药物发现慢、贵、有毒、特异性差。
- **AMP 的一体两面**：广谱/高特异性/低耐药 vs 降解快/合理设计难——设计难正是 AI 的切入点。
- **PANDORA = 多智能体平台**：生成、分类、预测模型像"虚拟科学家团队"一样协作，自主跑完设计流程，省时省钱、可换装扩展。
- **五模块闭环**：prompt 驱动 → 生成（VAE/语言模型/扩散在研）→ 分类过滤（蛋白 LM+经典 ML）→ 预测过滤（半衰期/IC50/几何深度学习）→ in silico 验证（对接/MD）→ 强化学习优化（插入/删除/替换/交换 + 湿实验反馈）。
- **架构取舍**：打分工具（分类/回归）固定不动，生成与强化学习一侧持续自我更新——这是"多智能体"区别于固定工作流的核心。
- **下一步**：以实验室概念验证检验平台；对本管线（6.4）而言，它演示了生成步（AMP-Diffusion 等）在完整 AMP 开发流程中的位置与上下游。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| AMP（antimicrobial peptide） | 抗菌肽；广谱、高特异性、低耐药，但体内降解快、合理设计难 |
| 多智能体系统（multi-agent） | 多个 AI 模型像虚拟科学家团队一样分工协作、共同完成设计任务 |
| prompt | 用户输入的任务描述；决定平台打开/关闭哪些模型 |
| 生成模型 | 产出候选肽序列的模型；候选路线含 VAE、神经语言模型、扩散模型（如 AMP-Diffusion） |
| 分类过滤 | 第一道闸门：用蛋白语言模型嵌入 + 经典 ML 判定抗菌谱等类别 |
| 预测过滤 | 第二道闸门：按半衰期、比值、IC50 等回归指标筛选；几何深度学习在研 |
| in silico 验证 | 用分子对接（受限/无受限）与分子动力学在计算机里复核预测结论 |
| 强化学习优化 | 对候选序列做插入/删除/替换/交换以提升活性、降低毒性，并随湿实验反馈更新模型 |
| 概念验证（proof of concept） | 用真实实验检验平台端到端能力的关键下一步 |
