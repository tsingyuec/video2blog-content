## 本讲要解决的核心问题（SCQA）

**背景**：如果你有一个蛋白质的 3D 结构——天然解析的、AlphaFold 预测的、或 RFdiffusion 从头生成的骨架——想优化它的序列：比如提高稳定性、改善表达量，或者为一个全新设计的骨架寻找合适的氨基酸序列。

**冲突**：命令行版 ProteinMPNN 对纯新手门槛不低；而且从头设计的骨架常常「能折叠但不好用」——表达量低、容易聚集沉淀。

**疑问**：能不能在网页上点几下就完成逆折叠，还能针对「可溶性」专门优化？

**回答（中心思想）**：可以。纽普生物开发的在线工具把 **ProteinMPNN 算法**（通用版）和它的**可溶性蛋白特化版本 SolubleMPNN** 打包成图形化流程：上传结构 → 调参数 → 一键生成 → 读三个关键指标 → 批量导出 FASTA。本讲把每个参数的含义与取值逐项讲清 [【跳转到 00:05】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=5)。

## 二、参数逐项讲清

### 2.1 模型版本与序列数量

- **模型版本**：新手直接用默认 **v_48_020**；如果是低分辨率冷冻电镜结构，可选 **v_48_030**；想要高度还原天然序列，选 **v_48_002** [【跳转到 00:50】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=50)。
- **生成序列数量**：1~10 条，一次性生成多条，方便后续筛选最优序列。

![模型版本选择：v_48_020 / 030 / 002](assets/双模型%20ProteinMPNN%20可视化教程｜通用%20+%20可溶性模型，零基础一键逆向设计蛋白序列/00050.webp)

### 2.2 采样温度、骨架噪声与种子

- **采样温度**：控制序列多样性。0.1 属于保守值，序列不会突变过于激进；想要更多差异化序列，可以调高至 0.3 到 0.5。
- **骨架噪声**：给 3D 骨架加扰动。新手初次设计直接填 0，使用原始骨架；需要拓展突变库时再调高 [【跳转到 01:15】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=75)。
- **种子（seed）**：填 0 代表每次随机生成；如果你需要重复实验、复现相同序列，填写固定数字，比如 721。

![温度、骨架噪声与种子设置](assets/双模型%20ProteinMPNN%20可视化教程｜通用%20+%20可溶性模型，零基础一键逆向设计蛋白序列/00075.webp)

### 2.3 排除氨基酸与两个高级模式

- **排除氨基酸**：勾选后，生成序列不会出现对应氨基酸——比如去除半胱氨酸（C）、避免二硫键，按需勾选。
- **CA-only 模式**：仅读取蛋白 Cα 骨架原子，适合冷冻电镜的低分辨率、残缺骨架；注意它**不能和可溶性模型一起勾选**。我们从头设计骨架就选择这个模式 [【跳转到 01:40】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=100)。
- **可溶性模型 SolubleMPNN**：用于提升蛋白水溶性、减少表达聚集，做可溶性改造时直接勾选。

![CA-only 与 SolubleMPNN 高级模式](assets/双模型%20ProteinMPNN%20可视化教程｜通用%20+%20可溶性模型，零基础一键逆向设计蛋白序列/00100.webp)

### 2.4 JSON 约束与 PSSM 进化约束

- **约束与偏置（JSON）**：精细化定点控制，适合有特定改造需求的用户——可以固定催化位点不突变、对称蛋白强制同源残基、分链禁止特定氨基酸。新手第一次使用可以全部留空，不填写任何 JSON [【跳转到 02:05】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=125)。
- **PSSM**：多序列比对（MSA）进化约束，搭配同源序列使用，能保留蛋白原有功能、减少有害突变；如果是全新 de novo 从头设计蛋白，直接全部默认、不用填写。
- **最大序列长度**：默认 20 万，常规蛋白无需修改。

全部参数设置完成后点击提交设计，点击清除会重置所有参数。

### 3.2 三个筛选序列的关键指标

- **score**：仅对目标改造链的适配打分，数值越低越稳定；
- **global score**：整条复合物所有链综合打分，做多聚体蛋白重点看这个；
- **序列恢复率**：和天然序列一致残基的占比，数值越高突变越少，越容易保留原有蛋白功能 [【跳转到 02:31】](https://www.bilibili.com/video/BV1Fh3x6MEV2/?t=151)。

## 小结

- 该在线工具把 ProteinMPNN（通用）与 SolubleMPNN（可溶性特化）打包成图形化逆折叠流程，输入只需 PDB 或 mmCIF。
- 模型版本按场景选：默认 v_48_020，低分辨率冷冻电镜 v_48_030，高度还原天然序列 v_48_002。
- 想要差异化序列就调高采样温度（0.1 → 0.3~0.5）或骨架噪声；要复现就固定种子（如 721）。
- CA-only 模式适合低分辨率/残缺冷冻电镜骨架，不能与可溶性模型同时勾选。
- JSON 约束做定点控制（固定催化位点、对称强制同源、分链禁氨基酸），PSSM 搭配同源序列保留原功能；de novo 全默认。
- 结果看三大指标：score（目标链，越低越稳）、global score（全复合物，多聚体重点看）、序列恢复率（越高越保留原功能）。
- 可批量导出 FASTA，直接接 AlphaFold 预测、载体构建与湿实验表达。
