# DiffLinker：直接在 3D 点云上"去噪"出连接子的等变扩散模型

> 视频来源：[Equivariant 3D-Conditional Diffusion Models for Molecular Linker Design - Ilia Igashov](https://www.youtube.com/watch?v=l4Z-4c4Xw0s)（M2D2 研讨会，EPFL Ilia Igashov 报告，约 65 分钟）。本博客基于视频字幕与画面整理，数据与结论均以讲者报告为准。

## 本讲要解决的核心问题（SCQA）

**背景**：片段药物设计（fragment-based drug design）是主流策略之一：先把不超过约 300 Da 的小分子片段对接到靶蛋白上，再把它们"拼"成一个完整的先导分子。拼法有很多——片段生长、片段连接、骨架跃迁，甚至 PROTAC/分子胶这种"诱导降解"的路线（白血病已获批药物 venetoclax 的开发就走了"两个化合物 + NMR 观察 + 设计连接子"的路）。

**冲突**：要把**已经摆在 3D 空间里**的片段连起来，现实约束一大堆：连接子多大不知道；片段里哪些原子是锚点（attachment atoms）不知道；片段可能不止两个；而且生成的连接子必须与周围蛋白口袋无碰撞。已有方法各有短板：SyntaLinker 只看 SMILES 字符串，还要人先指定键数、标好锚点；DeLinker 用 2D 分子图，几何信息只有"距离 + 角度"两个标量；3DLinker 虽然上了 3D 等变网络，但仍是**逐原子自回归**生成——很难同时连接多个片段，而且这些方法全都没在"蛋白口袋条件"下测过。

**疑问**：能不能有一个方法——直接吃 3D 片段点云、自动决定连接子大小、支持任意数量片段同时连接，还能把蛋白口袋当作生成条件？

**回答（中心思想）**：DiffLinker——一个 **E(3) 等变扩散模型**，把"连接子"当作可去噪的 3D 点云：前向过程把连接子加噪成高斯噪声，反向过程在"片段上下文"条件下把噪声逐步去成连接子（原子坐标 + 原子类型一起扩散）；先验噪声在片段质心附近采样；去噪网络是等变图神经网络，**只更新连接子原子的坐标**；连接子大小由单独预训练的分类器预测。实验上：ZINC/CSD 基准与 DeLinker、3DLinker 有竞争力且多样性更高；多片段 GEOM-Drugs 上自回归方法明显落后；口袋条件生成的碰撞分布随口袋信息量增加而贴近真实数据；采样步数还可压缩 10 倍而不明显掉点。

![药物设计的基本想法：设计结合靶蛋白活性位点的小分子来改变其功能](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/00135.webp)

## 一、为什么需要 linker 设计：片段药物设计全景

### 1.1 蛋白、折叠与"改变功能"

[【跳转到 01:50】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=110)

蛋白是几乎所有生物体中起关键作用的大分子：氨基酸连成肽链，在细胞中立即折叠到能量最低的 3D 结构，结构决定功能。蛋白的各种功能几乎都由"蛋白与其他分子相互作用"介导——这意味着：如果我们能设计并导入与目标蛋白结合的新分子，就能改变它的功能，比如治病。药物设计的基本想法正是如此：靶蛋白正与底物相互作用时，设计一个结合其活性位点的新分子，抑制它原本的活动。

### 1.2 片段设计三大策略：生长、连接、骨架跃迁

[【跳转到 03:12】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=192)

- **片段生长（molecular growing）**：给核心片段加新的官能团或侧链；
- **片段连接（linking）**：把几个片段连起来——或者共用原子直接合并，或者引入新的原子构成连接子（linker）把它们缝在一起；
- **骨架跃迁（scaffold hopping）**：拿一个已知结合分子，改动或换掉它的中间核心，重新连接剩余部分，以改善结合亲和力、选择性甚至药代动力学性质。

![片段药物设计的主要策略：片段生长、片段连接与骨架跃迁](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/00267.webp)

### 1.3 PROTAC 与分子胶：用降解"改写"蛋白命运

[【跳转到 05:42】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=342)

还有一条更"釜底抽薪"的路：利用真核细胞里的**泛素-蛋白酶体系统**（负责蛋白降解）。最常见的用法是设计 **PROTAC** 或分子胶。以 PROTAC 为例：要让系统降解靶蛋白，先要给它打上泛素标记——而泛素由 **E3 连接酶**递送。核心难题是：怎么让"靶蛋白 + E3 连接酶"形成蛋白-蛋白复合物？思路是：已知一个结合靶蛋白的配体、一个强结合 E3 连接酶的配体，就用一个**连接子把两个配体连起来**——这个大分子就是 PROTAC，而设计这个连接子正是设计新化学物质的核心。

![PROTAC 原理：用连接子把靶蛋白配体与 E3 连接酶配体连成大分子，诱导靶蛋白降解](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/00367.webp)

### 1.4 已获批的先例与讲者组的片段筛选管线

[【跳转到 08:47】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=527)

讲者给了两个"落地"注脚：

- **venetoclax**：已获批、用于白血病患者的抗癌药，其开发借助了"两个结合化合物的 NMR 3D 信息 → 设计连接子 → 再修饰、再生长"的经典管线；
- **讲者组自己的片段筛选管线**：基于蛋白表面表征，从 PDBbind 提取"片段-口袋"对建库，用带学习嵌入的点云表征口袋——新口袋来时，比对表征、3D 对齐、打分，直接得到**已在 3D 空间定位好的片段清单**。这又引出同一个问题：这些"预定义、预就位"的片段，怎么连成分子？

## 二、任务定义与现有方法的短板

### 2.1 四大需求

[【跳转到 10:52】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=652)

把前面所有场景汇总，理想的连接子设计方法应满足：

1. **输入是 3D 片段**：拥有每个原子的坐标，生成的连接子要把它们连成单分子；
2. **不知道连接子大小**：方法要自己判断；
3. **不知道锚点**：片段中哪些原子该被连上，事先未知；
4. **不限片段数量**：最常见是一对，但要能同时连三个甚至更多；
5. **与口袋一致**：至少不能与周围蛋白原子有任何碰撞（clash）。

### 2.2 SyntaLinker：字符串世界的方法

[【跳转到 12:07】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=727)

**SyntaLinker** 是基于 Transformer 的模型，操作对象是 SMILES 字符串：输入片段的 SMILES，还要**人工指定连接子应含的共价键数**、并用特殊符号标出锚点原子；输出也是 SMILES。它完全不碰 3D 信息——本质上只是在"分子式文本"上做补全。

![已有方法一：SyntaLinker——基于 SMILES 字符串的 Transformer 模型，需人工指定键数并标记锚点原子](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/00752.webp)

### 2.3 DeLinker：2D 图 + 两个标量

**DeLinker** 是图变分自编码器，在 2D 分子图上迭代生成原子和共价键。它考虑了一点几何，但非常有限——只有两个标量：输入片段间的距离与夹角。

### 2.4 3DLinker：等变但仍自回归

[【跳转到 13:47】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=827)

**3DLinker** 同样是图变分自编码器，两项主要改进：锚点原子由单独的预训练网络预测；操作 3D 图，用等变向量神经元（vector-neuron）MLP 感知空间对称性。但 DeLinker 与 3DLinker 都是**自回归**的：每个时间步只生成一个原子、再把它连到已有原子上——这让"同时连接多个片段"变得困难（自回归方式很难同时顾及全部上下文）。此外，**这些方法都没在蛋白口袋条件下测过**。

![已有方法三：3DLinker——在 3D 图上用等变向量神经元 MLP，但仍逐原子自回归](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/00827.webp)

## 三、扩散模型 101：从猫图到分子

### 3.1 前向加噪，反向去噪

[【跳转到 17:44】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1064)

扩散模型有两个过程：**前向扩散**把数据点（比如一张猫图）逐步映射成噪声；**反向去噪**则把噪声变换回符合训练数据分布的东西（一张像样的猫图）。形式化地说：前向过程把复杂分布中的数据点映射到简单先验（通常是标准高斯）；反向过程学习这条轨迹，再把它倒过来走，就能生成新样本。

![扩散模型 101：前向加噪把数据映射为噪声，反向去噪从噪声恢复数据（讲者用"猫图"演示）](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/01106.webp)

### 3.2 数学骨架：马尔可夫 + 高斯

[【跳转到 20:28】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1228)

把 X 换成分子后概念完全一样：扩散过程每步给分子加一点噪声，经过大 T 步就只剩噪声。分子用两组变量表示——**所有原子的坐标**（连续）与**原子类型**（one-hot 向量），两者合记为 X，中间态记为 Z。转移核是各向同性高斯：均值由当前状态缩放（alpha-bar T）给出，方差由超参（sigma-bar T）定义。由于**马尔可夫性**，任意中间态 q(Z_t | X) 也有闭式解：把初始信号乘一个系数（系数越小保留的信号越少）、再叠加越来越大的方差——课程里用的是**平方型噪声调度**（t=0 时 alpha=1、sigma=0，信号未失真；随 t 增大信号递减、噪声递增）。

### 3.3 预测噪声更稳，MSE 即变分界

[【跳转到 25:08】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1508)

真实去噪过程的转移核可以解析导出，但它依赖未知的终点 X——于是引入**生成式去噪过程**：用神经网络预测噪声 x̂ 来近似。参数化技巧告诉我们：知道中间态就能反解出 X——所以**直接预测"该减去的噪声"比预测数据本身更稳定**（经验结论）。训练目标就是"真实噪声 vs 预测噪声"的**均方误差**，而这已被证明等价于优化变分界——即模型在优化对数据分布的似然。

## 四、等变性：让模型尊重 3D 世界的对称

[【跳转到 26:44】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1604)

处理几何对象时必须尊重空间对称性：**输入变换，输出要跟着一致地变换**——这样的函数称为**等变（equivariant）**。分子场景下关心的是 **E(3) 欧几里得群**（平移、旋转、反射），再加上图上的**置换等变**（节点顺序无关）。推广到条件分布：P(T(X)|T(Y)) = P(X|Y)——一个分子在空间中某处出现的可能性，应当与它被平移/旋转后出现的可能性相同。

![等变性要求：输入变换时输出随之一致变换；模型需要 E(3) 等变 + 置换等变](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/01854.webp)

## 五、DiffLinker 建模：连接子 + 上下文

### 5.1 把"可改的部分"交给扩散

[【跳转到 28:49】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1729)

DiffLinker 的核心设定：**数据点 X = 连接子**（可修改部分），**上下文 U = 固定部分**——最简单就是输入片段，也可以是蛋白口袋的原子系统。中间态 Z_T 带着同一个不变的 U；生成转移核也以 U 为条件——实际上 U 直接进入去噪网络的输入。

### 5.2 先验采样位置也是设计的：F(U)

[【跳转到 31:19】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=1879)

初始噪声总得在空间中的某个位置采样，而这个位置理应取决于上下文——最自然的选择是**输入片段的质心**。于是先验分布设为"中心在 F(U) 的高斯"，F 是可设计的函数。 elegance 在于：**只要 F 是 O(3) 等变的、去噪网络对"上下文与中间态的整体旋转/反射"等变，整个概率模型就是等变的**——把片段和连接子一起旋转，生成概率不变。

### 5.3 原子类型也一起扩散

原子类型是离散值，处理方式与等变扩散模型一致：把 one-hot 编码**提升到连续域**当作连续变量扩散，去噪结束后取 argmax 恢复原子类型。

## 六、去噪网络与连接子大小预测

### 6.1 等变 GNN：只动连接子

[【跳转到 36:58】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2218)

去噪网络就是等变图神经网络（与分子生成的等变扩散模型同款）。把片段原子与连接子原子放进**同一个全连接图**：每个节点有坐标向量与特征向量（原子类型），并计算所有节点对的距离；消息传递中，消息是节点特征与平方距离的函数，聚合时还会乘上由可训练模块计算的边权重。关键差别：**坐标更新只作用于连接子原子**——上下文是固定且已知的，改它没有意义。

![去噪网络：片段与连接子原子构成一个全连接图，消息传递依赖特征与距离](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/02243.webp)

### 6.2 连接子大小：一个单独的分类器

[【跳转到 39:53】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2393)

连接子该有多少个原子？训练一个**单独的预训练 GNN 分类器**：以输入片段的 3D 取向与位置为输入，预测"原子数"类别的概率分布，再从分类分布中采样。直觉：片段的 3D 摆位大致决定了需要多少原子来缝合。当然它也可以由用户直接指定，或用 ground truth（部分实验就这么做）。

## 七、实验结果：与 DeLinker、3DLinker 同台

### 7.1 ZINC + CSD 基准：四个模型变体

[【跳转到 42:23】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2543)

对比实验在两个此前方法用过的标准数据集上做：**ZINC** 与 **CSD**（后者由实验观测的小分子构成，更真实但更"噪"——ZINC 的 3D 构象是讲者组用力场优化自己生成的），任务都是连接一对片段。DiffLinker 测了四个变体：连接子大小已知与否、是否感知锚点原子、是否采样大小。评估指标是**药物相似性（QED）、合成可及性（SA）与连接子中的环数**——用来判断该方法在药物设计任务中的可用性。

一个亮点：看**唯一性与新颖性**，采样连接子大小（而非给定）如预期地显著提升了这两个数字——相当于多了一个控制生成多样性的旋钮。

![四个模型变体：连接子大小已知/未知、是否感知锚点原子](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/02568.webp)

### 7.2 validity：不加化合价约束仍然很高

[【跳转到 44:03】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2643)

被问到"如何保证最终 3D 图的几何合理"时，讲者坦承：DiffLinker 直接操作原始 3D 点云，**没有加入任何物理或化学约束**——这与 DeLinker/3DLinker 不同（它们放新原子时会施加化合价约束以保证键合法）。这是方法的第一改进方向；但另一方面，validity 指标（检查所有片段都在最终连通分量里 + RDKit sanitize 化合价检查）显示分子仍然相当合法——在没有任何人工约束、只靠模型从原始数据学习的情况下，这个表现相当可观。

### 7.3 GEOM-Drugs：多片段场景，自回归方法掉队

[【跳转到 47:48】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2868)

为测试更多应用，讲者组基于 **GEOM-Drugs** 构建了新数据集：把分子拆成**多于两个片段**，有时甚至需要**不止一个连接子**。为了对比，把 3DLinker 改造成"从随机片段对开始顺序连接"来适配——结果 **3DLinker 显著落后**，而 DeLinker 仍交出不错的成绩。

### 7.4 生成示例：非平凡连接子

[【跳转到 49:03】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2943)

生成的连接子里能看到非平凡的结果：不同的环与环系、环连在片段不同侧的摆放，也有更简单的连接子；甚至有**两个不相连的连接子**同时把三个片段连起来的例子——这正是"不限片段数、不限连通方式"能力的直接展示。

![生成示例：DiffLinker 能产生含不同环系的非平凡连接子，甚至不连通的双连接子](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/02943.webp)

## 八、口袋条件生成：越了解口袋，越少"撞墙"

[【跳转到 49:28】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=2968)

第三个数据集取自 **Binding MOAD**（实验观测并存入 PDB 的蛋白-配体结合数据）：从"结合在口袋里的分子"出发生成片段、去掉连接子，然后把"片段 + 蛋白口袋"整体作为上下文喂给模型。讲者训练了三个"信息量递增"的模型：

1. 不看口袋——只连接片段；
2. 看口袋**骨架原子**；
3. 看口袋**全原子表示**。

在测试集上采样并统计"生成连接子与口袋原子之间的碰撞分布"：**条件于全原子口袋时，碰撞分布与参考数据非常接近；口袋信息给得越少，碰撞越多**——符合预期，也直观地验证了"把口袋当上下文"这条路走通了。

## 九、采样加速：500 步压到 50 步

[【跳转到 51:13】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=3073)

扩散模型的采样是天然瓶颈：通常要跑很多去噪步，且步与步之间难以并行。沿袭计算机视觉里的做法，讲者测试了**压缩采样步数**（模型仍按 T=500 训练不变）：把采样步数减到十分之一（50 步代替 500 步），关键性能指标**没有明显退化**——模型比"扩散模型应有的速度"还要快。

## 十、Q&A 精华：边界与展望

[【跳转到 53:21】](https://www.youtube.com/watch?v=l4Z-4c4Xw0s&t=3201)

- **GFlowNets 能做这个任务吗？** 原理上可能可行，但需要架构调整（讲者只读过一些博客，持谨慎乐观态度）。
- **测过 PROTAC 吗？** 做过快速试验：从一篇 PROTAC/分子胶综述里取了几个随机 PROTAC 生成连接子——化学上看结果并不算好。原因：PROTAC 通常大得多，连接靶蛋白与 E3 配体的连接子比训练分布里的更长；要有足够多相似（被挖掉很多原子）的训练示例才可行。
- **口袋条件能带化学信息吗？** 可以：口袋原子就是带原子类型与坐标的额外节点（用 flag 区分蛋白/片段/连接子原子）；但加入口袋后不再用全连接图——节点距离超过约 5–6 Å 就不连边（100+ 节点的全连接图内存与计算都吃不消）。这为"口袋某处有个氮，连接子更倾向生成指向它的 OH"这类**3D 药效团式**的条件生成留了空间。
- **碰撞是好的评价指标吗？** 提问者建议改用非结合物的 RMSD/似然分布作为对照指标——讲者承认这是好建议，可作为后续工作。
- **考虑构象稳定性/自由能吗？** 没有——没有对最终分子做松弛（也许值得做）；另一个观察是：**过长的连接子**在无约束情境下可能与片段发生相互作用，化合物就不再那么"类药物"。

![总结：DiffLinker——E(3) 等变扩散模型，无需锚点与连接子大小即可连接任意数量片段](assets/Equivariant%203D-Conditional%20Diffusion%20Models%20for%20Molecular%20Linker%20Design%20-%20Ilia%20Igashov/03128.webp)

## 小结

- **任务**：把 3D 空间中已就位的片段连接成单分子——连接子大小未知、锚点未知、片段数不限、还要与口袋无碰撞。
- **已有方法的共同短板**：SyntaLinker 只看字符串且要人工指定键数与锚点；DeLinker 只有 2 个标量几何；3DLinker 等变但仍逐原子自回归——都难做多片段，都没测过口袋条件。
- **DiffLinker**：E(3) 等变扩散模型；X=连接子、U=上下文（片段或口袋原子）；先验高斯中心在 F(U)（质心），F 与去噪网络都等变 ⇒ 整个生成模型等变；原子类型 one-hot 连续化扩散、最后 argmax；等变 GNN 去噪且**只更新连接子坐标**；连接子大小由预训练 GNN 分类器预测（也可指定）。
- **结果**：ZINC/CSD 上有竞争力且采样大小提升多样性；无化合价约束仍高 validity；多片段 GEOM-Drugs 上自回归的 3DLinker 明显落后；口袋全原子条件下碰撞分布贴近真实数据；采样 500→50 步不掉点。
- **边界**：PROTAC（更长连接子）与构象松弛是明确的未来工作；口袋条件图需距离截断；评价指标可引入非结合物分布对照。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| fragment-based drug design | 先把小片段（≤约 300 Da）对接到靶蛋白，再"拼"成先导分子的设计范式 |
| linker / 连接子 | 连接片段的新原子部分；其大小与锚点事先未知是核心难点 |
| scaffold hopping | 替换/改动已知结合分子的核心骨架、重新连接剩余部分的策略 |
| PROTAC | 用连接子连接"靶蛋白配体 + E3 连接酶配体"的双功能分子，把靶蛋白拖给泛素-蛋白酶体降解 |
| E3 ligase / E3 连接酶 | 给靶蛋白打泛素标签的蛋白；PROTAC 三元复合物的另一半 |
| venetoclax | 借助"两化合物 NMR 观察 + 连接子设计"路线开发、已获批用于白血病的抗癌药 |
| SyntaLinker | 基于 SMILES 字符串的 Transformer 连接子模型；需人工指定键数并标记锚点 |
| DeLinker | 2D 图变分自编码器连接子模型；几何信息只有片段间距离与夹角两个标量 |
| 3DLinker | 3D 图变分自编码器（等变向量神经元 MLP）；另配锚点预测网络，但逐原子自回归 |
| 等变（equivariant） | 输入变换（旋转/平移/反射）时输出随之一致变换的性质；本模型要求 O(3) 等变 + 图上置换等变 |
| E(3) / O(3) | 三维欧几里得群（含平移、旋转、反射）与其正交子群 |
| 噪声调度（noise schedule） | 随时间步 t 缩小信号系数、放大方差的曲线；本模型用平方型调度 |
| clash / 碰撞 | 生成连接子与蛋白口袋原子距离过近的冲突；口袋条件生成质量的核心观测指标 |
| Binding MOAD | 实验观测并存储于 PDB 的蛋白-配体结合数据库；本讲口袋条件数据集的来源 |
| QED / SA | 药物相似性（drug-likeness）与合成可及性（synthetic accessibility），连接子质量的常用代理指标 |
