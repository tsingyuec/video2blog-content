# 一套「科学语法」统一七大模态：LOGOS 用纯序列自回归把配体生成、材料设计、逆合成、口袋识别做成一件事

> 视频来源：[首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向 【AI for Science】](https://www.bilibili.com/video/BV1eNjB63EDV)（B 站技术播客，UP 主：熊二等兵，2026-06-19 发布，约 18 分钟）。本期解读论文 *Speaking the Language of Science: Toward a General-Purpose Generative Foundation Model for the Natural Sciences*（阿里巴巴 & 中国人民大学高瓴人工智能学院，[arXiv:2606.16905](https://arxiv.org/abs/2606.16905)）。本博客基于视频字幕与画面整理，数据与结论均以节目内容为准。

## 本讲要解决的核心问题（SCQA）

**背景**：AI for Science（下称 AI4S）这几年遍地开花：蛋白质侧有 ESM 这样的预训练模型，分子侧有 Uni-Mol 这类表征模型，AlphaFold 更是把结构预测做成了标杆。初学者的直观印象是：**一个领域，养一个专用模型**。

**冲突**：真实的科研任务是跨域的。设计一条药物管线，往往同时涉及蛋白质口袋、小分子配体、化学反应甚至功能材料——专用模型各管一段，彼此不通。而且现有三条技术路线各有各的坎：BERT 式判别预训练与下游生成目标语义错位；自回归生成模型只顾单个领域；NatureLM 想用自然语言当「万能接口」，又撞上数据不平衡、模态鸿沟、参数效率三堵墙。

**疑问**：能不能绕开自然语言，让一个模型直接学会「科学语言本身」，并把条件配体生成、材料生成、逆合成预测、口袋识别这些核心科研任务一肩挑？

**回答（中心思想）**：论文提出 **LOGOS**——首个基于**统一科学语法**的多域生成基础模型。它把蛋白质、抗体、小分子、化学反应、材料、结合口袋等科学对象及其相互作用全部编码进一套共享 token 空间，用 next-token 预测做自回归预训练；不需要显式 3D 几何，就能以相对轻量的模型规模在代表性任务上追平甚至超过领域专用方法，并且模型权重与数据处理流水线全部开源。

## 一、旧路线各自撞上的三堵墙

### 1.1 BERT 式预训练-微调：表示与目标错位

[【跳转到 00:50】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=50)

第一代主流做法是 BERT 式「预训练 + 微调」：先在大规模无标注数据上做自监督预训练（掩码语言建模、对比学习），再在下游任务上微调。ESM 系列、Uni-Mol 这些知名模型都是这个思路，也确实取得了不少进展。

![讲解 BERT 式预训练-微调范式局限时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00055.webp)

但节目指出两条硬伤：

- **语义错位**：预训练学的是「通用的、可恢复的或判别性的表示」，而下游任务要优化的是结合亲和力、合成可行性这类复杂目标——预训练表示缺乏直接迁移能力，必须用下游有监督数据微调来重新校准表示空间。
- **架构短板**：纯编码器架构没有统一的原生条件生成机制，要支持生成任务就得额外加辅助生成模块、设计复杂采样策略，用起来很不方便。

### 1.2 自回归生成模型：目标对齐了，但只顾一个域

[【跳转到 01:45】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=105)

于是近几年大家转向**自回归语言模型**的生成式建模：显式建模序列的联合概率分布，用「预测下一个 token」来学习条件依赖——训练目标和生成过程天然对齐。蛋白质领域的 ProGen2、ProtGPT2，核酸基因组领域的 Evo 系列，都验证了这条路的潜力。

![讲解自回归生成范式及其代表模型时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00105.webp)

问题在于：**这类模型基本都是单领域的**。没有跨域建模的统一框架，就捕捉不到不同模态之间的共享规律和协同关系；而真实的生物过程恰恰是蛋白质、小分子等多种分子复杂相互作用的过程，单一模型没法模拟这种复杂度。

### 1.3 NatureLM：用自然语言统一的三道坎

[【跳转到 02:34】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=154)

此前也有研究尝试做「通用科学大模型」，代表是 NatureLM：用自然语言作为通用任务描述接口，把跨域异构科学任务都重写成「指令-响应」格式的条件生成问题。这确实是向通用科学模型迈进的重要一步，但带来了新问题：

1. **数据不平衡**：自然语言语料极其丰富，生物化学专业数据却少得多。以自然语言为接口，模型可能过度依赖通用语言模式，反而学不透领域原生模态的结构规律和跨域关联。
2. **模态鸿沟**：自然科学知识本来就不是主要靠自然语言传递的——氨基酸序列这类领域特有的表示，在组成规则、结构约束、语义机制上与自然语言差异巨大。
3. **参数效率**：参数预算固定时，把大量容量花在「保留自然语言理解与生成能力」上，对科学原生任务的边际收益很低；不如把容量优先投给专业表示。

## 二、核心洞察：科学对象是「同一门语言的不同方言」

[【跳转到 03:49】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=229)

论文的核心思路是：**直接从科学对象的原生结构和空间相互作用原理出发，把多领域科学任务统一成生成式的 token 建模问题**。

这个洞察的出发点很有意思：蛋白质、小分子、材料、反应系统的符号表示看起来五花八门，但本质上都遵循特定的**组成规则、结构约束和相互作用语义**——可以把它们看成**同一种科学语言的不同实例（方言）**。

![讲解「统一科学语法」核心洞察时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00229.webp)

只要用一套统一的形式语法，把所有下游问题都映射成统一生成范式下的**序列预测**问题，就能在单个模型里实现跨域知识迁移、多任务协同优化，还让预训练与下游目标高度对齐——预训练学的东西就是下游要做的事。

## 三、LOGOS 框架：把「科学」变成 token 序列

[【跳转到 04:26】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=266)

基于上述洞察，论文提出 LOGOS 框架：这是**第一个基于统一科学语法的多域生成框架**，用这套语法作为跨模态、跨任务、跨层级的共享表示接口——把不同科学对象及它们之间的相互作用，都编码成共享词汇表上的 token 序列，再通过自回归预训练学习这些序列的联合分布。因为预训练就发生在与下游任务高度对齐的语法空间里，模型能直接学到「怎么生成科学对象、怎么构建对象之间的关系、怎么在约束下做科学设计」。

### 3.1 空间相互作用的「语法化」：不依赖 3D 坐标

[【跳转到 04:51】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=291)

与依赖显式三维坐标、几何神经网络或专用结构模块的方法不同，LOGOS 走了另一条路线：**不把 3D 结构当成连续几何输入，而是把科学对象的关键关系和相互作用模式离散化、语法化、token 化**，整合进统一的序列生成框架。

最典型的例子是蛋白质口袋与配体的相互作用：不需要显式建模原子级坐标，而是设计序列表示来捕捉**空间接触与约束信息**，让模型用语言建模的方式学习口袋-配体的相互作用模式。

这样设计的好处非常明显：一是解决了不同领域 3D 结构数据可用性不一致的问题；二是把异构的多域科学数据放进同一个语法系统里实现深度统一。

### 3.2 四个核心贡献

[【跳转到 06:17】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=377)

节目把论文贡献归纳为四条：

1. **新的建模范式**：把蛋白质、抗体、小分子、材料、反应、口袋等任务统一成生成式 token 建模问题，推动自然科学任务从「模态特定的专用建模」转向「统一语法空间下的通用生成式建模」，且训练目标与科学设计的最终应用完全一致。
2. **LOGOS 框架本身**：统一科学语法把不同科学对象与跨对象关系纳入同一个离散 token 空间，尤其把**空间相互作用语法化成 token 表示**，实现口袋-配体这类复杂结构信息的序列化建模；同时统一多域数据、打通预训练与下游。
3. **无几何依赖的高性能**：完全基于纯序列范式，在条件配体生成、材料生成及性质相关任务、逆合成预测、口袋挖掘、蛋白质编辑、抗体 CDR 区预测等代表性任务上都取得很好效果——轻量模型规模就超过了领域专用方法，验证了自然科学领域「一个模型通吃」的可行性。
4. **全面开源**：模型权重、训练数据处理流水线及相关资源开放，为后续研究提供可复用的技术路径。

![讲解下游任务如何被重写为 next-token 预测问题时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00352.webp)

节目还点出一个工程启发：科学大模型不必另起一套与 LLM 完全独立的技术栈，反而可以通过共享架构、共享训练范式、共享推理基础设施，与大型语言模型深度对齐，让 LLM 成为 AI4S 的新入口。

## 四、七模态语料：448.7 亿 token 怎么拼出来

### 4.1 三层知识图景

[【跳转到 08:27】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=507)

数据构建围绕两个最核心的分子实体展开：**蛋白质**（生物过程的主要执行者，几乎参与所有细胞生化事件）与**小分子**（调节蛋白质功能、干预生物过程最常用的化学试剂，药物发现的物质基础）。围绕它们再沿两个维度扩展：

- **分子家族扩展**：抗体是蛋白质的功能特化子类；化学反应与功能材料则把表示范围从静态小分子结构扩展到转化过程和层级组成。
- **分子间界面相互作用**：蛋白质结合口袋对小分子配体的选择性识别，是连接生物大分子与化学实体的关键环节。

最终构成覆盖**七个模态**的大规模预训练语料：蛋白质、抗体、小分子、化学反应、材料、蛋白质配体结合位点、蛋白质配体复合物。其中蛋白质+抗体构成**生物大分子层**，小分子+反应+材料构成**化学实体与转化过程层**，两个「配体相关」模态则捕捉**连接两层的相互作用界面**。所有模态都在统一语法下编码成离散 token 序列，总计 **448.7 亿 token**。

![讲解七模态预训练语料构成时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00562.webp)

### 4.2 蛋白质：UniRef90 + 边界令牌

[【跳转到 10:12】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=612)

蛋白质模态用 **UniRef90** 数据集——UniProt 提供的非冗余蛋白质序列聚类数据，把 UniProtKB 条目按 90% 序列同一性聚类，既减少冗余又保留覆盖度与多样性，是蛋白质预训练的标准数据源之一。预处理时从 FASTA 文件按条目提取序列；为了让模型能识别「模态边界」，每个序列前后加上边界令牌 **PROTEIN_S / PROTEIN_E**，编码成 `PROTEIN_S … PROTEIN_E` 形式的离散 token 序列。

![讲解 UniRef90 与蛋白质边界令牌编码时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00637.webp)

### 4.3 抗体：OAS 过滤与 70% 聚类

[【跳转到 11:02】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=662)

抗体是体液免疫的主要效应分子，介导特异性抗原识别；作为功能特化的蛋白质子类，它序列多样性高、抗原结合特异性好，是治疗性抗体开发的核心。数据来自大型抗体序列库 **OAS（Observed Antibody Space）** 的非配对数据：先过滤掉来源不明、缺少供体/同种型信息、含非标准残基、无 IMGT 框架区注释的序列；再按 **70% 序列同一性聚类**去除高频克隆相关冗余，每簇保留一条代表序列。语法上使用边界令牌 **ANTIBODY_S / ANTIBODY_E**。

![讲解 OAS 抗体数据库与过滤流程时的幻灯片](assets/首个统一「科学语法」多领域生成基础模型！通用科学AI大一统的新方向%20【AI%20for%20Science】/00687.webp)

### 4.4 小分子：PubChemQC + SMILES + 构象过滤

[【跳转到 12:03】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=723)

小分子模态编码原子组成、键连接、立体化学、分子拓扑等信息，是化学实体知识层的基础。数据来自大型量子化学数据库 **PubChemQC**（基于 B3LYP/6-31G* 与 PM6 计算级别，源自 PubChem 分子库）。分子用 SMILES 这类线性表示法编码原子类型、键连接与手性，并基于对应三维构象做结构一致性过滤，保证拓扑与立体化学的高保真；最后统一加上边界令牌 **MOLECULE_S / MOLECULE_E**。

### 4.5 化学反应：ORD + EC-REACT，双向采样出「逆合成」

[【跳转到 13:18】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=798)

化学反应是连接已知化合物空间与新型功能分子设计的关键桥梁，直接支持逆合成规划、反应条件优化、产率预测等应用。数据来自两个开放反应库：**ORD（Open Reaction Database）** 收录实验验证的有机反应，**EC-REACT** 聚焦酶催化反应。

语法设计上，反应中每个参与分子（反应物/产物）都复用小分子模态的 `MOLECULE_S … MOLECULE_E` 语法，保持跨模态一致；同时引入方向令牌 **REACT**（反应物 → 产物的正向反应）与 **REVERSE_REACT**（产物 → 反应物的逆向推导），**每个反应都双向采样成正向和逆向两条训练序列**——这正是「ReverseReact」逆合成任务的语料来源。

### 4.6 材料：MOF 的嵌套语法

[【跳转到 14:58】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=898)

材料模态沿「层级组成」维度扩展了分子化学的表示范围，论文以**金属有机框架 MOF** 为代表——由无机金属簇与有机连接体通过配位键自组装形成的晶态多孔材料，结构可调、孔隙率高。数据来自 Boyd 等人构建的大型假设 MOF 结构数据库。

预处理用「金属/氧分解」策略把每个 MOF 拆成**金属簇**与**有机连接体**两组件，并用 RDKit 验证有机连接体的化学完整性（解析不出有效分子图、含断裂或非标准结构的条目丢弃）。语法表示是**嵌套**的：外层边界令牌 **MATERIAL_S / MATERIAL_E** 界定整个材料实体；金属簇组件用专用令牌 **METAL_S / METAL_E** 包裹；有机连接体则直接复用小分子的 `MOLECULE_S … MOLECULE_E` 语法——完整条目形如 `MATERIAL_S METAL_S … METAL_E MOLECULE_S … MOLECULE_E MATERIAL_E`。

### 4.7 口袋：PDB + P2Rank

[【跳转到 16:38】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=998)

最后一个核心模态是**蛋白质配体结合位点**（结合口袋）：蛋白质三维结构中负责与小分子配体特异性相互作用的局部空间区域。它是连接两个知识层的桥梁——既是蛋白质序列的局部子结构，其功能又是结合小分子。把口袋纳入预训练语料，能让模型在统一语法空间里显式学习「蛋白质序列上下文 ↔ 配体结合功能」的关联，直接服务条件配体生成、结合位点预测等下游任务。

数据来自 PDB 蛋白质结构，用 **P2Rank**（基于机器学习、对蛋白质表面潜在结合区域打分排序的工具）预测每个结构上的结合位点。（视频中列出的第七模态「蛋白质-配体复合物」数据未在节目中展开细节。）

## 五、四任务成绩单：正对本条目的 ReverseReact / Pocket / Ligand / Material

[【跳转到 07:39】](https://www.bilibili.com/video/BV1eNjB63EDV/?t=459)

把七模态语料喂给自回归模型后，论文在一系列下游任务上验证了 LOGOS 的能力，其中正对本文条目的四类任务是：

- **ReverseReact（逆合成预测）**：由反应语料的 REVERSE_REACT 方向令牌与双向采样直接支撑；
- **Pocket（口袋识别/挖掘）**：由 PDB + P2Rank 构建的口袋模态支撑；
- **Ligand（目标蛋白条件配体生成）**：由「口袋 + 小分子」两个模态的联合语法支撑；
- **Material（材料生成及性质相关任务）**：由 MOF 嵌套语法支撑。

此外还覆盖蛋白质编辑与抗体 CDR 区预测。实验结论是：**不依赖显式 3D 几何网络，仅凭统一科学语法，用相对轻量的模型规模就超过了领域专用方法**。

## 六、为什么这条路线值得期待

- **预训练与下游真正对齐**：不再是「先学表示再重新校准」，预训练空间就是下游任务的语法空间。
- **与 LLM 技术栈共享红利**：共享架构、训练范式与推理基础设施，让科学大模型搭上 LLM 生态的快车。
- **纯序列、易扩展**：绕开 3D 数据可用性不齐的坑，新领域只要定义好语法就能纳入。
- **开源可复现**：模型权重与数据流水线开放，社区可以直接在其上继续建设。

## 小结

- 旧三路线（BERT 判别预训练、单域自回归生成、NatureLM 自然语言接口）分别在语义错位、跨域缺失、模态鸿沟上受限。
- LOGOS 的核心洞察：科学对象的符号表示是「同一门科学语言的不同方言」，可用一套统一形式语法收敛到共享 token 空间。
- 空间相互作用（如口袋-配体接触）被语法化成 token 序列，模型不需要显式 3D 坐标也能学到跨模态结构规律。
- 语料覆盖七模态共 448.7 亿 token：UniRef90 蛋白质、OAS 抗体、PubChemQC 小分子、ORD/EC-REACT 反应（REACT/REVERSE_REACT 双向采样）、MOF 材料（嵌套语法）、P2Rank 口袋等。
- 在条件配体生成、材料生成、逆合成预测、口袋识别、蛋白质编辑、抗体 CDR 预测等任务上，轻量纯序列模型追平或超越领域专用方法。
- 模型权重与数据处理流水线全部开源。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 统一科学语法 | 把不同科学对象的符号表示与相互作用，统一成一套共享 token 规则（边界令牌 + 方向令牌等） |
| LOGOS | 首个基于统一科学语法的多域生成基础模型，阿里巴巴 & 人大高瓴提出 |
| next-token 预测 | 自回归训练目标：给定前文，预测序列中的下一个 token |
| 边界令牌 | 标记模态开始/结束的特殊 token，如 PROTEIN_S/E、ANTIBODY_S/E、MOLECULE_S/E、MATERIAL_S/E |
| 方向令牌 | REACT / REVERSE_REACT，显式编码化学反应的正向/逆向方向 |
| UniRef90 | UniProt 按 90% 序列同一性聚类的非冗余蛋白质序列数据集 |
| OAS | Observed Antibody Space，聚合公开免疫组库测序数据的大型抗体序列库 |
| PubChemQC | 基于 B3LYP/6-31G*、PM6 计算的大型量子化学数据库，源自 PubChem |
| ORD / EC-REACT | Open Reaction Database（实验验证有机反应）/ 酶催化反应数据库 |
| MOF | 金属有机框架：金属簇 + 有机连接体配位自组装的晶态多孔材料 |
| P2Rank | 基于机器学习的蛋白质表面结合位点打分与排序工具 |
| ReverseReact | 逆合成任务：从目标产物反推反应物，由 REVERSE_REACT 令牌支撑 |
