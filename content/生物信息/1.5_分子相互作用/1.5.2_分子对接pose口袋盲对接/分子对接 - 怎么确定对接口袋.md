# 分子对接 - 怎么确定对接口袋

> 视频来源：[分子对接 - 怎么确定对接口袋（B站，45:03）](https://www.bilibili.com/video/BV16z4y167q9/?t=0)，作者：钰沐菡-YuMuhan。本博客基于视频字幕与画面整理。

## 本讲要解决的核心问题（SCQA）

**背景**：跑对接软件本身的门槛越来越低，甚至 AI 工具都能帮你把流程跑起来。

**冲突**：但"盒子放在哪、放多大"没有定式——位置设错，流程再正确、结果也不靠谱；而且很多初学者分不清普通对接和盲对接（blind docking）。

**疑问**：对接位点到底是什么？对接盒子的位置和大小怎么确定？没有共晶配体、没有文献报道、什么信息都没有时怎么办？

**回答（中心思想）**：**对接位点是一个空间范围（结合口袋），不是一个氨基酸残基**。按已知信息的多寡有三条路：

1. **有共晶配体** → 在 ADT 里加载复合物，用 **Center on Ligand** 一键定盒；
2. **无共晶、但有文献/实验证据** → 找出口袋关键残基，手动移动盒子把它们包裹进去；
3. **什么都不知道** → 用 **DeepSite / DoGSiteScout** 等软件预测口袋，或直接**盲对接**（盒子包住整个蛋白，代价是准确率下降）。

## 一、对接位点：是一个空间范围，不是一个残基

经常有人说"这个小分子能不能对接到这个氨基酸上面"——这个说法其实欠妥当 [【跳转到 01:04】](https://www.bilibili.com/video/BV16z4y167q9/?t=64)：

![对接位点是一个空间范围，不是单个氨基酸](assets/分子对接%20-%20怎么确定对接口袋/00064.webp)

- 对接位点**不是一个氨基酸残基，而是一个空间范围**：它包含好多氨基酸残基，共同形成一个**结合口袋** [【跳转到 01:29】](https://www.bilibili.com/video/BV16z4y167q9/?t=89)；
- 所以它和"氨基酸位点"、定点突变实验里的"点"不是一回事；
- 确定对接位点 = 确定蛋白表面**哪一个凹陷的空间结构**可以容纳一个小分子、并与之发生相互作用。

顺带一提：口袋预测软件预测的其实就是 pocket 有多大、多深、亲水/疏水情况如何——疏水口袋容易设计小分子，特别亲水的口袋反而不好靶向。

## 二、对接盒子：限定搜索空间、控制计算量

![对接盒子的目的：减少计算量](assets/分子对接%20-%20怎么确定对接口袋/00438.webp)

- **盒子的目的就是减少计算量**：不用盒子的话，搜索会发生在整个蛋白范围内——第一不精确，第二计算量特别大 [【跳转到 07:18】](https://www.bilibili.com/video/BV16z4y167q9/?t=438)；
- 盒子设好后，**配体不能伸出盒子外面**，只能在盒内寻找可结合的构象；
- **大小的含义**：设小一点计算快；设大一点计算慢，但大出来的区域可能容纳更多相互作用、或更大的分子。技巧：想在哪一个方向"多找找"，就把那个方向调大——其余方向保持与共晶配体差不多，软件就会更多挑出往那边结合的构象。

## 三、情况一：有共晶配体 → Center on Ligand 一键定盒

**前提**：PDB 数据库里这个蛋白已有与其他小分子共结晶的结构。这本身就说明该 pocket 是可靶向的 [【跳转到 02:19】](https://www.bilibili.com/video/BV16z4y167q9/?t=139)。

操作（ADT）：

1. 加载蛋白文件；再加载共晶小分子（Input → Open）。只要没人为改动坐标，小分子就待在它原本的 pocket 里 [【跳转到 03:46】](https://www.bilibili.com/video/BV16z4y167q9/?t=226)；
2. Grid → Set Map Types → Choose Ligand 指定配体（否则点 Center on Ligand 会报错 *No current ligand*）；
3. Grid → GridBox 打开盒子面板，点 **Center on Ligand**：盒子直接跳到配体上，并自动收缩成**能包裹这个小分子的最小盒子**（初始盒子是正方体，之后按配体形状变成略长的盒）[【跳转到 05:47】](https://www.bilibili.com/video/BV16z4y167q9/?t=347)。

![Center on Ligand：盒子跳到配体并按其大小收缩](assets/分子对接%20-%20怎么确定对接口袋/00347.webp)

4. 想要更大的搜索空间：显示分子表面，若口袋还有空间、或要筛选的数据库分子比共晶配体大，就在 XYZ 方向手动调大。

## 四、情况二：无共晶，但有文献/实验证据 → 挑残基手动定盒

**前提**：PDB 里只有 apo 蛋白（无配体复合物），但文献报道了口袋并做了实验验证（如突变口袋内某个氨基酸后结合发生变化）[【跳转到 09:24】](https://www.bilibili.com/video/BV16z4y167q9/?t=564)。

![情况二：从文献 2D 相互作用图确定口袋残基](assets/分子对接%20-%20怎么确定对接口袋/00564.webp)

操作思路：

1. 从文献的**2D 相互作用图**找出口袋里的关键氨基酸残基（一个口袋肯定由好几个残基组成，不可能只有一个）；
2. 打开蛋白序列，定位这些残基的编号，显示成**棒状结构**，确认它们的空间位置 [【跳转到 12:53】](https://www.bilibili.com/video/BV16z4y167q9/?t=773)；
3. Grid → GridBox 生成默认盒子后，**手动调整中心坐标和大小**，把挑出来的残基全部包裹进去即可。

![手动移动盒子包裹口袋残基](assets/分子对接%20-%20怎么确定对接口袋/00773.webp)

注意：这条路线**完全不需要配体**——只加载 receptor 也能定盒；Center on Ligand 只是"有配体位置信息"时偷懒用的快捷方式 [【跳转到 14:17】](https://www.bilibili.com/video/BV16z4y167q9/?t=857)。

## 五、情况三：什么信息都没有 → 软件预测口袋

**前提**：没有共晶复合物、没有文献报道、也不打算做突变实验，拿到蛋白就想做虚拟筛选 [【跳转到 15:41】](https://www.bilibili.com/video/BV16z4y167q9/?t=941)。作者的做法：谷歌搜 `pocket prediction` 或 `binding site prediction`，从论文（发表在 Bioinformatics）摘要的 availability 找到在线工具。

### 5.1 DeepSite（PlayMolecule 平台）

![DeepSite 预测结果：橙色口袋与中心坐标](assets/分子对接%20-%20怎么确定对接口袋/01073.webp)

- 输入 PDB ID 或上传结构文件（演示时特意把 1IEP 的共晶配体删掉，模拟"无配体真实情况"）→ 提交排队计算；
- 结果页面：橙色区域即预测口袋，右侧给出每个口袋的 **center 坐标**等信息；
- 点 **Download Results** 得到 CSV：每个口袋的**打分 + 中心坐标** [【跳转到 21:10】](https://www.bilibili.com/video/BV16z4y167q9/?t=1270)；
- 回到 ADT：Grid → GridBox，把预测的 XYZ 坐标填进盒子中心，再显示表面、手动调大盒子把可见 pocket 全部包进去。

![把预测坐标填进 GridBox 后再手动放大](assets/分子对接%20-%20怎么确定对接口袋/01270.webp)

一个有趣的对照：带配体的 1IEP 与删掉配体的版本预测出的第一口袋坐标几乎一致（14、15、16、13），其余口袋也靠得很近——说明这个蛋白**只有这一个像样的口袋**。

### 5.2 ProteinPlus 的 DoGSiteScout

![DoGSiteScout 预测出 7 个口袋](assets/分子对接%20-%20怎么确定对接口袋/01642.webp)

- 上传/输入结构后预测出 **7 个口袋**，点"眼睛"图标可逐个查看范围；**Additional Information** 给出体积、深度、氢键给体/受体数、极性/非极性残基、原子类型等详细信息 [【跳转到 27:22】](https://www.bilibili.com/video/BV16z4y167q9/?t=1642)；
- 下载结果有两个文件夹 [【跳转到 29:06】](https://www.bilibili.com/video/BV16z4y167q9/?t=1746)：
  - `pockets/`：7 个 `.cp3` 盒子文件——**PyMOL 能打开、ADT 打不开**；在 PyMOL 里与蛋白同显，可见第一个盒子正好包裹共晶配体；
  - `residues/`：每个口袋一个 **PDB 文件**，只含该口袋的氨基酸残基；
- 用文本编辑器打开残基 PDB，记下序列号（如 235、248、249、253…），回到 ADT 把这些残基棒状显示出来，再用 GridBox 手动定盒包裹 [【跳转到 32:22】](https://www.bilibili.com/video/BV16z4y167q9/?t=1942)。

![从 residues PDB 里读口袋残基序列号](assets/分子对接%20-%20怎么确定对接口袋/01942.webp)

- **无配体蛋白同样能预测**：纯靠表面凹凸、深浅、体积等性质打分。演示中删掉配体后的预测结果与带配体版本形状一致，作者认为该软件挺准、推荐使用；
- 批量需求：DoGSiteScout 可下载到本地命令行运行，配合 Python 解析 `*_descriptors` 表（ligand coverage、volume、surface、氨基酸组成等），可以一次处理大量蛋白，甚至给机器学习模型做特征。

## 六、盲对接（blind docking）：不指定口袋的"撒网式"对接

**场景**：实验证明某个小分子能与蛋白结合，但不知道它结合到哪里；又不想"预测 7 个口袋 → 逐个设盒 → 逐个对接"这么麻烦 [【跳转到 35:03】](https://www.bilibili.com/video/BV16z4y167q9/?t=2103)。

**做法**：把对接盒子设得非常大——把 grid spacing 调大、盒子直接**包住整个蛋白** [【跳转到 35:48】](https://www.bilibili.com/video/BV16z4y167q9/?t=2148)。

![盲对接：盒子包住整个蛋白](assets/分子对接%20-%20怎么确定对接口袋/02148.webp)

**代价**：软件要在整个蛋白表面先探索哪里可能对接、再逐处尝试，计算量巨大；且没有给定范围，**每个位置分到的搜索精度都变少——所以盲对接准确率不高** [【跳转到 36:43】](https://www.bilibili.com/video/BV16z4y167q9/?t=2203)。视频开头那位同学总结得好："确定对接口袋的位置是对接准确与否的核心步骤"。

| 什么时候用 Center on Ligand？ | 有共晶结构、或历史对接结果文件，且配体位置就是你想要的口袋时 [【跳转到 20:53】](https://www.bilibili.com/video/BV16z4y167q9/?t=1253) |

## 小结

- 对接位点 = **空间范围（口袋）**，由多个残基组成，不是单个氨基酸；
- 对接盒子的本质是**限定搜索空间**：配体出不了盒子；小=快，大=慢但覆盖广；
- 定盒三条路：**共晶配体**（Center on Ligand）→ **文献/实验残基**（手动包裹）→ **软件预测**（DeepSite / DoGSiteScout）；
- 预测工具产出"口袋打分 + 中心坐标 + 残基列表"，坐标填进 GridBox、残基棒状显示后手动包裹；
- **盲对接 = 盒子包整个蛋白**：适合"知道有结合、不知道位点"的情形，代价是计算量大、准确率低；
- 能预测口袋就尽量预测，把对接做"精"而不是做"广"。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 对接位点 / 结合口袋 | 蛋白表面可容纳小分子的凹陷空间，由多个残基组成 |
| 对接盒子（grid box） | 限定配体搜索范围的三维盒子，用于减少计算量 |
| Center on Ligand | ADT 中把盒子对齐到当前配体并按其大小收缩的功能 |
| 盲对接（blind docking) | 不指定口袋、把盒子设为包裹整个蛋白的对接方式 |
| DeepSite | PlayMolecule 平台上的在线口袋预测工具，输出口袋打分与中心坐标 |
| DoGSiteScout | ProteinPlus 上的口袋检测工具，输出口袋几何/理化信息与残基列表 |
| .cp3 | DoGSiteScout 导出的口袋盒子格式，PyMOL 可打开、ADT 不支持 |
| grid spacing | 对接网格间距；盲对接时调大以覆盖全蛋白 |
