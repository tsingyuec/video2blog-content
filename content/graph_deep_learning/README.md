## 项目简介

本系列把《图深度学习：理论与应用》的 9 讲课程逐秒抽帧、抓取字幕，先做成可核查的「图-字幕」文稿，再据此写成初学者也能看懂的金字塔式博客。内容覆盖图学习基础、深度学习基础、网络嵌入、图神经网络、鲁棒性与可扩展性、图上的其他深度模型、应用与研究前沿。

> **字幕说明**：第 1、2、5、6、7、9 讲使用 B 站 AI 字幕；第 3、4、8 讲的 B 站字幕接口不可用，改用本地 GPU Whisper 转写。所有文稿均经过逐窗口通顺化与术语纠错。

## 建议学习路线

| 阶段 | 讲次 | 内容 |
| --- | --- | --- |
| 入门 | 1–2 | 课程导览、图的价值，以及神经网络、反向传播、CNN/RNN 等深度学习基础 |
| 图表示学习 | 3 | 从矩阵分解、Word2Vec 到 DeepWalk、LINE、Node2Vec 的网络嵌入 |
| 核心模型 | 4 | 图信号与拉普拉斯矩阵、谱滤波、GCN、GraphSAGE、GAT、MPNN、图池化 |
| 深入 | 5–6 | 对抗攻击与防御、可扩展性采样；图 RNN、图自编码器、图 GAN 等模型 |
| 应用与前沿 | 7–9 | NLP/知识图谱/推荐/生物医药/视觉等应用，以及自监督、表达性、可解释性等前沿 |
