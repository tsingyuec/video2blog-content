## 本讲要解决的核心问题（SCQA）

**背景**：蛋白质很少「单打独斗」——它们往往两两结合，甚至几十上百个蛋白组成复合体来执行功能。研究某个蛋白时，「它和谁互作、是否直接结合」是最基础的一环。

**冲突**：刚接触时很容易把概念和方法搅在一起：什么是「二元交互」？「蛋白互作」到底研究什么？酵母单杂和双杂有什么区别？体内、体外的技术分别解决什么问题？

**疑问**：PPI 的基本概念是什么？它的核心研究逻辑是什么？常用的研究技术各自解决什么问题？

**回答（中心思想）**：**PPI（蛋白质-蛋白质相互作用）** 是「两个分子之间的直接相互作用」，属于二元交互中最常见的一类；其核心逻辑一句话——**由已知的蛋白 A，去筛选/找到未知的蛋白 B，并证明两者结合**。围绕这句逻辑，体内技术（酵母双杂交、双分子荧光互补）用于在细胞内筛选/观察互作，体外技术（免疫共沉淀、pull-down）用于在细胞外捕获并验证互作。

---

## 一、先建立概念：什么是「二元交互」和 PPI

所谓**二元交互（binary interaction）**，本质就是**两个分子**之间的关系。这两个「元素」可以是**蛋白、mRNA、lncRNA、microRNA、circRNA、DNA……**，只要是在这么多元素中**任意两个元素之间发生的结合/交互**，就叫二元交互。

![解螺旋幻灯片「二元交互」：两个元素（蛋白/mRNA/lncRNA/microRNA/circRNA/DNA……），一个已知、一个未知；交互即相互作用、相互结合](assets/蛋白质互作（PPI）基础/BV1dM41187Gy_00105.webp)

[【跳转到 01:45】](https://www.bilibili.com/video/BV1dM41187Gy/?t=105)

常见的二元交互有：

- **蛋白-蛋白交互**（非常常见，也是本文重点）；
- **蛋白-RNA 交互**（非常常见）；
- **RNA-RNA 交互**：例如 **miRNA 结合到 mRNA 的 3′UTR**，通过转录后机制调控基因表达；
- **蛋白-DNA 交互**：最常见的是**转录因子与基因启动子区结合**。

其中在二元交互里**最常见的两大类，是「蛋白-蛋白」与「蛋白-RNA」**；其他形式的核心逻辑相通，只是表现形式和所用方法略有不同。

> **关键区分**：这里的「**交互**」指的是两个分子之间的**直接相互作用、相互结合**。它区别于「二元变量/三元研究」那种**间接**的研究模式（例如「一个药物 + 一个分子/通路」，但彼此是否存在直接作用并不明确）。**直接相互作用是机制研究中最基本的内容**，也是现在写科研基金标书最常见的作用模式。

## 二、PPI 研究的核心逻辑：由已知，推未知

**蛋白-蛋白交互是最简单、最基本、最常见的二元交互。** 研究它时要先明确一件事：你手上的两个蛋白里，**一个是已知的、一个是未知的**——你要做的，是**用一个已知蛋白去筛选/找到那个未知的、能与它结合的蛋白**。

![解螺旋幻灯片「蛋白-蛋白交互」：元素 A=已知蛋白、元素 B=未知蛋白；核心是①由已知推未知，②证实二者结合及其机制](assets/蛋白质互作（PPI）基础/BV1dM41187Gy_00218.webp)

[【跳转到 03:38】](https://www.bilibili.com/video/BV1dM41187Gy/?t=218)

这就是所有蛋白-蛋白互作研究的**核心逻辑**，可以浓缩成一句话：

> **通过已知的蛋白 A，找到未知的蛋白 B，并证明 A 与 B 之间存在相互作用。**

后面所有的研究模式和套路，都是围绕这句话展开的。

## 三、常用研究技术总览：体内 vs 体外

围绕上面的逻辑，实验中常用的技术可以按「**蛋白-DNA**」与「**蛋白-蛋白**」、「**体内**」与「**体外**」来分组：

![lyrical79 的提纲：Pr 与 DNA（酵母单杂交、EMSA）；体内 Pr-Pr（酵母双杂交、双分子荧光互补）；体外 Pr-Pr（免疫共沉淀、pull-down）](assets/蛋白质互作（PPI）基础/BV1ZjmPYeEVz_00900.webp)

[【跳转到 15:00】](https://www.bilibili.com/video/BV1ZjmPYeEVz/?t=900)

| 研究对象 | 体内 / 体外 | 常用技术 |
| :--- | :--- | :--- |
| 蛋白 - DNA | — | 酵母单杂交（Y1H）、凝胶阻滞（EMSA） |
| **蛋白 - 蛋白** | **体内** | **酵母双杂交（Y2H）、双分子荧光互补（BiFC）** |
| **蛋白 - 蛋白** | **体外** | **免疫共沉淀（Co-IP）、pull-down** |

其中**酵母单杂交、EMSA 研究的是蛋白与 DNA**；真正研究**蛋白-蛋白互作**的是后四类。下面逐一讲它们要解决什么问题。

## 四、体内技术一：酵母双杂交（Y2H）

**酵母双杂交（Yeast two-hybrid, Y2H）** 是研究蛋白-蛋白互作最常用的体内方法，它**既可以用来筛选未知蛋白，也可以用来验证两个蛋白是否真的结合**。

它利用的是转录因子 **GAL4** 的结构特点：GAL4 有两个结构域——**DNA 结合域（BD）**和**转录激活域（AD）**。BD 负责结合 DNA，AD 负责激活下游基因转录；两者合在一起，才能启动下游报告基因的表达。

![解螺旋幻灯片：酵母双杂交原理——把 GAL4 拆成 BD 与 AD 两部分，X-BD、Y-AD，当 X 与 Y 结合时 BD、AD 靠拢，报告基因才被转录](assets/蛋白质互作（PPI）基础/BV1dM41187Gy_00341.webp)

[【跳转到 05:41】](https://www.bilibili.com/video/BV1dM41187Gy/?t=341)

实验设计：把完整的 GAL4「**拆成两半**」——

- **蛋白 X 融合 BD**（写成一个融合蛋白 X-BD）；
- **蛋白 Y 融合 AD**。

当**X 与 Y 结合**时，BD 与 AD 在空间上被拉近、**重新组成一个功能完整的转录因子**，从而启动下游**报告基因**表达；如果 X 与 Y 不结合，单独的 BD 或 AD 都**无法**启动转录，报告基因不表达。所以，「**报告基因有没有表达**」就成了判断 X 与 Y 是否互作的信号。

**为什么它能用来筛选？** 因为可以把其中一个蛋白设为**已知**，另一个用 **cDNA 文库**（包含几千甚至几万个分子）来表示：用已知分子与文库「杂交」，凡是能让报告基因表达的克隆，就说明**已知分子与该位置的分子可能结合**；再把阳性克隆挑出来测序，就知道潜在的互作分子是什么。

**为什么它又能用来验证？** 筛选（尤其文库筛选）难免有**假阳性**，所以找到候选后，还需进一步验证——把已知分子与候选分子分别接到 BD、AD 上再测一次即可。

> **一句话记忆**：酵母双杂交**既可用于筛选未知蛋白，也可用于验证两个蛋白是否真正结合**。

## 五、体内技术二：双分子荧光互补（BiFC）

**双分子荧光互补（Bimolecular Fluorescence Complementation, BiFC）** 的思路和酵母双杂交很像，但报告信号换成了「**发光**」。

把一个**荧光蛋白**（如 GFP）在合适的位点**切成两半**（A 和 B）。这两半在细胞内共表达时**不会自发重新组合成荧光蛋白**，因此单独存在时不发光。但如果把 **蛋白 X 连上 A、蛋白 Y 连上 B**，当 **X 与 Y 相互作用**时，A、B 在空间上被拉到一起、**重新生成荧光蛋白**，在激发光下**发出荧光**——用荧光显微镜就能观察到。

![lyrical79 手写示意：荧光蛋白切两半 A、B；X-A、Y-B；X 与 Y 结合后 A、B 重组并产生荧光](assets/蛋白质互作（PPI）基础/BV1ZjmPYeEVz_01400.webp)

[【跳转到 23:20】](https://www.bilibili.com/video/BV1ZjmPYeEVz/?t=1400)

因此，**看到荧光 = X 与 Y 相互作用**；不发光则说明两者不互作。它是在**体内或体外**检测蛋白互作的一种直观技术。

## 六、体外技术一：免疫共沉淀（Co-IP）

**免疫共沉淀（Co-Immunoprecipitation, Co-IP）** 是在细胞外（裂解液水平）捕获蛋白复合物的经典方法。

原理是：用**固体基质**（通过亲核试剂连接）连上**靶蛋白的抗体**，抗体再结合**靶蛋白 X**。随后向体系中加入待筛选的**蛋白混合液**（其中含有蛋白 Y），再用**低离心力**或**微膜过滤**，把「固体基质—抗体—X（—Y）」的复合物**沉淀**到管底或滤膜上。

![lyrical79 手写示意：固体基质—抗体—靶蛋白 X，再加蛋白 Y；若 X 与 Y 互作，则 Y 随复合物一起被沉淀（依离心力/微膜过滤）](assets/蛋白质互作（PPI）基础/BV1ZjmPYeEVz_01725.webp)

[【跳转到 28:45】](https://www.bilibili.com/video/BV1ZjmPYeEVz/?t=1725)

如果 **X 与 Y 相互作用**，Y 就会「搭便车」跟着复合物一起被沉淀下来；如果原本加入的蛋白（如 Z）不与 X 互作，就沉淀不下来。Co-IP 可用来检测**已知两个蛋白**之间、或**两个未知蛋白**之间是否存在相互作用。

## 七、体外技术二：pull-down（GST pull-down）

**pull-down** 是另一个体外方法，常用于**证明蛋白互作**或对**未知互作做初始筛选**。这里以一个形象的类比来说明：**GST 是「鱼钩」，X 是「鱼饵」，Y 是「鱼」**。

具体来说：**GST（谷胱甘肽 S-转移酶）能与 GSH（谷胱甘肽）结合**。把 **GST 与诱饵蛋白 X 做成融合蛋白（GST-X）**，当它流经**固定了 GSH 的色谱柱**时，GST 就牢牢挂在柱子上——相当于把「鱼饵 X」用鱼钩挂在了杆上。接着加入含目标蛋白 Y 的混合液：

- 若 **Y 与 X 互作**，Y 就被 X「钓住」，留在柱上；
- 若 **Y 不与 X 互作**，Y 就随液体流走。

![lyrical79 手写示意：GST 与 GSH 结合、GST-X 作诱饵固定在柱上，Y 若与 X 互作则被「钓」下（钓鱼类比）](assets/蛋白质互作（PPI）基础/BV1ZjmPYeEVz_02000.webp)

## 八、别混淆：酵母单杂交与 EMSA 研究的是「蛋白-DNA」

这一组容易和上面的蛋白互作混淆，简单区分：

- **酵母单杂交（Y1H）**：研究的是**DNA 与蛋白质**的互作。原理是在启动子上游插入**已知的顺势作用元件**（即要研究的 DNA 序列），下游接**报告基因**（如 GFP）；把**待测转录因子 cDNA 与 AD 融合**后导入酵母。若待测蛋白能与该 DNA 结合（此时它起到「BD」的作用），再加上 AD，就构成完整转录因子、驱动报告基因表达。它**不能**替代酵母双杂交来研究蛋白-蛋白互作。
- **凝胶阻滞实验（EMSA）**：DNA 与蛋白结合后会形成复合物、**相对分子质量变大**，因此在凝胶电泳中**迁移变慢**（被「阻滞」）。把待测 DNA 做成（放射性）标记探针，与细胞提取物共孵育后跑**非变性凝胶**、再做放射自显影，就能看出 DNA 是否与蛋白结合、以及结合的特异性。它同样研究**蛋白-DNA**。

> **记忆点**：酵母**单**杂交 / EMSA → **蛋白-DNA**；酵母**双**杂交 / BiFC / Co-IP / pull-down → **蛋白-蛋白**。

## 小结

- **二元交互**：任意两个分子（蛋白、mRNA、lncRNA、miRNA、circRNA、DNA…）之间的结合；最常用的是**蛋白-蛋白**与**蛋白-RNA**；「交互」指**直接**相互作用，区别于间接的「二元/三元变量研究」。
- **PPI 核心逻辑**：**由已知的蛋白 A，找到未知的蛋白 B，并证明二者结合**——所有互作研究套路都由此展开。
- **技术总览**：蛋白-DNA（酵母单杂、EMSA）；蛋白-蛋白体内（酵母双杂交、BiFC）；蛋白-蛋白体外（Co-IP、pull-down）。
- **酵母双杂交**：GAL4 拆成 BD / AD，X-BD 与 Y-AD 结合后可组成完整转录因子、激活报告基因；既可用于**筛选**（已知蛋白 + cDNA 文库），也可用于**验证**。
- **BiFC**：荧光蛋白切两半，X、Y 互作时两半重组、发出荧光，显微镜观察。
- **Co-IP**：固体基质 + 抗体捕获靶蛋白 X，与之互作的 Y 被一起沉淀（低离心力/微膜过滤）。
- **pull-down（GST）**：GST-X 作诱饵挂在 GSH 柱上，Y 若与 X 互作则被「钓」住。
- **易错点**：酵母单杂、EMSA 研究的是**蛋白-DNA**，不是 PPI。
