# 小分子药物为什么必须做剂量梯度：量效曲线、EC50 与治疗指数

> 视频来源：[药物效应动力学 量效关系 药理学](https://www.bilibili.com/video/BV1xs421T7J6/)（Bilibili · 生产队的医学牲）｜时长约 11 分钟
> 导读：这支视频是药理学课程里「药物效应动力学」的一节，用十几分钟把量效曲线的两种画法、效能与效价、ED50 与 LD50、治疗指数与安全范围串成一条线。它讲的是一般药物，本文把它翻译成扰动组学的语言——**为什么给细胞加药时「只做一个浓度」几乎必然得出错误结论**。本文不展开 Hill 方程的推导，只讲曲线上各个读数的含义与实验设计上的后果。

## 本讲要解决的核心问题（SCQA）

**背景**：做一次化学扰动实验，最省事的流程是：查文献，挑一个别人用过的浓度，加药，收细胞，测序，看哪些基因变了。这个流程在绝大多数论文的方法部分都能找到。

**冲突**：但同一个化合物，不同文献里的「有效浓度」经常差几个数量级——有的报到纳摩尔，有的报到几十微摩尔。更麻烦的是，**「加药之后细胞确实变了」和「你想要的靶点确实被抑制了」是两件不同的事**：细胞变了，可能是因为靶点被抑制，也可能是因为溶剂本身有毒、化合物在培养基里析出、或者高浓度下它开始抑制一堆无关的蛋白。

**疑问**：那么，一个浓度上的观测结果，凭什么能支撑「抑制了某个靶点会导致某种表达变化」这样的因果结论？药物效应到底是怎么随浓度变化的？

**回答（中心思想）**：**药物效应不是「有」或「没有」，而是剂量的连续函数；只有把整条量效曲线画出来，你才能同时读到四件事——起效的门槛、半最大效应的位置、能达到的最大效应、以及毒性开始出现的位置。** 讲者把这条曲线上的读数拆成两组：一组描述「效应有多强」（阈值、EC50、效能、效价），一组描述「安全余量有多大」（ED50 与 LD50 的距离、曲线的斜率）。缺了任何一组，一个浓度点都无法解释。

## 一、剂量是自变量：量效曲线的两种画法

讲者开场先纠正了一句俗话：「药到病除」并不完整，**药到不等于病除**——药物用得对不对、给药方法是否合理、用药剂量是否正确，都影响治疗效果 [【跳转到 00:05】](https://www.bilibili.com/video/BV1xs421T7J6/?t=5)。这句纠正其实是整节课的题眼：剂量是一个必须被认真对待的自变量。

最朴素的画法是：以药物剂量或浓度为横坐标，以药理效应强度为纵坐标，把测到的点连起来，得到的就是**量效曲线（dose–response curve）** [【跳转到 00:35】](https://www.bilibili.com/video/BV1xs421T7J6/?t=35)。

![以剂量或浓度为横轴、药理效应强度为纵轴，效应随剂量上升后趋于平台，这就是最朴素的量效曲线](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00035.webp)

在一定的剂量范围内，效应强度与浓度成正比；但剂量继续加大，曲线会弯下来、走平——**效应有天花板**。这个「上升 + 平台」的形状，是后面所有参数的来源。

### 1.1 量反应与质反应：你测的是数值，还是状态

讲者把量效曲线分成两类，区分标准是**你观察的指标是什么类型** [【跳转到 01:00】](https://www.bilibili.com/video/BV1xs421T7J6/?t=60)：

| | 量反应（graded） | 质反应（quantal / all-or-none） |
| --- | --- | --- |
| 观察指标 | 可以用具体数值表示 | 性质不同的两种状态 |
| 举例 | 尿量多少、心率快慢、血压升降、血糖高低、肌肉张力大小 | 存活与死亡、惊厥与不惊厥、睡眠与觉醒、麻醉与非麻醉、有毒与无毒 |
| 研究对象 | 个体 | 群体 |
| 纵轴 | 效应强度（或效应的百分比） | 反应出现的频数，或累加阳性率 |

![量反应量效曲线：纵轴是可用数值表示的效应强度，横轴是剂量或浓度](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00060.webp)

这个区分在单细胞实验里非常实用。**量反应**对应的是「每个细胞测一个连续读数」——比如某个标记基因的 UMI 计数、某个荧光报告基因的强度；**质反应**对应的是「每个细胞只判一个二值状态」——比如是否进入凋亡、是否进入增殖周期、是否表达某个状态标记。前者画出来是曲线，后者画出来是比例。

### 1.2 为什么横轴一定要取对数

这是本节第一个「技术细节决定结论」的地方。讲者说得很直接：如果以**浓度**为横轴、以**效应的百分比**为纵轴，得到的是一条「直方双曲线」（双曲线的一支）——**这种曲线很难进行药物间量效关系的比较** [【跳转到 01:55】](https://www.bilibili.com/video/BV1xs421T7J6/?t=115)。

原因是：药物的有效浓度往往横跨好几个数量级（纳摩尔到微摩尔），线性坐标下绝大多数点会挤在靠近原点的一小段里，曲线左端几乎竖着上去，右端拖一条长长的尾巴。你既看不清左端发生了什么，也没法把两条曲线并排比较。

**换成对数浓度（$\log C$）作为横轴，同一条曲线就变成一条对称的 S 型曲线。** 这一个换轴的动作带来三个直接后果：

1. **阈浓度看得见了**。S 曲线的最低点是**最小有效量**（也称阈剂量、阈浓度），指引起药理效应的最小剂量或最小药物浓度。低于阈浓度，药物通常不产生效果——这正是「药到不等于病除」的量化版本 [【跳转到 02:20】](https://www.bilibili.com/video/BV1xs421T7J6/?t=140)。
2. **中段最灵敏**。曲线的中段部分是最灵敏的，**剂量的很小变化会带来效应的明显变化**；而曲线的两端（阈附近和平台附近）对剂量几乎不敏感。
3. **半最大效应点可以定义**。以引起 50% 效应所需要的剂量或浓度，确定为**半最大效应剂量或浓度**，用 ED50 或 EC50 表示。

![对数浓度横轴下的对称 S 型量效曲线：50% 效应对应的浓度就是 EC50，曲线的中段最陡也最灵敏](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00140.webp)

> **对扰动实验的直接推论**：既然中段最灵敏、两端最迟钝，那么「随便挑一个浓度」最可能挑到的地方恰恰是两端——要么低到什么都测不出，要么高到已经进入平台、甚至进入毒性区。这就是为什么药理学实验几乎总是用**对数间隔**布点，而不是线性间隔。布点的范围、点数与间隔需要单独设计，不能靠「挑一个文献浓度」代替。

## 二、S 曲线上的两个强度读数：效能与效价

有了曲线，接下来要回答的是「这个药有多强」。讲者强调，为了客观量化效应的变化，药理学上常用到**两个**概念，而且这两个概念经常被初学者混为一谈 [【跳转到 02:45】](https://www.bilibili.com/video/BV1xs421T7J6/?t=165)。

### 2.1 效能：曲线能爬多高

**效能（efficacy）**指药物所能达到的最大效应，记作 $E_{\max}$，反映药物**内在活性**的大小 [【跳转到 03:10】](https://www.bilibili.com/video/BV1xs421T7J6/?t=190)。

![效能 efficacy 指药物能达到的最大效应 Emax，反映内在活性；图中平台高度就是效能](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00190.webp)

用曲线的语言说：药物的效应在一定剂量范围内随剂量增加而增强，增加到一定程度时效应不再继续增强，**这一药理效应的极限就是最大效应或效能**。它对应的是 S 曲线上方那条渐近线的高度。

对单细胞扰动来说，效能这个概念有一个非常具体的含义：**如果某个化合物对某个通路的最大抑制能力只有 40%，那么无论你把浓度加到多高，这条通路上都不会出现「完全关闭」的表达谱。** 这种情况下的高浓度实验，你看到的不是更强的扰动，而是更多的脱靶。

### 2.2 效价：曲线在横轴上的位置

**效价强度（potency，简称效价）**是指能引起**等效反应**的剂量，**其数值越小则效价强度越大**——它反映的是药物与受体的**亲和力**大小 [【跳转到 04:00】](https://www.bilibili.com/video/BV1xs421T7J6/?t=240)。

![效价强度 potency 指引起等效反应的剂量，数值越小效价越大；图中 A、B、C、D 四种利尿药曲线位置不同、平台高度也不同](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00265.webp)

讲者用四种同属利尿药的化合物把两个概念彻底分开，这个例子值得完整复述，因为它同时演示了「效能」和「效价」为什么会给出相反的排序：

- **效能最大的是 C 药**。它产生的最大利尿效果，是 A、B、D 药无论使用多大剂量也无法产生的。
- **效价最大的却是 A 药**。因为 A 药 1 毫克就等于 C 药 100 毫克的利尿效应，所以效价 A 大于 C。
- 但**继续提高 A 的剂量，也不会增加它的每日排尿量**——A 的平台比 C 低。

于是出现了一个在临床上很典型的场景：**用 A 无效的患者，改用 C 后常能继续利尿，取得更强的治疗效果**。讲者的结论是：**在安全剂量范围内，效能比效价更重要** [【跳转到 04:40】](https://www.bilibili.com/video/BV1xs421T7J6/?t=280)。

> **这个结论对实验设计的推论**：挑化合物时，「IC50 更低」通常被当作「更好」，但 IC50 低只说明效价高，不说明它能达到你想要的最大效应。如果目标是「把某条通路压到底」，该看的是效能；如果目标是「在尽量低的浓度下拿到一半效应、减少脱靶」，才该看效价。

## 三、从「有效」到「安全」：质反应曲线与治疗指数

量反应曲线告诉你效应有多强，但它回答不了另一个问题：**剂量再往上加，什么时候开始出事？** 这个问题要靠质反应曲线。

### 3.1 质反应曲线的两条画法

讲者给出的做法是：如果以药物剂量或浓度为横坐标、以**反应出现的频数**为纵坐标作图，质反应量效曲线呈**正态分布曲线**；如果以对数剂量或对数浓度为横坐标、以**累加阳性率**为纵坐标作图，质反应量效曲线呈现**对称 S 型** [【跳转到 05:40】](https://www.bilibili.com/video/BV1xs421T7J6/?t=340)。

![质反应量效曲线：横轴为对数剂量，阴影是反应频数的正态分布，阶梯状的累加曲线被拟合成一条对称 S 曲线，中点即 ED50](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00340.webp)

这两条曲线是同一批数据的两种呈现：**频数分布**告诉你「多少个个体在哪个剂量上发生反应」，**累加阳性率**告诉你「到某个剂量为止，累计多少比例的个体发生了反应」。S 曲线的中点，就是 50% 个体发生反应的那个剂量。

### 3.2 效应、中毒、死亡：三条曲线排在一起看

把「治疗量的累加量效曲线」「中毒量的累加量效曲线」「致死量的累加量效曲线」画在同一张图上，量变到质变的过程就一目了然：药物的效应与剂量只在一定范围内随剂量增加而增强，**但超过一定剂量范围，效应就会从量变引起质变，引起毒性反应，出现中毒甚至死亡** [【跳转到 06:05】](https://www.bilibili.com/video/BV1xs421T7J6/?t=365)。

![治疗量、中毒量、致死量三条累加量效曲线依次右移：剂量继续加大时，效应曲线之后还有中毒曲线和死亡曲线](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00365.webp)

讲者用了一个真实案例把这件事落地：年仅 27 岁的小张因感冒发烧应用对乙酰氨基酚（扑热息痛）治疗，但由于药物过量导致肝肾衰竭，入院仅七天去世。**正常剂量时可以用于治疗感冒发烧，但用药剂量过大会导致疗效由量变到质变**，患者最终因药物过量出现肝肾功能衰竭而死亡 [【跳转到 06:53】](https://www.bilibili.com/video/BV1xs421T7J6/?t=413)。

一句话总结这一层：**药量太小无法起效，药量过大出现毒性。**

### 3.3 四个参数：ED50、ED95、LD50、LD5

在这三条曲线上，可以读出四个关键刻度 [【跳转到 07:34】](https://www.bilibili.com/video/BV1xs421T7J6/?t=454)：

| 参数 | 定义 | 反映什么 |
| --- | --- | --- |
| ED50（半数有效量） | 引起 50% 实验动物出现阳性反应的药物剂量 | 有效性 |
| ED95 / ED99 | 引起 95% / 99% 实验动物出现阳性反应的剂量 | 有效性的上界 |
| LD50（半数致死量） | 能引起 50% 实验动物死亡的药物剂量 | 急性毒性 |
| LD1 / LD5 | 能引起 1% / 5% 实验动物死亡的剂量 | 毒性的下界 |

![质反应曲线上同时读出 ED50、ED95、ED99 与 LD50：左边是有效性曲线，右边是急性毒性曲线](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00504.webp)

把 LD50 与 ED50 相除，就得到**治疗指数（therapeutic index）**，可用于评价药物的安全性，**其数值越大，药物相对越安全** [【跳转到 08:24】](https://www.bilibili.com/video/BV1xs421T7J6/?t=504)。

### 3.4 治疗指数相同，安全性可以完全不同

这是整支视频里最反直觉、也最有价值的一段。讲者设了一个局：A 药和 B 药的 LD50 和 ED50 完全相同，所以**两药治疗指数相同**。那么这两个药就一样安全吗？[【跳转到 09:14】](https://www.bilibili.com/video/BV1xs421T7J6/?t=554)

答案是**不一样，取决于曲线的斜率**：

- **A 药**表示疗效的曲线和表示毒性的曲线**首尾无重叠**：在 ED95 和 ED99 时没有动物死亡。
- **B 药**表示疗效的曲线与表示毒性的曲线**首尾有重叠**，即 $LD_5 < ED_{95}$——说明 B 药**在未达到最大效应时，已经出现动物死亡**。

![A 药与 B 药治疗指数相同但曲线斜率不同：A 药疗效与毒性曲线不重叠，B 药两者首尾重叠，因此实际安全性 A 优于 B](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00554.webp)

所以结论是：**单用治疗指数不能完全反映药物的安全性**。讲者给出两个补充指标 [【跳转到 10:04】](https://www.bilibili.com/video/BV1xs421T7J6/?t=604)：

- **安全范围**：5% 致死量与 95% 有效量之间的距离，其值越大，药物越安全；
- **可靠安全系数**：1% 致死量与 99% 有效量的比值。**若系数小于 1，说明有效量与致死量仍有重叠，是不安全的。**

![安全范围的读法：ED95 与 LD5 之间的距离越大越安全；若两者重叠，可靠安全系数小于 1](assets/小分子药物为什么必须做剂量梯度：量效曲线、EC50%20与治疗指数/00579.webp)

> **这里隐藏着一个对扰动组学极其重要的提醒**：斜率本身是信息。两条曲线可以中心位置相同（同样的 ED50、同样的 LD50），却因为陡峭程度不同而有完全不同的安全边界。在剂量-反应曲线里，**陡峭度由 Hill 系数描述**，它决定的是曲线中段的斜率，而不是曲线中心的位置。

## 四、把这张图搬到单细胞扰动实验上

讲者最后留了一个思考题：**在某一药物的量效曲线上可以得到哪些信息？** [【跳转到 10:53】](https://www.bilibili.com/video/BV1xs421T7J6/?t=653) 把前面几节的答案收拢起来，就是本节要回答的那个问题——为什么「一个浓度」的实验结论常常不可靠。

**第一，一个浓度落在曲线的哪个区段，决定了你能看到什么。** 落在阈浓度以下，你看到的是「没有差异」，但这个「没有差异」只说明剂量不够，不说明通路无关；落在平台上，你看到的是「饱和响应」，此时再加浓度不会给出更多信息，只会引入毒性；只有落在中段，剂量的小变化才会被效应放大，信号最容易被检出。

**第二，一个浓度无法区分「靶点特异效应」与「非特异毒性」。** 讲者用对乙酰氨基酚的例子说明，同一个分子在低剂量是药、在高剂量是毒，**两者作用在完全不同的机制上**。在细胞实验里，高浓度化合物最常见的非特异效应就是细胞毒性——而毒性本身会带来一整套应激、凋亡、细胞周期相关的表达变化，这些变化在差异表达列表里看起来和「靶点被抑制」造成的表达变化一样显著。

**第三，效能决定你的实验有没有可能成功。** 如果一个化合物对该靶点的最大抑制只有 40%，那么无论怎么加浓度，你都拿不到「完全抑制」的对照；这时候「加药后仍有残余表达」不能解释成「扰动不完全」，它就是这条曲线的天花板。

**第四，安全性边界决定了你的浓度上限。** 治疗指数、安全范围、可靠安全系数这套语言，在细胞实验里的对应物是「有效浓度」与「细胞毒性浓度」之间的窗口。窗口越窄，可供布点的浓度区间越窄，也越需要密集的梯度。

> **本节边界**：溶剂（DMSO）对照的原则、vehicle 与 untreated 的区别，属于本系列 3.1.3 节；这里只提醒一句——DMSO 本身有细胞毒性，梯度实验里最高浓度点对应的 DMSO 百分比，必须和溶剂对照保持一致。化合物溶解度、析出、单细胞层面「同一浓度下细胞间响应异质」这些陷阱，属于本系列 3.4.4 节与本小节其他篇目的范围。

## 小结

- **药物效应是剂量的连续函数**，不是「有/没有」。只看一个浓度，无法判断这个浓度落在曲线的哪一段，因此无法解释结果。
- **横轴必须取对数**。线性坐标下曲线挤成一团、无法比较；取对数后得到对称 S 曲线，阈浓度、EC50、平台高度才都读得出来。
- **量反应看数值、质反应看比例**。前者研究对象是个体（尿量、心率、表达量），后者研究对象是群体（存活/死亡、是否进入某状态）。
- **效能与效价是两件事**：效能是曲线能爬多高（内在活性），效价是曲线在横轴的哪个位置（亲和力）。安全剂量范围内，效能比效价更重要。
- **S 曲线的中段最灵敏、两端最迟钝**——这正是剂量梯度要用对数间隔、且必须覆盖中段的原因。
- **治疗指数相同不代表安全性相同**，还要看曲线斜率：疗效曲线与毒性曲线是否首尾重叠，决定了安全范围与可靠安全系数。
- **在扰动实验里，一个浓度同时混淆了三件事**：剂量落在哪一段、效应是靶点特异还是毒性非特异、以及这条通路本身的天花板有多高。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 量效关系 | 在一定剂量范围内，药物效应强度随剂量或浓度变化的关系 |
| 量效曲线 | 以剂量或浓度为横轴、以效应强度为纵轴画出的曲线，通常呈上升后走平 |
| 量反应 | 观察指标可用具体数值表示的效应，研究对象是个体 |
| 质反应 | 观察指标是两种性质不同状态的效应，研究对象是群体 |
| 阈浓度 | 能引起药理效应的最小剂量或最小浓度，低于它通常无效 |
| EC50 / ED50 | 引起 50% 最大效应（或 50% 个体出现阳性反应）的浓度/剂量 |
| 效能（efficacy，$E_{\max}$） | 药物能达到的最大效应，反映内在活性，对应曲线平台高度 |
| 效价强度（potency） | 引起等效反应所需的剂量，数值越小效价越大，反映亲和力 |
| LD50 | 能引起 50% 实验动物死亡的剂量，反映急性毒性 |
| 治疗指数 | LD50 与 ED50 的比值，数值越大相对越安全 |
| 安全范围 | 5% 致死量与 95% 有效量之间的距离，越大越安全 |
| 可靠安全系数 | 1% 致死量与 99% 有效量的比值，小于 1 表示有效量与致死量重叠 |
