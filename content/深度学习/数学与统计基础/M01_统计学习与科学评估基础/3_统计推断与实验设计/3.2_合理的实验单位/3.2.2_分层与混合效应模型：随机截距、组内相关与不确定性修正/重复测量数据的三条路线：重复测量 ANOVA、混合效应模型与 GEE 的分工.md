# 同一个人测四次不算四份数据：重复测量 ANOVA、混合效应模型与 GEE 的分工

> 视频来源：[重复测量ANOVA、GEE和混合效应模型，到底怎么选？](https://www.bilibili.com/video/BV1gEHD6UEUS)（Bilibili · 尖研统计）｜时长约 6 分钟
> 导读：一支 6 分钟的动画讲解，用「同一位患者在基线、3、6、12 个月各测一次血压」把三种方法摆在一起：它们解决同一个问题（患者内相关），区别在于处理相关的方式和适合的数据形状。本文保留视频给出的三问判断顺序、三种方法的边界，以及「没有谁更高级」的结论。

## 本讲要解决的核心问题（SCQA）

**背景**：纵向数据里，同一个人被反复测量——基线、3 个月、6 个月、12 个月，一共四次血压。做分析时，这四次测量就是表里的四行。

**冲突**：这四行**不是四份互相独立的数据**。它们都来自同一个人，同一个人反复测量的结果彼此相关。重复测量 ANOVA、GEE、混合效应模型其实都在解决同一个核心问题——同一个人被反复测量时，怎样正确分析随时间发生的变化——但它们处理这种相关性的方式不同，适合的数据场景也不同。[【跳转到 00:10】](https://www.bilibili.com/video/BV1gEHD6UEUS/?t=10)

**疑问**：三种方法看起来都能跑出「随时间变化」的结论，到底该用哪一个？

**回答（中心思想）**：**先问研究问题，再问数据结构，最后才选模型**。要比较固定时间点的平均值、数据又很规整，用重复测量 ANOVA；要看总体趋势、又允许每个人有自己的起点和变化速度、数据还不整齐，用混合效应模型；只关心整个人群平均怎么样、结局是反复出现的二分类或计数，用 GEE。三者没有谁一定更高级。

## 一、先看三个问题，再看三个方法

讲者在展开方法之前，先给了选型前必须回答的三个问题：

1. **数据规不规则、有没有缺失？** 每个人的时间点和测量次数是否一致，有没有人少来一次。
2. **你真正想回答的是整体时间趋势，还是更关注个体之间的差异？**
3. **结局是什么类型？** 连续变量，还是达标/未达标这类二分类，或计数。

这三个问题决定了后面所有选择。方法本身没有优劣，只有「和问题、数据结构是否匹配」。[【跳转到 00:35】](https://www.bilibili.com/video/BV1gEHD6UEUS/?t=35)

## 二、重复测量 ANOVA：比较固定时间点的平均值

重复测量 ANOVA 可以简单理解成：**同一批患者在多个固定时间点反复测量，然后比较这些时间点的平均值有没有变化**。

![重复测量 ANOVA 的定位：0、3、6、12 个月四次血压，比较平均血压是否随时间下降、两组总体有无差异、两组变化趋势是否不同](assets/重复测量数据的三条路线：重复测量%20ANOVA、混合效应模型与%20GEE%20的分工/00065.webp)

它能回答三类问题：平均血压是否随时间下降；如果有 A、B 两组，两组总体有没有差异；两组的变化趋势是不是不一样。

| | 重复测量 ANOVA |
| --- | --- |
| 适合的数据 | 时间点固定、每个人测量次数基本一致、数据比较完整、研究结构简单 |
| 好处 | 逻辑直观，结果也容易解释 |
| 局限 | 一旦有人少来一次，或实际随访时间不完全一致，数据开始「不整齐」，灵活性就下降 |

讲者的措辞很准确：它更像是在**比较不同时间点的平均值**，以及不同组的平均变化。这句话已经暗示了它的边界——它处理的是「平均」，不是「每个人自己的轨迹」。[【跳转到 01:05】](https://www.bilibili.com/video/BV1gEHD6UEUS/?t=65)

## 三、混合效应模型：总体趋势加每个人的起点与速度

混合效应模型和重复测量 ANOVA 最大的区别是：它**不仅关心大家平均怎么变，还允许不同患者有自己的特点**。

![混合效应模型的两层结构：一层是所有患者共同的平均变化，另一层是不同患者之间的个体差异；患者 A 起点高、下降快，患者 B 起点低、下降慢](assets/重复测量数据的三条路线：重复测量%20ANOVA、混合效应模型与%20GEE%20的分工/00144.webp)

讲者用两位患者把「个体差异」讲得很具体：患者 A 血压起点比较高、下降也快；患者 B 起点低一些、下降速度也慢。混合效应模型可以同时描述总体平均变化，也把不同患者之间的**起点差异**和**变化速度差异**考虑进去。

所以它天然是两层的：

- **一层**是所有患者共同的平均变化（固定效应）；
- **另一层**是不同患者之间的个体差异（随机效应）。

这也正是 3.2.2 另一篇里随机截距模型的同一个结构——只不过那里讲的是「组」，这里讲的是「人」。

真实临床数据几乎都不整齐：有人测四次，有人只测三次，有人甚至测五次，还有人本来三个月复查、结果第四个月才回来。对血压、HbA1c、BMI、eGFR 这类**连续型纵向指标**，混合效应模型通常会更灵活。[【跳转到 02:24】](https://www.bilibili.com/video/BV1gEHD6UEUS/?t=144)

## 四、GEE：只回答「整个人群平均怎么样」

如果结局不是连续变量，而是「达标/未达标」这种分类变量，就轮到 GEE（广义估计方程）。

![GEE 的定位：同样考虑患者内相关，但只回答整个人群平均的达标概率有没有变化，关键词是 population-averaged effect](assets/重复测量数据的三条路线：重复测量%20ANOVA、混合效应模型与%20GEE%20的分工/00199.webp)

GEE 同样会考虑同一个患者多次测量之间的相关性，但它更关注**整个研究人群平均来看，结果发生了什么变化**。比如每次随访记录的是血压达标还是未达标，同一个患者在不同时间点的结果仍然相关；GEE 把这种患者内相关性考虑进去，然后回答：整个人群平均来看，达标概率有没有变化？A 方案和 B 方案的总体平均达标概率有没有差异？[【跳转到 02:54】](https://www.bilibili.com/video/BV1gEHD6UEUS/?t=174)

这里的关键词是 **population-averaged effect（人群平均效应）**。讲者还补了一句：GEE 并不是只能分析二分类结局，连续型、二分类、计数型等重复结局都可以应用。

一句话记住三者的差别：**GEE 更关注「这群人平均怎么样」，而不是「每个人自己的轨迹怎么样」。**

## 五、怎么选：三种情况，一张决策表

讲者把选择压缩成三种情况：

![三种情况的选择：数据非常规则用重复测量 ANOVA；数据不整齐、结局连续、想看个体起点与速度用混合效应模型；只关心人群平均用 GEE](assets/重复测量数据的三条路线：重复测量%20ANOVA、混合效应模型与%20GEE%20的分工/00234.webp)

| 情况 | 数据与研究问题 | 选择 |
| --- | --- | --- |
| 情况 1 | 所有患者时间点一样、测量次数一样、数据完整、结构简单 | 重复测量 ANOVA |
| 情况 2 | 有人测 3 次、有人测 5 次，随访时间不齐；结局是连续变量；还想考虑不同患者的起点和变化速度 | 混合效应模型 |
| 情况 3 | 更关心整个人群的平均结果（反复记录是否达标、是否出现不良反应、住院次数等），希望回答人群平均效应 | GEE |

而**选择的顺序**不是「哪个模型更高级」，而是：

> 研究问题 → 结局类型 → 数据结构（规则还是不整齐）→ 是否需要考虑个体差异 → 最后才选模型。

![一句话带走三种方法：重复测量 ANOVA 看固定时间点的平均值，混合效应模型既看总体也允许个体差异，GEE 看人群平均；三者没有谁一定更高级](assets/重复测量数据的三条路线：重复测量%20ANOVA、混合效应模型与%20GEE%20的分工/00319.webp)

## 六、三种方法的分工，可以这样记

| | 重复测量 ANOVA | 混合效应模型 | GEE |
| --- | --- | --- | --- |
| 回答的问题 | 几个固定时间点的平均值怎么变 | 总体怎么变，同时每个人怎么变 | 整个人群平均怎么变 |
| 个体差异 | 不建模 | 随机效应显式建模（起点、速度） | 不估个体轨迹，只作冗余处理 |
| 数据要求 | 规则、完整、次数一致 | 允许不平衡、时间点不齐 | 允许不平衡，需指定工作相关结构 |
| 结局类型 | 连续 | 连续为主（广义版本可扩展） | 连续、二分类、计数均可 |
| 典型场景 | 固定随访的对照试验 | 真实临床纵向数据 | 反复出现的达标/计数结局 |

最后一行「典型场景」是本文按视频的适用条件归纳的，视频本身只给了三种情况的选择表。

> 与随机截距的关系：混合效应模型里那「两层」就是固定效应加随机效应；GEE 不估随机效应，只估人群平均，所以**同一份数据用两者会得到含义不同的系数**——一个是个体特异效应，一个是人群平均效应。选哪个，取决于你要回答哪一个问题。

## 小结

- **患者内相关**是三种方法共同的起点：同一个人反复测量，四行数据不是四份独立证据。
- **重复测量 ANOVA** 比较固定时间点的平均值，适合规则、完整、次数一致的数据；数据一不整齐，灵活性就下降。
- **混合效应模型**分两层：总体平均变化 + 个体差异（起点、速度），适合不平衡的连续纵向数据。
- **GEE** 估计人群平均效应，适合反复出现的二分类、计数结局，也适用于连续结局。
- **选择顺序**：研究问题 → 结局类型 → 数据结构 → 是否需要个体差异 → 模型；三者没有谁更高级。
- **同一份数据，混合模型与 GEE 的系数含义不同**：前者是个体特异效应，后者是人群平均效应。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 重复测量 | 同一个体在多个时间点被反复观测，观测之间不独立 |
| 患者内相关 | 同一个体多次测量之间的相关性，纵向数据必须处理的结构 |
| 重复测量 ANOVA | 在固定时间点上比较均值的方法，要求数据规整、次数一致 |
| 混合效应模型 | 固定效应描述总体趋势、随机效应描述个体差异的两层模型 |
| 随机效应 | 每个个体（或组）自己的偏移，报告为方差 |
| GEE | 广义估计方程，估计人群平均效应，用工作相关结构处理个体内相关 |
| 人群平均效应 | 把整个人群平均起来看的效应，不描述任何一个个体的轨迹 |
| 不平衡数据 | 各个体的测量次数或时间点不一致的纵向数据 |
