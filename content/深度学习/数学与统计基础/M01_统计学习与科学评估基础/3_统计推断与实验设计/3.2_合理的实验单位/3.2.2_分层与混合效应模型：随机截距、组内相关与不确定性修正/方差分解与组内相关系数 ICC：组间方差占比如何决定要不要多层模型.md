# 方差分解与组内相关系数 ICC：组间方差占比如何决定要不要多层模型

> 视频来源：[变异水平和组内相关系数](https://www.bilibili.com/video/BV1Gm421W7Qr)（Bilibili · 小云爱生信）｜时长约 10 分钟
> 导读：一支英文统计课的搬运（中文字幕为机器翻译），讲者用「25 家公司、5 个行业、5 年盈利」的例子，把多层数据的方差拆成组间与组内，给出 ICC1 的定义、两个极端（0 与 1）的箱线图长相，以及「ICC 多大才需要多层模型」的判断与报告写法。字幕里 intraclass correlation 被译成「类间相关性」「国际商会」、boxplot 被译成「方框图」、cluster 被译成「星系团」，本文已按画面幻灯片订正；凡属本文由画面公式推出的一步，均已标注。

## 本讲要解决的核心问题（SCQA）

**背景**：拿到一张带分组列的数据表——每个样点若干样本、每个患者若干次随访、每家公司若干年——跑一个普通回归，得到系数和 p 值，这是最常见的做法。

**冲突**：同一组的观测彼此相关，普通回归却把它们当成互相独立的证据，标准误偏小、p 值偏小。可「相关到底有多强」一直停留在直觉层面：看一眼箱线图觉得「组间好像有差别」，却说不出一个数。

**疑问**：有没有一个数，能直接量出「总变异里有多少来自组与组的不同」？这个数多大时，才**必须**把层级写进模型？

**回答（中心思想）**：把总方差拆成**组间方差**与**组内方差**，二者之比就是组内相关系数 ICC1。ICC 接近 0 时层级可以不管；接近 1 时每组取一个观测就够；**落在中间地带时，必须把层级写进分析**——用多层模型，或用聚类标准误修正不确定性。

## 一、三层嵌套：年份套在公司里，公司套在行业里

讲者的例子是一份公司盈利数据：25 家公司、5 个行业、每家公司 5 年。数据结构因此有三层：

- **L1（最低层）**：某家公司某一年的盈利观测；
- **L2**：公司——同一家公司的 5 个年份观测归它管；
- **L3**：行业——同一行业的 5 家公司归它管。

![三层嵌套的盈利数据：绿色是全部观测的总密度，蓝色是各公司的分布，红色是各年份的分布——同一份数据里同时存在多个层级的变异](assets/方差分解与组内相关系数%20ICC：组间方差占比如何决定要不要多层模型/00101.webp)

为什么不能只看总密度那条绿色曲线？因为「一家公司有时好年景、有时坏年景」和「这家公司长期比那家公司赚得多」是两种完全不同的变异来源。前者是组内波动，后者是组间差异。只看总分布，两者混在一起。[【跳转到 00:33】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=33)

讲者还强调：层级数量没有上限，可以继续往上加（行业之上还有地区、年份之上还有季度）。本例停在行业这一层，是因为三层已经足够说明问题。

## 二、方差分解：先算组均值，再做组均值中心化

要拆开两种变异，只需要三步算术。

**第一步，算组均值**。把每家公司的 5 个观测求平均，得到 5 个「簇均值」（cluster mean）。这些均值之间变化多大，就是**组间方差**。

**第二步，组均值中心化**。把每个观测减去它所在组的均值，得到「组均值中心化值」。这些值变化多大，就是**组内方差**。

**第三步，相加**。总方差 = 组间方差 + 组内方差。

![方差分解的算表：每一行是一家公司，中间是组均值，右边是减去组均值后的中心化值；最下面一行 Var 给出组间与组内的方差](assets/方差分解与组内相关系数%20ICC：组间方差占比如何决定要不要多层模型/00360.webp)

这张表把「分解」变成了看得见的列：同一行内的中心化值有正有负、量级不大，说明组内波动有限；而组均值那一列在不同行之间拉开了距离，说明组间差异明显。[【跳转到 05:12】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=312)

但方差有个毛病：**它带量纲**。盈利的方差是「百分点的平方」，换成收入、换成体重，数值完全不可比。要跨变量、跨研究比较「组间差异到底占多大份量」，需要一个无量纲的比例。

## 三、ICC1：组间方差占总方差的比例

这个比例就是组内相关系数：

$$
\mathrm{ICC1} = \frac{\text{组间方差}}{\text{组间方差} + \text{组内方差}}
$$

![ICC1 的定义与两个极端：公式是组间方差除以总方差；左图 ICC1=0 时各组箱线图重叠在同一水平，右图 ICC1=1 时每个箱线图退化成一条线](assets/方差分解与组内相关系数%20ICC：组间方差占比如何决定要不要多层模型/00543.webp)

它的读法只有一句：**因变量的总变异里，有多大比例来自「组与组不同」，而不是「组内个体不同」**。ICC 之所以叫「组内」相关，是因为它同时也在度量同一组内任意两个观测的相关程度——ICC 越高，同组观测越像（这一步由公式与两个极端的定义直接推出）。

两个极端最好记：

| 取值 | 含义 | 箱线图长相 |
| --- | --- | --- |
| ICC1 = 0 | 没有聚类，最低层单位彼此独立 | 各组箱子都在同一水平，中位数接近，箱子互相重叠 |
| ICC1 = 1 | 簇内没有方差，所有观测都等于本组均值 | 每个箱子退化成一条水平线，线的高度就是该组均值 |
| 0 < ICC1 < 1 | 组内既相似又有差异，两层都有信息 | 箱子各自错开，但仍有高度 |

讲者用两张并排的箱线图把这两个极端画了出来：左边 ICC1=0，五个箱子在同一水平线上摊开；右边 ICC1=1，五个箱子变成五条互不重叠的短线。[【跳转到 07:20】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=440)

## 四、ICC 的第一个用途：决定要不要为「组」做点什么

算 ICC 不是为了报告一个漂亮数字，而是为了回答一个决策问题：**这个分组变量值不值得在分析里特殊对待**。

讲者给的判断链是这样的：

1. **ICC1 = 1（簇内完全无变异）**：每组取一个观测放进回归就够了。剩下的观测不会给你更多数据——它们和取走的那一个是同一个值。[【跳转到 08:16】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=496)
2. **ICC1 = 0（没有聚类）**：这个变量里没有组结构，普通回归没问题。如果所有变量的 ICC 都很低，说明没有有意义的聚类，不做多层建模通常是安全的。
3. **ICC 落在中间**：组内既有相似性、又有差异，两层都带信息，**通常需要在分析里考虑层级**。讲者给了一个粗略的参照：到 50% 左右，基本就不能再忽略层级了。

![ICC 的决策用途：先判断「簇内观测是否完全相同」，再判断「ICC 是否接近 0」，两头都可以简化，中间地带才需要多层模型或聚类标准误](assets/方差分解与组内相关系数%20ICC：组间方差占比如何决定要不要多层模型/00496.webp)

讲者也说明这条规则有例外——ICC 只是决策的一个输入，不是自动开关。但它把「要不要多层模型」从口味问题变成了可计算的问题。

## 五、ICC 高时，普通回归的标准误为什么不可信

这是 ICC 与「不确定性」之间最关键的一环，也是本小节学习目标里那条「组内相关对标准误的影响」。

普通回归的标准误是按「有 $n$ 个独立观测」算的。但 ICC 高意味着同一组内的观测高度重复：它们提供的是同一份信息的多个副本，而不是 $n$ 份独立证据。于是**有效样本量远小于观测数**——ICC = 1 时，有效样本量就等于组数。

有效样本量一小，标准误就被低估，置信区间过窄，p 值过小。这正是讲者引用的那篇已发表研究的说法：**如果 ICC 数值很高，普通回归分析可能不合适，就得做别的事情，例如使用聚类标准误，或者多层建模**。[【跳转到 09:49】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=589)

由此可以推出一条对实验设计很实用的结论（本文推论）：**在 ICC 高的数据里，增加同一组内的观测数，几乎不增加有效样本量**；要提高推断精度，得增加**组数**，而不是把每组测得更细。这与 3.2.1 讲的伪重复是同一件事的两个视角：那边看 p 值怎么被细胞数带偏，这边看方差里有多少份量根本不属于组内。

## 六、ICC 怎么写进报告

讲者最后展示了一篇论文的写法，并逐句拆开：

1. 先解释这个统计量**是什么**（一句话，不假设读者懂多层模型）；
2. 再给一句简明的解释：ICC 可以理解为「因变量总方差中，由单位之间的差异、而不是单位内部随时间变化所解释的那部分」；
3. 再给实际取值，以及这个取值对分析的含义（例如「数值较高，因此普通回归不合适，改用聚类标准误或多层模型」）。

讲者的评价是：**简短地解释你的统计量，对读者非常有用**，因为读者未必是多层数据的专家。[【跳转到 10:14】](https://www.bilibili.com/video/BV1Gm421W7Qr/?t=614)

可以直接套用的模板：

> 我们计算了组内相关系数 ICC = 0.xx，表示该指标的总方差中有 xx% 来自组间（个体/样点/中心之间）差异，其余来自组内。据此，我们在模型中加入了随机截距 / 使用了聚类稳健标准误。

## 小结

- **多层数据的方差可以拆开**：组均值之间的变化是组间方差，观测减去组均值后的变化是组内方差，两者相加是总方差。
- **ICC1 = 组间方差 /（组间方差 + 组内方差）**，是一个无量纲的比例，回答「总变异里有多少来自组与组的不同」。
- **两个极端有明确含义**：ICC1 = 0 表示没有聚类；ICC1 = 1 表示簇内没有方差、每组取一个观测就够。
- **决策规则**：ICC 接近 0 可以不管层级；接近 1 可以聚合到组均值；**居中时必须在分析里考虑层级**。
- **ICC 高会破坏普通回归的标准误**：有效样本量远小于观测数，标准误被低估、p 值偏小；补救办法是聚类标准误或多层模型。
- **报告时先解释再报数**：一句话说明 ICC 是什么、占比多少、因此选了什么模型。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 组内相关系数（ICC） | 组间方差占总方差的比例，衡量同组观测的相似程度 |
| 组间方差 | 各组均值围绕总均值的变异，反映「组与组不同」 |
| 组内方差 | 组内观测围绕本组均值的变异，反映「组内个体不同」 |
| 组均值中心化 | 每个观测减去所属组的均值，用来分离组内变异 |
| 簇（cluster） | 共享同一分组标签的一组观测，如一家公司、一个样点、一位患者 |
| 多层模型 | 把不同层级的方差分别建模的模型，随机截距是其中最简单的一种 |
| 聚类标准误 | 允许同一簇内观测相关、只按簇数计算有效信息的标准误修正 |
| 有效样本量 | 扣除组内重复信息后，真正独立的证据份数 |
