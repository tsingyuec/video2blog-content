# 多分类指标怎么合成一个数：micro 累加与 macro 平均

> 视频来源：[二分类多分类评估指标：F1指标，Micro-F1，Macro-F1，混淆矩阵，查全率，查准率，ROC曲线（Bilibili）](https://www.bilibili.com/video/BV1Fg4y1n7Xd/)，时长约 7 分钟（风中丫丫）。本文基于视频演说图文稿整理，时间戳可跳转到对应讲解。

## 本讲要解决的核心问题（SCQA）

**背景**：二分类有了混淆矩阵，就能算出查准率（precision）、查全率（recall）和把它们绑在一起的 F1。

**冲突**：类别一多，每个类别都有一组 P、R、F1，最后要报一个数时，怎么合成？同样是"多分类 F1"，micro 与 macro 可以给出完全不同的数值。

**疑问**：micro 和 macro 到底在哪一步分岔？两条路线各自回答什么问题？

**回答（中心思想）**：分岔点在**先加还是先算**。micro 先把各类的 TP、FP、FN、TN 累加成一张"总混淆矩阵"，再套一次二分类公式；macro 先对每个类别各算一次 F1，再把各类的 F1 求平均。前者被样本多的类别主导，后者给每个类别同等权重。

## 一、二分类：一张 2×2 表就够

视频用"一堆瓜"开场：好瓜标签为 1，坏瓜标签为 0，把真实（好瓜 / 坏瓜）与预测（好瓜 / 坏瓜）交叉，就得到混淆矩阵 [【跳转到 00:30】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=30)。

- 真实是好瓜、预测也是好瓜 → **TP**（true positive）；
- 真实是坏瓜、预测是好瓜 → **FN**（false negative）：真实是负标签，却被错误地预测成了正类 [【跳转到 00:55】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=55)；
- 真实是坏瓜、预测也是坏瓜 → **TN**；真实是好瓜、预测是坏瓜 → **FP**。

![二分类混淆矩阵与查准率、查全率、F1 的定义](assets/多分类指标怎么合成一个数：micro%20累加与%20macro%20平均/00080.webp)

指标就从这张表里挑分子分母 [【跳转到 01:20】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=80)：

- **查准率 P = TP / (TP + FP)**，分母是"这一列"（所有被判为好瓜的）；
- **查全率 R = TP / (TP + FN)**，分母是"这一行"（所有真实为好瓜的）；
- **F1 = 2PR / (P + R)**。

视频给了一个便于记忆的读法：查准率是"尽可能把挑出来的都挑对"，查全率是"尽可能把该挑的都挑出来" [【跳转到 01:45】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=105)。

## 二、P 与 R 的拉扯：两个极端策略

为什么要另造 F1？因为 P 和 R 相互矛盾：查准率越高，查全率往往越低；查全率越高，查准率往往越低 [【跳转到 02:10】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=130)。

视频用 200 个瓜（150 好瓜、50 坏瓜）演示两个极端 [【跳转到 02:35】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=155)：

- **把 R 刷到 1**：把所有瓜都预测为好瓜。此时 FN = 0，R = 1，但 FP 变成 50，P 只有 150/200 = 0.75。
- **把 P 刷到 1**：只把分类器最有把握的那 1 个（或 2 个）瓜判为好瓜，其余全判坏瓜。此时 FP = 0，P = 1，但 R 只有 1/150（或 2/150）。

![只判最有把握的一两个瓜为好瓜：精确率可以很高，召回率几乎归零](assets/多分类指标怎么合成一个数：micro%20累加与%20macro%20平均/00255.webp)

这个例子说明：**单看 P 或单看 R，都可以被一个"故意偏科"的策略刷到 1**。所以需要一个同时看两头的数。

> 核对提示：视频手写稿的两个极端与其矩阵里的计数对不上。① 写的是"让 P=1 → 把所有瓜都预测为好瓜"，但全判好瓜时 FP=50，得到的是 R=1、P=0.75（P=1 需要 FP=0）；② 写的是"让 R=1 → 只判一两个瓜"，而它的矩阵把真实好瓜数写成了 1（与 150 个好瓜的前提不符）。正文按"150 好瓜 + 50 坏瓜"的前提重新数格子：全判好瓜 → R=1、P=0.75；只判一个 → P=1、R=1/150。

## 三、F1：用调和平均"惩罚偏科"

F1 = 2PR/(P + R)，是 P 与 R 的调和平均。视频对它的核心思想说得很直白：在尽可能提高 P 和 R 的同时，**希望两者之间的差异尽可能小** [【跳转到 04:40】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=280)。

调和平均的性质决定了这一点：P、R 中只要有一个很低，F1 就上不去。上面两个极端策略的 F1 分别是 2×1×0.75/(1+0.75) ≈ 0.857 与 2×1×(1/150)/(1+1/150) ≈ 0.013——后者立刻暴露了"只挑一个判对"的做法并不好用。

## 四、多分类：每个类别各拆一张小混淆矩阵

多分类的 F1 有两种：**微观 F1（micro）**与**宏观 F1（macro）** [【跳转到 05:05】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=305)。

视频的例子是猫、狗、人三类，分别 50、100、150 个样本，共 300 个。两种路线的第一步相同：**把 N×N 混淆矩阵拆成 N 张"该类 vs 非该类"的二分类小表**——猫/非猫、狗/非狗、人/非人，各自数出 TP、FP、FN、TN [【跳转到 05:30】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=330)。

![micro：把三个小矩阵的 TP/FP/FN/TN 分别加总，得到一张总混淆矩阵](assets/多分类指标怎么合成一个数：micro%20累加与%20macro%20平均/00330.webp)

分岔从第二步开始：

- **micro（微观）**：把三张小表里的 TP 加总、FP 加总、FN 加总、TN 加总，得到一组"总的 TP/FP/FN/TN"，再用这组数算 P、R，最后算 F1 [【跳转到 05:55】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=355)。也就是**先累加，再算指标**。
- **macro（宏观）**：对猫、狗、人各算一个 F1，再把这三个 F1 加起来求平均 [【跳转到 06:20】](https://www.bilibili.com/video/BV1Fg4y1n7Xd/?t=380)。也就是**先算指标，再平均**。

![macro：先得到三个类别的 F1，再对它们求平均](assets/多分类指标怎么合成一个数：micro%20累加与%20macro%20平均/00380.webp)

## 五、两条路线各回答什么问题

视频本身只交代了机制，没有展开"什么时候该用哪个"。按上面的构造可以直接读出两条推论（**以下为本文推论，非视频原话**）：

1. **micro 的每个格子都按样本计数**，样本多的类别在总表里占的格子多，因此 micro 更接近"整体样本层面的表现"；它衡量的是"随便抽一个样本，判对的概率有多大"这一侧的信息。
2. **macro 给每个类别相同的权重**，一个只有 50 个样本的类别与一个有 150 个样本的类别，在平均值里分量一样。因此当少数类的失败必须被看见时，macro 更合适；反过来，若只报 micro，小类别判错对总分的影响会被大类别稀释。

这也解释了为什么在类别不平衡的多分类任务上，**只报一个聚合分数不足以说明问题**：同一个模型可以 micro 很高而 macro 明显更低，差值本身就是"少数类被牺牲"的信号。要判断到底牺牲了谁，必须回到每个类别的 P/R/F1 去看。

## 小结

- 二分类：P = TP/(TP+FP)、R = TP/(TP+FN)、F1 = 2PR/(P+R)；P 与 R 相互矛盾，F1 用调和平均惩罚偏科。
- 多分类第一步：把 N×N 混淆矩阵拆成 N 张"该类 vs 非该类"的小表，各自数 TP/FP/FN/TN。
- micro：先累加四类计数，再套一次二分类公式；被样本多的类别主导。
- macro：先对每类算 F1，再对类别求平均；每类权重相同。
- 聚合分数只是入口，判断少数类是否失败必须回到单类指标。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 查准率 Precision | TP/(TP+FP)，判为正类的样本里真正为正的比例 |
| 查全率 Recall | TP/(TP+FN)，真实正类里被找出来的比例 |
| F1 | 2PR/(P+R)，P 与 R 的调和平均，偏科重罚 |
| 一类 vs 其余 | 多分类拆成 N 个二分类子问题，每个类别各得一组 TP/FP/FN/TN |
| Micro-F1 | 先累加各类 TP/FP/FN/TN，再算 P、R、F1 |
| Macro-F1 | 先算各类 F1，再对类别求平均 |
