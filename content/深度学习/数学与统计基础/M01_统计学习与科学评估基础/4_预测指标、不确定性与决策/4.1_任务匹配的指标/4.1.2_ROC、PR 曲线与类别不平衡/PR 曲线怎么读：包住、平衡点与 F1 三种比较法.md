# PR 曲线怎么读：包住、平衡点与 F1 三种比较法

> 视频来源：[二分类PR曲线(4) 如何用PR曲线评估模型的性能（Bilibili）](https://www.bilibili.com/video/BV14m4y1J7hs/)，时长约 24 分钟（耿大哥讲算法）。本文基于视频演说图文稿（B 站 AI 中文字幕）整理，时间戳可跳转到对应讲解。

## 本讲要解决的核心问题（SCQA）

**背景**：给定 N 个样本的真实类别（负/正，编码为 0/1），两个算法各自输出每个样本属于正类的概率。每个算法都能画出一条 PR 曲线——横轴召回率 R、纵轴精确率 P。

**冲突**：两条曲线摆在面前，怎么判断哪个算法更好？PR 曲线不是一条光滑函数，而是由一串折线点连成，每个点对应一个不同的阈值；两条曲线还可能交叉，此时"看起来更高"没有意义。

**疑问**：有没有不依赖单个阈值、又能处理交叉情形的比较规则？

**回答（中心思想）**：视频给出三种方法——**观察法**（一条曲线完全包住另一条时可直接判定）、**平衡点法 BEP**（比较两条曲线与 P=R 直线的交点，交点在右上者更优）、**F1 分数法**（用调和平均把 P 和 R 压成一个数，β 决定偏向谁）。观察法最直观但怕交叉；平衡点法最常用；F1 法必须事先定好 β，否则结论随权重漂移。

## 一、两条 PR 曲线从哪来

样本的真实类别给定后，每个算法输出一组"属于正类的概率" [【跳转到 00:00】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=0)。对每一组概率，按阈值从高到低扫描，每个阈值算出该阈值下的精确率与召回率，得到一个点；把所有点连起来就是该算法的 PR 曲线。算法一一条、算法二一条，比较两条曲线就能评估两个算法 [【跳转到 00:50】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=50)。

![两个算法、两组输出概率，各自对应一条 PR 曲线](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00075.webp)

坐标轴的分工与 4.1.1 的混淆矩阵指标一致 [【跳转到 02:05】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=125)：

- **横轴召回率 R = TP/(TP+FN)**：实际为正的样本里，有多少被找出来了；
- **纵轴精确率 P = TP/(TP+FP)**：预测为正的样本里，有多少是真的正。

两者都是"预测对了的比例"，但分母不同：一个在真实正类里数，一个在预测正类里数。它们此消彼长，所以 PR 曲线画的是**一条取舍曲线**，而不是一条"越高越好"的单调曲线。

## 二、观察法：完全包住就能判胜负

观察法的核心规则：**如果一条 PR 曲线被另一条完全包住（允许部分重合，但不能交叉），则后者的分类效果优于前者** [【跳转到 01:15】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=75)。

为什么可以这样判？因为比较两条曲线有两条等价路径 [【跳转到 03:45】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=225)：

- **固定 P，比较 R**：在同一条水平线上，横坐标更大（召回更多）的曲线更好；
- **固定 R，比较 P**：在同一条竖直线上，纵坐标更大（更准）的曲线更好。

如果一条曲线在每个 P 上都给出更大的 R、在每个 R 上都给出更大的 P，两种比法结论一致，就可以直接判胜负。

![观察法：P 相同比 R，R 相同比 P](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00350.webp)

视频用一条橙色曲线与一条绿色曲线演示：橙色在每个固定 P 处的 R 都更大，在每个固定 R 处的 P 也都更大，于是橙色算法更优 [【跳转到 05:25】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=325)。

![一条曲线完全包住另一条：允许重合，不允许交叉](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00275.webp)

**局限**：一旦两条曲线交叉，观察法就失效了——橙线在低召回区更高，绿线在高召回区更高，"谁更好"取决于你打算把阈值放在哪一段 [【跳转到 06:15】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=375)。

![交叉的 PR 曲线：时而在上时而在下，观察法无法判定](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00375.webp)

## 三、平衡点法（BEP）：用与 P=R 的交点定胜负

平衡点（Break-Even Point，BEP）有两个层次的定义 [【跳转到 07:05】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=425)：

- **定义 1（狭义）**：PR 曲线由许多小线段连成，只考察这些小线段的**端点**；如果某个端点恰好满足 P = R，这个点就是平衡点。
- **定义 2（广义）**：整条 PR 曲线与直线 **P = R**（45° 线）的交点，就是平衡点。

定义 2 是为定义 1 兜底的：曲线上所有端点的 P 与 R 都不相等时，画一条 45° 线与曲线相交，交点处 P 与 R 必然相等，只是它落在某条线段内部而不是端点上 [【跳转到 08:20】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=500)。

![平衡点的两种定义：端点上的 P=R，或整条曲线与 45° 线的交点](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00425.webp)

**判定规则**：把两条曲线各自与 45° 线的交点画出来，**交点落在右上方的曲线更优** [【跳转到 10:00】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=600)。这把"两条曲线"的比较压缩成"两个点"的比较，交叉情形也能给出结论。

两个必须注意的性质 [【跳转到 10:25】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=625)：

- **平衡点不唯一**：一条 PR 曲线可能与 45° 线有多个交点（视频示例有两个），此时按"最外侧/最右上"的那个交点比较；
- **平衡点不一定是端点**：它常常落在某条线段内部，所以不能只在端点里找。

## 四、平衡点到底在平衡什么

平衡点的内部含义可以直接从混淆矩阵推出来 [【跳转到 12:30】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=750)：

- 精确率 P = TP/(TP+FP)——分母是混淆矩阵里"预测为正"那一列的和；
- 召回率 R = TP/(TP+FN)——分母是"实际为正"那一行的和。

令 P = R，两个分数的分子相同（都是 TP），于是分母必须相等：**TP + FP = TP + FN，即 FP = FN** [【跳转到 14:35】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=875)。

![P=R 的推导：分子都是 TP，故 FP = FN](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00875.webp)

所以平衡点就是**"假阳性个数等于假阴性个数"的那个阈值**——两类错误打平的位置。这也解释了为什么它适合当作"不分偏重"的比较基准：它把两类错误的代价视为相同。

![平衡点对应混淆矩阵里 FP 与 FN 相等](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/00925.webp)

## 五、F1 分数法：把 P 和 R 压成一个数

第三种方法用 P 与 R 的**调和平均**作为单值指标 [【跳转到 15:00】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=900)。视频先用一个"融冰"比喻解释调和平均从哪来：两块截面积 S₁、S₂、高度 h₁、h₂ 的冰融在同一个容器里，液面高度 h = (S₁+S₂)/(S₁/h₁ + S₂/h₂)——总面积除以总宽度 [【跳转到 15:25】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=925)。

- 当 S₂/S₁ = 1（两块冰一样大）：h = 2h₁h₂/(h₁+h₂)，即等权调和平均；
- 当 S₂/S₁ = β²（β ≥ 0）：h = (1+β²)h₁h₂/(h₂ + β²h₁)。

把 h₁、h₂ 换成 P、R，就得到带权重的 F1 [【跳转到 19:10】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=1150)：

- P 与 R 权重相同时：**F1 = 2PR/(P+R)**
- R 与 P 的权重之比为 β²:1（β ≥ 0）时：**F1 = (1+β²)PR/(R + β²P)**

![F1 的调和平均来源与带 β 权重的公式](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/01225.webp)

视频对 β 做了求导与取极限 [【跳转到 20:25】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=1225)：

- F1 对 β² 的导数恒大于 0，所以 F1 在 β ≥ 0 上**单调递增**；
- β² → 0⁺ 时 F1 → P；β² → +∞ 时 F1 → R。

结论一句话：**R 和 P 谁重要，F1 就倾向于谁** [【跳转到 21:40】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=1300)。β 小则精确率主导，β 大则召回率主导。

![β 的极限行为：β 越小越像 P，越大越像 R](assets/PR%20曲线怎么读：包住、平衡点与%20F1%20三种比较法/01325.webp)

关键约束：**β 不能在模型设计阶段拍脑袋定**，必须结合具体问题在最终评估时确定 [【跳转到 22:30】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=1350)。否则同一个模型换一个 β 就能换一个结论——这正是"单值指标"最容易被误用的地方。

## 六、三种方法怎么选

视频的收尾判断 [【跳转到 22:55】](https://www.bilibili.com/video/BV14m4y1J7hs/?t=1375)：

| 方法 | 适用条件 | 局限 |
| --- | --- | --- |
| 观察法 | 一条曲线完全包住另一条（可重合、不可交叉） | 交叉时失效 |
| 平衡点法 BEP | 任意两条曲线，包括交叉 | 交点可能不唯一；只反映 FP=FN 这一个工作点 |
| F1 分数法 | 已确定 β（P/R 的相对重要性） | β 未定则结论不定；单值会掩盖曲线形状 |

实际用得最多的是**平衡点法**，观察法因为太受限而只能作为第一步筛查。

## 小结

- PR 曲线的每个点对应一个阈值，横轴 R、纵轴 P，两者此消彼长。
- 观察法：一条曲线完全包住另一条（允许重合、不允许交叉）时，后者更优；固定 P 比 R、固定 R 比 P 是它的两条等价判据。
- 平衡点法：比较两条曲线与 P=R 直线的交点，交点在右上者更优；平衡点的实质是 **FP = FN**（两类错误打平），且可能不唯一、不落在端点上。
- F1 法：F1 = (1+β²)PR/(R+β²P)，β 越大越偏向召回率；β 必须由问题决定，不能由模型设计阶段指定。
- 三种方法都在回答同一个问题："在不指定单一阈值的前提下，怎么排序两个模型"——它们与 AUC 的思路相同，但 PR 曲线只用 P 和 R，不看 TN。
