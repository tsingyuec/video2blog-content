# 低事件率下 AUC 会高估：PR 曲线与 AP 的随机基准

> 视频来源：[PR曲线｜弥补ROC致命缺陷，不平衡数据集必看（Bilibili）](https://www.bilibili.com/video/BV1b9Ww67EKZ/)，时长约 2 分半（统计之光公开课）。本文基于视频演说图文稿整理（该视频无平台字幕，文稿由本地语音转写后逐句校对），时间戳可跳转到对应讲解。

## 本讲要解决的核心问题（SCQA）

**背景**：AUC 是二分类模型最常用的单值指标，0.5 是随机猜测、1 是完美，判读规则简单。

**冲突**：当"阳性事件"很稀少时——发病率只有 5% 甚至 1%——AUC 会**系统性地高估**模型的真实能力。一个 AUC = 0.853 的模型，看起来相当不错，但它报出的阳性可能大部分是错的。

**疑问**：有没有一个指标，能在阳性事件极少时仍然诚实？

**回答（中心思想）**：PR 曲线。它的两个轴（召回率、精确率）都只由阳性事件与"被判为阳性"的样本决定，完全不看真负类；曲线下面积叫 **AP（Average Precision）**。关键在于 **AP 的随机基准不是 0.5，而是事件发生率本身**——所以 AP 数值看起来低，未必表示模型差，必须与基线比。

## 一、AUC 的缺陷：阴性样本太多会把曲线"抬"起来

视频开篇就点出 ROC/AUC 的致命缺陷：**当结局事件很少时，AUC 会系统性高估模型的真实能力** [【跳转到 00:05】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=5)。

机制在于 FPR（也就是 1 − 特异度）的分母是**全部阴性样本** [【跳转到 00:18】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=18)：发病率 5% 甚至 1% 时，阴性样本占绝大多数，同样的假阳性个数被摊薄成一个很小的比例，特异度很容易被抬高，ROC 曲线左段看起来非常"干净" [【跳转到 00:21】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=21)。

换句话说：**AUC 衡量的排序能力里，绝大多数"排对了"的配对来自真负类**。阴性越多，这部分越容易做对，AUC 也就越乐观。

## 二、PR 曲线的两个轴：只看阳性这一侧

PR 曲线的两个轴都是上一节混淆矩阵里算过的量 [【跳转到 00:30】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=30)：

- **横轴召回率（= 灵敏度）**：真正生病的人里，模型找出了多少；
- **纵轴精确率**：模型预测为生病的人里，有多少是真的生病。

两者此消彼长：阈值降低，召回率提高但精确率下降；阈值提高，精确率提高但召回率下降。PR 曲线画的就是这条取舍关系 [【跳转到 00:44】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=44)。

注意分母：召回率的分母是真实阳性总数，精确率的分母是**被判为阳性的样本数**。两个分母里都没有真负类 TN——这就是 PR 曲线"不看阴性"的原因。

## 三、AP：曲线下面积，以及它真正的基准线

PR 曲线的重点仍是**曲线下面积**，叫 **Average Precision，简称 AP** [【跳转到 00:55】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=55)。AP 越高，说明模型在兼顾精确率与召回率上做得越好。

这里有一处与 ROC 的根本差别 [【跳转到 01:07】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=67)：

- **ROC 的随机基准是固定的 0.5**：因为它的两个轴是 TPR 与 FPR，随机猜测时两者相等，曲线就是对角线，面积恒为 0.5。
- **AP 的随机基准等于事件发生率本身**：一个只会瞎猜的模型，其精确率大约等于阳性比例，所以 AP 的基线随数据而变。

这直接改变判读方式：**AP 看起来小，不一定很差**——因为它的基线本来就低 [【跳转到 01:22】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=82)。

![PR 曲线：横轴召回率、纵轴精确率，AP = 0.263，随机基准是事件发生率 4%](assets/低事件率下%20AUC%20会高估：PR%20曲线与%20AP%20的随机基准/00039.webp)

## 四、同一个模型，两种说法

视频用一个低事件率的队列做对比：验证集的事件率只有 **3.92%** [【跳转到 01:31】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=91)。

- **ROC**：AUC = **0.853**，看起来是一个相当不错的模型 [【跳转到 01:34】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=94)；
- **PR**：AP = **0.263**，单看数字似乎很差 [【跳转到 01:40】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=100)。

但关键在于对照：随机基准只有 **4%** 左右，0.263 相对于这条基线提升了将近 **7 倍** [【跳转到 01:49】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=109)。所以同一个模型，ROC 说"不错"，PR 说"其实相当好"——**两个指标并不矛盾，只是分母不同、基线不同**。

![同一模型、同一数据：AUC = 0.853 看着漂亮，AP = 0.263 要跟 4% 的基线比](assets/低事件率下%20AUC%20会高估：PR%20曲线与%20AP%20的随机基准/00111.webp)

反过来也有另一种情形：ROC 说非常不错，PR 却反映模型**根本不行**——这时 AUC 是被大量阴性样本抬高的，而 PR 完全不看阴性、只盯着阳性事件，因此对这类极端不平衡更合适 [【跳转到 02:02】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=122)。

## 五、什么时候该看 PR

视频给出的判据很直接：**事件率低的时候，PR 曲线比 ROC 更诚实** [【跳转到 02:15】](https://www.bilibili.com/video/BV1b9Ww67EKZ/?t=135)。

这条规则并不限于临床预测模型。任何"正例稀少"的任务都适用：罕见功能位点、低频突变、稀有细胞状态、少数阳性扰动——只要阳性占比只有百分之几，AUC 都会被大量真负类"撑"得很好看，而真正要回答的问题（报出的阳性里有多少是真的）恰好由精确率承担。

配套的判读习惯有两条：

1. **报 AP 时必须同时报基线**（事件发生率），否则 0.263 这样的数字无法解读；
2. **不要用 0.5 去衡量 AP**——0.5 是 ROC 的随机线，不是 AP 的。

## 小结

- AUC 的 FPR 分母包含全部阴性样本，阳性事件稀少时会被摊薄，导致系统性高估。
- PR 曲线的召回率与精确率都不含真负类，因此只反映阳性这一侧的表现。
- AP 是 PR 曲线下面积；它的随机基准是**事件发生率**，不是 0.5。
- 同一模型可以同时得到 AUC = 0.853 与 AP = 0.263：前者与 0.5 比、后者与 4% 比，结论都是"比随机好很多"。
- 事件率低时优先看 PR/AP，并且必须把 AP 与基线一起报。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 事件率 | 阳性样本占全部样本的比例，也是 AP 的随机基准 |
| AP（Average Precision） | PR 曲线下面积，衡量兼顾精确率与召回率的程度 |
| 随机基准 | 瞎猜时的期望指标值：ROC 固定 0.5，AP 等于事件率 |
| 系统性高估 | 指标稳定偏向乐观，而不是随机波动 |
| 稀释效应 | 阴性样本极多时，同样的假阳性个数对应很小的 FPR |
