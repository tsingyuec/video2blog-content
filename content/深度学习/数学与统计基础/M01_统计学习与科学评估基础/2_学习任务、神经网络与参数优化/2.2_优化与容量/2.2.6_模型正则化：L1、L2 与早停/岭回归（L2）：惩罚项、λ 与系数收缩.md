# 岭回归（L2）：惩罚项、λ 与系数收缩

> 视频来源：[Regularization Part 1: Ridge (L2) Regression](https://www.youtube.com/watch?v=Q81RR3yKn30)（YouTube · StatQuest，讲者 Josh Starmer）｜时长约 20 分钟
> 导读：这支视频从"只有两个训练点"的最小二乘失败讲起，把岭回归的目标函数拆成"残差平方和 + λ×斜率平方"，用一个能算出数字的两点例子说明惩罚项为什么会选一条拟合更差、但对新数据更稳的线；随后把 λ 从 0 扫到很大，看斜率如何被压向 0，并说明 λ 由交叉验证选定。最后一段处理参数比样本还多的高维情形。L1 的版本与早停见同节另两篇。

## 本讲要解决的核心问题（SCQA）

**背景**：最小二乘（least squares）是线性模型的标准解法——找一条线，使残差平方和最小。样本充足时，它给出的斜率和截距相当可靠。

**冲突**：样本很少时，最小二乘会"贴着"训练点走。两个训练点就能把一条线完全钉死，训练残差为 0，可换到测试点上误差极大。这就是低偏差、高方差，也就是过拟合。

**疑问**：既然最小二乘在训练集上已经做到最好，还有什么可改的？能不能故意让拟合差一点，换来对新数据的稳定预测？

**回答（中心思想）**：岭回归在最小化目标里加了一项 **λ 乘所有非截距参数的平方和**。这一项让"斜率很大"本身变成一种代价，于是最优解被拉向斜率更小的方向：训练集上的拟合变差了一点（偏差上升），但预测不再对训练数据的细节敏感（方差下降）。λ 控制这笔交换的力度——λ=0 时退回最小二乘，λ 越大收缩越强；λ 由交叉验证在没参与拟合的数据上选定。

## 一、两个点的最小二乘：训练残差为零，测试残差很大

视频先用小鼠的体重（weight）与体型（size）测量值建立线性模型，用最小二乘拟合一条直线，也就是让残差平方和最小的那条线 [【跳转到 01:23】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=83)。这条线有两个参数：纵轴截距与斜率；代入体重 2.5，就能算出体型 2.8，得到线上一个点 [【跳转到 01:30】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=90)。

测量很多时，最小二乘线能相当准确地反映体重与体型的关系。但视频马上把数据砍到只剩两个点 [【跳转到 02:20】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=140)：

![只剩两个训练点时，最小二乘线穿过它们，训练残差平方和为 0，但绿色测试点离这条线很远](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00190.webp)

两个点必然被一条线穿过，所以最小残差平方和等于 0。把这两个红点叫训练数据、其余绿点叫测试数据，就能看清问题：训练残差平方和很小（这里是 0），测试残差平方和却很大 [【跳转到 02:45】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=165)。用机器学习的说法，这条线**方差很高**，也就是**对训练数据过拟合**。

## 二、岭回归的目标：残差平方和加上 λ 乘斜率平方

岭回归的主意就是反过来：**主动找一条不那么贴合训练数据的线**，引入一点点偏差，换回方差的大幅下降；因为起点稍差，长期预测反而更好 [【跳转到 03:10】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=190)。

具体到目标函数，最小二乘最小化的是残差平方和；岭回归最小化的是**残差平方和加上 λ 乘以斜率的平方** [【跳转到 04:00】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=240)：

![最小二乘只最小化残差平方和；岭回归在其后加上 λ×斜率²，λ 决定惩罚有多重](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00265.webp)

视频特意点出这个希腊字母的名字：**λ（lambda）**，它决定惩罚的严重程度 [【跳转到 04:25】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=265)。

### 2.1 用两个点的数字算一遍

把数字代进去，差别就变成一道算术题 [【跳转到 04:50】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=290)。先看最小二乘：残差平方和为 0（线穿过两个点），斜率是 1.3，令 λ=1，目标值就是 $0 + 1\times 1.3^2 = 1.69$ [【跳转到 05:15】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=315)。

![最小二乘解：残差平方和 0，斜率 1.3，λ=1 时目标值为 1.69](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00340.webp)

再看岭回归线：两个残差分别是 0.3 与 0.1，斜率是 0.8，λ 仍取 1，目标值为 $0.3^2 + 0.1^2 + 1\times 0.8^2 = 0.74$ [【跳转到 05:40】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=340)。

于是同一个目标函数下，最小二乘线得 1.69，岭回归线得 0.74——要最小化"残差平方和 + 惩罚"，就该选岭回归线 [【跳转到 06:30】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=390)。这就是惩罚项改变解的方式：它不接受"残差为 0 但斜率很大"这个方案，因为斜率本身要付代价。

## 三、惩罚项在做什么：缩小斜率等于降低敏感度

视频用一个更简单的例子解释"斜率大"意味着什么 [【跳转到 06:55】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=415)。若斜率为 1，体重每增加 1 个单位，预测体型增加 1 个单位；斜率更陡时，体重很小的变化会让预测体型变化超过 2 个单位——预测对输入非常敏感；斜率很小时，体重增加 1 个单位，预测体型几乎不变——预测对输入不敏感 [【跳转到 07:45】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=465)。

回到两条线：惩罚项让岭回归线的斜率比最小二乘线小，因此岭回归的预测对体重更不敏感 [【跳转到 08:10】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=490)。

![斜率很小时，体重每增加一个单位，预测体型几乎不变——这就是“不敏感”的几何含义](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00490.webp)

![惩罚项把斜率压小：岭回归线（蓝）在训练点上不如最小二乘线（红）贴合，但对测试点更稳](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00440.webp)

"不敏感"正是方差下降的直观含义：换一批训练数据，斜率不会剧烈摆动，预测也就不会剧烈摆动。

## 四、λ 从 0 到无穷：一个连续的容量旋钮

λ 可以取 0 到正无穷之间的任何值 [【跳转到 08:35】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=515)。两个端点很清楚：

- **λ=0**：惩罚项为 0，岭回归只最小化残差平方和，解与最小二乘完全相同 [【跳转到 09:00】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=540)。
- **λ 增大**：例子中 λ=1 时斜率已小于最小二乘，λ=2 时更小，λ=3 时再小；λ 越大，斜率渐近地趋近 0 [【跳转到 09:25】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=565)。

![λ 增大时岭回归线绕向水平：斜率渐近趋近 0，预测对体重越来越不敏感](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00565.webp)

也就是说，λ 不是"开/关"式的开关，而是一个连续调节"允许多大的斜率"的旋钮。λ 怎么定？视频的回答是：试一组 λ 值，用交叉验证挑出让方差最低的那个，通常用 10 折交叉验证 [【跳转到 09:50】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=590)。这里的关键是 λ 必须在没参与拟合的数据上选，否则"方差最低"只是训练集上的假象。

## 五、离散变量、逻辑回归与多参数模型

岭回归不只用于"连续变量预测连续变量"。视频接着换成离散输入：正常饮食与高脂饮食（编码为 0 和 1）预测体型 [【跳转到 10:15】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=615)。此时截距 1.5 对应正常饮食组的平均体型，系数 0.7 对应两组平均体型之差，视频把它叫作"饮食差"（diet difference）[【跳转到 10:40】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=640)。

最小二乘最小化各点到本组均值的残差平方和；岭回归则在后面加上 **λ×饮食差的平方** [【跳转到 11:55】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=715)。λ=0 时退回最小二乘；λ 很大时，要最小化整个式子就只能把饮食差压小，于是高脂饮食与正常饮食的预测差别变得越来越不敏感 [【跳转到 12:20】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=740)。

同样的逻辑可以套到逻辑回归上：用体重预测小鼠是否肥胖，岭回归会收缩斜率的估计，让"是否肥胖"的判断对体重不那么敏感；区别在于逻辑回归用最大似然求解，所以惩罚加在似然上，而不是残差平方和上 [【跳转到 13:24】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=804)。

![逻辑回归里的岭惩罚：目标从残差平方和换成似然，收缩的仍是斜率](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00829.webp)

模型变复杂时，惩罚项的形式不变：把体重（连续）与饮食（离散）合到一个方程里，惩罚就同时包含斜率与饮食差 [【跳转到 14:01】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=841)。

![把两类数据合到一个方程：惩罚项包含斜率与饮食差，但不含截距](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/00866.webp)

这里有一条容易被忽略的规则：**岭惩罚包含除纵轴截距以外的所有参数** [【跳转到 14:26】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=866)。视频给的理由是：除截距外的每个参数都被测量值缩放，所以截距不放进惩罚项 [【跳转到 14:51】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=891)。（这也意味着惩罚的力度会随特征单位而变，做岭回归前需要先统一尺度；这一点由 1.1.5 的特征缩放单元展开。）

## 六、参数比样本多时，岭回归仍能给出解

视频最后一段讲一个看似无关的事实：要估计 $k$ 个参数，最小二乘至少需要 $k$ 个数据点。一个参数（截距）加一个斜率需要两个点；三个参数（截距、体重斜率、年龄斜率）需要三个点，因为此时要在三维里拟合一个平面，两个点无法区分哪个平面更好；四个参数要四个点；10001 个参数就要 10001 个数据点 [【跳转到 15:16】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=916)。

10001 个参数并不夸张：用 10000 个基因的表达量预测体型，就是 10000 个斜率加一个截距，按最小二乘就需要 10001 只小鼠的表达数据——现实中一个大数据集可能只有 500 只 [【跳转到 17:14】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1034)。

![10001 个参数的方程：加上岭惩罚后，500 个甚至更少的样本也能解出全部参数](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/01109.webp)

岭回归能处理这种情形：加上惩罚项后，10001 个参数可以用 500 个甚至更少的样本解出来 [【跳转到 18:04】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1084)。直观理由还是"只有一个训练点"的例子——最小二乘无法在无数条穿过该点的线里挑出一条，而岭惩罚偏好参数更小的解，配合交叉验证就能定出一个解 [【跳转到 18:29】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1109)。

## 七、小结：目标函数改动如何换来泛化

![小结：小样本时岭回归通过惩罚项让预测对训练数据不敏感，从而降低方差](assets/岭回归（L2）：惩罚项、λ%20与系数收缩/01157.webp)

- 样本量较小时，岭回归能改善对新数据的预测，也就是通过让预测对训练数据不敏感来**降低方差** [【跳转到 19:12】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1152)。
- 做法是在要最小化的目标上加一项岭惩罚：**λ 乘以除截距外所有参数的平方和** [【跳转到 19:17】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1157)。
- λ 用交叉验证确定 [【跳转到 19:17】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1157)。
- 即使数据量不足以求最小二乘解，岭回归仍能借助惩罚项与交叉验证给出解 [【跳转到 19:42】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=1182)。

把这条链连起来看：改动只发生在**目标函数**上（加了一项），后果却落在**泛化**上（方差下降、偏差略升）。这正是"正则化"的含义——不是让训练误差更小，而是让解的性质更受约束。视频开场把这层意思说得很直白：正则化就是另一种说法的"脱敏"（desensitization）[【跳转到 00:00】](https://www.youtube.com/watch?v=Q81RR3yKn30&t=0)。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 最小二乘 | 找使残差平方和最小的参数，等价于对训练数据做最优拟合 |
| 残差 | 数据点到拟合线的竖直距离 |
| 过拟合 | 对训练数据拟合很好、对新数据很差，对应高方差 |
| 岭回归（L2） | 在残差平方和上加 λ×参数平方和（不含截距）的线性回归 |
| λ（lambda） | 惩罚强度，0 到正无穷；0 退回最小二乘，越大收缩越强 |
| 收缩 | 惩罚项把参数估计拉向更小的值，使预测对输入不敏感 |
| 交叉验证 | 在未参与拟合的数据上比较不同 λ 的表现，常用 10 折 |
| 高维情形 | 参数个数多于样本个数，最小二乘无唯一解，岭回归仍可给出解 |
