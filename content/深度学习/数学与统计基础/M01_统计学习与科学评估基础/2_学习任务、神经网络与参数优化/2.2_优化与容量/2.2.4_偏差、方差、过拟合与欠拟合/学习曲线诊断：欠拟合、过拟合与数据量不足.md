# 学习曲线诊断：欠拟合、过拟合与数据量不足

> 视频来源：[A Critical Skill People Learn Too LATE: Learning Curves In Machine Learning](https://www.youtube.com/watch?v=nt5DwCuYY5c)（YouTube · Underfitted）｜时长约 7 分钟
> 导读：一支用"学生复习—考试"类比讲学习曲线的短片。它给出三个可操作的判据：训练损失高 = 欠拟合；测试损失高 = 过拟合；两条都低但差距大 = 数据量不足或分布不一致。本文只用学习曲线做诊断，不涉及梯度消失、初始化等训练故障，也不展开正则化细节。

## 本讲要解决的核心问题（SCQA）

**背景**：训练模型时，我们只能看到损失在下降或不动。要判断模型到底哪里出了问题，需要把"训练时的表现"和"没见过的数据上的表现"放在同一张图上比较。

**冲突**：只看训练损失会误判。训练损失很低只说明模型把训练数据学好了——就像老师用课上讲过的原题当考卷，学生把答案背下来也能考高分，但这不代表学会了。

**疑问**：怎样从训练过程本身看出模型是欠拟合、过拟合，还是数据不够？看到不同的曲线形状，分别该做什么？

**回答（中心思想）**：画**学习曲线**——横轴是训练轮数（epoch），纵轴是损失，同时画训练损失与测试损失两条线。**训练损失高 → 欠拟合**（模型没学会）；**测试损失高 → 过拟合**（模型不泛化）；**两条都低 → 拟合良好**。此外有两种常见形状：两条都在降但差距很大，说明训练数据不足或训练/测试分布不一致；测试损失先降后升，说明训练太久，可以在上升前早停。

## 一、先看一个类比：复习时间与考试错误

想象一所学校：有老师、有一套要复习的题、还有期末考试。学年结束时老师公布一张图，画的是学生犯的错误数量与他们花多少时间复习的关系——复习时间越长，表现越好 [【跳转到 00:44】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=44)。

每个老师都希望学生真正学会材料，而不是只为考试做优化；他们希望学生建立的知识能推广到课堂之外的情境 [【跳转到 01:08】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=68)。训练模型是同一回事：我们希望模型学到能泛化的东西，一个学不会、或者不能泛化到新样本的模型是没有用的。

这两种失败各有名字 [【跳转到 01:38】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=98)：

- **欠拟合**（underfit）：模型没学会；
- **过拟合**（overfit）：模型不能泛化到没见过的样本。

两者都让模型变得没用。要处理它们，第一步是先识别出来。

## 二、学习曲线：把"错误数"换成"损失"

把上面那张图的"错误数"换成模型的损失，把"复习时间"换成 **epoch**（训练迭代的轮数），就得到**学习曲线** [【跳转到 02:07】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=127)。损失越低越好，这正是我们想要的；学习曲线是诊断欠拟合与过拟合的关键工具 [【跳转到 02:24】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=144)。

### 2.1 第一个判据：训练损失高 = 欠拟合

先只看训练损失。注意它的含义：我们在用**训练模型的那份数据**衡量模型的学习能力 [【跳转到 02:35】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=155)。回到学生的类比，这相当于老师用课堂上讲过的原题当考卷——学生很可能把答案背下来，考得很好 [【跳转到 02:50】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=170)。

可这个模型占尽了优势，损失却仍然不低。为什么？这就是本视频的第一个要点：**训练损失高，说明模型没有把数据拟合好，这叫欠拟合** [【跳转到 03:05】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=185)。

![只有一条训练损失曲线：它下降后停在一个较高的水平，说明模型没把数据拟合好](assets/学习曲线诊断：欠拟合、过拟合与数据量不足/00185.webp)

### 2.2 第二个判据：测试损失高 = 过拟合

换一种情形：训练损失很低。所以这个模型不是欠拟合。但我们能说它是个好模型吗？不能——别忘了这只是训练损失，相当于用课上的原题考学生；学生考得好，可能只是背下了每道题的答案 [【跳转到 03:16】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=196)。

要判断模型好不好，我们需要更多信息。每位老师都会出和课上不一样的题；用同样的思路，我们可以在另一份数据上评估模型，于是有了两条学习曲线：**训练损失**和**测试损失** [【跳转到 03:56】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=236)。

如果测试损失很高，说明学生在熟悉的题上表现好、在新题上一塌糊涂——这不是一个好模型。这就是第二个要点：**测试损失高，说明模型泛化不好，这种情况叫过拟合** [【跳转到 04:12】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=252)。

### 2.3 两条都低 = 拟合良好

反过来，训练损失低说明模型把训练数据学好了；测试损失低说明它能泛化到没见过的数据。这叫**拟合良好**（well-fit）：既不欠拟合，也不过拟合 [【跳转到 04:27】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=267)。这就是我们想看到的样子。

![两条曲线都降到低位、彼此贴近：拟合良好](assets/学习曲线诊断：欠拟合、过拟合与数据量不足/00270.webp)

## 三、两种常见的失败形状

### 3.1 两条都在降，但差距很大：数据不足或分布不一致

第一种形状：两条曲线都在下降，看起来一切正常，但问题出在两条曲线**之间的差距** [【跳转到 04:50】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=290)。

当训练集不足以让模型在测试集上表现好时，就会出现这种差距。原因可能是训练集和测试集分布有差异，也可能是训练集太小 [【跳转到 05:05】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=305)。这种情况非常常见。

要点是：**你希望这个差距小**。解决办法之一是给训练集加更多数据；另一种是确保训练集和测试集来自同一个分布 [【跳转到 05:16】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=316)。无论哪种，看到这种形状就说明模型还有很大提升空间 [【跳转到 05:31】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=331)。

![两条曲线都在下降，但测试损失始终明显高于训练损失：差距来自数据不足或分布不一致](assets/学习曲线诊断：欠拟合、过拟合与数据量不足/00295.webp)

### 3.2 测试损失先降后升：训练太久，用早停

第二种形状：一开始训练损失和测试损失都在下降，这很好；然后测试损失**突然开始上升** [【跳转到 05:43】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=343)。

在这一点之前模型是拟合良好的，从这一点开始它过拟合了：它在记住训练数据，不再泛化 [【跳转到 05:59】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=359)。要点是：我们训练得太久了。

一个简单的修法是**早停**（early stopping）：在模型开始过拟合之前就停下来 [【跳转到 06:15】](https://www.youtube.com/watch?v=nt5DwCuYY5c&t=375)。

![测试损失先降后升：上升的拐点就是该早停的位置](assets/学习曲线诊断：欠拟合、过拟合与数据量不足/00350.webp)

## 小结

- **学习曲线**：横轴 epoch、纵轴损失，同时画训练损失与测试损失。
- **训练损失高 → 欠拟合**：模型连训练数据都没拟合好。
- **测试损失高 → 过拟合**：训练集上表现好，新数据上表现差。
- **两条都低且贴近 → 拟合良好**。
- **两条都降但差距大 → 数据不足或分布不一致**：加数据、或让训练/测试同分布。
- **测试损失先降后升 → 训练太久**：在上升前早停。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 学习曲线（learning curve） | 以训练轮数为横轴、损失为纵轴的曲线，通常画训练与测试两条。 |
| 训练损失 | 在训练数据上算的损失，衡量"学得怎么样"。 |
| 测试损失 | 在没参与训练的数据上算的损失，衡量"能不能泛化"。 |
| 欠拟合（underfit） | 训练损失高，模型没把数据拟合好。 |
| 过拟合（overfit） | 训练损失低但测试损失高，模型记住了训练数据。 |
| 拟合良好（well-fit） | 训练与测试损失都低且接近。 |
| 泛化差距 | 测试损失与训练损失之间的差；差大说明数据不足或分布不一致。 |
| 早停（early stopping） | 在测试损失开始上升之前停止训练，避免过拟合。 |
| epoch | 训练轮数，把训练集完整过一遍算一轮。 |
