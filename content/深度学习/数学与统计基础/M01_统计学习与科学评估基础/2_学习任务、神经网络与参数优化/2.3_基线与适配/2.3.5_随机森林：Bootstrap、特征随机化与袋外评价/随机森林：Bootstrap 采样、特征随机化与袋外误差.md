# 随机森林：Bootstrap 采样、特征随机化与袋外误差

> 视频来源：[StatQuest: Random Forests Part 1 - Building, Using and Evaluating](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ)（YouTube · StatQuest with Josh Starmer）｜时长约 10 分钟
> 导读：这支视频只做一件事——把随机森林的四个动作按顺序走一遍：有放回抽样、每个节点只从随机子集里挑特征、投票聚合、用袋外样本估误差。本文按这条流水线整理，并在"为什么有效"和"袋外估计能替代什么"两处补上视频点到为止的推导与边界。

## 本讲要解决的核心问题（SCQA）

**背景**：决策树容易构建、容易使用、也容易解释。它的问题不在训练集：给它建树用的那些样本，它能分得很好。

**冲突**：换成新样本就不行了。用《统计学习基础》里的话说，树的致命弱点是**不准确**——它在训练数据上表现很好，但对新样本不够灵活。单棵树的高方差，靠"再建一棵更好的树"解决不了。

**疑问**：把很多棵树合起来，凭什么能比单棵树准？这些树如果长得都差不多，合起来不还是同一个错误？合完之后，又怎么知道这片森林到底好不好，而不必另留一份验证集？

**回答（中心思想）**：随机森林用两道随机化把树**拉开差异**——每棵树用一份有放回抽样的训练集（Bootstrap），每个节点只从随机选出的一小部分特征里挑分裂。差异让各棵树的错误不同步，平均或投票时相互抵消，方差随之下降。而 Bootstrap 天然留下的那约三分之一"袋外"样本，正好可以当作每棵树的天然测试集，聚合起来就是整片森林的**袋外误差**。

## 一、先承认单树的短板：训练集上准，新样本上不稳

视频开场先给树一个公允评价：容易构建、容易使用、容易解释，但在实践中"并没有那么理想"。它引用《统计学习基础》（The Elements of Statistical Learning，常被称作机器学习圣经）的说法：树有一个特点使它无法成为预测学习的理想工具，那就是**不准确**。

![决策树容易构建、使用和解释，但实践中并不理想](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00038.webp)

这句话要拆成两层读：

- 树能把训练集切得很细，切到每个叶子只剩几个样本，于是训练误差很低；
- 但切分位置对训练样本非常敏感——换一批样本，根节点的分裂特征可能就变了。**单棵树是一个高方差估计器**。

随机森林的思路不是去修某一棵树，而是承认每棵树都会犯错，然后让这些错误**不要同时犯**。它把决策树的简单性和这种灵活性结合起来，换来准确率的大幅提升（[【跳转到 01:03】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=63)）。

## 二、第一道随机化：Bootstrap 让每棵树看到不同的训练集

### 2.1 有放回地抽一份同样大的数据集

随机森林的第一步是创建一个 **Bootstrap（自助抽样）数据集**。做法很朴素：从原数据集里随机抽样本，抽出来的放进新数据集；**同一个样本可以被抽中不止一次**。抽到和原数据集一样多为止。

视频用一个只有四个样本的心脏病数据演示：原数据有胸痛、血液循环、动脉阻塞、体重四个特征和心脏病标签；第一次抽中第二行，第二次抽中第三行，第三次抽中第四行，第四次又抽中第四行——于是这份 Bootstrap 数据集里第四行出现了两次，第一行一次也没出现（[【跳转到 01:17】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=77)）。

![Bootstrap：从原数据集有放回地抽同样多的样本，允许重复](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00107.webp)

"允许重复"不是实现上的偷懒，而是这套方法的关键：

- 每次抽样得到的训练集都不同，树看到的数据就不同；
- 有的样本在这一次抽样里出现好几次，在另一次里一次都不出现；
- 因此每棵树的根节点、分裂阈值、叶子划分都会自然分化。

### 2.2 袋外样本是抽样公式的副产品

有放回抽样会留下一个可计算的余量。一个样本在一次抽样中**没被抽中**的概率是

$$
\left(1-\frac{1}{N}\right)^{N} \approx e^{-1} \approx 0.368,
$$

其中 $N$ 是原数据集样本数。也就是说，每份 Bootstrap 训练集约覆盖原数据的 $63.2\%$，剩下约 $36.8\%$ 一次都没被抽到。视频的说法是"通常大约三分之一的原数据不会进入 Bootstrap 数据集"（[【跳转到 06:04】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=364)）。

![原数据中没进 Bootstrap 数据集的那个条目](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00386.webp)

这些没被抽中的样本，就叫这棵树的**袋外（out-of-bag）数据集**。视频在这里开了个玩笑：按它的来历，叫 out-of-boot 更贴切，因为它就是"没进靴子"的那些条目。名字不重要，重要的是它的身份：**这棵树在训练时完全没见过这些样本**。

## 三、第二道随机化：每个节点只从随机子集里挑特征

只有 Bootstrap 还不够。如果每棵树都在"几乎相同"的数据上、用"全部特征"找最优分裂，树与树之间仍然高度相关，聚合的收益有限。随机森林的第二道随机化针对的正是这一点。

### 3.1 规则：每一步都重新抽一次候选特征

建树时，**每个节点**都先从全部 $M$ 个特征中随机选出 $m$ 个（$m < M$），再只在这 $m$ 个候选里挑最优分裂。注意两个细节：

- 随机化发生在**每一个节点**，不是只在根节点抽一次；
- 被选进候选的特征里，仍然按原来的准则（基尼、信息增益或均方误差）挑最好的那个——单棵树怎么分裂，这里还是怎么分裂。

视频的例子里有四个特征，每一步只考虑两个。根节点随机抽到"血液循环良好"和"动脉阻塞"作为候选，假设前者区分效果最好，就用它分裂；到了下一层，把已用过的特征灰掉，再从剩下的三列里重新随机抽两个作为候选（[【跳转到 02:24】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=144)）。

![每个节点只从随机选出的两个特征里挑分裂](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00144.webp)

![根节点候选：随机抽中的两个特征](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00169.webp)

### 3.2 为什么"每个节点都抽"比"每棵树抽一次"更狠

如果只在建树前抽一次特征，那么一棵树从头到尾都看不到某些特征，树与树之间的差异很大，但每棵树本身可能被削弱得太厉害。改成**每个节点重新抽**之后：

- 强特征仍然有机会在多数节点被选中，单棵树的精度不至于崩掉；
- 但强特征不再垄断所有树的所有节点，树与树之间的相关性被压低。

这就是随机森林与单纯 Bagging 的区别：Bagging 只随机化**样本**，随机森林同时随机化**样本和特征**（[【跳转到 03:56】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=236)）。

![在同一份数据上重复 Bootstrap 与特征随机化，得到结构各异的树](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00247.webp)

## 四、聚合：差异越大，平均越稳

### 4.1 分类投票、回归平均

森林建好后，用法很直接：新样本跑过每一棵树，收集每棵树的输出。分类任务**投票取多数**，回归任务**取平均**。

视频的新病人例子：数据先送进第一棵树，它说"有心脏病"；再送进第二棵树，它也说"有"；对所有树重复一遍，最后看哪个选项票数多。"有"票数最多，于是整片森林判定这位病人有心脏病（[【跳转到 05:04】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=304)）。

![新样本跑过每棵树，逐棵记录投票](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00304.webp)

视频在这里给出术语：**对数据做 Bootstrap 抽样，再把各棵树的判断聚合起来做决定，这套流程叫 Bagging（Bootstrap Aggregating，装袋）**。随机森林是 Bagging 的一个特例，额外加了特征随机化。

### 4.2 方差为什么下降：把"平均"写成式子

视频的直觉是"正是树的多样性，让随机森林比单棵决策树更有效"。把这句话写成式子，就能看清随机化到底在做什么。

设单棵树的预测方差为 $\sigma^2$，森林里有 $B$ 棵树，两两之间的平均相关系数为 $\rho$。取平均后的方差是

$$
\operatorname{Var}\!\left(\frac{1}{B}\sum_{b=1}^{B} T_b\right)
= \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2 .
$$

这个式子把方差拆成两块，正好对应两道随机化：

- **第二项随 $B$ 增大而趋近于零**。树越多，独立的那部分噪声被平均得越干净。这就是"多种树"的收益，也是它边际递减的原因——$B$ 从 10 加到 100 收益明显，从 1000 加到 2000 几乎看不出来。
- **第一项 $\rho\sigma^2$ 不随 $B$ 下降**。树再多，只要它们高度相关，方差就卡在这个下限上。降低它的唯一办法是**让树之间不相关**，也就是特征随机化。

所以随机森林的两道随机化分工明确：Bootstrap 让每棵树的训练集不同，特征随机化进一步切断树与树之间的共同依赖。**没有特征随机化，$B$ 再大也压不下 $\rho\sigma^2$ 这一项**；这正是单靠 Bagging 不够、还要随机选特征的原因。

需要说明的是，这个式子是"树两两等相关、方差相同"这一简化假设下的结论，真实森林里各棵树的相关结构并不整齐。它给的是方向，不是精确的误差预测。

## 五、袋外误差：不用另留验证集的自检

### 5.1 每棵树都有一批"没见过的样本"

现在回到第二节留下的袋外样本。关键事实只有一句：**袋外样本没有参与这棵树的训练**。因此它对这棵树来说，就是一份天然的测试集（[【跳转到 06:51】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=411)）。

视频的做法是逐棵树进行的：

1. 取出这棵树的袋外样本；
2. 把它送进这棵树，看预测对不对；
3. 再把这个样本送进**其他所有没有用它训练过的树**，收集这些树的投票；
4. 票数最多的标签，就是随机森林对这个袋外样本的预测（[【跳转到 07:11】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=431)）。

![袋外样本送进其他没有用它建过的树，按投票定标签](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00431.webp)

注意第 3 步的限定："其他**没有用它训练过**的树"。一个样本对不同树的袋外身份是不同的：它可能是第 1 棵树的袋外样本，却进了第 2 棵树的 Bootstrap 训练集。所以每个样本要用到的是"以它为袋外的那些树"的子集，而不是整片森林。

### 5.2 从"逐样本判对错"到"整片森林的误差"

对所有树的袋外样本重复上面的流程，每个样本都会得到一个由部分树投票产生的预测。把这些预测和真实标签比对：

- 被正确分类的袋外样本**比例**，就是随机森林准确率的估计；
- 被错误分类的袋外样本**比例**，就是**袋外误差（out-of-bag error）**。

![每个袋外样本的投票结果汇总，错误比例即袋外误差](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00482.webp)

它之所以有用，是因为**不需要额外切一份验证集**：验证信息已经藏在 Bootstrap 的抽样过程里了。对样本量紧张的数据集（生物序列、稀有扰动、小规模实验批次），这一点很实际——留出法会再吃掉一块本就不多的数据，袋外估计则把每份数据都用在训练上，同时仍然给出一个"没见过它"的误差读数。

### 5.3 它估计的是什么，不估计什么

袋外误差回答的是"这片森林在**与训练集同分布**的新样本上错多少"。它不能自动回答另外几类问题：

- **分布外泛化**：换物种、换细胞系、换实验平台之后还准不准，袋外样本回答不了，它们仍然来自同一批数据；
- **分组泄漏**：如果同一供体、同一骨架、同一批次的样本被分散进不同 Bootstrap 集，袋外样本与训练样本并不独立，袋外误差会偏乐观；
- **超参数选择的乐观偏差**：用袋外误差挑完 $m$ 之后，这个最小值本身就是被挑选过的，最好再在一份完全独立的数据上复核。

换句话说，袋外误差是**便宜的内部估计**，不是外部验证的替代品（[【跳转到 08:02】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=482)）。

## 六、用袋外误差选 $m$：一个不用验证集的调参循环

视频最后把前面的零件装成一个调参流程（[【跳转到 08:21】](https://www.youtube.com/watch?v=J4Wdy0Wc_xQ&t=501)）。既然袋外误差能估准确率，就可以拿它来比较不同的 $m$：

1. 建一片随机森林；
2. 用袋外误差估计它的准确率；
3. 改变每一步使用的变量个数 $m$，重复很多次；
4. 挑袋外误差最小的那个设置。

![比较不同 m 的袋外误差，选最准的森林](assets/随机森林：Bootstrap%20采样、特征随机化与袋外误差/00522.webp)

视频给了一个常用的起点：**从变量数的平方根开始，再在这个值上下试几个设置**。分类任务常取 $m \approx \sqrt{M}$，回归任务常取 $m \approx M/3$；视频只提到平方根这一条经验规则，回归的取值属于同一类经验做法，具体数值仍要以袋外误差或交叉验证的结果为准。

这个循环的意义不只是省一份验证集，更在于它把"随机化强度"变成了一个**可测量的旋钮**：

- $m$ 太小：每棵树的候选特征太少，单树变弱，偏差上升；
- $m$ 太大：树与树越来越像，$\rho$ 上升，方差降不下来；
- 袋外误差曲线通常在中间某处最低，这个位置就是这片数据上的折中。

## 七、把这条流水线放回基线位置

随机森林在建模工作里的角色，是**一个很强的表格数据基线**：不需要特征缩放、不需要复杂的预处理、能处理高维特征，还能顺手给出特征重要性和一个内部误差估计。它的局限也同样明确：

- 它由树组成，预测是分段常数，**不会外推到训练数据范围之外**；
- 它对难样本的处理是"投票时被多数压过"，而不是像 Boosting 那样专门去修正；
- "袋外误差很低"只说明在同分布数据上表现稳定，不说明机制解释或实验验证已经完成。

本站另一篇《[中字]简单易懂的随机森林算法原理分析》从应用角度补了它的优缺点清单和 Bagging/Boosting 的分工，可以和本文对照阅读：本文讲"随机化怎么产生差异、差异怎么变成误差估计"，那一篇讲"这套方法适合放在什么场景"。

## 小结

- 单棵树在训练集上准、对新样本不稳，问题出在**高方差**；随机森林用"多棵差异化的树 + 聚合"来降方差。
- **第一道随机化是 Bootstrap**：有放回地抽和原数据同样多的样本，同一个样本可重复出现；每份训练集约覆盖 $63.2\%$ 的样本。
- **第二道随机化是特征随机化**：每个节点都从全部 $M$ 个特征里随机抽 $m$ 个候选，再在候选里挑最优分裂。它压低的是树与树的相关性。
- 聚合规则：分类投票取多数，回归取平均。平均后方差为 $\rho\sigma^2 + (1-\rho)\sigma^2/B$：增加树数只能压掉第二项，压低第一项要靠降低相关性。
- **袋外样本**是 Bootstrap 的副产品，约占原数据三分之一，没参与该树训练，可当天然测试集；逐样本用"以它为袋外的那些树"投票，错误比例就是**袋外误差**。
- 袋外误差可用于选 $m$（常用起点 $\sqrt{M}$），但它是同分布下的内部估计，不能替代外部验证，也不解决分组泄漏。
- 术语：Bootstrap 抽样 + 聚合决策 = **Bagging**；随机森林是 Bagging 加特征随机化。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| Bootstrap（自助抽样） | 从原数据中有放回地抽同样多的样本，允许重复，用来给每棵树造一份不同的训练集 |
| Bagging | Bootstrap Aggregating：有放回抽样训练多棵树，再投票或平均；随机森林是它的特例 |
| 特征随机化 | 每个节点只从随机选出的 $m$ 个特征里挑分裂，而不是看全部 $M$ 个 |
| $m$ / $M$ | 每个节点的候选特征数 / 特征总数；$m$ 越小树越不同，单树也越弱 |
| 袋外样本（out-of-bag） | 某次 Bootstrap 抽样中没被抽中的样本，约占原数据三分之一，可当该树的测试集 |
| 袋外误差（OOB error） | 袋外样本中被随机森林错误分类的比例，不需要另留验证集 |
| 树间相关性 $\rho$ | 决定聚合后方差下限的量；特征随机化就是为了压低它 |
| 方差降低 | 对差异化的树取平均，使各自的随机误差相互抵消 |
