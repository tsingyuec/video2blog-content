## 本讲要解决的核心问题（SCQA）

**背景**：拿到一批没有标签的样本（细胞、病人、基因、化合物），最自然的动作是“把它们分成几组”。聚类算法就是做这件事的工具，输入只有特征矩阵，没有标准答案。

**冲突**：三种常见算法都能给出彩色分组图，但它们对“簇”的定义并不一样。k-means 假设簇围绕一个中心、大致呈球形；层次聚类只记录“谁和谁先合并”；DBSCAN 则把簇定义为高密度区域，并允许把低密度点判为离群点。同一份数据，k-means 可能硬把嵌套结构切成两半，DBSCAN 却能把外圈和内圈分开；反过来，DBSCAN 也可能把一片均匀数据判成一堆噪声。更麻烦的是，k-means 还要你先说出簇数 $K$。

**疑问**：这三种算法各自假设了什么？距离、链接方式和簇数到底怎样影响结果？拿到一份新数据，应该先问哪些问题再选算法？

**回答（中心思想）**：**先看数据的几何形态，再选算法**。k-means 用“到中心的距离”定义簇，必须给定 $K$，对初始点和球形假设敏感；层次聚类用“样本或子簇之间的距离”逐步合并，输出一棵树，簇数可以事后在树上切；DBSCAN 用“邻域内的密度”定义簇，不需要 $K$，能处理嵌套簇和离群点，但要调邻域半径与核心点阈值。三者没有谁更“正确”，只有假设与当前数据、当前问题是否匹配。

## 一、k-means：把每个点交给最近的中心，再反复修正中心

### 1.1 算法只有五步

视频用一个一维例子开场：每个点代表一个样本（比如某种肿瘤或细胞类型的测量值），肉眼能看出三团，现在要让计算机自己找出来 [【跳转到 00:32】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=32)。

k-means 的流程可以写成五步：

1. **选定簇数 $K$**：这就是 k-means 里的“k”。例子里取 $K=3$ [【跳转到 00:52】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=52)。
2. **随机选 $K$ 个互不相同的点作为初始簇**（初始中心）。
3. **计算每个点到各个中心的距离**。
4. **把点分配给最近的中心**。
5. **重新计算每个簇的均值**，把均值当作新的中心，回到第 3 步；直到分配不再变化 [【跳转到 02:32】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=152)。

![一维数据上的 k-means：横轴是样本值，彩色竖线是当前簇中心，点按最近中心着色](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/kmeans_00032.webp)

![一轮更新：先按当前中心分配点，再用每个簇的均值替换中心，重复到分配不再变化](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/kmeans_00152.webp)

### 1.2 它只保证“局部最好”，所以要多次随机起步

第一轮跑完，视频里的结果明显不如人眼：有一团被切开了，两个本应分开的团被并在一起 [【跳转到 02:52】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=172)。

原因是 k-means 在优化一个目标：**簇内变异之和**（total variation within clusters）。每轮“分配给最近中心 + 用均值更新中心”都会让这个目标下降，但它只保证落到一个局部最优，不保证是全局最优。初始中心选得不好，就会停在一个糟糕的划分上。

所以实际实现会**用不同的随机起点重复跑很多次**，每次记录簇内变异之和，最后返回变异最小的那一组 [【跳转到 03:32】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=212)。这也解释了一个常见现象：同一份数据、同一个 $K$，换随机种子结果可能不同；固定种子只是让结果可复现，不等于消除了这个不稳定性。

![初始点选择不佳时，k-means 会把本应分开的团合并、把本应完整的团切开](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/kmeans_00172.webp)

### 1.3 距离不一定是欧氏距离，但“中心”假设一直在

视频随后把一维例子扩展到二维：仍然随机选三个点，用**欧氏距离**（二维时就是勾股定理）把每个点分给最近中心，再算中心、再分配 [【跳转到 06:12】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=372)。

对热图数据也一样：如果只有两个样本，可以把它们当作 $x$、$y$ 两个坐标；有三个样本就加一个 $z$ 轴；更多维就继续加轴。**聚类并不需要真的把图画出来，只需要能计算样本之间的距离** [【跳转到 07:12】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=432)。欧氏距离在 $d$ 维下的写法是：

$$
d(\mathbf{x},\mathbf{y})=\sqrt{\sum_{j=1}^{d}(x_j-y_j)^2}
$$

这里要记住 k-means 的隐含假设：**每个簇由一个中心代表，簇的形状围绕中心大致对称**。如果真实结构是“外圈包住内圈”或“长条形、月牙形”，用中心距离就会失真；这正是后面 DBSCAN 要解决的问题。

## 二、簇数 $K$：肘部图给的是一个参考点，不是判决

$K$ 不能由 k-means 自己决定，只能由使用者给定。视频给了一个可操作的选法：**把 $K=1,2,3,\ldots$ 都跑一遍，画“簇内变异之和随 $K$ 的变化”** [【跳转到 04:32】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=272)。

- $K=1$ 时所有点在一簇，簇内变异最大；
- 每增加一个簇，簇内变异都会下降；极端情况下每个点自成一簇，变异为 0；
- 但下降速度不是均匀的：如果数据里真有 3 团，$K$ 从 2 到 3 会出现一次大幅下降，之后收益迅速变小。

把“方差的减少量”对 $K$ 画出来，曲线会在某个 $K$ 处出现明显折角，这就是**肘部图（elbow plot）**，折角对应的 $K$ 作为参考 [【跳转到 05:32】](https://www.youtube.com/watch?v=4b5d3muPQmA&t=332)。

![肘部图：横轴是簇数 K，纵轴是“方差的减少量”；K=3 之后曲线明显变平，折角提示 3 是一个候选](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/kmeans_00332.webp)

必须补一句边界：肘部图**没有唯一的数学答案**。折角有时很尖，有时很圆；数据本身没有清晰簇结构时，曲线可能平滑下降，这时“找肘部”就是在一段连续曲线上强行选点。因此 $K$ 的选择需要和后面的轮廓系数、稳定性以及领域知识一起看，不能只看一张图。

## 三、层次聚类：不预设簇数，先建一棵“合并树”

### 3.1 从“最相似的两个”开始反复合并

层次聚类（视频讲的是凝聚式，agglomerative）不要求先给簇数。它的输入仍然是一组样本，输出是一棵**树状图（dendrogram）**。

视频用一个 $3$ 个样本 × $4$ 个基因的热图演示，只对基因（行）聚类 [【跳转到 01:35】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=95)。步骤是：

1. 对每个基因，找出与它最相似的另一个基因；
2. 在所有两两组合里，找出**最相似的一对**，把它们合并成一个簇；
3. 回到第 1 步，但把新形成的簇当作一个“单个基因”，继续和其他基因或簇比较；
4. 重复合并，直到所有对象并成一个簇。

例子里，基因 1 和基因 3 最相似，先合并成簇 1；然后基因 2 和基因 4 最相似，合并成簇 2；最后两个簇再合并，整棵树完成 [【跳转到 03:00】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=180)。

![层次聚类的输入与输出：左边是基因 × 样本热图，右边是树状图；先合并的簇分支最短，最后合并所有对象的簇分支最长](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/hier_00300.webp)

### 3.2 树状图怎么读：分支高度就是“合并时的距离”

树状图同时编码了两件事：**谁和谁相似**，以及**它们是在第几步被合并的**。

- 最先形成的簇，分支最短，说明这两个对象最相似；
- 越晚合并的簇，分支越长，说明它们之间的差异越大；
- 整棵树最上面的根，包含所有对象，是最后一次合并。

因此层次聚类**不需要预先指定 $K$**：你可以先建完整的树，再在某个高度“切一刀”，切出来的连通分支就是簇。切得低，簇多而细；切得高，簇少而粗。这一点和 k-means 正好相反：k-means 是“先定簇数再优化”，层次聚类是“先建树再决定在哪里切”。

![层次聚类对热图排序的效果：左图未聚类，右图按相似性重排行与列后，表达模式相近的基因和样本聚成块](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/hier_00079.webp)

### 3.3 两个必须先定的选择：距离与链接方式

层次聚类并不是“没有参数”。它至少有两个隐含选择，而且都会改变结果。

**第一，样本之间用什么距离。** 视频用两个基因、两个样本的小例子手算了欧氏距离：

$$
d(g_1,g_2)=\sqrt{(1.6-(-0.5))^2+(0.5-(-1.9))^2}
=\sqrt{2.1^2+2.4^2}\approx 3.2
$$

[【跳转到 06:02】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=362)

![两个基因、两个样本的欧氏距离手算：先把每个样本上的差值平方，再相加开方，得到 3.2](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/hier_00382.webp)

换成**曼哈顿距离**，就把“平方再开方”换成“绝对值相加”：

$$
d(\mathbf{x},\mathbf{y})=\sum_{j=1}^{d}\lvert x_j-y_j\rvert
$$

视频把两种距离画成热图，结果非常相似但并非完全相同 [【跳转到 08:16】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=496)。讲者的态度很明确：**距离度量的选择没有唯一的生物学或物理学理由，选能让你看清数据的那个**。

![用欧氏距离与曼哈顿距离分别聚类得到的同一份热图：整体结构相似，但局部排序和分块有差异](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/hier_00618.webp)

**第二，簇与簇之间怎么比较。** 当两个对象已经合并成一个簇，接下来要算“这个簇和另一个点/簇有多远”，有三种常见定义：

| 链接方式 | 用什么代表一个簇 | 直观含义 |
| :--- | :--- | :--- |
| 质心（centroid） | 簇内所有点的平均值 | 比较两个簇的中心 |
| 单链接（single linkage） | 簇内离目标最近的点 | 只要有一对点很近，就算两个簇近 |
| 全链接（complete linkage） | 簇内离目标最远的点 | 必须所有点都较近，才算两个簇近 |

视频用二维平面上的两个簇和一个待分配点演示了这三种比较方式 [【跳转到 09:19】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=559)。讲者还提醒：**R 的 `hclust` 默认使用全链接**，所以“默认结果”本身已经带了一个链接假设 [【跳转到 10:04】](https://www.youtube.com/watch?v=7xHsRkOdVwo&t=604)。

![三种链接方式的比较对象：质心看簇的平均位置，单链接看最近点，全链接看最远点](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/hier_00599.webp)

单链接容易产生“链式效应”：只要两个簇之间有一串密集的点把它们连起来，就会被合并成一个长条簇；全链接则倾向于产生紧凑、大小相近的簇。**没有哪种链接普遍更好，只有和数据结构是否匹配。**

## 四、DBSCAN：把“高密度区域”当作簇，把低密度点留给噪声

### 4.1 为什么需要密度视角

DBSCAN 的开场例子是体重—身高散点图：肉眼能看到两团密集的人，以及几个离大家很远的离群点 [【跳转到 00:21】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=21)。

麻烦在于这两团是**嵌套**的：绿色簇包住蓝色簇。k-means 这类以中心距离为准的算法很难处理这种结构，可能把外圈的一些点错误地分给内圈 [【跳转到 01:01】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=61)。而且真实数据往往不止两个特征，四维以上无法靠肉眼观察，所以需要一个能按“密度”而不是“到中心的距离”来定义簇的算法。

![嵌套簇：绿色簇包住蓝色簇，外围还有低密度离群点；k-means 的中心距离假设在这里不适用](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/dbscan_00061.webp)

### 4.2 两个参数：邻域半径与核心点阈值

DBSCAN 的第一步是：对每个点画一个半径为 `eps` 的圆（高维时是超球），数一数圆内（含边界）有多少个其他点 [【跳转到 03:01】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=181)。

- **邻域半径 `eps`**：圆画多大，由使用者定；
- **核心点（core point）**：如果圆内至少有 `minPts` 个其他点，这个点就是核心点。视频例子里把阈值定为“至少 4 个邻居” [【跳转到 04:01】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=241)。

这两个参数都是**用户定义**的，所以 DBSCAN 不是“免调参”的算法；它只是把“簇数”换成了“密度尺度”。

![核心点判定：每个点画一个固定半径的邻域圆，圆内邻居数达到阈值才是核心点；右侧孤立点的圆内没有任何其他点](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/dbscan_00241.webp)

### 4.3 从一个核心点长出一个簇

确定核心点之后，算法按下面的规则生长簇：

1. 随机选一个尚未分配的核心点，作为第一个簇的起点 [【跳转到 04:41】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=281)；
2. 所有与当前簇“相邻”（邻域圆相交）的核心点加入该簇，并继续向外扩展；
3. 当没有新的核心点可以加入时，把**紧挨着核心点、但自己不是核心点**的点也加入该簇；
4. 非核心点只能“加入”，不能“扩展”：它不能再把更远的非核心点拉进来 [【跳转到 06:01】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=361)；
5. 所有核心点都分配完后，剩下的、不挨着任何核心点的非核心点就是**离群点（outlier）** [【跳转到 07:41】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=461)。

![从一个随机核心点开始，相邻核心点不断加入并把簇向外延伸；非核心点只在最后被“贴”到簇边缘](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/dbscan_00301.webp)

![最终结果：两个高密度区域各自成簇，远离所有核心点的低密度点被标为离群点，不强行归入任何簇](assets/聚类方法的假设与选择：k-means、层次聚类与%20DBSCAN%20的分工/dbscan_00481.webp)

### 4.4 DBSCAN 的两个容易忽略的后果

**第一，簇是“按顺序”长出来的。** 如果一个非核心点同时靠近两个簇，它会在先构建的那个簇里被吸收；一旦进入第一个簇，就不再有机会属于第二个簇 [【跳转到 08:01】](https://www.youtube.com/watch?v=RDZUdRSDOok&t=481)。所以点的处理顺序可能影响边界点的归属。

**第二，它能发现任意形状的簇，也能把“噪声”显式留下来。** 这对生物数据很有用：稀有细胞、异常样本、实验伪影可能本来就不属于任何主群。但反过来说，如果 `eps` 太小，正常簇会被打碎成很多小簇加一堆噪声；如果 `eps` 太大，不同簇会被桥接成一个。`minPts` 也有同样的双刃性。

## 五、把三种方法放在一张表里

| 维度 | k-means | 层次聚类（凝聚式） | DBSCAN |
| :--- | :--- | :--- | :--- |
| 簇的定义 | 围绕中心的一组点 | 按相似性逐级合并出的子树 | 高密度连通区域 |
| 要不要先给簇数 | 要，必须给 $K$ | 不要，建树后切 | 不要，给密度参数 |
| 主要参数 | $K$、初始点、距离 | 距离、链接方式、切树高度 | `eps`、`minPts`、距离 |
| 能否发现非球形簇 | 较弱 | 取决于链接方式 | 较强 |
| 是否显式处理离群点 | 不处理，所有点必须入簇 | 不处理，所有点都在树上 | 处理，低密度点可判为噪声 |
| 结果稳定性 | 受初始点影响，需多次重启 | 通常确定（给定距离、链接与并列处理） | 受点顺序与参数影响 |
| 典型输出 | 每个点一个簇标签 | 一棵树 + 任意高度的切分 | 簇标签 + 噪声标签 |

这张表可以直接转成选型问题：

1. **数据里有没有明确的“中心”？** 如果簇大致是球形、大小相近，k-means 简单有效；如果有嵌套、长条、月牙形，优先考虑 DBSCAN 或换链接方式。
2. **能不能先给出簇数？** 完全不知道就先跑层次聚类看树，或在 k-means 上用肘部图 + 轮廓系数扫一遍 $K$。
3. **离群点要不要保留？** 如果噪声本身是研究对象（稀有细胞、异常样本），DBSCAN 的“噪声”标签是信息；如果每个样本都必须归属，k-means 或层次聚类更合适。
4. **距离和链接方式有没有被默认值替你做决定？** `hclust` 的默认全链接、k-means 的默认欧氏距离，都是假设，不是中性设置。

## 六、聚类结果不是生物学分组

这三种算法都只做一件事：**根据特征空间里的几何关系，把样本分成若干组**。它们不知道“T 细胞”“上皮细胞”“处理组”意味着什么，也不会因为两个簇在图上离得远就证明它们生物学上不同。

因此，从“算法给出簇”到“支持一个生物学分组”，中间至少还要补三步：

- **外部证据**：用独立的 marker 基因、蛋白标记、空间位置或功能实验说明这个簇对应什么；
- **评价**：有金标准时用调整兰德指数等外部指标，没有金标准时用轮廓系数、稳定性和领域可解释性；
- **边界声明**：说明簇数、距离、链接方式、随机种子和参数，否则别人无法复现“为什么是这几组”。

同目录的《单细胞降维与聚类全流程：从PCA到UMAP与分辨率选择》展示了这套逻辑在单细胞数据上的具体形态：图聚类在 PCA 空间里建 KNN 图，`resolution` 决定分几群，UMAP 只负责展示；**聚类是某个参数下的划分，细胞类型要靠注释命名**。评价指标与外部验证的细节，见同目录《聚类评价：轮廓系数、兰德指数与调整兰德指数》。

## 小结

- **k-means 是“中心 + 分配”的迭代**：给定 $K$，随机起步，分配到最近中心，再用均值更新中心；只保证局部最优，所以要多起点重启。
- **$K$ 用肘部图选只是参考**：看簇内变异之和随 $K$ 的下降折角；曲线平滑时没有唯一答案，要结合轮廓系数、稳定性和领域知识。
- **层次聚类先建树、后切树**：反复合并最相似的对象，树状图的分支高度表示合并时的距离；不需要预先给簇数。
- **层次聚类有两个隐藏选择**：距离（欧氏/曼哈顿等）和链接方式（质心/单链接/全链接）；R 的 `hclust` 默认全链接。
- **DBSCAN 用密度定义簇**：`eps` 定邻域半径，`minPts` 定核心点阈值；核心点扩展成簇，非核心点只能加入，低密度点判为离群。
- **DBSCAN 能处理嵌套簇和噪声，但参数敏感**：`eps` 太小会碎、太大要桥接；点的处理顺序还会影响边界点归属。
- **算法选择先问数据形态**：有中心、球形、已知 $K$ → k-means；想看层级、不想先定 $K$ → 层次聚类；有嵌套、任意形状、需要噪声标签 → DBSCAN。
- **聚类 ≠ 生物学分组**：算法只给几何分组，命名和结论需要独立证据与可复现的参数记录。

## 关键术语速查

| 术语 | 一句话解释 |
| :--- | :--- |
| 簇内变异之和 | 每个点到所属簇中心的距离平方和，k-means 优化的目标 |
| 肘部图 | 把簇内变异（或其减少量）对 $K$ 作图，用折角选簇数 |
| 局部最优 | 当前起点下无法再改进、但不一定是全局最好的解 |
| 凝聚式层次聚类 | 从每个对象自成一簇开始，反复合并最相似的两个对象 |
| 树状图（dendrogram） | 记录合并顺序与合并距离的树，分支高度=距离 |
| 链接方式（linkage） | 定义“簇与簇之间的距离”的规则，如单链接、全链接、质心 |
| 单链接 | 用两个簇中最近的一对点代表簇间距离，容易产生链式长簇 |
| 全链接 | 用两个簇中最远的一对点代表簇间距离，倾向紧凑簇 |
| DBSCAN | 基于密度的聚类，核心点扩展成簇，低密度点判为噪声 |
| 核心点（core point） | 邻域内邻居数达到 `minPts` 的点 |
| `eps` | DBSCAN 的邻域半径，决定“多近算邻居” |
| `minPts` | 成为核心点所需的最少邻居数 |
| 离群点（outlier） | 不靠近任何核心点的非核心点，DBSCAN 不把它归入簇 |
