## 本讲要解决的核心问题（SCQA）

**背景**：回归树把特征空间切成若干段，每个叶节点用落入该段的观测均值作为预测值。树长得越深，叶子越多，对训练数据的拟合越细。

**冲突**：叶子多到一定程度，树开始记住训练数据里的偶然波动。训练残差很小，换一批测试数据却处处对不上——这就是过拟合。可是，剪掉哪些叶子、剪到什么程度，不能凭感觉。

**疑问**：怎样比较一棵大树和它的各个剪枝版本？剪枝的力度由谁决定？

**回答（中心思想）**：代价复杂度剪枝（cost-complexity pruning，又称 weakest link pruning）给每棵子树打一个**树分数**：`Tree Score = SSR + αT`。SSR 是叶节点内残差平方和，T 是叶子数，α 是每增加一个叶子的代价。α 越大，树越倾向简单；α 由交叉验证在“全树到单叶”的子树序列上选出。这样，剪枝就从“凭经验砍枝”变成一个有目标函数、有验证流程的选择问题。

## 三、第一步：给每棵子树算残差平方和

代价复杂度剪枝的第一步，是对每个候选树计算**残差平方和**（SSR，sum of squared residuals）：把每个叶节点内各观测与叶节点预测值之差的平方加起来，再对所有叶子求和。

先看原始全树。四个叶子的 SSR 分别是 320.8、75、148.8、0；视频把 320.8 取整为 320 相加，得到全树 SSR = 543.8。

## 四、树分数：用 αT 给复杂度定价

只有 SSR 无法在树之间做选择，因为 SSR 永远偏向更大的树。weakest link pruning 的做法是再加一项**树复杂度惩罚**，它随叶子数 T 增长：

```
Tree Score = SSR + αT
```

其中 α 是调节参数：每多一个叶子，树分数就多付 α 的代价。α 越大，模型越不愿意保留叶子；α = 0 时惩罚消失，树分数退化为 SSR。

![树分数 = SSR + αT，T 为叶节点数](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00490.webp)

[【跳转到 08:10】](https://www.youtube.com/watch?v=D0efHEJsfHo&t=490)

设 α = 10000，逐棵算分：

| 树 | SSR | 叶子数 T | 复杂度惩罚 αT | 树分数 |
| --- | ---: | ---: | ---: | ---: |
| 全树 | 543.8 | 4 | 40000 | 40543.8 |
| 三叶子树 | 5494.8 | 3 | 30000 | 35494.8 |
| 两叶子树 | 19243.7 | 2 | 20000 | 39243.7 |
| 单叶子树 | 28897.2 | 1 | 10000 | 38897.2 |

在 α = 10000 时，三叶子树的树分数最低（35494.8），于是选它。

![α = 10000 时，三叶子树的树分数最低](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00515.webp)

[【跳转到 08:35】](https://www.youtube.com/watch?v=D0efHEJsfHo&t=515)

换一个 α，答案会变。若 α = 22000，单叶子树的惩罚最小，树分数最低，剪枝结果就退到只剩一个叶子。**α 决定了剪枝的力度**，所以它不能随手设定。

![α = 22000 时，单叶子树的树分数最低](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00640.webp)

## 五、α 从哪里来：子树序列 + 交叉验证

α 是调参参数，视频用交叉验证来选。流程分两段：先在全部数据上生成一串候选子树，再用交叉验证挑 α。

### 5.1 生成从全树到单叶的子树序列

先用**全部数据**建一棵全尺寸树。α = 0 时复杂度惩罚为零，这棵全树的树分数最低。

![α = 0 时全树的树分数最低](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00684.webp)

[【跳转到 11:24】](https://www.youtube.com/watch?v=D0efHEJsfHo&t=684)

然后逐步提高 α：每当提高到一个临界值，剪掉某些叶子会让树分数更低，就得到一棵更小的子树。视频里的临界值是 α = 10000（剪成三叶）、15000（剪成两叶）、22000（剪成单叶）。

![提高 α 会依次触发剪枝，形成一串候选子树](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00759.webp)

[【跳转到 12:39】](https://www.youtube.com/watch?v=D0efHEJsfHo&t=759)

最终得到一条**从全树到单叶的子树序列**，每个候选对应一个 α 区间。这一步只用全量数据，还没有做模型选择。

### 5.2 用 10 折交叉验证选 α

接着把数据切成训练集和测试集：

1. 只用训练集，按刚才得到的 α 值重建全树和各子树；
2. 在测试集上计算每棵树的 SSR；
3. 换一组新的训练/测试划分，重复上述过程，共做 10 折交叉验证；
4. 取“在测试集上平均 SSR 最低”的 α 作为最终值。

视频的例子里，第一折 α = 10000 的树测试 SSR 最小，第二折 α = 0 的树最小；10 折平均下来，α = 10000 胜出。

![每折在测试集上比较各 α 对应的树，取平均最优的 α](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00846.webp)

[【跳转到 14:06】](https://www.youtube.com/watch?v=D0efHEJsfHo&t=846)

### 5.3 回到全量数据取最终树

最后，回到最初用全量数据生成的那串子树，取 α = 10000 对应的那一棵，就是最终剪枝后的树。

![最终剪枝树：取交叉验证选出的 α 对应的子树](assets/回归树的代价复杂度剪枝：树分数、alpha%20与交叉验证/00927.webp)

## 六、把这条链放回“深度带来的拟合风险”

这段视频只讲回归树，但剪枝要解决的问题对一般决策树同样成立：

- **深度与叶子数就是容量旋钮**。树越深，叶子越多，每个叶子覆盖的样本越少，叶节点预测越贴近个别训练点；训练残差下降，测试残差可能上升。
- **剪枝不是“越简单越好”**。α 越大，保留的叶子越少；视频里 α 从 0 升到 22000，树就从四个叶子退到只剩一个叶子。合适的 α 要在拟合与复杂度之间取平衡。
- **比较必须用同一把尺子**。树分数把“拟合误差”和“复杂度”放在同一个数值上；没有复杂度项，比较必然偏向大树。
- **本篇讲的是后剪枝**。先长全树，再按树分数往回剪；剪枝控制的就是树的容量。

## 小结

- 回归树的叶节点输出该段观测的均值；树太深会把训练数据的局部波动记成规律，表现为训练残差小而测试残差大。
- 剪枝的直观操作：去掉叶子，把分裂换成一个取更多观测均值的叶节点；训练拟合变差，测试表现可能变好。
- 代价复杂度剪枝给每棵子树算 `Tree Score = SSR + αT`：SSR 衡量拟合，αT 惩罚叶子数。
- α = 0 时全树最优；α 增大，最优子树依次变小，形成“全树 → 三叶 → 两叶 → 单叶”的序列。
- α 由 10 折交叉验证在测试集 SSR 上选出；最终用全量数据中该 α 对应的子树。
- 深度/叶子数是容量旋钮；α 决定保留多少叶子，并由交叉验证选出，而不是固定值。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 回归树 | 叶节点输出该段观测均值的树模型 |
| 残差（residual） | 观测值与叶节点预测值之差 |
| SSR（残差平方和） | 所有叶节点内残差平方的总和，衡量训练拟合 |
| 过拟合 | 训练残差很小但测试残差变大，树记住了噪声 |
| 剪枝（pruning） | 去掉叶子、把分裂换成叶节点，以降低复杂度 |
| 代价复杂度剪枝 | 用 `SSR + αT` 给子树打分并选择，又称 weakest link pruning |
| 树分数（Tree Score） | `SSR + αT`，同时衡量拟合与复杂度 |
| α | 每增加一个叶子的惩罚系数，越大树越简单 |
| 子树序列 | α 从 0 增大时依次得到的一串候选树，从全树到单叶 |
| 交叉验证选 α | 在训练集建树、测试集算 SSR，取平均最优的 α |
