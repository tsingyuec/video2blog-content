# 逻辑回归：S 形曲线给出类别概率，最大似然替代最小二乘

> 视频来源：[StatQuest: Logistic Regression](https://www.youtube.com/watch?v=yIYKR4sgzI8)（YouTube · StatQuest with Josh Starmer）｜时长约 9 分钟
> 导读：这支短片用"小鼠是否肥胖"一个例子，把逻辑回归和线性回归的差别讲成三件事：预测对象从连续值变成真/假，拟合对象从直线变成 S 形曲线，拟合准则从最小二乘变成最大似然。本文按这三件事重排，并补上视频没有写的两步：一是从对数几率反解出 S 形曲线的公式（第五节），二是从伯努利似然推出二分类交叉熵、并逐样本算一遍损失（第四节的 4.4–4.6）。

## 本讲要解决的核心问题（SCQA）

**背景**：线性回归用一条直线，从体重这样的测量值预测体型这样的连续值；它还能给出 $R^2$、p 值，并且能比较"只用体重"和"体重加血量"两个模型谁更好（见 2.3.1）。

**冲突**：很多问题的答案不是数值，而是"是/否"——这只小鼠肥胖还是不肥胖。标签只有 0 和 1，用直线去拟合会算出 $-0.3$ 或 $1.4$：既不是概率，也没法解释成"可能性"。更麻烦的是，线性回归赖以工作的残差平方和在这里失去了意义，$R^2$ 也算不出来。

**疑问**：怎样让一个线性打分输出 $0$ 到 $1$ 之间的概率，并且用这套概率本身来训练模型？

**回答（中心思想）**：**逻辑回归 = 线性打分 + S 形曲线**。曲线把打分压成概率，读作"这只小鼠肥胖的可能性"；训练时不比残差，而是换一条准则——**最大似然**：移动曲线，让"观测到手里这批 0/1 标签"的联合概率最大。概率是模型的输出，类别是概率再经过一个阈值（默认 50%）之后的决定，两者不是同一件事。

## 一、任务换了：从预测连续值到预测真/假

### 1.1 先回顾线性回归能做什么

视频用前两分钟快速回放线性回归 [【跳转到 00:25】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=25)：给一批"体重—体型"数据点，拟合一条直线，然后可以做三件事——算 $R^2$ 判断体重与体型是否相关、算 p 值判断 $R^2$ 是否显著、用直线给新小鼠预测体型。它还能扩展到多元回归（体重加血量预测体型），也能把基因型这类离散测量放进来 [【跳转到 02:05】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=125)，并且可以比较简单模型与复杂模型，判断多测一个变量是否值得。

这些能力构成了对照系：下面每讲一条逻辑回归的做法，都要问一句"线性回归的那套还能不能用"。

### 1.2 逻辑回归预测的是真或假

逻辑回归和线性回归很像，只有一处根本区别：**它预测某件事为真还是为假，而不是预测体型那样的连续值** [【跳转到 02:55】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=175)。

![逻辑回归的纵轴只有两档：Is Obese 与 Is Not Obese；数据点落在两条水平线上，横轴仍是体重](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00195.webp)

图上每个点仍然是一只小鼠，横轴是体重，但纵轴不再是一个连续刻度，而是两档：肥胖、不肥胖。这时再画一条斜线就荒唐了——斜线会穿过两档之间的空白区域，给出"0.37 个肥胖"这种没有对应实体的值。

### 1.3 拟合的不是直线，而是一条 S 形曲线

逻辑回归改为拟合一条 **S 形的 logistic 曲线** [【跳转到 03:15】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=195)。曲线从 0 出发、在中间快速上升、最后在 1 附近变平，**整条曲线都被关在 0 到 1 之间**。

![S 形曲线的两端分别贴着 0 和 1：曲线纵轴从 0 到 1，正好是概率的取值范围](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00220.webp)

正因为值域是 $[0,1]$，曲线的纵坐标可以直接读成概率：**给定体重，这只小鼠肥胖的概率**。体重很大时曲线贴近 1，肥胖概率高；体重很轻时曲线贴近 0，肥胖概率低。

## 二、概率是输出，类别是阈值之后的决定

### 2.1 曲线读出的是概率，不是标签

视频用一个中等体重的小鼠说明读法 [【跳转到 03:40】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=220)：把它的体重放到横轴上，向上碰到曲线，再向左读到纵轴——大约 50%。这句话的准确含义是"这只小鼠有 50% 的概率肥胖"，而不是"它一半肥胖"。

![中等体重的小鼠落在曲线中点，对应约 50% 的肥胖概率](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00245.webp)

曲线本身只回答"概率是多少"。它没有义务回答"那到底算不算肥胖"——那是下一个问题。

### 2.2 分类规则是外加的一刀

逻辑回归虽然输出概率，实际使用时通常拿来做分类。视频给的规则很朴素 [【跳转到 04:05】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=245)：**如果肥胖概率大于 50%，就判为肥胖；否则判为不肥胖。**

![分类规则：概率大于 50% 判为肥胖，否则判为不肥胖；箭头指向曲线上 50% 的位置](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00270.webp)

这句话里藏着两个可以分开的部分：

- **模型给的是概率**：曲线在某个体重处的高度，是数据与拟合结果共同决定的；
- **50% 是决策规则**：它是人事先选的一个门槛，不是曲线自带的属性。

把门槛从 50% 挪到 30%，曲线一点没变，变的是"哪些样本被划进阳性"。所以看到"逻辑回归预测为阳性"时，要追问一句：概率是多少、阈值取在哪。阈值该怎么按错误代价来选，属于 4.2.2 的内容，本节只把这两层分开。

### 2.3 同一个模型可以吃连续变量和离散变量

和线性回归一样，逻辑回归的右边可以是简单模型，也可以逐步加变量 [【跳转到 04:30】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=270)：肥胖由体重预测；或由体重加基因型预测；或再加年龄；甚至再加星座。**体重、年龄是连续测量，基因型、星座是离散类别**，逻辑回归都能处理。

## 三、变量有没有用：不能靠比较两个模型，要逐个检验

线性回归里，比较简单模型与复杂模型的 $R^2$ 就能判断多测一个变量值不值。视频明确指出，逻辑回归**不能这么方便地比较**，原因稍后讲（见第四节：它没有残差，也算不出 $R^2$）[【跳转到 05:20】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=320)。

替代做法是：**逐个检验每个变量对预测的效应是否显著异于 0**。不显著，就说明这个变量没在帮忙，可以从研究里去掉，省时间省样本。

![逐个检验变量：肥胖由体重、基因型、年龄、星座共同预测，箭头分别指向每个变量，判断谁真的有用](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00320.webp)

视频用星座做反例：它的效应不显著，用讲者的原话说"完全没用"，于是可以从模型里删掉。这里执行检验的是 **Wald 检验**，视频把它留给另一支 StatQuest，本节只记住它的用途：**判断单个变量是否值得保留**。注意这和"模型整体预测得准不准"是两个问题——一个变量可以显著，但模型整体仍然很弱。

## 四、拟合准则换了：没有残差，就没有最小二乘

### 4.1 线性回归靠残差平方和

线性回归拟合直线的方式是最小二乘：对每个点量出它与直线的竖直距离（残差），把残差平方后全部加起来，选让这个和最小的那条线 [【跳转到 06:15】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=375)。同一批残差还被用来算 $R^2$、比较简单模型与复杂模型。

![最小二乘：每个点到直线的竖直距离是残差，选残差平方和最小的直线](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00375.webp)

### 4.2 逻辑回归没有"残差"这个概念

问题在于：逻辑回归的观测值只有 0 和 1，曲线给出的是一个概率。**"0.7 的概率"与"标签 1"之间该算多大的距离？** 没有一种像"竖直距离"那样自然、又被全体样本一致接受的定义。视频的说法很直接：逻辑回归没有同样的残差概念，所以不能用最小二乘，也算不出 $R^2$ [【跳转到 06:36】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=396)。

于是必须换一条准则。这条准则不是拍脑袋选的，它来自概率本身。

### 4.3 最大似然：让"观测到这批标签"的概率最大

视频给的替代方案是**最大似然** [【跳转到 07:01】](https://www.youtube.com/watch?v=yIYKR4sgzI8&t=421)。做法分四步：

1. **读曲线**：对一只肥胖的小鼠，按它的体重在曲线上读出高度，这个高度就是"模型认为它肥胖"的概率。似然把这个概率当作"观测到它肥胖"的可能性。
2. **取补**：对一只不肥胖的小鼠，同样在曲线上读出高度 $h$，但这次要的是"观测到它不肥胖"的可能性，也就是 $1-h$。
3. **连乘**：对所有小鼠都这样做，再把所有这些概率乘起来。乘积就是"在这条曲线下，观测到手里这整批标签"的似然。
4. **比大小**：换一条曲线（改变形状与位置），重新算一遍似然；再换、再算。最后选**似然最大**的那条曲线。

![最大似然的第一步：对一只不肥胖的小鼠，从曲线读出高度 h，再用 1-h 作为"观测到它不肥胖"的可能性](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00446.webp)

![换一条曲线就重算一次似然：灰色虚线是候选曲线，黑色虚线是当前曲线，逐条比较谁的似然更大](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00471.webp)

![最大似然：不用最小二乘，而是找让观测数据最可能出现的曲线](assets/逻辑回归：S%20形曲线给出类别概率，最大似然替代最小二乘/00421.webp)

这套流程和 1.2.5 的最大似然是同一个思想：**固定数据、转动模型参数，找让数据最可能出现的那个位置**。区别只在于那里的参数是分布的位置与宽度，这里的参数是曲线的形状与位置。

### 4.4 取对数：从连乘到负对数似然

视频停在"连乘、比大小"这一步，没有写公式。但连乘在实践中没法直接用：每个概率都小于 1，几百个样本相乘会迅速下溢到 0，计算机分不清 $10^{-400}$ 和 $10^{-401}$。标准做法是取对数——**乘积变求和，单调性不变，所以似然最大的曲线仍是取对数后似然最大的曲线**（这一步与 1.2.5 把似然变成对数似然是同一操作）。

把第 4.3 节四步写成式子。设第 $i$ 个样本的特征为 $\mathbf{x}_i$、真实标签为 $y_i \in \{0,1\}$，模型给出的肥胖概率为 $p_i = \sigma(\mathbf{w}^\top \mathbf{x}_i + b)$。单个样本"观测到它的真实标签"的概率可以统一写成一行：

$$
P(y_i \mid \mathbf{x}_i) = p_i^{\,y_i}\,(1-p_i)^{\,1-y_i}
$$

这个写法值得停一下：$y_i=1$ 时 $p_i$ 的一次方留下、$(1-p_i)$ 的零次方变成 1，得到 $p_i$；$y_i=0$ 时反过来，得到 $1-p_i$。**一个式子同时覆盖了 4.3 节的"读曲线"和"取补"两种操作**。

$n$ 个样本独立时，联合似然是各自概率的连乘，取对数后变成求和：

$$
\ell(\mathbf{w}, b) = \log \prod_{i=1}^{n} P(y_i \mid \mathbf{x}_i)
= \sum_{i=1}^{n} \Big[\, y_i \log p_i + (1-y_i)\log(1-p_i) \,\Big]
$$

这就是**对数似然**。训练要让它最大，而优化器习惯最小化，于是取负号、再除以样本数 $n$（除以常数不改变最优解的位置，只是让损失与样本量无关）：

$$
\mathrm{BCE} = -\frac{1}{n}\sum_{i=1}^{n} \Big[\, y_i \log p_i + (1-y_i)\log(1-p_i) \,\Big]
$$

这个量叫**二分类交叉熵**（binary cross-entropy），也叫**负对数似然**（negative log-likelihood）。两个名字说的是同一件事：前者从"两个分布的差距"看，后者从"最大化似然"看。

### 4.5 逐样本算一遍：交叉熵在数什么

先看单个样本的损失，记作 $L_i$：

$$
L_i = -\big[\, y_i \log p_i + (1-y_i)\log(1-p_i) \,\big]
$$

因为 $y_i$ 只能是 0 或 1，每一项其实只剩一半：

- **标签为 1**（这只小鼠确实肥胖）：$L_i = -\log p_i$。模型给的概率越高，损失越小。$p_i=0.9$ 时 $L_i = -\log 0.9 \approx 0.105$；$p_i=0.6$ 时 $\approx 0.511$；$p_i=0.5$ 时 $\approx 0.693$。
- **标签为 0**（不肥胖）：$L_i = -\log(1-p_i)$。这时被惩罚的是"给肥胖留的那份概率"。$p_i=0.1$ 时 $L_i = -\log 0.9 \approx 0.105$；$p_i=0.4$ 时 $\approx 0.511$；$p_i=0.5$ 时仍是 $\approx 0.693$。

把四个样本摆在一起，就能看出这个损失在奖励什么：

| 样本 | 标签 $y_i$ | 预测 $p_i$ | 损失 $L_i$ |
| --- | --- | --- | --- |
| A | 1 | 0.9 | 0.105 |
| B | 1 | 0.6 | 0.511 |
| C | 0 | 0.4 | 0.511 |
| D | 0 | 0.1 | 0.105 |

四个样本的平均损失是 $(0.105+0.511+0.511+0.105)/4 \approx 0.308$。注意两件事：

- **A 与 D、B 与 C 的损失相同**：损失只看"模型给真实标签留了多少概率"，不看这个标签是 0 还是 1。所以它衡量的是**置信度是否放对了地方**，而不是"预测成了哪一类"。
- **损失对"自信地错"的惩罚远重于对"自信地对"的奖励**：$p_i$ 从 0.9 掉到 0.6 只多了 0.4 的损失，但从 0.1 掉到 0.01（标签为 1 时）会从 2.303 涨到 4.605。$p_i \to 0$ 而标签为 1 时，$-\log p_i \to +\infty$——**模型越自信地错，罚得越狠**。这条性质来自 $\log$ 在 0 附近发散，也正是交叉熵比"数错几个"（0-1 损失）更适合做训练目标的原因：它有梯度，能告诉模型往哪个方向改。

这个式子和 1.2.6 的交叉熵定义是同一个东西。把真实标签看成一个退化的分布 $y = (y_i,\, 1-y_i)$（one-hot，概率全压在真实类上），模型分布看成 $p = (p_i,\, 1-p_i)$，按定义

$$
H(y, p) = -\sum_{j \in \{0,1\}} y_j \log p_j = -\big[\, y_i \log p_i + (1-y_i)\log(1-p_i) \,\big] = L_i
$$

两项完全对上。**"最小化交叉熵"与"最大化似然"不是两条准则，而是同一件事的两种说法**：前者说"让模型分布贴近数据分布"，后者说"让观测到的标签更可能出现"。1.2.6 讲的是这个量的信息论含义与下界，这里讲的是它怎么从伯努利似然长出来。

### 4.6 两个可以顺手验证的推论

**其一，损失对打分 $z$ 的梯度就是 $p_i - y_i$。** 对 $L_i = -[y_i\log p_i + (1-y_i)\log(1-p_i)]$ 用链式法则（见 1.3.2），先对 $p_i$ 求导得 $-(y_i/p_i) + (1-y_i)/(1-p_i)$，再乘 Sigmoid 的导数 $p_i(1-p_i)$，两项的分母正好被约掉：

$$
\frac{\partial L_i}{\partial z_i} = p_i - y_i
$$

形式极简：**梯度就是"预测概率减真实标签"**。标签为 1 而预测 0.6 时梯度是 $-0.4$，把 $z$ 往上推；预测已经 0.9 时只剩 $-0.1$，推力自动变小。这也解释了为什么逻辑回归配 Sigmoid 配交叉熵是一套：换掉其中任何一个，梯度都会多出 $p(1-p)$ 这类在两端趋近 0 的因子，训练会变慢。

**其二，损失可以直接用打分写，不必先算 $p$。** 把 $p_i = 1/(1+e^{-z_i})$ 代入，$\log p_i = -\log(1+e^{-z_i})$、$\log(1-p_i) = -z_i - \log(1+e^{-z_i})$，合并后

$$
L_i = \log(1 + e^{z_i}) - y_i z_i
$$

这个形式（$\log(1+e^{z})$ 常称 softplus）在 $z_i$ 很大或很小时都不会上溢或下溢，所以是数值实现里的常用写法。它同时说明：**损失只通过打分 $z$ 依赖参数**，特征怎么进模型、损失怎么算，是两件可以分开看的事。

> 本节 4.4–4.6 的公式与逐样本计算是视频没有展开的部分，按学习目标补齐；交叉熵的信息论含义与"为什么以熵为下限"见 1.2.6，多分类时 Softmax 与交叉熵的配合见 2.1.3。

## 五、把打分和概率接起来：S 形曲线就是 Sigmoid

视频展示了 S 形曲线的形状与读法，但没有写出它的公式。把上一节《几率与对数几率》的 logit 定义接过来，这一步只是代数。

设线性打分为 $z = \mathbf{w}^\top \mathbf{x} + b$，并令它等于对数几率：

$$
z = \log\left(\frac{p}{1-p}\right)
$$

两边取指数、整理（推导过程见上一篇第四节），得到

$$
p = \frac{1}{1 + e^{-z}}
$$

这条式子就是视频里那条 S 形曲线，名字叫 **Sigmoid**。它把三件事一次说清：

- **值域合法**：无论 $z$ 多大或多小，$p$ 永远落在 $(0,1)$，不会给出 $-0.3$ 或 $1.4$；
- **中点固定**：$z=0$ 时 $p=0.5$，正好是视频里"50% 概率"那个位置；$z$ 为正则 $p>0.5$，为负则 $p<0.5$；
- **两端饱和**：$z$ 很大时 $p$ 贴近 1，很小时贴近 0，但永远到不了端点，所以"100% 确定"只能无限逼近。

于是整条链路是：**特征 $\to$ 线性打分 $z$ $\to$ Sigmoid $\to$ 概率 $p$ $\to$ 阈值 $\to$ 类别**。训练时被调整的是 $\mathbf{w}$ 与 $b$，它们决定曲线的陡峭程度和左右位置；Sigmoid 本身不含可调参数，只负责翻译。

### 5.1 一个必须说清的推论：决策边界是线性的

因为 logit 是线性打分，$p=0.5$ 等价于 $z=0$，也就是 $\mathbf{w}^\top \mathbf{x} + b = 0$——这是特征空间里的一个线性边界（二维时是一条直线，高维时是一个超平面）。所以逻辑回归属于**线性分类器**：概率随特征是弯曲的，但"判为阳性/阴性"的分界是平的。这也解释了它的局限：如果两类样本的边界本身是弯的，逻辑回归要么欠拟合，要么得先手工构造非线性特征（例如平方项、交互项）。

## 六、边界与去处

- **多分类**：逻辑回归处理两类；多类时把 Sigmoid 换成 Softmax，见 2.1.3。
- **阈值与代价**：50% 只是默认门槛；按漏检与误报的代价选阈值、以及概率是否校准，属于 4.2.1 与 4.2.2。
- **Wald 检验**：视频只点名，不展开；单变量显著性与模型整体评价是两件事。
- **正则化**：逻辑回归同样可以加 L1/L2 惩罚，入口与线性回归一致，见 2.2.6。
- **损失与信息论**：交叉熵作为"编码长度"的含义、为什么以熵为下限，见 1.2.6；本节只负责它如何从分类似然长出来。
- **与线性回归的关系**：同一个线性打分，只是被解释成对数几率而不是条件均值；系数解释的假设不同，不能把逻辑回归系数直接读成"体重每增加一克，肥胖概率增加多少"。

## 小结

- **任务换了**：逻辑回归预测真/假，不预测连续值；纵轴只有两档，数据点落在两条水平线上。
- **拟合对象换了**：不是直线，而是一条被关在 0 到 1 之间的 S 形曲线，曲线高度读作概率。
- **概率与决策是两层**：模型给概率；"大于 50% 判为肥胖"是外加的阈值规则，改阈值不改曲线。
- **变量筛选方式换了**：不能像线性回归那样比较两个模型的 $R^2$，改为逐个检验变量效应是否显著异于 0（Wald 检验）；不显著就可以删。
- **拟合准则换了**：逻辑回归没有残差概念，不能用最小二乘、算不出 $R^2$；改用最大似然——把每个样本"观测到其真实标签"的概率连乘，选似然最大的曲线。
- **连乘变成可优化的损失**：单个样本的概率写作 $p^{y}(1-p)^{1-y}$，取对数、取负、平均，就得到二分类交叉熵 $\mathrm{BCE} = -\frac{1}{n}\sum [y\log p + (1-y)\log(1-p)]$；它与"最大化似然"是同一件事的两种说法。
- **交叉熵只看置信度放没放对**：标签为 1 时损失是 $-\log p$，标签为 0 时是 $-\log(1-p)$；$p=0.9$ 且猜对时约 0.105，$p=0.5$ 时约 0.693，越自信地错罚得越重。对打分的梯度就是 $p-y$。
- **曲线有公式**：Sigmoid $p = 1/(1+e^{-z})$ 是 logit 的反函数，把任意实数打分压进 $(0,1)$，$z=0$ 对应 $p=0.5$。
- **它是线性分类器**：$p=0.5$ 等价于 $\mathbf{w}^\top \mathbf{x} + b = 0$，决策边界是平的。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 逻辑回归 | 用线性打分加 S 形曲线输出类别概率的模型 |
| S 形曲线 / logistic 函数 | 值域为 $(0,1)$ 的单调曲线，把打分翻译成概率 |
| Sigmoid | $1/(1+e^{-z})$，logit 的反函数，逻辑回归用的就是它 |
| 阈值 | 把概率转成类别的门槛，默认 50%，是决策规则而非模型参数 |
| 最大似然 | 选让"观测到这批标签"的联合概率最大的参数；逻辑回归的拟合准则 |
| 残差 | 观测值与拟合值的差；逻辑回归里没有对应物，所以不能用最小二乘 |
| Wald 检验 | 检验单个变量的效应是否显著异于 0，用于判断变量是否保留 |
| 负对数似然 | 把似然连乘取对数再取负，便于数值优化；二分类时即交叉熵 |
| 二分类交叉熵（BCE） | $-\frac{1}{n}\sum[y\log p+(1-y)\log(1-p)]$，由伯努利似然取负对数得到 |
| 对数似然 | 各样本"观测到真实标签"概率的连乘取对数，变成求和；训练时让它最大 |
| 梯度 $p-y$ | 交叉熵对线性打分的导数，预测概率与标签的差，两端自动变小 |
