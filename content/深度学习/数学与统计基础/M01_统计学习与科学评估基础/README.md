# M01 统计学习与科学评估基础

编号：M01 · 类型：模型基础 · 目录规模：60 个小节（三级叶子节点，少于 100）。

**知识主线**：数据与概率 → 学习和优化 → 统计证据 → 泛化与可信评估。

**范围与边界**：提供模型和数据专题共同使用的数学、统计及实验设计基础；不展开纯数学课程。

**前置知识**：无外部硬性前置，起点由本地第一阶段建立。 其余所需基础在下方章节使用处以 `[复用]` 小节编入，不要求通读任何上游脉络。

**组织与素材策略**：以可独立解释的一条计算或推断链为单元。先满足基础，再读模型；一个张量/参数不是一个独立课程。

**本脉络的深度边界**：补齐了多层感知机这一桥梁；数学单元不要求完整大学课程，但必须支撑后续网络、概率目标与指标的阅读。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 博客已从 cairn 的 `统计学习与科学评估基础` 迁入对应小节；与其他脉络重复的博客已归入其主脉络，本脉络暂无独立博客的 TASK 小节保持 `[WAITING]`。

## 1 表示、概率与不确定性

<a id="m01-1-1"></a>

### 1.1 数值对象

- 1.1.1 向量、矩阵、张量与维度 <a id="m01-1-1-1"></a> [DONE]
  - 学习目标：读写向量、矩阵与张量的形状和索引，说明批量维度与特征维度的区别。
- 1.1.2 向量相似性：内积、夹角与距离 <a id="m01-1-1-2"></a> [DONE]
  - 学习目标：在同一向量例子中比较方向和距离。
- 1.1.3 特征分解与奇异值分解：谱结构与低秩近似 <a id="m01-1-1-3"></a> [DONE]
  - 学习目标：以小矩阵比较特征分解与 SVD 的适用对象，解释截断后的低秩近似；不展开数值求解器。
- 1.1.4 主成分分析（PCA）：中心化、投影与解释方差 <a id="m01-1-1-4"></a> [DONE]
  - 学习目标：从中心化数据矩阵走到主成分坐标，解释方差贡献与保留维度；分解基础引用前一单元。
- 1.1.5 数据预处理与特征缩放：缺失值、标准化与类别编码 <a id="m01-1-1-5"></a> [DONE]
  - 学习目标：说明缺失值处理、标准化与类别编码的适用条件；判断预处理应在训练/测试切分内完成；解释缩放对距离、正则化和系数解释的影响；识别预处理泄漏。

<a id="m01-1-2"></a>

### 1.2 概率语言

- 1.2.1 随机变量与概率分布：离散概率、连续密度与归一化 <a id="m01-1-2-1"></a> [DONE]
  - 学习目标：用离散和连续例子区分概率质量、密度与区间概率，检查分布归一化。
- 1.2.2 条件概率、联合分布与边缘化 <a id="m01-1-2-2"></a> [DONE]
  - 学习目标：用同一列联表或联合分布计算条件概率和边缘分布，解释独立性；贝叶斯参数推断留给后续单元。
- 1.2.3 贝叶斯推断：先验、似然与后验 <a id="m01-1-2-3"></a> [DONE]
  - 学习目标：从先验、似然到后验完成一个推断案例。
- 1.2.4 分布统计量：期望、方差与协方差 <a id="m01-1-2-4"></a> [DONE]
  - 学习目标：用同一分布解释位置、离散程度与相关变化。
- 1.2.5 似然、对数似然与最大似然估计 <a id="m01-1-2-5"></a> [DONE]
  - 学习目标：从数据概率走到可优化目标，不混同参数的概率。
- 1.2.6 信息量与散度：熵、交叉熵和 KL <a id="m01-1-2-6"></a> [DONE]
  - 学习目标：在两组离散概率上计算熵和交叉熵，并由差得到 KL，区分编码不确定性和分布失配；不把 KL 当对称距离。

<a id="m01-1-3"></a>

### 1.3 微积分与网络计算基础

- 1.3.1 导数、偏导与梯度：局部变化和最陡上升 <a id="m01-1-3-1"></a> [DONE]
  - 学习目标：用一个标量函数和二维损失面计算变化率，解释参数梯度；不要求完整高等数学课程。
- 1.3.2 链式法则与 Jacobian：复合函数和维度传递 <a id="m01-1-3-2"></a> [DONE]
  - 学习目标：从向量输入到标量损失追踪维度及局部导数，为反向传播和坐标力计算建立基础。
- 1.3.3 积分与期望：密度累积、数值平均和蒙特卡洛估计 <a id="m01-1-3-3"></a> [DONE]
  - 学习目标：区分单点密度、区间概率和样本平均，用一个期望估计解释数值采样与误差。

## 2 学习任务、神经网络与参数优化

<a id="m01-2-1"></a>

### 2.1 学习任务、网络与观测模型

- 2.1.1 学习任务：回归、分类与无监督学习 <a id="m01-2-1-1"></a> [DONE]
  - 学习目标：只建立任务地图和输出对象，不同时讲完各类算法。
- 2.1.2 多层感知机（MLP）：线性层、激活函数与任务头 <a id="m01-2-1-2"></a> [DONE]
  - 学习目标：补齐神经网络最小基础，解释非线性与任务头如何组合。
- 2.1.3 观测模型与损失函数：回归误差和分类交叉熵 <a id="m01-2-1-3"></a> [DONE]
  - 学习目标：比较回归损失和分类交叉熵的预测对象。
- 2.1.4 计数似然与过度离散：泊松、负二项与对数连接 <a id="m01-2-1-4"></a> [DONE]
  - 学习目标：说明泊松、负二项与对数连接的假设；判断过度离散的来源；把似然选择与下游模型联系起来；零膨胀的实现留给 B04/P08。

<a id="m01-2-2"></a>

### 2.2 优化与容量

- 2.2.1 网络梯度计算：链式法则与反向传播 <a id="m01-2-2-1"></a> [DONE]
  - 学习目标：手算一个小网络的梯度传播。
- 2.2.2 梯度下降与随机优化：小批量、学习率与收敛 <a id="m01-2-2-2"></a> [DONE]
  - 学习目标：在同一损失面比较全批量与小批量更新，解释步长和梯度噪声；不重复求梯度过程。
- 2.2.3 动量与 Adam：梯度累积、自适应尺度与优化轨迹 <a id="m01-2-2-3"></a> [DONE]
  - 学习目标：比较动量、一阶矩与二阶矩对更新的作用，说明收敛曲线与泛化不是同一结论。
- 2.2.4 偏差、方差、过拟合与欠拟合 <a id="m01-2-2-4"></a> [DONE]
  - 学习目标：用偏差—方差分解解释欠拟合与过拟合，说明容量、数据量与正则化的关系。
- 2.2.5 交叉验证与验证集：k 折、分层、嵌套交叉验证与超参数选择 <a id="m01-2-2-5"></a> [DONE]
  - 学习目标：说明训练、验证与测试的分工，用嵌套交叉验证避免选择偏差。
- 2.2.6 模型正则化：L1、L2 与早停 <a id="m01-2-2-6"></a> [DONE]
  - 学习目标：用 L1/L2 或早停解释目标与泛化的关系。
- 2.2.7 训练诊断：损失曲线、梯度消失/爆炸与初始化 <a id="m01-2-2-7"></a> [DONE]
  - 学习目标：从损失曲线和梯度统计判断训练失败，说明初始化与归一化的作用。

<a id="m01-2-3"></a>

### 2.3 基线与适配

- 2.3.1 线性回归：最小二乘、系数与连续值预测 <a id="m01-2-3-1"></a> [DONE]
  - 学习目标：从设计矩阵和残差解释最小二乘，辨认系数解释依赖的假设及正则化入口。
- 2.3.2 逻辑回归：对数几率、Sigmoid 与分类似然 <a id="m01-2-3-2"></a> [DONE]
  - 学习目标：从线性打分走到类别概率与交叉熵，区分概率估计和阈值决策。
- 2.3.3 支持向量机（SVM）：最大间隔与核方法 <a id="m01-2-3-3"></a> [DONE]
  - 学习目标：解释间隔与核的作用。
- 2.3.4 决策树：递归划分、分裂准则与剪枝 <a id="m01-2-3-4"></a> [DONE]
  - 学习目标：用一棵小树解释特征切分与叶节点预测，辨认深度带来的拟合风险。
- 2.3.5 随机森林：Bootstrap、特征随机化与袋外评价 <a id="m01-2-3-5"></a> [DONE]
  - 学习目标：从多棵差异化树解释方差降低与袋外估计，不重复单树构建细节。
- 2.3.6 梯度提升树：逐轮加法、残差拟合与正则化 <a id="m01-2-3-6"></a> [DONE]
  - 学习目标：追踪一个加法模型的更新，比较 Boosting 与随机森林的组合机制及过拟合控制。
- 2.3.7 预训练、迁移学习、微调与冻结表征 <a id="m01-2-3-7"></a> [DONE]
  - 学习目标：区分预训练、微调与冻结表征，说明目标分布差异下的迁移收益与风险。
- 2.3.8 最近邻与相似性基线：kNN、相似度检索与适用条件 <a id="m01-2-3-8"></a> [DONE]
  - 学习目标：用 kNN 与相似度检索建立非参数基线，说明维度灾难和距离选择的影响。
- 2.3.9 聚类方法与聚类评价：k-means、层次聚类与轮廓系数/ARI <a id="m01-2-3-9"></a> [DONE]
  - 学习目标：比较 k-means、层次聚类与密度聚类的假设；说明距离、链接方式与簇数选择；用轮廓系数、ARI 与稳定性评价聚类；判断聚类结果是否支持生物学分组。

<a id="m01-2-4"></a>

### 2.4 顺序决策与实验优化

- 2.4.1 贝叶斯优化：代理模型、后验不确定性与采集函数 <a id="m01-2-4-1"></a> [DONE]
  - 学习目标：从少量观测选择下一次实验，比较探索和利用及噪声假设，不把预测均值最高等同最优实验。
- 2.4.2 强化学习：状态、动作、奖励与策略更新 <a id="m01-2-4-2"></a> [DONE]
  - 学习目标：用一段序列构建过程定义决策目标，区分即时奖励、累计回报及离线监督，不在本单元推导全部算法。

## 3 统计推断与实验设计

<a id="m01-3-1"></a>

### 3.1 比较与检验

- 3.1.1 效应量、置信区间与估计不确定性 <a id="m01-3-1-1"></a> [DONE]
  - 学习目标：在一个组间比较中解释大小与不确定性。
- 3.1.2 统计功效、样本量与未检出效应 <a id="m01-3-1-2"></a> [DONE]
  - 学习目标：区分未检出与不存在效应。
- 3.1.3 假设检验：零假设、p 值与显著性 <a id="m01-3-1-3"></a> [DONE]
  - 学习目标：用一个零假设说明判定和常见误读。
- 3.1.4 多重检验校正与假发现率（FDR） <a id="m01-3-1-4"></a> [DONE]
  - 学习目标：用许多基因同时检验的案例说明校正。
- 3.1.5 重采样推断：置换检验与自助法 <a id="m01-3-1-5"></a> [DONE]
  - 学习目标：用置换和自助法构造零分布与置信区间，说明其假设和适用样本量。

<a id="m01-3-2"></a>

### 3.2 合理的实验单位

- 3.2.1 重复测量、分层结构与伪重复 <a id="m01-3-2-1"></a> [DONE]
  - 学习目标：识别重复测量与分层结构，说明伪重复如何低估不确定性。
- 3.2.2 分层与混合效应模型：随机截距、组内相关与不确定性修正 <a id="m01-3-2-2"></a> [DONE]
  - 学习目标：说明分层结构为何需要随机效应；区分固定效应与随机效应；解释组内相关对标准误的影响；判断混合效应模型与聚合分析的适用条件。
- 3.2.3 观察研究中的混杂、选择偏差与关联解释 <a id="m01-3-2-3"></a> [DONE]
  - 学习目标：画出简单因果图，说明共同原因和选择机制产生的偏差；不把预测相关解释为干预效果。
- 3.2.4 随机化实验与因果效应：干预、对照与识别假设 <a id="m01-3-2-4"></a> [DONE]
  - 学习目标：用处理组和对照组定义目标效应，解释随机分配解决的混杂及依然存在的依从性和外推限制。
- 3.2.5 因子设计与交互效应：多因素组合、区组与部分因子设计 <a id="m01-3-2-5"></a> [DONE]
  - 学习目标：说明主效应、交互效应与区组的作用；比较全因子、部分因子与响应面设计；判断样本量与检验功效；把组合扰动和剂量—反应实验映射到设计矩阵。

## 4 预测指标、不确定性与决策

<a id="m01-4-1"></a>

### 4.1 任务匹配的指标

- 4.1.1 混淆矩阵、精确率、召回率与 MCC <a id="m01-4-1-1"></a> [DONE]
  - 学习目标：在同一分类结果上理解阈值指标。
- 4.1.2 ROC、PR 曲线与类别不平衡 <a id="m01-4-1-2"></a> [DONE]
  - 学习目标：解释阈值扫描与 AUROC/AUPRC 的差异。
- 4.1.3 多类指标聚合：宏平均、微平均与加权平均 <a id="m01-4-1-3"></a> [DONE]
  - 学习目标：说明宏平均、微平均与加权平均的差别；判断类别不平衡时哪种聚合更合适；解释聚合指标与单类指标的关系；避免用单一聚合分数掩盖少数类失败。
- 4.1.4 回归误差指标：MAE、RMSE 与残差 <a id="m01-4-1-4"></a> [DONE]
  - 学习目标：在同一回归例子中比较指标对异常值的敏感性。
- 4.1.5 预测相关性、排序指标与数值准确性 <a id="m01-4-1-5"></a> [DONE]
  - 学习目标：说明预测相关性、排序指标与数值准确性的适用场景；判断排序好但数值偏差大的情况；避免把相关系数当成校准或决策质量。

<a id="m01-4-2"></a>

### 4.2 概率与决策

- 4.2.1 概率校准与可靠性曲线 <a id="m01-4-2-1"></a> [DONE]
  - 学习目标：读懂可靠性曲线与置信分数。
- 4.2.2 分类决策：阈值、类别权重与错误代价 <a id="m01-4-2-2"></a> [DONE]
  - 学习目标：用错误代价与不平衡选择阈值，不重复曲线定义。
- 4.2.3 预测区间与均值置信区间 <a id="m01-4-2-3"></a> [DONE]
  - 学习目标：区分均值置信区间与个体预测区间。
- 4.2.4 模型适用域：分布外输入与拒绝预测 <a id="m01-4-2-4"></a> [DONE]
  - 学习目标：以新分子或新细胞背景解释不应强行给答案的场景。
