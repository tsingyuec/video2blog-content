编号：M04 · 类型：模型基础 · 目录规模：52 个小节（三级叶子节点，少于 100）。

**知识主线**：概率分布 → 潜变量与去噪 → 扩散和流 → 条件采样与生成评价。

**范围与边界**：统一讲机制，再由专题说明生成对象是序列、潜表示、坐标还是构象；不把所有生成方法都叫扩散。

- 2.1.9 VAE 变分目标：近似后验、ELBO 与 KL 正则项 <a id="m04-2-1-9"></a> [DONE]
