# Grammar VAE：连续潜变量要生成离散分子，合法性得写进解码器

> 视频来源：[Grammar Variational Autoencoder](https://www.youtube.com/watch?v=ar4Fm1V65Fw)（YouTube · Microsoft Research 研讨会 · 讲者 Brooks Paige，约 21 分钟）
> 导读：一支 2017 年前后的报告录像，讲的是 Grammar VAE 这篇论文。它回答的问题很具体：潜变量是连续的高斯向量，输出却是离散的分子，解码器凭什么保证吐出来的字符串是合法分子？本文只讲「连续潜变量 → 离散对象」这一步怎么落地、合法性约束放在哪里，ELBO 与重参数化见 2.1.9、2.1.10，潜变量的可辨识性见 2.2.2。

## 本讲要解决的核心问题（SCQA）

**背景**：变分自编码器（VAE）的潜空间是连续的：编码器输出均值 $\mu$ 和协方差，从高斯里采一个实值向量 $z$，解码器把它还原成数据。连续潜空间的好处是能插值、能求梯度、能在上面做优化。

**冲突**：分子不是连续量，而是一串离散符号。把分子写成 SMILES 字符串之后，它变成了一门**形式语言**：一个字符写错，整串就不再属于这门语言，连解析都解析不了。用逐字符解码的 VAE 去生成 SMILES，潜空间里大片区域解码出来是无效串——讲者给出的数字是：字符 VAE 采出来的分子只有 17% 能被解析。

**疑问**：既然 SMILES 有一份现成的、固定的上下文无关文法（context-free grammar），为什么还要让解码器从零去猜哪个字符合法？能不能把「合法性」从**学出来的东西**变成**构造出来的东西**？

**回答（中心思想）**：能，而且改动只有一处——把解码的单位从「字符」换成「文法的产生式规则」。编码时先把分子解析成语法树、再先序遍历成规则序列；解码时用一个栈模拟下推自动机，每一步对网络输出的概率向量做**掩码**，只允许当前非终结符的合法展开。这样语法合法性由解码过程本身保证，与潜变量学到什么无关。代价是：文法只管语法，管不了语义（价键是否允许、环闭合数字是否成对），所以分子上的有效率只从 17% 提到 31%，而表达式上能从 86% 提到 99%。

## 一、先把问题摆清楚：从性质反推分子，缺的是一条可导的路

### 1.1 正问题是好办的，反问题不是

讲者一上来先划清任务[【跳转到 00:35】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=35)：给定一个分子，现成的化学信息学软件可以算出它的性质（溶解度、logP 之类），这是**正问题**，成熟且可靠。

难的是**反问题**：我想要一个具备某些性质的分子，该拿哪个分子？[【跳转到 01:00】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=60)

现实中的做法只有两种，都很笨：

- 拿几十万个类药分子的大数据库，挨个算一遍性质，挑出符合的；
- 从一个看着不错的分子出发，人工提出「这里改一下、那里换一个基团」的局部修改。

两种做法都缺同一样东西：**梯度**。分子是离散对象，你没法把「性质」对「分子」的导数穿过化学信息学软件反传回来，然后说「这个原子该往这个方向挪」[【跳转到 01:25】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=85)。

### 1.2 SMILES：分子居然有「源代码」

讲者说自己不是化学出身，所以第一次看到下面这张图时很意外[【跳转到 01:50】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=110)：左边是分子结构式，右边是一串字符，两者一一对应。这串字符就是 **SMILES**（Simplified Molecular-Input Line-Entry System），讲者的说法是「它基本上就是分子的源代码」。

![分子与它的 SMILES 串一一对应：左边是结构式，右边是同一分子的文本写法](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00110.webp)

这件事在很多离散领域都成立：结构很复杂，但人们早就在用一套文本表示。于是问题被翻译成了：**能不能用文本生成模型来生成分子？**

### 1.3 借用文本 VAE：连续潜空间 + 逐字符解码

文本生成模型里最现成的模板，是 Bowman 等人那篇《Generating Sentences from a Continuous Space》里的 VAE[【跳转到 02:25】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=145)。它的结构就是最朴素的编码—解码：

- 编码器 $q(z \mid \text{text})$ 读入字符序列，输出 $\mu$ 和 $\Sigma$，定义一个实值向量上的高斯分布；
- 从里面采一个 $z$；
- 解码器 $p(\text{text} \mid z)$ 是一个循环神经网络，每一步输出**下一个字符**的概率，逐位采样出整串文本。

![文本 VAE 的结构：左边编码器把序列压成 μ、Σ，中间是连续潜空间，右边解码器逐位吐出字符](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00145.webp)

这套东西在自然语言上有一个漂亮的性质：在潜空间里做线性插值，解码出来的中间句子是「像话」的。讲者举的例子是从「I want to talk to you」插值到「she didn't want to be with him」，中间会经过「I want to be with you」「I do n't want to be with you」这类句子[【跳转到 03:40】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=220)。这说明离散文本空间里存在某种局部结构，被连续潜空间编码住了。

Gómez-Bombarelli 等人把这套结构直接搬到分子上：文本换成 SMILES 串，学 $q(z \mid \text{molecule})$ 和 $p(\text{molecule} \mid z)$，然后在潜空间上再挂一个**性质预测器**[【跳转到 04:04】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=244)。

![在潜空间上挂一个预测器：编码器、解码器之外，从 z 分出一支预测分子性质，于是性质对 z 可导](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00244.webp)

这一步是整个思路的关键[【跳转到 04:41】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=281)：直接拿分子去算性质很贵，而且不可导；但如果先在潜空间上拟合一个预测器，性质就变成了 $z$ 的光滑函数，可以反传梯度、可以做贝叶斯优化。讲者特别强调，这个连续嵌入是**无监督**学出来的——它只看 SMILES 串，跟你要优化哪个性质无关。

### 1.4 但 SMILES 不是自然语言

讲者在这里给「文本」加了引号[【跳转到 05:31】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=331)，因为 SMILES 和英文的差别是本质性的。

![SMILES 不是自然语言：左边是「严格到改一个字符就废」的挑战，右边是「有现成文法、解析唯一」的机会](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00336.webp)

**挑战**：英文里句子长一点、错一点，读者还能猜出意思；SMILES 改一个字符，整串就根本解析不了。单个字符的错误就足以让这个串**不属于这门形式语言**。

**机会**：正因为它是形式语言，所以它有确定的语法：

- SMILES 的语法是**上下文无关**的（context-free），有现成的上下文无关文法；
- 这份文法是**已知且固定**的，不需要从数据里学；
- 而且**解析是唯一的**——给定一个串，动态规划算法会还你唯一一棵语法树，没有语法歧义。

对生成模型来说，最后一条尤其值钱：既然一个合法串唯一对应一棵语法树，那么「生成一个串」和「生成一棵语法树」就是同一件事，只是后者的每一步都天然受文法约束。

## 二、换一种解码单位：从字符换成产生式规则

### 2.1 文法就是一张产生式规则表

上下文无关文法由一组**产生式规则**（production rule）组成，每条规则的形式是「一个非终结符 → 一串终结符或非终结符」。讲者用苯环举例[【跳转到 06:53】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=413)：

```
smiles         -> chain
chain          -> chain, branched_atom
chain          -> branched_atom
branched_atom  -> atom, ringbond
branched_atom  -> atom
atom           -> aromatic_organic
atom           -> aliphatic_organic
ringbond       -> digit
aromatic_organic -> 'c'
aliphatic_organic -> 'C'
aliphatic_organic -> 'N'
digit          -> '1'
digit          -> '2'
```

生成的过程是自顶向下的：从起始符号 `smiles` 出发，不断把左边的非终结符替换成右边的串，直到整棵树的所有叶子都是终结符。**凡是能这样造出来的串，一定属于这门语言**——所有语法约束都已经写在这张表里了[【跳转到 07:18】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=438)。

![文法规则表与苯环的语法树：从 smiles 出发逐层展开，叶子是 c、1 这样的终结符，合起来就是 c1ccccc1](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00463.webp)

真实的 SMILES 文法比这大得多。讲者后来贴出了 openSMILES 的完整规则[【跳转到 13:58】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=838)：`bracket_atom`、`chiral`、`hcount`、`charge`、`bond`、`branch` 一层套一层，文法里一共有 22 个非终结符。

![openSMILES 的完整文法片段：atom、bracket_atom、chiral、hcount、charge、bond、branch 逐层展开](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00838.webp)

### 2.2 编码：把分子变成「用了哪些规则」的序列

有了文法，编码就变成三步[【跳转到 07:43】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=463)：

1. 用解析器把 SMILES 串解析成语法树（苯的 `c1ccccc1` 对应一棵确定的树）；
2. 对这棵树做**先序遍历**：从根往下，遇到分支先走最左边，把沿途用到的产生式规则依次记下来；
3. 得到一个**产生式规则的序列**——注意，不再是字符序列。

因为文法里的产生式是有限集合，这个序列可以直接 one-hot 编码，然后喂进**跟之前一模一样的神经网络**——讲者的说法是，除了输入表示换了，模型本身一个字都没改[【跳转到 08:08】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=488)。讲者的原话是：之前分子的表示是 SMILES 字符的 one-hot，这里最大的改动，是换成语法树里用到的产生式的 one-hot。

![新的序列：每一行是一条产生式规则的 one-hot 向量，整串喂进编码器得到连续潜空间](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00501.webp)

这就是「连续潜变量解码成离散对象」的第一半答案：**离散对象先被结构化成一棵语法树，再被线性化成一个符号序列**。潜变量仍然是一个连续高斯向量，只是它现在编码的是「这棵树长什么样」，而不是「这串字符长什么样」。

### 2.3 为什么这一步值得做

对比一下两种表示就清楚了：

- **字符序列**：相邻两个字符之间没有必然的语法关系，模型必须自己学会「`(` 后面不能跟 `)`」这类规则，而且学不全；
- **规则序列**：每一步「下一条规则该选什么」由当前的非终结符唯一决定候选集，非法选项根本不在候选里。

换句话说，语法约束从「需要从数据里学到的统计规律」变成了「解码过程的结构性事实」。这也是后面所有收益的来源。

## 三、解码器怎么做：一次前向 + 一个栈 + 一个掩码

这是全篇最核心的机制，讲者分了三页幻灯片讲[【跳转到 08:56】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=536)。

### 3.1 解码网络只跑一次

给定一个 $z$，把它确定性地过一遍解码网络，得到**一整串向量**。这些向量可以解释成未归一化的对数概率（logits），第 $t$ 个向量对应「第 $t$ 步该选哪条产生式规则」。

注意这里和逐字符自回归解码的差别：网络不是「生成一个符号、把它喂回去、再生成下一个」，而是**一次前向就给出整条规则序列的分数**。之所以能这样，是因为规则序列的长度和位置在解码开始时并不确定——真正决定「下一步该展开谁」的不是上一步输出了什么字符，而是**栈的状态**。所以网络只负责给分，结构由外部过程维护。

### 3.2 栈：把「现在该展开哪个非终结符」变成状态

解码过程模拟的是一个**非确定性下推自动机**（nondeterministic pushdown automaton）——讲者说，熟悉上下文无关文法和下推自动机关系的人会觉得这非常眼熟[【跳转到 08:21】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=501)。

具体算法：

1. 初始化一个栈，压入起始符号 `smiles`；
2. 每次迭代，从栈顶弹出一个非终结符；
3. 取出网络在这一步给出的未归一化对数概率向量；
4. **做掩码**，只保留这个非终结符的合法产生式；
5. 按掩码后的分布采样一条产生式；
6. 把它右端的非终结符压回栈顶；
7. 重复，直到栈空。

![采样语法树的第一步：栈里只有起始符号 smiles，右侧是这一步的概率向量](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00571.webp)

![继续这个过程直到栈空：t=1 时栈顶是 chain，概率向量只在该非终结符的合法展开上有值](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00621.webp)

### 3.3 掩码：把非法选项的概率质量清零

掩码这一步是合法性约束的落点。设文法共有 $K$ 条产生式，网络在第 $t$ 步给出 logits $f_{t1}, \dots, f_{tK}$，当前栈顶的非终结符是 $\alpha$。定义掩码

$$
m_{\alpha,k} =
\begin{cases}
1, & \text{第 } k \text{ 条产生式的左端是 } \alpha \\
0, & \text{否则}
\end{cases}
$$

采样分布就是**掩码后的 softmax**：

$$
p(x_t = k \mid \alpha, z) = \frac{m_{\alpha,k} \exp(f_{tk})}{\sum_{j=1}^{K} m_{\alpha,j} \exp(f_{tj})}
$$

![掩码后的 softmax：分母只在当前非终结符的合法产生式上求和，非法项的概率严格为 0](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00596.webp)

这个式子的含义值得逐项说清：

- 分子里的求和只在 $m_{\alpha,j} = 1$ 的项上进行，非法产生式**连分母都进不去**，因此概率严格等于 0，不是「很小」；
- 网络输出的 logits 仍然可以是任意实数——模型不需要学会「非法项要给很小的分」，它只需要在合法项之间排好序；
- 于是「语法合法性」这件事从**学习的责任**变成了**构造的责任**：即使网络训练得很差，采样出来的规则序列仍然对应一棵合法的语法树。

讲者的原话是：我们不想提议任何非法的东西[【跳转到 09:56】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=596)。

### 3.4 从规则序列回到分子：确定性映射

栈空之后，我们手上有两样东西[【跳转到 10:21】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=621)：

- 生成的**终结符序列**，拼起来就是 SMILES 串；
- 一路用到的**产生式规则序列**，就是这棵语法树的先序线性化。

关键在于：从规则序列到分子是**确定性映射**——同一棵语法树只会拼出同一个串，没有歧义[【跳转到 10:46】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=646)。所以「采样规则序列」和「采样分子」是等价的，只是前者每走一步都被文法夹住了。

讲者顺带点了一句理论联系：这其实是把文法当成一个**概率上下文无关文法**（PCFG）来用——固定文法定义产生式规则，另有一个过程（这里是神经网络）定义每一步分配给各条产生式的概率。

## 四、合法性约束其实有三层，文法只管住第一层

这是整支报告最容易被忽略、也最重要的一段：讲者在结论部分专门讲了「文法管不了的东西」。

### 4.1 第一层：语法合法性——由构造保证

只要解码过程严格按栈 + 掩码走，产出的串一定属于这门语言。这一层是**零成本**的：不需要额外的损失项，不需要后处理过滤，也不需要重采样。

### 4.2 第二层：语义合法性——文法里没有

讲者举了一个具体的反例[【跳转到 17:50】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=1070)：SMILES 里环闭合用的数字必须**成对出现**——每个数字在同一个分子里必须出现偶数次，才能配成一对括号。这个约束**不在文法里**，它是语义约束。

![Challenges：语法约束由文法处理，但语义约束怎么办？例子 c12(cccccc1)ccccc2 语法上能解析，化学上却不成立](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/01045.webp)

幻灯片上的例子 `c12(cccccc1)ccccc2` 很能说明问题：它完全符合 openSMILES 文法，能解析出一棵语法树，但两个环共用一条键的方式在化学上不成立。同样的道理也适用于「哪些键是允许的」这类化学价键规则——它们都不在文法里[【跳转到 16:28】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=988)。

### 4.3 第三层：任务合法性——连语义层都管不了

讲者把话题推到别的领域[【跳转到 17:25】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=1045)：如果拿这套方法做**程序合成**，那么「某个变量此刻是否在作用域内」这类约束，文法同样管不了。而且它未必是编译错误——取决于语言，它可能是运行时错误，你在静态检查阶段根本发现不了。

三层约束的对照可以整理成一张表：

| 约束层次 | 例子 | 由谁保证 | Grammar VAE 是否覆盖 |
| :--- | :--- | :--- | :--- |
| 语法 | 括号是否配对、终结符是否合法 | 文法 + 掩码 | 完全覆盖（构造保证） |
| 语义 | 环闭合数字成对、价键是否允许 | 需要额外的化学规则 | 不覆盖 |
| 任务 | 变量作用域、运行时不变量 | 需要领域专用的检查器 | 不覆盖 |

### 4.4 有效性数字：语法层解决后还剩多少

讲者给出的对照表[【跳转到 16:03】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=963)非常直白：

| 任务 | 方法 | 有效比例 | 平均得分 |
| :--- | :--- | :--- | :--- |
| 表达式 | Grammar VAE | $0.99 \pm 0.01$ | $3.47 \pm 0.24$ |
| 表达式 | 字符 VAE | $0.86 \pm 0.06$ | $4.75 \pm 0.25$ |
| 分子 | Grammar VAE | $0.31 \pm 0.07$ | $-9.57 \pm 1.77$ |
| 分子 | 字符 VAE | $0.17 \pm 0.05$ | $-54.66 \pm 2.66$ |

![与字符 VAE 的对照：上半部分是采样有效率，下半部分是潜空间对性质预测的适用性（对数似然与 RMSE）](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00963.webp)

读这张表要注意三件事：

- **表达式上几乎是满分**（0.99），因为算术表达式的合法性**全部**由文法决定，没有额外的语义层；
- **分子上只有 0.31**，讲者的解释就是第 4.2 节说的：分子除了语法约束还有语义约束，那些不在文法里；
- 但相对字符 VAE 的 0.17，仍然是**翻倍**的提升——讲者的原话是「说真的这是巨大的改进」。

这也顺带回答了一个常见误解：把语法约束塞进解码器，不等于「生成的东西一定可用」。它只保证**能解析**，不保证**化学上成立**。

## 五、连续潜变量 + 离散解码，会带来什么

### 5.1 合法性是解码器给的，不是潜空间学到的

这是这套方法最需要说清的一点：Grammar VAE 的有效率提升，**不来自更好的潜空间**，而来自解码路径的受限。把同一个学到的 $z$ 喂给字符解码器，出来的串可能无效；喂给语法树解码器，出来的树一定合法。

对使用者的含义是：**不要用「采样有效率」去反推「潜空间学得好」**。有效率衡量的是解码器的约束强度，潜空间的质量要看另外的指标。

### 5.2 潜空间质量：插值、贝叶斯优化、预测似然

讲者给了三类证据说明潜空间本身也没坏。

**插值**：在两个方程之间线性插值，Grammar VAE 给出的每一行都是合法方程；字符 VAE 的潜空间里有位置根本不对应能解析的东西，那些用红色标了出来[【跳转到 12:46】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=766)。

![方程之间的插值对照：右列 Grammar VAE 每一行都合法，左列字符 VAE 里红色的行解析不了](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00741.webp)

**分子潜空间的可视化**：从某个分子出发做局部修改，潜空间里邻近的位置解码出来是化学上合理的相似分子——讲者说这「可能更多是一张好看的图」，但确实和第一页那些有化学动机的修改对得上[【跳转到 14:29】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=869)。

![分子潜空间的网格可视化：每一格是一个采样点解码出来的分子，相邻格子结构相近](assets/Grammar%20VAE：连续潜变量解码成离散分子时，合法性要写进解码器/00869.webp)

**贝叶斯优化**：目标性质是 logP（分配系数的对数，判断「像不像药」的常用指标），外加合成难度和分子大小的惩罚项。在潜空间上拟合稀疏 GP 做代理模型，Grammar VAE 找到的分子得分更高[【跳转到 15:08】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=908)。

**预测适用性**：看稀疏 GP 拟合性质预测得好不好，两个指标是对数似然和均方误差，Grammar VAE 在两个任务上都更好[【跳转到 16:53】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=1013)。

### 5.3 那 KL 项塌缩呢

提问环节有人直接问了这个问题[【跳转到 19:55】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=1195)：VAE 训练里常见 KL 项趋于零、编码器完全忽略潜变量，你们遇到过吗？——毕竟在你们这里应该不会，因为你能插值。

讲者的回答很实在：**没有遇到**。他们沿用了之前那篇药物发现论文的网络结构——编码器是 1D 卷积，解码器是 RNN——效果挺好[【跳转到 20:20】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=1220)。

这段对话值得记下来，因为它说明了「连续潜变量 + 离散解码」的一个隐含风险：**如果解码器足够强，它完全可以不看 $z$、直接从文法里采样出合法串**。这时重建损失很小、KL 项被压到零，潜空间就退化成装饰品。Grammar VAE 在这组实验里没碰到，但这不是「结构上不可能发生」，而是「这个架构 + 这份数据下没发生」。

### 5.4 无效样本的概率质量去哪了

一个容易被忽略的推论：掩码不是把非法串的概率「学小」，而是把那些概率质量**重新分配到合法项上**。所以 Grammar VAE 的采样分布永远落在语言内部，它没有「学会避开非法串」，它只是**从来没机会**产生非法串。

这也解释了为什么语义层的错误反而更隐蔽：既然语法层已经滴水不漏，剩下的 69% 无效分子全都是**语法合法但化学不成立**的样本，靠加大文法覆盖不到。

## 六、这套做法的适用边界

### 6.1 换个文法就能换个领域

讲者用**符号回归**做了一组对照实验[【跳转到 11:26】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=686)：给一堆 $(x, y)$ 数据点，能不能反推出这个函数的表达式？表达式也是文本，比如 $3x \cdot x \cdot x^{3/2}$。

他们定义了一个简单的算术函数域（单变量、几种运算、几种原始函数、几个常数、括号分组），用文法生成 10 万个合成方程来训练，然后问：能不能从数据里学出这个函数的符号形式？注意训练时**并不知道**目标函数是什么，所以这个流程对任何函数都能用[【跳转到 11:51】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=711)。

下游任务是贝叶斯优化：在潜空间上拟合稀疏 GP，预测「这个表达式对给定点的均方误差」，然后提议下一个该试的表达式[【跳转到 13:25】](https://www.youtube.com/watch?v=ar4Fm1V65Fw&t=805)。在这个任务上，Grammar VAE 比字符 VAE 更好也更快。

这说明方法本身是**领域无关**的：只要有形式文法，就能把解码换成语法树。分子、表达式、程序，都是同一个模板。

### 6.2 边界：文法覆盖不到的地方就是天花板

把前面几节收拢起来，这套方法的适用条件可以写成三条：

1. **目标对象得有一份确定的、上下文无关的文法**。SMILES 有，算术表达式有；自然语言没有（英文语法不是上下文无关的），所以这套方法搬不到自然语言上。
2. **主要错误模式得是语法错误**。表达式任务符合这一点（0.99），分子任务不符合（0.31）——分子的主要失败模式是语义。
3. **语义约束得有地方放**。要么另加检查器，要么把语义也编进文法（讲者没做，但这是后来一系列工作的方向），要么接受这部分无效样本。

### 6.3 对「连续潜变量解码成离散对象」的一般启示

把 Grammar VAE 抽象一层，它给的是一个可复用的套路：

- **离散对象 → 结构化表示**（语法树）：把「生成一个合法对象」变成「生成一棵合法的树」；
- **结构化表示 → 线性序列**（先序遍历）：让循环神经网络能处理；
- **解码时用外部状态机约束采样**（栈 + 掩码）：把合法性从学习问题变成构造问题；
- **剩下的约束分层处理**：语法层用文法，语义层用领域规则，任务层用检查器。

讲者在结尾也把这套做法往别的领域推了一步：程序合成、符号回归这类同样有形式文法的任务，都可以套同一个模板——先找到「结构」，再把合法性交给状态机。区别只在于「结构」是什么、「状态机」怎么定义。

## 小结

- **问题**：VAE 的潜变量是连续的高斯向量，分子却是离散的 SMILES 串；逐字符解码时，一个字符错整串就废，字符 VAE 采出的分子只有 17% 能解析。
- **关键洞察**：SMILES 是上下文无关的形式语言，文法已知且固定，解析唯一——所以合法性可以**构造出来**，不必**学出来**。
- **编码**：分子 → 语法树 → 先序遍历得到产生式规则序列 → one-hot → 编码器 → 连续潜空间。解码单位从字符换成了规则。
- **解码**：解码网络一次前向给出全部 logits；用栈模拟下推自动机，每一步对 logits 做掩码，只在当前非终结符的合法产生式上做 softmax。非法项概率严格为 0。
- **合法性分三层**：语法层由文法 + 掩码完全覆盖；语义层（环闭合数字成对、价键规则）文法管不了，分子有效率因此只有 0.31；任务层（变量作用域等）连语义层都管不了。
- **有效性数字**：表达式 0.99 对 0.86，分子 0.31 对 0.17——分子上的翻倍提升仍然远未到 100%，原因就是语义层。
- **风险**：合法性来自解码器而非潜空间；如果解码器足够强，它可能完全忽略 $z$，把 KL 项压到零、让潜空间退化。这组实验里没发生，但结构上并非不可能。
- **可迁移性**：只要有形式文法，就能把「生成离散对象」改写成「生成语法树」。分子、算术表达式、程序合成都是同一个模板。

## 关键术语速查

| 术语 | 一句话解释 |
| :--- | :--- |
| SMILES | 用一串 ASCII 字符描述分子结构的文本表示，相当于分子的「源代码」，改一个字符就可能整串失效 |
| 上下文无关文法 | 一组形如「非终结符 → 符号串」的产生式规则；从起始符号出发反复替换，能造出的串就属于这门语言 |
| 产生式规则 | 文法里的一条替换规则，例如把 chain 替换成「chain 加一个 branched_atom」 |
| 语法树（解析树） | 一次具体推导的记录：根是起始符号，叶子是终结符，中间节点是各步用到的产生式 |
| 先序遍历 | 从根往下、遇到分支先走最左，把节点依次记下来的遍历顺序；用它把语法树线性化成规则序列 |
| 下推自动机 | 带一个栈的自动机，用来识别上下文无关语言；解码时用栈记录「还有哪些非终结符待展开」 |
| 掩码 softmax | 在 softmax 之前把非法项的分母贡献置零，使非法项概率严格等于 0 |
| 语法约束 | 由文法规定的合法性，例如括号是否配对、终结符是否在字母表里 |
| 语义约束 | 文法管不到的合法性，例如 SMILES 里环闭合数字必须成对、价键是否允许 |
| 采样有效率 | 解码出的样本中能被解析（或化学上成立）的比例，衡量解码器约束强度，不等价于潜空间质量 |
| 后验塌缩 | KL 项被压到接近零、编码器输出与输入无关，解码器完全忽略潜变量 $z$ |
| PCFG | 概率上下文无关文法：固定文法 + 每条产生式的概率，Grammar VAE 的采样过程可看作它的神经网络版本 |
