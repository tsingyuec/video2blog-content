# 离散 token 上的扩散：分类空间怎么加噪，分词为何是一等设计维度

> 视频来源：[离散扩散模型统一框架：从分词到生成](https://www.bilibili.com/video/BV18vKE69Euc/)（Bilibili · 熊二等兵）｜时长约 15 分钟
> 导读：这是一期对谈式的综述解读，围绕《Discrete Diffusion Models: A Unified Framework from Tokenization to Generation》。本文只取「表示空间」这一层：为什么离散 token 不能加高斯噪声、加噪对象换成什么、代价落在哪。具体的掩码/吸收态转移核机制留给后续小节。

## 本讲要解决的核心问题（SCQA）

**背景**：扩散模型在图像上已经跑通——从真实图片出发逐步加高斯噪声，再训练一个网络把噪声逐步去掉，整个过程都在连续的实数空间里，数学基础很成熟。

**冲突**：但语言模型的主流是自回归，而自回归有两个越来越突出的短板：生成是串行的（时间复杂度随序列长度线性增长），而且**不可撤销**——一个 token 输出之后就没法再根据后面的上下文修改。扩散看起来能补上这两点，可一旦把对象换成离散 token，连续扩散那一套就搬不过去了。

**疑问**：离散 token 上的扩散，到底「加噪」加的是什么？为什么不能直接把 token 嵌入到连续空间里加高斯噪声？

**回答（中心思想）**：离散扩散换掉的是**加噪对象本身**——从「在实数向量上加高斯扰动」换成「在词表里做状态跳转」。这个替换不是实现细节，它决定了扰动拓扑、每一步去噪的难度和最终的生成顺序；而跳转怎么设计，又取决于 token 是怎么分出来的。所以在这条路线上，**分词（tokenization）是一等的设计维度**，而不是预处理的小事。

## 一、先看动机：自回归的两个短板，与扩散能补的三件事

### 1.1 自回归的优势与短板

现在大语言模型普遍用自回归模型，优势和短板都特别明显（[【跳转到 00:44】](https://www.bilibili.com/video/BV18vKE69Euc/?t=44)）。

优势是：

- 训练目标清晰，就是最大似然估计；
- 训练过程稳定；
- 解码的技术栈已经非常成熟。

这也是为什么大模型能从十几亿参数一路扩容到现在的几千亿参数。

但自回归的短板会随着模型规模和序列长度增长而越来越突出（[【跳转到 01:09】](https://www.bilibili.com/video/BV18vKE69Euc/?t=69)）：

| 短板 | 具体表现 |
| --- | --- |
| 串行瓶颈 | 不管有多少并行算力，都得等前一个 token 生成完才能生成下一个，时间复杂度是线性的 $\mathcal{O}(L)$；处理几万甚至几十万长度序列时延迟成本非常高，KV 缓存和投机解码也没法从根本上解决 |
| 不可撤销 | 一旦输出了一个 token，就没法再根据后面的上下文修改；整个生成过程是单向前馈的，没有全局规划能力，也没法满足跨整个序列的非局部约束 |

像文本补全、可控编辑、长链条推理这些任务，用自回归模型做天生就有局限性。

### 1.2 扩散的生成逻辑完全不同

扩散模型不是从左到右逐个拼 token，而是**从完全被破坏的输入开始多轮迭代，同时优化所有位置的 token**；每一步都能访问当前的完整状态，相当于整个生成过程都有双向上下文支持，随时可以调整之前的输出（[【跳转到 01:34】](https://www.bilibili.com/video/BV18vKE69Euc/?t=94)）。

这带来四个实打实的好处（[【跳转到 01:59】](https://www.bilibili.com/video/BV18vKE69Euc/?t=119)）：

1. **并行解码的效率优势**：只要算力足够，生成时间基本和序列长度无关；已经有研究把扩散语言模型的解码步骤压缩到十几步甚至几步，达到和自回归模型差不多的生成质量。
2. **全局规划能力**：每一步都能看到完整的中间状态，可以协调长距离依赖、修正早期的错误，更容易满足全局约束。比如生成代码时要保证函数名前后一致，生成结构化输出时要满足格式要求。
3. **天然支持编辑和补全**：只需要把要修改的位置重新加噪，其他位置保持不变，模型就能在保留上下文的前提下修改或补全，不需要改模型结构，也不需要针对特定任务微调。
4. **灵活的速度-质量权衡**：去噪步数 $T$ 是可调的自由参数，通常远小于序列长度 $L$，可以根据应用需求在生成速度和样本质量之间权衡。

![扩散范式的核心优势：并行更新、全局上下文、原生编辑填空、速度-质量权衡](assets/离散%20token%20上的扩散：分类空间加噪与分词为何是设计维度/00194.webp)

## 二、核心差别：离散 token 加不了高斯噪声

### 2.1 连续扩散的加噪对象是实数

连续扩散的前向过程是逐步加高斯噪声，每一步的扰动都符合高斯分布；反向过程就是预测噪声或者原始的干净数据。整个过程都在连续的实数空间里，有很成熟的数学基础（[【跳转到 10:45】](https://www.bilibili.com/video/BV18vKE69Euc/?t=645)）。

### 2.2 为什么直接搬不过来

把扩散用到离散数据上，可不是把连续扩散的方法直接搬过来就行的（[【跳转到 02:49】](https://www.bilibili.com/video/BV18vKE69Euc/?t=169)）：

- 连续扩散比如图像领域是加高斯噪声，在预测得分或者去噪后的信号时，都在同一个实数空间里；
- 但离散序列是在**分类空间**里的，欧式空间里的「小扰动」、梯度、得分这些概念根本没法直接套用；
- 最直接的证据：离散 token 的取值是有限的分类集合，你加个高斯噪声出来的结果**根本不在词表里**（[【跳转到 10:45】](https://www.bilibili.com/video/BV18vKE69Euc/?t=645)）。

### 2.3 折中方案为什么失败：嵌入 + rounding

之前有人想过折中方案：把离散 token 嵌入到连续空间，用标准的高斯扩散，最后再 rounding（取整）回最近的 token（[【跳转到 03:14】](https://www.bilibili.com/video/BV18vKE69Euc/?t=194)）。

这个方法有个根本问题：**嵌入流形和离散词表之间存在几何不匹配**，很容易出现 rounding 错误、表示坍塌的问题，生成的样本质量一直上不去。

这里值得停一下：这条折中路线恰好说明了「加噪对象」这件事有多要紧——它试图保留连续扩散的加噪方式，只在两头做嵌入和解码，结果误差就卡在「连续空间里的位置」和「词表里的符号」之间那层不匹配上。

### 2.4 主流做法：直接在离散空间里定义扩散

所以现在主流的研究方向是**直接在离散空间里定义扩散过程**（[【跳转到 03:39】](https://www.bilibili.com/video/BV18vKE69Euc/?t=219)）：

- 设计一个离散的加噪过程；
- 再搭配对应的去噪器，直接从被破坏的分类输入里预测干净的 token。

也就是说，加噪对象不再是「加了一点噪声的实数向量」，而是「被破坏过的 token 序列」；每一步的扰动都是在离散词表里的**跳转**（[【跳转到 11:10】](https://www.bilibili.com/video/BV18vKE69Euc/?t=670)）。

![离散扩散的特有困难：分类空间没有默认距离度量、嵌入方案的几何不匹配、破坏过程设计复杂](assets/离散%20token%20上的扩散：分类空间加噪与分词为何是设计维度/00269.webp)

## 三、加噪过程一旦变成「跳转」，设计空间就变了

视频强调：这里的加噪过程可不是随便选的，它会直接决定三件事（[【跳转到 03:39】](https://www.bilibili.com/video/BV18vKE69Euc/?t=219)）：

1. token 空间里的**扰动拓扑**；
2. 每一步**去噪任务的难度**；
3. 最终的**生成顺序**。

而且离散场景还有很多连续扩散里不会遇到的独有挑战（[【跳转到 04:04】](https://www.bilibili.com/video/BV18vKE69Euc/?t=244)）：

- **精确似然怎么计算**；
- **分类变量的噪声日程怎么设计**；
- **词表结构和前向过程的语义怎么匹配**。

这些挑战让离散扩散的设计空间比连续扩散复杂得多。换句话说，在连续空间里「加高斯噪声」几乎是唯一的自然选择，而在离散空间里，加噪方式是一个需要认真选的设计决策。

## 四、分词不是预处理：它决定了加噪能怎么设计

这篇综述最核心的观点：上面这些设计选择，其实都可以通过 **tokenization** 这个统一视角来理解（[【跳转到 04:04】](https://www.bilibili.com/video/BV18vKE69Euc/?t=244)）。

Tokenization 根本不是什么前置预处理的小细节，而是**一等的设计维度**，几乎会影响后续所有的建模决策（[【跳转到 04:29】](https://www.bilibili.com/video/BV18vKE69Euc/?t=269)）：

- **文本领域**：你选的子词词表大小，直接决定了掩码的力度、替换噪声的语义，还有去噪器看到的有效序列长度。用字符级词表和用词级词表，整个扩散过程的设计肯定完全不一样。
- **多模态生成领域**：VQ-VAE 或者残差量化器的**码本拓扑结构**，其实就定义了 token 之间的距离。加噪过程可以选择利用这个距离，也可以选择忽略，这会直接影响去噪的难度和生成样本的一致性（[【跳转到 04:54】](https://www.bilibili.com/video/BV18vKE69Euc/?t=294)）。
- **科学计算领域**：氨基酸、核苷酸、原子类型这些天然的字母表，本身就带了丰富的结构和化学语义。怎么设计噪声调度才能不破坏这些语义，怎么保证生成的结构符合化学或生物的有效性约束，都和这些天然的 token 定义直接相关。

视频里给了一张跨领域的对照表，把 token 族、度量特性、典型破坏过程和设计关注点放在一起看：

| token 族 | 示例 | 度量特性 | 典型破坏过程 | 核心设计关注点 |
| --- | --- | --- | --- | --- |
| 语义（文本、代码） | BPE、WordPiece、字符级 | 无（索引任意） | 吸收 / 掩码 | 词汇表粒度与序列长度的权衡 |
| 量化（图像、音频、视频） | VQ-VAE、VQ-GAN、RVQ 编码 | 学习到的（码本几何） | 掩码；结构化（未充分利用） | 码本崩溃；拓扑-语义对齐 |
| 自然字母表（蛋白质、DNA/RNA） | 氨基酸、核苷酸 | 外部（BLOSUM、生化特性） | 吸收；可结构化 | 长距离依赖；生物学有效性 |
| 图 / 组合（分子、布局） | 原子/键类型、元素类别 | 部分（化学相似性） | 联合节点-边掩码 | 硬有效性（化合价、连通性） |

![跨领域分词方案对比：不同 token 族的度量特性决定了典型的破坏过程与设计关注点](assets/离散%20token%20上的扩散：分类空间加噪与分词为何是设计维度/00586.webp)

这张表是本文最值得记住的部分：**「加噪对象」不是一个中性的容器**。同样是离散扩散，加在 BPE 子词上的噪声和加在氨基酸字母表上的噪声，语义完全不同，能用的破坏过程也不同。

## 五、统一框架：所有离散扩散模型拆成四个组件

基于这个以 tokenization 为中心的视角，论文把所有离散扩散模型拆成四个组件（[【跳转到 07:17】](https://www.bilibili.com/video/BV18vKE69Euc/?t=437)）：

| 组件 | 定义 | 主流选择 |
| --- | --- | --- |
| 破坏算子（Corruption Operator） | 前向过程如何逐步破坏干净数据，核心是转移矩阵的设计 | 均匀替换、吸收掩码、结构化转移三种；决定扰动拓扑和去噪任务难度 |
| 去噪器参数化（Denoiser Parameterization） | 反向模型的输出形式 | 预测干净 token $x_0$（最常用）、直接预测前一步 token、预测对数概率比、预测得分类似物 |
| 训练目标（Training Objective） | 优化的损失函数 | 通常是变分下界的简化形式；按参数化方式选交叉熵损失、重加权 MSE 损失等；训练中常结合无分类器引导提升可控性 |
| 采样器（Sampler） | 反向过程怎么一步步还原 | 基础祖先采样、基于置信度的重掩码、半自回归与块更新、步数蒸馏等加速 |

![离散扩散的四大通用组件：破坏算子、去噪器参数化、训练目标与采样器](assets/离散%20token%20上的扩散：分类空间加噪与分词为何是设计维度/00695.webp)

视频里还提到加噪过程的几个大类（[【跳转到 11:10】](https://www.bilibili.com/video/BV18vKE69Euc/?t=670)）：转移矩阵模型（用马尔可夫转移矩阵定义每一步的 token 跳转概率）、吸收态掩码（把 token 逐步掩码成一个特殊的掩码 token）、替换和混合加噪、连续时间过程、基于得分或者比率的方法。论文把它们统一到同一个框架下——**具体每种转移核怎么定义、怎么采样，留给后续小节展开**。

## 六、把三条路线摆在一起看

回到本小节的主题：同一个扩散机制，加在不同的表示空间上，就得到三条不同的路线。

| 维度 | ① 像素/连续数据上的扩散 | ② 潜表示上的扩散 | ③ 离散 token 上的扩散 |
| --- | --- | --- | --- |
| 加噪对象 | 高分辨率图像等连续向量（实数空间） | 编码器压出来的连续隐变量 | 分类变量（词表里的符号） |
| 加噪方式 | 加高斯噪声，扰动符合高斯分布 | 同样加高斯噪声，只是作用在隐变量上 | 在词表里做状态跳转（掩码、替换、吸收态等） |
| 反向过程预测什么 | 噪声或干净数据 | 噪声或干净隐变量 | 干净的 token（$x_0$ 参数化最常用），或前一步 token、对数概率比等 |
| 为什么这么选 | 实数空间有成熟的数学基础，加噪简单可控 | 每一步要处理的数据更小 | token 加高斯噪声根本不在词表里；嵌入+rounding 又会有几何不匹配 |
| 代价在哪 | 高分辨率下每步都很贵 | 多一个编解码器，重建有损、隐空间分布要对齐 | 设计空间复杂：扰动拓扑、噪声日程、精确似然、词表语义匹配都要单独设计 |

这张表里，② 的具体做法（感知压缩、缩放因子、条件注入）由本小节另一篇博客《潜空间扩散 LDM》展开；③ 的转移核机制留给后续小节。本文只负责一件事：**看清「加噪对象」这一列**。

顺带说明一个容易混淆的点：图像也可以走路线 ③——先用 VQ-VAE 或残差量化器把连续信号离散化成 token，再在 token 空间里用离散扩散建模，还能和文本 token 放在统一架构里联合建模（[【跳转到 05:44】](https://www.bilibili.com/video/BV18vKE69Euc/?t=344)）。所以「图像/文本」不是路线划分的依据，**「加噪对象是连续向量还是分类符号」才是**。

## 七、离散扩散适合什么、不适合什么

视频也讨论了什么时候适合用离散扩散，什么时候用自回归或者混合方法更好（[【跳转到 13:15】](https://www.bilibili.com/video/BV18vKE69Euc/?t=795)）：

- **离散扩散更有优势**：对生成速度要求高、需要全局可控性、需要编辑补全能力的场景；
- **自回归可能更简单高效**：短序列生成、只需要左到右输出的场景。

论文还整理了跨领域的设计 checklist（[【跳转到 09:21】](https://www.bilibili.com/video/BV18vKE69Euc/?t=561)）：怎么选 tokenization 方案、怎么选加噪算子、怎么匹配训练目标和反向过程、什么时候用迭代重掩码/块更新/半自回归解码、怎么加软硬约束、怎么选评估指标。

## 八、应用领域与开放问题

框架落到三大应用领域（[【跳转到 05:19】](https://www.bilibili.com/video/BV18vKE69Euc/?t=319)）：

1. **扩散语言模型（DLLM）**：已有掩码、吸收态、流匹配等多种方案，做到 10 亿参数级别，能做开放生成、指令跟随、推理、代码合成；
2. **token 化的多模态生成**：图像、音频、视频先离散化，再在 token 空间里用离散扩散建模；
3. **科学与工程里的固有离散结构**：蛋白质氨基酸序列、DNA/RNA 核苷酸序列、分子图的分类节点和边属性、图布局与调度方案；
4. 还有一个新兴方向：**智能体规划与工具使用**，离散扩散可以作为规划器或结构化输出生成器，用在视觉-语言-动作模型和组合优化问题里。

## 小结

- **换的是加噪对象**：连续扩散加高斯噪声，离散扩散在词表里做状态跳转；公式形式可以类比，但扰动的含义完全不同。
- **不能直接搬的原因很硬**：token 是分类变量，加了高斯噪声的结果不在词表里；嵌入到连续空间再 rounding 的折中方案，会卡在嵌入流形与词表之间的几何不匹配上（rounding 错误、表示坍塌）。
- **加噪方式是一个设计决策**：它决定扰动拓扑、每步去噪难度和生成顺序；离散场景还要额外处理精确似然、噪声日程、词表语义匹配。
- **分词是一等设计维度**：子词词表大小决定掩码力度与有效序列长度；VQ 码本拓扑定义 token 之间的距离；氨基酸/核苷酸这类天然字母表自带化学与生物语义。
- **统一框架的四个组件**：破坏算子、去噪器参数化、训练目标、采样器——不同模型家族只是这套结构的不同实例化。
- **路线划分的依据是「加噪对象」**：连续向量（像素或连续隐变量）走高斯噪声，分类符号走离散跳转；图像也可以先量化成 token 再走离散扩散。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 离散扩散（discrete diffusion） | 在分类变量（token）上定义的扩散过程，前向是词表内的状态跳转，反向逐步还原干净 token |
| 破坏算子（corruption operator） | 前向过程怎么逐步破坏干净数据，核心是转移矩阵；均匀替换、吸收掩码、结构化转移是三大类 |
| 吸收态 / 掩码（absorbing / mask） | 把 token 逐步替换成一个特殊的掩码 token，反向过程再从掩码恢复 |
| 均匀替换 | 以一定概率把 token 替换成词表里随机的一个 token |
| 去噪器参数化 | 反向网络输出什么：预测干净 token $x_0$、预测前一步 token、预测对数概率比等 |
| 嵌入 + rounding | 把离散 token 嵌入连续空间做高斯扩散、最后取整回词表的折中方案，会有几何不匹配问题 |
| 码本拓扑 | VQ-VAE 等量化器学出的 token 之间的距离结构，决定加噪过程能不能利用语义相近性 |
| 半自回归 / 块更新 | 把序列分块、块内并行更新的采样加速方式 |
| 迭代重掩码 | 每步只更新置信度低的位置，减少不必要计算的重掩码策略 |
