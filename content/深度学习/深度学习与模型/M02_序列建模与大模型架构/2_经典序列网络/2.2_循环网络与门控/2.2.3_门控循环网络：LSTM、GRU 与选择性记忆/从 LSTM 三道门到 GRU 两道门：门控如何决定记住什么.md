## 本讲要解决的核心问题（SCQA）

**背景**：RNN 把历史压进一个隐状态，逐步往前传。结构极简、算力消耗小，处理序列也"够用"。

**冲突**：它只有短期记忆。反向传播时梯度沿时间连乘，越往前越小；拿到小梯度的层（通常是最早那几层）几乎不更新，于是 RNN 会"忘掉"序列开头看到的东西 [【跳转到 00:39】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=39)。

**疑问**：能不能让网络自己学会"哪些信息该留、哪些该丢"，而不是把所有历史一律压进同一个隐状态？

**回答（中心思想）**：LSTM 和 GRU 的答案是**门（gate）**——一组带 sigmoid 的小神经网络，输出 0 到 1 的系数，像阀门一样调节信息流入流出的比例。LSTM 用**细胞状态**当一条贯穿序列的"传送带"承载长期信息，再用**遗忘门、输入门、输出门**分别控制旧记忆留多少、新内容写多少、这一步输出多少；GRU 则去掉细胞状态、把遗忘与输入合并成一个**更新门**，再加一个**重置门**，用更少的张量运算换来更快的训练 [【跳转到 05:41】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=341)。

## 二、先看 RNN：一个 tanh 就是全部

### 2.1 隐状态就是网络的记忆

RNN 先把词变成机器可读的向量，然后逐个处理；处理到某一步时，把上一步的**隐状态**一起传进来。隐状态充当网络的记忆，装着它此前见过的信息 [【跳转到 03:02】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=182)。

把 RNN 的单元放大：当前输入和上一步隐状态先合并成一个向量，这个向量带着"当前输入 + 之前输入"的信息；它过一个 tanh，输出就是新的隐状态，也就是网络此刻的记忆 [【跳转到 03:27】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=207)。

![RNN 单元的全部运算：输入与上一步隐状态合并后过一个 tanh，输出新的隐状态](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00207.webp)

### 2.2 tanh 在干什么：把数值关进 -1 到 1

tanh 把值压缩到 $-1$ 和 $1$ 之间。为什么要压？因为向量在网络里要经过大量数学变换，如果某个值被反复乘以（比如一直乘 3），它会指数级膨胀到天文数字，让其他值显得无足轻重 [【跳转到 04:01】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=241)。

视频给了一组直观数字：八个单元串起来，中间出现 405、0.81、$-40.5$ 这样的中间值，经过 tanh 之后分别被压成 0.99、0.65、$-0.99$ [【跳转到 04:26】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=266)。

![tanh 把 405、0.81、-40.5 这样的中间值统一压到 -1 到 1 之间，避免数值爆炸](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00266.webp)

所以 RNN 的优点是**内部运算极少、算力消耗远小于它的进化版本**；缺点是只有这一条通路，所有信息都被同一个 tanh 反复压缩 [【跳转到 04:26】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=266)。

## 三、LSTM 的改动：不动控制流，只改单元内部的运算

LSTM 的**控制流和 RNN 完全一样**：顺序处理数据，边往前传边传递信息。区别只在单元内部——多了若干运算，用来让 LSTM 决定"忘掉"还是"保留" [【跳转到 04:51】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=291)。

第一次看到这些运算会觉得眼花，所以视频选择一件一件拆。它声明这部分内容受 Chris Olah 那篇著名的 LSTM 博客启发 [【跳转到 04:51】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=291)。

### 3.1 两个核心概念：细胞状态与门

LSTM 的核心概念只有两个：**细胞状态（cell state）**和**各种门（gates）**。

细胞状态像一条**传送高速公路（transport highway）**，把相关信息一路往下传。可以把它理解为网络的记忆：信息随着序列处理被携带下去，理论上，很早时间步的信息可以被一直带到最后一个时间步，从而缓解短期记忆问题 [【跳转到 05:16】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=316)。

![LSTM 单元的内部运算图：顶部贯穿的横线就是细胞状态这条"传送带"，红色圆圈是 sigmoid，蓝色圆圈是 tanh](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00399.webp)

信息通过门被加进细胞状态、或从细胞状态里移除。**门本身就是一些小神经网络**，决定哪些信息允许进入细胞状态；训练过程中，门学会判断哪些信息该留、哪些该忘 [【跳转到 05:41】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=341)。

### 3.2 门为什么用 sigmoid 而不是 tanh

sigmoid 和 tanh 很像，区别是：tanh 把值压到 $-1$ 到 $1$，sigmoid 把值压到 $0$ 到 $1$ [【跳转到 06:06】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=366)。

![sigmoid 曲线：输出严格落在 0 到 1 之间，天然可以当"保留比例"使用](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00366.webp)

这个区间正好适合"更新或遗忘"：任何数乘 0 都是 0，值就消失（被忘掉）；任何数乘 1 都还是自己，值就被保留。于是网络可以学出"哪些数据该忘、哪些数据重要该留" [【跳转到 06:31】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=391)。

**一句话记住分工：sigmoid 给出"比例"，tanh 给出"内容"。**

## 四、三道门：都只调节流量，不产生内容

LSTM 单元里有三道门调节信息流：遗忘门、输入门、输出门 [【跳转到 06:39】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=399)。

### 4.1 遗忘门：旧隐状态里哪些该丢

遗忘门决定上一步隐状态里的哪些信息该丢掉、哪些该留下。做法是把上一步隐状态和当前输入一起送进 sigmoid，输出落在 0 到 1 之间：越接近 0 表示遗忘，越接近 1 表示保留 [【跳转到 06:50】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=410)。

### 4.2 输入门：候选内容里哪些该写进细胞状态

要更新细胞状态，需要输入门。它分两路：

1. 上一步隐状态与当前输入送进 **sigmoid**，得到 0 到 1 的系数，决定哪些值要更新——0 表示不重要，1 表示重要 [【跳转到 06:50】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=410)。
2. 同一对输入再送进 **tanh**，把值压到 $-1$ 到 $1$，这一路是**候选内容**，用来调节网络的数值范围 [【跳转到 07:15】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=435)。

然后两路逐元素相乘：sigmoid 的输出决定 tanh 输出里哪些信息重要、该保留 [【跳转到 07:15】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=435)。

### 4.3 细胞状态的更新：一次乘法 + 一次加法

现在可以算新的细胞状态了：先把旧细胞状态乘上遗忘向量（如果遗忘向量接近 0，细胞状态里的值就被丢掉），再把输入门的输出**逐元素加上去**，得到新的细胞状态 [【跳转到 07:40】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=460)。

$$
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t
$$

![完整的 LSTM 单元与图例：旧细胞状态 c(t-1) 乘遗忘门 f(t)，加上输入门 i(t) 乘候选 c(t)，得到新细胞状态](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00460.webp)

对照图看这条式子：$c_{t-1}$ 那条线上**没有任何权重矩阵**，只有一次逐元素乘 $f_t$ 和一次逐元素加 $i_t \odot \tilde{c}_t$。这就是细胞状态被称为"传送带"的原因，也是门控能缓解梯度消失的结构性原因——梯度沿这条路径回传时，只需要穿过一串 0~1 的系数，而系数可以学成接近 1。

### 4.4 输出门：这一步对外说什么

最后是输出门，它决定下一个隐状态应该是什么。注意隐状态有两个用途：携带此前输入的信息，以及**用于预测** [【跳转到 08:05】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=485)。

做法是：上一步隐状态与当前输入过 sigmoid 得到比例；刚更新好的细胞状态过 tanh；两者相乘，就得到这一步该携带的隐状态。新的细胞状态和新的隐状态一起被送到下一个时间步 [【跳转到 08:05】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=485)。

![带完整图例的 LSTM 单元：右侧标出了遗忘门 f、输入门 i、候选 c、输出门 o 与隐状态 h 各自的位置](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00485.webp)

## 五、用伪代码把控制流串起来

如果更习惯看代码，视频给了一段 Python 伪代码，把整个单元的控制流写成一个函数 [【跳转到 08:30】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=510)：

```python
def LSTMCELL(prev_ct, prev_ht, input):
    # 1. 拼接：上一步隐状态 + 当前输入
    combined = concat(prev_ht, input)

    # 2. 遗忘层：去掉不相关的数据
    f = sigmoid(W_f @ combined + b_f)

    # 3. 候选层：给出可能写入细胞状态的值
    candidate = tanh(W_c @ combined + b_c)

    # 4. 输入层：决定候选值里哪些真的写进去
    i = sigmoid(W_i @ combined + b_i)

    # 5. 更新细胞状态：旧的按比例留 + 新的按比例加
    new_ct = f * prev_ct + i * candidate

    # 6. 输出层：决定细胞状态有多少变成隐状态
    o = sigmoid(W_o @ combined + b_o)
    new_ht = o * tanh(new_ct)

    return new_ht, new_ct
```

对应到文字描述：先把上一步隐状态和当前输入**拼接**成 `combined`；`combined` 送进遗忘层，去掉不相关的数据；同一份 `combined` 送进候选层，得到可能加入细胞状态的候选值；再送进输入层，决定候选值里哪些该加进新的细胞状态；然后用这些向量和旧细胞状态算出新的细胞状态；最后把输出与新的细胞状态逐元素相乘，得到新的隐状态 [【跳转到 09:00】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=540)。

**整个 LSTM 的控制流，本质上就是一个 for 循环**：沿序列逐步调用这个单元，隐状态输出可以拿去接预测层 [【跳转到 09:25】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=565)。

## 六、GRU：去掉细胞状态，两道门够不够

### 6.1 结构上的三处减法

GRU 是更新一代的循环网络，和 LSTM 很像，但做了三处简化 [【跳转到 09:42】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=582)：

1. **去掉细胞状态**，只用隐状态来传递信息；
2. 门从三道减到**两道**：重置门（reset gate）和更新门（update gate）；
3. 张量运算更少，因此训练稍快一些。

![LSTM 与 GRU 的单元结构对比：左边 LSTM 有贯穿的细胞状态与三道门，右边 GRU 只有一条状态线、两道门](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00078.webp)

### 6.2 两道门各管什么

- **更新门（update gate）**：作用相当于 LSTM 的遗忘门与输入门的合体——它同时决定"丢掉哪些旧信息"和"加入哪些新信息" [【跳转到 09:42】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=582)。
- **重置门（reset gate）**：决定有多少过去的信息该被忘掉 [【跳转到 10:07】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=607)。

![GRU 单元中的更新门：它把"遗忘"和"写入"两件事合成一次决策](assets/从%20LSTM%20三道门到%20GRU%20两道门：门控如何决定记住什么/00607.webp)

工程上的结论很朴素：**LSTM 和 GRU 通常都要试**，由具体任务决定哪个更好 [【跳转到 10:07】](https://www.youtube.com/watch?v=8HyCNIVRbSU&t=607)。

### 6.3 LSTM / GRU 与普通 RNN 的取舍

| 维度 | 普通 RNN | LSTM | GRU |
| --- | --- | --- | --- |
| 状态 | 只有隐状态 | 隐状态 + 细胞状态 | 只有隐状态 |
| 门数 | 无 | 3（遗忘、输入、输出） | 2（更新、重置） |
| 单元内运算量 | 极少 | 多 | 较少 |
| 长序列表现 | 只有短期记忆 | 好 | 好 |
| 训练速度 | 最快 | 较慢 | 较快 |

## 小结

- 门控要解决的问题是 RNN 的短期记忆：梯度沿时间连乘后过小，早期时间步学不到东西。
- 门就是"带 sigmoid 的小神经网络"，输出 0~1 的系数：乘 0 即遗忘，乘 1 即保留。
- LSTM 用细胞状态当贯穿序列的传送带，上面只有逐元素乘法和加法，没有直接作用的权重，因此长期信息能一路带下去。
- 三道门分工：遗忘门管旧记忆留多少，输入门管候选内容写多少，输出门管这一步对外输出多少；候选内容由 tanh 产生。
- 整个 LSTM 的控制流就是一个 for 循环，每步复用同一套权重，因此能处理任意长度的序列。
- GRU 去掉细胞状态，把遗忘与输入合并成更新门，再加一个重置门，用更少的张量运算换更快的训练；实践中两者都要试。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 门（gate） | 一组带 sigmoid 的小神经网络，输出 0~1 的系数调节信息流量 |
| 细胞状态（cell state） | LSTM 中贯穿序列的长期记忆通路，只经历逐元素乘加 |
| 隐状态（hidden state） | 短期记忆，同时作为该步输出，直接连接权重 |
| 遗忘门（forget gate） | 决定上一步隐状态与旧细胞状态里哪些信息该丢 |
| 输入门（input gate） | 决定 tanh 产生的候选内容里哪些写入细胞状态 |
| 输出门（output gate） | 决定细胞状态有多少转成本步的隐状态输出 |
| 候选内容（candidate） | 由隐状态与输入经 tanh 产生的待写入值，范围 $-1$ 到 $1$ |
| 更新门（update gate） | GRU 中合并"遗忘 + 写入"的那道门 |
| 重置门（reset gate） | GRU 中决定遗忘多少过去信息的门 |
