# 循环神经网络：隐状态递推、按时间展开与 BPTT 的梯度连乘

> 视频来源：[【RNN】手把手讲解 RNN 框架和原理——BPTT 手推以及简单模型搭建预测](https://www.bilibili.com/video/BV1Sc411r7o6/)（Bilibili · 皮卡丘上大学啦）｜时长约 37 分钟

## 本讲要解决的核心问题（SCQA）

**背景**：多层感知机（MLP）一次吃一个固定长度的输入，吐一个输出。它的每一层只和上一层相连，与"上一次调用"没有任何关系。

**冲突**：语言、传感器读数、股价这些数据是**有序**的。同一个词在不同上下文中含义不同——"256G 的苹果"说的是手机内存，"256 克的苹果"说的是水果。如果模型每次只看当前这一个输入，它就永远分不清这两句话。要让模型"记住前面"，就必须让上一步的计算结果参与这一步的计算。

**疑问**：这个"记忆"在数学上是什么？把它摊开到时间轴上长什么样？既然每一时刻都用了同一个状态，那么训练时梯度要怎么穿过这一串时间步？为什么这个做法在序列一长就训练不动？

**回答（中心思想）**：**RNN 用一个隐藏状态 $S_t$ 把历史压缩成一个定长向量，每一步都用同一组权重把"上一步的状态"和"这一步的输入"合成新的状态；把循环按时间展开后，它就变成一张权重共享的深前馈网络，因此可以直接用反向传播训练——这就是 BPTT（Backpropagation Through Time，随时间反向传播）。代价在于梯度要沿时间连乘：连乘因子是 $W_S$ 的幂次乘以 tanh 的导数，$W_S$ 的谱半径小于 1 就梯度消失、大于 1 就梯度爆炸，于是长程依赖学不动。** [【跳转到 08:22】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=502)

## 一、序列为什么需要"记忆"

### 1.1 同一个输入，前后文不同含义不同

视频开场给了一个很朴素的动机：时间序列在很多场景里非常有用，比如在工厂里**提前感知异常、提前感知错误**，用时间序列去做这件事是高效且有帮助的 [【跳转到 00:25】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=25)。

接着用一个动画说明"时间线"的直觉。正常的神经网络是这样一个流程：输入经过权重和偏置（还有一个 bias）进入隐藏层，隐藏层做完一系列运算和激活后输出到 output layer [【跳转到 01:28】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=88)。这其实就是前面讲过的 MLP——多个神经元堆叠起来做一件事。

加入时间序列之后，结构上多出一样东西：**时间线上相邻的状态之间有一条"通信"通道**。前面的状态会作为一个输入，进入下一个状态的计算 [【跳转到 02:18】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=138)。

为什么非要这条通道？视频举了两个例子 [【跳转到 02:43】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=163)：

- **"256G 的苹果"与"256 克的苹果"**：前者说的是 iPhone 的内存，后者说的是能吃的水果。同一个"苹果"，靠前后文才能定出意思。
- **一个像名字的词**：它既可以当普通英文单词（有词义），也可以当人名。到底取哪种解释，要看它在句中与前面内容的关系。

结论是：**当前这一步的理解依赖前面几步做了什么**，所以模型必须把"前面做过什么"带在身上。这就是引入 RNN 的理由 [【跳转到 03:58】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=238)。

### 1.2 隐状态：把历史压成一个向量

视频里把"带在身上的东西"记作 $S$（state，状态）。它到下一步时会乘上一个权重 $W_S$，也就是 $W_S \times S_{t-1}$；同时当前输入 $X_t$ 也会乘上自己的权重 $W_X$ 进到同一个位置。两路相加再加上偏置，就是这个时刻隐藏层的输出 [【跳转到 05:39】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=339)。

所以隐藏层的输入有**两个来源**：

1. 当前时刻的原始特征 $X_t$（走 $W_X$）；
2. 上一时刻的隐藏状态 $S_{t-1}$（走 $W_S$）。

这一步就把"记忆"具体化了：**历史不再是一串变长的序列，而是一个定长向量**。序列再长，进到下一时刻的也只有这一个向量。

### 1.3 五种输入输出形态

在进入推导之前，视频先扫了一遍 RNN 能摆出的几种形状 [【跳转到 09:12】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=552)：

![RNN 的五种输入输出形态：一对一、一对多、多对一、多对多（等长与不等长）](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/00557.webp)

- **一对一**：输入输出刚好对得上，就是普通的前馈网络。
- **多对一**：输入一整段，只出一个判断。情感分类就是典型——输入 "you happy watching the movie" 这样一串词，输出只有一个情感标签（positive / negative）[【跳转到 10:02】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=602)。实际做的时候，每个词会被做成 one-hot 向量，于是输入是一串向量，输出是一个标量。
- **一对多**：给一个东西，生成很多个东西。比如"帮我生成一首诗"，输入一句话，输出一串文字 [【跳转到 11:17】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=677)。视频顺带提了一句：现在最火的 GPT 属于 Transformer 系，是在 RNN、LSTM、GRU 这一大串之后出现的 [【跳转到 10:52】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=652)。
- **多对多（等长）**：输入输出长度相同，逐位置对齐。
- **多对多（不等长）**：最直观的例子是翻译——"what is artificial intelligence?" 进去，"什么是人工智能？" 出来，两边长度不一样，但都是序列 [【跳转到 11:42】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=702)。

## 二、隐状态递推：一个式子，两个权重

### 2.1 递推式

把上面说的写成一个式子，就是 RNN 的核心：

$$
S_t = f\left(W_X X_t + W_S S_{t-1} + b_1\right)
$$

其中 $f$ 是激活函数，这里用 $\tanh$；$b_1$ 是隐藏层的偏置。输出层再乘一个权重：

$$
O_t = W_O S_t + b_2
$$

视频里的幻灯片把这两行写在一起，并在 $W_S S_{t-1}$ 下面画了一条弧线，标注"**关联不同时刻**"——这条弧线就是 RNN 与 MLP 的唯一区别 [【跳转到 05:02】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=302)。

![RNN 输出式 $S_t = f(W_{in}X + W_S S_{t-1} + b)$，橙色弧线标出"关联不同时刻"的那一项](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/00302.webp)

注意这里只有**三个**权重矩阵：$W_X$（输入到隐藏）、$W_S$（隐藏到隐藏）、$W_O$（隐藏到输出）。它们在整个时间轴上**是同一组**——这正是下一小节要解释的设计。

### 2.2 为什么三个权重矩阵要全时间步共享

视频专门停下来讲了共享权重的三个理由 [【跳转到 13:21】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=801)：

1. **同一组权重面对不同输入能给出不同结果**。共享不等于"输出恒定"，因为输入在变、状态在变。
2. **大幅减少参数量**。如果每个时间步都用一套独立的参数矩阵，那么序列一长，参数就非常庞大，训练时间和训练量都随之上升 [【跳转到 13:46】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=826)。
3. **泛化与统一处理**。矩阵相同，序列长度可以不同；如果每个时刻矩阵都不一样，维度计算会非常复杂，观测和统一的数据处理也不好做 [【跳转到 14:11】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=851)。

这条"权重共享"的性质，是后面把它当"展开的深网络"来训练的前提：展开后每一层长得一样、参数也同一份，梯度要对所有时间步的贡献求和。

### 2.3 同一张图的三种画法

同一件事，视频给了三种画法，从具体到抽象：

**第一种：逐神经元画。** 左边是输入 $X_{t-1}, X_t, X_{t+1}$，中间是隐藏层，右边是输出，橙色连线就是 $W_S$ 把相邻时刻的隐藏层接起来。图上还标了"时间"箭头，说明这是同一个网络被沿时间复用了三次 [【跳转到 01:03】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=63)。

![把 RNN 画到神经元级：纵向是时间，橙色连线 $W_S$ 把相邻时刻的隐藏层串起来](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/00063.webp)

**第二种：抽象成一根线。** 把整层抽象成一根线，前后时刻之间只留一根连接，就得到论文里常见的那种简图；它和上面那张逐神经元的图是**完全对应**的 [【跳转到 06:37】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=397)。

**第三种：横过来，按时间铺开。** 把上面那张转 90 度，横轴变成时间，就得到最常用的"展开图"：输入 $X_t$ 经 $U$ 得到状态 $S_t$，$S_t$ 经 $V$ 得到输出 $O_t$，同时 $S_t$ 经 $W$ 流向 $S_{t+1}$ [【跳转到 07:52】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=472)。

![按时间铺开的 RNN：横轴是时间，$U$ 是输入到状态的权重，$W$ 是状态到状态的权重，$V$ 是状态到输出的权重](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/00472.webp)

这张图里 $U$、$W$、$V$ 在三个时间步上重复出现，一眼就能看出"权重共享"。

## 三、按时间展开：把循环摊成一张前馈图

展开（unroll）这个词听起来抽象，做的事其实很朴素：**把"同一个模块被反复调用"画成"很多个模块首尾相接"**。

- 折叠视角下，网络只有一个方块，方块上有一个指回自己的箭头（自环）。
- 展开视角下，这个方块被复制 $T$ 份，第 $t$ 份的输入是 $X_t$ 和上一份的输出 $S_{t-1}$，输出是 $O_t$ 和传给下一份的 $S_t$。

展开之后，**时间变成了深度**：一个长度 3 的序列，就是一个 3 层的网络；一个长度 1000 的序列，就是一个 1000 层的网络。这一步的意义在于：一旦变成前馈图，前面小节讲过的反向传播就可以直接套用，不需要发明新的求导规则。反过来，深度带来的麻烦（梯度在深网络里连乘）也会原封不动地搬到时间维度上——这就是后面第五节的伏笔。

视频在讲完结构后直接切到训练：**寻找最优权重仍然是通过梯度下降做的，只不过这里是基于时间序列的梯度下降，推导过程会更复杂** [【跳转到 08:22】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=502)。

## 四、BPTT：梯度怎样沿时间一路乘回去

为了把推导讲清楚，视频把序列截到三个时间步，并把符号统一成 $S_1, S_2, S_3$、$O_1, O_2, O_3$、$X_1, X_2, X_3$ [【跳转到 15:26】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=926)。隐藏层用 $\tanh$；输出层为了简化，**先不加激活函数**（视频说加上也可以，只是求导时多一项）[【跳转到 15:51】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=951)。

![三个时间步的完整前向表达式、均方误差损失，以及 $\partial L_3/\partial W_O$、$\partial L_3/\partial W_X$、$\partial L_3/\partial W_S$ 三条求导路径的总览](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/00776.webp)

### 4.1 先把前向写死

三个时间步的前向传播写成显式表达式 [【跳转到 16:41】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1001)：

$$
\begin{aligned}
S_1 &= \tanh\left(W_X X_1 + W_S S_0 + b_1\right)\\
S_2 &= \tanh\left(W_X X_2 + W_S S_1 + b_1\right)\\
S_3 &= \tanh\left(W_X X_3 + W_S S_2 + b_1\right)
\end{aligned}
$$

输出层（不加激活）：

$$
O_1 = W_O S_1 + b_2,\quad O_2 = W_O S_2 + b_2,\quad O_3 = W_O S_3 + b_2
$$

这里 $S_0$ 是初始状态，通常取零向量。偏置 $b_1$ 在三个式子中取同一个值（视频说取不一样也没多大影响，因为它不参与对权重的求导）[【跳转到 17:31】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1051)。

损失函数取均方误差，并且**只看最后一个时间步**：

$$
L_3 = \frac{1}{2}\left(O_3 - Y_3\right)^2
$$

### 4.2 对 $W_O$ 求导：只有一条路径

先算最简单的 $\partial L_3 / \partial W_O$。$L_3$ 和 $W_O$ 没有直接关联，但 $L_3$ 连到 $O_3$，$O_3$ 连到 $W_O$，所以走一次链式法则就够了 [【跳转到 19:11】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1151)：

$$
\frac{\partial L_3}{\partial W_O}
= \frac{\partial L_3}{\partial O_3}\cdot\frac{\partial O_3}{\partial W_O}
= \left(O_3 - Y_3\right)\cdot S_3
$$

关键点：$S_3$ 对 $W_O$ 求导时是**常数**（$S_3$ 里不含 $W_O$），所以它被直接提出来乘在误差项后面。这里只有一条路径，没有"沿时间回溯"。

### 4.3 对 $W_X$ 求导：路径不止一条

$\partial L_3 / \partial W_X$ 就麻烦了。$W_X$ 在三个时间步里都出现过，所以它对 $L_3$ 的影响有三条通路 [【跳转到 20:51】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1251)：

$$
\frac{\partial L_3}{\partial W_X}
= \frac{\partial L_3}{\partial O_3}\cdot\frac{\partial O_3}{\partial S_3}\cdot\frac{\partial S_3}{\partial W_X}
$$

看上去只有三项，但最后这一项 $\partial S_3/\partial W_X$ **不能直接算**——因为 $S_3$ 里面还嵌着 $S_2$，$S_2$ 里面还嵌着 $S_1$，而 $S_1$、$S_2$ 也都含 $W_X$ [【跳转到 22:06】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1326)。所以每往前一个时间步，就要再套一层链式法则。

视频的处理办法是**换元**：令

$$
c_3 = W_X X_3 + W_S S_2 + b_1,\qquad S_3 = \tanh(c_3)
$$

于是

$$
\frac{\partial S_3}{\partial W_X}
= \frac{\partial \tanh(c_3)}{\partial c_3}\cdot\frac{\partial c_3}{\partial W_X}
$$

前一项就是 tanh 的导数，好算；后一项用加法法则拆开：

$$
\frac{\partial c_3}{\partial W_X}
= X_3 + W_S\cdot\frac{\partial S_2}{\partial W_X}
$$

因为 $W_X X_3$ 对 $W_X$ 求导只剩系数 $X_3$，而 $W_S$ 和 $W_X$ 是两个独立的权重矩阵、互不相干，所以 $W_S$ 可以原样提到前面 [【跳转到 24:11】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1451)。

![把 $\partial S_3/\partial W_X$ 用换元 $c_3$ 拆开：先对 $c_3$ 求导，再对 $W_X$ 求导，最后一项里冒出 $\partial S_2/\partial W_X$](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/01376.webp)

同样的换元对 $S_2$ 做一遍（令 $c_2 = W_X X_2 + W_S S_1 + b_1$），会得到**形式完全相同、只是下标变了**的式子；再对 $S_1$ 做一遍 [【跳转到 25:51】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1551)。最后一步里 $S_0$ 也和参数有关，但既然只考虑三个时间步，就把它当常数处理掉 [【跳转到 26:34】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1594)。

### 4.4 展开到底：连乘里有什么

把三层换元一路代回去，最终得到 [【跳转到 26:59】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1619)：

$$
\frac{\partial L_3}{\partial W_X}
= \left(O_3 - Y_3\right) W_O \left[
\frac{\partial \tanh(c_3)}{\partial c_3} X_3
+ \frac{\partial \tanh(c_3)}{\partial c_3}\frac{\partial \tanh(c_2)}{\partial c_2} X_2 W_S
+ \frac{\partial \tanh(c_3)}{\partial c_3}\frac{\partial \tanh(c_2)}{\partial c_2}\frac{\partial \tanh(c_1)}{\partial c_1} X_1 W_S^2
\right]
$$

![把三层换元代回后得到的完整表达式：每一项都带一串 tanh 导数，越靠前的项多带一个 $W_S$ 的幂](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/01619.webp)

这个式子值得逐项看：

| 项 | 来自哪个时间步 | tanh 导数个数 | $W_S$ 的幂次 |
| --- | --- | --- | --- |
| 第一项 | $X_3$ | 1 | 0 |
| 第二项 | $X_2$ | 2 | 1 |
| 第三项 | $X_1$ | 3 | 2 |

规律很清楚：**离损失越远的输入，它在梯度里带的 tanh 导数越多、$W_S$ 的幂次越高**。这就是 BPTT 的"沿时间连乘"——它不是一句口号，而是这个式子的直接形状。

## 五、长程依赖的代价：梯度消失与梯度爆炸

### 5.1 连乘的两种命运

上一节的式子里，起决定作用的是两类因子 [【跳转到 27:24】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1644)：

- **$\tanh$ 的导数**：它落在一个固定区间内（最大不超过 1）。视频的判断是"它不影响咱们的取值"——不管怎么乘，最多也就是 1，不会放大。
- **$W_S$ 的幂次**：随着时间步增加，指数一直在上升。这才是主导因素。

于是有两种结局 [【跳转到 28:14】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1694)：

- 如果 $W_S$ 的取值小于 1，做指数幂之后**越来越小**，梯度在向前传播的过程中慢慢趋近于零——**梯度消失**。
- 如果 $W_S$ 大于 1，随着指数上升**不断变大**——**梯度爆炸**。

![幻灯片在 tanh 导数曲线旁标出 $W_S$：tanh 导数被限制在 0 到 1 之间，真正随步数放大或缩小的是 $W_S$ 的幂](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/01694.webp)

### 5.2 为什么"越靠前的输入越没影响"

梯度消失的后果，落到学习上就是一句话：**在不断传递的过程中，越到后面，前面信息对应的权重在下降** [【跳转到 29:09】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1749)。

具体说，$X_1$ 的信息要经过 $S_1 \to S_2 \to S_3$ 才能影响到 $L_3$，这一路的连乘让它所占的比例越来越小。模型因此学不到"很久以前发生过什么"，而这恰恰是长程依赖任务最需要的能力 [【跳转到 29:14】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1754)。

视频在这里明确收口：解决这个问题需要引入新的结构，也就是后面要讲的 LSTM（门控循环网络），本节只把 RNN 的结构、梯度消失/爆炸的成因和 BPTT 的推导讲完 [【跳转到 29:39】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1779)。

> 关于"梯度为什么会消失"这件事，还有一层工程上的对应：展开后的网络深度等于序列长度，梯度要保存的中间激活也随长度线性增长。当序列很长时，除了梯度问题，显存也会成为瓶颈——这正是相邻小节「截断 BPTT」要处理的事。

## 六、动手：用 SimpleRNN 预测一段等差序列

推导讲完，视频用一个小例子把流程走了一遍：给一段序列 $10, 20, 30, \dots, 90$，让模型预测后面两个数——人一眼看出是 100 和 110 [【跳转到 30:04】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1804)。

### 6.1 切样本：用前 3 个预测后 2 个

设定是"输入 3 个、预测 2 个"。做法是用一个滑动窗口把长序列切成样本：从索引 0 开始，取 `[0:3]` 作为 $X$、`[3:5]` 作为 $Y$；然后窗口右移，继续切 [【跳转到 30:54】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1854)。序列长度是 9，所以能切出 5 个样本。

运行后打印出来，就是"前面是 X、后面是 Y"的样子 [【跳转到 32:09】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1929)。

### 6.2 改形状：从二维变三维

RNN 要的是**时间序列**格式，每一步只能喂一个时间片，所以要把二维的 `(样本数, 窗口长度)` reshape 成三维的 `(样本数, 时间步, 特征数)`，这里是 `(5, 3, 1)`；对应的 $Y$ 是 `(5, 2)` [【跳转到 32:34】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=1954)。

### 6.3 建模型与数参数

模型用 `Sequential` 搭两层 [【跳转到 33:24】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2004)：

```python
model = Sequential()
model.add(SimpleRNN(50, activation='relu', input_shape=(seq_len, 1)))
model.add(Dense(n_steps))
model.compile(optimizer='adam', loss='mse')
```

隐藏单元数取 50，输出层 `Dense(2)` 对应要预测的两个数，用 Adam 优化、MSE 作损失。

![在 Jupyter 里搭 SimpleRNN + Dense、编译并开始训练，loss 从 2424 一路下降到 1400 附近](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/02054.webp)

`model.summary()` 打印出两个数字：`simple_rnn` 有 **2600** 个参数，`dense` 有 **102** 个，合计 2702 [【跳转到 35:29】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2129)。这两个数怎么来的？视频当场拆了一遍 [【跳转到 34:14】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2054)：

- **SimpleRNN 的 2600**：输入维度是 1，隐藏单元是 50。从输入到隐藏的权重是 $1 \times 50 = 50$ 个，从上一状态到隐藏的权重是 $50 \times 50 = 2500$ 个，再加 50 个偏置，合计 $50 + 2500 + 50 = 2600$。
- **Dense 的 102**：隐藏 50 维接到 2 个输出，权重 $50 \times 2 = 100$ 个，加 2 个偏置，合计 102。

注意这里**没有**随序列长度增长的参数——序列有 3 步还是 300 步，参数量都是 2600。这正是第二节"权重共享"的直接体现。

![model.summary 的输出：simple_rnn 2600 个参数、dense 102 个参数，合计 2702](assets/循环神经网络：隐状态递推、按时间展开与%20BPTT%20的梯度连乘/02129.webp)

### 6.4 训练与预测

接着 `fit` 训练 500 个 epoch，打开 verbose 实时看 loss：训练过程中 loss 不断减少，到最后已经很小 [【跳转到 35:29】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2129)。然后画出 loss 曲线，把想预测的前三个数 reshape 成正式输入维度，再 `predict` 后面两个值。

结果得到 **100 和 114**——第一个数很准，第二个数偏了一点 [【跳转到 35:54】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2154)。视频的解释是：可以通过继续训练、加 dropout、加正则化或者增加训练轮数来改善；重新跑一次结果又会不一样，这些都可以调 [【跳转到 36:44】](https://www.bilibili.com/video/BV1Sc411r7o6/?t=2204)。

这个例子本身很简单，但它把整条链路串起来了：**切样本 → 改形状 → 建模型 → 数参数 → 训练 → 预测**。真实任务里换掉的只是数据和规模，形状约定是一样的。

## 小结

- **隐状态是"记忆"的载体**：$S_t = f(W_X X_t + W_S S_{t-1} + b_1)$，历史被压成一个定长向量带在身上，序列再长进到下一步的也只有这一个向量。
- **三个权重矩阵全时间步共享**：$W_X$、$W_S$、$W_O$ 各一份。好处是参数不随序列长度增长、能处理不同长度、便于统一处理；代价是梯度要对所有时间步的贡献求和。
- **按时间展开就是"时间变深度"**：折叠图里一个带自环的方块，展开后是 $T$ 个首尾相接的副本。展开之后，普通的反向传播可以直接套用。
- **BPTT 的实质是沿时间连乘**：离损失越远的输入，梯度里带的 tanh 导数越多、$W_S$ 的幂次越高。
- **长程依赖学不动的根源是连乘**：$W_S$ 的幂次主导结果，小于 1 就梯度消失、大于 1 就梯度爆炸；tanh 导数被限制在 0 到 1 之间，帮不上忙。
- **梯度消失的表现**：越靠前的输入对最终损失的影响越小，模型记不住"很久以前发生过什么"。
- **参数量与序列长度无关**：$1\times50 + 50\times50 + 50 = 2600$，序列 3 步和 300 步都一样。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 隐状态（hidden state） | RNN 里携带历史信息的定长向量，每一步被更新一次 |
| 权重共享（weight sharing） | 同一组 $W_X, W_S, W_O$ 在所有时间步复用，参数量不随序列长度增长 |
| 展开（unroll） | 把"同一模块反复调用"画成"多个模块首尾相接"，时间维度变成网络深度 |
| BPTT | Backpropagation Through Time，在展开后的计算图上做反向传播 |
| 梯度消失 | 连乘因子小于 1，梯度沿时间迅速衰减，远距离依赖学不到 |
| 梯度爆炸 | 连乘因子大于 1，梯度沿时间迅速放大，训练发散 |
| 多对一 | 输入一整段、只输出一个判断，如情感分类 |
| 一对多 | 输入一个、输出一串，如文本生成 |
| 多对多 | 输入输出都是序列，如翻译（两边长度可以不同） |
| 时间步（time step） | 序列中的一个位置，展开后对应网络中的一层 |
