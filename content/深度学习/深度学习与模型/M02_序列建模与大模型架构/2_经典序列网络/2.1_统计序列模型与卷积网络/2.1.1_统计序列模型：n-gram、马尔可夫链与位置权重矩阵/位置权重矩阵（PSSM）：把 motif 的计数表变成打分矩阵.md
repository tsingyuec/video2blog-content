# 位置权重矩阵（PSSM）：把 motif 的计数表变成打分矩阵

> 视频来源：[Position-specific Scoring Matrices (PSSMs): Theory and Biopython](https://www.youtube.com/watch?v=ontjFJNOlMY)（YouTube · Professor Hendrix）｜时长约 12 分钟
> 本文基于视频演说图文稿整理，配图截自视频。这支视频从"背景模型"讲起，一步步把一组对齐的 DNA 序列变成计数矩阵、频率矩阵，最后变成可以拿去扫描整条基因组的打分矩阵，并在 Biopython 里跑通。文中公式与代码均取自幻灯片，字幕里的口语碎片已按上下文订正。

## 本讲要解决的核心问题（SCQA）

**背景**：做 ChIP-seq 之类的实验之后，你手上会有一批对齐好的转录因子结合位点序列。它们长度相同、位置对齐，但碱基并不完全一致——同一个位置上，多数时候是某个碱基，偶尔换成别的。

**冲突**：最常见的表示法是**一致序列（consensus sequence）**：每个位置只写一个字母，模糊的位置用 IUPAC 简并码（如 W 表示 A 或 T）。可这只保留了"最常出现的那个碱基"，把"第二常见的碱基有多常见"整个丢掉了。更麻烦的是，这种表示没法给一条**新**序列打分：我们真正想做的不是描述这批序列，而是拿它去全基因组里找"下一个结合位点"。

**疑问**：怎样用概率而不是字母来描述一个 motif？"某个位置偏爱某个碱基"这件事，怎么变成一个新序列的分数？分数为什么必须是**似然比**、而不是单纯的概率？计数表里出现 0 会怎样？

**回答（中心思想）**：**PSSM 把 motif 表示成一张"每个位置、每种碱基"的对数似然比表：先用计数矩阵 $C$ 数出每个位置每种碱基出现几次，按列归一化成频率矩阵 $f$，再取 $\log(f_{b,i}/p_b)$ 与背景频率之比——于是给一条新序列打分，只需把每个位置对应的那一格权重加起来，分数越高越像 motif。** 这套"计数 → 归一化 → 取对数比 → 求和打分"的流程，与 n-gram 语言模型的"计数 → 归一化 → 取对数 → 连乘打分"是同一件事在两条序列轴上的两种写法。

## 一、先说 PSSM 不是什么：背景模型

要讲清 PSSM，得先讲它的分母。视频的做法是先定义**背景模型（background model）**——一个描述"随机序列"的概率模型 [【跳转到 00:31】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=31)。

最简单的背景模型只由四个单核苷酸频率 $p_A, p_C, p_G, p_T$ 定义（如果四种等概率，就是各 0.25）。在它之下，一条长度为 $k$ 的序列 $x$ 的概率是各位置碱基频率的连乘：

$$
P(x \mid R) = \prod_{i=1}^{k} p_{x[i]} = p_{x[1]} \cdot p_{x[2]} \cdots p_{x[k]}
$$

![背景模型幻灯片：最简单的背景模型由四个单核苷酸频率定义，序列概率是各位置频率的连乘](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00036.webp)

注意这个模型**没有位置概念**：第 1 个位置是 A 的概率和第 5 个位置是 A 的概率完全一样。这正是它"随机"的含义，也正是 motif 模型要打破的东西。

## 二、motif 模型：给每个位置一套自己的概率

motif 模型则是一张概率矩阵：**行是四种碱基 A、C、G、T，列是 motif 的各个位置**。矩阵里的每个元素 $f_{b,i}$ 表示"在位置 $i$ 观察到碱基 $b$"的概率 [【跳转到 01:01】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=61)。

同样地，一条序列在 motif 模型下的概率是逐位置频率的连乘，只不过现在频率**依赖位置**，所以下标里必须带上 $i$：

$$
P(x \mid M) = \prod_{i=1}^{k} f_{x[i],\,i}
$$

这就是"位置特异性（position-specific）"这个词的全部含义：同一个碱基，在不同位置上可以有不同的权重。

## 三、从序列到计数矩阵：用指示矩阵做加法

### 3.1 指示矩阵与 Kronecker delta

现在假设手上有一批序列 $s_1, \dots, s_N$（长度相同、已对齐）。要把它们汇总成计数矩阵，视频先用一个数学小工具：**Kronecker delta**

$$
\delta_{a,b} = \begin{cases} 1, & a = b \\ 0, & a \neq b \end{cases}
$$

用它定义**指示矩阵（indicator matrix）**：当序列 $x$ 在位置 $i$ 的碱基是 $b$ 时取 1，否则取 0，记作 $\delta_{b, x_i}$ [【跳转到 02:16】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=136)。

![指示矩阵：序列 ACGTA 被写成一个 4 行 5 列的 0/1 矩阵，行是四种碱基，列是位置](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00191.webp)

以序列 `ACGTA` 为例：第 1 列在 A 行放 1（因为第一个碱基是 A），第 2 列在 C 行放 1，以此类推。看起来有点吓人，但它只是"把一条序列翻译成矩阵"的机械操作 [【跳转到 03:06】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=186)。

### 3.2 计数矩阵就是把指示矩阵加起来

有了指示矩阵，计数矩阵 $C_{b,i}$ 的定义就非常自然：**把所有序列的指示矩阵逐元素相加** [【跳转到 03:11】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=191)。

$$
C_{b,i} = \sum_{j=1}^{N} \delta_{b,\,x_j[i]}
$$

含义就是"在位置 $i$ 上，碱基 $b$ 出现了几次"。视频给的例子：若第一列有 3 个 A、2 个 G，这一列就是 $(3, 0, 0, 2)$；第二列全是 C，第三列全是 G [【跳转到 03:39】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=219)。

### 3.3 归一化得到频率矩阵

把计数矩阵**按列归一化**（每列求和，再让每个元素除以该列的和），就得到频率矩阵：

$$
f_{b,i} = \frac{C_{b,i}}{\sum_{b' \in \{A,C,G,T\}} C_{b',i}}
$$

![计数矩阵与频率矩阵：C 数出现次数，按列归一化后得到 f，每列加起来为 1](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00244.webp)

到这里，motif 模型就估出来了。**这一步和 n-gram 的最大似然估计一模一样**：都是"数出现次数、再除以该上下文的总次数"。区别只在轴——n-gram 沿着**序列方向**数"前一个词后面跟什么"，PSSM 沿着**位置方向**数"第 $i$ 个位置是什么碱基"。

## 四、打分：为什么用似然比而不是概率

### 4.1 直接比概率不行：长度和背景会捣乱

有了 $P(x\mid M)$ 和 $P(x\mid R)$，最直觉的打分是"这条序列在 motif 模型下概率多大"。但视频的做法是取**两者的比值的对数**——对数似然比（log likelihood ratio） [【跳转到 04:04】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=244)：

$$
S(x) = \log \frac{P(x \mid M)}{P(x \mid R)}
$$

把两边的连乘代进去，再用"对数的乘积等于乘积的对数"这条性质，连乘就变成了求和：

$$
S(x) = \log \frac{\prod_{i=1}^{k} f_{x[i],\,i}}{\prod_{i=1}^{k} p_{x[i]}} = \sum_{i=1}^{k} \log \frac{f_{x[i],\,i}}{p_{x[i]}}
$$

![对数似然比：S(x) 是 motif 概率与随机模型概率之比的对数，连乘在对数下变成求和](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00269.webp)

这个变形是整支视频的技术核心。它带来两个好处：

1. **打分变成查表相加**。每个位置、每种碱基的贡献可以预先算好存成一张表，给新序列打分时只需"按位置查格子、把数加起来"，O(k) 时间。
2. **分数有了可解释的零点**。比值为 1（对数 0）意味着"这个位置对 motif 和随机序列一样偏爱"；正分意味着"更像 motif"，负分意味着"更像随机序列"。

### 4.2 PSSM 就是那张预先算好的表

被求和的那一项，就是 PSSM 的元素（也叫权重矩阵，weight matrix）：

$$
W_{b,i} = \log \frac{f_{b,i}}{p_b}
$$

于是给序列 $x$ 打分就是**挑出对应的那些格子加起来**。视频的例子：序列 `CGTAAGGT` 的分数是

$$
S(x) = W_{C,1} + W_{G,2} + W_{T,3} + W_{A,4} + W_{A,5} + W_{G,6} + W_{G,7} + W_{T,8}
$$

![PSSM 元素定义与逐位置求和：W(b,i)=log(f(b,i)/p(b))，序列分数是各位置权重之和](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00319.webp)

用前面定义的指示矩阵，这件事还能写得更紧凑：

$$
S(x) = \sum_{i} \sum_{b} \delta_{b,\,x[i]} \, W_{b,i}
$$

也就是"指示矩阵与权重矩阵逐元素相乘再求和"——本质上是一次矩阵内积。视频说，无论哪种写法，**分数的含义都是"这条序列是 motif 而不是随机序列的对数似然比"** [【跳转到 05:44】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=344)。

### 4.3 和 n-gram 计数的对应关系

把两套记号并排放，结构完全同构：

| 步骤 | n-gram 语言模型 | PSSM / motif |
| --- | --- | --- |
| 数什么 | 词对 $(w_{n-1}, w_n)$ 出现次数 | 位置 $i$ 上碱基 $b$ 出现次数 |
| 归一化分母 | 前一个词的计数 $C(w_{n-1})$ | 该列计数之和 $\sum_b C_{b,i}$ |
| 得到 | 条件概率 $P(w_n \mid w_{n-1})$ | 位置频率 $f_{b,i}$ |
| 打分 | 对数概率相加 $\sum \log P$ | 对数似然比相加 $\sum \log(f_{b,i}/p_b)$ |
| 零计数怎么办 | 平滑 / 回退 / 插值 | 伪计数（pseudocount） |

两条轴不同（一条沿序列位置、一条沿碱基种类），但**"计数 → 归一化 → 取对数 → 求和"**这套骨架是同一个东西。理解了 n-gram，PSSM 只是换了个方向的计数表。

## 五、在 Biopython 里跑通

### 5.1 造 motif、看计数

视频给了一段可以直接复现的代码 [【跳转到 06:07】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=367)：

```python
from Bio.Seq import Seq
from Bio import motifs

sites = [Seq('ACGTA'), Seq('TCGTA'), Seq('ACGAA'), Seq('ACGTG'), Seq('TCGAG')]
motif = motifs.create(sites)

print(motif.counts)          # 计数矩阵，列是零基位置
print(motif.degenerate_consensus)   # 简并一致序列，如 WCGWR
```

![Biopython 打印的计数矩阵：A/C/G/T 四行、5 列，以及简并一致序列 WCGWR](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00417.webp)

打印出来的计数矩阵与手算的一致，只是列号从 0 开始而不是从 1 开始。`degenerate_consensus` 给出的是简并码版本（`WCGWR`），也就是前面说的"每个位置一个字母、模糊处用 IUPAC 码"的经典表示。

### 5.2 看 PSSM：注意那些负无穷

```python
W = motif.pssm
print(W)
print(len(motif.consensus))   # k = motif 长度
print(motif.consensus)        # 非简并的一致序列，如 ACGTA
```

![motif.pssm 的输出：计数为 0 的格子变成了 -inf，因为 log 0 无定义](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00467.webp)

这里出现了一个必须正视的现象：**计数为 0 的格子，权重是 $-\infty$**。原因很直白——$f_{b,i}=0$ 时 $\log(f_{b,i}/p_b)$ 就是负无穷（无定义）。

和 n-gram 的零概率完全一样，这是**稀疏性**的直接后果：5 条序列、每个位置最多只能看到 4 种碱基中的少数几种，大量格子必然是 0。后果也一样严重：只要待打分序列在某个位置上踩到一个 $-\infty$，总分就是 $-\infty$，这条序列被判"绝不可能是 motif"。

### 5.3 扫描一条 DNA：`W.search`

```python
for i, score in W.search(DNA):
    print(i, score, DNA[i:i+k])
```

`W.search` 会滑动窗口，把每个长度为 $k$ 的 k-mer 都打一个分。视频里加了阈值过滤，只打印超过阈值的位点 [【跳转到 07:47】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=467)。

### 5.4 负位置与反向链

打印结果里会出现**负的位置编号**。这不是 bug：它们表示匹配落在 DNA 的**反向链（reverse strand）**上，位置按 Python 的负数索引从末尾数起 [【跳转到 08:12】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=492)。

视频举的例子很能说明问题：motif 的一致序列在第 2、3 位（零基的 1、2 位）有 `CG`，而反向链上与之配对的 k-mer 是它的**反向互补（reverse complement）**。所以要写一个 if 分支：

```python
for i, score in W.search(DNA):
    if i < 0:
        print(len(DNA) - i, score, DNA[i:i+k].reverse_complement(), '-')  # 反向链
    else:
        print(len(DNA) - i, score, DNA[i:i+k], '+')                       # 正向链
```

![修正后的输出：位置换算到正向坐标，并多出一列标出链方向（+ / -）](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00644.webp)

视频还现场核对了一个位点：位置 11 对应的序列确实以反向链的形式匹配上了。**做 motif 扫描时永远要同时考虑两条链**，这是生物序列特有的"方向对称"。

### 5.5 伪计数：把 $-\infty$ 变成有限的数

最后一步是修掉那些负无穷。办法就是 n-gram 里的**平滑**，在这里叫**伪计数（pseudocount）**：在定义频率矩阵时给每个格子加一个常数，再用这个频率矩阵去算权重矩阵 [【跳转到 10:37】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=637)。

$$
f_{b,i} = \frac{C_{b,i} + c}{\sum_{b'} \left(C_{b',i} + c\right)}
$$

最简单的选择是 $c = 1$，也就是加一平滑。视频说这是"最朴素的选择"，还有更精细的做法留到以后讲 [【跳转到 10:49】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=649)。

```python
motif.pseudocounts = 1
W = motif.pssm          # 重新定义 PSSM，不再有 -inf
```

![加入伪计数后的扫描结果：不再有负无穷，命中位点变多，原来的位点仍然是最高分](assets/位置权重矩阵（PSSM）：把%20motif%20的计数表变成打分矩阵/00688.webp)

效果非常直观：**权重矩阵里不再有负无穷，命中位点数量大幅增加**。原来的那些位点仍然在，而且分数最高；但周围多出了一大批分数较低的候选——因为模型不再把"没见过"当成"绝不可能" [【跳转到 11:28】](https://www.youtube.com/watch?v=ontjFJNOlMY&t=688)。

## 小结

- **背景模型**是 PSSM 的分母：它只由四个单核苷酸频率定义，没有位置概念，描述"随机序列"。
- **motif 模型**是一张"碱基 × 位置"的概率表，它打破的正是背景模型"位置无关"的假设。
- **计数矩阵**可以由指示矩阵逐元素相加得到；**频率矩阵**是计数矩阵按列归一化的结果——这与 n-gram 的最大似然估计是同一套计数逻辑。
- **打分必须用对数似然比**：$\log P(x\mid M) - \log P(x\mid R)$，把连乘变成求和，每个位置贡献一格权重 $W_{b,i}=\log(f_{b,i}/p_b)$，序列分数就是这些格子之和。
- **零计数会变成 $-\infty$**，一条序列踩到就彻底出局；这正是 n-gram 里"零概率毁掉整句概率"的同构问题。
- **伪计数（平滑）**把 $-\infty$ 换成有限值，代价是命中变多、特异性下降——和 add-k 平滑的取舍一模一样。
- **扫描时别忘了反向链**：负位置对应反向链上的反向互补匹配，报告位点时要换算坐标并标注链方向。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| motif | 序列中反复出现、被认为有功能的短模式，如转录因子结合位点 |
| 一致序列（consensus） | 每个位置只取最常见碱基的表示，模糊处用 IUPAC 简并码 |
| 背景模型（background model） | 由 $p_A,p_C,p_G,p_T$ 定义的随机序列模型，无位置特异性 |
| 指示矩阵（indicator matrix） | 把一条序列写成 4×k 的 0/1 矩阵，标出每个位置的碱基 |
| 计数矩阵 $C_{b,i}$ | 位置 $i$ 上碱基 $b$ 出现的次数，等于各指示矩阵之和 |
| 频率矩阵 $f_{b,i}$ | 计数矩阵按列归一化后的概率表，每列和为 1 |
| 对数似然比 | $\log\frac{P(x\mid M)}{P(x\mid R)}$，衡量"更像 motif 还是更像随机序列" |
| PSSM / 权重矩阵 $W_{b,i}$ | $\log(f_{b,i}/p_b)$，给序列打分时按位置取格子求和 |
| 伪计数（pseudocount） | 给计数加常数以避免 $\log 0$，等价于 n-gram 里的平滑 |
| 反向链（reverse strand） | DNA 双链的另一条，motif 可能以反向互补形式出现 |
