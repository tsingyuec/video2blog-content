# 选择性扫描：为什么 Mamba 必须放弃卷积形式

> 视频来源：[Mamba 和 S4 解读：架构、并行扫描、内核融合、循环、卷积、数学](https://www.bilibili.com/video/BV1G2421c7vL/)（B 站 · 竹言见智，Umar Jamil 视频的中配版 · 时长约 74 分钟）
> 这是一支**逐公式推导**的视频：从"兔子繁殖"的一阶微分方程开始，一路推出离散递推、卷积核、HiPPO 矩阵，最后落到 Mamba 的算法伪代码——左边是 S4 的时不变版本，右边是 S6 的时变版本，两者只差三行，却决定了"能不能用卷积"。本文按同一条推导线走一遍，重点讲清**选择性为什么会让卷积失效、以及扫描如何补回来**。

## 本讲要解决的核心问题（SCQA）

**背景**：状态空间模型（SSM）把序列建模写成一个线性时不变系统：$h_t = \bar{A}h_{t-1} + \bar{B}x_t$，$y_t = Ch_t$。因为它时不变（参数不随 $t$ 变），同一个系统有两种等价算法：**递推**（一次一步，推理友好）和**卷积**（预先算出一个核 $\bar{K}=(C\bar{B}, C\bar{A}\bar{B}, \dots)$，一次并行卷完，训练友好）。

**冲突**：S4 这类模型在长程合成任务上很强，但在语言模型上打不过 Transformer。原因不在"记不住"，而在"不会挑"：参数对每个 token 都一样，模型无法根据内容决定"这个 token 该记、那个 token 该忘"。Mamba 的解法是让 $\bar{B}, C, \Delta$ 都变成输入 $x_t$ 的函数——可这一改，**核 $\bar{K}$ 就不再固定**，卷积形式当场失效。

**疑问**：训练必须并行，而卷积是唯一现成的并行算法。既然卷积没了，Mamba 靠什么在 GPU 上并行训练一个"每步参数都不同"的递推？

**回答（中心思想）**：靠**扫描（scan）**。递推 $h_t = a_t h_{t-1} + b_t$ 本质上是一次"带系数的前缀和"，而前缀和的运算符满足**结合律**，因此可以用树形并行扫描把关键路径从 $O(N)$ 压到 $O(\log N)$。Mamba 的全部工程工作就是把这次扫描做得足够快：把状态留在 SRAM 里（内核融合）、反向传播时不缓存中间状态而是重算（重计算）。**选择性换来的是表达能力，扫描负责把代价补回来**。

## 一、先看三条老路，再看理想模型长什么样

视频开头把序列模型的目标说得很清楚：把输入序列映射到输出序列。输入可以是连续信号（音频），也可以是离散符号（文本）；实际上连音频也是采样后的离散信号。做这件事的模型有三类，各有各的病：

| 模型 | 训练并行 | 每 token 推理代价 | 上下文 | 硬伤 |
| --- | --- | --- | --- | --- |
| RNN | 不能（要等上一步） | 恒定 | 理论无限 | 梯度消失/爆炸 |
| CNN | 能 | 恒定 | 受核大小与层数限制 | 长距离依赖要堆很多层 |
| Transformer | 能 | 随已生成长度增长（KV cache 变大） | 受窗口限制 | 训练算力 $O(N^2)$ |

于是理想模型的条件是三条同时成立：**像 Transformer 一样并行训练**、**像 RNN 一样线性扩展**、**每 token 推理代价恒定**。讲者说，状态空间模型正是冲着这三条去的。

## 二、从微分方程到离散递推：$\Delta$ 是学出来的

视频用"兔子繁殖"引入：兔子数量以恒定速率 $\lambda$ 增长，增长量与当前数量成正比，于是

$$
\dot{B}(t) = \lambda B(t)
$$

解是 $B(t)=K e^{\lambda t}$（$K$ 为初始数量）。验证方法就是把它代回去，两边相等。

状态空间模型的形式完全一样，只是把标量换成矩阵、并加上输入项：

$$
h'(t) = A h(t) + B x(t),\qquad y(t) = C h(t) + D x(t)
$$

它**线性**（关系是线性的）且**时不变**（$A,B,C,D$ 不随 $t$ 变）。要算输出，得先解这个微分方程；但解析求解很难，而且计算机处理的是离散信号，所以要做**离散化**：只在 $t=0,1,2,\dots$ 上求近似值，步长就是 $\Delta$。

讲者用高中导数的定义推了一遍欧拉法：$f(t+\Delta)\approx f(t)+\Delta f'(t)$，代入 $h'=Ah+Bx$ 并合并同类项，得到

$$
\bar{A} = I + \Delta A,\qquad \bar{B} = \Delta B,\qquad
h_t = \bar{A}h_{t-1} + \bar{B}x_t
$$

这就是离散后的递推公式，和兔子问题的循环公式一模一样。

[【跳转到 13:20】](https://www.bilibili.com/video/BV1G2421c7vL/?t=800)

他特别说明：**Mamba 论文实际用的是零阶保持（ZOH）而不是欧拉法**，因为 ZOH 近似更好；但离散化的思路相同——不去解析求解，而是近似求出离散时刻的状态，再代入输出方程。

关键的一句：**实践中我们不自己选 $\Delta$，而是把它当参数用梯度下降学出来**。这句话是后面"选择性"的伏笔：既然 $\Delta$ 可以是参数，那它也可以是**输入的函数**。

## 三、循环适合推理，卷积适合训练

![卷积形式：输出 y_k 可以写成一个核 K̄ 与输入 x 的卷积](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/01750.webp)

把递推一步步展开（设初始状态为零）：

$$
y_0 = C\bar{B}x_0,\quad
y_1 = C\bar{A}\bar{B}x_0 + C\bar{B}x_1,\quad
y_2 = C\bar{A}^2\bar{B}x_0 + C\bar{A}\bar{B}x_1 + C\bar{B}x_2,\ \dots
$$

规律很明显：$y_k=\sum_{j\le k} C\bar{A}^{k-j}\bar{B}\,x_j$。这正是**卷积**，核为

$$
\bar{K} = (C\bar{B},\; C\bar{A}\bar{B},\; C\bar{A}^2\bar{B},\; \dots)
$$

![构造卷积核：核反向排列后与填充过的输入做滑动相乘](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/01825.webp)

讲者现场把核反转、给输入左侧补零，然后一步步滑动验证：第一个输出只有 $C\bar{B}x_0$（前面没有 token），第二个是 $C\bar{B}x_1 + C\bar{A}\bar{B}x_0$，与公式完全对上。

于是得到 SSM 的**双形式**：

- **卷积形式**：所有输出 $y_k$ 互不依赖，可以全并行算，适合**训练**；代价是要先构造长度为 $N$ 的核，计算和内存都不便宜。
- **递推形式**：一次一步，每 token 代价恒定，适合**推理**。

这正是 SSM 相对于 RNN 的核心优势：RNN 只有递推，所以训练只能串行；SSM 时不变，所以训练可以走卷积。

## 四、向量输入：每个维度一个独立的 SSM

语言模型的输入是向量（Transformer 里 512 维，Llama 里 4096 维），而上面的推导都是标量。处理办法是：**输入向量的每个维度由一个独立的状态空间模型管理**，彼此不通信。这和多头注意力把 512 维切成 8 个头、每头 64 维、各头独立计算是同一个思路。

于是参数形状变成（记 $B$ 为批量、$L$ 为序列长度、$D$ 为模型维度、$N$ 为状态维度）：

| 参数 | 形状 | 含义 |
| --- | --- | --- |
| $A$ | $(D, N)$ | 每个维度一个 $N$ 维状态，决定历史如何向前搬 |
| $B$ | $(D, N)$ | 输入如何写进状态 |
| $C$ | $(D, N)$ | 状态如何读成输出 |
| $\Delta$ | $(D)$ | 每个维度一个离散步长 |

![S4 的算法伪代码：A/B/C/Δ 都是固定参数，第 6 行注明 "Time-invariant: recurrence or convolution"](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/02819.webp)

## 五、$A$ 矩阵为什么重要，以及 HiPPO 是什么

讲者强调 $A$ 是"捕获过去状态信息的矩阵"：它决定历史如何沿时间传递，也决定系统的稳定性（不稳定则输出发散）。$h_t$ 本质上压缩了模型到目前为止看到的全部输入，所以 $A$ 的结构直接决定"历史能不能被好好保存"。

HiPPO 的直觉借自傅里叶变换：傅里叶把信号分解成一堆正弦基，HiPPO 则用勒让德多项式做基，用它们来近似地表征"到目前为止的整段输入信号"。效果是：**重建信号时，最近的时刻近似得很好，越早的时刻越模糊**——这非常像指数移动平均，正好符合语言模型的需要（局部上下文要准，远处信息可以衰减）。S4 的做法就是**用 HiPPO 矩阵初始化 $A$**，性能立刻大幅提升。

## 六、两个任务暴露固定线性系统的死穴

Mamba 论文用两个玩具任务说明"时不变"不够用：

**选择性复制（selective copying）**。输入是蓝、白、白、橙、红、绿这样的 token 序列，模型只需输出彩色 token、跳过白色。普通 SSM 做不到：参数对每个 token 相同，它没法区分"蓝色"和"白色"，也就没法"忽略白色、保留蓝色"。讲者的类比很形象：**给一条推文做脏话过滤**——你希望模型看到脏词就丢掉、看到正常词就保留，而固定参数做不到"看内容下菜"。

**归纳头（induction head）**。模型需要"看到黑色 token 就回忆之前出现过什么、输出对应的蓝色 token"。这要求模型能按内容检索历史，而不是按位置衰减——同样超出了时不变系统的能力。

从循环视角看，$A,B$ 对每个 token 相同，所以"上下文动态"无法选择性地从当前上下文里取信息；从卷积视角看，卷积能学会"时间平移"（所以普通复制任务能做），但学不会"按内容筛选"（所以选择性复制做不了）。

## 七、选择性：让 $B, C, \Delta$ 变成输入的函数

![S4（Algorithm 1）与 Mamba/S6（Algorithm 2）的逐行对比：B、C、Δ 从固定参数变成 (B, L, N) 的张量](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03019.webp)

这张幻灯片是本小节的核心。左右两栏的伪代码几乎一样，差别只有三行：

| 项目 | Algorithm 1（S4） | Algorithm 2（S6，Mamba） |
| --- | --- | --- |
| $B$ | $(D,N)$，参数 | $(B,L,N)$，由 $s_B(x)=\mathrm{Linear}_N(x)$ 生成 |
| $C$ | $(D,N)$，参数 | $(B,L,N)$，由 $s_C(x)=\mathrm{Linear}_N(x)$ 生成 |
| $\Delta$ | $(D)$，参数 | $(B,L,D)$，由 $\tau_\Delta=\mathrm{softplus}$ 作用在 $s_\Delta(x)$ 上 |
| 离散化后 | $\bar{A},\bar{B}$ 形状 $(D,N)$ | $\bar{A},\bar{B}$ 形状 $(B,L,D,N)$ |
| 算法 | 时不变：**递推或卷积** | 时变：**只能递推（scan）** |

注意 $\Delta$ 那一行：它先用一个线性层把 $D$ 维输入投影成 1 维（$\mathrm{Broadcast}_D(\mathrm{Linear}_1(x))$），再过 softplus 保证为正。**$\Delta$ 因此成了"每个 token 一个数"的开关**：$\Delta$ 大，$\bar{A}=e^{\Delta A}$ 衰减得快，模型倾向于"重置状态、关注当前输入"；$\Delta$ 小，状态几乎原样保留，模型倾向于"记住历史"。这就是"选择性"最直观的解释——**用输入决定记忆的保留时长**。

同时 $B$ 决定"写什么进状态"、$C$ 决定"从状态里读什么"，两者都随 token 变化，于是模型可以做到"看到关键词才写入、看到无关词就不写"。

## 八、卷积失效之后：扫描 + 三项工程

### 8.1 为什么卷积必然失效

卷积成立的前提是核 $\bar{K}=(C\bar{B}, C\bar{A}\bar{B}, \dots)$ **对所有位置相同**。现在 $B, C, \Delta$ 每个 token 都不一样，$\bar{A}$ 也跟着变，于是每个位置都需要**自己的核**——卷积形式不复存在，只能回到递推。这就是伪代码第 6 行那句 "Time-varying: recurrence (scan) only"。

### 8.2 递推 = 扫描，扫描可以并行

![扫描就是前缀和：初始数组 9,6,7,10,8,7 的前缀和是 9,15,22,32,40,47](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03169.webp)

讲者用竞赛编程里的**前缀和**引入扫描：每个位置的值由"前一个已算出的值 + 当前输入"得到。SSM 的递推正是这种结构：$h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t$。

![并行扫描的树形结构：多线程同时做二元运算，复杂度从 O(N) 降到 O(N/T)](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03340.webp)

看起来天生串行，但只要运算是**结合的**（$(a*b)*c = a*(b*c)$），就能并行：开多个线程同时算相邻元素的和，再对结果并行求和，一层层向上（up-sweep），最后再向下（down-sweep）补齐中间值。复杂度从 $O(N)$ 降到 $O(N/T)$，$T$ 是并行线程数；关键路径长度是 $O(\log N)$。

### 8.3 内核融合：把中间状态留在 SRAM

![GPU 内存层次：DRAM（GB 级，相对慢）→ SRAM（MB 级，相对快）→ 计算单元](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03490.webp)

讲者给出 A100 的量级：算力约 20 TFLOP/s（32 位），HBM 带宽约 2 TB/s——**算比搬快约 40 倍**。所以很多内核慢不是因为算得多，而是因为搬得多，这叫 **IO 受限**。

![内核融合：把三个连续算子合成一个 CUDA 内核，中间结果不再往返 HBM](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03785.webp)

普通框架执行三个连续算子时，每个算子都要"HBM→SRAM→算→写回 HBM"，三次往返把时间全占了。**内核融合**把三个算子合成一个自定义 CUDA 内核：参数（$\Delta, A, B, C$）从 HBM 加载进 SRAM 后，**离散化、扫描、输出投影全在 SRAM 里完成**，只把最终结果写回 HBM。

### 8.4 重计算：不存激活，反向时再算

![论文原话：中间状态不存储，而是在反向传播、输入从 HBM 载入 SRAM 时重新计算](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/03985.webp)

反向传播需要前向的中间激活，缓存它们意味着写 HBM、再读回来；而 GPU 算得快、搬得慢，所以**重算比搬运便宜**。Mamba 因此不保存中间状态，反向时重算。论文的说法是：这样融合后的选择性扫描层，内存需求和用了 FlashAttention 的优化版 Transformer 相当。

## 九、Mamba 块与整体架构

![Mamba 块：线性投影 → 卷积 → SiLU → SSM（并行扫描）→ 逐元素相乘 → 线性投影，旁支是门控](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/04085.webp)

一个 Mamba 块的结构（讲者对照代码讲的）：

1. 两个线性层把 $d_{model}$ 投影到 $d_{inner}$（通常取 $d_{model}$ 的若干倍）；
2. 一条分支上做**短卷积**：因为 SSM 在每个维度上独立运行，需要卷积把相邻 token 混一混；
3. 过 SiLU 激活；
4. 进 SSM，用**并行扫描**跑递归；
5. 与另一条分支做**逐元素相乘**（门控，类似 Gated MLP）；
6. 线性层投影回 $d_{model}$。

整模型就是把这个块堆 $n$ 层，块外加 RMS Norm 和残差，最后接 RMS Norm + 线性层 + softmax 输出词表分布——和 Llama/Mistral 的骨架几乎一样。

## 十、结果与局限

![左：选择性复制准确率，S4 18.3%、S6 97.0%、Mamba 99.8%；右：归纳头外推，Mamba 在 10⁶ 长度上仍保持 1.0](assets/选择性扫描：为什么%20Mamba%20必须放弃卷积形式/04235.webp)

- **选择性复制**：S4 只有 18.3%，换成 S6 层立刻到 97.0%，完整 Mamba 到 99.8%。同一架构换一层，差距就是"能不能按内容选择"。
- **归纳头外推**：训练长度 $2^8=256$，测试长度一路加到 $2^{20}$。MHA（绝对位置编码、RoPE、xPos）、H3、Hyena 的准确率在超过训练长度后迅速掉到 0，Mamba 始终保持在 1.0。
- **缩放曲线**：达到同样困惑度所需的算力与最好的 Transformer 接近，但长序列上扩展性更好。

讲者也讲了局限：Mamba 仍然是循环网络，仍然像循环一样运行；它在 Llama/Mistral 那个数据量级上的表现还没有被验证。他做这支视频的动机是"不喜欢只扔公式"，所以把每个公式都推了一遍。

## 小结

- SSM 从连续系统 $h'=Ah+Bx$ 出发，离散化后得到 $h_t=\bar{A}h_{t-1}+\bar{B}x_t$；$\Delta$ 是**学出来的**参数，不是人选定的常数。
- 时不变 SSM 有两种等价算法：**递推**（推理，代价恒定）与**卷积**（训练，全并行），卷积核为 $\bar{K}=(C\bar{B}, C\bar{A}\bar{B}, \dots)$。
- 向量输入下，每个维度一个独立 SSM；参数形状为 $A,B,C\in(D,N)$、$\Delta\in(D)$。
- $A$ 决定历史如何传递与系统是否稳定，S4 用 **HiPPO 矩阵**初始化它，使状态对近期信息近似得好、对远期信息自然衰减。
- 固定参数的系统无法"按内容选择"，在**选择性复制**和**归纳头**上失败——这是 Mamba 的动机。
- Mamba 让 $B, C, \Delta$ 成为输入的线性函数，形状从 $(D,N)$ 变成 $(B,L,N)$；$\Delta$ 经 softplus 保证为正，充当"记忆保留时长"的开关。
- 一旦时变，核不再固定，**卷积失效**，只剩递推；但递推等于扫描，扫描因结合律可并行到 $O(\log N)$ 关键路径。
- 工程三件套：**并行扫描**（并行化）、**内核融合**（把状态留在 SRAM）、**重计算**（不缓存激活），使训练内存与 FlashAttention 版 Transformer 相当。
- 结果：选择性复制 99.8%、归纳头外推到 $10^6$ 长度不掉点；局限是仍是循环结构，超大规模数据上的表现待验证。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 时不变（time-invariant） | 参数 $A,B,C,D$ 不随时刻变化，因此同一核可作用于所有位置 |
| 离散化（discretization） | 把连续微分方程近似成离散递推，步长 $\Delta$ 决定近似精度 |
| 零阶保持（ZOH） | 一种比欧拉法更精确的离散化方式，假设区间内输入恒定，Mamba 采用它 |
| $\bar{A},\bar{B}$ | 离散化后的参数；ZOH 下 $\bar{A}=e^{\Delta A}$，$\Delta$ 越大衰减越快 |
| 卷积形式 | $y=x*\bar{K}$，核固定时可全并行，用于训练 |
| 递推形式 | $h_t=\bar{A}h_{t-1}+\bar{B}x_t$，逐 token 计算，用于推理 |
| 选择性（selection） | 让 $B,C,\Delta$ 随输入变化，使"写什么、读什么、记多久"由内容决定 |
| 扫描（scan） | 带系数的前缀和运算，SSM 递推是它的特例 |
| 结合律 | $(a*b)*c=a*(b*c)$，是扫描可并行的充分条件 |
| 内核融合 | 把多个算子合成一个 CUDA 内核，避免中间结果往返 HBM |
| IO 受限 | 算法耗时由数据搬运而非计算决定 |
| 重计算 | 反向传播时重新前向计算激活，以省显存换少量算力 |
| HiPPO | 用正交多项式基构造 $A$ 矩阵，使状态能近似重建输入历史 |
