# Mamba 的选择性递归：权重随输入变化，并行扫描把递推压到 log n

> 视频来源：[Mamba 原理解析](https://www.bilibili.com/video/BV1NbjMzWEEV/)（B 站 · NeuroHacks · 时长约 32 分钟）
> 这支视频不讲微分方程，而是**从 RNN 的视角**把 Mamba 拆开：先证明"线性递归 = 一种叫扫描（scan）的运算，可以并行算到 log n"，再指出线性递归在语言建模上输给 Transformer 的**唯一**原因是"权重不能随输入变化"，最后用"权重由输入生成"一句话把选择性（selectivity）讲完，并顺带解释了 16 倍扩宽为何几乎免费、以及 ICLR 2024 拒稿争议。

## 本讲要解决的核心问题（SCQA）

**背景**：Transformer 的算力随序列长度平方增长，RNN 的算力线性增长但训练时必须一步等一步。所有人都知道"想要 Transformer 的并行 + RNN 的线性"，线性 RNN（把循环里的神经网络换成线性函数）看起来就是答案：它的递推可以写成一个**结合律**运算，于是能用并行扫描在 $\log n$ 步内算完。

**冲突**：线性 RNN 在 Long Range Arena 这类长程合成任务上确实拿了 SOTA，甚至比 Transformer 高约 30%，可一到**语言建模**就全线落后——图上的困惑度曲线里，所有线性模型（Hyena、RWKV、RetNet、H3）都在 Transformer 下方（越低越好，它们更差）。算得快、记得久，却写不好语言。

**疑问**：一个能记住几十万步的模型，为什么连"该记什么、该忘什么"都做不到？把递推算快了，为什么反而不如平方复杂度的注意力？

**回答（中心思想）**：因为线性递归的**权重矩阵是固定的**，它对每个 token 一视同仁，只能"均匀地记"或"均匀地忘"，无法根据内容决定保留谁。Mamba 的全部创新就是把这一步权重**变成输入的函数**：$w_j$ 由当前输入 $x_j$ 生成，于是模型可以"看到关键词就记住、看到噪声就清零"。代价是参数随时间步变化、**卷积形式失效**，只能回到递推——但因为递推本身等价于扫描，仍能用并行扫描算到 $\log n$，再配合内核融合把中间状态留在片上，速度反而更快。

## 一、先看清两条老路各自的短板

![线性递归层的算子：第 i 个输出等于前一个输出乘 W_y 加上当前输入乘 W_x](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00423.webp)

视频从三个模型讲起，每个模型的"病"都写在它的计算图里：

| 模型 | 训练能否并行 | 每 token 推理代价 | 上下文 |
| --- | --- | --- | --- |
| RNN | 不能（必须等上一步输出） | 恒定 | 理论无限，实际只有几十步 |
| CNN | 能 | 恒定 | 受卷积核与层数限制 |
| Transformer | 能 | 随已生成长度线性增长 | 受窗口限制，训练算力平方 |

[【跳转到 02:30】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=150)

线性递归层的算子只有一行：

$$
y_i = W_y\,y_{i-1} + W_x\,x_i
$$

其中 $W_y$ 是"如何把历史搬过来"的权重矩阵，$W_x$ 作用在每个输入上、可以并入前一层，所以可以简写成"上一步输出 + 当前输入"。讲者强调：**把循环里的非线性换成线性，恰好同时解决了 RNN 的两个老问题**——并行化和训练稳定性。非线性并没有丢，因为可以像 Transformer 一样，在递归层之间插入逐元素（element-wise）的全连接网络来补足。

## 二、线性递归 = 扫描：结合律是并行的许可证

![扫描的最简单例子：输入 7,3,15,1,5,8,20,4 的累加和](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00473.webp)

要并行化递推，先看一个更简单的问题：**累加和（prefix sum）**。给定 $n$ 个数，输出第 $i$ 项是前 $i$ 项之和。

![并行累加和的结果：7,10,25,26,31,39,59,63](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00498.webp)

顺序相加是 $O(n)$ 步。并行做法是**步长翻倍**：先把相邻两个数相加，再把相隔两个的项相加，然后相隔四个、八个……每轮步长翻倍，$\log n$ 轮之后每个位置就累积了它之前的全部项。每轮内部的所有加法互不依赖，可以同时做；轮与轮之间必须顺序执行，所以总深度是 $\log n$。如果你有 $n$ 个进程，总时间从 $n$ 降到 $\log n$。

[【跳转到 08:18】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=498)

![结合律：3+7+2 无论先算哪两个，结果都是 12](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00623.webp)

这个技巧成立的唯一条件是**运算符满足结合律**：$(a\circ b)\circ c = a\circ(b\circ c)$，括号怎么打结果都一样。加法满足，所以累加和能并行。

关键一步：把"数"换成"矩阵 + 向量"的**对（pair）**，定义运算符

$$
(A_1, x_1)\circ(A_2, x_2) = (A_2A_1,\; A_2x_1 + x_2)
$$

它同样满足结合律（把几项按不同顺序展开即可验证），而对它做扫描，得到的就是线性递归层的输出。于是**线性递归被翻译成了一次并行扫描**，$\log n$ 时间即可算完。

## 三、扫描的隐藏账单：每步一次 $d\times d$ 矩阵乘法

![对角化：W = P D P⁻¹，D 是对角矩阵](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00773.webp)

上面那个运算符有个代价：它把元组的第一个元素当作"累积矩阵"，也就是到目前为止所有矩阵的乘积，于是**每一步都要做一次 $d\times d$ 乘 $d\times d$ 的矩阵乘法**，即 $O(d^3)$。而原始的顺序 RNN 每步只做"矩阵乘向量"，是 $O(d^2)$。在标准模型规模下，这很容易慢上一千倍。

[【跳转到 12:03】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=723)

解法是**对角化**：几乎所有方阵都能写成 $W = PDP^{-1}$，其中 $D$ 是对角矩阵。对角矩阵自乘只需把对角线元素各自取幂，$P^{-1}$ 与 $P$ 两两抵消，于是 $O(m^3)$ 变成 $O(m)$。落到实现上：

1. 先用一个复矩阵 $P$ 变换输入；
2. 用**复数权重向量** $w$ 做**逐元素**乘法的线性递归（不需要矩阵乘法）；
3. 再用 $P^{-1}$ 变换回输出。

实际实现里不会真的去算矩阵逆（太慢），而是用两个独立的复矩阵分别放在递归前后；输出因此可能是复数，传给下一层前取实部即可。这让模型比实值线性 RNN 更有表现力，但也不再严格等价于实值递归。

## 四、第二个老问题：梯度只剩 $w^{n-1}$

![梯度推导：输入都设为零后，第 n 步输出是 w 的 n 次方乘 x₁](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/00998.webp)

为了看清 RNN 为什么难训，讲者把输入都设为零，只看递归本身：经过 $n$ 步，输出等于 $w^n x_1$；给权重加一个极小的扰动再算一次，差值正比于 $w^{n-1}x_1$。

于是**梯度的大小完全由 $w^{n-1}$ 决定**：$|w|>1$ 时指数爆炸，一次更新就把已有功能摧毁；$|w|<1$ 时指数消失，网络什么也学不到。普通深度网络没有这个问题，因为每层权重不同——有的层小于 1、有的层大于 1，只要整体梯度量级稳定，就有大量"稳定配置"可选。而 RNN 每一步共用同一个权重，**只有 $w=1$ 这一种稳定配置**。

[【跳转到 17:03】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=1023)

![复数极坐标参数化：模 a、角 b，把模限制在 (0,1) 内](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01172.webp)

线性 RNN 论文的对策是**把初始化钉在稳定点上**：用极坐标 $a e^{ib}$ 参数化权重（$a$ 是模、$b$ 是角），让 $a$ 经过一个把输出压到 $(0,1)$ 的函数，使初始化时 $|w|$ 非常接近 1；再把输入乘以一个初始化为极小值的学习参数 $\Delta$，保证初始化阶段输入不会扰动递归。训练开始后不保证一直稳定，但实践表明，仅靠这样的初始化就足以让模型在几十万步的尺度上学习记忆。

## 五、状态空间模型其实就是线性 RNN

![状态空间模型……就是线性 RNN](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01341.webp)

视频在这里做了一个很有用的"祛魅"：状态空间模型（SSM）来自控制理论，是从"离散化连续动态系统"这条完全不同的路走出来的，但**结果就是一个线性 RNN，只是初始化方案不同**。最常见的 SSM 把循环权重参数化为

$$
w = e^{\Delta (a + bi)},\qquad \Delta \text{ 可学习，初值在 } 0.0001 \sim 0.1
$$

$\Delta$ 很小，指数就接近 0，$e^{\Delta(a+bi)}$ 就接近 1——同样是为了初始化时梯度稳定。控制理论还要求把输入乘以 $\Delta(a+bi)/(w-1)$，但讲者实测：只把输入乘以 $\Delta$，在 Long Range Arena 上的成绩与线性 RNN 相同。所以"听到状态空间模型，就把它想成线性 RNN"。

## 六、线性 RNN 在语言建模上失败：因为它不会"选择"

![语言模型缩放曲线：Hyena、RWKV、RetNet、H3 等线性模型都不如 Transformer（困惑度越低越好）](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01435.webp)

Long Range Arena 上的 SOTA 并没有转化成语言模型能力。讲者引用 Mamba 论文的归因：**线性 RNN 无法选择性地从状态中遗忘信息**。

![权重接近 0 时，每处理一个输入，输出向量就被清零](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01445.webp)

把权重看成一个旋钮就懂了：

- $w \approx 0$：每来一个输入，历史就被清零，模型永远只记得当前 token；
- $w \approx 1$：历史原封不动地累积，噪声和关键词一起被记住。

而语言需要的恰恰是**按内容决定**：看到"但是"要保留前文，看到无意义的填充词要丢掉。固定权重做不到这件事——它对每个 token 的处理方式完全一样。这正是上一小节（固定线性系统）与本小节（选择性系统）的分界线。

## 七、Mamba 的一句话创新：让权重由输入生成

![不同输入生成不同的权重向量，模型因此能决定何时存储、何时遗忘](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01470.webp)

Mamba 的做法极其直接：**不再每步用同一个权重，而是对每个输入向量施加一个线性函数，生成该输入专属的权重向量**，再用这个权重做循环扫描。

![Mamba 层的公式：Δ_j = W_Δ x_j，w_j = exp(Δ_j ⊙ (a+ib))，y_j = w_j ⊙ y_{j-1} + x_j](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01520.webp)

写成公式就是：

$$
\Delta_j = W_\Delta x_j,\qquad
w_j = e^{\Delta_j \odot (a + ib)},\qquad
y_j = w_j \odot y_{j-1} + x_j
$$

其中 $W_\Delta \in \mathbb{R}^{d\times d}$、$a, b \in \mathbb{R}^{d}$ 都是可学习参数，$\odot$ 是逐元素乘法。注意 $\Delta_j$ 现在**每个 token 都不一样**：某个 token 可以生成接近 0 的权重，把状态擦掉；另一个 token 可以生成接近 1 的权重，把状态原样保留。这就是"选择性"（selectivity）的全部含义——**状态更新的强度由内容决定**。

[【跳转到 24:30】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=1470)

讲者补充了一个论文里没写的观察：每步用不同权重，也让梯度更容易稳定，因为"稳定配置"不再只有 $w=1$ 一种，而是像前馈网络那样有很多种可选。

## 八、选择性破坏了卷积，但扫描还在

选择性的代价必须说清楚。固定线性系统（S4 那一类）有两种等价算法：递推形式适合推理，**卷积形式**适合训练——因为参数不随时间变化，可以预先算出一个长度等于序列的卷积核，然后像 CNN 一样并行卷积。一旦 $B, C, \Delta$ 都随输入变化，**核就不再固定**，卷积形式失效，只能回到递推。

[【跳转到 27:05】](https://www.bilibili.com/video/BV1NbjMzWEEV/?t=1625)

但"回到递推"不等于"回到串行"，因为递推等价于扫描，而扫描可以并行。Mamba 的三项工程手段：

1. **并行扫描**：把 $O(n)$ 的串行深度压到 $O(\log n)$（严格说，总工作量仍是 $O(n)$，省的是关键路径长度）。
2. **16 倍扩宽几乎免费**：Mamba 把状态/输出向量的维度扩大 16 倍（讲者原话），以便存更多历史。这本来会让计算时间涨 16 倍，但 Mamba 层的瓶颈在**读写显存**而非算术：现代 GPU 的算力（A100 约 20 TFLOP/s 量级）远高于 HBM 带宽（约 2 TB/s 量级），讲者给出的比例是"算比搬快约 40 倍"。所以只要把传输的数据量控制住，多出来的算术几乎不影响总耗时。
3. **内核融合（kernel fusion）**：正常框架里每个算子都要"显存→SRAM→算→写回显存"，三次连续算子就有三次往返。融合就是把整段 Mamba 操作（离散化、扫描、输出投影）放进**一个** CUDA 内核，中间结果只留在 SRAM。

![把整个 Mamba 操作放进一个块里计算，中间结果不写回显存](assets/Mamba%20的选择性递归：权重随输入变化，并行扫描把递推压到%20log%20n/01600.webp)

此外还有**激活重计算**：反向传播需要前向的中间激活，缓存它们要占大量显存，而重新算一遍比从显存读回来更快，所以干脆不存、反向时重算。

## 九、和标准注意力比，差在哪

讲者最后把 Mamba 概括为"**一个动态线性递归神经网络**"：语言模型上优于 Transformer，计算量是 $n\log n$ 而不是 $n^2$。把它和注意力并排看：

| 维度 | 标准注意力 | Mamba（选择性 SSM） |
| --- | --- | --- |
| 训练算力 | $O(n^2)$ | $O(n)$（扫描深度 $O(\log n)$） |
| 推理每 token | 随长度增长（KV cache 变大） | 恒定（只带一个固定大小的状态） |
| 记忆载体 | 全部历史 token 的 K/V | 一个固定维度的状态 $h$ |
| 记忆策略 | 按相似度加权检索 | 按内容决定写入/遗忘的强度 |
| 长序列表现 | 位置编码外推后精度下降 | 讲者引用论文：序列长到 $10^6$ 仍稳定 |

代价是：状态是**有损压缩**，一旦写坏无法回查；而注意力永远保留原始 token，可以精确检索。

## 十、附带：一次被拒稿的争议

视频后半段讲了 Mamba 投稿 ICLR 2024 被拒的事。预印本公开后多组独立复现都成功，社区普遍预期它会被接收，但一月的评审给了拒稿。讲者引用的两条主要批评是：

- **没在 Long Range Arena 上测**。讲者认为这个理由站不住：长程合成任务和语言模型是两回事，Transformer 在该任务上比线性 RNN 差得多，却仍是更好的语言模型。
- **只评估了语言建模（下一词准确率）**。讲者指出论文其实做了零样本下游评测，Mamba 在所有对比模型中最好。

还有一位评审称"Mamba 训练需要二次内存"，讲者认为这完全错误：Transformer 是二次**计算**、线性**内存**，Mamba 两者都是线性。这场争议本身值得记住的一点是：**评价指标与任务错配**会让评审结论失真。

## 小结

- 线性递归层 $y_i = W_y y_{i-1} + W_x x_i$ 把循环里的非线性换成线性，从而同时获得可并行与可训练。
- 线性递归等价于**扫描**：只要算子满足结合律，就能用步长翻倍的并行扫描在 $\log n$ 深度内算完。
- 朴素扫描每步要做 $d\times d$ 矩阵乘法；**对角化**把 $O(d^3)$ 降到 $O(d)$，代价是引入复数与前后变换。
- RNN 难训的根源是梯度只剩 $w^{n-1}$，唯一稳定点是 $w=1$；线性 RNN 与 SSM 都靠**特殊初始化**把模型钉在稳定点附近。
- 状态空间模型就是线性 RNN，只是初始化来自控制理论（$\Delta$ 很小，$e^{\Delta(a+bi)}\approx 1$）。
- 线性 RNN 在语言建模上输给 Transformer，是因为**固定权重无法按内容选择记忆**。
- Mamba 让权重由输入生成：$\Delta_j = W_\Delta x_j$、$w_j = e^{\Delta_j \odot (a+ib)}$，实现"看到什么决定记什么"。
- 选择性使卷积形式失效，但递推仍是扫描；配合并行扫描、16 倍扩宽与内核融合，Mamba 在长序列上既快又能保持精度。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 线性递归（linear recurrence） | 循环体是线性函数 $y_i = W_y y_{i-1} + W_x x_i$ 的 RNN，可并行、易训练 |
| 扫描（scan） | 用结合律运算符对序列做"前缀累积"的运算，线性递归是它的特例 |
| 结合律（associativity） | $(a\circ b)\circ c = a\circ(b\circ c)$，是并行扫描能成立的前提 |
| 对角化（diagonalization） | 把 $W$ 写成 $PDP^{-1}$，使矩阵幂变成逐元素幂，$O(d^3)\to O(d)$ |
| 梯度消失/爆炸 | 梯度含 $w^{n}$ 因子，$\lvert w\rvert \ne 1$ 时随步数指数衰减或增长 |
| 状态空间模型（SSM） | 从连续系统 $h'=Ah+Bx,\ y=Ch$ 离散化得到的线性递归，本质是线性 RNN |
| 选择性（selectivity） | 让 $B, C, \Delta$ 成为输入的函数，使状态更新强度随内容变化 |
| 并行扫描（parallel scan） | 用步长翻倍的树形归约把扫描深度压到 $O(\log n)$ |
| 内核融合（kernel fusion） | 把多个算子合成一个 CUDA 内核，避免中间结果往返显存 |
| 激活重计算 | 反向传播时不缓存中间激活，而是重新前向计算，以省显存 |
