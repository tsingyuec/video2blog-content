## 本讲要解决的核心问题（SCQA）

**背景**：蛋白质语言模型的常规做法是套 Transformer——ProtT5、ESM、ProtBERT 都是大型 Transformer 架构，靠海量数据和算力做自监督预训练，再把学到的表征迁移到下游任务。

**冲突**：这套做法的门槛很高。训练和运行都要大量数据与计算资源，对资源有限的实验室或应用方来说，直接使用或微调一个大型 Transformer 蛋白质模型并不现实。

**疑问**：能不能换一条不走注意力的技术路线，把模型规模压到极小，同时不牺牲准确度？

**回答（中心思想）**：能。ProtHyena 用 **Hyena 算子**（长卷积 + 逐元素门控）替换自注意力，配上前馈网络和归一化层堆成 Hyena Block，模型只有 **160 万参数**，却在与 ProtGPT 系列的对比中取得了最低的困惑度，并在荧光预测、稳定性预测、二级结构预测等八类下游任务上达到与大型模型相当的水平。**它证明的是"架构效率"这件事：参数少两个数量级，也能把蛋白质序列建模做到可用。**

## 二、Hyena 算子：把注意力换成"长卷积 + 门控"

### 2.1 长卷积是什么

普通卷积用一个很短的窗口（比如 3、5 个位置）扫过序列，只能看到局部；**长卷积**则把卷积核拉到和序列长度同一个量级，让每个输出位置直接对整段输入做加权求和：

$$
y_t = \sum_{\tau=0}^{N-1} k_\tau \, x_{t-\tau}
$$

其中 $k$ 是长度为 $N$ 的卷积核（滤波器）。和注意力相比，它同样是"全局"的——每个位置都能看到整条序列——但它不是两两配对打分，而是**固定形状的加权叠加**，所以没有 $N\times N$ 的分数矩阵 [【跳转到 00:58】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=58)。

### 2.2 滤波器不是学出来的表，而是"现算"的

直接学一个长度 $N$ 的卷积核，参数量会随序列长度爆炸。ProtHyena 用的是**隐式滤波器**：用一个小网络（窗口 → 线性层 → SiLU 激活 → 线性层，重复三次）把位置映射成核值，再拼成整条滤波器 [【跳转到 01:48】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=108)。

![ProtHyena 框架图：左侧 Hyena Operator-2 由长卷积与逐元素门控交替组成，右上 Long Convolution Filter 用小网络生成滤波器，下方是 MLP 解码器与 Hyena Block 的堆叠方式](assets/ProtHyena：用长卷积加逐元素门控，160%20万参数的蛋白质语言模型打平大型%20Transformer/00108.webp)

这张图是整支视频里信息量最大的一页，可以拆成四块看：

- **(A) Hyena Operator-2**：长卷积的输出先与输入做**逐元素相乘**（Element-wise Gate，即门控），再进 Dense & Conv；这样的"卷积 → 门控"结构重复若干次。门控的作用是让模型能按内容放大或抑制某些通道——这正是 Transformer 里注意力的"选择性"在做的事，只是换成了乘性交互。
- **(B) Long Convolution Filter**：滤波器由一个小网络生成（Window → Linear → SiLU → Linear，重复 3 次），所以核的形状由参数决定、不需要存 $N$ 个系数。
- **(C) 预测下一个氨基酸**：蛋白质嵌入 → Hyena Operator → Add & Norm → Feed Forward → Add & Norm，重复 2 次（Hyena Block ×2），最后接 MLP 解码器输出词表上的分布。
- **(D) 下游任务头**：冻结预训练模型，取最后一层隐状态，按任务接分类层或回归层（蛋白级分类、残基级分类、蛋白级回归）。

> 补充一句视频没展开的背景：长卷积的朴素实现是 $O(N^2)$，但卷积在频域是逐点相乘，用快速傅里叶变换（FFT）可以一次算完整条卷积，复杂度降到 $O(N\log N)$——这是"长卷积能做长序列"的算力前提。

### 2.3 一个 Hyena Block 里有什么

视频对预训练阶段的架构描述是：使用含有以下元件的 Hyena Blocks——**Hyena 算子、前馈神经网络、归一化层**。

对照 Transformer 的块结构看就很清楚：**把多头自注意力那一格换成 Hyena 算子，其余（残差、归一化、前馈）保持不变** [【跳转到 01:23】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=83)。这也是后来一大批"非注意力架构"的共同做法——不动骨架，只换混合机制。

## 三、训练：两阶段，先学语言再学任务

ProtHyena 沿用"预训练 + 微调"的两段式：

- **预训练**：在 **Pfam 数据库的 1400 万条序列**上训练，目标是预测下一个氨基酸残基，损失用交叉熵；产出是序列嵌入。
- **微调**：把预训练模型适配到具体生物任务——荧光预测、稳定性预测、病毒蛋白功能预测、蛋白质二级结构预测等。

![预训练与微调流程：输入蛋白序列切分为氨基酸 token，经 Hyena Block ×2 与 MLP 解码器输出下一残基分布；下方是各下游任务头](assets/ProtHyena：用长卷积加逐元素门控，160%20万参数的蛋白质语言模型打平大型%20Transformer/00058.webp)

这套流程和 ProtGPT、ESM 的做法没有本质区别，**变的只是主干网络** [【跳转到 00:58】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=58)。所以后面所有对比都可以理解为"同一套训练范式下，换主干带来的差别"。

## 四、结果：小两个数量级，指标不落下风

### 4.1 参数、困惑度与资源开销

![与 ProtGPT 系列的对比：ProtHyena 与 ProtGPT-tiny 均为 1.6M 参数、ProtGPT-base 为 25.2M，三者同源数据；ProtHyena 困惑度最低，GPU 占用与计算时间也最小](assets/ProtHyena：用长卷积加逐元素门控，160%20万参数的蛋白质语言模型打平大型%20Transformer/00133.webp)

讲者给出的三组数字很关键：

- **参数量**：ProtHyena 1.6M，ProtGPT-tiny 1.6M，ProtGPT-base 25.2M。
- **困惑度**：三者使用相同的预训练数据，ProtHyena 达到了最低的困惑度。
- **资源**：ProtHyena 在训练中所需要的资源更少，计算速度更快（右侧两张图分别是 GPU 占用与每秒迭代次数随 batch size 的变化）。

**同样 1.6M 参数、同样数据，换主干后困惑度更低**——这是"架构效率"最直接的证据；而对比 25.2M 的 ProtGPT-base 也不吃亏，说明参数不是唯一决定因素 [【跳转到 02:13】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=133)。

### 4.2 荧光预测：Spearman 0.68

荧光预测是蛋白质工程里的经典任务：给定一个绿色荧光蛋白的序列，预测它的亮度。训练集只包含相对更亮的突变，测试集则要覆盖更暗的突变。

![荧光预测任务：训练集与测试集的亮度分布，以及各模型的 Spearman 相关系数对比](assets/ProtHyena：用长卷积加逐元素门控，160%20万参数的蛋白质语言模型打平大型%20Transformer/00158.webp)

讲者的结论是 ProtHyena 以 **0.68 的 Spearman 相关系数**脱颖而出，超过了许多资源密集型的大模型 [【跳转到 02:38】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=158)。

### 4.3 稳定性预测：Spearman 0.73

稳定性预测的难点在于样本经过多轮突变，序列与野生型的距离较远。ProtHyena 在这个任务上达到 **0.73 的 Spearman 相关系数**，说明它在涉及邻近突变的复杂场景中也能较好泛化 [【跳转到 03:23】](https://www.bilibili.com/video/BV1qs66YJEHx/?t=203)。

### 4.4 属性预测：ROC 曲线与大型模型相当

在神经肽切割、无序区预测、信号肽预测、溶解度预测等任务上，视频用准确率、F1、MCC 和 AUC 等指标评估，结论是 ProtHyena 在保持高效率的同时达到了与最先进大型模型相当的性能。

## 小结

- **动机是成本**：ProtT5、ESM、ProtBERT 这类大型 Transformer 蛋白质模型训练与运行成本高，资源有限的用户需要更轻的替代方案。
- **替换点是混合机制**：ProtHyena 把注意力换成 Hyena 算子——长卷积负责全局加权，逐元素门控负责按内容选择，滤波器由小网络隐式生成。
- **骨架不变**：Hyena Block = Hyena 算子 + 前馈网络 + 归一化层，外面仍是残差与两段式"预训练 + 微调"。
- **训练数据与目标**：Pfam 的 1400 万条序列，预测下一个氨基酸残基，交叉熵损失。
- **效率证据**：1.6M 参数、与 ProtGPT-tiny 同参数同数据，困惑度最低，GPU 占用与计算时间更小。
- **下游不落下风**：荧光预测 Spearman 0.68、稳定性预测 0.73，属性预测 ROC 与大型模型相当，病毒蛋白九分类甚至更好。
- **它回答的是"能不能换"**：长卷积可以替代注意力做蛋白质语言模型；"能撑多长上下文、要不要混合"留给后续的 Evo 系列回答。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| Hyena 算子 | 用长卷积与逐元素门控交替堆叠，替代自注意力做序列混合 |
| 长卷积（long convolution） | 卷积核长度与序列长度同量级的卷积，每个位置都能看到整条序列 |

| 困惑度（perplexity） | 语言模型对下一 token 预测不确定性的度量，越低越好 |
| Spearman 相关系数 | 衡量预测排序与真实排序一致性的指标，常用于突变效应预测 |
| AUROC / AUPRC | 分类任务的两种阈值无关评价指标，前者看正负样本排序，后者更关注正类精度 |
