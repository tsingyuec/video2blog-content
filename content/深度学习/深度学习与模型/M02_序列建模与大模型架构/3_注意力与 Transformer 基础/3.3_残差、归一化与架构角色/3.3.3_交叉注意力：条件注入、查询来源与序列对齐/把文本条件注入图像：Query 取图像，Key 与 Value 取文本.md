# 把文本条件注入图像：Query 取图像，Key 与 Value 取文本

> 视频来源：[小白学习 cross attention](https://www.bilibili.com/video/BV13FYNzeExr/)（Bilibili · PureDaily，搬运讲解）｜时长约 12 分钟
> 导读：这支视频先在一块 2×2 的小图上把自注意力手算一遍，然后只改一处——让 Q 来自图像、K 和 V 来自文本条件——就得到了交叉注意力。本文照这个顺序走：4×3 的展平、3×2 的投影、相似度矩阵、softmax、加权平均、投影回 RGB、残差相加，每一步都带着具体数字。字幕里的"记忆来自 0.47 的文本条件化"这类生硬译法已改写，术语按画面校正。

本文基于视频演说图文稿整理，配图截自视频。

## 本讲要解决的核心问题（SCQA）

**背景**：稳定扩散（Stable Diffusion）这类文本到图像模型，输入一句话就能生成对应的图。它们内部都用了交叉注意力（cross-attention），而交叉注意力是一种**通过额外信息对模型进行条件控制**的方法——这些模型正是用它来做文本条件控制的 [【跳转到 00:18】](https://www.bilibili.com/video/BV13FYNzeExr/?t=18)。

**冲突**：很多人是通过稳定扩散的热潮听说交叉注意力的，但并不真正理解它的工作原理，只是把它当成黑箱。公式 $\mathrm{softmax}\!\left(\frac{Q\cdot K^{\top}}{\sqrt{d}}\right)\cdot V$ 反复出现，可要命的是——**这个公式和自注意力长得一模一样**，那"条件"到底是从哪里进去的？

**疑问**：如果公式不变，交叉注意力靠什么把文本信息注入图像？Q、K、V 分别该从哪来？注入之后图像的特征变成了什么样？

**回答（中心思想）**：交叉注意力只改矩阵的来源——**Q 来自要处理的主输入（图像），K 和 V 来自条件信息（文本）**。于是"每个图像 patch 去和每个词比对相似度"这件事自然发生：包含山脉的像素会高度关注"山"这个词，最后每个像素都变成"按自己的需要，把整句话的语义加权混合"的结果 [【跳转到 07:46】](https://www.bilibili.com/video/BV13FYNzeExr/?t=466)。

## 一、先看自注意力：它在一块小图上做了什么

### 1.1 把图像变成序列

为简化说明，假设图像只有 2×2 像素、RGB 三通道。把图像展平，得到 $4 \times 3$ 的矩阵——四行是四个像素，三列是每个像素的 RGB 三个通道 [【跳转到 01:56】](https://www.bilibili.com/video/BV13FYNzeExr/?t=116)。

这里有一个值得记住的判断：**自注意力是全局地在整张图像间传递信息的方式，而非局部**，这一点和卷积操作正好相反 [【跳转到 01:44】](https://www.bilibili.com/video/BV13FYNzeExr/?t=104)。卷积只看邻域，注意力一次就能看到全部像素。

### 1.2 三个投影：把 3 维投到 2 维

要得到 Q、K、V，需要**三种不同的方式把输入像素投影到潜在空间**。视频为了直观，把 3 维输入投影到 2 维（实际应用会用更高维度）。记住这条规则：**要把某个向量从 $n$ 维空间投影到 $m$ 维空间，权重矩阵的形状就是 $n \times m$**——所以这里是 $3 \times 2$ [【跳转到 02:21】](https://www.bilibili.com/video/BV13FYNzeExr/?t=141)。

四个像素、每个 3 维，乘上 $3 \times 2$ 的权重，得到 $4 \times 2$ 的 Q、K、V。

![三个投影矩阵各自把 4×3 的像素矩阵压到 4×2：Q、K、V 形状相同但权重不同](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00191.webp)

### 1.3 $QK^{\top}$ 就是相似度测量

第一步算 $Q \cdot K^{\top}$：q 中的每个向量（代表一个像素）与 k 中所有其他像素向量做点积，每个点积得到一个数值，表示两个向量间的相似度。遍历所有像素，就得到每个像素与其他像素的相似度矩阵 [【跳转到 03:11】](https://www.bilibili.com/video/BV13FYNzeExr/?t=191)。

![Q 乘 K 转置：4×2 乘 2×4 得到 4×4 的相似度矩阵](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00216.webp)

为什么点积能当相似度用？视频给了一个几何直觉：如果模型认为两个像素应该相互关注、需要共享信息，它可以通过 $W_Q$、$W_K$ 把这两个向量投影得彼此靠近，点积就大；反之两个向量距离远，点积就小，它们不会过多相互关注 [【跳转到 03:36】](https://www.bilibili.com/video/BV13FYNzeExr/?t=216)。

公式里那个除以 $\sqrt{d}$ 的因子，视频为了演示省略了——它只是缩放相似度矩阵，主要为了让后续训练更稳定。

### 1.4 softmax 与加权平均

对相似度矩阵**按行**做 softmax，因为要归一化的是"单个像素对其他像素的倾向程度"。比如某个像素会关注自身 23%、33% 关注第二个像素、27% 关注第三个、17% 关注第四个 [【跳转到 04:26】](https://www.bilibili.com/video/BV13FYNzeExr/?t=266)。

![softmax 之后每一行和为 1，右侧是待混合的 V 矩阵](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00266.webp)

最后把相似度矩阵乘上 $V$。视频特意把它拆成"逐行加权求和"来讲：取第一行的每个值，乘以 $V$ 对应的那一行，再把所有向量加起来——结果与常规矩阵乘法相同，但理解起来更清晰 [【跳转到 05:41】](https://www.bilibili.com/video/BV13FYNzeExr/?t=341)。

![逐行加权：0.23 乘 V 第一行，0.33 乘第二行……最后相加](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00341.webp)

这里有个必须强调的结论：**我们最初每个像素只有自身影响的嵌入，最终得到的是所有像素嵌入的混合，而这种混合及其比例由模型自己决定**——就像厨师决定如何混合食材 [【跳转到 06:06】](https://www.bilibili.com/video/BV13FYNzeExr/?t=366)。

### 1.5 投影回去，再加残差

最后把 $4 \times 2$ 的注意力输出用形状 $2 \times 3$ 的线性层投影回原始的三维 RGB 空间，再通过残差连接把注意力输出加回输入 [【跳转到 06:31】](https://www.bilibili.com/video/BV13FYNzeExr/?t=391)。

残差在这里的作用，视频讲得比"梯度好流"更具体：**有了残差，注意力可以完全集中、专注于所需内容**。没有残差，每个像素还得花大量注意力关注自己，以免丢失自身信息；有了残差，原始输入被完整保留，注意力输出可以在上面按模型认为有用的任何方式做修改 [【跳转到 06:56】](https://www.bilibili.com/video/BV13FYNzeExr/?t=416)。

## 二、换成交叉注意力：只改一处

### 2.1 关键改动

掌握了自注意力，理解交叉注意力就非常简单：**在 q、K、V 矩阵上做重大改变——只有 q 是输入特征的投影，而 k 和 v 变成条件信息的投影** [【跳转到 07:46】](https://www.bilibili.com/video/BV13FYNzeExr/?t=466)。

| | q 来自 | k 来自 | v 来自 |
| --- | --- | --- | --- |
| 自注意力 | 输入特征 | 输入特征 | 输入特征 |
| 交叉注意力 | 输入特征（图像） | 条件信息（文本） | 条件信息（文本） |

视频里假设条件是文本，但它也明确说了：**本质上其他任何内容也同样适用**。

### 2.2 条件文本怎么变成 K、V

大多数文本到图像模型采用大型预训练的 Transformer，通常**只使用编码器部分**：描述先分词，每个 token 被嵌入，再送进编码器的 Transformer 层 [【跳转到 08:11】](https://www.bilibili.com/video/BV13FYNzeExr/?t=491)。

![文本条件的处理链：caption → Tokenizer → Embedding → Transformer Encoder](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00516.webp)

输出的形状是 `(batch, token 数, 嵌入维度)`。忽略 batch，视频举例说文本是"我爱山"，分词后三个 token，每个 6 维嵌入，于是得到一个 $3 \times 6$ 的矩阵 [【跳转到 08:36】](https://www.bilibili.com/video/BV13FYNzeExr/?t=516)。

### 2.3 两套权重、两种维度

现在构建权重矩阵，仍然投影到 2 维空间：

- 图像侧：$4 \times 3$ 的像素矩阵乘 $3 \times 2$ 的 $W_Q$，得到 $Q$ 形状 $4 \times 2$。
- 文本侧：$3 \times 6$ 的文本矩阵乘 $6 \times 2$ 的 $W_K$、$W_V$，得到 $K$、$V$ 形状 $3 \times 2$。

![图像 → Q（4×2），文本条件 → K 与 V（3×2）：注意两边的输入维度不同，输出维度相同](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00541.webp)

这张图是整支视频的核心，值得盯着看几秒：**输入维度可以不同（3 维像素 vs 6 维词嵌入），但投影后的维度必须相同（都是 2 维）**——否则点积算不了。这也解释了为什么交叉注意力能跨模态：它不要求两侧的表示空间原本一样，只要求投影到同一个子空间。

### 2.4 走完剩下的步骤

后面的步骤和自注意力完全相同：$q$ 乘 $k$，每个像素嵌入与每个词嵌入相乘，相似的嵌入获得高值——**包含山脉的像素可能高度关注"山"这个词** [【跳转到 09:26】](https://www.bilibili.com/video/BV13FYNzeExr/?t=566)。

![4 个像素对 3 个词的相似度：Q[4,2] × K[3,2] 的转置 = [4,3]，每个 patch 与每个 token 的相关性](assets/把文本条件注入图像：Query 取图像，Key 与 Value 取文本/00566.webp)

聚焦第一行（第一个像素）：它对第一个词的关注度是 47%、对第二个词 22%、对最后一个词 31%。于是把 $V$ 的第一行乘 0.47、第二行乘 0.22、第三行乘 0.31，再相加 [【跳转到 09:51】](https://www.bilibili.com/video/BV13FYNzeExr/?t=591)。

![第一个像素的加权求和：0.47×(−0.37, 0.98) + 0.22×(−1.03, 1.05) + 0.31×(−0.45, 0.86) = (−0.54, 0.96)](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00616.webp)

对剩余像素和所有词重复同样的操作，最终**每个像素都包含整个文本条件的完整信息，并自行决定最需要关注的内容** [【跳转到 10:16】](https://www.bilibili.com/video/BV13FYNzeExr/?t=616)。

最后把 $4 \times 2$ 的输出用 $2 \times 3$ 的投影层映射回三维 RGB 空间，再通过残差连接加回输入 [【跳转到 10:41】](https://www.bilibili.com/video/BV13FYNzeExr/?t=641)。

![交叉注意力的收尾：注意力输出投影回 3 维后与输入相加](assets/把文本条件注入图像：Query%20取图像，Key%20与%20Value%20取文本/00641.webp)

## 三、这套做法为什么能推广

视频结尾给了一段我觉得比公式更重要的判断：交叉注意力可以用于许多其他任务，正如 Stable Diffusion 所示——**只需找到一种有效引入条件数据的方法，把它映射到不过大的维度空间，确保计算不会爆炸** [【跳转到 11:06】](https://www.bilibili.com/video/BV13FYNzeExr/?t=666)。

把这句话拆开看，其实是三条工程约束：

1. **找得到条件数据**：文本、类别、另一张图、甚至音频，只要能编码成序列。
2. **映射到不过大的维度**：条件序列的长度和维度会直接进到注意力矩阵里，太长就是 $O(mn)$ 的开销。
3. **计算不爆炸**：所以视频里反复强调"投影到 2 维"这种降维演示，实际系统里也是先压到与图像特征可比的维度。

而这一切的底层思想，视频最后总结得很朴素：**这本质上是给予模型最大程度的自由，避免人工特征和硬编码规则**。哪些像素该关注哪些词，不由人写规则，而是让模型自己学 [【跳转到 12:20】](https://www.bilibili.com/video/BV13FYNzeExr/?t=740)。

## 小结

- 交叉注意力与自注意力的公式完全相同，**唯一区别是 q 来自主输入、k 和 v 来自条件信息**。
- 自注意力在一块 2×2 小图上的完整流程：展平成 $4 \times 3$ → 三个 $3 \times 2$ 投影 → $QK^{\top}$ 相似度 → 按行 softmax → 加权求和 $V$ → $2 \times 3$ 投影回 RGB → 残差相加。
- 交叉注意力里，图像侧给出 $Q$（$4 \times 2$），文本侧给出 $K$、$V$（$3 \times 2$）：**输入维度可以不同，投影后的维度必须相同**。
- 结果矩阵是 $4 \times 3$（像素数 × 词数），**不是方阵**；每一行是一个像素对整句话的注意力分布。
- 每个像素最终都"装进了整句话的语义"，但装多少由它自己决定——这正是条件注入的含义。
- 残差在这里不只是为了梯度：它让注意力可以放心地专注外部信息，而不必分心保留自身。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 交叉注意力（cross-attention） | q 来自主输入、k 和 v 来自条件信息的注意力，用来做条件控制 |
| 条件注入（conditioning） | 把额外信息（如文本）通过 K/V 混进主特征的过程 |
| 相似度矩阵 | $QK^{\top}$ 的结果，第 $i$ 行第 $j$ 列表示第 $i$ 个像素对第 $j$ 个词/像素的匹配程度 |
| 加权平均 | softmax 权重乘 $V$ 后求和，得到"按关注比例混合"的新特征 |
| 残差连接 | 把注意力输出加回输入，保留原始信息、让注意力可以专注外部内容 |
| 文本编码器 | 预训练 Transformer 的编码器部分，把 caption 变成 `(token 数, 维度)` 的矩阵 |
