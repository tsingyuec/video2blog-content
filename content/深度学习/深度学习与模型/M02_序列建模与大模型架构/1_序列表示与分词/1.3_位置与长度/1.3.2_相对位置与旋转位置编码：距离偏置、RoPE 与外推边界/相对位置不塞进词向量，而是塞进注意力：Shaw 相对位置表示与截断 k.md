# 相对位置不塞进词向量，而是塞进注意力：Shaw 相对位置表示与截断 k

> 视频来源：[Self-Attention with Relative Position Representations – Paper explained](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=0)（YouTube · AI Coffee Break with Letitia，10 分钟）
> 本篇只讲「相对位置表示（relative position representations）」这一支：为什么它不往词向量上加位置、而是去改注意力的公式，以及截断 $k$ 为什么反而换来了长度上的通用性。RoPE 那条路线另有一篇。

## 本讲要解决的核心问题（SCQA）

**背景**：Transformer 本身对顺序不敏感。同样几个词打乱顺序喂进去，输出可以完全一样，所以必须在某处注入位置信息。最常见的一招是给每个 token 加一个"我是第几个"的位置向量——这叫绝对位置编码。

**冲突**：可是很多任务里真正重要的不是"我是第几个"，而是"我离你多远"。想象一张图：凭什么说某个节点是第一个、另一个是第二个？这种编号对图来说是任意的，甚至误导。序列其实只是一张退化的图——一条链，链上真正有意义的量是相邻关系与距离。

**疑问**：如果位置信息不该以"绝对编号"的形式塞进词向量，那它该以什么形式、加在哪个位置？加进去之后，模型还能不能处理训练时没见过的长度？

**回答（中心思想）**：**相对位置表示把"距离"做成一张可学习的向量表 $w_{j-i}$，并且不加在输入词向量上，而是加到自注意力内部的两处：value 的加权求和项、以及决定注意力权重的 key 上。** 因为表里只存"距离 → 向量"的映射，再用截断 $k$ 把过远的距离并成一档，这张表就与序列的绝对长度无关——训练时见过 5 个 token，推理时来 50 个 token，表照样能用 [【跳转到 08:46】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=526)。

---

## 一、绝对位置编码回答的是"第几个"，相对位置回答的是"差多少"

先看一个 5 个 token 的序列 $x_1,\dots,x_5$。在经典做法里，每个 token 只配一个位置编码，比如 $x_4$ 拿到的那一个向量，告诉 Transformer "我在第 4 位" [【跳转到 02:47】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=167)。

相对做法换了问法：不问"我在第几位"，而问"我相对于其他每个 token 在第几位"。于是每个 token 不再是 1 个位置向量，而是和序列长度一样多个——5 个 token 的序列，每个 token 配 5 个向量。

![每个 token 不再是 1 个位置向量，而是按距离配一组 $w_i$：$w_0$ 是"相对自己"，$w_1$、$w_2$ 往右，$w_{-1}$、$w_{-2}$ 往左](assets/相对位置不塞进词向量，而是塞进注意力：Shaw%20相对位置表示与截断%20k/00182.webp)

论文的记号值得记住：

- $w_0$：描述"一个 token 与它自己"的关系，因为距离是 0；
- $w_1, w_2, \dots$：向右移动 1 格、2 格；
- $w_{-1}, w_{-2}, \dots$：向左移动 1 格、2 格。

关键在于 **$w_i$ 的取值与"当前是哪个 token"无关**。$w_1$ 永远表示"往右一格"这件事，无论这一格落在 $x_1$ 还是 $x_4$ 上。这正是它能脱离绝对位置的原因：表里存的是位移，不是坐标。

顺带说一句，这套定义对图也成立：$w_1$ 表示沿出边跳一步，$w_{-1}$ 表示沿入边跳一步。序列只是"链"这种特殊图 [【跳转到 03:52】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=232)。

## 二、长度 5 的序列，只需要 9 个位置向量

序列长度是 5，相对距离的取值范围是 $-4$ 到 $+4$，所以总共只要 $2\times5-1=9$ 个向量：$w_{-4},\dots,w_0,\dots,w_4$。把它们竖着排成一张表，就得到论文里那种"每个 token 一列、按距离取行"的矩阵 [【跳转到 04:17】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=257)。

![长度 5 的序列：每个 token 一列，按相对距离取 $w_i$，表里只有 9 种不同的向量](assets/相对位置不塞进词向量，而是塞进注意力：Shaw%20相对位置表示与截断%20k/00257.webp)

图里写成 $a_{ij}$ 的形式：第 $i$ 个 token 相对第 $j$ 个 token 取到的向量，只由 $j-i$ 决定。所以这张表是"沿对角线相同"的——同一距离在所有位置复用同一个向量。视频里特意强调，这些向量来自"一个 token 与其他 token 的距离"，因此天然适合用配对下标 $(i,j)$ 来记 [【跳转到 04:47】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=287)。

这就带来第一个直接好处：**参数量只随最大距离增长，不随序列长度增长**。如果再把距离截断，最大距离也被钉死了。

## 三、截断 $k$：超过 $k$ 步的距离一律并成一档

论文还试了一个操作：clipping at $k$。设 $k=2$，那么 $w_3$、$w_4$ 都取 $w_2$ 的值——距离超过 2 之后，模型不再区分"3 格"和"4 格"，只知道"很远" [【跳转到 04:56】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=296)。

![截断 $k=2$ 的效果：$w_3$、$w_4$ 全部退化成 $w_2$，超过 2 步的距离共享同一个向量](assets/相对位置不塞进词向量，而是塞进注意力：Shaw%20相对位置表示与截断%20k/00296.webp)

这个设计初看很怪：小 $k$ 等于主动扔掉长程依赖的精度，模型只能知道"近"或"远"，不知道"多远"。但它在工程上换来两件事：

1. **长度通用**：表里只有 $2k+1$ 个向量，序列再长也不会越界。这是学习式绝对位置编码做不到的——后者一旦只学到 512 个位置，就无法表示第 513 个。
2. **一种"事件视界"**：视频里把它类比成图神经网络里的小跳数。多跳能把远处信息扩散过来，但也会把远处的噪声一起聚合；只依赖局部信息的任务，截断反而不掉点 [【跳转到 09:11】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=551)。

所以截断不是"省参数"的偷懒，而是一个显式的归纳偏置：**距离超过 $k$ 之后不再有区分度，模型只能靠内容本身判断相关性**。

## 四、为什么不加在词向量上：加法会把语义和位置搅在一起

现在每个 token 手上有一堆 $w_i$，怎么用？最直觉的做法是全加起来，加到词向量上。视频明确否掉了这条路：即使只有一个位置编码，加法已经在混合语义与位置信息；每个 token 有 5 个位置向量时，这种混淆会放大 5 倍 [【跳转到 05:21】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=321)。

于是作者转向一个"本来就在算 token 之间关系"的机制：自注意力。自注意力的输出是

$$
z_i = \sum_{j=1}^{n} \alpha_{ij}\,(x_j W^V)
$$

其中 $\alpha_{ij}$ 是 $i$ 对 $j$ 的注意力权重，$x_j W^V$ 是 $j$ 的 value。这个式子里有两处可以动手脚：**被加权求和的内容**，和**权重本身**。

![自注意力的两处注入点：一处是 value 的加权和，一处是决定权重的分数](assets/相对位置不塞进词向量，而是塞进注意力：Shaw%20相对位置表示与截断%20k/00421.webp)

论文两处都改了，各配一套可学习的相对位置向量：

$$
z_i = \sum_{j=1}^{n} \alpha_{ij}\,\bigl(x_j W^V + a^{V}_{ij}\bigr)
$$

$$
\alpha_{ij} = \frac{\exp e_{ij}}{\sum_{k}\exp e_{ik}},\qquad
e_{ij} = \frac{x_i W^Q \,(x_j W^K + a^{K}_{ij})^\top}{\sqrt{d_z}}
$$

其中 $a^{V}_{ij}$ 与 $a^{K}_{ij}$ 都取自前面那张按距离索引的表（$a^K$ 与 $a^V$ 各一张），并且对超出 $k$ 的距离做截断。

用几何的话说：$x_j$ 经过线性变换后落在高维空间里，加上 $a_{ij}$ 相当于把它往一个子空间推一把，那个子空间的意思是"我带着这份语义，同时我还是你右边第 2 个邻居"。value 被推一次，是为了让新表示 $z_i$ 知道相对位置；key 被推一次，是为了让注意力权重本身也做出"带位置感"的判断 [【跳转到 07:01】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=421)。

这里有个容易被忽略的细节：**位置信息不是加一次就完事，而是在每一层注意力的每一对 token 上重新注入**。这与"在 embedding 上加一次位置向量"是两种完全不同的作用位置，也是后文比较 RoPE 时的关键坐标。

## 五、代价与边界：它换来了长度通用，但没成为大模型主流

论文只在文本（机器翻译）上做了实验，拿到了性能提升；方法本身对任何"元素之间有配对关系"的数据都适用，包括图 [【跳转到 07:57】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=477)。

但它的代价也很清楚：

- **每对 token 都要查表**，注意力里多了一次"按距离取向量再相加"的操作，$n$ 个 token 就有 $n^2$ 次；
- **表随距离增长**（不截断时是 $2n-1$ 个向量），距离越远参数越多；
- **截断会牺牲长程精度**，只适合以局部依赖为主的任务。

视频最后给了一个中肯的定位：截断 $k$ 让学到的位置信息能泛化到任意序列长度，这是手工正弦编码也有的性质，却不是任何学习式绝对位置编码都有的性质 [【跳转到 08:46】](https://www.youtube.com/watch?v=DwaBQbqh5aE&t=526)。

![截断 $k$ 带来的长度通用性：表的大小由 $k$ 决定，与序列长度无关](assets/相对位置不塞进词向量，而是塞进注意力：Shaw%20相对位置表示与截断%20k/00526.webp)

## 小结

- 绝对位置编码回答"我是第几个"，相对位置表示回答"我离你多远（往哪个方向）"；后者对序列平移不变，也能直接推广到图。
- 相对表示是一张按距离索引的向量表 $w_{j-i}$，长度 $n$ 的序列只需 $2n-1$ 个向量；截断 $k$ 后只需 $2k+1$ 个。
- 它不加在词向量上，而是加在自注意力内部：value 上加 $a^V_{ij}$ 影响输出表示，key 上加 $a^K_{ij}$ 影响注意力权重。
- 截断 $k$ 用"只知道远近、不知道多远"换来了长度通用性，是一个显式的局部性归纳偏置。
- 代价是每对 token 都要查表、表随距离增长；这也是后来 RoPE 把位置做成"旋转"而不是"查表"的动机之一。

## 关键术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 绝对位置编码 | 给每个位置一个固定或可学习的向量，加在词向量上，表示"第几个" |
| 相对位置表示 | 按两个 token 的距离 $j-i$ 取一个可学习向量，表示"差多少、往哪边" |
| $w_i$ / $a_{ij}$ | 距离为 $i$ 的位置向量；$a_{ij}$ 表示第 $i$ 个 token 相对第 $j$ 个取到的向量 |
| 截断 $k$（clipping） | 距离超过 $k$ 后统一取 $w_k$，使位置表大小与序列长度无关 |
| 长度通用 | 训练见过的长度之外仍能表示，因为位置表只依赖距离而非绝对位置 |
| 自注意力注入点 | 相对位置可以加在 value（影响输出）或 key（影响权重）上，而不是加在输入上 |
