# 从 token 到句向量：CLS 池化、平均池化与各向异性造成的语义损失

> 视频来源：[武大Neo博士：BERT句向量表示的局限与改进，《BERT有时候也挺鸡肋》](https://www.bilibili.com/video/BV1Q54y1T78a/)（Bilibili · 二范数智能）｜时长约 63 分钟
> 导读：这是一场 BERT-flow 论文（*On the Sentence Embeddings from Pre-trained Language Models*）的精读直播。本文只取其中与"表征粒度"有关的一条线：token 级隐状态长什么样、CLS 与平均池化各自做了什么、为什么把 N 个 token 向量压成 1 个句向量会丢信息。论文里关于 STS 相关系数、SentEval 分类器的实验只作为现象证据引用，评价方法本身不在这里展开。字幕为直播 AI 转写，口误与错拼已按上下文订正。

## 本讲要解决的核心问题（SCQA）

**背景**：BERT 在自然语言处理的许多任务上取得了 SOTA 效果，于是大家默认"想要句向量，就把句子喂给 BERT，取个向量出来"。取法通常有两种：取 `[CLS]` 位置的输出，或者把所有 token 的输出取平均（mean pooling）。

**冲突**：这两种取法都很难看。论文里给出的数字是：在 STS 系列数据集上，平均 BERT 句向量的平均相关系数是 46.35，`[CLS]` 向量只有 16.01，而一个几年前的、完全不带上下文的静态词向量 GloVe 取平均就有 61.32 [【跳转到 17:19】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=1039)。更奇怪的是，同一个 BERT 模型，只把相似度度量从余弦相似度换成一个逻辑斯蒂回归分类器，效果就"迎来了质的提升" [【跳转到 17:49】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=1069)。

**疑问**：到底是 BERT 的 token 级隐状态里本来就没学到语义，还是语义学到了、只是在"压成一个向量"这一步被弄丢了？

**回答（中心思想）**：语义是学到了的——掩码语言模型的训练目标可以推导到点互信息（PMI），而 PMI 正是词与上下文语义相关性的统计度量，所以 BERT 的隐状态里确实带着语义相似度信息 [【跳转到 41:03】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2463)。损失发生在**池化**这一步：BERT 的向量空间是**各向异性**的，所有词向量挤在一个狭窄的圆锥里，高频词靠近原点、低频词又远又稀疏，于是"把一串 token 向量平均起来"得到的句子向量，往往正好落在低频词之间那些语义不明确的空洞里 [【跳转到 46:12】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2772)。所以问题不是"表示不好"，而是"表示的粒度被压扁了、方向又趋同"。

## 一、先分清三种粒度：token、片段、整句

同一句输入，BERT 其实同时给出了三套不同粒度的表示，只是我们平时只取最后一层、只取一个位置。分清它们，才知道池化到底压掉了什么。

### 1.1 token 级：形状 `[B, L, H]` 的那一摞向量

BERT 的输出不是一个向量，而是一个三维张量：批大小 $B$、序列长度 $L$、隐藏维度 $H$。对第 $i$ 个 token，它的隐状态是

$$
\mathbf{h}_i = \mathrm{BERT}(x_1, \dots, x_L)_i \in \mathbb{R}^{H}
$$

这个向量是**上下文相关**的：同一个词在不同句子里 $\mathbf{h}_i$ 不同。它回答的问题是"这个词在这个上下文里是什么"。所以序列标注、抽取式问答（预测答案片段的起止位置）、命名实体识别这类任务，直接在 token 级张量上接一个分类头就行，根本不需要池化 [【跳转到 11:54】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=714)。

视频里还提到 BERT 的一个可利用率很高的性质：**可以根据任务需要取出每一层的参数**来供下游任务使用 [【跳转到 12:24】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=744)。也就是说 token 级表示不只是"最后一层"，中间层的 token 向量也是一种可选的粒度——层数本身也是粒度的一个维度。

### 1.2 片段级：对一段连续 token 做池化

把 token 级张量按位置切一刀，就得到片段（span）级表示：

$$
\mathbf{s}_{i:j} = \mathrm{Pool}\left(\mathbf{h}_i, \dots, \mathbf{h}_j\right)
$$

它回答的问题是"这段连续文本在说什么"。视频里最典型的使用场景是**交互型模型**：两个句子被拼进同一个编码器，模型"共同学习、关注到两个句子细粒度的表示情况"，再在匹配层上得到得分 [【跳转到 08:54】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=534)。这里的"细粒度"就是片段级——对齐发生在词与词、短语与短语之间，而不是发生在两个整句向量之间。

片段级的代价是**必须两两在线交互**：交互型模型没法离线算好向量再复用，所以视频里说它"必须是在线实时交互的"，时间效率不如表示型模型，但精度提升十分巨大 [【跳转到 09:24】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=564)。

### 1.3 全局级：一个句子一个向量

再往上压一层，就是整句表示。视频把 BERT 常用的句向量表示方式总结成两种 [【跳转到 33:10】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=1990)：

- **`[CLS]` 向量**：取序列第一个特殊 token 的隐状态 $\mathbf{h}_{\mathrm{CLS}}$；
- **平均句向量（MEAN）**：对全部 token 的隐状态取平均 $\frac{1}{L}\sum_i \mathbf{h}_i$。

这两种都是**池化**——把长度 $L$ 的序列压成一个固定长度的向量。压完之后，句子可以被离线编码、存进向量库、用余弦相似度两两比较，这正是"表示型模型"能离线计算的原因 [【跳转到 09:24】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=564)。

![经典 BERT 把两句话拼进同一个编码器、只在 CLS 上做判断；Sentence-BERT 则让两个句子各自过 BERT、各自池化出一个句向量，再比较两个向量的余弦相似度](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/00984.webp)

图里左右两种结构的差别，本质就是**粒度选择**：左边保留了 token 级的两句交互，右边把每句话压成了一个向量。压得越狠，能离线复用的东西越多，被丢掉的东西也越多。

## 二、平均池化：把"语义空洞"一起平均进来

### 2.1 平均池化在做什么

mean pooling 的公式简单到没什么可解释的：

$$
\mathbf{e}_{\text{mean}} = \frac{1}{L}\sum_{i=1}^{L} \mathbf{h}_i
$$

它的隐含假设是：**句子的语义等于各个 token 语义的平均**。这个假设在一种情况下成立——所有 token 向量均匀地散布在空间里，平均之后落在它们中间，位置有意义。但如果 token 向量并不均匀，平均就会出问题。

### 2.2 各向异性：所有向量挤在一个窄锥里

视频引用的前人结论是：BERT 的向量表示存在**各向异性**（anisotropy）[【跳转到 42:15】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2535)。这个词原本指物体的物理化学性质随方向不同而变化，比如"顺纹切的肉比横纹切的肉更有嚼劲"；放到向量空间里，它的含义就是**分布和方向有关系**——不同方向的分布不一样，空间不是各向同性的球。

视频用一组具体坐标说明为什么这会坑到余弦相似度：$x_1=(2,2)$、$x_2=(-2,2)$、$x_3=(2,-2)$，人一眼能看出 $x_1$ 和 $x_3$ 不同，但算余弦相似度得到的值是一样的——因为余弦只看夹角、不看长度，而各向异性恰恰让"长度"和"方向"的分布都变得不均匀 [【跳转到 43:15】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2595)。

结果就是词向量全部挤在一个**狭窄的圆锥空间**里：高频词靠近圆锥的原点、彼此距离很近；低频词离原点很远、彼此也很远。

![各向异性的几何图像：词向量被限制在一个窄锥内，高频词靠近原点且分布紧密，低频词远离原点且分布稀疏](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/02655.webp)

### 2.3 两个观察：高频近、低频远；高频密、低频疏

论文用两个实验把这个现象钉死。

**观察一：词频会让向量空间产生偏差。** 按词频排名分组（top 100、100–500、500–5K、5K–1K 等），计算每组词向量的平均 L2 范数：

| 词频排名 | (0, 100] | (100, 500] | (500, 5K] | (5K, 1K] |
| :--- | ---: | ---: | ---: | ---: |
| Mean $\ell_2$-norm | 0.95 | 1.04 | 1.22 | 1.45 |

排名越靠后（越低频），平均范数越大，也就是**离原点越远** [【跳转到 44:42】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2682)。

![观察一：按词频分组统计 BERT 词向量的 L2 范数与 kNN 距离，高频词离原点近、低频词离原点远](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/02682.webp)

**观察二：低频词的分布是稀疏的。** 同一张表里还有 kNN 距离：高频词的 $k$ 近邻距离小、低频词的 $k$ 近邻距离大。视频的解释是：低频词周围存在许多**语义含义不明确的空洞** [【跳转到 45:42】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2742)。

### 2.4 关键一步：平均之后，句子向量正好落进空洞

把两个观察接起来，就得到池化造成信息损失的机制：

> 由于这种稀疏性，在空间当中低频词周围就会存在许多语义含义不明确的空洞。而当上下文的嵌入表示平均得到句向量后，这个句子向量就正好落在这些语义不明确的地方 [【跳转到 46:12】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2772)。

![观察二：低频词分布稀疏，平均池化得到的句子向量可能正好落在语义不明确的"空洞"里](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/02772.webp)

换句话说：**每个 token 向量单独看都有意义，但它们中间的位置没有意义**。平均池化把句子映射到"重心"，而重心恰好落在没有语义定义的空地上。这就是"池化造成的局部信息损失"最具体的一种形态——不是某个词的信息被删掉了，而是**词与词之间的组合关系在平均这一步被抹平了**：语序、否定、修饰关系都不进入平均的结果。

## 三、CLS 池化：一个没被训练成"句子摘要"的位置

如果平均池化的问题是"平均到了空洞里"，那 `[CLS]` 的问题更直接：**它在预训练时并没有被要求成为整句的摘要**。

视频在回顾 BERT 的预训练目标时提到，MLM 相当于完形填空，而 NSP（next sentence prediction）这个二分类任务"在后面被逐渐证明为没有起到多少效果" [【跳转到 12:54】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=774)。`[CLS]` 位置原本是 NSP 的输入位——NSP 没用，`[CLS]` 也就没被训练成一个好的句子表示。

论文原文里还有一句容易被忽略的话：产出句向量时**不做 token mask**，这和预训练阶段不同；并且前人实验显示，平均上下文嵌入的效果**始终优于** `[CLS]` 嵌入，所以论文后文所说的"BERT 句向量"一律指平均池化，不再区分两者 [【跳转到 33:10】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=1990)。

![论文对 BERT 句向量表示方式的总结：常用 CLS 与 MEAN 两种取法，且平均上下文嵌入始终优于 CLS 嵌入](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/02020.webp)

差距有多大？看 STS 那张表：`Avg. BERT embeddings` 平均 46.35，`BERT CLS` 只有 16.01，而 `Avg. GloVe embeddings` 是 61.32 [【跳转到 17:19】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=1039)。同一个模型、同一批 token 级隐状态，只换池化方式，相关系数差了 30 个点——这本身就说明**池化不是无损的搬运，而是一个需要设计的选择**。

![STS 数据集上的对比：平均 BERT 句向量 46.35、CLS 向量 16.01、平均 GloVe 61.32；下半张表换成逻辑回归分类器后，BERT 的排名又完全不同](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/01039.webp)

### 3.1 实现细节：padding 不能参与平均

平均池化的公式里那个 $L$，必须是**真实 token 数**，不是补齐后的长度。一批长度不一的句子会被 pad 到同一长度，如果直接对补齐后的张量取平均，pad 位置的隐状态也会被算进去：

$$
\mathbf{e}_{\text{wrong}} = \frac{1}{L_{\max}}\sum_{i=1}^{L_{\max}} \mathbf{h}_i
\quad\text{vs}\quad
\mathbf{e}_{\text{right}} = \frac{\sum_{i=1}^{L} m_i \mathbf{h}_i}{\sum_{i=1}^{L} m_i}
$$

其中 $m_i \in \{0,1\}$ 是 attention mask。短句子被 pad 得越多，$\mathbf{e}_{\text{wrong}}$ 被稀释得越厉害——同一句话单独编码和放在一个长 batch 里编码会得到不同的向量。这是 mean pooling 在工程上最容易踩的坑，也是"池化是有损操作"的一个直接体现：**分母算错，语义就被稀释**。

## 四、池化丢的是组合信息：句向量反而更像"词袋"

论文最后做了一个很有意思的实验：比较**语义相似度**和**词汇相似度**（用编辑距离度量）的关系 [【跳转到 55:13】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=3313)。

拿"我喜欢这家餐厅"和"我不喜欢这家餐厅"举例：两句话语义完全相反，但编辑距离非常小，只差一个字。如果句向量真的编码了语义，它应该判断这两句"不相似"；如果它只是把词平均了一下，它就会判断"很相似"。

实验结果正是后者：金标准（人类标注的语义相似度）与编辑距离的斯皮尔曼相关系数只有 24.61，而 **BERT 句向量与编辑距离的相关系数高达 59.30** [【跳转到 56:13】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=3373)。

![语义相似度与编辑距离的关系：金标准与编辑距离相关性低，BERT 句向量却与编辑距离高度相关，散点图上编辑距离小的样本被压在相似度 0.75 以上](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/03433.webp)

散点图把这件事讲得更清楚：横轴是真实相似度、纵轴是编辑距离。金标准那张图里点是散的，没有明显规律；BERT 那张图里，编辑距离小于 5 的样本被压在相似度 0.75 以上，聚集得十分紧密 [【跳转到 58:13】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=3493)。

这说明池化之后的句向量**退化成了一个加权词袋**：它保留了"出现了哪些词"（所以和编辑距离高度相关），却丢掉了"这些词以什么顺序、什么结构组合"（所以否定词翻转不了判断）。这正是 token 级 → 全局级这一步的信息损失。

## 五、不改池化也能救：把空间掰正

论文的解法不是换池化方式，而是换**空间**：用一个可逆映射把 BERT 的句向量空间变换到高斯分布空间（BERT-flow）[【跳转到 47:42】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2862)。选高斯分布的理由有两条：

- **各向同性**：把锥体上的向量映射到一个球体，分布更均匀，缓解各向异性 [【跳转到 48:30】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2910)；
- **凸函数**：缓解"空洞"问题，让语义分布更平滑，相近的点更近、相远的点更远 [【跳转到 49:00】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=2940)。

这个映射是可逆的、可参数化成神经网络来训练的，训练时 BERT 本身的参数**保持不变**，只训练映射的参数，而且是无监督的 [【跳转到 50:29】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=3029)。

![BERT-flow 的设计动机：用高斯分布做向量转换，把锥体映射成球体以缓解各向异性，并用凸性缓解语义空洞](assets/从%20token%20到句向量：CLS%20池化、平均池化与各向异性造成的语义损失/02910.webp)

值得注意的是，作者与"丢弃前 $n$ 个奇异值"这类方法对比时特别强调：丢弃奇异值虽然效果接近，但**存在语义丢失**，而 BERT-flow 的映射是无损的 [【跳转到 54:43】](https://www.bilibili.com/video/BV1Q54y1T78a/?t=3283)。这提示了一个判据：任何"修句向量"的手段，先问它是**改空间**（可逆、无损）还是**删信息**（降维、丢弃）。

## 六、任务匹配：该用哪一级粒度

把上面的机制翻译成选择规则：

| 任务类型 | 该用的粒度 | 理由 |
| :--- | :--- | :--- |
| 序列标注、抽取式问答、NER | token 级 $\mathbf{h}_i$ | 答案本身就是一段位置，池化会把这层信息抹掉 |
| 句子对匹配（精度优先） | 片段/交互级 | 两句话进同一个编码器，对齐发生在词与短语之间 |
| 语义检索、聚类、去重（规模优先） | 全局句向量 | 必须能离线编码、预先建库，只能接受池化带来的损失 |
| 长文档里找一段 | 片段级池化 | 对候选 span 做池化，比整篇压成一个向量更保真 |

两条判据：

1. **答案是不是一段位置？** 是，就不要池化到全局；不是，才考虑压成一个向量。
2. **能不能离线编码？** 能离线，就必须接受池化；不能离线（要两两交互），就保留 token/片段级。

## 小结

- BERT 同时给出三种粒度的表示：token 级 `[B, L, H]`、片段级（对一段 token 池化）、全局级（CLS 或 mean）。粒度越粗，越能离线复用，丢的信息也越多。
- 池化不是无损搬运：mean 把句子压到 token 向量的重心，而重心可能落在低频词之间的语义空洞里；CLS 位置在预训练时没被训练成句子摘要，实测比 mean 差 30 个点。
- 池化丢的主要是**组合信息**：句向量与编辑距离的相关系数（59.30）远高于人类判断（24.61），说明它退化成了加权词袋。
- 各向异性是放大器：向量挤在窄锥里、方向趋同，余弦相似度对"不同"不敏感。
- 修法有两条路：改空间（BERT-flow，可逆无损）或删信息（丢弃奇异值，有语义丢失）；改池化方式（mean/max/CLS）只是其中一种选择。
- 工程上，mean pooling 的分母必须是真实 token 数（用 attention mask 加权），否则 padding 会稀释语义。
- 选粒度的两条判据：答案是不是一段位置；能不能离线编码。

## 关键术语速查

| 术语 | 一句话解释 |
| :--- | :--- |
| token 级表征 | BERT 每个位置输出的 $H$ 维隐状态，形状 `[B, L, H]`，上下文相关 |
| 片段级表征 | 对一段连续 token 的隐状态做池化得到的向量，用于 span 对齐与抽取 |
| 全局池化 | 把长度 $L$ 的序列压成一个固定长度向量，常见有 CLS、mean、max 三种 |
| mean pooling | 对全部 token 隐状态取平均，隐含"句子语义 = 词义平均"的假设 |
| CLS 向量 | 取 `[CLS]` 位置隐状态作为句子表示；预训练时它是 NSP 的输入位 |
| 各向异性 | 向量分布随方向变化，BERT 词向量挤在狭窄锥体内，高频词近原点、低频词远且稀疏 |
| 语义空洞 | 低频词之间缺乏定义的区域，平均池化后的句子向量容易落在这里 |
| BERT-flow | 用可逆的高斯分布映射把 BERT 句向量空间变换到各向同性空间 |
| 交互型 / 表示型模型 | 前者两句话进同一编码器在线交互，后者各自编码成向量后离线比较 |
