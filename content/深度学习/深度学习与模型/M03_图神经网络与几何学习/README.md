# M03 图神经网络与几何学习

编号：M03 · 类型：模型基础 · 目录规模：46 个小节（三级叶子节点，少于 100）。

**知识主线**：关系图 → 消息传递 → 三维对称性 → 几何预测与结构化约束。

**范围与边界**：区分一般 GNN 和三维等变网络；不是所有图模型都处理原子坐标。

**前置知识**：[M01 §1.1.1 向量、矩阵、张量与维度](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-1-1)、[M01 §2.1.2 多层感知机（MLP）：线性层、激活函数与任务头](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-2-1-2)；仅作为最低起点。 其余所需基础在下方章节使用处以 `[复用]` 小节编入，不要求通读任何上游脉络。

**组织与素材策略**：以可独立解释的一条计算或推断链为单元。先满足基础，再读模型；一个张量/参数不是一个独立课程。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 内容构成：36 个自有写作小节，10 个通用复用小节。`[REUSE]` 是终态，与 `[DONE]` 并列；计入本脉络小节规模，不另建正文，不参与认领。

## 2 图上的学习机制

<a id="m03-2-1"></a>

### 2.1 消息传递

- 2.1.1 邻域聚合、节点更新与读出 <a id="m03-2-1-1"></a> [DONE]
  - 学习目标：追踪一轮消息传递的聚合、更新与读出，说明层数与感受野的关系。
- 2.1.2 边特征与边更新：有向消息与键类型 <a id="m03-2-1-2"></a> [DONE]
  - 学习目标：说明边特征和方向如何进入消息与更新，解释键类型信息的传递路径。
- 2.1.3 图卷积（GCN）：邻域归一化与特征聚合 <a id="m03-2-1-3"></a> [DONE]
  - 学习目标：将具体图卷积与消息传递框架对应。
- 2.1.4 查询、键、值与自注意力 <a id="m03-2-1-4"></a> [REUSE](../M02_序列建模与大模型架构/README.md#m02-3-1-2)
  - 学习目标：说明查询、键、值与自注意力的计算关系；判断注意力权重如何分配信息；把多头注意力与序列、结构建模对应起来。
- 2.1.5 图注意力（GAT）：注意力权重与邻域聚合 <a id="m03-2-1-5"></a> [WAITING]
  - 学习目标：比较固定聚合与注意力聚合，不复制序列注意力全套基础。
- 2.1.6 谱图方法：图拉普拉斯、谱域滤波与谱卷积 <a id="m03-2-1-6"></a> [WAITING]
  - 学习目标：说明图拉普拉斯、谱域滤波与谱卷积；判断谱方法与空间消息传递的对应关系；注明与 2.3.2 拉普拉斯位置编码的分工。

<a id="m03-2-2"></a>

### 2.2 表达能力与失败模式

- 2.2.1 置换不变性与置换等变性 <a id="m03-2-2-1"></a> [DONE]
  - 学习目标：区分不变与等变输出，说明为什么图任务要求对节点顺序不敏感。
- 2.2.2 图网络过平滑与节点表示趋同 <a id="m03-2-2-2"></a> [DONE]
  - 学习目标：用多层聚合展示节点表示趋同。
- 2.2.3 图网络过压缩、信息瓶颈与远程依赖 <a id="m03-2-2-3"></a> [DONE]
  - 学习目标：区分信息瓶颈与表示趋同，不把二者当同一故障。

<a id="m03-2-3"></a>

### 2.3 图表示能力、位置编码与异质图

- 2.3.1 图表达能力：同构判别、WL 视角与消息传递边界 <a id="m03-2-3-1"></a> [DONE]
  - 学习目标：比较简单图中无法由局部聚合区分的结构，说明局部消息传递的能力边界，不要求完整图论证明。
- 2.3.2 图上的位置编码与结构编码：拉普拉斯特征向量、随机游走与距离编码 <a id="m03-2-3-2"></a> [DONE]
  - 学习目标：说明位置与结构编码如何弥补消息传递的局部性，比较几类编码的代价。
- 2.3.3 异质图学习：节点类型、关系类型与关系特定传播 <a id="m03-2-3-3"></a> [DONE]
  - 学习目标：用基因—通路—药物图解释多类型关系及参数共享，区分语义关系与无类型邻接。
- 2.3.4 图级表示：节点读出、池化与层级结构 <a id="m03-2-3-4"></a> [WAITING]
  - 学习目标：比较求和/均值读出和层级池化，说明节点顺序、图大小与预测对象的关系。

## 3 三维数据的对称性

<a id="m03-3-1"></a>

### 3.1 坐标变换

- 3.1.1 向量相似性：内积、夹角与距离 <a id="m03-3-1-1"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-1-2)
  - 学习目标：在同一向量例子中比较方向和距离。
- 3.1.2 旋转、平移、反射与手性 <a id="m03-3-1-2"></a> [DONE]
  - 学习目标：区分旋转、平移、反射与手性变换，说明哪些变换应保持物理结果。
- 3.1.3 几何变换下的不变预测与等变预测 <a id="m03-3-1-3"></a> [WAITING]
  - 学习目标：区分不变预测与等变预测的含义；判断任务需要严格等变还是只需不变；说明几何变换对标签和输出的约束。
- 3.1.4 对称性实现路线：不变量特征、数据增广与等变架构的取舍 <a id="m03-3-1-4"></a> [WAITING]
  - 学习目标：比较不变量特征、数据增广与等变架构三条路线；说明表达力、数据效率与计算代价的权衡；判断任务是否需要严格等变；避免把数据增广等同于架构等变。

<a id="m03-3-2"></a>

### 3.2 几何特征

- 3.2.1 分子内部几何：距离、键角与二面角 <a id="m03-3-2-1"></a> [DONE]
  - 学习目标：用同一分子比较内部几何量，说明刚体变换不变性、角度周期性及重建歧义。
- 3.2.2 局部坐标框架：基向量、相对位置与框架变换 <a id="m03-3-2-2"></a> [DONE]
  - 学习目标：从三个非共线点构造局部框架，解释相对变换及其在残基几何网络中的用途。
- 3.2.3 几何网络中的标量与向量特征 <a id="m03-3-2-3"></a> [WAITING]
  - 学习目标：追踪旋转下标量和向量的变换，说明不同类型特征可以使用的操作；不把通道数组都叫几何向量。
- 3.2.4 高阶几何特征：张量表示、球谐与特征耦合 <a id="m03-3-2-4"></a> [DONE]
  - 学习目标：通过一个方向编码示例认识高阶表示及耦合用途；只提供阅读等变网络所需基础，不要求完整表示论证明。

## 4 分子几何表示与等变网络

<a id="m03-4-1"></a>

### 4.1 等变网络

- 4.1.1 E(3)、SE(3) 等变及反射约束的差异 <a id="m03-4-1-1"></a> [WAITING]
  - 学习目标：对照 E(3) 与 SE(3) 的允许变换，说明反射约束对分子手性的影响。
- 4.1.2 等变消息传递：特征更新与坐标更新 <a id="m03-4-1-2"></a> [DONE]
  - 学习目标：以 EGNN 类计算解释坐标变换后一致的输出。

- 4.1.4 几何向量感知机（GVP）：标量—向量通道与等变更新 <a id="m03-4-1-4"></a> [DONE]
  - 学习目标：以一个残基图层解释向量线性组合、模长和标量门控，区分一般 MLP 与几何类型约束，不扩成全部等变架构综述。

- 4.2.1 局部邻接、长程接触与多尺度表示 <a id="m03-4-2-1"></a> [DONE]
  - 学习目标：说明局部邻接与长程接触的互补，解释多尺度表示如何扩大有效感受野。
- 4.2.2 键长、键角、排斥与合法结构 <a id="m03-4-2-2"></a> [DONE]
  - 学习目标：用键长、键角和原子排斥判断结构合法性，说明几何约束与能量项的分工。

## 5 图模型的预测任务与科学评估

<a id="m03-5-1"></a>

### 5.1 不同任务层级

- 5.1.1 导数、偏导与梯度：局部变化和最陡上升 <a id="m03-5-1-1"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-3-1)
  - 学习目标：用一个标量函数和二维损失面计算变化率，解释参数梯度；不要求完整高等数学课程。
- 5.1.2 链式法则与 Jacobian：复合函数和维度传递 <a id="m03-5-1-2"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-1-3-2)
  - 学习目标：从向量输入到标量损失追踪维度及局部导数，为反向传播和坐标力计算建立基础。
- 5.1.3 观测模型与损失函数：回归误差和分类交叉熵 <a id="m03-5-1-3"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-2-1-3)
  - 学习目标：说明回归与分类损失的选择；判断损失函数与任务输出、标签分布是否匹配；把损失设计与评价指标区分开。
- 5.1.4 梯度下降与随机优化：小批量、学习率与收敛 <a id="m03-5-1-4"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-2-2-2)
  - 学习目标：说明小批量、学习率与收敛的关系；判断图网络训练中的梯度问题；把优化配置与力/能量监督联系起来。
- 5.1.5 图模型的训练与监督信号：节点掩码、图级标签、力与能量监督 <a id="m03-5-1-5"></a> [DONE]
  - 学习目标：对照节点、图级、力与能量监督，说明监督粒度如何决定可学信息。
- 5.1.6 节点分类、边预测与图级性质 <a id="m03-5-1-6"></a> [DONE]
  - 学习目标：对照节点、边与图级任务的读出方式，说明标签粒度对评价的影响。
- 5.1.7 坐标生成、力预测与能量建模 <a id="m03-5-1-7"></a> [DONE]
  - 学习目标：区分坐标生成、力回归与能量预测的输出，说明力与能量的一致性要求。
- 5.1.8 能量与力的一致性：势能梯度、等变力与守恒约束 <a id="m03-5-1-8"></a> [DONE]
  - 学习目标：从标量能量对坐标求导得到力，比较直接回归向量和由势能导出力，说明几何对称和能量守恒的区别。

<a id="m03-5-2"></a>

### 5.2 评估结构与先验

- 5.2.1 供体、细胞系、扰动和化学骨架切分 <a id="m03-5-2-1"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-5-1-2)
  - 学习目标：说明化学骨架切分如何防止图先验泄漏；判断随机切分与骨架切分的差别；把切分策略与图先验评估对应起来。
- 5.2.2 模型验证：基线对照、消融实验与外部验证 <a id="m03-5-2-2"></a> [REUSE](../../数学与统计基础/M01_统计学习与科学评估基础/README.md#m01-5-2-1)
  - 学习目标：将“高分不等于实验成功”纳入同一证据评估案例，而非另找一句话视频。
- 5.2.3 力与能量预测的误差评估：力分量误差、能量误差与分层报告 <a id="m03-5-2-3"></a> [DONE]
  - 学习目标：说明力分量误差、能量误差与相对误差的差别；判断分层报告（元素、环境、构象）的必要性；比较力与能量的误差传播；避免只用总能量误差评价力场。
- 5.2.4 图先验评估：覆盖范围、知识泄漏与化学约束 <a id="m03-5-2-4"></a> [DONE]
  - 学习目标：将化学合法性、知识泄漏和先验覆盖作为一个图模型评估案例的检查项。
- 5.2.5 图核与分子指纹基线：子图核、WL 核与相似性检索 <a id="m03-5-2-5"></a> [DONE]
  - 学习目标：用图核与指纹建立非神经基线，说明它们在分子性质预测中的适用条件。
