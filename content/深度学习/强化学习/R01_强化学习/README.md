# R01 强化学习

编号：R01 · 类型：模型专题 · 目录规模：70 个小节（三级叶子节点）。

> 博客已从 `content/reinforcement_learning` 迁入对应小节，状态更新为 `[DONE]`。

## 脉络章程

**知识主线**：从 MDP 与贝尔曼方程出发，沿动态规划、蒙特卡洛、时序差分、DQN、策略梯度、Actor-Critic、PPO/SAC、基于模型、模仿/离线/MARL 到大模型 RL，形成一条完整的强化学习课程线。

**一句话范围**：不展开 LLM 架构与推理系统（归 M02/S01）；RL for LLMs 作为本脉络最后一章，只讲强化学习侧。

**学习入口 → 学习出口**：概率、线性代数、深度学习基础（可复用 M01/M02） → 能推导贝尔曼方程与策略梯度，能读懂 PPO/GRPO 等算法，能判断一个 RL 应用该用哪类方法。

**完整问题链**：
1. 强化学习与监督学习的边界是什么？
2. 如何用 MDP 描述一个序贯决策问题？
3. 已知模型时如何精确求解？
4. 未知模型时如何从采样中估计价值？
5. 如何把预测与控制统一到 TD 框架？
6. 状态连续、表格放不下时怎么办？
7. 如何直接优化策略而不是价值？
8. 如何降低策略梯度的方差并稳定训练？
9. 现代深度 RL 算法（TRPO/PPO/SAC）各自解决什么问题？
10. 如何利用环境模型、搜索和世界模型？
11. 没有奖励、只有专家演示时怎么学？
12. 只能使用离线数据时怎么避免 OOD 高估？
13. 多个智能体同时学习时有什么新问题？
14. 大模型时代的 RLHF/DPO/GRPO 分别对应哪些 RL 组件？

**与相邻脉络的关系**：上游是 M01 的概率/优化与 M02 的序列建模；下游是 M02 的大模型架构与 S01 的推理系统。
