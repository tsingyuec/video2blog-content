## 编号与层级

编号按“域 → 分类 → 学习顺序”编排，同一域内连续：

- **生命科学**：B（生命科学基础）→ D（生物数据）→ P（生物建模）。
- **深度学习**：M01 数学与统计 → M02 序列建模与大模型架构 → M03 图与几何 → M04 扩散 → R01 强化学习。
- **计算机系统**：S01 大模型推理系统 → S02 GPU 内核与性能工程 → S03 容器隔离、镜像、运行时与网络 → S04 Kubernetes 集群。
- 云原生与容器按“容器隔离/镜像/运行时/网络数据面 → Kubernetes 编排”由浅入深排列，K8s 作为进阶内容放在最后。
- S02 按“硬件 → 编程 → 剖析 → 案例 → 优化 → 编译器”排列，先理解 GPU，再写内核，再测，再以 FlashAttention 为完整案例，最后看编译器如何自动生成内核。

## 组织规则

- **模型侧与系统侧分开**：模型架构、深度学习、科学建模、强化学习归“深度学习”；推理系统、GPU 内核、云原生归“计算机系统”。
- **生物专有模型归生命科学**：P01–P10 是面向生物分子、结构、抗体、核酸、细胞与扰动的建模，放在 `生命科学/生物建模/`。
- **深度学习不再设“通用方法”筐**：M02 序列建模与大模型架构、M03 图与几何、M04 扩散同属“深度学习与模型”，不再按来源仓库割裂。
- **脉络是完整学习线**：每条脉络能独立从入口走到出口；不按书的章节或课程讲次机械拆分。
- **100 节是复审触发器**：超过时先写脉络章程，证明是否真的需要拆；S01 目前 104 节、S03 目前 105 节，作为有理由的例外保留或后续再拆。
- **一篇博客一个规范归宿**：其他小节用 `[REUSE]` 引用，不复制正文。
- **杂项** 收录碎片化、不成体系的内容，不设状态机，不计入脉络小节数；容器网络排障已归入 `杂项/工具与排障/`。
- **课程系列**（cs336、minimind、vllm 等）作为 M02/S01/S02 的素材来源，不单列脉络。
