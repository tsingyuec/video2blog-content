# 未迁移博客归入分析

对象：`docs/unmigrated-blogs.txt` 中的 271 篇（相对 `content/` 尚未迁移的博客）。最终 23 篇纳入脉络，其余 248 篇归档到 `content/杂项/`。

判定标准不是“主题相关”，而是：

1. 目标小节必须是 `[WAITING]`（`[DONE]` 已有内容，`[REUSE]` 已指向别处，均不能挂）；
2. 博客内容要能对上该小节的**学习目标/边界**，而不是只命中关键词；
3. 一个小节最多接收 1–3 篇，避免把同一节堆成资料库；
4. 如果目标小节已有同主题博客，或该博客只是 `[DONE]` 小节的替代讲法，则不归入。

---

## 结论

- **可直接归入：23 篇**，分布在 16 个 `[WAITING]` 小节。
- **相关但不够严格、需要逐篇复核：约 20–25 篇**。
- **其余约 220 篇不建议归入现有课程小节**：多数是工具/环境配置、课程绪论、观点与评测、实验操作流程，或已经是 `[DONE]` 小节的替代材料。
